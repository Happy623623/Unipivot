## Day 2 — API 뼈대 (Dev 1)

```text
docs/API_뼈대_구현.md에 있는 파일을 적힌 경로(api/, supabase/ci/, .github/workflows/)에 그대로 만들어줘.
내용은 바꾸지 마. 그다음 api에서 uv sync, uv run ruff check ., uv run pytest를 돌려서 결과를 알려줘.

다 만든 뒤 두 가지를 더 고쳐줘.
1. .github/workflows/ci.yml의 api 작업에서, 마이그레이션을 적용하는 단계 바로 뒤에
   psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f supabase/ci/schema_checks.sql 단계를 넣어줘.
2. api/tests의 test_profile_repository_roundtrip에서, 테스트 시작 때 departments에
   ('인공지능학과', '테스트대학', '공학계열')을 넣고, 저장하는 값의
   "welfare_status": "none"을 "enrollment_status": "enrolled"로 바꿔줘.
```

ERD v0.9에서 프로필 학과가 `departments` FK가 되고, 소득·수급 값은 선택 동의 없이는 저장할 수 없다. 위 2번을 안 고치면 DB 테스트가 그 두 제약에 걸린다.

- [ ] `11 passed, 2 skipped`(DB 테스트는 `DATABASE_URL`이 없으면 건너뜀)
- [ ] `uv run uvicorn app.main:app --reload` → `http://localhost:8000/docs`에 API 5개가 보인다
