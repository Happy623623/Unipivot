# 준비하기 — 서류 안내와 역산 준비 일정 (F-30·F-31)

> 📝 기준: PRD v0.9 F-30·F-31 · API 명세 v0.4 2·7·11·13장 · ERD v0.9 · 2026-10-14
>
> 기준 커밋: main `0af9303`(#26 전남광주통합특별시 판정). 그 앞은 #25 홈 목록(`768c724`)이다

공고 상세의 "준비 일정 만들기"를 실제로 돌아가게 했다. 누르면 공고의 필요 서류마다 발급처·방법·소요 일수를 채우고, 마감일에서 거꾸로 세어 할 일을 만든다. 지금까지 이 버튼은 실제 모드에서 "준비 중"이라고만 알렸다.

**규모와 확인:**
- api 새 파일 11개·바꾸는 파일 8개(`.env.example` 포함), 테스트 새 파일 5개·바꾸는 파일 1개, web 새 파일 1개·바꾸는 파일 5개다.
- **DB 변경이 없다.** 쓰는 테이블(`prep_plans`·`planner_tasks`·`opportunity_documents`·`agent_runs`·`tool_calls`·`llm_calls`)은 이미 있다. 합친 뒤 db push가 필요 없다.
- 새 에러 코드 `DEADLINE_PASSED`(409)를 API 명세 13장에 같은 PR에서 더한다(레포 규칙).
- api `ruff check`·`ruff format --check` 통과, `552 passed, 66 skipped`(DB 없이) · `618 passed`(새 DB). web `typecheck`·`build` 통과(라우트 11개).
- 실제 모드 E2E로 여섯 경우를 눌러 봤다(아래 "확인한 것"). 목 모드도 함께 봤다.
- 되돌림 시험(변이) api 4가지·web 1가지를 해서 모두 테스트·E2E가 잡는 것을 봤다.
- 따로 띄운 검토 에이전트가 한 번 봤다. 지적 가운데 8가지를 고쳤고(아래 "검토에서 고친 것"), 바로 고치지 않은 4가지는 "남은 것"에 적었다.

## 정한 것

| 항목 | 정한 것 | 이유 |

| 응답 방식 | `POST /opportunities/{id}/prepare` → `202 {run_id, status:"running"}`. 서류 안내·역산은 뒤에서 돌고 `GET /runs/{id}`로 진행과 결과를 본다 | 모델을 부르는 작업이라 수 초가 걸린다(API 명세 2장). 단계 표시(F-42)와 지표가 `agent_runs`→`tool_calls`→`llm_calls`에서 나온다 |
| 작업 큐 | FastAPI `BackgroundTasks` 대신 `TaskRunner`(요청과 따로 도는 asyncio 작업)다. 서버를 끌 때 10초까지 기다린다 | `BackgroundTasks`는 요청의 의존성 정리 **전에** 돌아서, 일이 끝날 때까지 요청 트랜잭션과 프로필 잠금을 붙잡는다. 명세 2장의 "BackgroundTasks로 시작" 문장을 이 PR에서 고친다 |
| 다시 누름 | 이미 준비했거나 준비 중이면 `200`과 그 실행이다. 5분(`STALE_AFTER_SECONDS`) 넘게 running인 실행은 멈춘 것으로 보고 계획을 지운 뒤 새로 만든다. 실패하면 계획이 남지 않아 다시 누르면 새로 만든다. 두 번 눌러도 계획은 하나다(`(사용자, 공고)` 유니크) | 버튼을 두 번 눌러도 할 일이 두 벌 생기면 안 된다. 서버가 일 도중 꺼져도 다음 누름이 스스로 푼다 |
| 누를 때 판정 | 상세와 같은 방법으로 지금 프로필로 다시 판정한다. 지원 어려움은 `409 NOT_ELIGIBLE`이고 `force: true`면 진행한다 | 화면을 열어 둔 사이 프로필이 바뀌었을 수 있다. "그래도 준비하기"는 PRD F-31의 확인 절차다 |
| 마감 지난 공고 | 막는다. 새 코드 `409 DEADLINE_PASSED` | 10/14 선택. 지난 날짜로 역산하면 할 일이 모두 오늘로 뭉친다 |
| 상시 공고 | `target_date`가 필수다(없거나 어제 이전이면 `422`, 항목 문구를 `details.fields.target_date`에 담는다) | `planner_tasks.due_date`가 NOT NULL이다(ERD). 화면에서 목표일을 받는다 |
| 서류 안내 | 코드 사전(`app/prepare/documents.py`, 27가지)이 먼저고, 사전에 없는 서류만 모델에 **한 번** 묻는다(`GUIDE_MODEL=gemini-3.5-flash-lite`, `submit_document_guides` 강제 도구). 채운 값은 `opportunity_documents`에 남아 다음 학생은 묻지 않는다 | LLM 비용을 최대한 들이지 않는다(핵심 결정). 재학증명서·주민등록등본처럼 자주 내는 서류는 모델이 필요 없다 |

| 역산 규칙 | "○○ 준비" = 마감 2일 전 − 발급 소요일(모르면 1일), "신청 제출" = 마감 1일 전. 오늘보다 앞선 날짜는 오늘로 둔다. 서류 수와 서류 할 일 수가 같다(PRD F-31) | 10/14 선택. 지난 날짜가 생기지 않게 한다 |
| 모델 호출 자리 | 읽기 → **모델(트랜잭션 밖)** → 쓰기(공고 잠금 + 한 트랜잭션) 순이다. 잠근 뒤 서류를 다시 읽어, 묻는 사이 다른 학생이 넣거나 채운 값을 그대로 쓰고 빈 칸만 채운다(`coalesce`) | 모델을 부르는 동안 요청 풀의 연결과 공고 행 잠금을 쥐면, 같은 공고를 준비하는 다른 학생이 그만큼 기다린다 |
| 모델 호출 상한 | 서류 안내 호출 하나에 60초 상한을 둔다(`guide.TIMEOUT_SECONDS`). 멈춤 기준(300초)보다 짧고, 테스트가 이 관계를 지킨다 | Gemini 클라이언트는 한 번에 120초이고 3번까지 다시 보내서 6분을 넘길 수 있다. 그러면 아직 도는 실행을 다음 누름이 멈춘 것으로 보고 지운다 |
| 실패했을 때 | 서류 안내와 할 일은 한 트랜잭션이라 아무것도 남지 않고, 계획 행을 지워 다시 누를 수 있다. 실행 기록은 실패로 남고 running으로 남지 않게 닫는다. 쓰기 직전에 계획 행이 사라졌으면(다음 누름이 지웠다) 쓰지 않고 그 요청에 넘긴다 | 반쯤 만든 일정이 "준비한 공고"로 보이면 안 된다. 열린 채 남은 실행은 지표를 더럽힌다 |
| 거절과 계획 지우기 | 멈춘·실패한 계획은 마감·숨김·지원 어려움·목표일 검사를 **모두 지난 뒤에** 지운다 | 숨김 공고는 준비한 사람에게만 보인다. 먼저 지우면 거절당한 학생이 그 공고를 다시 열지 못한다 |
| 실패 이유 | `ApiError`면 "코드: 문구"로 남겨 `GET /runs/{id}`의 `error`로 그대로 보여 준다. 그 밖의 예외는 `INTERNAL_ERROR`와 정해진 문구다 | 학생에게 보일 문구와 내부 기록을 가른다. DB 오류 글이 화면에 나가지 않는다 |
| 웹 준비 상태 | `PREPARE_READY`를 지우고 `TASKS_READY`·`PLANNER_READY`·`CALENDAR_READY`(= `USE_MOCKS`)로 나눴다. 준비하기는 실제 API를 부르고, 서류 체크·플래너 바로가기·캘린더 등록은 각자의 API가 생길 때까지 꺼 둔다 | 준비하기만 실제가 되면 `PREPARE_READY`는 늘 true여서 죽은 가지가 된다. 아직 없는 기능이 새어 보이면 안 된다(web/CLAUDE.md) |
| 캘린더 | `register_calendar`·`calendar_provider`는 받기만 하고 등록하지 않는다. 결과의 `calendar_event`·`calendar_error`는 null이다. 화면은 체크 칸을 그리지 않고 "아직 준비 중" 한 줄만 보인다 | F-32는 다음다음 PR이다. 쓸 수 없는 칸을 보여 주지 않는다 |

## 합친 뒤 확인

모델 키(`GOOGLE_CLOUD_PROJECT`)가 있어야 사전에 없는 서류와 청년정책 서류 목록을 채운다. 키가 없으면 그 공고는 "필요 서류를 확인하지 못했어요"로 끝난다(사전에 있는 서류만 든 공고는 키 없이도 된다).

1. **API 다시 띄우기:** 8000 포트에 이전 API가 남아 있으면 준비하기 경로가 없어 404가 난다. PowerShell에서 남은 uvicorn을 끄고 다시 띄운 뒤, `http://localhost:8000/docs`에 `POST /api/v1/opportunities/{opportunity_id}/prepare`와 `GET /api/v1/runs/{run_id}`가 있는지 본다.

   ```powershell
   Get-CimInstance Win32_Process -Filter "Name='python.exe'" | Where-Object { $_.CommandLine -match 'uvicorn|spawn_main' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
   Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue
   ```

2. **학교 공지 준비하기:** 지원 가능한 공고를 열고 "준비 일정 만들기"를 누른다. "필요 서류 확인 → 마감일에서 거꾸로 일정 짜기"가 차례로 완료가 되고, 서류마다 "○○ 준비"와 마지막 "신청 제출"이 날짜와 함께 나온다. 필요 서류 칸에 발급처와 받는 방법이 보인다.
3. **다시 누르기:** 같은 공고를 다시 열면 "서류 n/N 완료" 막대가 보이고, 준비하기를 다시 눌러도 할 일이 늘지 않는다.
4. **청년정책:** 상시 공고는 목표일을 고르기 전에는 버튼이 눌리지 않는다. 고르고 누르면 제출 서류 글에서 만든 서류가 나온다.
5. **지원 어려움·마감:** 지원 어려움 공고의 "그래도 준비하기" → "그래도 만들기"로 일정이 만들어진다. 마감이 지난 공고는 "마감이 지난 공고예요. 준비 일정을 만들 수 없어요."가 뜬다.
6. **아직인 것:** 서류 체크 칸은 눌리지 않고 "서류 체크는 아직 준비 중이에요"가 붙는다. 캘린더 체크 칸은 보이지 않고 안내 한 줄만 있다. 플래너에는 아직 이 할 일이 보이지 않는다(플래너 API는 다음 PR).

## 남은 것

- **실행 로그 연결을 실행 내내 쥔다(검토 지적):** `agent_run`이 로그 연결 하나를 실행이 끝날 때까지 들고 있어서, 모델이 느리면 로그 풀(`max_size=5`)이 준비하기의 동시 처리 수를 정한다. 여섯 번째 요청부터는 연결을 기다리다 500이 날 수 있다. 호출 상한을 60초로 줄여 창을 좁혀 뒀다. 제대로 고치려면 ① 로그를 쓸 때만 연결을 빌리도록 `agent_log`를 바꾸거나 ② 로그 풀을 키우고 대기 시간을 짧게 잡아 바로 `503`으로 떨어뜨린다. 요건 추출·수집도 같은 구조라 따로 한다.
- **청년정책을 다시 수집하면 준비하기가 넣은 서류가 지워진다(검토 지적):** 재수집은 공고의 서류를 모두 지우고 다시 넣는데, 청년정책은 넣을 서류가 없어 빈 목록이 된다. 그러면 이미 준비한 학생의 서류 목록이 비고 할 일의 서류 연결이 끊긴다. 정기 수집을 켜기 전에 고친다(준비하기가 넣은 행은 지우지 않거나, 청년정책은 서류를 지우지 않는다).
- **동시에 두 번 누르면 버린 실행이 failed로 남는다:** 사용자에게는 200으로 정상 응답하지만 `agent_runs`에는 실패가 쌓인다. 성공률 지표를 뽑을 때(W9–10) 이 실행을 뺄지 정한다.
- **InlineRunner가 가리는 겹침:** DB 테스트는 일을 응답 전에 끝내는 `InlineRunner`로 돈다. 실제 `TaskRunner`로 바꿔 끼운 겹침 테스트와 풀 고갈 테스트가 없다.
- **서류를 하나도 못 고른 청년정책:** 제출 서류 글에서 서류가 하나도 나오지 않으면 다음 학생이 누를 때 모델을 다시 부른다(한 번에 몇 원 수준이라 두고 본다).
- **플래너·캘린더:** 서류 체크(`PATCH /planner/tasks/{id}`)와 플래너 API는 다음 PR, 캘린더 등록(F-32)은 그다음 PR이다. 그때 `TASKS_READY`·`PLANNER_READY`·`CALENDAR_READY`를 지운다.

```python
"""요청이 끝난 뒤 이어서 할 일(준비하기 실행). API 명세 2장의 202 + run_id 작업이 쓴다.

FastAPI BackgroundTasks는 요청의 의존성(DB 연결·트랜잭션)이 그 일을 마칠 때까지 닫히지 않아 프로필 잠금을
붙잡는다. 그래서 요청과 따로 asyncio 작업으로 돌리고, 일은 자기 연결을 따로 연다.
테스트는 InlineRunner로 바꿔 응답 전에 끝까지 돌린다.
"""

import asyncio
import logging
from collections.abc import Coroutine
from typing import Annotated, Any

from fastapi import Depends, Request

logger = logging.getLogger(__name__)


class TaskRunner:
    def __init__(self) -> None:
        self._tasks: set[asyncio.Task[None]] = set()

    async def start(self, job: Coroutine[Any, Any, None]) -> None:
        """일을 띄우고 바로 돌아온다. 일 안의 예외는 일이 스스로 기록한다(여기서는 로그만)."""
        task = asyncio.create_task(job)
        self._tasks.add(task)
        task.add_done_callback(self._finished)

    def _finished(self, task: asyncio.Task[None]) -> None:
        self._tasks.discard(task)
        if not task.cancelled() and (error := task.exception()) is not None:
            logger.error("뒤에서 돌던 일이 실패했어요: %r", error)

    async def drain(self, timeout: float) -> None:
        """서버를 끌 때 돌던 일을 timeout초까지 기다린다. 못 끝낸 일은 다음 요청이 멈춘 실행으로 본다."""
        if self._tasks:
            await asyncio.wait(set(self._tasks), timeout=timeout)


class InlineRunner(TaskRunner):
    """테스트용: 일을 그 자리에서 끝까지 돌린다."""

    async def start(self, job: Coroutine[Any, Any, None]) -> None:
        await job


def get_runner(request: Request) -> TaskRunner:
    return request.app.state.runner


RunnerDep = Annotated[TaskRunner, Depends(get_runner)]
```

```python
@dataclass(frozen=True)
class GuideDraft:
    name: str
    issuer: str | None
    how_to: str | None
    lead_days: int | None
    effort_minutes: int | None
    is_required: bool = True


class GuideError(Exception):
    """모델 답을 쓸 수 없다(도구를 부르지 않았거나 모양이 틀렸다)."""


def prompt(title: str, organizer: str | None, names: Sequence[str] | None, text: str | None) -> str:
    head = f"공고: {title}" + (f" ({organizer})" if organizer else "")
    if names:
        listed = "\n".join(f"{index}. {name}" for index, name in enumerate(names, 1))
        return f"{head}\n{_NAMES_TASK}\n{listed}"
    return f"{head}\n{_TEXT_TASK}\n---\n{text or ''}\n---"


async def ask_guides(
    llm: LlmClient,
    *,
    model: str,
    title: str,
    organizer: str | None,
    names: Sequence[str] | None = None,
    text: str | None = None,
) -> tuple[list[GuideDraft], LlmReply]:
    """names를 주면 그 서류만(모델이 빼먹은 이름은 빠진다), text를 주면 글에서 고른 서류를 돌려준다.

    TIMEOUT_SECONDS를 넘기면 TimeoutError다(부르는 쪽에서 LLM_TIMEOUT).
    """
    async with asyncio.timeout(TIMEOUT_SECONDS):
        reply = await llm.generate(
            model=model,
            system=SYSTEM,
            turns=[UserTurn(prompt(title, organizer, names, text))],
            tools=[TOOL],
            force_tool=TOOL_NAME,
        )
    calls = [call for call in reply.turn.tool_calls if call.name == TOOL_NAME]
    raw = calls[0].args.get("documents") if calls else None
    if not isinstance(raw, list):
        raise GuideError("서류 안내 도구를 부르지 않았어요.")
    drafts = _drafts(raw)
    if names:  # 물어본 이름만 남긴다(이름을 조금 바꿔 답해도 같은 서류면 받는다)
        wanted = {normalize(name): name for name in names}
        drafts = [
            replace(draft, name=wanted[normalize(draft.name)])
            for draft in drafts
            if normalize(draft.name) in wanted
        ]
    return _unique(drafts)[:MAX_DOCUMENTS], reply


def _drafts(items: list[Any]) -> list[GuideDraft]:
    drafts = []
    for item in items:
        if not isinstance(item, dict):
            continue
        name = _short(item.get("name"), _NAME_LIMIT)
        if name is None:
            continue
        drafts.append(
            GuideDraft(
                name=name,
                issuer=_short(item.get("issuer"), _ISSUER_LIMIT),
                how_to=_short(item.get("how_to"), _HOW_LIMIT),
                lead_days=_whole(item.get("lead_days"), _LEAD_MAX),
                effort_minutes=_whole(item.get("effort_minutes"), _EFFORT_MAX) or None,
                is_required=item.get("is_required") is not False,
            )
        )
    return drafts


def _unique(drafts: list[GuideDraft]) -> list[GuideDraft]:
    seen: set[str] = set()
    unique = []
    for draft in drafts:
        if (key := normalize(draft.name)) and key not in seen:
            seen.add(key)
            unique.append(draft)
    return unique


def _short(value: Any, limit: int) -> str | None:
    """공백을 한 칸으로 줄인 한 줄. 비었으면 None, 길면 자른다."""
    if not isinstance(value, str):
        return None
    text = " ".join(value.split())
    return text[:limit].rstrip() or None


def _whole(value: Any, limit: int) -> int | None:
    """0–limit 정수. 숫자가 아니면 None, 넘치면 limit."""
    if isinstance(value, bool) or not isinstance(value, int | float):
        return None
    return max(0, min(limit, int(value)))
```

#### `api/app/prepare/plan.py`

```python
"""역산 준비 일정(F-31, PRD 6장 build_prep_plan). 코드로만 만든다.

서류마다 "○○ 준비" 할 일 하나(마감 2일 전 − 소요 일수)와 마지막 "신청 제출" 할 일 하나(마감 1일 전)다.
오늘보다 앞선 날짜는 오늘로 둬서 지난 할 일이 생기지 않게 한다(API 명세 7장). 상시 공고는 학생이 고른
목표일을 마감일처럼 쓴다.
"""

from collections.abc import Sequence
from dataclasses import dataclass
from datetime import date, timedelta

SUBMIT_TITLE = "신청 제출"
DOCUMENT_BUFFER_DAYS = 2  # 서류는 마감 이틀 전까지 갖춘다
SUBMIT_BUFFER_DAYS = 1  # 신청은 마감 하루 전에 낸다
UNKNOWN_LEAD_DAYS = 1  # 소요 일수를 모르는 서류는 하루를 둔다


@dataclass(frozen=True)
class PlanDocument:
    id: str
    name: str
    lead_days: int | None


@dataclass(frozen=True)
class TaskDraft:
    title: str
    due_date: date
    document_id: str | None
    sort_order: int


def build_tasks(documents: Sequence[PlanDocument], deadline: date, today: date) -> list[TaskDraft]:
    """서류 할 일(서류 순서대로)과 신청 제출 할 일. 서류 수와 서류 할 일 수가 같다(PRD F-31)."""

    def due(days_before: int) -> date:
        return max(today, deadline - timedelta(days=days_before))

    tasks = [
        TaskDraft(
            title=f"{document.name} 준비",
            due_date=due(
                DOCUMENT_BUFFER_DAYS
                + (UNKNOWN_LEAD_DAYS if document.lead_days is None else document.lead_days)
            ),
            document_id=document.id,
            sort_order=index,
        )
        for index, document in enumerate(documents)
    ]
    tasks.append(TaskDraft(SUBMIT_TITLE, due(SUBMIT_BUFFER_DAYS), None, len(tasks)))
    return tasks
```

#### `api/app/prepare/service.py`

```python
"""준비하기 실행(PRD 6장 "준비하기 버튼": get_document_guide → build_prep_plan).

POST /opportunities/{id}/prepare(라우터)가 판정·확인을 마치면 begin이 실행 행과 계획 행을 만들고 일을 띄운다.
일(execute)은 요청과 따로 돌며 자기 연결을 연다.

일은 읽기 → 모델 → 쓰기 셋으로 나눈다. 모델 호출은 트랜잭션 밖이라 묻는 동안 DB 연결(요청 풀)과 공고 행
잠금을 쥐지 않는다. 쓰기(서류 안내 + 할 일)는 공고를 잠근 한 트랜잭션이고, 잠근 뒤 서류를 다시 읽어 그새
다른 학생이 넣거나 채운 값을 그대로 쓴다. 실패하면 아무것도 남지 않고 계획 행을 지워 다시 누를 수 있다.
실행 기록(agent_runs·tool_calls·llm_calls)은 실패해도 남고, running으로 남지 않게 닫는다.
"""

import logging
from collections.abc import Callable
from contextlib import AbstractAsyncContextManager, AsyncExitStack
from dataclasses import dataclass, field
from datetime import date, datetime
from typing import Annotated

from fastapi import Depends, Request
from psycopg import AsyncConnection

from app.agent_log import AgentRun, ToolCall, abandon_run, agent_run, start_run
from app.background import RunnerDep, TaskRunner
from app.config import Settings, get_settings
from app.errors import ApiError
from app.llm import LlmClient
from app.llm.deps import LlmDep
from app.prepare.documents import Guide, lookup
from app.prepare.guide import GuideDraft, GuideError, ask_guides
from app.prepare.plan import PlanDocument, build_tasks
from app.repositories.opportunities import OpportunityRepository
from app.repositories.prepare import DocumentRow, OpportunityText, PlanState, PrepareRepository
from app.schemas.opportunities import OpportunityDetail
from app.youth.convert import raw_section

logger = logging.getLogger(__name__)
Connect = Callable[[], AbstractAsyncContextManager[AsyncConnection]]
GUIDE_FAILED = "필요 서류를 확인하지 못했어요. 잠시 후 다시 눌러 주세요."
STOPPED = "준비 일정을 만들다 멈췄어요. 다시 눌러 주세요."


@dataclass(frozen=True)
class PrepareJob:
    run_id: str
    plan_id: str
    user_id: str
    opportunity_id: str
    deadline: date  # 마감일(KST 날짜). 상시 공고는 학생이 고른 목표일
    today: date  # 요청한 날(KST). 이보다 앞선 할 일은 이날로 둔다


@dataclass(frozen=True)
class Asked:
    """모델에 물어 온 것. 쓰기 트랜잭션을 열기 전에 다 받아 둔다."""

    listed: list[GuideDraft] | None = None  # 청년정책 '제출 서류' 글에서 만든 서류 목록
    guides: dict[str, GuideDraft] = field(default_factory=dict)  # 사전에 없던 서류의 이름 → 안내


@dataclass(frozen=True)
class Started:
    run_id: str | None
    status: str  # running | succeeded
    created: bool  # 이번 요청이 시작했다(202). 아니면 그새 다른 요청이 시작한 계획(200)


class PrepareService:
    def __init__(
        self,
        *,
        transaction: Connect,
        log_connection: Connect,
        llm: LlmClient | None,
        model: str,
        runner: TaskRunner,
    ) -> None:
        self.transaction = transaction  # 블록이 끝나면 커밋하는 연결(요청 트랜잭션과 따로)
        self.log_connection = log_connection  # autocommit 연결(agent_run)
        self.llm = llm
        self.model = model
        self.runner = runner

    async def judge(
        self, user_id: str, opportunity_id: str, *, now: datetime, display_name: str | None
    ) -> OpportunityDetail | None:
        """상세와 같이 지금 프로필로 다시 판정한다(프로필 잠금 포함). 보이지 않는 공고면 None.

        요청 트랜잭션을 쓰지 않고 바로 커밋한다. 뒤에서 도는 일과 잠금을 나눠 갖지 않게 한다.
        """
        async with self.transaction() as conn:
            return await OpportunityRepository(conn).detail(
                user_id, opportunity_id, now=now, display_name=display_name
            )

    async def plan(self, user_id: str, opportunity_id: str) -> PlanState | None:
        async with self.transaction() as conn:
            return await PrepareRepository(conn).plan(user_id, opportunity_id)

    async def reset(self, plan: PlanState) -> None:
        """멈췄거나 실패한 계획을 지운다. 실행 중으로 남은 실행은 실패로 닫는다."""
        async with self.transaction() as conn:
            await PrepareRepository(conn).drop_plan(plan.id)
        if plan.run_id:
            await self._close(plan.run_id)

    async def begin(
        self, user_id: str, opportunity_id: str, *, deadline: date, today: date
    ) -> Started:
        """실행 행과 계획 행을 만들고 일을 띄운다. 그새 다른 요청이 계획을 만들었으면 그 계획을 준다."""
        async with self.log_connection() as log_conn:
            run_id = await start_run(log_conn, trigger="prepare", user_id=user_id)
        try:
            async with self.transaction() as conn:
                plan_id = await PrepareRepository(conn).create_plan(user_id, opportunity_id, run_id)
        except Exception:  # 계획 행을 만들지 못했다. 실행이 running으로 남지 않게 닫는다
            await self._close(run_id)
            raise
        if plan_id is None:
            await self._close(run_id, "같은 공고를 이미 준비하고 있어요.")
            existing = await self.plan(user_id, opportunity_id)
            if existing is None:  # 그 계획도 그새 실패해 지워졌다. 다시 누르면 된다
                raise ApiError(500, "INTERNAL_ERROR", STOPPED)
            status = "succeeded" if existing.done else "running"
            return Started(existing.run_id, status, created=False)
        job = PrepareJob(run_id, plan_id, user_id, opportunity_id, deadline, today)
        work = self.execute(job)
        try:
            await self.runner.start(work)
        except Exception:  # 일을 띄우지 못했다. 계획을 지워 다시 누를 수 있게 한다
            work.close()
            await self._give_up(job)
            raise
        return Started(run_id, "running", created=True)

    async def execute(self, job: PrepareJob) -> None:
        """서류 안내 → 역산 일정. 실패하면 계획을 지운다(실행은 실패로 남는다)."""
        try:
            async with self.log_connection() as log_conn:
                async with agent_run(
                    log_conn, trigger="prepare", user_id=job.user_id, run_id=job.run_id
                ) as run:
                    await self._prepare(run, job)
        except Exception:
            logger.exception("준비하기 실행 실패: run %s", job.run_id)
            await self._give_up(job)

    async def _give_up(self, job: PrepareJob) -> None:
        """계획을 지우고 실행을 닫는다. 로그 연결을 얻지 못해 agent_run 밖에서 끝난 경우까지 닫는다."""
        try:
            async with self.transaction() as conn:
                await PrepareRepository(conn).drop_plan(job.plan_id)
        except Exception:
            logger.exception("실패한 준비 계획을 지우지 못했어요: plan %s", job.plan_id)
        await self._close(job.run_id)

    async def _close(self, run_id: str, message: str = STOPPED) -> None:
        """아직 running인 실행을 실패로 닫는다(이미 닫혔으면 그대로 둔다).

        닫지 못해도 다음 누름이 멈춘 실행으로 보고 지운다(repositories/prepare.py의 STALE_AFTER).
        """
        try:
            async with self.log_connection() as log_conn:
                await abandon_run(log_conn, run_id, ApiError(500, "INTERNAL_ERROR", message))
        except Exception:
            logger.exception("준비하기 실행을 닫지 못했어요: run %s", run_id)

    async def _prepare(self, run: AgentRun, job: PrepareJob) -> None:
        """읽기 → 모델 → 쓰기. 쓰기 트랜잭션은 모델 호출이 끝난 뒤에 열어 두 단계가 함께 커밋된다."""
        async with AsyncExitStack() as stack:
            async with run.tool(
                "get_document_guide", {"opportunity_id": job.opportunity_id}
            ) as call:
                asked = await self._ask_guides(run, call, job)  # 트랜잭션 밖(모델)
                conn = await stack.enter_async_context(self.transaction())
                repo = PrepareRepository(conn)
                if not await repo.lock_plan(job.plan_id):
                    # 묻는 사이에 다음 누름이 멈춘 실행으로 보고 계획을 지웠다. 그 요청에 넘긴다
                    raise ApiError(500, "INTERNAL_ERROR", STOPPED)
                documents, counts = await self._save_guides(repo, job, asked)
                call.output = {"documents": len(documents), **counts}
            plan_input = {
                "opportunity_id": job.opportunity_id,
                "deadline": job.deadline.isoformat(),
                "documents": len(documents),
            }
            async with run.tool("build_prep_plan", plan_input) as call:
                tasks = build_tasks(
                    [PlanDocument(doc.id, doc.name, doc.lead_days) for doc in documents],
                    job.deadline,
                    job.today,
                )
                await repo.add_tasks(job.user_id, job.plan_id, tasks)
                call.output = {"tasks": len(tasks)}

    async def _ask_guides(self, run: AgentRun, call: ToolCall, job: PrepareJob) -> Asked:
        """모델에 물을 것만 묻는다. 공고 행을 잠그지 않고, 묻는 동안 DB 연결도 쥐지 않는다."""
        async with self.transaction() as conn:
            repo = PrepareRepository(conn)
            opportunity = await repo.opportunity(job.opportunity_id)
            if opportunity is None:  # 그새 공고가 지워졌다
                raise ApiError(404, "NOT_FOUND", "공고를 찾을 수 없어요.")
            documents = await repo.documents(job.opportunity_id)
        if not documents and opportunity.source_type == "youth_policy":
            text = raw_section(opportunity.raw_text, "제출 서류")
            if text:  # 청년정책은 서류 행이 없다. 제출 서류 글에서 목록과 안내를 함께 만든다
                drafts = await self._ask(run, call, opportunity, text=text)
                # 묻는 사이에 서류 행이 생겼으면 목록은 버리고 안내만 이름으로 맞춰 쓴다
                return Asked(listed=drafts, guides={draft.name: draft for draft in drafts})
        unknown = [
            document.name
            for document in documents
            if not document.guided and lookup(document.name) is None
        ]
        if not unknown:  # 사전으로 다 되거나 이미 채워진 공고는 모델을 부르지 않는다
            return Asked()
        drafts = await self._ask(run, call, opportunity, names=unknown)
        return Asked(guides={draft.name: draft for draft in drafts})

    async def _save_guides(
        self, repo: PrepareRepository, job: PrepareJob, asked: Asked
    ) -> tuple[list[DocumentRow], dict[str, int]]:
        """공고를 잠그고 서류를 다시 읽어 빈 칸만 채운다. 채운 값은 공고에 남아 다른 학생도 쓴다."""
        if await repo.lock_opportunity(job.opportunity_id) is None:  # 그새 공고가 지워졌다
            raise ApiError(404, "NOT_FOUND", "공고를 찾을 수 없어요.")
        documents = await repo.documents(job.opportunity_id)
        counts = {"dictionary": 0, "model": 0, "unknown": 0, "listed": 0}
        if asked.listed is not None and not documents:  # 그새 다른 학생이 넣었으면 그 서류를 쓴다
            drafts = [_with_dictionary(draft) for draft in asked.listed]
            await repo.add_documents(job.opportunity_id, drafts)
            counts["listed"] = len(drafts)
            documents = await repo.documents(job.opportunity_id)
        guides: list[tuple[str, Guide]] = []
        for document in documents:
            if document.guided:  # 이미 채워져 있다(다른 학생이 준비한 공고)
                continue
            if guide := lookup(document.name):
                guides.append((document.id, guide))
                counts["dictionary"] += 1
            elif draft := asked.guides.get(document.name):
                guides.append((document.id, _guide(draft)))
                counts["model"] += 1
            else:  # 모델도 답하지 않은 서류. 소요 일수는 계획에서 하루로 둔다
                counts["unknown"] += 1
        await repo.save_guides(guides)
        return await repo.documents(job.opportunity_id), counts

    async def _ask(
        self,
        run: AgentRun,
        call: ToolCall,
        opportunity: OpportunityText,
        *,
        names: list[str] | None = None,
        text: str | None = None,
    ) -> list[GuideDraft]:
        if self.llm is None:
            raise ApiError(502, "LLM_ERROR", GUIDE_FAILED)
        try:
            drafts, reply = await ask_guides(
                self.llm,
                model=self.model,
                title=opportunity.title,
                organizer=opportunity.organizer,
                names=names,
                text=text,
            )
        except TimeoutError as exc:
            raise ApiError(502, "LLM_TIMEOUT", GUIDE_FAILED) from exc
        except GuideError as exc:
            raise ApiError(502, "LLM_ERROR", GUIDE_FAILED) from exc
        except Exception as exc:
            logger.warning("서류 안내 모델 호출 실패: %r", exc)
            raise ApiError(502, "LLM_ERROR", GUIDE_FAILED) from exc
        await run.record_llm(
            provider=self.llm.provider,
            model=self.model,
            input_tokens=reply.usage.input_tokens,
            output_tokens=reply.usage.output_tokens,
            latency_ms=reply.latency_ms,
            tool_call=call,
        )
        return drafts


def _guide(draft: GuideDraft) -> Guide:
    return Guide(draft.issuer, draft.how_to, draft.lead_days, draft.effort_minutes)


def _with_dictionary(draft: GuideDraft) -> GuideDraft:

    if guide := lookup(draft.name):
        return GuideDraft(
            draft.name,
            guide.issuer,
            guide.how_to,
            guide.lead_days,
            guide.effort_minutes,
            draft.is_required,
        )
    return draft

    request: Request,
    llm: LlmDep,
    runner: RunnerDep,

    return PrepareService(
```

```python
계획 행은 준비하기를 누를 때(POST) 실행 id와 함께 먼저 만든다. (사용자, 공고) 유니크라 두 번 눌러도 하나다.
실행이 실패하면 계획을 지워 다시 누를 수 있게 한다. 실행이 성공해야 준비한 공고로 본다

from dataclasses import dataclass

from psycopg import AsyncConnection

from app.prepare.documents import Guide

# 실행 중인 채로 이만큼 지난 계획은 멈춘 것(서버가 꺼짐 등)으로 보고 다시 만든다.
# 준비하기가 한 번에 쓸 수 있는 시간보다 길어야 한다(서류 안내 모델 호출 상한은
# app/prepare/guide.py의 TIMEOUT_SECONDS이고, test_prepare_rules가 이 관계를 지킨다)
STALE_AFTER_SECONDS = 300
STALE_AFTER = f"{STALE_AFTER_SECONDS} seconds"


@dataclass(frozen=True)
class PlanState:
    id: str
    run_id: str | None
    run_status: str | None  # 실행 기록이 지워졌으면 None
    stale: bool  # 실행 중으로 STALE_AFTER가 지났다

    @property
    def done(self) -> bool:
        """준비를 마쳤다(실행 성공, 또는 실행 기록이 없다)."""
        return self.run_id is None or self.run_status == "succeeded"

    @property
    def running(self) -> bool:
        return self.run_status == "running" and not self.stale


@dataclass(frozen=True)
class OpportunityText:
    title: str
    organizer: str | None
    source_type: str
    raw_text: str | None


@dataclass(frozen=True)
class DocumentRow:
    id: str
    name: str
    issuer: str | None
    lead_days: int | None

    @property
    def guided(self) -> bool:
        """안내를 한 번이라도 채웠다. 모델이 소요 일수를 숫자로 주지 않아도 다시 묻지 않는다."""
        return self.issuer is not None or self.lead_days is not None


class PrepareRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def plan(self, user_id: str, opportunity_id: str) -> PlanState | None:
        row = await (
            await self.conn.execute(
                "select p.id, p.agent_run_id, r.status::text as run_status,"
                " coalesce(r.status = 'running' and r.started_at < now() - %s::interval, false)"
                " as stale"
                " from prep_plans p left join agent_runs r on r.id = p.agent_run_id"
                " where p.user_id = %s and p.opportunity_id = %s",
                (STALE_AFTER, user_id, opportunity_id),
            )
        ).fetchone()
        if row is None:
            return None
        run_id = row["agent_run_id"]
        return PlanState(
            id=str(row["id"]),
            run_id=str(run_id) if run_id else None,
            run_status=row["run_status"],
            stale=row["stale"],
        )

    async def create_plan(self, user_id: str, opportunity_id: str, run_id: str) -> str | None:
        """계획 행. 그새 다른 요청이 만들었으면 None."""
        row = await (
            await self.conn.execute(
                "insert into prep_plans (user_id, opportunity_id, agent_run_id) values (%s, %s, %s)"
                " on conflict (user_id, opportunity_id) do nothing returning id",
                (user_id, opportunity_id, run_id),
            )
        ).fetchone()
        return str(row["id"]) if row else None

    async def lock_plan(self, plan_id: str) -> bool:
        """계획 행이 아직 있나(잠근다). 멈춘 실행으로 보고 지운 뒤면 False다."""
        row = await (
            await self.conn.execute(
                "select id from prep_plans where id = %s for update", (plan_id,)
            )
        ).fetchone()
        return row is not None

    async def drop_plan(self, plan_id: str) -> None:
        """계획과 그 할 일(on delete cascade)을 지운다."""
        await self.conn.execute("delete from prep_plans where id = %s", (plan_id,))

    async def opportunity(self, opportunity_id: str) -> OpportunityText | None:
        """공고 글. 잠그지 않는다(모델에 묻기 전에 읽는 쪽)."""
        return await self._opportunity(opportunity_id, lock=False)

    async def lock_opportunity(self, opportunity_id: str) -> OpportunityText | None:
        """공고 행을 잠근다. 같은 공고를 여럿이 함께 준비해도 서류는 한 번만 넣는다.

        모델 호출은 이 잠금 밖에서 한다(app/prepare/service.py). 잠근 뒤에는 서류를 다시 읽어
        그새 다른 학생이 넣거나 채운 값을 그대로 쓴다.
        """
        return await self._opportunity(opportunity_id, lock=True)

    async def _opportunity(self, opportunity_id: str, *, lock: bool) -> OpportunityText | None:
        row = await (
            await self.conn.execute(
                "select title, organizer, source_type::text as source_type, raw_text"
                " from opportunities where id = %s" + (" for no key update" if lock else ""),
                (opportunity_id,),
            )
        ).fetchone()
        if row is None:
            return None
        return OpportunityText(row["title"], row["organizer"], row["source_type"], row["raw_text"])

    async def documents(self, opportunity_id: str) -> list[DocumentRow]:
        """공고 서류. 상세와 같은 순서(필수 먼저, 이름 순)다."""
        rows = await (
            await self.conn.execute(
                "select id, name, issuer, lead_days from opportunity_documents"
                " where opportunity_id = %s"
                " order by coalesce(is_required, true) desc, name, id",
                (opportunity_id,),
            )
        ).fetchall()
        return [
            DocumentRow(str(row["id"]), row["name"], row["issuer"], row["lead_days"])
            for row in rows
        ]

    async def add_documents(self, opportunity_id: str, drafts: Sequence[GuideDraft]) -> None:
        """청년정책의 제출 서류 글에서 만든 서류(안내 포함)."""
        for draft in drafts:
            await self.conn.execute(
                "insert into opportunity_documents (opportunity_id, name, issuer, how_to, lead_days,"
                " effort_minutes, is_required) values (%s, %s, %s, %s, %s, %s, %s)",
                (
                    opportunity_id,
                    draft.name,
                    draft.issuer,
                    draft.how_to,
                    draft.lead_days,
                    draft.effort_minutes,
                    draft.is_required,
                ),
            )

    async def save_guides(self, guides: Sequence[tuple[str, Guide]]) -> None:

            await self.conn.execute(
                "update opportunity_documents set issuer = coalesce(issuer, %s),"
                " how_to = coalesce(how_to, %s), lead_days = coalesce(lead_days, %s),"
                " effort_minutes = coalesce(effort_minutes, %s) where id = %s",
                (guide.issuer, guide.how_to, guide.lead_days, guide.effort_minutes, document_id),
            )

    async def add_tasks(self, user_id: str, plan_id: str, tasks: Sequence[TaskDraft]) -> None:
        for task in tasks:
            await self.conn.execute(
                "insert into planner_tasks (user_id, source, prep_plan_id, document_id, title,"
                " due_date, sort_order) values (%s, 'prep_plan', %s, %s, %s, %s, %s)",
                (user_id, plan_id, task.document_id, task.title, task.due_date, task.sort_order),
            )
```

```python
from datetime import datetime
from typing import Annotated, Any

from psycopg import AsyncConnection

# 준비하기 단계 이름(화면의 처리 과정). 정해진 순서로 도는 단계라 chosen_by는 pipeline이다
PREPARE_LABELS = {
    "get_document_guide": "필요 서류 확인",
    "build_prep_plan": "마감일에서 거꾸로 일정 짜기",

FAILED_MESSAGE = "준비 일정을 만들지 못했어요. 잠시 후 다시 눌러 주세요."
_CODED = re.compile(r"^([A-Z][A-Z_]+): (.+)$", re.S)  # agent_log.error_text의 "코드: 문구"


@dataclass(frozen=True)
class RunRow:
    id: str
    user_id: str | None
    trigger_type: str
    status: str
    started_at: datetime | None
    finished_at: datetime | None
    latency_ms: int | None
    error_message: str | None

    def error(self) -> RunError | None:
        """학생에게 보여 줄 실패 이유. ApiError로 남긴 것만 그대로 보여 주고 나머지는 내부 기록이다."""
        if self.status != "failed":
            return None
        if self.error_message and (match := _CODED.match(self.error_message)):
            return RunError(code=match.group(1), message=match.group(2))
        return RunError(code="INTERNAL_ERROR", message=FAILED_MESSAGE)


class RunRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def run(self, run_id: str) -> RunRow | None:
        row = await (
            await self.conn.execute(
                "select id, user_id, trigger_type, status::text as status, started_at, finished_at,"
                " latency_ms, error_message from agent_runs where id = %s",
                (run_id,),
            )
        ).fetchone()
        if row is None:
            return None
        return RunRow(
            id=str(row["id"]),
            user_id=str(row["user_id"]) if row["user_id"] else None,
            trigger_type=row["trigger_type"],
            status=row["status"],
            started_at=_kst(row["started_at"]),
            finished_at=_kst(row["finished_at"]),
            latency_ms=row["latency_ms"],
            error_message=row["error_message"],
        )

    async def steps(self, run_id: str) -> list[ProcessStep]:
        rows = await (
            await self.conn.execute(
                "select seq, tool_name, status::text as status, latency_ms from tool_calls"
                " where run_id = %s order by seq, id",
                (run_id,),
            )
        ).fetchall()
        return [
            ProcessStep(
                seq=row["seq"],
                tool=row["tool_name"],
                label=PREPARE_LABELS.get(row["tool_name"], row["tool_name"]),
                status=row["status"],
                latency_ms=row["latency_ms"],
                chosen_by="pipeline",
                note=None,
            )
            for row in rows
        ]

    async def prepare_result(self, user_id: str, run_id: str) -> PrepareResult | None:
        """그 실행이 만든 내 계획. 없으면(지워짐) None."""
        plan = await (
            await self.conn.execute(
                "select id, opportunity_id from prep_plans where agent_run_id = %s and user_id = %s",
                (run_id, user_id),
            )
        ).fetchone()
        if plan is None:
            return None
        params: dict[str, Any] = {"plan": plan["id"], "oid": plan["opportunity_id"]}
        documents = await (
            await self.conn.execute(
                "select d.id::text as id, d.name, d.issuer, d.how_to, d.lead_days, d.effort_minutes,"
                " d.form_url, coalesce(d.is_required, true) as is_required,"
                " t.id::text as task_id, t.is_done"
                " from opportunity_documents d left join planner_tasks t"
                " on t.prep_plan_id = %(plan)s and t.document_id = d.id"
                " where d.opportunity_id = %(oid)s"
                " order by coalesce(d.is_required, true) desc, d.name, d.id",
                params,
            )
        ).fetchall()
        tasks = await (
            await self.conn.execute(
                "select id::text as id, title, due_date, document_id::text as document_id"
                " from planner_tasks where prep_plan_id = %(plan)s order by sort_order, due_date, id",
                params,
            )
        ).fetchall()
        return PrepareResult(
            prep_plan_id=str(plan["id"]),
            documents=[DocumentItem(**row) for row in documents],
            tasks=[PrepTask(**row) for row in tasks],
            calendar_event=None,  # 캘린더 등록(F-32)은 다음 작업
            calendar_error=None,
        )
```

```python
from fastapi import APIRouter

from app.auth import CurrentUserDep
from app.errors import ApiError
from app.repositories.runs import RunRepoDep
from app.schemas.prepare import RunView

router = APIRouter(prefix="/runs", tags=["실행"])


@router.get("/{run_id}", response_model=RunView)
async def read_run(run_id: UUID, user: CurrentUserDep, repo: RunRepoDep) -> RunView:
    """실행 진행·결과(API 명세 11장). 본인 실행만 본다. 배치 실행은 403, 남의 실행·없는 실행은 404다.

    steps는 처리 과정(F-42)이고, 끝나면 result(준비하기는 계획·서류·할 일)나 error(코드·문구)가 붙는다.
    """

    if run is not None and run.user_id is None:
        raise ApiError(403, "FORBIDDEN", "이 실행은 볼 수 없어요.")
    if run is None or run.user_id != user.id:
        raise ApiError(404, "NOT_FOUND", "실행을 찾을 수 없어요.")
    result = None
    if run.status == "succeeded" and run.trigger_type == "prepare":
        result = await repo.prepare_result(user.id, run.id)
    return RunView(
        id=run.id,
        trigger_type=run.trigger_type,
        status=run.status,
        started_at=run.started_at,
        finished_at=run.finished_at,
        latency_ms=run.latency_ms,
        steps=await repo.steps(run.id),
        result=result,
        error=run.error(),
    )
```

```python
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager
from dataclasses import dataclass

from typing import Any

SECRET_HINTS = ("token", "secret", "password", "authorization", "api_key")
# 프로필 값은 LLM에도 로그에도 넣지 않는다(PRD 6장). 실수로 들어와도 여기서 지운다
PROFILE_KEYS = frozenset(PROFILE_FIELDS)
_KST = timezone(timedelta(hours=9))


def _hidden(key: str) -> bool:
    lowered = key.lower()
    return lowered in PROFILE_KEYS or any(hint in lowered for hint in SECRET_HINTS)


def scrub(value: Any) -> Any:
    """비밀값이나 프로필 항목 이름의 키는 값을 지운다. tool_calls에 남지 않게 하는 마지막 안전장치."""
    if isinstance(value, dict):
        return {
            key: "[REDACTED]" if _hidden(str(key)) else scrub(item) for key, item in value.items()
        }
    if isinstance(value, list):
        return [scrub(item) for item in value]
    return value


def _elapsed_ms(started: float) -> int:
    return int((time.perf_counter() - started) * 1000)


@dataclass
class ToolCall:
    id: str
    output: Any = None


@dataclass
class AgentRun:
    conn: AsyncConnection
    id: str
    input_tokens: int = 0
    output_tokens: int = 0
    cost_usd: Decimal = Decimal(0)
    _seq: int = 0

    @asynccontextmanager
    async def tool(self, name: str, input: dict[str, Any] | None = None) -> AsyncIterator[ToolCall]:
        self._seq += 1
        started = time.perf_counter()
        cursor = await self.conn.execute(
            "insert into tool_calls (run_id, seq, tool_name, input, status)"
            " values (%s, %s, %s, %s, 'running') returning id",
            (self.id, self._seq, name, Jsonb(scrub(input or {}))),
        )
        call = ToolCall(id=str((await cursor.fetchone())["id"]))
        status = "failed"
        try:
            yield call
            status = "succeeded"
        finally:
            output = Jsonb(scrub(call.output)) if call.output is not None else None
            await self.conn.execute(
                "update tool_calls set output = %s, status = %s, latency_ms = %s where id = %s",
                (output, status, _elapsed_ms(started), call.id),
            )

    async def record_llm(
        self,
        *,
        provider: str,
        model: str,
        input_tokens: int,
        output_tokens: int,
        latency_ms: int,
        cost_usd: Decimal | float | None = None,
        tool_call: ToolCall | None = None,
        priced_on: date | None = None,
    ) -> None:
        """LLM 호출 1건. cost_usd를 빼면 priced_on(기본: 오늘 KST)의 단가로 계산한다."""
        if cost_usd is None:
            on = priced_on or datetime.now(_KST).date()
            cost = priced_cost(provider, model, input_tokens, output_tokens, on)
        else:
            cost = Decimal(str(cost_usd))
        await self.conn.execute(
            "insert into llm_calls (run_id, tool_call_id, provider, model, input_tokens,"
            " output_tokens, cost_usd, latency_ms) values (%s, %s, %s, %s, %s, %s, %s, %s)",
            (
                self.id,
                tool_call.id if tool_call else None,
                provider,
                model,
                input_tokens,
                output_tokens,
                cost,
                latency_ms,
            ),
        )
        self.input_tokens += input_tokens
        self.output_tokens += output_tokens
        self.cost_usd += cost


async def start_run(
    conn: AsyncConnection,
    *,
    trigger: str,
    user_id: str | None = None,
    scenario_code: str | None = None,
) -> str:
    """실행 행만 만든다(status running). 이어서 agent_run(run_id=...)으로 기록하거나 abandon_run으로 닫는다."""
    _require_autocommit(conn)
    cursor = await conn.execute(
        "insert into agent_runs (user_id, trigger_type, scenario_code) values (%s, %s, %s)"
        " returning id",
        (user_id, trigger, scenario_code),
    )
    return str((await cursor.fetchone())["id"])


async def abandon_run(conn: AsyncConnection, run_id: str, error: ApiError) -> None:
    """시작하지 않을 실행을 실패로 닫는다(같은 공고를 그새 다른 요청이 준비하기 시작했을 때 등)."""
    await conn.execute(
        "update agent_runs set status = 'failed', finished_at = now(), latency_ms = 0,"
        " error_message = %s where id = %s and status = 'running'",
        (error_text(error), run_id),
    )


@asynccontextmanager
async def agent_run(
    conn: AsyncConnection,
    *,
    trigger: str,
    user_id: str | None = None,
    scenario_code: str | None = None,
    run_id: str | None = None,
) -> AsyncIterator[AgentRun]:
    """실행 하나를 기록한다. conn은 autocommit이어야 실패한 실행도 남는다(db.get_log_conn).

    run_id를 주면 start_run으로 만든 행을 이어서 쓴다(latency_ms는 여기부터 잰다).
    """
    _require_autocommit(conn)
    started = time.perf_counter()
    if run_id is None:
        run_id = await start_run(
            conn, trigger=trigger, user_id=user_id, scenario_code=scenario_code
        )
    run = AgentRun(conn=conn, id=run_id)
    try:
        yield run
    except Exception as exc:
        await _finish(run, started, "failed", error_text(exc))
        raise
    await _finish(run, started, "succeeded", None)


def error_text(exc: BaseException) -> str:
    """agent_runs.error_message. ApiError는 "코드: 문구", 그 밖은 내부 기록(repr)이다."""
    if isinstance(exc, ApiError):
        return f"{exc.code}: {exc.message}"[:500]
    return repr(exc)[:500]


def _require_autocommit(conn: AsyncConnection) -> None:
    if not conn.autocommit:
        raise RuntimeError("agent_run에는 autocommit 연결(get_log_conn)을 넘겨야 해요.")


async def _finish(run: AgentRun, started: float, status: str, error: str | None) -> None:
    await run.conn.execute(
        "update agent_runs set status = %s, finished_at = now(), latency_ms = %s,"
        " input_tokens = %s, output_tokens = %s, cost_usd = %s, error_message = %s where id = %s",
        (
            status,
            _elapsed_ms(started),
            run.input_tokens,
            run.output_tokens,
            run.cost_usd,
            error,
            run.id,
        ),
    )
```

```python
        " o.apply_start_at, o.source_type::text as source_type,"
        " e.user_id is not null as had_result, e.status::text as old_status,"
        " e.missing_fields as old_missing, " + _REQUIREMENTS_JSON + " as requirements"
        " from opportunities o"
        + _COURSE_JOIN
        + _RESULT_JOIN
        + " where"
        + scope
        + " and"
        + _VISIBLE
        + " and o.extraction_run_id is not null"
        " and (%(force)s or e.user_id is null or e.evaluated_at is null"
        " or e.requirements_version <> o.requirements_version"
        " or e.engine_version <> %(engine)s"
        # 날이 바뀌면 다시: 기준일이 "오늘"인 공고(청년정책 포함), 엔진 오류로 판정하지 못한 공고(오류를
        # 고쳤을 수 있다)
        " or (((o.eligibility_basis_date is null and (o.deadline_at is null"
        " or (o.source_type = 'youth_policy' and o.deadline_at >= %(now)s)))"
        " or e.reason_text = %(engine_error)s)"
        " and (e.evaluated_at at time zone 'Asia/Seoul')::date < %(today)s))"
    )

@dataclass(frozen=True)
class Cursor:
    scope: str  # 목록 조건(정렬·필터)의 지문. 조건이 다른 목록에는 쓸 수 없다
    # 마지막 행의 정렬 값(deadline: 마감 시각, recent: 등록 시각). 없을 수 있다
    value: datetime | None
    id: str


@dataclass(frozen=True)
class FeedQuery:
    eligibility: frozenset[str] | None = None  # None이면 전체
    categories: tuple[str, ...] | None = None
    source_types: tuple[str, ...] | None = None
    sort: Sort = "deadline"
    include_expired: bool = False
    include_not_interested: bool = False  # 관심 없음 공고도 준다(F-45)
    limit: int = 20
    cursor: Cursor | None = None

    def scope(self) -> str:
        """cursor를 묶는 목록 조건의 지문. 정렬이나 필터를 바꾸면 목록을 처음부터 다시 부른다.

        같은 목록이면 지문도 같다: 값의 순서는 보지 않고, 모든 값을 고른 필터는 필터 없음과 같다.
        """
        parts = (
            self.sort,
            _filter_key(self.eligibility, ELIGIBILITY_STATUSES),
            _filter_key(self.categories, CATEGORIES),
            _filter_key(self.source_types, SOURCE_TYPES),
            str(self.include_expired),
            str(self.include_not_interested),
        )
        return hashlib.sha256("|".join(parts).encode()).hexdigest()[:16]


def _filter_key(values: Collection[str] | None, everything: Collection[str]) -> str:
    chosen = set(values or ())
    return "" if chosen >= set(everything) else ",".join(sorted(chosen))


@dataclass(frozen=True)
class FeedPage:
    items: list[OpportunityItem]

@dataclass(frozen=True)
class Refresh:
    judged: int  # 다시 계산한 공고 수
    changed: int  # 라벨이 바뀐 공고 수(전에 판정이 있던 공고만 센다)


def display_status(status: str, missing_fields: Sequence[str]) -> str:
    """화면 라벨 4종. 판정 불가는 입력하면 바뀔 수 있으면 정보 필요, 아니면 원문 확인 필요다."""
    if status == "undetermined":
        return "missing_info" if missing_fields else "needs_review"
    return status


def encode_cursor(cursor: Cursor) -> str:
    data = {
        "q": cursor.scope,
        "v": cursor.value.isoformat() if cursor.value else None,
        "id": cursor.id,
    }
    raw = json.dumps(data, separators=(",", ":")).encode()
    return base64.urlsafe_b64encode(raw).decode().rstrip("=")


def decode_cursor(text: str) -> Cursor:
    """next_cursor로 준 값을 되돌린다. 모양이 틀리면 ValueError."""
    try:
        data = json.loads(base64.urlsafe_b64decode(text + "=" * (-len(text) % 4)))
        scope, value, ident = data["q"], data["v"], data["id"]
        if not isinstance(scope, str) or not isinstance(ident, str):
            raise ValueError(scope)
        moment = None if value is None else datetime.fromisoformat(value)
        if moment is not None and moment.tzinfo is None:
            raise ValueError(value)
        return Cursor(scope=scope, value=moment, id=str(uuid.UUID(ident)))
    except (binascii.Error, ValueError, KeyError, TypeError, UnicodeDecodeError) as exc:
        raise ValueError("잘못된 cursor") from exc


class OpportunityRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def refresh_judgments(
        self,
        user_id: str,
        *,
        now: datetime,
        force: bool = False,
        include_expired: bool = False,
        display_name: str | None = None,
    ) -> Refresh:
        """피드에 나올 공고(include_expired면 지난 공고까지)의 낡은 판정을 다시 계산해 저장한다.

        force면 그 공고를 모두 다시 판정하고 나머지 공고의 판정은 지운다.
        프로필 행이 없으면(첫 요청이 피드) display_name과 함께 만든다.
        """
        profile = Profile.from_row(await self._lock_profile(user_id, display_name))
        today = now.astimezone(KST).date()
        stale = await (
            await self.conn.execute(
                _stale_sql(_WITH_EXPIRED if include_expired else _ACTIVE),
                {
                    "uid": user_id,
                    "now": now,
                    "force": force,
                    "engine": ENGINE_VERSION,
                    "engine_error": ENGINE_ERROR_SUMMARY,
                    "today": today,
                },
            )
        ).fetchall()
        payload: list[dict[str, Any]] = []
        changed = 0
        if stale:
            departments = await self._departments()
            for item in stale:
                judged = _judge(item, profile, departments, today)
                payload.append(_payload(item, judged.stored))
                old = display_status(item["old_status"] or "", item["old_missing"] or ())
                if item["had_result"] and old != judged.label:
                    changed += 1
        await self._upsert(user_id, payload, now)
        if force:  # 다시 판정하지 않은 공고(마감·숨김·안 보임)의 판정은 지운다
            await self.conn.execute(
                "delete from eligibility_results"
                " where user_id = %s and opportunity_id <> all(%s::uuid[])",
                (user_id, [item["opportunity_id"] for item in payload]),
            )
        else:  # 요건 추출에 실패한 공고의 옛 판정은 지운다(판정하지 않는다)
            await self.conn.execute(
                "delete from eligibility_results e using opportunities o"
                " where e.user_id = %s and e.opportunity_id = o.id and o.extraction_run_id is null",
                (user_id,),
            )
        return Refresh(judged=len(payload), changed=changed)

    async def detail(
        self,
        user_id: str,
        opportunity_id: str,
        *,
        now: datetime,
        display_name: str | None = None,
    ) -> OpportunityDetail | None:
        """공고 상세(S1-6). 이 사용자에게 보이지 않는 공고면 None이다.

        피드와 같은 잠금 아래에서 그 공고를 다시 판정해 저장하고, 조회 기록을 남긴다(is_new가 꺼진다).
        """
        profile_row = await self._lock_profile(user_id, display_name)
        row = await (
            await self.conn.execute(_DETAIL, {"uid": user_id, "oid": opportunity_id})
        ).fetchone()
        if row is None:
            return None
        if row["extraction_run_id"] is None:  # 요건 추출에 실패한 공고는 판정하지 않는다
            await self.conn.execute(
                "delete from eligibility_results where user_id = %s and opportunity_id = %s",
                (user_id, opportunity_id),
            )
            eligibility = DetailEligibility(
                status="undetermined",
                display_status="needs_review",
                reason_text=UNJUDGED_SUMMARY,
                basis_date=None,
                requirements_version=row["requirements_version"],
                missing_fields=[],
                clauses=[],
                conditions=[],
                evaluated_at=None,
            )
        else:
            profile = Profile.from_row(profile_row)
            departments = await self._departments()
            judged = _judge(row, profile, departments, now.astimezone(KST).date())
            await self._upsert(user_id, [_payload(row, judged.stored)], now)
            eligibility = _detail_eligibility(
                judged, profile, departments, row["requirements_version"], now
            )
        await self.conn.execute(_VIEW, (user_id, opportunity_id, now, now))
        names = {item["seq"]: item["file_name"] for item in row["attachments"]}
        apply_start: datetime | None = row["apply_start_at"]
        deadline: datetime | None = row["deadline_at"]
        confidence = row["extraction_confidence"]
        return OpportunityDetail(
            id=str(row["id"]),
            title=row["title"],
            organizer=row["organizer"],
            category=row["category"],
            source_type=row["source_type"],
            status=row["status"],
            original_url=row["original_url"],
            poster_url=None,  # TODO(W6): 포스터 업로드에서 Storage 서명 URL(5분)을 붙인다
            easy_summary=row["easy_summary"],
            apply_start_at=apply_start.astimezone(KST) if apply_start else None,
            deadline_at=deadline.astimezone(KST) if deadline else None,
            needs_review=bool(row["needs_review"]),
            review_reasons=_lines(row["review_reasons"]),
            extraction_confidence=float(confidence) if confidence is not None else None,
            uploaded_by_me=row["uploaded_by_me"],
            course_name=row["course_name"],
            attachments=[_attachment(item) for item in row["attachments"] if item["source_url"]],
            eligibility=eligibility,
            documents=[DocumentItem(**document) for document in row["documents"]],
            prep=Prep(
                prepared=row["prep_done"],
                prep_plan_id=_text(row["prep_plan_id"]) if row["prep_done"] else None,
                tasks_total=row["tasks_total"],
                tasks_done=row["tasks_done"],
                calendar_events=[CalendarEventRef(**event) for event in row["calendar_events"]],
            ),
            process=Process(
                extraction=[_step(step, names) for step in row["steps"]],
                evaluated_at=eligibility.evaluated_at,
                prepare_run_id=_text(row["prepare_run_id"]),
            ),
            reported_by_me=row["reported_by_me"],
            my_mark=row["my_mark"],
        )

    async def set_mark(
        self,
        user_id: str,
        opportunity_id: str,
        mark: str,
        *,
        now: datetime,
        display_name: str | None = None,
    ) -> datetime | None:
        """관심·관심 없음 표시(F-45). 상세를 열 수 있는 공고에만 붙인다. 아니면 None.

        공고마다 표시는 하나다. 다른 표시를 보내면 바꾼다. 프로필 행이 없으면(첫 요청) 만든다.
        피드처럼 프로필 행을 잠근다: 피드 응답 하나의 목록(my_mark)과 숫자(counts)가 어긋나지 않는다.
        """
        await self._lock_profile(user_id, display_name)
        params = {"uid": user_id, "oid": opportunity_id, "mark": mark, "now": now}
        if await (await self.conn.execute(_MARK_OPENABLE, params)).fetchone() is None:
            return None
        row = await (await self.conn.execute(_MARK_UPSERT, params)).fetchone()
        assert row is not None
        return row["marked_at"]

        )

        )

    async def feed_page(self, user_id: str, query: FeedQuery, *, now: datetime) -> FeedPage:
        params: dict[str, Any] = {
            "uid": user_id,
            "now": now,
            "new_since": now - timedelta(days=NEW_DAYS),
            "limit": query.limit + 1,
        }
        where = [_WITH_EXPIRED if query.include_expired else _ACTIVE, _VISIBLE, _SHOWN]
        if not query.include_not_interested:
            where.append(_NOT_DISMISSED)
        if query.categories:
            where.append(" o.category::text = any(%(categories)s)")
            params["categories"] = list(query.categories)
        if query.source_types:
            where.append(" o.source_type::text = any(%(source_types)s)")
            params["source_types"] = list(query.source_types)
        outer = []
        if query.eligibility:
            outer.append("eff_status = any(%(eligibility)s)")
            params["eligibility"] = sorted(query.eligibility)
        if query.cursor:
            outer.append(_after(query.sort, query.cursor))
            params["cursor_value"], params["cursor_id"] = query.cursor.value, query.cursor.id
        sql = _feed_sql(
            " and".join(where),
            " where " + " and ".join(outer) if outer else "",
            _ORDER[query.sort],
        )
        rows = await (await self.conn.execute(sql, params)).fetchall()
        today = now.astimezone(KST).date()
        page = rows[: query.limit]
        next_cursor = None
        if len(rows) > query.limit:
            last = page[-1]
            value = last["deadline_at"] if query.sort == "deadline" else last["created_at"]
            cursor = Cursor(scope=query.scope(), value=value, id=str(last["id"]))
            next_cursor = encode_cursor(cursor)
        return FeedPage(items=[_item(row, today) for row in page], next_cursor=next_cursor)

    async def feed_counts(self, user_id: str, *, now: datetime) -> FeedCounts:
        """홈 요약 카드: 필터와 상관없이 지금 보이는 활성 공고 전체 기준."""
        row = await (

                {
                    "uid": user_id,
                    "now": now,

                    "today": now.astimezone(KST).date(),
                    "soon": SOON_DAYS,
                },
            )
        ).fetchone()
        assert row is not None
        return FeedCounts.model_validate(row)

    async def _lock_profile(self, user_id: str, display_name: str | None) -> dict[str, Any]:
        """프로필 행을 (없으면 만들고) 잠근 뒤 읽는다.

        같은 사용자의 판정은 한 번에 하나씩: 프로필 저장과 피드 읽기가 겹쳐도 옛 프로필로 덮어쓰지 않는다.
        no key update라서 이 사용자의 다른 행(이벤트·알림 등)이 profiles를 참조하며 넣는 것은 막지 않는다.
        """
        await self.conn.execute(
            "insert into profiles (id, display_name) values (%s, %s) on conflict do nothing",
            (user_id, display_name),
        )
        row = await (
            await self.conn.execute(
                "select * from profiles where id = %s for no key update", (user_id,)
            )
        ).fetchone()
        assert row is not None
        return row

    async def _upsert(self, user_id: str, payload: list[dict[str, Any]], now: datetime) -> None:
        """판정 여러 개를 한 문장으로 저장한다(_payload 모양)."""
        if payload:
            await self.conn.execute(
                _UPSERT,
                {"uid": user_id, "engine": ENGINE_VERSION, "now": now, "rows": Jsonb(payload)},
            )

    async def _departments(self) -> list[Department]:

        rows = await (

def _after(sort: Sort, cursor: Cursor) -> str:
    """정렬 순서(_ORDER)에서 cursor 다음에 오는 행. 값이 없는 행은 맨 뒤에 id 순으로 온다."""
    column, beyond = ("deadline_at", ">") if sort == "deadline" else ("created_at", "<")
    if cursor.value is None:
        return f"({column} is null and id {beyond} %(cursor_id)s)"
    return (
        f"({column} {beyond} %(cursor_value)s"
        f" or ({column} = %(cursor_value)s and id {beyond} %(cursor_id)s) or {column} is null)"
    )

class _Judged:
    stored: dict[str, Any]  # eligibility_results에 넣을 값(Judgment.storage_row 모양)
    label: str  # display_status
    judgment: Judgment | None  # 엔진이 오류를 냈으면 None
    requirements: tuple[Requirement, ...]
    basis_date: date | None


def _judge(
    item: dict[str, Any], profile: Profile, departments: list[Department], today: date
) -> _Judged:
    """공고 행 하나(requirements·eligibility_basis_date·deadline_at)를 판정한다.

    엔진 오류면 "판정하지 못함" 행을 돌려준다: 그 공고만 원문 확인 필요로 보인다.
    """
    basis: date | None = None
    try:
        requirements = tuple(Requirement.from_row(r) for r in item["requirements"])
        days = _basis_dates(item, today)
        basis = days[0]
        # 기준일이 둘이면(청년정책) 더 나은 쪽을 쓴다. 같으면 앞 날짜다(max는 처음 나온 것을 고른다)
        judgment = max(
            (
                check_eligibility(
                    list(requirements), profile, basis_date=day, departments=departments
                )
                for day in days
            ),
            key=lambda found: _RANK[found.status],
        )
        return _Judged(
            judgment.storage_row(),
            judgment.display_status,
            judgment,
            requirements,
            judgment.basis_date,
        )
    except Exception:
        logger.exception("판정하지 못한 공고: %s", item["id"])
        return _Judged(_engine_error_row(), "needs_review", None, (), basis)


_RANK = {"ineligible": 0, "undetermined": 1, "eligible": 2}


def _basis_dates(item: dict[str, Any], today: date) -> tuple[date, ...]:
    """판정 기준일(판정엔진_규칙.md 8장). 보통 하나다(공고 기준일 → 마감일 → 오늘).

    청년정책(온통청년)은 신청일 기준이 대부분이고 신청 기간이 몇 년인 정책도 있다. 그래서 신청할 수 있는 첫날
    (오늘, 신청 기간 전이면 시작일)과 마감일을 둘 다 보고 더 나은 결과를 쓴다. 나이 상한은 첫날에, 하한은
    마감일에 맞으면 그 사이 어느 날엔 신청할 수 있다. 신청 기간이 끝났으면 마감일 하나다."""
    if item["source_type"] != "youth_policy" or item["eligibility_basis_date"] is not None:
        return (resolve_basis_date(item["eligibility_basis_date"], item["deadline_at"], today),)
    start = item["apply_start_at"]
    first = max(today, to_kst_date(start)) if start is not None else today
    if item["deadline_at"] is None:
        return (first,)
    deadline = to_kst_date(item["deadline_at"])
    return (deadline,) if deadline <= first else (first, deadline)

def _step(step: dict[str, Any], names: dict[int, str]) -> ProcessStep:
    """처리 과정 한 줄(_DETAIL의 steps 행 하나). 첨부를 읽은 단계는 첨부 이름을 넣어 보인다.

    도구가 오류를 돌려준 호출(없는 첨부 번호 등)과 거절된 제출은 실행 로그에 succeeded로 남는다
    (에이전트는 오류를 모델에 돌려주고 계속 간다). 화면에는 실패로 보인다. 첨부 번호·위치는
    에이전트와 같은 규칙(whole)으로 읽는다. 읽기·토큰 상한에 닿아 코드가 시킨 제출(forced)은
    모델이 고른 단계가 아니라서 pipeline으로 보인다.
    """
    tool: str = step["tool"]
    again = "이어 " if _continued(step) else ""
    if tool in (READ_TEXT, READ_IMAGE):
        number = whole(step.get("attachment_no"))
        name = names.get(number) if number is not None else None
        target = f"첨부 '{name}'" if name else f"첨부 {number}번" if number else "첨부"
        how = "이미지로 " if tool == READ_IMAGE else ""
        label = f"{target} {how}{again}읽기"
    elif tool == FETCH_ORIGINAL:
        label = f"공고 원문 페이지 {again}읽기"
    elif tool == FETCH_YOUTH:
        label = "온통청년에서 정책 정보 받기"
    elif tool == BUILD_YOUTH:
        label = "온통청년 항목으로 지원 자격 정리"
    else:
        label = "지원 자격 정리" if tool == SUBMIT else tool
    failed = step.get("error") is True or (tool == SUBMIT and step.get("accepted") is False)
    chosen = tool in _AGENT_TOOLS and step.get("forced") is not True
    return ProcessStep(
        seq=step["seq"],
        tool=tool,
        label=label,
        status="failed" if failed else step["status"],
        latency_ms=step["latency_ms"],
        chosen_by="agent" if chosen else "pipeline",
        note=_line(step.get("reason")),
    )


def _continued(step: dict[str, Any]) -> bool:
    """앞에서 읽은 곳의 뒷부분을 읽은 호출. 도구가 실제로 읽은 위치를 보고, 오류면 요청한 위치를 본다.

    글자 읽기·원문 읽기는 시작 위치(offset)가 0보다 크면, Vision은 PDF를 2쪽부터 읽었으면 이어 읽기다.
    이미지는 한 장이라 이어 읽기가 없다.
    """
    if step["tool"] != READ_IMAGE:
        offset = whole(step.get("offset"))
        return offset is not None and offset > 0
    pages = step.get("pages")  # 읽은 PDF 쪽 "4–6/8". 이미지는 없다
    if isinstance(pages, str) and (first := _PAGES.match(pages)):
        return int(first.group(1)) > 1
    if step.get("error") is not True:
        return False  # 이미지를 읽었다
    start_page = whole(step.get("start_page"))
    return start_page is not None and start_page > 1


def _line(text: Any) -> str | None:
    """모델이 쓴 글(고른 이유, 원문 확인 필요 이유)을 화면용 한 줄로: 보이지 않는 문자(폭 없는 문자,
    글자 방향 제어)와 주소를 지우고 공백·줄바꿈을 한 칸으로 줄여 LINE_MAX_CHARS자까지. 남는 글이
    없으면 None이다.

    공고 글을 읽은 모델이 쓴 글이라, 공고 속 지시문이 링크를 끼워 넣지 못하게 쉬운 설명과 같은 규칙으로
    정리한다(app/extraction/validate.py). 저장된 값을 읽을 때 정리해서 예전 행에도 같이 적용된다.
    화면은 이 글을 일반 텍스트로 보여 준다(자동 링크·마크다운 없이).
    """
    if not isinstance(text, str):
        return None
    line = " ".join(_LINK.sub("", _INVISIBLE.sub("", text)).split())
    if len(line) > LINE_MAX_CHARS:
        line = line[: LINE_MAX_CHARS - 1].rstrip() + "…"
    return line or None


def _lines(texts: Sequence[Any] | None) -> list[str]:
    """여러 줄을 _line으로 정리한다. 빈 줄과 같은 줄은 빼고, REASONS_MAX줄이 넘으면 "외 N건"으로 줄인다."""
    lines = list(dict.fromkeys(line for text in texts or () if (line := _line(text))))
    if len(lines) > REASONS_MAX:
        return [*lines[:REASONS_MAX], f"외 {len(lines) - REASONS_MAX}건"]
    return lines


def _attachment(item: dict[str, Any]) -> AttachmentItem:
    if item["error"]:
        status = "failed"
    elif item["method"]:
        status = "succeeded"
    else:
        status = "skipped"  # 에이전트가 읽지 않은 첨부
    return AttachmentItem(
        id=str(item["id"]),
        file_name=item["file_name"],
        source_url=item["source_url"],
        extract_status=status,
    )

    return str(value) if value is not None else None
```

```python
def _age(policy: Mapping[str, Any]) -> list[Condition]:

    정책이 많아 쓰지 않는다. 병역 연장을 적은 정책은 상한을 복무 기간만큼(최대 36개월) 늘린다.

    숫자를 그대로 믿으면 지원할 수 있는 학생을 지원 어려움으로 보는 두 모양은 판정하지 않는다(10/13 실제 자료).
    - 상한이 CHILD_MAX세 이하: 부모급여(0~1세)·아이돌봄(0~12세)처럼 자녀 나이다. 기타 조건(원문 확인)
    - 상한 없이 하한만 OPEN_MIN세 이상: 인천 정책 16건이 34~99세인데, 대학생 학자금·천원의 아침밥처럼
      대상과 맞지 않는다. 나이 조건은 남기되 모호한 조건(원문 확인)으로 둔다
    """
    low, high = _whole(policy.get("sprtTrgtMinAge")), _whole(policy.get("sprtTrgtMaxAge"))
    has_low, has_high = low > 1, 0 < high < 99
    if not has_low and not has_high:
        return []
    if has_high and high <= CHILD_MAX:
        text = f"지원 대상 나이: 만 {low}~{high}세(자녀 나이일 수 있음)"
        return [_other(text, f"온통청년 지원 연령 {low}~{high}세")]
    if not has_high:
        evidence = f"온통청년 지원 연령 {low}세 이상"
        return [Condition("age", "gte", low, None, evidence, ambiguous=low >= OPEN_MIN)]
    value: dict[str, Any] = {"min": low, "max": high} if has_low else {"max": high}
    if _mentions_military_extension(policy):
        value["military_extension"] = {"max_months": 36}
    evidence = (
        f"온통청년 지원 연령 {low}~{high}세" if has_low else f"온통청년 지원 연령 {high}세 이하"
    )
    return [Condition("age", "between", value, None, evidence)]


def _mentions_military_extension(policy: Mapping[str, Any]) -> bool:
    return any(
        _MILITARY.search(text) and "연장" in text for text in _texts(policy, _CONDITION_TEXTS)
    )


def _mentions(policy: Mapping[str, Any], pattern: re.Pattern[str]) -> bool:
    return any(pattern.search(text) for text in _texts(policy, _CONDITION_TEXTS))


def _texts(policy: Mapping[str, Any], keys: tuple[str, ...]) -> list[str]:
    return [text for key in keys if (text := _text(policy.get(key)))]


def _region(codes: list[str], registered: date | None, table: RegionTable) -> list[Condition]:
    condition = table.condition(codes, registered)
    if condition is None:
        return []
    evidence = f"온통청년 지역 코드 {len(codes)}곳"
    found: list[Condition] = []
    if condition.values:
        found.append(Condition("region", "in", list(condition.values), "unspecified", evidence))
    if condition.uncertain:
        found.append(_other("거주지역 원문 확인: " + ", ".join(condition.uncertain), evidence))
    return found


def _school(policy: Mapping[str, Any]) -> list[Condition]:
    """학력(최종 학력). 대학 재학은 재학·휴학·졸업유예, 대학 졸업은 졸업이거나 대학원 과정(대학을 마쳤다),
    석·박사는 대학원 과정이다. 대졸 예정·기타는 원문 확인이다. 대학 학력을 고르고 대졸 예정은 고르지 않았는데
    글에 졸업예정자가 있으면 대졸 예정도 고른 것으로 본다. 고교 학력만 고른 정책은 대학생에게 맞는지 몰라
    원문 확인이다."""
    chosen = _choices(policy, "schoolCd")
    if not chosen:
        return []
    evidence = "온통청년 학력 요건: " + "·".join(SCHOOL.get(code, code) for code in chosen)
    university = bool(UNIVERSITY & set(chosen))
    if university and "0049006" not in chosen and _mentions(policy, _GRADUATING):
        chosen = [*chosen, "0049006"]
        evidence += "(글에 졸업예정자가 있음)"
    found: list[Condition] = []
    statuses = []
    if "0049005" in chosen:
        statuses += ["enrolled", "on_leave", "deferred_graduation"]
    if "0049007" in chosen:
        statuses.append("graduated")
    if statuses:
        found.append(Condition("enrollment_status", "in", statuses, None, evidence))
    if "0049007" in chosen or "0049008" in chosen:
        found.append(Condition("degree_program", "in", GRADUATE, None, evidence))
    if university:
        unsure = [code for code in chosen if code in ("0049006", "0049009") or code not in SCHOOL]
    else:
        unsure = chosen
    if unsure:
        found.append(
            _other("학력: " + "·".join(SCHOOL.get(code, code) for code in unsure), evidence)
        )
    return found

def _income(policy: Mapping[str, Any]) -> list[Condition]:
    """소득. 연소득 금액(만 원)은 프로필에 없고, 기타는 글(earnEtcCn)이라 둘 다 원문 확인이다."""
    code = _text(policy.get("earnCndSeCd"))
    if code in (None, INCOME_ANY):
        return []
    note = _meaningful(_INCOME_LABEL.sub("", _text(policy.get("earnEtcCn")) or ""))
    if code == INCOME_YEARLY:
        low, high = _whole(policy.get("earnMinAmt")), _whole(policy.get("earnMaxAmt"))
        parts = [f"{low:,}만 원 이상"] if low > 1 else []
        parts += [f"{high:,}만 원 이하"] if high > 0 else []
        text = "연소득 " + " ".join(parts) if parts else "연소득 조건이 있음"
        text += f" ({note})" if note else ""
    else:
        text = f"소득: {note}" if note else "소득 조건이 있음"
    return [_other(text, f"온통청년 {text}")]


def _free_text(policy: Mapping[str, Any], key: str, name: str) -> list[Condition]:
    text = _meaningful(policy.get(key))
    return [_other(f"{name}: {text}", f"온통청년 {name}: {text}")] if text else []


def _other(text: str, evidence: str) -> Condition:
    """기타 조건(원문 확인). 글이 길면 앞부분만 쓰고 전체는 근거에 둔다."""
    if len(text) > TEXT_MAX:
        evidence = f"온통청년 {text}"
    return Condition(
        "other", "eq", {"text": _cut(text, TEXT_MAX)}, None, _cut(evidence, EVIDENCE_MAX)
    )


def _drafts(clauses: Iterable[list[Condition]]) -> list[RequirementDraft]:
    drafts = []
    for clause_no, clause in enumerate(clauses, 1):
        for condition in clause:
            drafts.append(
                RequirementDraft(
                    clause_no=clause_no,
                    field=condition.field,
                    operator=condition.operator,
                    value=condition.value,
                    basis=condition.basis,
                    evidence_text=condition.evidence,
                    is_ambiguous=condition.ambiguous,
                )
            )
    return drafts


def _checked(drafts: list[RequirementDraft]) -> tuple[tuple[RequirementDraft, ...], bool]:
    """판정 엔진이 받을 수 있는 모양인지 본다(요건 추출과 같은 검사). 아니면 그 조건만 모호한 기타 조건으로 바꾼다.
    정책 자료가 틀린 경우다(예: 최소 나이가 최대 나이보다 큼)."""
    checked, broken = [], False
    for draft in drafts:
        requirement = Requirement(
            id="draft",
            clause_no=draft.clause_no,
            field=draft.field,
            operator=draft.operator,
            value=draft.value,
            basis=draft.basis,
        )
        if requirement_problem(requirement) is None:
            checked.append(draft)
            continue
        broken = True
        text = _cut(draft.evidence_text or "원문 확인 필요", TEXT_MAX)
        checked.append(
            replace(
                draft,
                field="other",
                operator="eq",
                value={"text": text},
                basis=None,
                is_ambiguous=True,
            )
        )
    return tuple(checked), broken


def _choices(policy: Mapping[str, Any], key: str) -> list[str]:
    """쉼표로 나눈 코드. 제한없음 코드가 있거나 모든 코드를 골랐으면 조건이 없다."""
    codes = _codes(policy.get(key))
    if not codes or NO_LIMIT[key] in codes or set(_NAMES[key]) <= set(codes):
        return []
    return codes


def _codes(value: Any) -> list[str]:
    return list(dict.fromkeys(code.strip() for code in str(value or "").split(",") if code.strip()))


def _raw_text(policy: Mapping[str, Any]) -> str:
    """공고 원문(opportunities.raw_text). 칸마다 "이름: 내용"이고, 내용의 줄바꿈은 둔다."""
    sections = []
    for key, name in _RAW_SECTIONS:
        if _meaningful(policy.get(key)):
            lines = (" ".join(line.split()) for line in str(policy[key]).splitlines())
            sections.append(f"{name}: " + "\n".join(line for line in lines if line))
    return "\n".join(sections)


def raw_section(raw_text: str | None, name: str) -> str | None:
    """원문(_raw_text)에서 한 칸의 내용. 다음 칸 이름("신청 사이트: " 등)이 나오기 전까지다. 없으면 None.

    준비하기가 청년정책의 "제출 서류" 칸을 읽어 서류 목록을 만들 때 쓴다(app/prepare).
    """
    heads = tuple(f"{label}: " for _, label in _RAW_SECTIONS)
    collected: list[str] | None = None
    for line in (raw_text or "").splitlines():
        if line.startswith(heads):
            if collected is not None:
                break
            if line.startswith(f"{name}: "):
                collected = [line[len(name) + 2 :]]
        elif collected is not None:
            collected.append(line)
    text = "\n".join(collected or []).strip()
    return text or None


def _meaningful(value: Any) -> str | None:
    """빈 값·"-"·"해당없음" 같은 글은 None이다. 공백·줄바꿈은 한 칸으로 줄인다."""
    text = _text(value)
    if text is None or text.lower() in _TRIVIAL or not re.search(r"[0-9A-Za-z가-힣]", text):
        return None
    return text


def _text(value: Any) -> str | None:
    text = " ".join(str(value).split()) if value is not None else ""
    return text or None


def _cut(text: str | None, limit: int) -> str | None:
    if text is None or len(text) <= limit:
        return text
    return text[: limit - 1].rstrip() + "…"


def _whole(value: Any) -> int:
    try:
        return int(str(value).strip())
    except (TypeError, ValueError):
        return 0


def _day(value: Any) -> date | None:
    text = str(value or "").strip()
    if not re.fullmatch(r"\d{8}", text):
        return None
    try:
        return date(int(text[:4]), int(text[4:6]), int(text[6:]))
    except ValueError:
        return None


def _hash(values: Mapping[str, Any]) -> str:
    def plain(item: Any) -> Any:
        if isinstance(item, datetime):
            return item.isoformat()
        if isinstance(item, RequirementDraft):
            return asdict(item)
        if isinstance(item, tuple | list):
            return [plain(part) for part in item]
        return item

    text = json.dumps({key: plain(item) for key, item in values.items()}, ensure_ascii=False)
    return hashlib.sha256(text.encode()).hexdigest()
```

```typescript
  const started = await apiFetch<PrepareStarted>(
    `/opportunities/${encodeURIComponent(id)}/prepare`,
    {
      method: "POST",
      body: JSON.stringify({
        register_calendar: includeCalendar && CALENDAR_READY,
        ...(targetDate ? { target_date: targetDate } : {}),
        ...(options.force ? { force: true } : {}),
      }),
    },
  );
  if (!started.run_id) return null; // 실행 기록이 지워진 옛 계획. 상세로 보여 준다
  const run = await waitForRun<PrepareResult>(started.run_id, (current) =>
    options.onProgress?.(current.steps),
  );
  if (run.status === "failed") {
    const error = run.error;
    throw new ApiError(
      error?.code ?? "INTERNAL_ERROR",
      error?.message ?? "준비 일정을 만들지 못했어요. 잠시 후 다시 눌러 주세요.",
      0,
    );
  }
  return run.result;
}
```

```typescript
    if (feedItem) feedItem.prepared = true;
  }

  const tasks = tasksForOpportunity(id);
  detail.prep = {
    prepared: true,
    prep_plan_id: prepPlanId,
    tasks_total: tasks.length,
    tasks_done: tasks.filter((task) => task.is_done).length,
    calendar_events:
      includeCalendar && detail.deadline_at
        ? [{ id: `gcal-${id}`, provider: "google" }]
        : [],
  };
  detail.process.prepare_run_id = `run-prepare-${id}`;

  return {
    kind: "prepare",
    prep_plan_id: prepPlanId,
    documents: detail.documents,
    tasks: tasks.map((task) => ({
      id: task.id,
      title: task.title,
      due_date: task.due_date,
      document_id:
        detail.documents.find((document) => document.task_id === task.id)?.id ?? null,
    })),
    calendar_event:
      includeCalendar && detail.deadline_at
        ? {
            id: `gcal-${id}`,
            provider: "google",
            starts_at: detail.deadline_at,
          }
        : null,
    calendar_error: null,
  };
}

export function setStoredDocumentDone(

  documentId: string,
  isDone: boolean,
): OpportunityDetail {
  const detail = detailsState[opportunityId];
  if (!detail) throw new Error("공고를 찾을 수 없어요.");
  const document = detail.documents.find((item) => item.id === documentId);
  if (!document?.task_id) throw new Error("준비 일정을 먼저 만들어 주세요.");

  document.is_done = isDone;
  const task = plannerState.items.find((item) => item.id === document.task_id);
  if (task) task.is_done = isDone;
  const tasks = tasksForOpportunity(opportunityId);
  detail.prep.tasks_done = tasks.filter((item) => item.is_done).length;
  detail.prep.tasks_total = tasks.length;
  return detail;
}

export function setStoredPlannerTaskDone(

): PlannerTask {
  const task = plannerState.items.find((item) => item.id === taskId);
  if (!task) throw new Error("할 일을 찾을 수 없어요.");
  task.is_done = isDone;

  if (task.link.type === "opportunity" && task.link.id) {
    const detail = detailsState[task.link.id];
    const document = detail?.documents.find((item) => item.task_id === taskId);
    if (document) document.is_done = isDone;
    if (detail) {

    }
  }

}

  );

}
```
