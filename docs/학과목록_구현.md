# 학과 목록 넣기 — ERICA 2026 (`departments` seed)

> 📝 기준: ERD v0.9 5장 "학과"(목록은 별도 seed 마이그레이션) · PRD v0.9 판정 원칙 7. 학과, 14장 "학과 매핑 목록 — S1-2 전" · 한양대학교 [대학/학과 소개](https://www.hanyang.ac.kr/e_college_department-info)(ERICA, 2026-10-10 확인) · [ERICA 2026학년도 정시 모집요강](https://goerica.hanyang.ac.kr/upload/BBS0061/20251021095558NUC6EP.PDF) · 2026-10-10

실제 DB의 `departments`가 비어 있다(0개). 그래서 지금은 두 가지가 막혀 있다.
- 온보딩에서 학과를 저장할 수 없다. 프로필 학과는 목록에 있는 이름만 받는다(FK).
- 요건 추출이 학과 조건을 모두 "원문 확인 필요"로 저장한다. 프롬프트에 학과 목록이 없어서다.

이 PR은 ERICA 학과·학부 48개를 넣는 마이그레이션 1개와 그 목록을 확인하는 DB 테스트 1개 파일이다. 코드는 바꾸지 않는다. **저장해 둔 공지를 가져오기 전에 실제 DB에 적용해야 한다.**

| --- | --- | --- |
| 범위 | 한양대학교 대학/학과 소개 페이지의 ERICA 단과대학 10곳, 학과·학부 48개 | 학교 공식 목록이다. 재학생이 남아 있는 학과(재료화학공학과, 한국언어문학과, 중국학과 등)도 페이지에 있는 대로 넣었다 |

| 판정 기록 | 같은 마이그레이션에서 `eligibility_results`를 비운다 | 목록에 없던 이름은 "모름"으로 판정됐다. 다음 피드·상세 요청에서 새 목록으로 다시 계산한다(S1-5 규칙) |
| 다시 돌리기 | 이름이 같으면 단과대학·계열·순서를 고치고 목록에 다시 보이게 한다 | 같은 파일을 여러 번 적용해도 결과가 같다 |

### 팀이 확인할 계열

계열 조건(예: "공학계열 재학생")에만 쓰인다. 학과·단과대학 조건에는 영향이 없다. 틀렸으면 나중에 새 마이그레이션으로 `update departments set field_group = …`과 `delete from eligibility_results`를 함께 돌려 고친다.

| 학과·학부 | 둔 계열 | 이유 |
| --- | --- | --- |
| 에너지바이오학과 | 공학계열 | 공학대학 소속이라 공학계열로 뒀다. 학과 이름은 자연계열(생명과학) 쪽이다 |
| ICT융합학부 | 공학계열 | 데이터인텔리전스·디자인컨버전스 전공이라 공학과 예체능(디자인)이 섞였다 |
| 수리데이터사이언스학과 | 자연계열 | 수학 바탕이라 자연계열로 뒀다. 소프트웨어융합대학이라 공학계열로 볼 수도 있다 |
| 바이오신약융합학부 | 공학계열 | 분자의약(자연·의약)과 바이오나노공학(공학) 전공이 섞였다 |
| 글로벌문화통상학부 | 인문계열 | 입학 계열은 인문이다. 통상(무역)은 사회계열이다 |
| 문화인류학과 | 사회계열 | 인류학은 사회과학이라 사회계열로 뒀다. 인문계열로 분류하는 곳도 있다 |
| 문화콘텐츠학과 | 인문계열 | 인문계열로 뒀다. 사회계열로 분류하는 곳도 있다 |

## 남은 것

- 계열 8개 확인(위 표). 팀이 정해 주면 새 마이그레이션으로 고친다.
- 옛 학과 이름: 페이지에 없는 예전 학과(통폐합 전 이름)는 넣지 않았다. PRD대로 통폐합 이력은 MVP에서 다루지 않는다. 그 학생은 지금 학과를 고르거나 비워 둔다.
- 전공 단위 조건(예: "건축학전공 학생")은 목록에 없는 이름이라 모호한 요건으로 저장되고(코드가 확인), 판정은 원문 확인 필요가 된다.
- LIONS자율전공학부 학생은 계열 조건에서 불충족으로 나온다. 2학년에 학과를 고르면 프로필을 바꾼다.
- 학과가 바뀌는 학기마다(신설·명칭 변경) 이 표를 다시 보고 새 마이그레이션을 만든다. 이름을 바꿀 때는 `update departments set name = …`로 바꾸면 프로필이 따라간다(on update cascade).

```python
"""학과 목록 seed(supabase/migrations/20261010000100_seed_departments.sql)를 적용한 DB를 확인한다.

CI와 같이 마이그레이션을 모두 적용한 DB에서 돈다. DATABASE_URL이 있을 때만 돈다.
"""

from datetime import date

import pytest

from app.eligibility import Profile, Requirement, check_eligibility
from app.extraction.store import load_departments
from app.repositories.meta import MetaRepository
from tests.db_world import DATABASE_URL, connect

pytestmark = [
    pytest.mark.db,
    pytest.mark.anyio,
    pytest.mark.skipif(not DATABASE_URL, reason="DATABASE_URL이 없어서 DB 통합 테스트를 건너뜀"),
]

# 한양대학교 대학/학과 소개의 ERICA 단과대학 순서
COLLEGES = [
    "공학대학",
    "소프트웨어융합대학",
    "약학대학",
    "첨단융합대학",
    "글로벌문화통상대학",
    "커뮤니케이션&컬처대학",
    "경상대학",
    "디자인대학",
    "예체능대학",
    "LIONS칼리지",
]
FIELD_GROUPS = {
    "공학계열",
    "자연계열",
    "의약계열",
    "인문계열",
    "사회계열",
    "예체능계열",
    "자율전공",
}


async def test_seeded_departments() -> None:
    conn = await connect()
    try:
        rows = await (
            await conn.execute(
                "select name, college, field_group, sort_order, is_active from departments"
                " where sort_order >= 100 order by sort_order"
            )
        ).fetchall()
        assert len(rows) == 48 and all(row["is_active"] for row in rows)
        assert list(dict.fromkeys(row["college"] for row in rows)) == COLLEGES
        assert {row["field_group"] for row in rows} == FIELD_GROUPS
        by_name = {row["name"]: (row["college"], row["field_group"]) for row in rows}
        # 다른 테스트와 가짜 저장소(tests/fakes.py)가 쓰는 학과와 같은 값이다
        assert by_name["인공지능학과"] == ("소프트웨어융합대학", "공학계열")
        assert by_name["경영학부"] == ("경상대학", "사회계열")
        assert by_name["약학과"] == ("약학대학", "의약계열")
        # 가운뎃점은 U+00B7 하나로 쓴다(학교 글에는 ㆍ도 섞여 있다)
        assert "교통·물류공학과" in by_name and "주얼리·패션디자인학과" in by_name
        assert not any("ㆍ" in name or " " in name for name in by_name)

        # 온보딩 목록(GET /meta/departments)과 요건 추출 프롬프트가 같은 목록을 쓴다
        listed = [department.name for department in await MetaRepository(conn).list_departments()]
        assert [name for name in listed if name in by_name] == list(by_name)
        assert {department.name for department in await load_departments(conn)} >= set(by_name)
    finally:
        await conn.rollback()
        await conn.close()


async def test_seeded_departments_judge_college_and_field_group() -> None:
    """단과대학·계열 조건이 seed 목록으로 판정된다. 목록에 없는 이름("이공계")은 불충족으로 보지 않는다."""
    conn = await connect()
    try:
        departments = await load_departments(conn)

        def judge(department: str, basis: str, *names: str) -> str:
            requirement = Requirement(
                id="r1",
                clause_no=1,
                field="department",
                operator="in",
                value=list(names),
                basis=basis,
            )
            judgment = check_eligibility(
                [requirement],
                Profile(department=department),
                basis_date=date(2026, 10, 10),
                departments=departments,
            )
            return judgment.status

        assert judge("인공지능학과", "college", "소프트웨어융합대학") == "eligible"
        assert judge("수리데이터사이언스학과", "field_group", "공학계열", "자연계열") == "eligible"
        assert judge("경영학부", "field_group", "공학계열", "자연계열") == "ineligible"
        assert judge("경영학부", "field_group", "이공계") == "undetermined"
    finally:
        await conn.rollback()
        await conn.close()
```
