# 마감일 캘린더 등록 (F-32)

> 📝 기준: PRD v0.9 F-32 · API 명세 v0.4 4·7장 · ERD v0.9 · 2026-10-15
>
> 기준 커밋: main `d917409`(#30 플래너). 준비하기(#27)가 남겨 둔 캘린더 자리를 채운다

준비한 공고의 마감일을 **Google 캘린더에 실제로 넣고 뺀다.** 캘린더 연결(증분 승인)은 설정 화면에서 이미 되고 토큰도 저장되고 있었는데, 그 토큰으로 일정을 만드는 쪽이 없었다. 준비하기 결과 창의 "마감일을 Google Calendar에도 넣기" 체크는 눌러도 아무 일이 없었다.

**규모와 확인:**
- api 새 파일 7개(캘린더 클라이언트·서비스·저장소·라우터·스키마와 테스트 2개), 바꾸는 파일 8개. web 새 파일 2개, 바꾸는 파일 9개.
- **DB 변경이 없다.** `calendar_events`·`oauth_tokens`는 이미 있다. 합친 뒤 db push가 필요 없다.
- 새 에러 코드가 없다. `CALENDAR_NOT_CONNECTED`·`GOOGLE_API_ERROR`·`DEADLINE_PASSED`·`VALIDATION_FAILED`·`NOT_FOUND` 모두 명세 13장 표에 있다.
- **`.env`에 Google OAuth 앱 값을 넣어야 토큰 갱신이 된다**(아래 "합친 뒤 확인" 0번). 없어도 돌아가지만 55분 뒤 다시 연결해야 한다.
- api `ruff` 통과, `590 passed, 89 skipped`(DB 없이) · `679 passed`(새 DB, `TZ=UTC`에서도 같다). web `typecheck`·`build` 통과.
- 가짜 Google 캘린더로 실제 모드 E2E 6단계, 목 모드 3가지를 돌렸다. 되돌림 시험(변이) 14가지가 모두 잡혔다.
- 따로 띄운 검토 에이전트가 한 번 봤다. **막아야 할 문제 1건**(같은 공고 일정이 두 개가 되는 길)과 고치면 좋은 것 9건을 고쳤고, 남은 3건은 "남은 것"에 적었다.

## 정한 것

| 항목 | 정한 것 | 이유 |
| --- | --- | --- |
| 등록하는 길 | 웹이 `POST /calendar/events`를 직접 부른다. 준비하기와 따로다 | 10/15 선택. 준비 결과 창의 체크도, 나중에 상세에서 넣는 것도 같은 길이라 이미 준비한 공고도 언제든 넣고 뺄 수 있다 |
| 준비하기 요청 | `register_calendar`·`calendar_provider`를 **없앴다**. 명세 7장에서도 뺀다 | 받기만 하고 아무 일도 안 하는 필드였다. 캘린더가 따로 생겼으니 둘 이유가 없다. 준비하기 결과의 `calendar_event`·`calendar_error`도 늘 null이라고 적는다 |
| 이벤트 모양 | 마감 시각으로 **끝나는 1시간짜리**(18:00 마감 → 17:00~18:00), 제목은 "[마감] 공고 이름", `all_day`는 false, 시간대는 `Asia/Seoul` | 10/15 선택. 종일 일정은 기본 알림이 전날이라 당일에 안 울리고 몇 시 마감인지도 안 보인다 |
| 누가 넣을 수 있나 | **준비를 마친 공고**만. 공고 상세·플래너 마커와 같은 기준(`PREP_DONE`)이다. 아니면 422 "준비 일정을 먼저 만들어 주세요." | 마감일만 캘린더에 넣는 기능이 아니라 준비의 한 걸음이다. 세 화면이 같은 기준을 쓴다 |
| 막는 경우 | 마감일이 없는 상시 공고는 422, 마감이 지난 공고는 409 `DEADLINE_PASSED`(준비하기와 같다) | 지난 일정을 캘린더에 넣지 않는다 |
| **다시 눌러도 하나** | 기록 자리를 **먼저 잡고**(`external_event_id` 없이) 그 행 id로 Google 일정 번호를 정한 뒤 넣는다. 같은 번호로 다시 넣으면 Google이 409를 주는데 그것은 앞 요청이 이미 넣었다는 뜻이라 성공으로 본다 | 검토가 잡은 막아야 할 문제. Google에 넣고 나서 기록하면, 넣는 응답을 못 받았을 때(타임아웃) 기록이 없어 다시 누르면 **캘린더에 같은 일정이 두 개**가 되고 DELETE로도 못 지운다 |
| 넣는 중인 자리 | 공고 상세의 `prep.calendar_events`는 **번호가 붙은 것만** 센다 | 자리만 잡힌 상태를 "등록됨"으로 보여 주면 "캘린더에서 빼기"만 누를 수 있는데 캘린더엔 아무것도 없다 |
| 토큰 | `oauth_tokens`의 암호화된 access token을 쓰고, 만료 2분 전이면 `.env`의 앱 값으로 갱신해 다시 저장한다. refresh token은 덮지 않는다 | Google은 갱신 때 refresh token을 다시 주지 않는다 |
| 다시 연결 | **401**(권한이 없어짐), 갱신 4xx(`invalid_grant`), 앱 값이 없음, 복호화 실패 → `409 CALENDAR_NOT_CONNECTED`(`details.reason`) | 학생이 할 수 있는 일(다시 연결)이 있는 경우만 그렇게 안내한다 |
| 바깥 오류 | **403**·5xx·연결 오류·타임아웃 → `502 GOOGLE_API_ERROR`. 바깥 문구는 그대로 내보내지 않는다 | 403은 쿼터·한도에도 온다(검토 지적). 다시 연결하라고 하면 학생이 해도 아무 효과가 없다 |
| 빼기 | Google에서도 지운다. 이미 Google에 없으면(404·410) 지운 것으로 본다. **캘린더 권한이 없어졌으면 우리 기록만 지운다**(204) | 권한이 없으면 영영 못 지워 그 줄이 화면에 남는다. Google이 잠깐 멈춘 것(502)은 기록을 두고 다시 누르게 한다 |
| 권한이 없을 때 | 바로 Google 증분 승인으로 보내고, 돌아오면(`?calendar=connected`) **하려던 등록을 이어서 한다**. 실패하고 돌아오면 까닭을 알린다 | 돌아와서 학생이 같은 버튼을 다시 찾아 누르게 하지 않는다(검토 지적) |
| 실패 문구 | 캘린더만 실패하면 "… 준비 일정은 플래너에 그대로 있어요."를 붙인다 | 준비까지 망한 줄 알고 다시 누르지 않게 한다 |
| 실행 로그 | 캘린더 호출은 `agent_runs`에 남기지 않는다. 준비하기 단계 label에서 `create_calendar_event`를 뺐다 | 준비하기 실행 밖으로 나왔고, `run_trigger`에 캘린더용 값이 없어 넣으려면 DB를 바꿔야 한다(아래 "남은 것") |

## 합친 뒤 확인

0. **`.env`에 Google OAuth 앱 값 넣기(한 번만).** Google Cloud Console → API 및 서비스 → 사용자 인증 정보에서 **Supabase Authentication > Providers > Google에 넣은 것과 같은** 클라이언트 ID·보안 비밀을 찾아 `api/.env`에 넣는다. 비밀값은 채팅에 붙이지 말고 터미널에서 직접 적는다.

   ```text
   GOOGLE_OAUTH_CLIENT_ID=<클라이언트 ID>
   GOOGLE_OAUTH_CLIENT_SECRET=<보안 비밀>
   ```

   비워 두어도 등록은 되지만, access token이 만료되는 55분 뒤부터는 누를 때마다 "다시 연결해 주세요"가 뜬다.
1. **API 다시 띄우기:** `http://localhost:8000/docs`에 `POST /api/v1/calendar/events`와 `DELETE /api/v1/calendar/events/{event_id}`가 보여야 한다.
2. **처음 등록:** 지원 가능한 공고를 준비하고, 결과 창의 "마감일을 Google Calendar에도 넣기"를 켠 채 완료를 누른다. 캘린더 권한이 없으면 Google 화면이 뜨고, 허용하면 공고로 돌아와 **저절로 등록된다.** Google 캘린더(web)에서 마감 1시간 전 "[마감] 공고 이름" 일정을 확인한다.
3. **넣기·빼기:** 그 공고를 다시 열면 "마감일 캘린더" 줄에 "캘린더에서 빼기"가 있다. 누르면 Google 캘린더에서도 사라지고, "캘린더에 넣기"로 다시 넣을 수 있다.
4. **중복 없음:** 넣은 뒤 상세를 새로 고쳐 다시 눌러도 캘린더에 일정이 하나다.
5. **권한 끊기:** Google 계정 설정에서 이 앱의 접근을 지우고 다시 눌러 본다. 다시 연결 화면으로 가야 한다(502 오류 화면이 아니다).
6. **상시 공고:** 마감일이 없는 공고에는 "마감일 캘린더" 줄이 보이지 않는다.

| --- | --- |

## 남은 것

- **캘린더 호출이 실행 로그에 남지 않는다.** 루트 CLAUDE.md는 외부 도구 호출을 모두 `agent_log`로 남기라고 한다. 준비하기 실행에서 떼어 낸 결과이고, `agent_runs.trigger_type`에 캘린더용 값이 없어 넣으려면 마이그레이션이 필요하다. AOP 지표(성공률·응답시간)에 캘린더를 넣을지 W9–10 측정 때 정하고, 넣기로 하면 그때 DB를 바꾼다.
- **`.env`에 앱 값이 없으면 55분마다 다시 연결해야 한다.** 등록 자체는 되지만 access token을 갱신하지 못한다. 위 "합친 뒤 확인" 0번을 먼저 한다.
- **강의계획서 일정·LMS 과제는 아직 못 넣는다.** 명세 7장의 `syllabus_item_id`·`lms_assignment_id`는 그 기능(F-14·F-51)과 함께 연다. 지금 보내면 422다.
- **.ics 내려받기(F-34, P1)는 없다.** `provider: "ics"`는 422다.
- **상시 공고는 캘린더에 넣을 수 없다.** 마감일이 없어서다. 학생이 고른 목표일을 쓰려면 `prep_plans`에 그 값을 담을 자리가 필요하다(ERD 변경, 플래너 마커와 같은 문제다).
- **Google 쪽에서 일정을 고치면 우리는 모른다.** 학생이 캘린더에서 시각을 옮기거나 지워도 `calendar_events`는 그대로다(지운 경우는 다음 "빼기"에서 404를 받아 조용히 맞춰진다).

```python
"""Google Calendar API 클라이언트 (F-32).

- 이벤트 넣기: POST {api_base}/calendars/primary/events
- 이벤트 빼기: DELETE {api_base}/calendars/primary/events/{id}
- access token 갱신: POST {token_url} (refresh_token 교환). 앱의 client_id·client_secret이 있어야 한다.
  비워 두면 갱신하지 못하고 만료로 본다(학생이 다시 연결한다).

마감 이벤트는 마감 시각으로 끝나는 1시간짜리다(10/15 선택). 종일 일정은 기본 알림이 전날이라 당일에
안 울리고, 몇 시 마감인지도 안 보인다. 토큰은 로그·오류 문구에 넣지 않는다.

일정 번호는 우리가 정해서 보낸다(calendar_events.id의 하이픈을 뺀 값). 같은 번호로 다시 넣으면 Google이
409로 거절하는데, 그것은 앞 요청이 이미 넣었다는 뜻이라 성공으로 본다. 응답을 받지 못하고 다시 눌러도
캘린더에 일정이 두 개가 되지 않는다.
"""

import re
from dataclasses import dataclass
from datetime import datetime, timedelta
from urllib.parse import quote

import httpx

CALENDAR_SCOPE = "https://www.googleapis.com/auth/calendar.events"
EVENT_MINUTES = 60  # 마감 시각으로 끝나는 1시간짜리
TIMEOUT_SECONDS = 15.0
_KST_NAME = "Asia/Seoul"
# Google이 받는 일정 번호: 소문자 a–v와 숫자, 5–1024자. uuid의 16진수는 그대로 들어간다
_EVENT_ID = re.compile(r"^[a-v0-9]{5,1024}$")


def event_id_for(row_id: str) -> str:
    """calendar_events.id → Google 일정 번호. 같은 행은 늘 같은 번호다(다시 넣어도 하나)."""
    value = row_id.replace("-", "").lower()
    if not _EVENT_ID.match(value):
        raise ValueError(f"Google이 받지 않는 일정 번호예요: {row_id}")
    return value


class GoogleCalendarError(Exception):
    """Google이 거절했거나 닿지 못했다. status가 401이면 다시 연결해야 한다."""

    def __init__(self, message: str, status: int | None = None) -> None:
        super().__init__(message)
        self.status = status

    @property
    def unauthorized(self) -> bool:
        """다시 연결해야 하는 오류. 403은 쿼터·한도에도 오므로 여기 넣지 않는다."""
        return self.status == 401


@dataclass(frozen=True)
class GoogleEvent:
    id: str
    starts_at: datetime
    ends_at: datetime


def event_title(opportunity_title: str) -> str:
    """캘린더에 보이는 제목. 앞에 [마감]을 붙여 다른 일정과 구분한다."""
    return f"[마감] {opportunity_title}"


class GoogleCalendarClient:
    def __init__(
        self, *, api_base: str, token_url: str, client_id: str, client_secret: str
    ) -> None:
        self.api_base = api_base.rstrip("/")
        self.token_url = token_url
        self.client_id = client_id
        self.client_secret = client_secret

    @property
    def can_refresh(self) -> bool:
        """앱 정보가 있어야 access token을 갱신할 수 있다."""
        return bool(self.client_id and self.client_secret)

    async def refresh(self, refresh_token: str) -> tuple[str, int]:
        """새 access token과 남은 초. 갱신하지 못하면 GoogleCalendarError(401)다."""
        if not self.can_refresh:
            raise GoogleCalendarError("캘린더 권한을 갱신할 수 없어요.", 401)
        body = {
            "client_id": self.client_id,
            "client_secret": self.client_secret,
            "refresh_token": refresh_token,
            "grant_type": "refresh_token",
        }
        try:
            payload = await self._send("POST", self.token_url, data=body)
        except GoogleCalendarError as exc:
            # 토큰 교환이 4xx면 refresh token이 없어졌거나 학생이 권한을 거뒀다(Google은 400
            # invalid_grant를 준다). 다시 연결해야 한다. 5xx·연결 오류는 잠깐 문제라 그대로 올린다
            if exc.status is not None and 400 <= exc.status < 500:
                raise GoogleCalendarError("캘린더 권한이 만료됐어요.", 401) from exc
            raise
        token = payload.get("access_token")
        if not token:
            raise GoogleCalendarError("캘린더 권한을 갱신하지 못했어요.", 401)
        return str(token), int(payload.get("expires_in") or 3600)

    async def insert(
        self, access_token: str, *, event_id: str, title: str, ends_at: datetime
    ) -> GoogleEvent:
        """우리가 정한 번호로 넣는다. 이미 그 번호가 있으면(409) 앞 요청이 넣은 것이라 성공으로 본다."""
        starts_at = ends_at - timedelta(minutes=EVENT_MINUTES)
        body = {
            "id": event_id,
            "summary": title,
            "start": {"dateTime": starts_at.isoformat(), "timeZone": _KST_NAME},
            "end": {"dateTime": ends_at.isoformat(), "timeZone": _KST_NAME},
        }
        try:
            await self._send(
                "POST",
                f"{self.api_base}/calendars/primary/events",
                json=body,
                token=access_token,
            )
        except GoogleCalendarError as exc:
            if exc.status != 409:  # 409는 같은 번호가 이미 있다는 뜻이다
                raise
        return GoogleEvent(event_id, starts_at, ends_at)

    async def delete(self, access_token: str, event_id: str) -> None:
        """이미 지워진 일정(404·410)은 지운 것으로 본다."""
        await self._send(
            "DELETE",
            f"{self.api_base}/calendars/primary/events/{quote(event_id, safe='')}",
            token=access_token,
            gone_is_ok=True,
        )

    async def _send(
        self,
        method: str,
        url: str,
        *,
        json: dict | None = None,
        data: dict | None = None,
        token: str | None = None,
        gone_is_ok: bool = False,
    ) -> dict:
        headers = {"Authorization": f"Bearer {token}"} if token else {}
        try:
            async with httpx.AsyncClient(timeout=TIMEOUT_SECONDS) as client:
                response = await client.request(method, url, json=json, data=data, headers=headers)
        except httpx.HTTPError as exc:
            raise GoogleCalendarError(
                f"Google 캘린더에 닿지 못했어요: {type(exc).__name__}"
            ) from exc
        if gone_is_ok and response.status_code in (404, 410):
            return {}
        if response.status_code >= 400:
            raise GoogleCalendarError(
                f"Google 캘린더가 요청을 거절했어요({response.status_code}).", response.status_code
            )
        if not response.content:
            return {}
        try:
            payload = response.json()
        except ValueError as exc:
            raise GoogleCalendarError("Google 캘린더 응답을 읽지 못했어요.") from exc
        return payload if isinstance(payload, dict) else {}
```

```python
"""캘린더 등록·취소 (F-32). 토큰을 꺼내 쓰고, 만료가 가까우면 갱신한 뒤 Google을 부른다.

연결이 없거나 갱신하지 못하면 409 CALENDAR_NOT_CONNECTED(details.reason)로 끝낸다. 화면은 그 코드를 보고
Google 연결(증분 승인)로 보낸다. Google이 거절하거나 닿지 못하면 502 GOOGLE_API_ERROR다.
토큰 값은 오류 문구·로그에 넣지 않는다.
"""

from datetime import datetime
from typing import Annotated

from fastapi import Depends

from app.calendar.google import GoogleCalendarClient, GoogleCalendarError
from app.config import Settings, get_settings
from app.crypto import decrypt, encrypt
from app.errors import ApiError
from app.repositories.calendar import CalendarRepoDep, CalendarRepository, GoogleTokens

NOT_CONNECTED = "Google 캘린더를 연결해 주세요."
EXPIRED = "캘린더 권한이 만료됐어요. 다시 연결해 주세요."


def _not_connected(reason: str) -> ApiError:
    return ApiError(
        409,
        "CALENDAR_NOT_CONNECTED",
        NOT_CONNECTED if reason == "not_connected" else EXPIRED,
        {"reason": reason},
    )


def _api_error(exc: GoogleCalendarError) -> ApiError:
    """권한 문제면 다시 연결하게 하고, 그 밖은 외부 서비스 오류다."""
    if exc.unauthorized:
        return _not_connected("expired")
    return ApiError(
        502, "GOOGLE_API_ERROR", "Google 캘린더가 응답하지 않아요. 잠시 후 다시 시도해 주세요."
    )


class CalendarService:
    def __init__(
        self, repo: CalendarRepository, client: GoogleCalendarClient, encryption_key: str
    ) -> None:
        self.repo = repo
        self.client = client
        self.key = encryption_key

    async def access_token(self, user_id: str, now: datetime) -> str:
        """쓸 수 있는 access token. 만료가 가까우면 갱신해 저장한다."""
        tokens = await self.repo.tokens(user_id)
        if tokens is None or not tokens.refresh_token:
            raise _not_connected("not_connected")
        if not tokens.expired(now):
            assert tokens.access_token is not None
            return self._decrypt(tokens.access_token)
        return await self._refresh(user_id, tokens)

    def _decrypt(self, value: str) -> str:
        """키를 바꿨거나 값이 깨졌으면 다시 연결하게 한다(500으로 끝내지 않는다)."""
        try:
            return decrypt(value, self.key)
        except Exception as exc:
            raise _not_connected("expired") from exc

    async def _refresh(self, user_id: str, tokens: GoogleTokens) -> str:
        assert tokens.refresh_token is not None
        # 앱 정보(.env의 client_id·secret)가 없으면 client.refresh가 401로 끝난다 → 다시 연결
        try:
            token, expires_in = await self.client.refresh(self._decrypt(tokens.refresh_token))
        except GoogleCalendarError as exc:
            raise _api_error(exc) from exc
        await self.repo.save_access_token(user_id, encrypt(token, self.key), expires_in)
        return token

    async def insert(self, token: str, *, event_id: str, title: str, ends_at: datetime) -> str:
        try:
            event = await self.client.insert(token, event_id=event_id, title=title, ends_at=ends_at)
        except GoogleCalendarError as exc:
            raise _api_error(exc) from exc
        return event.id

    async def delete(self, token: str, external_event_id: str | None) -> None:
        if not external_event_id:  # 기록만 있고 Google에는 없다(ics 등)
            return
        try:
            await self.client.delete(token, external_event_id)
        except GoogleCalendarError as exc:
            raise _api_error(exc) from exc


def get_calendar_service(
    repo: CalendarRepoDep, settings: Annotated[Settings, Depends(get_settings)]
) -> CalendarService:
    client = GoogleCalendarClient(
        api_base=settings.google_calendar_api_base,
        token_url=settings.google_token_url,
        client_id=settings.google_oauth_client_id,
        client_secret=settings.google_oauth_client_secret,
    )
    return CalendarService(repo, client, settings.token_encryption_key)


CalendarServiceDep = Annotated[CalendarService, Depends(get_calendar_service)]
```

"""캘린더 등록 기록 SQL (F-32, ERD calendar_events).

사용자 것만 읽고 쓴다. 같은 공고를 두 번 눌러도 등록은 하나다((user_id, provider, opportunity_id) 유니크).
Google access token은 oauth_tokens에 암호화해 두고, 만료가 가까우면 갱신해 다시 넣는다.
"""

from dataclasses import dataclass
from datetime import datetime
from typing import Annotated

from fastapi import Depends
from psycopg import AsyncConnection

from app.db import get_conn
from app.repositories.opportunities import PREP_DONE
from app.schemas.calendar import CalendarEventView

# 남은 시간이 이보다 적으면 미리 갱신한다(요청 도중에 만료되지 않게)
REFRESH_MARGIN_SECONDS = 120


@dataclass(frozen=True)
class GoogleTokens:
    access_token: str | None  # 암호화된 값
    refresh_token: str | None
    expires_at: datetime | None

    def expired(self, now: datetime) -> bool:
        if not self.access_token or self.expires_at is None:
            return True
        return (self.expires_at - now).total_seconds() <= REFRESH_MARGIN_SECONDS


@dataclass(frozen=True)
class OpportunityDeadline:
    id: str
    title: str
    deadline_at: datetime | None


def _event(row: dict) -> CalendarEventView:
    return CalendarEventView(
        id=row["id"],
        provider=row["provider"],
        external_event_id=row["external_event_id"],
        title=row["title"],
        starts_at=row["starts_at"],
        all_day=row["all_day"],
    )


_EVENT = (
    "select id::text as id, provider::text as provider, external_event_id, title, starts_at,"
    " coalesce(all_day, false) as all_day from calendar_events"
)


class CalendarRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def tokens(self, user_id: str) -> GoogleTokens | None:
        row = await (
            await self.conn.execute(
                "select access_token, refresh_token, expires_at from oauth_tokens"
                " where user_id = %s and provider = 'google'",
                (user_id,),
            )
        ).fetchone()
        if row is None:
            return None
        return GoogleTokens(row["access_token"], row["refresh_token"], row["expires_at"])

    async def save_access_token(self, user_id: str, encrypted: str, expires_in: int) -> None:
        """갱신한 access token. refresh token은 그대로 둔다(Google이 다시 주지 않는다)."""
        await self.conn.execute(
            "update oauth_tokens set access_token = %s,"
            " expires_at = now() + make_interval(secs => %s)"
            " where user_id = %s and provider = 'google'",
            (encrypted, expires_in, user_id),
        )

    async def prepared_opportunity(
        self, user_id: str, opportunity_id: str
    ) -> OpportunityDeadline | None:
        """준비를 마친 공고만 캘린더에 넣는다. 아니면 None(화면이 준비하기를 먼저 시킨다)."""
        row = await (
            await self.conn.execute(
                "select o.id::text as id, o.title, o.deadline_at from prep_plans p"
                " join opportunities o on o.id = p.opportunity_id"
                " where p.user_id = %(uid)s and p.opportunity_id = %(oid)s and " + PREP_DONE,
                {"uid": user_id, "oid": opportunity_id},
            )
        ).fetchone()
        if row is None:
            return None
        return OpportunityDeadline(row["id"], row["title"], row["deadline_at"])

    async def event_for(
        self, user_id: str, opportunity_id: str, provider: str
    ) -> CalendarEventView | None:
        row = await (
            await self.conn.execute(
                _EVENT + " where user_id = %s and opportunity_id = %s and provider = %s",
                (user_id, opportunity_id, provider),
            )
        ).fetchone()
        return None if row is None else _event(row)

    async def one(self, user_id: str, event_id: str) -> CalendarEventView | None:
        row = await (
            await self.conn.execute(_EVENT + " where id = %s and user_id = %s", (event_id, user_id))
        ).fetchone()
        return None if row is None else _event(row)

    async def reserve(
        self,
        user_id: str,
        *,
        provider: str,
        opportunity_id: str,
        title: str,
        starts_at: datetime,
    ) -> CalendarEventView:
        """Google을 부르기 전에 자리를 먼저 잡는다(external_event_id는 아직 비어 있다).

        Google에 넣고 나서 기록하면, 넣은 응답을 받지 못했을 때 기록이 없어 다시 누르면 캘린더에 일정이
        두 개가 된다. 자리를 먼저 잡으면 그 행의 id로 Google 일정 번호를 정할 수 있어, 다시 눌러도 같은
        번호로 들어간다(두 요청이 겹쳐도 진 쪽이 이긴 쪽의 행을 그대로 쓴다).
        """
        row = await (
            await self.conn.execute(
                "insert into calendar_events (user_id, provider, opportunity_id, title,"
                " starts_at, all_day) values (%s, %s, %s, %s, %s, false)"
                " on conflict (user_id, provider, opportunity_id) where opportunity_id is not null"
                " do nothing returning id::text as id",
                (user_id, provider, opportunity_id, title, starts_at),
            )
        ).fetchone()
        if row is None:  # 그새 다른 요청이 잡았다(또는 앞 요청이 끝내지 못하고 남겼다)
            existing = await self.event_for(user_id, opportunity_id, provider)
            assert existing is not None
            return existing
        found = await self.one(user_id, row["id"])
        assert found is not None
        return found

    async def attach(self, user_id: str, event_id: str, external_event_id: str) -> None:
        """Google에 넣고 나서 그 번호를 기록에 붙인다."""
        await self.conn.execute(
            "update calendar_events set external_event_id = %s, synced_at = now()"
            " where id = %s and user_id = %s",
            (external_event_id, event_id, user_id),
        )

    async def remove(self, user_id: str, event_id: str) -> None:
        await self.conn.execute(
            "delete from calendar_events where id = %s and user_id = %s", (event_id, user_id)
        )


def get_calendar_repo(conn: Annotated[AsyncConnection, Depends(get_conn)]) -> CalendarRepository:
    return CalendarRepository(conn)


CalendarRepoDep = Annotated[CalendarRepository, Depends(get_calendar_repo)]

NOT_FOUND = "캘린더 일정을 찾을 수 없어요."


@router.post("/events", status_code=201, response_model=CalendarEventView)
async def add_event(
    body: CalendarEventRequest,
    user: CurrentUserDep,
    repo: CalendarRepoDep,
    service: CalendarServiceDep,
    now: NowDep,
    response: Response,
) -> CalendarEventView:
    """준비한 공고의 마감일을 Google 캘린더에 넣는다. 이미 넣었으면 200과 그 일정이다.

    일정은 마감 시각으로 끝나는 1시간짜리다. 연결이 없거나 만료면 409 CALENDAR_NOT_CONNECTED,
    Google이 거절하면 502 GOOGLE_API_ERROR다.
    """
    if body.provider != "google":  # .ics 내려받기는 F-34(P1)다
        raise ApiError(
            422,
            "VALIDATION_FAILED",
            "입력값을 확인해 주세요.",
            {"fields": {"provider": "지금은 Google 캘린더만 등록할 수 있어요."}},
        )
    opportunity_id = str(body.opportunity_id)
    existing = await repo.event_for(user.id, opportunity_id, body.provider)
    if existing is not None and existing.external_event_id:
        response.status_code = 200
        return existing
    opportunity = await repo.prepared_opportunity(user.id, opportunity_id)
    if opportunity is None:
        raise _invalid("준비 일정을 먼저 만들어 주세요.")
    if opportunity.deadline_at is None:
        raise _invalid("마감일이 없는 공고예요. 캘린더에 넣을 수 없어요.")
    ends_at = opportunity.deadline_at.astimezone(KST)
    if ends_at <= now:
        raise ApiError(409, "DEADLINE_PASSED", "마감이 지난 공고예요. 캘린더에 넣을 수 없어요.")
    token = await service.access_token(user.id, now)
    title = event_title(opportunity.title)
    # 자리를 먼저 잡고 그 행의 id로 Google 일정 번호를 정한다(다시 눌러도 일정은 하나다)
    event = existing or await repo.reserve(
        user.id,
        provider=body.provider,
        opportunity_id=opportunity.id,
        title=title,
        starts_at=ends_at - timedelta(minutes=EVENT_MINUTES),
    )
    external_id = await service.insert(
        token, event_id=event_id_for(event.id), title=title, ends_at=ends_at
    )
    await repo.attach(user.id, event.id, external_id)
    return event.model_copy(update={"external_event_id": external_id})


@router.delete("/events/{event_id}", status_code=204, response_class=Response)
async def remove_event(
    event_id: UUID,
    user: CurrentUserDep,
    repo: CalendarRepoDep,
    service: CalendarServiceDep,
    now: NowDep,
) -> Response:
    """Google 캘린더에서도 지운다. 남의 일정·없는 일정은 404다.

    캘린더 권한이 없어졌으면 Google에서는 지우지 못한다. 그래도 우리 기록은 지운다. 그러지 않으면
    학생이 "캘린더에서 빼기"를 누를 때마다 실패하고 그 줄을 영영 지우지 못한다(Google 쪽 일정은
    학생이 직접 지운다). Google이 잠깐 멈춘 것(502)은 기록을 두고 다시 누르게 한다.
    """
    event = await repo.one(user.id, str(event_id))
    if event is None:
        raise ApiError(404, "NOT_FOUND", NOT_FOUND)
    try:
        token = await service.access_token(user.id, now)
        await service.delete(token, event.external_event_id)
    except ApiError as exc:
        if exc.code != "CALENDAR_NOT_CONNECTED":
            raise
        logger.info("캘린더 권한이 없어 기록만 지워요: event %s", event.id)
    await repo.remove(user.id, event.id)
    return Response(status_code=204)

async def lifespan(app: FastAPI) -> AsyncIterator[None]:
    settings: Settings = app.state.settings
    # 로그인 설정이 틀렸으면 첫 요청을 기다리지 않고 시작할 때 알린다(.env를 고치면 서버를 다시 켠다)

    await app.state.runner.drain(timeout=10)
    for pool in (app.state.pool, app.state.log_pool):
        if pool is not None:

    " 'status', s.status, 'latency_ms', s.latency_ms, 'reason', s.input->>'reason',"
    " 'attachment_no', s.input->'attachment_no',"
    " 'offset', coalesce(s.output->'offset', s.input->'offset'),"
    " 'start_page', s.input->'start_page', 'pages', s.output->'pages',"
    " 'error', s.output->>'error' is not null, 'accepted', s.output->'accepted',"
    " 'forced', s.output->'forced')"
    " order by s.seq, s.id)"
    " from tool_calls s where s.run_id = o.extraction_run_id), '[]'::jsonb) as steps,"
    " (select m.mark from opportunity_marks m where m.user_id = %(uid)s"
    " and m.opportunity_id = o.id) as my_mark"
    " from opportunities o" + _COURSE_JOIN + _PREP_JOIN + " where o.id = %(oid)s and" + _OPENABLE
)
# 관심 표시(F-45). 다른 표시로 바꾸면 시각을 새로 쓰고, 같은 표시를 다시 고르면 처음 시각을 둔다
_MARK_OPENABLE = (
    "select 1 from opportunities o"
    + _COURSE_JOIN
    + _PREP_JOIN
    + " where o.id = %(oid)s and"
    + _OPENABLE
)
_MARK_UPSERT = (
    "insert into opportunity_marks (user_id, opportunity_id, mark, marked_at)"
    " values (%(uid)s, %(oid)s, %(mark)s, %(now)s)"
    " on conflict (user_id, opportunity_id) do update set mark = excluded.mark,"
    " marked_at = case when opportunity_marks.mark = excluded.mark"
    " then opportunity_marks.marked_at else excluded.marked_at end"
    " returning marked_at"
)
# 조회 기록. 처음 연 시각은 그대로 두고 마지막 시각은 늦은 쪽을 남긴다. 시각을 고정한 실행(평가
# 러너·테스트)이 지난 시각으로 열어도 기록이 거꾸로 가지 않는다
_VIEW = (
    "insert into opportunity_views (user_id, opportunity_id, first_viewed_at, last_viewed_at)"
    " values (%s, %s, %s, %s) on conflict (user_id, opportunity_id) do update set"
    " last_viewed_at = greatest(opportunity_views.last_viewed_at, excluded.last_viewed_at)"
)


def _stale_sql(scope: str) -> str:
    """다시 판정할 공고와 그 요건."""
    return (
        "select o.id, o.requirements_version, o.eligibility_basis_date, o.deadline_at,"
        " o.apply_start_at, o.source_type::text as source_type,"
        " e.user_id is not null as had_result, e.status::text as old_status,"
        " e.missing_fields as old_missing, " + _REQUIREMENTS_JSON + " as requirements"
        " from opportunities o"
        + _COURSE_JOIN
        + _RESULT_JOIN
        + " where"
        + scope
        + " and"
        + _VISIBLE
        + " and o.extraction_run_id is not null"
        " and (%(force)s or e.user_id is null or e.evaluated_at is null"
        " or e.requirements_version <> o.requirements_version"
        " or e.engine_version <> %(engine)s"
        # 날이 바뀌면 다시: 기준일이 "오늘"인 공고(청년정책 포함), 엔진 오류로 판정하지 못한 공고(오류를
        # 고쳤을 수 있다)
        " or (((o.eligibility_basis_date is null and (o.deadline_at is null"
        " or (o.source_type = 'youth_policy' and o.deadline_at >= %(now)s)))"
        " or e.reason_text = %(engine_error)s)"
        " and (e.evaluated_at at time zone 'Asia/Seoul')::date < %(today)s))"
    )


def _feed_sql(where: str, outer: str, order: str) -> str:
    return (
        "with feed as (select o.id, o.title, o.organizer, o.category::text as category,"
        " o.source_type::text as source_type, o.deadline_at, o.created_at, o.easy_summary,"
        " o.needs_review, coalesce(o.uploaded_by = %(uid)s, false) as uploaded_by_me,"
        " c.name as course_name,"
        " exists(select 1 from prep_plans p where p.user_id = %(uid)s and p.opportunity_id = o.id"
        " and " + PREP_DONE + ") as prepared,"
        " coalesce(o.created_at >= %(new_since)s, false) and not exists(select 1"
        " from opportunity_views v where v.user_id = %(uid)s and v.opportunity_id = o.id) as is_new,"
        " " + _JUDGED + " as judged,"
        " case when " + _JUDGED + " then e.status::text else 'undetermined' end as eff_status,"
        " case when " + _JUDGED + " then coalesce(e.missing_fields, '{}') else '{}' end"
        " as eff_missing,"
        " e.reason_text, m.mark as my_mark"
        " from opportunities o" + _COURSE_JOIN + _RESULT_JOIN + _MARK_JOIN + " where" + where + ")"
        " select * from feed" + outer + " order by " + order + " limit %(limit)s"
    )


@dataclass(frozen=True)
class Cursor:
    scope: str  # 목록 조건(정렬·필터)의 지문. 조건이 다른 목록에는 쓸 수 없다
    # 마지막 행의 정렬 값(deadline: 마감 시각, recent: 등록 시각). 없을 수 있다
    value: datetime | None
    id: str


@dataclass(frozen=True)
class FeedQuery:
    eligibility: frozenset[str] | None = None  # None이면 전체
    categories: tuple[str, ...] | None = None
    source_types: tuple[str, ...] | None = None
    sort: Sort = "deadline"
    include_expired: bool = False
    include_not_interested: bool = False  # 관심 없음 공고도 준다(F-45)
    limit: int = 20
    cursor: Cursor | None = None

    def scope(self) -> str:
        """cursor를 묶는 목록 조건의 지문. 정렬이나 필터를 바꾸면 목록을 처음부터 다시 부른다.

        같은 목록이면 지문도 같다: 값의 순서는 보지 않고, 모든 값을 고른 필터는 필터 없음과 같다.
        """
        parts = (
            self.sort,
            _filter_key(self.eligibility, ELIGIBILITY_STATUSES),
            _filter_key(self.categories, CATEGORIES),
            _filter_key(self.source_types, SOURCE_TYPES),
            str(self.include_expired),
            str(self.include_not_interested),
        )
        return hashlib.sha256("|".join(parts).encode()).hexdigest()[:16]


def _filter_key(values: Collection[str] | None, everything: Collection[str]) -> str:
    chosen = set(values or ())
    return "" if chosen >= set(everything) else ",".join(sorted(chosen))


@dataclass(frozen=True)
class FeedPage:
    items: list[OpportunityItem]
    next_cursor: str | None


@dataclass(frozen=True)
class Refresh:
    judged: int  # 다시 계산한 공고 수
    changed: int  # 라벨이 바뀐 공고 수(전에 판정이 있던 공고만 센다)


def display_status(status: str, missing_fields: Sequence[str]) -> str:
    """화면 라벨 4종. 판정 불가는 입력하면 바뀔 수 있으면 정보 필요, 아니면 원문 확인 필요다."""
    if status == "undetermined":
        return "missing_info" if missing_fields else "needs_review"
    return status


def encode_cursor(cursor: Cursor) -> str:
    data = {
        "q": cursor.scope,
        "v": cursor.value.isoformat() if cursor.value else None,
        "id": cursor.id,
    }
    raw = json.dumps(data, separators=(",", ":")).encode()
    return base64.urlsafe_b64encode(raw).decode().rstrip("=")


def decode_cursor(text: str) -> Cursor:
    """next_cursor로 준 값을 되돌린다. 모양이 틀리면 ValueError."""
    try:
        data = json.loads(base64.urlsafe_b64decode(text + "=" * (-len(text) % 4)))
        scope, value, ident = data["q"], data["v"], data["id"]
        if not isinstance(scope, str) or not isinstance(ident, str):
            raise ValueError(scope)
        moment = None if value is None else datetime.fromisoformat(value)
        if moment is not None and moment.tzinfo is None:
            raise ValueError(value)
        return Cursor(scope=scope, value=moment, id=str(uuid.UUID(ident)))
    except (binascii.Error, ValueError, KeyError, TypeError, UnicodeDecodeError) as exc:
        raise ValueError("잘못된 cursor") from exc


class OpportunityRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def refresh_judgments(
        self,
        user_id: str,
        *,
        now: datetime,
        force: bool = False,
        include_expired: bool = False,
        display_name: str | None = None,
    ) -> Refresh:
        """피드에 나올 공고(include_expired면 지난 공고까지)의 낡은 판정을 다시 계산해 저장한다.

        force면 그 공고를 모두 다시 판정하고 나머지 공고의 판정은 지운다.
        프로필 행이 없으면(첫 요청이 피드) display_name과 함께 만든다.
        """
        profile = Profile.from_row(await self._lock_profile(user_id, display_name))
        today = now.astimezone(KST).date()
        stale = await (
            await self.conn.execute(
                _stale_sql(_WITH_EXPIRED if include_expired else _ACTIVE),
                {
                    "uid": user_id,
                    "now": now,
                    "force": force,
                    "engine": ENGINE_VERSION,
                    "engine_error": ENGINE_ERROR_SUMMARY,
                    "today": today,
                },
            )
        ).fetchall()
        payload: list[dict[str, Any]] = []
        changed = 0
        if stale:
            departments = await self._departments()
            for item in stale:
                judged = _judge(item, profile, departments, today)
                payload.append(_payload(item, judged.stored))
                old = display_status(item["old_status"] or "", item["old_missing"] or ())
                if item["had_result"] and old != judged.label:
                    changed += 1
        await self._upsert(user_id, payload, now)
        if force:  # 다시 판정하지 않은 공고(마감·숨김·안 보임)의 판정은 지운다
            await self.conn.execute(
                "delete from eligibility_results"
                " where user_id = %s and opportunity_id <> all(%s::uuid[])",
                (user_id, [item["opportunity_id"] for item in payload]),
            )
        else:  # 요건 추출에 실패한 공고의 옛 판정은 지운다(판정하지 않는다)
            await self.conn.execute(
                "delete from eligibility_results e using opportunities o"
                " where e.user_id = %s and e.opportunity_id = o.id and o.extraction_run_id is null",
                (user_id,),
            )
        return Refresh(judged=len(payload), changed=changed)

    async def detail(
        self,
        user_id: str,
        opportunity_id: str,
        *,
        now: datetime,
        display_name: str | None = None,
    ) -> OpportunityDetail | None:
        """공고 상세(S1-6). 이 사용자에게 보이지 않는 공고면 None이다.

        피드와 같은 잠금 아래에서 그 공고를 다시 판정해 저장하고, 조회 기록을 남긴다(is_new가 꺼진다).
        """
        profile_row = await self._lock_profile(user_id, display_name)
        row = await (
            await self.conn.execute(_DETAIL, {"uid": user_id, "oid": opportunity_id})
        ).fetchone()
        if row is None:
            return None
        if row["extraction_run_id"] is None:  # 요건 추출에 실패한 공고는 판정하지 않는다
            await self.conn.execute(
                "delete from eligibility_results where user_id = %s and opportunity_id = %s",
                (user_id, opportunity_id),
            )
            eligibility = DetailEligibility(
                status="undetermined",
                display_status="needs_review",
                reason_text=UNJUDGED_SUMMARY,
                basis_date=None,
                requirements_version=row["requirements_version"],
                missing_fields=[],
                clauses=[],
                conditions=[],
                evaluated_at=None,
            )
        else:
            profile = Profile.from_row(profile_row)
            departments = await self._departments()
            judged = _judge(row, profile, departments, now.astimezone(KST).date())
            await self._upsert(user_id, [_payload(row, judged.stored)], now)
            eligibility = _detail_eligibility(
                judged, profile, departments, row["requirements_version"], now
            )
        await self.conn.execute(_VIEW, (user_id, opportunity_id, now, now))
        names = {item["seq"]: item["file_name"] for item in row["attachments"]}
        apply_start: datetime | None = row["apply_start_at"]
        deadline: datetime | None = row["deadline_at"]
        confidence = row["extraction_confidence"]
        return OpportunityDetail(
            id=str(row["id"]),
            title=row["title"],
            organizer=row["organizer"],
            category=row["category"],
            source_type=row["source_type"],
            status=row["status"],
            original_url=row["original_url"],
            poster_url=None,  # TODO(W6): 포스터 업로드에서 Storage 서명 URL(5분)을 붙인다
            easy_summary=row["easy_summary"],
            apply_start_at=apply_start.astimezone(KST) if apply_start else None,
            deadline_at=deadline.astimezone(KST) if deadline else None,
            needs_review=bool(row["needs_review"]),
            review_reasons=_lines(row["review_reasons"]),
            extraction_confidence=float(confidence) if confidence is not None else None,
            uploaded_by_me=row["uploaded_by_me"],
            course_name=row["course_name"],
            attachments=[_attachment(item) for item in row["attachments"] if item["source_url"]],
            eligibility=eligibility,
            documents=[DocumentItem(**document) for document in row["documents"]],
            prep=Prep(
                prepared=row["prep_done"],
                prep_plan_id=_text(row["prep_plan_id"]) if row["prep_done"] else None,
                tasks_total=row["tasks_total"],
                tasks_done=row["tasks_done"],
                calendar_events=[CalendarEventRef(**event) for event in row["calendar_events"]],
            ),
            process=Process(
                extraction=[_step(step, names) for step in row["steps"]],
                evaluated_at=eligibility.evaluated_at,
                prepare_run_id=_text(row["prepare_run_id"]),
            ),
            reported_by_me=row["reported_by_me"],
            my_mark=row["my_mark"],
        )

    async def set_mark(
        self,
        user_id: str,
        opportunity_id: str,
        mark: str,
        *,
        now: datetime,
        display_name: str | None = None,
    ) -> datetime | None:
        """관심·관심 없음 표시(F-45). 상세를 열 수 있는 공고에만 붙인다. 아니면 None.

        공고마다 표시는 하나다. 다른 표시를 보내면 바꾼다. 프로필 행이 없으면(첫 요청) 만든다.
        피드처럼 프로필 행을 잠근다: 피드 응답 하나의 목록(my_mark)과 숫자(counts)가 어긋나지 않는다.
        """
        await self._lock_profile(user_id, display_name)
        params = {"uid": user_id, "oid": opportunity_id, "mark": mark, "now": now}
        if await (await self.conn.execute(_MARK_OPENABLE, params)).fetchone() is None:
            return None
        row = await (await self.conn.execute(_MARK_UPSERT, params)).fetchone()
        assert row is not None
        return row["marked_at"]

    async def clear_mark(self, user_id: str, opportunity_id: str) -> None:
        """표시를 지운다. 없으면 아무것도 하지 않는다.

        set_mark처럼 프로필 행을 잠근다. 프로필 행이 없으면 만들지 않는다(지울 표시도 없다).
        """
        await self.conn.execute(
            "select 1 from profiles where id = %s for no key update", (user_id,)
        )
        await self.conn.execute(
            "delete from opportunity_marks where user_id = %s and opportunity_id = %s",
            (user_id, opportunity_id),
        )

    async def feed_page(self, user_id: str, query: FeedQuery, *, now: datetime) -> FeedPage:
        params: dict[str, Any] = {
            "uid": user_id,
            "now": now,
            "new_since": now - timedelta(days=NEW_DAYS),
            "limit": query.limit + 1,
        }
        where = [_WITH_EXPIRED if query.include_expired else _ACTIVE, _VISIBLE, _SHOWN]
        if not query.include_not_interested:
            where.append(_NOT_DISMISSED)
        if query.categories:
            where.append(" o.category::text = any(%(categories)s)")
            params["categories"] = list(query.categories)
        if query.source_types:
            where.append(" o.source_type::text = any(%(source_types)s)")
            params["source_types"] = list(query.source_types)
        outer = []
        if query.eligibility:
            outer.append("eff_status = any(%(eligibility)s)")
            params["eligibility"] = sorted(query.eligibility)
        if query.cursor:
            outer.append(_after(query.sort, query.cursor))
            params["cursor_value"], params["cursor_id"] = query.cursor.value, query.cursor.id
        sql = _feed_sql(
            " and".join(where),
            " where " + " and ".join(outer) if outer else "",
            _ORDER[query.sort],
        )
        rows = await (await self.conn.execute(sql, params)).fetchall()
        today = now.astimezone(KST).date()
        page = rows[: query.limit]
        next_cursor = None
        if len(rows) > query.limit:
            last = page[-1]
            value = last["deadline_at"] if query.sort == "deadline" else last["created_at"]
            cursor = Cursor(scope=query.scope(), value=value, id=str(last["id"]))
            next_cursor = encode_cursor(cursor)
        return FeedPage(items=[_item(row, today) for row in page], next_cursor=next_cursor)

    async def feed_counts(self, user_id: str, *, now: datetime) -> FeedCounts:
        """홈 요약 카드: 필터와 상관없이 지금 보이는 활성 공고 전체 기준."""
        row = await (
            await self.conn.execute(
                _COUNTS,
                {
                    "uid": user_id,
                    "now": now,
                    "new_since": now - timedelta(days=NEW_DAYS),
                    "today": now.astimezone(KST).date(),
                    "soon": SOON_DAYS,
                },
            )
        ).fetchone()
        assert row is not None
        return FeedCounts.model_validate(row)

    async def _lock_profile(self, user_id: str, display_name: str | None) -> dict[str, Any]:
        """프로필 행을 (없으면 만들고) 잠근 뒤 읽는다.

        같은 사용자의 판정은 한 번에 하나씩: 프로필 저장과 피드 읽기가 겹쳐도 옛 프로필로 덮어쓰지 않는다.
        no key update라서 이 사용자의 다른 행(이벤트·알림 등)이 profiles를 참조하며 넣는 것은 막지 않는다.
        """
        await self.conn.execute(
            "insert into profiles (id, display_name) values (%s, %s) on conflict do nothing",
            (user_id, display_name),
        )
        row = await (
            await self.conn.execute(
                "select * from profiles where id = %s for no key update", (user_id,)
            )
        ).fetchone()
        assert row is not None
        return row

    async def _upsert(self, user_id: str, payload: list[dict[str, Any]], now: datetime) -> None:
        """판정 여러 개를 한 문장으로 저장한다(_payload 모양)."""
        if payload:
            await self.conn.execute(
                _UPSERT,
                {"uid": user_id, "engine": ENGINE_VERSION, "now": now, "rows": Jsonb(payload)},
            )

    async def _departments(self) -> list[Department]:
        """판정에 쓰는 학과 목록. 목록에서 빠진(폐지·통합) 학과도 단과대학·계열을 알아야 해서 모두 읽는다."""
        rows = await (
            await self.conn.execute("select name, college, field_group from departments")
        ).fetchall()
        return [Department.from_row(row) for row in rows]


def _after(sort: Sort, cursor: Cursor) -> str:
    """정렬 순서(_ORDER)에서 cursor 다음에 오는 행. 값이 없는 행은 맨 뒤에 id 순으로 온다."""
    column, beyond = ("deadline_at", ">") if sort == "deadline" else ("created_at", "<")
    if cursor.value is None:
        return f"({column} is null and id {beyond} %(cursor_id)s)"
    return (
        f"({column} {beyond} %(cursor_value)s"
        f" or ({column} = %(cursor_value)s and id {beyond} %(cursor_id)s) or {column} is null)"
    )


def _item(row: dict[str, Any], today: date) -> OpportunityItem:
    deadline: datetime | None = row["deadline_at"]
    status: str = row["eff_status"]
    missing = list(row["eff_missing"] or [])
    return OpportunityItem(
        id=str(row["id"]),
        title=row["title"],
        organizer=row["organizer"],
        category=row["category"],
        source_type=row["source_type"],
        deadline_at=deadline.astimezone(KST) if deadline else None,
        d_day=(to_kst_date(deadline) - today).days if deadline else None,
        easy_summary=row["easy_summary"],
        eligibility=FeedEligibility(
            status=status,
            display_status=display_status(status, missing),
            summary=(row["reason_text"] or "") if row["judged"] else UNJUDGED_SUMMARY,
            missing_fields=missing,
        ),
        needs_review=bool(row["needs_review"]),
        uploaded_by_me=row["uploaded_by_me"],
        course_name=row["course_name"],
        prepared=row["prepared"],
        is_new=row["is_new"],
        my_mark=row["my_mark"],
    )


@dataclass(frozen=True)
class _Judged:
    stored: dict[str, Any]  # eligibility_results에 넣을 값(Judgment.storage_row 모양)
    label: str  # display_status
    judgment: Judgment | None  # 엔진이 오류를 냈으면 None
    requirements: tuple[Requirement, ...]
    basis_date: date | None


def _judge(
    item: dict[str, Any], profile: Profile, departments: list[Department], today: date
) -> _Judged:
    """공고 행 하나(requirements·eligibility_basis_date·deadline_at)를 판정한다.

    엔진 오류면 "판정하지 못함" 행을 돌려준다: 그 공고만 원문 확인 필요로 보인다.
    """
    basis: date | None = None
    try:
        requirements = tuple(Requirement.from_row(r) for r in item["requirements"])
        days = _basis_dates(item, today)
        basis = days[0]
        # 기준일이 둘이면(청년정책) 더 나은 쪽을 쓴다. 같으면 앞 날짜다(max는 처음 나온 것을 고른다)
        judgment = max(
            (
                check_eligibility(
                    list(requirements), profile, basis_date=day, departments=departments
                )
                for day in days
            ),
            key=lambda found: _RANK[found.status],
        )
        return _Judged(
            judgment.storage_row(),
            judgment.display_status,
            judgment,
            requirements,
            judgment.basis_date,
        )
    except Exception:
        logger.exception("판정하지 못한 공고: %s", item["id"])
        return _Judged(_engine_error_row(), "needs_review", None, (), basis)


_RANK = {"ineligible": 0, "undetermined": 1, "eligible": 2}


def _basis_dates(item: dict[str, Any], today: date) -> tuple[date, ...]:
    """판정 기준일(판정엔진_규칙.md 8장). 보통 하나다(공고 기준일 → 마감일 → 오늘).

    청년정책(온통청년)은 신청일 기준이 대부분이고 신청 기간이 몇 년인 정책도 있다. 그래서 신청할 수 있는 첫날
    (오늘, 신청 기간 전이면 시작일)과 마감일을 둘 다 보고 더 나은 결과를 쓴다. 나이 상한은 첫날에, 하한은
    마감일에 맞으면 그 사이 어느 날엔 신청할 수 있다. 신청 기간이 끝났으면 마감일 하나다."""
    if item["source_type"] != "youth_policy" or item["eligibility_basis_date"] is not None:
        return (resolve_basis_date(item["eligibility_basis_date"], item["deadline_at"], today),)
    start = item["apply_start_at"]
    first = max(today, to_kst_date(start)) if start is not None else today
    if item["deadline_at"] is None:
        return (first,)
    deadline = to_kst_date(item["deadline_at"])
    return (deadline,) if deadline <= first else (first, deadline)


def _engine_error_row() -> dict[str, Any]:

def _step(step: dict[str, Any], names: dict[int, str]) -> ProcessStep:
    """처리 과정 한 줄(_DETAIL의 steps 행 하나). 첨부를 읽은 단계는 첨부 이름을 넣어 보인다.

    도구가 오류를 돌려준 호출(없는 첨부 번호 등)과 거절된 제출은 실행 로그에 succeeded로 남는다
    (에이전트는 오류를 모델에 돌려주고 계속 간다). 화면에는 실패로 보인다. 첨부 번호·위치는
    에이전트와 같은 규칙(whole)으로 읽는다. 읽기·토큰 상한에 닿아 코드가 시킨 제출(forced)은
    모델이 고른 단계가 아니라서 pipeline으로 보인다.
    """
    tool: str = step["tool"]
    again = "이어 " if _continued(step) else ""
    if tool in (READ_TEXT, READ_IMAGE):
        number = whole(step.get("attachment_no"))
        name = names.get(number) if number is not None else None
        target = f"첨부 '{name}'" if name else f"첨부 {number}번" if number else "첨부"
        how = "이미지로 " if tool == READ_IMAGE else ""
        label = f"{target} {how}{again}읽기"
    elif tool == FETCH_ORIGINAL:
        label = f"공고 원문 페이지 {again}읽기"
    elif tool == FETCH_YOUTH:
        label = "온통청년에서 정책 정보 받기"
    elif tool == BUILD_YOUTH:
        label = "온통청년 항목으로 지원 자격 정리"
    else:
        label = "지원 자격 정리" if tool == SUBMIT else tool
    failed = step.get("error") is True or (tool == SUBMIT and step.get("accepted") is False)
    chosen = tool in _AGENT_TOOLS and step.get("forced") is not True
    return ProcessStep(
        seq=step["seq"],
        tool=tool,
        label=label,
        status="failed" if failed else step["status"],
        latency_ms=step["latency_ms"],
        chosen_by="agent" if chosen else "pipeline",
        note=_line(step.get("reason")),
    )


def _continued(step: dict[str, Any]) -> bool:
    """앞에서 읽은 곳의 뒷부분을 읽은 호출. 도구가 실제로 읽은 위치를 보고, 오류면 요청한 위치를 본다.

    글자 읽기·원문 읽기는 시작 위치(offset)가 0보다 크면, Vision은 PDF를 2쪽부터 읽었으면 이어 읽기다.
    이미지는 한 장이라 이어 읽기가 없다.
    """
    if step["tool"] != READ_IMAGE:
        offset = whole(step.get("offset"))
        return offset is not None and offset > 0
    pages = step.get("pages")  # 읽은 PDF 쪽 "4–6/8". 이미지는 없다
    if isinstance(pages, str) and (first := _PAGES.match(pages)):
        return int(first.group(1)) > 1
    if step.get("error") is not True:
        return False  # 이미지를 읽었다
    start_page = whole(step.get("start_page"))
    return start_page is not None and start_page > 1


def _line(text: Any) -> str | None:
    """모델이 쓴 글(고른 이유, 원문 확인 필요 이유)을 화면용 한 줄로: 보이지 않는 문자(폭 없는 문자,
    글자 방향 제어)와 주소를 지우고 공백·줄바꿈을 한 칸으로 줄여 LINE_MAX_CHARS자까지. 남는 글이
    없으면 None이다.

    공고 글을 읽은 모델이 쓴 글이라, 공고 속 지시문이 링크를 끼워 넣지 못하게 쉬운 설명과 같은 규칙으로
    정리한다(app/extraction/validate.py). 저장된 값을 읽을 때 정리해서 예전 행에도 같이 적용된다.
    화면은 이 글을 일반 텍스트로 보여 준다(자동 링크·마크다운 없이).
    """
    if not isinstance(text, str):
        return None
    line = " ".join(_LINK.sub("", _INVISIBLE.sub("", text)).split())
    if len(line) > LINE_MAX_CHARS:
        line = line[: LINE_MAX_CHARS - 1].rstrip() + "…"
    return line or None


def _lines(texts: Sequence[Any] | None) -> list[str]:
    """여러 줄을 _line으로 정리한다. 빈 줄과 같은 줄은 빼고, REASONS_MAX줄이 넘으면 "외 N건"으로 줄인다."""
    lines = list(dict.fromkeys(line for text in texts or () if (line := _line(text))))
    if len(lines) > REASONS_MAX:
        return [*lines[:REASONS_MAX], f"외 {len(lines) - REASONS_MAX}건"]
    return lines


def _attachment(item: dict[str, Any]) -> AttachmentItem:
    if item["error"]:
        status = "failed"
    elif item["method"]:
        status = "succeeded"
    else:
        status = "skipped"  # 에이전트가 읽지 않은 첨부
    return AttachmentItem(
        id=str(item["id"]),
        file_name=item["file_name"],
        source_url=item["source_url"],
        extract_status=status,
    )


def _text(value: Any) -> str | None:
    return str(value) if value is not None else None

FAILED_MESSAGE = "준비 일정을 만들지 못했어요. 잠시 후 다시 눌러 주세요."
_CODED = re.compile(r"^([A-Z][A-Z_]+): (.+)$", re.S)  # agent_log.error_text의 "코드: 문구"


@dataclass(frozen=True)
class RunRow:
    id: str
    user_id: str | None
    trigger_type: str
    status: str
    started_at: datetime | None
    finished_at: datetime | None
    latency_ms: int | None
    error_message: str | None

    def error(self) -> RunError | None:
        """학생에게 보여 줄 실패 이유. ApiError로 남긴 것만 그대로 보여 주고 나머지는 내부 기록이다."""
        if self.status != "failed":
            return None
        if self.error_message and (match := _CODED.match(self.error_message)):

        return RunError(code="INTERNAL_ERROR", message=FAILED_MESSAGE)


class RunRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def run(self, run_id: str) -> RunRow | None:
        row = await (
            await self.conn.execute(
                "select id, user_id, trigger_type, status::text as status, started_at, finished_at,"
                " latency_ms, error_message from agent_runs where id = %s",
                (run_id,),
            )
        ).fetchone()
        if row is None:
            return None
        return RunRow(
            id=str(row["id"]),
            user_id=str(row["user_id"]) if row["user_id"] else None,
            trigger_type=row["trigger_type"],
            status=row["status"],
            started_at=_kst(row["started_at"]),
            finished_at=_kst(row["finished_at"]),
            latency_ms=row["latency_ms"],
            error_message=row["error_message"],
        )

        rows = await (
            await self.conn.execute(
                "select seq, tool_name, status::text as status, latency_ms from tool_calls"
                " where run_id = %s order by seq, id",
                (run_id,),
            )
        ).fetchall()
        return [
            ProcessStep(
                seq=row["seq"],
                tool=row["tool_name"],
                label=PREPARE_LABELS.get(row["tool_name"], row["tool_name"]),
                status=row["status"],
                latency_ms=row["latency_ms"],
                chosen_by="pipeline",
                note=None,
            )
            for row in rows
        ]

    async def prepare_result(self, user_id: str, run_id: str) -> PrepareResult | None:
        """그 실행이 만든 내 계획. 없으면(지워짐) None."""
        plan = await (
            await self.conn.execute(
                "select id, opportunity_id from prep_plans where agent_run_id = %s and user_id = %s",
                (run_id, user_id),
            )
        ).fetchone()
        if plan is None:
            return None
        params: dict[str, Any] = {"plan": plan["id"], "oid": plan["opportunity_id"]}
        documents = await (
            await self.conn.execute(
                "select d.id::text as id, d.name, d.issuer, d.how_to, d.lead_days, d.effort_minutes,"
                " d.form_url, coalesce(d.is_required, true) as is_required,"
                " t.id::text as task_id, t.is_done"
                " from opportunity_documents d left join planner_tasks t"
                " on t.prep_plan_id = %(plan)s and t.document_id = d.id"
                " where d.opportunity_id = %(oid)s"
                " order by coalesce(d.is_required, true) desc, d.name, d.id",
                params,
            )
        ).fetchall()
        tasks = await (
            await self.conn.execute(
                "select id::text as id, title, due_date, document_id::text as document_id"
                " from planner_tasks where prep_plan_id = %(plan)s order by sort_order, due_date, id",
                params,
            )
        ).fetchall()
        return PrepareResult(
            prep_plan_id=str(plan["id"]),
            documents=[DocumentItem(**row) for row in documents],
            tasks=[PrepTask(**row) for row in tasks],
            # 마감일 캘린더는 따로 등록한다(POST /calendar/events). 준비하기 결과에는 담지 않는다
            calendar_event=None,
            calendar_error=None,
        )

def _values(
    field: str, raw: str | None, allowed: Sequence[str], errors: dict[str, str]
) -> tuple[str, ...] | None:
    """쉼표로 여러 값을 받는다. 비어 있으면 None(전체). 알 수 없는 값은 errors에 모은다."""
    values = tuple(dict.fromkeys(part.strip() for part in (raw or "").split(",") if part.strip()))
    if unknown := [value for value in values if value not in allowed]:

) -> MarkResult:

    상세를 열 수 있는 공고에만 붙인다. 그 밖은 404 NOT_FOUND다.
    """
    marked_at = await repo.set_mark(
        user.id, str(opportunity_id), body.mark, now=now, display_name=user.name
    )
    if marked_at is None:
        raise ApiError(404, "NOT_FOUND", "공고를 찾을 수 없어요.")
    return MarkResult(mark=body.mark, marked_at=marked_at.astimezone(KST))

    await repo.clear_mark(user.id, str(opportunity_id))
    return Response(status_code=204)


@router.post("/{opportunity_id}/prepare", status_code=202, response_model=PrepareStarted)
async def prepare_opportunity(
    opportunity_id: UUID,
    body: PrepareRequest,
    user: CurrentUserDep,
    service: PrepareServiceDep,
    now: NowDep,
    response: Response,
) -> PrepareStarted:
    """준비하기(F-30·F-31). 서류 안내 → 역산 일정을 뒤에서 만들고 run_id를 먼저 준다(GET /runs/{id}).

    누를 때 지금 프로필로 다시 판정한다. 이미 준비한 공고(또는 준비하는 중)면 200과 그 실행이다.
    지원 어려움은 force가 아니면 409 NOT_ELIGIBLE, 마감이 지난 공고는 409 DEADLINE_PASSED, 상시 공고는
    target_date가 필요하다(422). 마감일 캘린더 등록은 따로 한다(POST /calendar/events, F-32).
    """
    oid = str(opportunity_id)
    detail = await service.judge(user.id, oid, now=now, display_name=user.name)
    if detail is None:
        raise ApiError(404, "NOT_FOUND", "공고를 찾을 수 없어요.")
    plan = await service.plan(user.id, oid)
    if plan is not None and (plan.done or plan.running):
        response.status_code = 200
        return PrepareStarted(run_id=plan.run_id, status="succeeded" if plan.done else "running")
    # 멈췄거나 실패한 계획은 지우고 다시 만든다. 지우면 그 공고를 다시 열지 못할 수도 있어
    # (숨김 공고는 준비한 사람에게만 보인다) 아래 거절 검사를 모두 지난 뒤에 지운다
    stale = plan
    if detail.status == "expired" or (detail.deadline_at is not None and detail.deadline_at <= now):
        raise ApiError(409, "DEADLINE_PASSED", "마감이 지난 공고예요. 준비 일정을 만들 수 없어요.")
    if detail.status != "active":  # 숨김·병합된 공고(준비하지 않았으면 보이지도 않는다)
        raise ApiError(404, "NOT_FOUND", "공고를 찾을 수 없어요.")
    if detail.eligibility.status == "ineligible" and not body.force:
        raise ApiError(
            409,
            "NOT_ELIGIBLE",
            "지원 조건을 충족하지 못한 공고예요. 그래도 준비할지 확인해 주세요.",
        )
    today = now.astimezone(KST).date()
    if detail.deadline_at is not None:
        deadline = detail.deadline_at.astimezone(KST).date()
    elif body.target_date is None or body.target_date < today:
        reason = (
            "상시 공고는 목표일을 골라 주세요."
            if body.target_date is None
            else "목표일은 오늘이나 그 뒤로 골라 주세요."
        )
        raise ApiError(
            422, "VALIDATION_FAILED", "입력값을 확인해 주세요.", {"fields": {"target_date": reason}}
        )
    else:
        deadline = body.target_date
    if stale is not None:
        await service.reset(stale)
    started = await service.begin(user.id, oid, deadline=deadline, today=today)
    if not started.created:
        response.status_code = 200
    return PrepareStarted(run_id=started.run_id, status=started.status)

async def test_detail_keeps_the_extraction_order() -> None:
    """판정표는 묶음 순서, 묶음 안에서는 추출이 낸 순서(원문 순서)다. 다시 추출해도 같다."""
    conn = await connect()

        opportunity = await one(
            conn,
            "insert into opportunities (source_type, title) values ('school_notice', '순서 장학')"
            " returning id, now() as now",
        )
        run = await one(
            conn,
            "insert into agent_runs (trigger_type, status) values ('batch_crawl', 'succeeded')"
            " returning id",
        )
        assert opportunity is not None and run is not None
        opportunity_id, now = str(opportunity["id"]), opportunity["now"]
        order = [  # 묶음 1은 "다음 중 하나" 5개, 묶음 2는 2개

            (1, "credits_last_semester", "gte", 12),
            (1, "gpa_last_semester", "gte", 3.0),
            (1, "semesters_completed", "lte", 7),
            (1, "credits_total", "gte", 60),
            (2, "grade", "neq", 4),

        ]
        drafts = tuple(
            RequirementDraft(no, field, op, value, None, f"근거 {no}-{field}", False)

        )

            )

        assert [c.condition_count for c in detail.eligibility.clauses] == [5, 2]
    finally:
        await conn.rollback()

async def test_detail_shows_review_reasons() -> None:
    """원문 확인 필요 이유(S1-6b): 추출할 때마다 새 값으로 바뀌고, 실패한 추출도 이유가 보인다.

    저장은 받은 그대로 하고, 상세는 모델이 쓴 글을 한 줄로 정리해 보인다.
    """
    conn = await connect()
    try:
        me = await make_user(conn)
        opportunity = await one(
            conn,
            "insert into opportunities (source_type, title) values ('school_notice', '이유 장학')"
            " returning id, now() as now",
        )
        run = await one(
            conn,
            "insert into agent_runs (trigger_type, status) values ('batch_crawl', 'succeeded')"
            " returning id",
        )
        assert opportunity is not None and run is not None
        opportunity_id, now, run_id = str(opportunity["id"]), opportunity["now"], str(run["id"])
        repo = OpportunityRepository(conn)

        async def save(result: ExtractionResult, digest: str) -> Any:
            await save_extraction(conn, opportunity_id, result, run_id=run_id, content_hash=digest)
            stored = await one(
                conn, "select review_reasons from opportunities where id = %s", opportunity_id
            )
            detail = await repo.detail(me, opportunity_id, now=now)
            assert stored is not None and detail is not None
            return stored["review_reasons"], detail

        # 새 공고는 이유가 없다(빈 배열)
        fresh = await repo.detail(me, opportunity_id, now=now)
        assert fresh is not None and (fresh.needs_review, fresh.review_reasons) == (False, [])

        raw = (
            "읽지 못한 첨부가 있음",
            "AI 메모: 신청서는\nhttps://evil.example/form 에서 받기",
        )
        flagged = ExtractionResult(
            succeeded=True, confidence=Decimal("0.9"), needs_review=True, review_reasons=raw
        )
        stored, detail = await save(flagged, "h1")
        assert stored == list(raw)  # 저장은 그대로
        assert detail.needs_review and detail.review_reasons == [
            "읽지 못한 첨부가 있음",
            "AI 메모: 신청서는 에서 받기",
        ]

        # 다시 추출해서 이유가 없어지면 비운다
        clean = ExtractionResult(succeeded=True, confidence=Decimal("0.9"))
        stored, detail = await save(clean, "h2")
        assert stored == [] and (detail.needs_review, detail.review_reasons) == (False, [])

        # 추출에 실패해도 이유는 남는다. 처리 과정은 비어 있다(실행이 공고에 이어지지 않음)
        failed = ExtractionResult(
            succeeded=False, needs_review=True, review_reasons=("자격 요건을 정리하지 못함",)
        )
        stored, detail = await save(failed, "h3")
        assert stored == ["자격 요건을 정리하지 못함"]
        assert (detail.needs_review, detail.review_reasons) == (True, ["자격 요건을 정리하지 못함"])
        assert detail.eligibility.reason_text == UNJUDGED_SUMMARY
        assert detail.process.extraction == []
    finally:
        await conn.rollback()
        await conn.close()

import { useEffect, useState } from "react";
import {
  ApiError,
  connectCalendar,
  getOpportunity,
  registerCalendarEvent,
  removeCalendarEvent,
} from "@/api/client";
import { calendarFailure } from "@/components/DeadlineCalendarRow";
import { routeToHref } from "@/lib/routes";
import type { OpportunityDetail } from "@/types/api";

interface Options {
  detail: OpportunityDetail;
  calendarConnected: boolean;
  calendarResult: "connected" | "error" | null;
  onDetailChange: (detail: OpportunityDetail) => void;
  onMessage: (message: string | null) => void;
}

/**
 * 마감일 캘린더 등록(F-32)의 상태와 동작.
 *
 * - 권한이 없으면 Google 증분 승인으로 보낸다. 돌아오면(?calendar=connected) 하려던 등록을 이어서 한다
 * - 넣는 중에 권한이 만료됐다고 하면(CALENDAR_NOT_CONNECTED) 다시 연결 화면으로 보낸다
 */
export default function useCalendarEvent({
  detail,
  calendarConnected,
  calendarResult,
  onDetailChange,
  onMessage,
}: Options) {
  const [busy, setBusy] = useState(false);
  const here = routeToHref({ name: "opportunity", id: detail.id }); // 연결 뒤 돌아올 곳
  const registered = detail.prep.calendar_events.length > 0;
  const canRegister = detail.prep.prepared && detail.deadline_at !== null;

  const add = async () => {
    if (!calendarConnected) return connectCalendar(here);
    await registerCalendarEvent(detail.id);
    onDetailChange(await getOpportunity(detail.id));
  };

  // Google 연결에서 돌아왔다. 연결됐으면 이어서 넣고, 실패했으면 까닭을 알린다
  useEffect(() => {
    if (calendarResult === "error") {
      onMessage("Google 캘린더를 연결하지 못했어요. 다시 눌러 주세요.");
      return;
    }
    if (calendarResult !== "connected" || !calendarConnected) return;
    if (!canRegister || registered) return;
    let alive = true;
    setBusy(true);
    registerCalendarEvent(detail.id)
      .then(() => getOpportunity(detail.id))
      .then((fresh) => alive && onDetailChange(fresh))
      .catch((error) => alive && onMessage(calendarFailure(error)))
      .finally(() => alive && setBusy(false));
    return () => {
      alive = false;
    };
    // 돌아온 직후 한 번만 한다
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [calendarResult, calendarConnected]);

  const toggle = async () => {
    setBusy(true);
    onMessage(null);
    try {
      const event = detail.prep.calendar_events[0];
      if (event) {
        await removeCalendarEvent(event.id);
        onDetailChange(await getOpportunity(detail.id));
      } else {
        await add();
      }
    } catch (error) {
      if (error instanceof ApiError && error.code === "CALENDAR_NOT_CONNECTED") {
        await connectCalendar(here); // 서버는 만료라고 본다. 권한을 다시 받는다
        return;
      }
      onMessage(calendarFailure(error));
    } finally {
      setBusy(false);
    }
  };

  return { busy, registered, canRegister, here, add, toggle };
}

// "기타" 칩은 연구·시험·기타 세 카테고리를 함께 고른다
function feedCategories(category: FeedParams["category"]): Category[] | null {

  return category === "etc" ? ["research", "exam", "etc"] : [category];
}

const FEED_PAGE_SIZE = 50; // API 최대값
const FEED_MAX_PAGES = 20; // 1,000개까지 받는다. 더 있으면 next_cursor가 남는다

// GET /opportunities. 홈은 판정 결과를 모두 받아 화면에서 묶는다(지원 어려움은 맨 아래 묶음, 추천·관심·숨김 탭).
// 숨김 탭을 위해 관심 없음 공고도 받고(include_not_interested), 다음 쪽(next_cursor)이 없을 때까지 50개씩
// 이어 받는다. counts는 필터와 상관없는 전체 기준이고 관심 없음 공고는 세지 않는다
export async function getFeed(params: FeedParams = {}): Promise<FeedResponse> {
  const categories = feedCategories(params.category);
  const sort = params.sort ?? "deadline";
  if (USE_MOCKS) return mock.getFeed(categories, sort, true);
  const query = new URLSearchParams({ sort, limit: String(FEED_PAGE_SIZE), include_not_interested: "true" });
  if (categories) query.set("category", categories.join(","));
  let page = await apiFetch<FeedResponse>(`/opportunities?${query}`);
  const items: OpportunityItem[] = [...page.items];
  for (let pages = 1; page.next_cursor && pages < FEED_MAX_PAGES; pages += 1) {
    query.set("cursor", page.next_cursor);
    page = await apiFetch<FeedResponse>(`/opportunities?${query}`);
    items.push(...page.items);
  }
  return { items, next_cursor: page.next_cursor, counts: page.counts };
}

export interface PrepareOptions {
  force?: boolean; // 지원 어려움 공고를 "그래도 준비하기"로 다시 보낸다
  onProgress?: (steps: ProcessStep[]) => void; // 실행 단계(GET /runs/{id}의 steps)
}

// POST /opportunities/{id}/prepare → 202 run_id → GET /runs/{id}로 끝날 때까지 기다린다(API 명세 2·7장).
// 이미 준비한 공고는 200이고, 그 실행이 남아 있지 않으면 결과도 없다(null: 부른 쪽이 상세를 다시 받는다)
export async function prepareOpportunity(
  id: string,
  targetDate?: string,
  options: PrepareOptions = {},
): Promise<PrepareResult | null> {
  if (USE_MOCKS) return respond(prepareStoredOpportunity(id, targetDate));
  const started = await apiFetch<PrepareStarted>(
    `/opportunities/${encodeURIComponent(id)}/prepare`,
    {
      method: "POST",
      body: JSON.stringify({
        ...(targetDate ? { target_date: targetDate } : {}),
        ...(options.force ? { force: true } : {}),
      }),
    },
  );
  if (!started.run_id) return null; // 실행 기록이 지워진 옛 계획. 상세로 보여 준다
  const run = await waitForRun<PrepareResult>(started.run_id, (current) =>
    options.onProgress?.(current.steps),
  );
  if (run.status === "failed") {
    const error = run.error;
    throw new ApiError(
      error?.code ?? "INTERNAL_ERROR",
      error?.message ?? "준비 일정을 만들지 못했어요. 잠시 후 다시 눌러 주세요.",
      0,
    );
  }
  return run.result;
}

      showToast("저장했어요. 화면을 새로 고치면 다시 판정한 결과가 보여요.");
    }
  };

  // 숨겨도 상세는 그대로 보이고, 홈의 숨김 탭에서 다시 볼 수 있다. 서버 답을 기다리지 않고 바로 바꾸고,
  // 저장하지 못하면 되돌린다
  const changeMark = async (next: OpportunityMark | null) => {
    const target = detail.id;
    const before = myMark;
    setMarkChange({ id: target, mark: next });
    showToast(markToast(before, next));
    setMarking(target);
    try {
      await setOpportunityMark(target, next);
    } catch (error) {
      setMarkChange((current) => (current?.id === target ? { id: target, mark: before } : current));
      showToast(markError(error));
    } finally {
      setMarking((current) => (current === target ? null : current));
    }
  };

  const subtitle = [
    getCategoryLabel(detail.category, "detail"),
    detail.organizer ?? "주최 미정",
    ...(isPoster && detail.uploaded_by_me ? ["내가 올린 포스터"] : []),
    ...(detail.course_name ? [`${detail.course_name} 수강생 대상`] : []),
  ].join(" · ");

  return (
    <>
      <Header
        title={detail.title}
        subtitle={subtitle}
        action={
          <div className="flex shrink-0 items-center gap-2">
            {originalHref ? (
              <a href={originalHref} target="_blank" rel="noopener noreferrer" className="shrink-0 text-[13px] font-semibold text-[#4f6ef7]">원문 보기</a>
            ) : openPoster ? (
              <button type="button" onClick={openPoster} className="shrink-0 text-[13px] font-semibold text-[#4f6ef7]">원문 보기</button>
            ) : null}
            <OpportunityMarkButtons mark={myMark} pending={marking === detail.id} onChange={changeMark} />
          </div>
        }
      />
      {detail.status !== "active" && (
        <p role="status" className="rounded-[14px] border border-[#e5e7eb] bg-[#f2f4f7] px-[18px] py-3 text-[13px] font-semibold text-[#475467]">
          {STATUS_NOTICE[detail.status]}
          {detail.prep.prepared && " 준비한 서류와 일정은 그대로 볼 수 있어요."}
        </p>
      )}
      <OpportunityPreparation
        detail={detail}
        calendarConnected={calendarConnected}
        calendarResult={calendarResult ?? null}
        navigate={navigate}
        onOpenProfile={() => setProfileOpen(true)}
        originalHref={originalHref}
        onOpenPoster={openPoster}
        onDetailChange={setOverride}
      />
      <section className="grid grid-cols-[1.3fr_1fr] gap-5 max-[900px]:grid-cols-1">
        <div className="min-h-[400px] rounded-2xl border border-[#e5e7eb] bg-white p-[22px]">
          <h2 className="text-[18px] font-semibold">AI 자격 판정</h2>
          <p className="mt-2 text-[13px] text-[#667085]">행을 누르면 판정에 사용한 공고 원문을 확인할 수 있어요.</p>
          <OpportunityConditions eligibility={detail.eligibility} />
        </div>
        <OpportunityDocuments detail={detail} onChange={setOverride} onError={showToast} />
      </section>
      <AiProcessPanel detail={detail} />
      <ProfileInputModal
        open={profileOpen && detail.eligibility.missing_fields.length > 0}
        opportunityId={detail.id}
        missingFields={detail.eligibility.missing_fields}
        onClose={() => setProfileOpen(false)}
        onSaved={reloadAfterProfile}
      />
      <Modal open={posterOpen} title="포스터 원문" onClose={() => setPosterOpen(false)}>
        {detail.poster_url && <img src={detail.poster_url} alt={`${detail.title} 포스터`} className="mx-auto max-h-[70dvh] rounded-[14px]" />}
      </Modal>
      <Toast toast={toast} />
    </>
  );
}
