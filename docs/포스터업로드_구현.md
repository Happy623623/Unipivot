# 포스터 파일 업로드 (F-13 1차)

> 📝 기준: PRD v0.9 F-13 · API 명세 v0.4 6·13·14장 · ERD v0.9 5·8장 · 2026-10-15
>
> 기준 커밋: main `d237d9e`(#31 캘린더)

포스터 사진·PDF를 **Supabase Storage에 올리고 `files`에 기록하는 `POST /files`**를 만든다. 지금까지 포스터 등록 화면은 실제 모드에서 "준비 중"만 보여 줬다. 이제 파일은 진짜로 올라간다. 포스터에서 제목·마감일·요건을 뽑아 공고로 만드는 일(Vision 추출·확인 화면·중복 공고)은 **다음 PR(W6 2차)**이다.

**규모와 확인:**
- api 새 파일 9개(검사·저장소 클라이언트·저장소·라우터·스키마와 테스트 4개), 바꾸는 파일 6개. web 새 파일 5개, 바꾸는 파일 7개, 지우는 파일 1개.
- **DB 변경이 없다.** `files` 테이블도, `original_name`도, 같은 파일을 막는 부분 유니크(`files_user_upload_sha_uq`)도 ERD v0.9에 이미 있다. 합친 뒤 db push가 필요 없다.
- **새 의존성 1개: `python-multipart`.** FastAPI가 파일 업로드(multipart)를 읽는 데 필요하다. `uv add`로 넣는다(아래 "레포에 넣는 법" 3번).
- **새 에러 코드 1개: `STORAGE_API_ERROR`(502).** 같은 PR에서 명세 13장 표에 넣는다. 나머지(`FILE_TOO_LARGE`·`PAGE_LIMIT_EXCEEDED`·`UNSUPPORTED_FILE_TYPE`·`DAILY_UPLOAD_LIMIT`·`VALIDATION_FAILED`)는 이미 있다.
- **Supabase 대시보드에서 비공개 버킷을 만들고 `.env`에 서비스 역할 키를 넣어야 돌아간다**(아래 "합친 뒤 확인" 0번). 없으면 올릴 때 502다.
- api `ruff` 통과, `626 passed, 97 skipped`(DB 없이) · `723 passed`(새 DB). web `typecheck`·`build` 통과.
- 가짜 Supabase Storage로 실제 모드 E2E 6단계, 목 모드 포스터 흐름을 돌렸다. 되돌림 시험(변이) 23가지가 모두 잡혔다.
- 따로 띄운 검토 에이전트 둘이 api와 web·문서를 나눠 봤다. **이미 있는 유니크를 한 번 더 만드는 마이그레이션**, **저장소에 올리는 동안 DB 연결을 쥐는 것**, **같은 파일을 다시 고르면 아무 일도 안 일어나는 것**을 포함해 12건을 고쳤다.

## 합친 뒤 확인

0. **Supabase에 비공개 버킷 만들고 `.env` 채우기(한 번만).**
   1. Supabase 대시보드 → Storage → New bucket. 이름은 `uploads`, **Public bucket은 끈 채로** 만든다(ERD 8장: 클라이언트 정책은 두지 않는다).
   2. Project Settings → API Keys에서 `service_role` 키를 복사한다. **DB 전체를 읽고 쓸 수 있는 값이라 채팅에 붙이지 말고 터미널에서 `api/.env`에 직접 적는다.**

   ```text
   SUPABASE_STORAGE_BUCKET=uploads
   SUPABASE_SERVICE_ROLE_KEY=<service_role 키>
   ```

   버킷 이름을 다르게 지었으면 `SUPABASE_STORAGE_BUCKET`을 그 이름으로 둔다. 비워 두면 서버를 켤 때 "파일 저장소 설정 확인" 경고가 뜨고, 올릴 때 502가 난다.
1. **API 다시 띄우기:** `http://localhost:8000/docs`에 `POST /api/v1/files`가 보여야 한다.
2. **올리기:** 사이드바 "포스터 등록" → 포스터 사진을 고른다. "포스터를 올렸어요"가 뜨고, Supabase Storage의 `uploads` 버킷에 `<내 user_id>/poster/<uuid>.jpg`가 생긴다. SQL Editor에서 `select original_name, mime_type, size_bytes, storage_path from files` 로 기록도 확인한다.
3. **2쪽 PDF·3쪽 PDF:** 2쪽 PDF는 올라가고(`page_count = 2`), 3쪽 PDF는 "PDF는 2쪽까지만 올릴 수 있어요"가 뜬다.
4. **아이폰 사진:** 아이폰에서 찍은 HEIC를 고르면 "사진을 JPG로 바꿔서 올려 주세요"가 뜬다(올라가지 않는다).

## 구조

```text
브라우저  ── multipart(file, kind=poster) ──▶  POST /api/v1/files
                                                │
                       20MB까지 읽기 ◀──────────┤  app/uploads.read_upload
                 앞부분 바이트로 형식·쪽수 ◀────┤  app/uploads.inspect_poster
                                                │
            ┌── 연결 빌림 ──┐                   │
            │ 같은 파일?    │ ──있으면──▶ 200 { reused: true, file_id: 기존 }
            │ 오늘 몇 개?   │ ──20개──▶ 429 DAILY_UPLOAD_LIMIT (reset_at)
            └── 연결 돌려줌 ┘                   │
                                                ▼
                        Supabase Storage  POST /object/uploads/<user>/poster/<id>.jpg
                                                │ 실패 ──▶ 502 STORAGE_API_ERROR
            ┌── 연결 빌림 ──┐                   ▼
            │ files insert  │ ──충돌──▶ 올린 파일 지우고 200 { reused: true }
            └── 연결 돌려줌 ┘                   │
                                                ▼
                                        201 { file_id, kind, page_count }
```

웹은 올리기 전에 같은 기준으로 한 번 거르고(`lib/posterFile.ts`), 올린 뒤에는 `POSTER_EXTRACT_READY`가 false면 "포스터를 올렸어요 + 자동 정리는 준비 중" 화면에서 멈춘다. 목 모드는 그대로 분석 → 확인 → 등록까지 간다.

## 확인한 것

- **단위·DB 테스트 44개**(api 17 · 검사 12 · 저장소 7 · DB 8). 성공, 같은 파일, 다른 사용자의 같은 파일, 20MB 초과, 3쪽 PDF, HEIC, 이름만 바꾼 파일, 깨진 PDF, 빈 파일, 하루 한도와 그 경계, 한도를 다 쓴 뒤의 같은 파일, 다른 kind, kind 없음, 토큰 없음, 저장소 거절, 겹친 요청, 연결을 빌렸다 돌려주는지, 풀이 없을 때 503.
- **하루 경계**는 KST로 고정했다. `2026-10-15 23:00 UTC`는 KST로 10/16이라 그날 기준이 10/16 0시다. `TZ=UTC`에서도 같은 결과다.
- **가짜 Supabase Storage로 실제 모드 E2E 6단계**: ① 올리면 버킷과 `files`에 남고 경로·`mime_type`·`size_bytes`·`sha256`·`original_name`이 맞다 ② 같은 파일을 또 올려도 하나다 ③ HEIC는 서버에 가기 전에 막힌다 ④ 저장소가 거절하면 기록이 안 남는다 ⑤ "다시 올리기"로 같은 파일을 다시 골라도 올라간다 ⑥ 20개를 채우면 한도 안내가 뜬다.
- **목 모드 포스터 흐름**: 파일 고르기 → 분석 → 확인 화면 → 공고 등록까지 그대로 돈다.
- **되돌림 시험 23가지**가 모두 잡혔다. HEIC 안내·HEIC 가리기·크기 한도·쪽수 한도·KST 경계·파일 이름 경로 떼기·저장소 경로의 사용자 폴더·같은 파일 검사·한도 off-by-one·진 쪽 파일 지우기·다른 kind 막기·중복의 200·연결을 쥔 채 올리기·`origin` 조건·`on conflict`·하루 세기의 날짜/사용자 조건·연결 돌려주기·풀 없음 검사·저장소 설정 검사·지워진 파일 지나가기·시험용 Storage 주소·웹의 multipart Content-Type.

## 남은 것

- **아주 큰 몸통을 앞단에서 끊기.** 지금은 1GB를 보내도 다 받은 뒤 413이다(FastAPI가 핸들러 전에 몸통을 임시 파일에 쓴다). 배포할 때 리버스 프록시나 ASGI 쪽에 몸통 상한을 두는 게 맞다.
- **쓰이지 않는 파일 치우기.** 올린 뒤 기록 직전에 끊기면 버킷에 아무도 안 보는 파일이 남는다. 비공개라 새지는 않지만 세는 길도 지우는 길도 없다. 다음 PR 전에 버킷 수명주기 규칙이나 정리 작업을 정한다.
- **하루 한도는 겹친 요청에서 한두 개 샐 수 있다.** 세는 것과 넣는 것이 다른 트랜잭션이다. 비용 울타리라 정확할 필요는 없다고 봤다.
- **업로드는 실행 로그(`agent_runs`)에 없다.** 다음 PR의 추출 실행(`poster_upload`)이 이 파일을 함께 기록한다.
- **내려받기(서명 URL)는 아직 없다.** 다음 PR에서 Vision에 그림을 넘길 때 5분짜리 서명 URL을 만든다(PRD·ERD가 정해 둔 방식).
- **HEIC**, `kind = syllabus`·`lecture_material`, `lms_course_id` 연결은 각 기능(F-14·F-15)과 함께 연다.

```python
"""업로드 파일 검사 (F-13, API 명세 6장).

파일 이름과 브라우저가 보낸 Content-Type은 믿지 않고 앞부분 바이트로 형식을 가린다. 확장자만 .jpg로
바꾼 실행 파일이 저장소에 들어가지 않게 하려는 것이다.

포스터는 JPG·PNG·WEBP 사진과 2쪽 이하 PDF를 받는다. HEIC(아이폰 기본 사진 형식)는 아직 못 읽는다.
아이폰에서 고른 사진은 그대로 HEIC로 올라오기 쉬워서, "형식이 아니에요" 대신 무엇을 하면 되는지
알려 준다.

20MB까지만 메모리로 올린다. FastAPI는 핸들러가 돌기 전에 몸통을 모두 받아 임시 파일에 쓰므로
(1MB가 넘으면 디스크), 여기서 끊는 것은 큰 파일을 통째로 메모리에 올리지 않기 위한 것이다. 아주 큰
몸통 자체를 거절하는 것은 앞단(프록시·ASGI)의 몫이다.
"""

import hashlib
import io
from dataclasses import dataclass
from datetime import datetime, timedelta
from typing import Protocol

from pypdf import PdfReader
from pypdf.errors import PdfReadError

from app.eligibility.dates import KST
from app.errors import ApiError

MAX_BYTES = 20 * 1024 * 1024
MAX_MB = MAX_BYTES // (1024 * 1024)
POSTER_MAX_PAGES = 2
DAILY_UPLOAD_LIMIT = 20  # 사용자당 KST 하루 (API 명세 14장, 10/15 확정)
_CHUNK_BYTES = 1024 * 1024
_NAME_MAX = 200


@dataclass(frozen=True)
class FileType:
    mime: str
    extension: str


JPEG = FileType("image/jpeg", "jpg")
PNG = FileType("image/png", "png")
WEBP = FileType("image/webp", "webp")
PDF = FileType("application/pdf", "pdf")
HEIC = FileType("image/heic", "heic")

# ISO 기반 미디어 파일(ftyp 박스)의 HEIF 계열 브랜드. 아이폰 사진은 heic·heix·mif1로 온다
_HEIF_BRANDS = frozenset({b"heic", b"heix", b"heim", b"heis", b"hevc", b"hevx", b"mif1", b"msf1"})


def sniff(data: bytes) -> FileType | None:
    """앞부분 바이트로 가린 형식. 아는 형식이 아니면 None이다."""
    if data.startswith(b"\xff\xd8\xff"):
        return JPEG
    if data.startswith(b"\x89PNG\r\n\x1a\n"):
        return PNG
    if data[:4] == b"RIFF" and data[8:12] == b"WEBP":
        return WEBP
    if data.startswith(b"%PDF-"):
        return PDF
    if data[4:8] == b"ftyp" and data[8:12] in _HEIF_BRANDS:
        return HEIC
    return None


class Chunked(Protocol):
    """UploadFile처럼 조금씩 읽을 수 있는 것."""

    async def read(self, size: int = -1, /) -> bytes: ...


async def read_upload(source: Chunked) -> bytes:
    """20MB까지만 모은다. 넘으면 나머지를 읽지 않고 413이다."""
    chunks: list[bytes] = []
    total = 0
    while chunk := await source.read(_CHUNK_BYTES):
        total += len(chunk)
        if total > MAX_BYTES:
            raise ApiError(
                413,
                "FILE_TOO_LARGE",
                f"파일이 {MAX_MB}MB를 넘어요. 더 작은 파일을 올려 주세요.",
            )
        chunks.append(chunk)
    return b"".join(chunks)


@dataclass(frozen=True)
class Inspected:
    type: FileType
    page_count: int | None  # PDF만 센다
    sha256: str


def inspect_poster(data: bytes) -> Inspected:
    """포스터로 받을 수 있는 파일인지 보고 형식·쪽수·해시를 돌려준다."""
    found = sniff(data)
    if found is HEIC:
        raise ApiError(
            400,
            "UNSUPPORTED_FILE_TYPE",
            "아이폰 사진 형식(HEIC)은 아직 올릴 수 없어요. 사진을 JPG로 바꿔서 올려 주세요.",
        )
    if found is None:
        raise ApiError(
            400,
            "UNSUPPORTED_FILE_TYPE",
            "JPG·PNG·WEBP 사진이나 2쪽 이하 PDF만 올릴 수 있어요.",
        )
    pages = _pdf_pages(data) if found is PDF else None
    if pages is not None and pages > POSTER_MAX_PAGES:
        raise ApiError(
            413,
            "PAGE_LIMIT_EXCEEDED",
            f"PDF는 {POSTER_MAX_PAGES}쪽까지만 올릴 수 있어요. 포스터가 있는 쪽만 남겨서 올려 주세요.",
        )
    return Inspected(found, pages, hashlib.sha256(data).hexdigest())


def _pdf_pages(data: bytes) -> int:
    try:
        return len(PdfReader(io.BytesIO(data)).pages)
    except (PdfReadError, ValueError, OSError) as exc:
        # 앞 5바이트는 %PDF-인데 안이 깨졌다. 쪽수를 모르면 2쪽 제한을 지킬 수 없어 받지 않는다
        raise ApiError(
            400,
            "UNSUPPORTED_FILE_TYPE",
            "PDF를 읽지 못했어요. 사진으로 찍어서 올려 주세요.",
        ) from exc


def clean_name(name: str | None) -> str | None:
    """올린 파일 이름. 경로와 줄바꿈을 떼고 길이를 줄인다(그대로 쓰면 저장소 경로가 흔들린다)."""
    if not name:
        return None
    base = name.replace("\\", "/").rsplit("/", 1)[-1]
    base = "".join(ch for ch in base if ch.isprintable()).strip()
    return base[:_NAME_MAX] or None


def storage_path(user_id: str, kind: str, file_id: str, extension: str) -> str:
    """버킷 안 경로. ERD 8장대로 사용자 폴더(`<user_id>/…`)로 시작한다."""
    return f"{user_id}/{kind}/{file_id}.{extension}"


def day_start(now: datetime) -> datetime:
    """KST 오늘 0시. 하루 한도를 세는 기준이다."""
    return now.astimezone(KST).replace(hour=0, minute=0, second=0, microsecond=0)


def day_reset(now: datetime) -> datetime:
    """한도가 풀리는 시각(KST 내일 0시). 429의 details.reset_at으로 준다."""
    return day_start(now) + timedelta(days=1)
```

```python
경로는 `<user_id>/<kind>/<file_id>.<확장자>`다.

- 올리기: POST {base}/object/{bucket}/{path} (본문은 파일 바이트 그대로)
- 지우기: DELETE {base}/object/{bucket}/{path}

서비스 역할 키는 DB 전체를 읽고 쓸 수 있는 값이라 응답·로그·오류 문구에 넣지 않는다. 내려받기는
나중에 API가 만드는 5분짜리 서명 URL로만 한다(포스터 추출에서 쓴다).
"""

from typing import Annotated
from urllib.parse import quote

import httpx
from fastapi import Depends

from app.config import Settings, get_settings

TIMEOUT_SECONDS = 60.0  # 20MB까지 올라온다


class StorageError(Exception):
    """저장소에 올리지 못했다. 설정이 비었을 때도 이 오류다(키·주소는 담지 않는다)."""


class SupabaseStorage:
    def __init__(self, *, base_url: str, bucket: str, service_key: str) -> None:
        self.base_url = base_url.rstrip("/")
        self.bucket = bucket
        self.service_key = service_key

    @property
    def ready(self) -> bool:
        """주소·버킷·키가 모두 있어야 올릴 수 있다."""
        return bool(self.base_url and self.bucket and self.service_key)

    def _url(self, path: str) -> str:
        quoted = quote(path, safe="/")
        return f"{self.base_url}/object/{quote(self.bucket, safe='')}/{quoted}"

    async def upload(self, path: str, data: bytes, content_type: str) -> None:
        await self._send("POST", path, content=data, content_type=content_type)

    async def remove(self, path: str) -> None:
        """올려 둔 파일을 지운다(기록을 남기지 못했을 때 되돌리기용). 없으면 그냥 지나간다."""
        await self._send("DELETE", path, gone_is_ok=True)

    async def _send(
        self,
        method: str,
        path: str,
        *,
        content: bytes | None = None,
        content_type: str | None = None,
        gone_is_ok: bool = False,
    ) -> None:
        if not self.ready:
            raise StorageError("파일 저장소 설정이 비었어요(SUPABASE_SERVICE_ROLE_KEY).")
        headers = {"Authorization": f"Bearer {self.service_key}"}
        if content_type:
            headers["Content-Type"] = content_type
        try:
            async with httpx.AsyncClient(timeout=TIMEOUT_SECONDS) as client:
                response = await client.request(
                    method, self._url(path), content=content, headers=headers
                )
        except httpx.HTTPError as exc:
            raise StorageError(f"파일 저장소에 닿지 못했어요: {type(exc).__name__}") from exc
        if gone_is_ok and response.status_code in (404, 410):
            return
        if response.status_code >= 400:
            raise StorageError(f"파일 저장소가 요청을 거절했어요({response.status_code}).")


def get_storage(settings: Annotated[Settings, Depends(get_settings)]) -> SupabaseStorage:
    return SupabaseStorage(
        base_url=settings.storage_base_url,
        bucket=settings.supabase_storage_bucket,
        service_key=settings.supabase_service_role_key,
    )


StorageDep = Annotated[SupabaseStorage, Depends(get_storage)]
```

```python
"""업로드 파일 SQL (F-13, ERD files).

사용자 것만 읽고 쓴다. 같은 사용자가 같은 파일(sha256)을 같은 kind로 올리면 한 행이다
(ERD v0.9의 부분 유니크 files_user_upload_sha_uq, origin = 'upload'에만 걸린다). LMS 첨부 자동
수집은 (user_id, external_ref) 유니크가 맡으므로 이 저장소는 origin = 'upload'만 본다.

라우터에는 저장소가 아니라 **공급자**를 준다. 파일을 Supabase Storage에 올리는 동안 요청 풀의
연결을 쥐고 있으면, 저장소가 느리거나 멈췄을 때 열 개뿐인 연결이 모두 묶여 다른 화면까지 멈춘다.
필요할 때 빌렸다 블록이 끝나면 돌려준다(app/agent_log.py의 로그 연결과 같은 방식).
"""

from collections.abc import AsyncIterator, Callable
from contextlib import AbstractAsyncContextManager, asynccontextmanager
from dataclasses import dataclass
from datetime import datetime
from typing import Annotated

from fastapi import Depends, Request
from psycopg import AsyncConnection

from app.errors import ApiError


@dataclass(frozen=True)
class StoredFile:
    id: str
    kind: str
    page_count: int | None


_SELECT = "select id::text as id, kind::text as kind, page_count from files"


class FileRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def existing(self, user_id: str, *, kind: str, sha256: str) -> StoredFile | None:
        """같은 파일을 이미 올렸으면 그 행. 아니면 None이다."""
        row = await (
            await self.conn.execute(
                _SELECT + " where user_id = %s and kind::text = %s and sha256 = %s"
                " and origin = 'upload'",
                (user_id, kind, sha256),
            )
        ).fetchone()
        return None if row is None else StoredFile(row["id"], row["kind"], row["page_count"])

    async def uploads_since(self, user_id: str, since: datetime) -> int:
        """하루 한도를 세는 값. 올려서 저장한 것만 센다(이미 있던 파일을 다시 올린 것은 안 센다)."""
        row = await (
            await self.conn.execute(
                "select count(*) as used from files"
                " where user_id = %s and origin = 'upload' and created_at >= %s",
                (user_id, since),
            )
        ).fetchone()
        assert row is not None
        return int(row["used"])

    async def add(
        self,
        user_id: str,
        *,
        file_id: str,
        kind: str,
        path: str,
        mime_type: str,
        size_bytes: int,
        page_count: int | None,
        sha256: str,
        original_name: str | None,
    ) -> str | None:
        """기록을 남긴다. 그새 같은 파일이 들어왔으면 None이다(부른 쪽이 기존 행을 돌려준다).

        id를 우리가 정해서 넣는다. 저장소 경로에 그 id가 들어가므로, 먼저 정해야 올릴 수 있다.
        """
        row = await (
            await self.conn.execute(
                "insert into files (id, user_id, kind, origin, storage_path, mime_type,"
                " size_bytes, page_count, sha256, original_name)"
                " values (%(id)s, %(uid)s, %(kind)s, 'upload', %(path)s, %(mime)s, %(size)s,"
                " %(pages)s, %(sha)s, %(name)s)"
                " on conflict (user_id, kind, sha256) where origin = 'upload' do nothing"
                " returning id::text as id",
                {
                    "id": file_id,
                    "uid": user_id,
                    "kind": kind,
                    "path": path,
                    "mime": mime_type,
                    "size": size_bytes,
                    "pages": page_count,
                    "sha": sha256,
                    "name": original_name,
                },
            )
        ).fetchone()
        return None if row is None else row["id"]


# 한 번 부를 때마다 연결을 빌려 저장소를 만들고, 블록이 끝나면 커밋하고 돌려준다
FileRepos = Callable[[], AbstractAsyncContextManager[FileRepository]]


def get_file_repos(request: Request) -> FileRepos:
    pool = getattr(request.app.state, "pool", None)
    if pool is None:
        raise ApiError(503, "DB_UNAVAILABLE", "데이터베이스에 연결할 수 없어요.")

    @asynccontextmanager
    async def connect() -> AsyncIterator[FileRepository]:
        async with pool.connection() as conn:  # 블록이 끝나면 커밋, 예외면 롤백
            yield FileRepository(conn)

    return connect


FileReposDep = Annotated[FileRepos, Depends(get_file_repos)]
```

```python
"""파일 업로드 (F-13, API 명세 6장).

지금은 포스터만 받는다. 계획서(F-14)·강의자료(F-15)는 그 기능과 함께 연다.

차례: 20MB까지 읽기 → 바이트로 형식·쪽수 보기 → 같은 파일인지 보기 → 하루 한도 보기 →
저장소에 올리기 → 기록 남기기.

올리기를 기록보다 먼저 한다. 거꾸로 하면 기록을 남긴 뒤 올리다 끊겼을 때, 다음에 같은 파일을 올려도
"이미 있어요"라며 저장소에 없는 파일을 가리킨다. 먼저 올리면 끊겨도 쓰이지 않는 파일만 남는다
(비공개 버킷이라 아무도 보지 못하고, 다시 올리면 제대로 기록된다).

DB 연결은 읽을 때와 쓸 때만 빌린다. 저장소에 올리는 동안 쥐고 있으면 저장소가 느릴 때 요청 풀이
묶여 다른 화면까지 멈춘다. 두 번으로 나눠도 중복은 부분 유니크가 막는다.
"""

import logging
from typing import Annotated
from uuid import uuid4

from fastapi import APIRouter, File, Form, Response, UploadFile

from app.auth import CurrentUserDep
from app.clock import NowDep
from app.errors import ApiError
from app.repositories.files import FileReposDep, StoredFile
from app.schemas.files import FileUploadResult
from app.uploads import (
    DAILY_UPLOAD_LIMIT,
    clean_name,
    day_reset,
    day_start,
    inspect_poster,
    read_upload,
    storage_path,
)
from app.uploads.storage import StorageDep, StorageError, SupabaseStorage

logger = logging.getLogger(__name__)
router = APIRouter(prefix="/files", tags=["업로드"])

POSTER = "poster"


@router.post(
    "",
    status_code=201,
    response_model=FileUploadResult,
    responses={200: {"model": FileUploadResult, "description": "이미 올린 파일(reused)"}},
)
async def upload_file(
    user: CurrentUserDep,
    repos: FileReposDep,
    storage: StorageDep,
    now: NowDep,
    response: Response,
    file: Annotated[UploadFile, File()],
    kind: Annotated[str, Form()],
) -> FileUploadResult:
    """포스터 파일을 저장소에 올리고 `file_id`를 준다. 같은 파일을 다시 올리면 200과 기존 id다."""
    if kind != POSTER:
        raise ApiError(
            422,
            "VALIDATION_FAILED",
            "입력값을 확인해 주세요.",
            {"fields": {"kind": "지금은 포스터만 올릴 수 있어요."}},
        )
    data = await read_upload(file)
    found = inspect_poster(data)

    async with repos() as repo:
        existing = await repo.existing(user.id, kind=kind, sha256=found.sha256)
        # 이미 올린 파일은 새로 저장하지 않으므로 하루 한도를 보지 않는다
        used = None if existing else await repo.uploads_since(user.id, day_start(now))
    if existing is not None:
        return _reused(existing, response)
    if used is not None and used >= DAILY_UPLOAD_LIMIT:
        raise ApiError(
            429,
            "DAILY_UPLOAD_LIMIT",
            f"오늘 올릴 수 있는 {DAILY_UPLOAD_LIMIT}개를 다 썼어요. 내일 다시 올려 주세요.",
            {"reset_at": day_reset(now).isoformat()},
        )

    file_id = str(uuid4())
    path = storage_path(user.id, kind, file_id, found.type.extension)
    try:
        await storage.upload(path, data, found.type.mime)
    except StorageError as exc:
        logger.warning("파일 저장소 업로드 실패: %s", exc)
        raise ApiError(
            502, "STORAGE_API_ERROR", "파일을 저장하지 못했어요. 잠시 후 다시 시도해 주세요."
        ) from exc

    async with repos() as repo:
        saved = await repo.add(
            user.id,
            file_id=file_id,
            kind=kind,
            path=path,
            mime_type=found.type.mime,
            size_bytes=len(data),
            page_count=found.page_count,
            sha256=found.sha256,
            original_name=clean_name(file.filename),
        )
        if saved is None:  # 올리는 사이에 같은 파일이 들어왔다. 방금 올린 것은 지운다
            winner = await repo.existing(user.id, kind=kind, sha256=found.sha256)
            assert winner is not None  # 충돌이 났다는 것은 그 행이 있다는 뜻이다
    if saved is None:
        await _discard(storage, path)
        return _reused(winner, response)
    return FileUploadResult(file_id=file_id, kind=kind, page_count=found.page_count)


def _reused(found: StoredFile, response: Response) -> FileUploadResult:
    response.status_code = 200
    return FileUploadResult(
        file_id=found.id,
        kind=found.kind,
        page_count=found.page_count,
        duplicate_of=found.id,
        reused=True,
    )


async def _discard(storage: SupabaseStorage, path: str) -> None:
    """되돌리기용 삭제. 여기서 실패해도 요청은 성공이라 기록만 남긴다."""
    try:
        await storage.remove(path)
    except StorageError as exc:
        logger.warning("쓰이지 않는 업로드 파일을 지우지 못했어요: %s", exc)
```

```python
    """UploadFile처럼 조금씩 읽히는 것."""

    def __init__(self, data: bytes) -> None:
        self.data = data
        self.at = 0
        self.read_bytes = 0

        end = len(self.data) if size < 0 else min(self.at + size, len(self.data))
        chunk = self.data[self.at : end]
```

```python
@asynccontextmanager
async def lifespan(app: FastAPI) -> AsyncIterator[None]:
    settings: Settings = app.state.settings
    # 로그인 설정이 틀렸으면 첫 요청을 기다리지 않고 시작할 때 알린다(.env를 고치면 서버를 다시 켠다)

        logger.warning("로그인 설정 확인: %s", problem)
    # 파일 업로드(F-13)는 Supabase Storage가 있어야 한다. 비었으면 첫 업로드에서 502가 난다
    if not settings.supabase_service_role_key or not settings.storage_base_url:

        )
    app.state.pool = app.state.log_pool = None
    if settings.database_url:
        app.state.pool, app.state.log_pool = create_pools(settings.database_url)
        await app.state.pool.open()
        await app.state.log_pool.open()
    yield
    # 돌던 준비하기를 잠깐 기다린다(못 끝내면 다음 요청이 멈춘 실행으로 보고 다시 만든다)
    await app.state.runner.drain(timeout=10)
    for pool in (app.state.pool, app.state.log_pool):
        if pool is not None:
            await pool.close()

        calendar.router,

        meta.router,
        events.router,
        opportunities.router,
        planner.router,
        runs.router,
```

```python
def pdf(pages: list[str | None], *, user_password: str | None = None) -> bytes:

_HWPX_NS = (
    'xmlns:hp="http://www.hancom.co.kr/hwpml/2011/paragraph" '
    'xmlns:hs="http://www.hancom.co.kr/hwpml/2011/section"'

def hwpx(*sections: str, encrypted: bool = False) -> bytes:
    """sections는 <hs:sec> 안쪽 XML이다. 순서대로 section0.xml, section1.xml …이 된다."""
    buffer = BytesIO()
    with zipfile.ZipFile(buffer, "w") as archive:
        archive.writestr("mimetype", "application/hwp+zip")
        manifest = "<odf:encryption-data/>" if encrypted else ""
        archive.writestr(
            "META-INF/manifest.xml",
            '<odf:manifest xmlns:odf="urn:oasis:names:tc:opendocument:xmlns:manifest:1.0">'
            f"{manifest}</odf:manifest>",
        )
        for no, body in enumerate(sections):
            archive.writestr(
                f"Contents/section{no}.xml",
                f'<?xml version="1.0" encoding="UTF-8"?><hs:sec {_HWPX_NS}>{body}</hs:sec>',
            )
    return buffer.getvalue()


def hp(text: str) -> str:
    return f"<hp:p><hp:run><hp:t>{text}</hp:t></hp:run></hp:p>"


def hp_cell(row: int, col: int, text: str, row_span: int = 1) -> str:
    return (
        f"<hp:tc><hp:subList>{hp(text)}</hp:subList>"
        f'<hp:cellAddr colAddr="{col}" rowAddr="{row}"/>'
        f'<hp:cellSpan colSpan="1" rowSpan="{row_span}"/></hp:tc>'
    )


# ---------- HWP 5.0 ----------

PARA_HEADER, PARA_TEXT, CTRL_HEADER, LIST_HEADER, TABLE = 66, 67, 71, 72, 77


def record(tag: int, level: int, payload: bytes) -> bytes:
    if len(payload) >= 0xFFF:
        return struct.pack("<II", tag | level << 10 | 0xFFF << 20, len(payload)) + payload
    return struct.pack("<I", tag | level << 10 | len(payload) << 20) + payload


def para(level: int, text: str) -> bytes:
    """문단 하나(PARA_HEADER + PARA_TEXT). 끝의 13은 문단 끝 문자다."""
    return record(PARA_HEADER, level, b"\x00" * 22) + record(
        PARA_TEXT, level + 1, text.encode("utf-16-le") + struct.pack("<H", 13)
    )


def table(
    level: int, cells: list[tuple[int, int, int, str]], *, caption: str | None = None
) -> bytes:
    """level 문단 안의 표. cells는 (행, 열, 행 병합, 글자). 캡션은 TABLE 레코드 앞에 온다."""
    control = struct.pack("<8H", 11, 0x6C74, 0x2062, 0, 0, 0, 0, 11)  # 표 확장 제어 문자
    out = record(PARA_HEADER, level, b"\x00" * 22)
    out += record(PARA_TEXT, level + 1, control + struct.pack("<H", 13))
    out += record(CTRL_HEADER, level + 1, int.from_bytes(b"tbl ", "big").to_bytes(4, "little"))
    if caption is not None:  # 캡션 리스트 헤더: 셀 헤더와 같은 수준이라 셀로 오인하기 쉽다
        out += record(LIST_HEADER, level + 2, struct.pack("<iI", 1, 0) + b"\x07\x00" * 8)
        out += para(level + 2, caption)
    out += record(TABLE, level + 2, b"\x00" * 18)
    for row, col, row_span, text in cells:
        header = struct.pack("<iIHHHH", 1, 0, col, row, 1, row_span) + b"\x00" * 18
        out += record(LIST_HEADER, level + 2, header) + para(level + 2, text)
    return out


class FakeOle:
    """olefile.OleFileIO 대역. 테스트에서는 OLE 파일을 새로 만들 수 없어 스트림 사전으로 흉내 낸다."""

    def __init__(self, streams: dict[str, bytes]) -> None:
        self.streams = streams

    def exists(self, name: str) -> bool:
        return name in self.streams

    def listdir(self) -> list[list[str]]:
        return [name.split("/") for name in self.streams]

    def openstream(self, name: str) -> BytesIO:
        return BytesIO(self.streams[name])


def hwp_ole(
    *sections: bytes, compressed: bool = True, distribution: bool = False, version: int = 0x05000300
) -> FakeOle:
    props = int(compressed) | int(distribution) << 2
    streams = {"FileHeader": SIGNATURE.ljust(32, b"\x00") + struct.pack("<II", version, props)}
    storage = "ViewText" if distribution else "BodyText"
    for no, section in enumerate(sections):
        if compressed:
            deflater = zlib.compressobj(wbits=-15)
            section = deflater.compress(section) + deflater.flush()
        if distribution:
            section = _encrypt_distribution(section)
        streams[f"{storage}/Section{no}"] = section
    return FakeOle(streams)


def _encrypt_distribution(body: bytes) -> bytes:
    """배포용 문서 만들기: 256바이트 머리에 AES 키를 숨기고 본문을 AES-128-ECB로 잠근다."""
    key = bytes(range(16))
    head = bytearray(256)
    head[:4] = (0x2A2A2A2A).to_bytes(4, "little")
    offset = 4 + (head[0] & 0xF)
    head[offset : offset + 16] = key
    _xor_keystream(head)  # 같은 씨앗의 XOR이라 한 번 더 하면 원래대로 돌아온다
    padder = padding.PKCS7(128).padder()
    encryptor = Cipher(algorithms.AES(key), modes.ECB()).encryptor()
    sealed = encryptor.update(padder.update(body) + padder.finalize()) + encryptor.finalize()
    return struct.pack("<I", 28 | 256 << 20) + bytes(head) + sealed


def _xor_keystream(data: bytearray) -> None:
    seed = int.from_bytes(data[:4], "little")
    value = count = 0
    for i in range(256):
        if count == 0:
            seed, value = _rand(seed)
            seed, number = _rand(seed)
            value &= 0xFF
            count = (number & 0xF) + 1
        if i >= 4:
            data[i] ^= value
        count -= 1
```

```ts
import { createBrowserSupabase } from "@/lib/supabase/client";
import type { Run } from "@/types/api";

// 실제 FastAPI 호출 (API 명세 1·2·13장). 화면은 이 파일을 직접 쓰지 않고 client.ts 함수만 쓴다.
// code는 서버가 준 13장 코드를 그대로 쓴다. 서버에 닿지 못한 경우만 프론트 코드를 쓴다:
// NETWORK_ERROR(서버 연결 실패), CONFIG_MISSING(API 주소 없음), NOT_READY(아직 API가 없는 기능),
// CALENDAR_CONNECT_FAILED(Google 화면을 열지 못함), RUN_TIMEOUT(실행 확인 시간 초과)
export class ApiError extends Error {
  constructor(
    public code: string,
    message: string,
    public status: number,
    public details?: Record<string, unknown>,
  ) {
    super(message);
  }
}

// 목 모드면 목데이터, 아니면 FastAPI (web/CLAUDE.md, 스킬 mock-to-api)
export const USE_MOCKS = process.env.NEXT_PUBLIC_USE_MOCKS === "true";

// 실제 모드에서 아직 API가 없는 기능은 목데이터 대신 빈 값이나 이 오류를 준다
export function notReady(message: string): Promise<never> {
  return Promise.reject(new ApiError("NOT_READY", message, 0));
}

const FALLBACK_MESSAGE = "요청을 처리하지 못했어요. 잠시 후 다시 시도해 주세요.";

// 응답을 받지 못했다. 기기가 오프라인이면 인터넷을, 아니면 서버(꺼짐·주소·CORS 설정)를 탓한다
function networkMessage(): string {
  return typeof navigator !== "undefined" && !navigator.onLine
    ? "인터넷에 연결되어 있지 않아요. 연결을 확인하고 다시 시도해 주세요."
    : "서버에 연결하지 못했어요. 잠시 후 다시 시도해 주세요.";
}

export async function apiFetch<T>(path: string, init: RequestInit = {}): Promise<T> {
  const base = process.env.NEXT_PUBLIC_API_BASE_URL;
  if (!base) {
    throw new ApiError("CONFIG_MISSING", "API 주소(NEXT_PUBLIC_API_BASE_URL)가 설정되지 않았어요.", 0);
  }
  const { data } = await createBrowserSupabase().auth.getSession();
  const token = data.session?.access_token;
  // 파일 업로드(multipart)는 Content-Type을 브라우저가 경계 문자열과 함께 붙인다. 우리가 넣으면 깨진다
  const isForm = init.body instanceof FormData;
  let response: Response;
  try {
    response = await fetch(`${base}${path}`, {
      ...init,
      headers: {
        ...(isForm ? {} : { "Content-Type": "application/json" }),
        ...(token ? { Authorization: `Bearer ${token}` } : {}),
        ...init.headers,
      },
    });
  } catch {
    throw new ApiError("NETWORK_ERROR", networkMessage(), 0);
  }
  // 로그인 전이면 로그인 화면으로, 세션이 만료됐으면 이유와 함께 보낸다.
  // 페이지가 바뀌므로 화면에 오류를 넘기지 않고 기다리게 둔다
  if (response.status === 401 && typeof window !== "undefined") {
    window.location.assign(token ? "/login?error=session" : "/login");
    return new Promise<T>(() => {});
  }
  if (!response.ok) {
    const body = await response.json().catch(() => null);
    throw new ApiError(
      body?.error?.code ?? "UNKNOWN",
      body?.error?.message ?? FALLBACK_MESSAGE,
      response.status,
      body?.error?.details,
    );
  }
  return (response.status === 204 ? undefined : await response.json()) as T;
}

// 화면에 띄울 오류 문구. 서버(13장)와 프론트 코드가 준 문구는 그대로 쓰고,
// 서버 내부 오류(5xx)·알 수 없는 오류·목 모드 오류는 화면이 준 문구를 쓴다
export function errorMessage(error: unknown, fallback: string): string {
  if (!(error instanceof ApiError) || error.status >= 500 || error.code === "UNKNOWN") return fallback;
  return error.message;
}

const HANGUL = /[가-힣]/;

// 422 VALIDATION_FAILED의 details.fields를 항목별 문구로. 서버가 준 한국어 문구는 그대로 쓰고,
// 요청 형식 검사에서 온 영어 문구는 "값을 확인해 주세요."로 바꾼다
export function fieldErrors(error: unknown): Record<string, string> {
  if (!(error instanceof ApiError) || error.code !== "VALIDATION_FAILED") return {};
  const fields = error.details?.fields;
  if (!fields || typeof fields !== "object") return {};
  return Object.fromEntries(
    Object.entries(fields as Record<string, unknown>).map(([key, message]) => [
      key,
      typeof message === "string" && HANGUL.test(message) ? message : "값을 확인해 주세요.",
    ]),
  );
}

// 403 CONSENT_REQUIRED의 details.consent: terms_privacy(필수 동의 전) · income_info(소득 선택 동의 전)
export function consentRequired(error: unknown): "terms_privacy" | "income_info" | null {
  if (!(error instanceof ApiError) || error.code !== "CONSENT_REQUIRED") return null;
  const consent = error.details?.consent;
  return consent === "terms_privacy" || consent === "income_info" ? consent : null;
}

// 202로 받은 run_id를 1.5초 간격으로 최대 60초까지 확인한다 (API 2장)
export async function waitForRun<R>(runId: string, onProgress?: (run: Run<R>) => void): Promise<Run<R>> {
  const startedAt = Date.now();
  while (Date.now() - startedAt < 60_000) {
    const run = await apiFetch<Run<R>>(`/runs/${runId}`);
    onProgress?.(run);
    if (run.status === "succeeded" || run.status === "failed") return run;
    await new Promise((resolve) => setTimeout(resolve, 1_500));
  }
  throw new ApiError("RUN_TIMEOUT", "백그라운드에서 계속 처리하고 있어요. 끝나면 알림으로 알려드릴게요.", 0);
}
```

```ts
const allowedExtensions = /\.(jpe?g|png|webp|pdf)$/i;
const heicExtension = /\.(heic|heif)$/i;

async function getPdfPageCount(file: File): Promise<number> {
  const bytes = new Uint8Array(await file.arrayBuffer());
  const source = new TextDecoder("latin1").decode(bytes);
  return source.match(/\/Type\s*\/Page\b/g)?.length ?? 0;
}

// 서버(POST /files)와 같은 기준으로 먼저 거른다. 20MB 파일을 올렸다가 413을 받지 않게 한다
export async function validatePosterFile(file: File): Promise<string | null> {
  if (heicExtension.test(file.name)) {
    return "아이폰 사진 형식(HEIC)은 아직 올릴 수 없어요. 사진을 JPG로 바꿔서 올려 주세요.";
  }
  if (!allowedExtensions.test(file.name)) {
    return "JPG·PNG·WEBP 사진이나 2쪽 이하 PDF만 올릴 수 있어요.";
  }
  if (file.size > 20 * 1024 * 1024) {
    return "파일이 20MB를 넘어요. 더 작은 파일을 올려 주세요.";
  }
  const isPdf = file.type === "application/pdf" || /\.pdf$/i.test(file.name);
  if (isPdf && (await getPdfPageCount(file)) > 2) {
    return "PDF는 2쪽까지만 올릴 수 있어요. 포스터가 있는 쪽만 남겨서 올려 주세요.";
  }
  return null;
}
```

```tsx
const READ_FAILED = "글자를 읽지 못했어요. 포스터 전체가 보이게 밝은 곳에서 다시 찍어 주세요";
const UPLOAD_FAILED = "파일을 올리지 못했어요. 잠시 후 다시 시도해 주세요";
// 실제 모드는 아직 올려 두기만 한다. 올리기 전에 미리 알려 준다(올린 뒤에 말하면 속은 느낌이 든다)
const SUBTITLE = POSTER_EXTRACT_READY
  ? "포스터를 올리면 AI가 제목, 마감일, 지원 조건을 자동으로 정리해요."

const wait = (milliseconds: number) =>
  new Promise((resolve) => setTimeout(resolve, milliseconds));

export default function PosterUpload({ navigate }: PosterUploadProps) {
  const fileInputRef = useRef<HTMLInputElement>(null);
  const cameraInputRef = useRef<HTMLInputElement>(null);
  const objectUrlRef = useRef<string | null>(null);
  const scenario = useAsyncData(getPosterPreviewState, []);
  const [status, setStatus] = useState<UploadStatus>("idle");
  const [steps, setSteps] = useState<StepStatus[]>(["idle", "idle", "idle"]);
  const [result, setResult] = useState<PosterExtractResult | null>(null);
  const [draft, setDraft] = useState<PosterExtractResult["draft"] | null>(null);
  const [previewUrl, setPreviewUrl] = useState("");
  const [fileName, setFileName] = useState("");
  const [isPdf, setIsPdf] = useState(false);
  const [registering, setRegistering] = useState(false);
  const [toast, setToast] = useState("");
  const [failureMessage, setFailureMessage] = useState(READ_FAILED);
  const [failureBadge, setFailureBadge] = useState("분석 실패");

  const fail = (message: string, badge: string) => {
    setFailureMessage(message);
    setFailureBadge(badge);
    setStatus("failure");
  };

  useEffect(() => {
    if (!scenario.data) return;
    if (scenario.data.status === "duplicate") {
      setStatus("duplicate");
      setResult(scenario.data.result);
      setDraft(scenario.data.result.draft);
      setPreviewUrl("/assets/mock-opportunity-poster.svg");
    } else {
      setStatus(scenario.data.status);
    }
  }, [scenario.data]);

  useEffect(
    () => () => {
      if (objectUrlRef.current) URL.revokeObjectURL(objectUrlRef.current);
    },
    [],
  );

  const reset = () => {
    if (objectUrlRef.current) URL.revokeObjectURL(objectUrlRef.current);
    objectUrlRef.current = null;
    setStatus("idle");
    setSteps(["idle", "idle", "idle"]);
    setResult(null);
    setDraft(null);
    setPreviewUrl("");
    setFileName("");
    setIsPdf(false);
    setFailureMessage(READ_FAILED);
    setFailureBadge("분석 실패");
  };

  const runSteps = async () => {
    for (let index = 0; index < 3; index += 1) {
      setSteps((current) => current.map((step, at) => (
        at < index ? "done" : at === index ? "running" : step
      )));
      await wait(600);
      setSteps((current) => current.map((step, at) => (at === index ? "done" : step)));
    }
  };

  const analyze = async (file?: File) => {
    if (!file) return;
    const validationError = await validatePosterFile(file);
    if (validationError) {
      fail(validationError, "올릴 수 없는 파일");
      return;
    }

    const pdf = file.type === "application/pdf" || /\.pdf$/i.test(file.name);
    setIsPdf(pdf);
    setFileName(file.name);
    if (!pdf) {
      if (objectUrlRef.current) URL.revokeObjectURL(objectUrlRef.current);
      objectUrlRef.current = URL.createObjectURL(file);
      setPreviewUrl(objectUrlRef.current);
    }

    setStatus("uploading");
    let fileId: string;
    try {
      fileId = (await uploadPosterFile(file)).file_id;
    } catch (error) {
      if (error instanceof ApiError && error.code === "DAILY_UPLOAD_LIMIT") {
        setStatus("limit");
        return;
      }
      fail(errorMessage(error, UPLOAD_FAILED), "올리지 못했어요");
      return;
    }
    if (!POSTER_EXTRACT_READY) {
      setStatus("stored");
      return;
    }

    setStatus("analyzing");
    const extraction = extractPoster(fileId)
      .then((value) => ({ value, error: null }))
      .catch((error: unknown) => ({ value: null, error }));
    await runSteps();

    const extracted = await extraction;
    if (extracted.error) {
      fail(READ_FAILED, "분석 실패");
      return;
    }
    if (!extracted.value) return;
    setResult(extracted.value);
    setDraft(extracted.value.draft);
    setStatus(extracted.value.duplicate_candidate ? "duplicate" : "complete");
  };

  const register = async () => {
    if (!draft) return;
    setRegistering(true);
    const detail = await registerPosterOpportunity(draft);
    setToast("공고를 등록했어요");
    setTimeout(() => navigate({ name: "opportunity", id: detail.id }), 700);
  };

  const pickAgain = () => {
    reset();
    setTimeout(() => fileInputRef.current?.click());
  };

  if (scenario.loading) {
    return (
      <>
        <Skeleton className="h-[70px] w-[430px]" />
        <Skeleton className="h-[310px] w-full rounded-[18px]" />
      </>
    );
  }

  const preview = (
    <PosterSourcePreview previewUrl={previewUrl} fileName={fileName} isPdf={isPdf} />
  );

  return (
    <>
      <Header title="포스터로 공고 등록" subtitle={SUBTITLE} />
      <input
        ref={fileInputRef}
        type="file"
        accept=".jpg,.jpeg,.png,.webp,.pdf"
        className="hidden"
        onChange={(event) => {
          const picked = event.target.files?.[0];
          event.target.value = "";  // 같은 파일을 다시 골라도 change가 뜨게 비운다
          analyze(picked);
        }}
      />
      <input
        ref={cameraInputRef}
        type="file"
        accept="image/jpeg,image/png,image/webp"
        capture="environment"
        className="hidden"
        onChange={(event) => {
          const picked = event.target.files?.[0];
          event.target.value = "";
          analyze(picked);
        }}
      />
      {status === "idle" && (
        <PosterDropzone
          onDropFile={analyze}
          onChooseFile={() => fileInputRef.current?.click()}
          onUseCamera={() => cameraInputRef.current?.click()}
        />
      )}
      {status === "uploading" && (
        <section className="flex min-h-[310px] flex-col items-center justify-center gap-3 rounded-[18px] border border-[#e5e7eb] bg-white p-8 text-center" role="status">
          <p className="text-[18px] font-semibold">포스터를 올리고 있어요</p>
          <p className="text-[13px] text-[#667085]">{fileName}</p>
        </section>
      )}
      {status === "analyzing" && (
        <div className="grid grid-cols-[1fr_1fr] gap-5 max-[900px]:grid-cols-1">
          {preview}
          <PosterAnalyzing steps={steps} />
        </div>
      )}
      {status === "stored" && (
        <div className="grid grid-cols-[1fr_1fr] gap-5 max-[900px]:grid-cols-1">
          {preview}
          <PosterStored onHome={() => navigate({ name: "home" })} onPickAgain={pickAgain} />
        </div>
      )}
      {status === "complete" && result && draft && (
        <div className="grid grid-cols-[0.85fr_1.15fr] gap-5 max-[900px]:grid-cols-1">
          {preview}
          <PosterExtractForm
            result={result}
            draft={draft}
            registering={registering}
            onDraftChange={setDraft}
            onRegister={register}
          />
        </div>
      )}
      {status === "duplicate" && result?.duplicate_candidate && (
        <div className="grid grid-cols-[1fr_1fr] gap-5 max-[900px]:grid-cols-1">
          {preview}
          <section className="flex min-h-[300px] flex-col items-center justify-center rounded-[18px] border border-[#e5e7eb] bg-white p-8 text-center">
            <Badge tone="yellow">중복 공고</Badge>
            <h2 className="mt-4 text-[22px] font-bold">이미 등록된 공고예요</h2>
            <p className="mt-2 text-[14px] text-[#667085]">{result.duplicate_candidate.title}</p>
            <div className="mt-5">
              <Button onClick={() => navigate({ name: "opportunity", id: result.duplicate_candidate!.opportunity_id })}>
                기존 공고 보기
              </Button>
            </div>
          </section>
        </div>
      )}
      {(status === "failure" || status === "limit") && (
        <section className="flex min-h-[310px] flex-col items-center justify-center rounded-[18px] border border-[#e5e7eb] bg-white p-8 text-center">
          <Badge tone="red">{status === "limit" ? "업로드 한도 초과" : failureBadge}</Badge>
          <h2 className="mt-4 text-[20px] font-bold">
            {status === "limit"
              ? "오늘은 더 올릴 수 없어요. 내일 0시부터 다시 올릴 수 있어요"
              : failureMessage}
          </h2>
          <div className="mt-5">
            {status === "failure" ? (
              <Button onClick={pickAgain}>다시 올리기</Button>
            ) : (
              <Button onClick={() => navigate({ name: "home" })}>홈으로</Button>
            )}
          </div>
        </section>
      )}
      {toast && (
        <div className="fixed bottom-6 left-1/2 z-[90] -translate-x-1/2 rounded-[10px] bg-[#181a20] px-4 py-3 text-[13px] font-semibold text-white">
          {toast}
        </div>
      )}
    </>
  );
}
```
