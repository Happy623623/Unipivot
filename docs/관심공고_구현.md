# 관심 공고 — 공고를 관심으로 담거나 숨기고, 홈에서 추천 공고·관심·숨김 탭으로 나눠 본다

> 📝 기준: PRD v0.9 F-45(이 PR에서 더함)·F-40·F-41·F-33 · API 명세 v0.4 5장·10장 · ERD v0.9 · 2026-10-13
>
> 함께 보는 파일: `시군구선택_구현.md`(먼저 합쳤다, main c6cdc14), `공고API연결_구현.md`(홈 피드 호출 방식)

10/13에 청년정책 411건을 넣고 확인하던 중에 "관심 없는 공고와 관심 있는 공고를 따로 모아 두는 곳이 있으면 좋겠다"는 의견이 나왔다. 그 자리에서 네 가지를 골랐다(10/13 결정).
- **숨긴 공고:** 추천 피드, 홈 요약 숫자, 공고 알림에서 뺀다. 상세는 그대로 열린다.
- **모아 보는 곳:** 홈 목록 위에 추천 공고·관심·숨김 탭을 둔다.
- **버튼 자리:** 카드와 공고 상세 양쪽에 둔다.
- **우선순위:** 지금 만든다. PRD에 F-45(P1)로 더한다.

화면 이름은 "☆ 관심"과 "숨기기"다. 숨긴 공고에서는 "숨기기"가 "숨김 풀기"로 바뀐다. 저장 값은 `interested`(관심)와 `not_interested`(관심 없음)이다.

**규모와 확인:**
- 새 파일 10개, 바꾸는 파일 15개다.
  - 새 파일: 마이그레이션 1개, api 테스트 2개, web 7개
  - 바꾸는 파일: api 3개, api 테스트 2개, web 10개
- DB 변경이 있다. 새 테이블 `opportunity_marks` 하나를 만든다. 합친 뒤 `npx supabase db push`가 필요하다.
- API 변경:
  - 엔드포인트 2개를 더한다: `PUT`·`DELETE /opportunities/{id}/mark`
  - 피드 파라미터 `include_not_interested`를 더한다.
  - 응답 필드 `my_mark`를 피드 항목과 상세에 더한다.
- api 테스트를 15개 더했다. Linux에서 `498 passed, 51 skipped`이고, DB를 붙이면 `549 passed`다. web `typecheck`·`build`도 통과한다.
- 새 동작을 하나씩 되돌려 테스트가 잡는지 봤다(아래 "확인한 것"). 모두 잡혔다.
  - api: 28가지
  - web: 28가지. 바꿀 때마다 실제 모드로 다시 빌드해 E2E를 돌렸다.
  - 목 모드: 8가지
- 실제 모드(웹·API·청년정책 410건)로 49단계를 확인했다. 목 모드로는 15단계를 확인했다.
- 처음 CI에서 DB 정렬 규칙 차이로 테스트 하나가 실패해 그 테스트를 고쳤다(아래 "확인한 것"의 CI 정렬 규칙).
- 따로 띄운 검토 에이전트가 두 번 봤다. 첫 검토에서 목 모드 표시 저장이 끝나지 않는 버그 등을 찾았고, 지적은 모두 고쳤다. 고친 뒤 다시 본 검토에서는 막을 문제가 없었고, 제안 5건도 고쳤다(아래 "검토에서 고친 것").

1. **마이그레이션:** 레포 루트에서 `npx supabase db push --dry-run`을 돌려 `20261013000000_opportunity_marks.sql` 하나만 나오는지 본다. 그다음 `npx supabase db push`를 돌린다. DB 비밀번호를 물으면 터미널에 직접 입력한다(채팅에 붙이지 않는다).
2. **서버:** `api`는 `uv run uvicorn app.main:app --reload`, `web`은 `npm run dev`로 띄운다(터미널 따로).
3. **홈:**

## 남은 것

- **알림(F-33):** 아직 만들지 않았다. 알림 배치를 만들 때 반영한다: 숨긴 공고의 공고 알림을 만들지 않고, 보내기 전에 다시 본다(API 명세 10장, ERD 5장에 적었다).
- **관심 공고를 더 쓸지:** 관심 공고만 마감 알림을 받거나 추천 순서에 반영하는 일은 정하지 않았다. 지금 관심은 모아 보기만 한다.
- **탭 숫자:** 관심·숨김 숫자는 지금 고른 카테고리 안에서 센다. 전체 숫자를 늘 보이게 하려면 서버가 표시 개수를 따로 줘야 한다(응답 필드부터 명세에 더한다).
- **동의 전 요청:** 피드·상세처럼 표시 API도 동의 전(CONSENT_REQUIRED)을 막지 않는다. 이 PR 전부터 그렇다. 온보딩이 동의를 먼저 받는다.
- **탈퇴(DELETE /me):** 아직 없다. profiles를 지우면 표시도 같이 지워지는 것만 확인했다.

-- 값: interested 관심, not_interested 관심 없음. 표시가 없으면 행이 없다.
-- 관심 없음 공고는 피드·홈 요약 숫자·알림(새 공고·마감 임박)에서 뺀다. 값 목록은 enum 대신 text + check(ERD 6장).

create table opportunity_marks (
  user_id         uuid not null references profiles(id) on delete cascade,
  opportunity_id  uuid not null references opportunities(id) on delete cascade,
  mark            text not null,
  marked_at       timestamptz not null default now(),   -- 표시가 바뀐 시각. 같은 표시를 다시 고르면 그대로
  primary key (user_id, opportunity_id),
  constraint opportunity_marks_mark_chk check (mark in ('interested','not_interested'))
);

-- user_id는 기본 키 앞쪽 열이라 따로 인덱스가 필요 없다
create index opportunity_marks_opportunity_id_idx on opportunity_marks (opportunity_id);

-- RLS: 본인 행만 읽기(쓰기는 백엔드). ERD 8장
alter table opportunity_marks enable row level security;
create policy opportunity_marks_select_own on opportunity_marks for select using (user_id = (select auth.uid()));

    " and (deadline_at at time zone 'Asia/Seoul')::date - %(today)s::date"
    " between 0 and %(soon)s) as deadline_soon"
    " from base"
)
# 요건 행을 판정 엔진 입력 모양(JSON 배열)으로. 공고 행과 같은 문장에서 읽어야 요건과 요건 버전이
# 같은 시점의 값이다
_REQUIREMENTS_JSON = (
    "coalesce((select jsonb_agg(jsonb_build_object("
    "'id', r.id, 'clause_no', r.clause_no, 'field', r.field, 'operator', r.operator,"
    " 'value', r.value, 'basis', r.basis, 'is_ambiguous', r.is_ambiguous,"
    " 'evidence_text', r.evidence_text) order by r.clause_no, r.created_at, r.id)"
    " from requirements r where r.opportunity_id = o.id), '[]'::jsonb)"
)
_PREP_JOIN = " left join prep_plans p on p.user_id = %(uid)s and p.opportunity_id = o.id"
# 상세를 열 수 있는 공고: 준비한 공고는 상태와 상관없이 본인에게, 그 밖은 활성·마감 공고 중 공개 범위 안
_OPENABLE = " (p.id is not null or (o.status in ('active', 'expired') and" + _VISIBLE + "))"
# 상세 한 건: 공고·요건·서류(내 준비 할 일)·첨부·처리 과정·캘린더를 한 문장으로 읽는다
_DETAIL = (
    "select o.id, o.title, o.organizer, o.category::text as category,"
    " o.source_type::text as source_type, o.status::text as status, o.original_url,"
    " o.easy_summary, o.apply_start_at, o.deadline_at, o.needs_review, o.review_reasons,"
    " o.extraction_confidence, o.eligibility_basis_date, o.requirements_version,"
    " o.extraction_run_id, coalesce(o.uploaded_by = %(uid)s, false) as uploaded_by_me,"
    # 과목 이름은 수강 중인지 따지지 않고 읽는다. 준비한 과목 공지는 수강을 끝낸 뒤에도 보인다
    " (select lc.name from lms_courses lc where lc.user_id = %(uid)s"
    " and lc.canvas_course_id = o.visible_canvas_course_id) as course_name,"
    " p.id as prep_plan_id, p.agent_run_id as prepare_run_id,"
    " exists(select 1 from opportunity_reports rp where rp.opportunity_id = o.id"
    " and rp.reporter_id = %(uid)s) as reported_by_me,"
    " " + _REQUIREMENTS_JSON + " as requirements,"
    " coalesce((select jsonb_agg(jsonb_build_object('id', d.id, 'name', d.name,"
    " 'issuer', d.issuer, 'how_to', d.how_to, 'lead_days', d.lead_days,"
    " 'effort_minutes', d.effort_minutes, 'form_url', d.form_url,"
    " 'is_required', coalesce(d.is_required, true), 'task_id', t.id, 'is_done', t.is_done)"
    " order by coalesce(d.is_required, true) desc, d.name, d.id)"
    " from opportunity_documents d left join planner_tasks t"
    " on t.prep_plan_id = p.id and t.document_id = d.id"
    " where d.opportunity_id = o.id), '[]'::jsonb) as documents,"
    " (select count(*) from planner_tasks t where t.prep_plan_id = p.id) as tasks_total,"
    " (select count(*) from planner_tasks t where t.prep_plan_id = p.id and t.is_done)"
    " as tasks_done,"
    " coalesce((select jsonb_agg(jsonb_build_object('id', ev.id, 'provider', ev.provider)"
    " order by ev.starts_at, ev.id) from calendar_events ev"
    " where ev.user_id = %(uid)s and ev.opportunity_id = o.id), '[]'::jsonb) as calendar_events,"
    " coalesce((select jsonb_agg(jsonb_build_object('id', a.id, 'seq', a.seq,"
    " 'file_name', a.file_name, 'source_url', a.source_url, 'method', a.extract_method,"
    " 'error', a.extract_error) order by a.seq, a.id)"
    " from opportunity_attachments a where a.opportunity_id = o.id), '[]'::jsonb) as attachments,"
    # 처리 과정은 추출 실행의 도구 호출이다. 고른 이유, 읽은 곳(첨부 번호, 실제로 읽기 시작한 위치.
    # 오류면 요청한 위치), 오류였는지, 제출을 받았는지, 상한에 닿아 코드가 시킨 제출인지만 꺼낸다.
    # 읽은 글자는 꺼내지 않는다
    " coalesce((select jsonb_agg(jsonb_build_object('seq', s.seq, 'tool', s.tool_name,"
    " 'status', s.status, 'latency_ms', s.latency_ms, 'reason', s.input->>'reason',"
    " 'attachment_no', s.input->'attachment_no',"
    " 'offset', coalesce(s.output->'offset', s.input->'offset'),"
    " 'start_page', s.input->'start_page', 'pages', s.output->'pages',"
    " 'error', s.output->>'error' is not null, 'accepted', s.output->'accepted',"
    " 'forced', s.output->'forced')"
    " order by s.seq, s.id)"
    " from tool_calls s where s.run_id = o.extraction_run_id), '[]'::jsonb) as steps,"
    " (select m.mark from opportunity_marks m where m.user_id = %(uid)s"
    " and m.opportunity_id = o.id) as my_mark"
    " from opportunities o" + _COURSE_JOIN + _PREP_JOIN + " where o.id = %(oid)s and" + _OPENABLE
)
# 관심 표시(F-45). 다른 표시로 바꾸면 시각을 새로 쓰고, 같은 표시를 다시 고르면 처음 시각을 둔다
_MARK_OPENABLE = (
    "select 1 from opportunities o"
    + _COURSE_JOIN
    + _PREP_JOIN
    + " where o.id = %(oid)s and"
    + _OPENABLE
)
_MARK_UPSERT = (
    "insert into opportunity_marks (user_id, opportunity_id, mark, marked_at)"
    " values (%(uid)s, %(oid)s, %(mark)s, %(now)s)"
    " on conflict (user_id, opportunity_id) do update set mark = excluded.mark,"
    " marked_at = case when opportunity_marks.mark = excluded.mark"
    " then opportunity_marks.marked_at else excluded.marked_at end"
    " returning marked_at"
)
# 조회 기록. 처음 연 시각은 그대로 두고 마지막 시각은 늦은 쪽을 남긴다. 시각을 고정한 실행(평가
# 러너·테스트)이 지난 시각으로 열어도 기록이 거꾸로 가지 않는다
_VIEW = (
    "insert into opportunity_views (user_id, opportunity_id, first_viewed_at, last_viewed_at)"
    " values (%s, %s, %s, %s) on conflict (user_id, opportunity_id) do update set"
    " last_viewed_at = greatest(opportunity_views.last_viewed_at, excluded.last_viewed_at)"
)


def _stale_sql(scope: str) -> str:
    """다시 판정할 공고와 그 요건."""
    return (
        "select o.id, o.requirements_version, o.eligibility_basis_date, o.deadline_at,"
        " o.apply_start_at, o.source_type::text as source_type,"
        " e.user_id is not null as had_result, e.status::text as old_status,"
        " e.missing_fields as old_missing, " + _REQUIREMENTS_JSON + " as requirements"
        " from opportunities o"
        + _COURSE_JOIN
        + _RESULT_JOIN
        + " where"
        + scope
        + " and"
        + _VISIBLE
        + " and o.extraction_run_id is not null"
        " and (%(force)s or e.user_id is null or e.evaluated_at is null"
        " or e.requirements_version <> o.requirements_version"
        " or e.engine_version <> %(engine)s"
        # 날이 바뀌면 다시: 기준일이 "오늘"인 공고(청년정책 포함), 엔진 오류로 판정하지 못한 공고(오류를
        # 고쳤을 수 있다)
        " or (((o.eligibility_basis_date is null and (o.deadline_at is null"
        " or (o.source_type = 'youth_policy' and o.deadline_at >= %(now)s)))"
        " or e.reason_text = %(engine_error)s)"
        " and (e.evaluated_at at time zone 'Asia/Seoul')::date < %(today)s))"
    )


def _feed_sql(where: str, outer: str, order: str) -> str:
    return (
        "with feed as (select o.id, o.title, o.organizer, o.category::text as category,"
        " o.source_type::text as source_type, o.deadline_at, o.created_at, o.easy_summary,"
        " o.needs_review, coalesce(o.uploaded_by = %(uid)s, false) as uploaded_by_me,"
        " c.name as course_name,"
        " exists(select 1 from prep_plans p where p.user_id = %(uid)s and p.opportunity_id = o.id)"
        " as prepared,"
        " coalesce(o.created_at >= %(new_since)s, false) and not exists(select 1"
        " from opportunity_views v where v.user_id = %(uid)s and v.opportunity_id = o.id) as is_new,"
        " " + _JUDGED + " as judged,"
        " case when " + _JUDGED + " then e.status::text else 'undetermined' end as eff_status,"
        " case when " + _JUDGED + " then coalesce(e.missing_fields, '{}') else '{}' end"
        " as eff_missing,"
        " e.reason_text, m.mark as my_mark"
        " from opportunities o" + _COURSE_JOIN + _RESULT_JOIN + _MARK_JOIN + " where" + where + ")"
        " select * from feed" + outer + " order by " + order + " limit %(limit)s"
    )


@dataclass(frozen=True)
class Cursor:
    scope: str  # 목록 조건(정렬·필터)의 지문. 조건이 다른 목록에는 쓸 수 없다
    # 마지막 행의 정렬 값(deadline: 마감 시각, recent: 등록 시각). 없을 수 있다
    value: datetime | None
    id: str


@dataclass(frozen=True)
class FeedQuery:
    eligibility: frozenset[str] | None = None  # None이면 전체
    categories: tuple[str, ...] | None = None
    source_types: tuple[str, ...] | None = None
    sort: Sort = "deadline"
    include_expired: bool = False
    include_not_interested: bool = False  # 관심 없음 공고도 준다(F-45)
    limit: int = 20
    cursor: Cursor | None = None

    def scope(self) -> str:
        """cursor를 묶는 목록 조건의 지문. 정렬이나 필터를 바꾸면 목록을 처음부터 다시 부른다.

        같은 목록이면 지문도 같다: 값의 순서는 보지 않고, 모든 값을 고른 필터는 필터 없음과 같다.
        """
        parts = (
            self.sort,
            _filter_key(self.eligibility, ELIGIBILITY_STATUSES),
            _filter_key(self.categories, CATEGORIES),
            _filter_key(self.source_types, SOURCE_TYPES),
            str(self.include_expired),
            str(self.include_not_interested),
        )
        return hashlib.sha256("|".join(parts).encode()).hexdigest()[:16]


def _filter_key(values: Collection[str] | None, everything: Collection[str]) -> str:
    chosen = set(values or ())
    return "" if chosen >= set(everything) else ",".join(sorted(chosen))


@dataclass(frozen=True)
class FeedPage:
    items: list[OpportunityItem]
    next_cursor: str | None


@dataclass(frozen=True)
class Refresh:
    judged: int  # 다시 계산한 공고 수
    changed: int  # 라벨이 바뀐 공고 수(전에 판정이 있던 공고만 센다)


def display_status(status: str, missing_fields: Sequence[str]) -> str:
    """화면 라벨 4종. 판정 불가는 입력하면 바뀔 수 있으면 정보 필요, 아니면 원문 확인 필요다."""
    if status == "undetermined":
        return "missing_info" if missing_fields else "needs_review"
    return status


def encode_cursor(cursor: Cursor) -> str:
    data = {
        "q": cursor.scope,
        "v": cursor.value.isoformat() if cursor.value else None,
        "id": cursor.id,
    }
    raw = json.dumps(data, separators=(",", ":")).encode()
    return base64.urlsafe_b64encode(raw).decode().rstrip("=")


def decode_cursor(text: str) -> Cursor:
    """next_cursor로 준 값을 되돌린다. 모양이 틀리면 ValueError."""
    try:
        data = json.loads(base64.urlsafe_b64decode(text + "=" * (-len(text) % 4)))
        scope, value, ident = data["q"], data["v"], data["id"]
        if not isinstance(scope, str) or not isinstance(ident, str):
            raise ValueError(scope)
        moment = None if value is None else datetime.fromisoformat(value)
        if moment is not None and moment.tzinfo is None:
            raise ValueError(value)
        return Cursor(scope=scope, value=moment, id=str(uuid.UUID(ident)))
    except (binascii.Error, ValueError, KeyError, TypeError, UnicodeDecodeError) as exc:
        raise ValueError("잘못된 cursor") from exc


class OpportunityRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def refresh_judgments(
        self,
        user_id: str,
        *,
        now: datetime,
        force: bool = False,
        include_expired: bool = False,
        display_name: str | None = None,
    ) -> Refresh:
        """피드에 나올 공고(include_expired면 지난 공고까지)의 낡은 판정을 다시 계산해 저장한다.

        force면 그 공고를 모두 다시 판정하고 나머지 공고의 판정은 지운다.
        프로필 행이 없으면(첫 요청이 피드) display_name과 함께 만든다.
        """
        profile = Profile.from_row(await self._lock_profile(user_id, display_name))
        today = now.astimezone(KST).date()
        stale = await (
            await self.conn.execute(
                _stale_sql(_WITH_EXPIRED if include_expired else _ACTIVE),
                {
                    "uid": user_id,
                    "now": now,
                    "force": force,
                    "engine": ENGINE_VERSION,
                    "engine_error": ENGINE_ERROR_SUMMARY,
                    "today": today,
                },
            )
        ).fetchall()
        payload: list[dict[str, Any]] = []
        changed = 0
        if stale:
            departments = await self._departments()
            for item in stale:
                judged = _judge(item, profile, departments, today)
                payload.append(_payload(item, judged.stored))
                old = display_status(item["old_status"] or "", item["old_missing"] or ())
                if item["had_result"] and old != judged.label:
                    changed += 1
        await self._upsert(user_id, payload, now)
        if force:  # 다시 판정하지 않은 공고(마감·숨김·안 보임)의 판정은 지운다
            await self.conn.execute(
                "delete from eligibility_results"
                " where user_id = %s and opportunity_id <> all(%s::uuid[])",
                (user_id, [item["opportunity_id"] for item in payload]),
            )
        else:  # 요건 추출에 실패한 공고의 옛 판정은 지운다(판정하지 않는다)
            await self.conn.execute(
                "delete from eligibility_results e using opportunities o"
                " where e.user_id = %s and e.opportunity_id = o.id and o.extraction_run_id is null",
                (user_id,),
            )
        return Refresh(judged=len(payload), changed=changed)

    async def detail(
        self,
        user_id: str,
        opportunity_id: str,
        *,
        now: datetime,
        display_name: str | None = None,
    ) -> OpportunityDetail | None:
        """공고 상세(S1-6). 이 사용자에게 보이지 않는 공고면 None이다.

        피드와 같은 잠금 아래에서 그 공고를 다시 판정해 저장하고, 조회 기록을 남긴다(is_new가 꺼진다).
        """
        profile_row = await self._lock_profile(user_id, display_name)
        row = await (
            await self.conn.execute(_DETAIL, {"uid": user_id, "oid": opportunity_id})
        ).fetchone()
        if row is None:
            return None
        if row["extraction_run_id"] is None:  # 요건 추출에 실패한 공고는 판정하지 않는다
            await self.conn.execute(
                "delete from eligibility_results where user_id = %s and opportunity_id = %s",
                (user_id, opportunity_id),
            )
            eligibility = DetailEligibility(
                status="undetermined",
                display_status="needs_review",
                reason_text=UNJUDGED_SUMMARY,
                basis_date=None,
                requirements_version=row["requirements_version"],
                missing_fields=[],
                clauses=[],
                conditions=[],
                evaluated_at=None,
            )
        else:
            profile = Profile.from_row(profile_row)
            departments = await self._departments()
            judged = _judge(row, profile, departments, now.astimezone(KST).date())
            await self._upsert(user_id, [_payload(row, judged.stored)], now)
            eligibility = _detail_eligibility(
                judged, profile, departments, row["requirements_version"], now
            )
        await self.conn.execute(_VIEW, (user_id, opportunity_id, now, now))
        names = {item["seq"]: item["file_name"] for item in row["attachments"]}
        apply_start: datetime | None = row["apply_start_at"]
        deadline: datetime | None = row["deadline_at"]
        confidence = row["extraction_confidence"]
        return OpportunityDetail(
            id=str(row["id"]),
            title=row["title"],
            organizer=row["organizer"],
            category=row["category"],
            source_type=row["source_type"],
            status=row["status"],
            original_url=row["original_url"],
            poster_url=None,  # TODO(W6): 포스터 업로드에서 Storage 서명 URL(5분)을 붙인다
            easy_summary=row["easy_summary"],
            apply_start_at=apply_start.astimezone(KST) if apply_start else None,
            deadline_at=deadline.astimezone(KST) if deadline else None,
            needs_review=bool(row["needs_review"]),
            review_reasons=_lines(row["review_reasons"]),
            extraction_confidence=float(confidence) if confidence is not None else None,
            uploaded_by_me=row["uploaded_by_me"],
            course_name=row["course_name"],
            attachments=[_attachment(item) for item in row["attachments"] if item["source_url"]],
            eligibility=eligibility,
            documents=[DocumentItem(**document) for document in row["documents"]],
            prep=Prep(
                prepared=row["prep_plan_id"] is not None,
                prep_plan_id=_text(row["prep_plan_id"]),
                tasks_total=row["tasks_total"],
                tasks_done=row["tasks_done"],
                calendar_events=[CalendarEventRef(**event) for event in row["calendar_events"]],
            ),
            process=Process(
                extraction=[_step(step, names) for step in row["steps"]],
                evaluated_at=eligibility.evaluated_at,
                prepare_run_id=_text(row["prepare_run_id"]),
            ),
            reported_by_me=row["reported_by_me"],
            my_mark=row["my_mark"],
        )

    async def set_mark(
        self,
        user_id: str,
        opportunity_id: str,
        mark: str,
        *,
        now: datetime,
        display_name: str | None = None,
    ) -> datetime | None:
        """관심·관심 없음 표시(F-45). 상세를 열 수 있는 공고에만 붙인다. 아니면 None.

        공고마다 표시는 하나다. 다른 표시를 보내면 바꾼다. 프로필 행이 없으면(첫 요청) 만든다.
        피드처럼 프로필 행을 잠근다: 피드 응답 하나의 목록(my_mark)과 숫자(counts)가 어긋나지 않는다.
        """
        await self._lock_profile(user_id, display_name)
        params = {"uid": user_id, "oid": opportunity_id, "mark": mark, "now": now}
        if await (await self.conn.execute(_MARK_OPENABLE, params)).fetchone() is None:
            return None
        row = await (await self.conn.execute(_MARK_UPSERT, params)).fetchone()
        assert row is not None
        return row["marked_at"]

    async def clear_mark(self, user_id: str, opportunity_id: str) -> None:
        """표시를 지운다. 없으면 아무것도 하지 않는다.

        set_mark처럼 프로필 행을 잠근다. 프로필 행이 없으면 만들지 않는다(지울 표시도 없다).
        """
        await self.conn.execute(
            "select 1 from profiles where id = %s for no key update", (user_id,)
        )
        await self.conn.execute(
            "delete from opportunity_marks where user_id = %s and opportunity_id = %s",
            (user_id, opportunity_id),
        )

    async def feed_page(self, user_id: str, query: FeedQuery, *, now: datetime) -> FeedPage:
        params: dict[str, Any] = {
            "uid": user_id,
            "now": now,
            "new_since": now - timedelta(days=NEW_DAYS),
            "limit": query.limit + 1,
        }
        where = [_WITH_EXPIRED if query.include_expired else _ACTIVE, _VISIBLE, _SHOWN]
        if not query.include_not_interested:
            where.append(_NOT_DISMISSED)
        if query.categories:
            where.append(" o.category::text = any(%(categories)s)")
            params["categories"] = list(query.categories)
        if query.source_types:
            where.append(" o.source_type::text = any(%(source_types)s)")
            params["source_types"] = list(query.source_types)
        outer = []
        if query.eligibility:
            outer.append("eff_status = any(%(eligibility)s)")
            params["eligibility"] = sorted(query.eligibility)
        if query.cursor:
            outer.append(_after(query.sort, query.cursor))
            params["cursor_value"], params["cursor_id"] = query.cursor.value, query.cursor.id
        sql = _feed_sql(
            " and".join(where),
            " where " + " and ".join(outer) if outer else "",
            _ORDER[query.sort],
        )
        rows = await (await self.conn.execute(sql, params)).fetchall()
        today = now.astimezone(KST).date()
        page = rows[: query.limit]
        next_cursor = None
        if len(rows) > query.limit:
            last = page[-1]
            value = last["deadline_at"] if query.sort == "deadline" else last["created_at"]
            cursor = Cursor(scope=query.scope(), value=value, id=str(last["id"]))
            next_cursor = encode_cursor(cursor)
        return FeedPage(items=[_item(row, today) for row in page], next_cursor=next_cursor)

    async def feed_counts(self, user_id: str, *, now: datetime) -> FeedCounts:
        """홈 요약 카드: 필터와 상관없이 지금 보이는 활성 공고 전체 기준."""
        row = await (
            await self.conn.execute(
                _COUNTS,
                {
                    "uid": user_id,
                    "now": now,
                    "new_since": now - timedelta(days=NEW_DAYS),
                    "today": now.astimezone(KST).date(),
                    "soon": SOON_DAYS,
                },
            )
        ).fetchone()
        assert row is not None
        return FeedCounts.model_validate(row)

    async def _lock_profile(self, user_id: str, display_name: str | None) -> dict[str, Any]:
        """프로필 행을 (없으면 만들고) 잠근 뒤 읽는다.

        같은 사용자의 판정은 한 번에 하나씩: 프로필 저장과 피드 읽기가 겹쳐도 옛 프로필로 덮어쓰지 않는다.
        no key update라서 이 사용자의 다른 행(이벤트·알림 등)이 profiles를 참조하며 넣는 것은 막지 않는다.
        """
        await self.conn.execute(
            "insert into profiles (id, display_name) values (%s, %s) on conflict do nothing",
            (user_id, display_name),
        )
        row = await (
            await self.conn.execute(
                "select * from profiles where id = %s for no key update", (user_id,)
            )
        ).fetchone()
        assert row is not None
        return row

    async def _upsert(self, user_id: str, payload: list[dict[str, Any]], now: datetime) -> None:
        """판정 여러 개를 한 문장으로 저장한다(_payload 모양)."""
        if payload:
            await self.conn.execute(
                _UPSERT,
                {"uid": user_id, "engine": ENGINE_VERSION, "now": now, "rows": Jsonb(payload)},
            )

    async def _departments(self) -> list[Department]:
        """판정에 쓰는 학과 목록. 목록에서 빠진(폐지·통합) 학과도 단과대학·계열을 알아야 해서 모두 읽는다."""
        rows = await (
            await self.conn.execute("select name, college, field_group from departments")
        ).fetchall()
        return [Department.from_row(row) for row in rows]


def _after(sort: Sort, cursor: Cursor) -> str:
    """정렬 순서(_ORDER)에서 cursor 다음에 오는 행. 값이 없는 행은 맨 뒤에 id 순으로 온다."""
    column, beyond = ("deadline_at", ">") if sort == "deadline" else ("created_at", "<")
    if cursor.value is None:
        return f"({column} is null and id {beyond} %(cursor_id)s)"
    return (
        f"({column} {beyond} %(cursor_value)s"
        f" or ({column} = %(cursor_value)s and id {beyond} %(cursor_id)s) or {column} is null)"
    )

@dataclass(frozen=True)
class _Judged:
    stored: dict[str, Any]  # eligibility_results에 넣을 값(Judgment.storage_row 모양)
    label: str  # display_status
    judgment: Judgment | None  # 엔진이 오류를 냈으면 None
    requirements: tuple[Requirement, ...]
    basis_date: date | None


def _judge(
    item: dict[str, Any], profile: Profile, departments: list[Department], today: date
) -> _Judged:
    """공고 행 하나(requirements·eligibility_basis_date·deadline_at)를 판정한다.

    엔진 오류면 "판정하지 못함" 행을 돌려준다: 그 공고만 원문 확인 필요로 보인다.
    """
    basis: date | None = None
    try:
        requirements = tuple(Requirement.from_row(r) for r in item["requirements"])
        days = _basis_dates(item, today)
        basis = days[0]
        # 기준일이 둘이면(청년정책) 더 나은 쪽을 쓴다. 같으면 앞 날짜다(max는 처음 나온 것을 고른다)
        judgment = max(
            (
                check_eligibility(
                    list(requirements), profile, basis_date=day, departments=departments
                )
                for day in days
            ),
            key=lambda found: _RANK[found.status],
        )
        return _Judged(
            judgment.storage_row(),
            judgment.display_status,
            judgment,
            requirements,
            judgment.basis_date,
        )
    except Exception:
        logger.exception("판정하지 못한 공고: %s", item["id"])
        return _Judged(_engine_error_row(), "needs_review", None, (), basis)


_RANK = {"ineligible": 0, "undetermined": 1, "eligible": 2}


def _basis_dates(item: dict[str, Any], today: date) -> tuple[date, ...]:
    """판정 기준일(판정엔진_규칙.md 8장). 보통 하나다(공고 기준일 → 마감일 → 오늘).

    청년정책(온통청년)은 신청일 기준이 대부분이고 신청 기간이 몇 년인 정책도 있다. 그래서 신청할 수 있는 첫날
    (오늘, 신청 기간 전이면 시작일)과 마감일을 둘 다 보고 더 나은 결과를 쓴다. 나이 상한은 첫날에, 하한은
    마감일에 맞으면 그 사이 어느 날엔 신청할 수 있다. 신청 기간이 끝났으면 마감일 하나다."""
    if item["source_type"] != "youth_policy" or item["eligibility_basis_date"] is not None:
        return (resolve_basis_date(item["eligibility_basis_date"], item["deadline_at"], today),)
    start = item["apply_start_at"]
    first = max(today, to_kst_date(start)) if start is not None else today
    if item["deadline_at"] is None:
        return (first,)
    deadline = to_kst_date(item["deadline_at"])
    return (deadline,) if deadline <= first else (first, deadline)

def _detail_eligibility(
    judged: _Judged,
    profile: Profile,

    requirements_version: int,

    """상세의 판정표. 조건 문구는 엔진(describe)이 만들고, 내 값은 저장한 값과 같은 모양이다."""

def _step(step: dict[str, Any], names: dict[int, str]) -> ProcessStep:
    """처리 과정 한 줄(_DETAIL의 steps 행 하나). 첨부를 읽은 단계는 첨부 이름을 넣어 보인다.

    도구가 오류를 돌려준 호출(없는 첨부 번호 등)과 거절된 제출은 실행 로그에 succeeded로 남는다
    (에이전트는 오류를 모델에 돌려주고 계속 간다). 화면에는 실패로 보인다. 첨부 번호·위치는
    에이전트와 같은 규칙(whole)으로 읽는다. 읽기·토큰 상한에 닿아 코드가 시킨 제출(forced)은
    모델이 고른 단계가 아니라서 pipeline으로 보인다.
    """
    tool: str = step["tool"]
    again = "이어 " if _continued(step) else ""
    if tool in (READ_TEXT, READ_IMAGE):
        number = whole(step.get("attachment_no"))
        name = names.get(number) if number is not None else None
        target = f"첨부 '{name}'" if name else f"첨부 {number}번" if number else "첨부"
        how = "이미지로 " if tool == READ_IMAGE else ""
        label = f"{target} {how}{again}읽기"
    elif tool == FETCH_ORIGINAL:
        label = f"공고 원문 페이지 {again}읽기"
    elif tool == FETCH_YOUTH:
        label = "온통청년에서 정책 정보 받기"
    elif tool == BUILD_YOUTH:
        label = "온통청년 항목으로 지원 자격 정리"
    else:
        label = "지원 자격 정리" if tool == SUBMIT else tool
    failed = step.get("error") is True or (tool == SUBMIT and step.get("accepted") is False)
    chosen = tool in _AGENT_TOOLS and step.get("forced") is not True
    return ProcessStep(
        seq=step["seq"],
        tool=tool,
        label=label,
        status="failed" if failed else step["status"],
        latency_ms=step["latency_ms"],
        chosen_by="agent" if chosen else "pipeline",
        note=_line(step.get("reason")),
    )


def _continued(step: dict[str, Any]) -> bool:
    """앞에서 읽은 곳의 뒷부분을 읽은 호출. 도구가 실제로 읽은 위치를 보고, 오류면 요청한 위치를 본다.

    글자 읽기·원문 읽기는 시작 위치(offset)가 0보다 크면, Vision은 PDF를 2쪽부터 읽었으면 이어 읽기다.
    이미지는 한 장이라 이어 읽기가 없다.
    """
    if step["tool"] != READ_IMAGE:
        offset = whole(step.get("offset"))
        return offset is not None and offset > 0
    pages = step.get("pages")  # 읽은 PDF 쪽 "4–6/8". 이미지는 없다
    if isinstance(pages, str) and (first := _PAGES.match(pages)):
        return int(first.group(1)) > 1
    if step.get("error") is not True:
        return False  # 이미지를 읽었다
    start_page = whole(step.get("start_page"))
    return start_page is not None and start_page > 1


def _line(text: Any) -> str | None:
    """모델이 쓴 글(고른 이유, 원문 확인 필요 이유)을 화면용 한 줄로: 보이지 않는 문자(폭 없는 문자,
    글자 방향 제어)와 주소를 지우고 공백·줄바꿈을 한 칸으로 줄여 LINE_MAX_CHARS자까지. 남는 글이
    없으면 None이다.

    공고 글을 읽은 모델이 쓴 글이라, 공고 속 지시문이 링크를 끼워 넣지 못하게 쉬운 설명과 같은 규칙으로
    정리한다(app/extraction/validate.py). 저장된 값을 읽을 때 정리해서 예전 행에도 같이 적용된다.
    화면은 이 글을 일반 텍스트로 보여 준다(자동 링크·마크다운 없이).
    """
    if not isinstance(text, str):
        return None
    line = " ".join(_LINK.sub("", _INVISIBLE.sub("", text)).split())
    if len(line) > LINE_MAX_CHARS:
        line = line[: LINE_MAX_CHARS - 1].rstrip() + "…"
    return line or None


def _lines(texts: Sequence[Any] | None) -> list[str]:
    """여러 줄을 _line으로 정리한다. 빈 줄과 같은 줄은 빼고, REASONS_MAX줄이 넘으면 "외 N건"으로 줄인다."""
    lines = list(dict.fromkeys(line for text in texts or () if (line := _line(text))))
    if len(lines) > REASONS_MAX:
        return [*lines[:REASONS_MAX], f"외 {len(lines) - REASONS_MAX}건"]
    return lines


def _attachment(item: dict[str, Any]) -> AttachmentItem:
    if item["error"]:
        status = "failed"
    elif item["method"]:
        status = "succeeded"
    else:
        status = "skipped"  # 에이전트가 읽지 않은 첨부
    return AttachmentItem(
        id=str(item["id"]),
        file_name=item["file_name"],
        source_url=item["source_url"],
        extract_status=status,
    )


def _text(value: Any) -> str | None:
    return str(value) if value is not None else None

    field: str, raw: str | None, allowed: Sequence[str], errors: dict[str, str]
) -> tuple[str, ...] | None:
    """쉼표로 여러 값을 받는다. 비어 있으면 None(전체). 알 수 없는 값은 errors에 모은다."""

def removed_from_counts(item: OpportunityItem) -> dict[str, int]:
    """공고 하나를 숨기면 요약 숫자에서 빠지는 칸. 웹 lib/feedCounts.ts의 countDelta와 같은 규칙이다."""
    status, display = item.eligibility.status, item.eligibility.display_status
    soon = status != "ineligible" and item.d_day is not None and 0 <= item.d_day <= 3
    return {
        "eligible": int(status == "eligible"),
        "new_eligible": int(status == "eligible" and item.is_new),
        "undetermined": int(status == "undetermined"),
        "missing_info": int(display == "missing_info"),
        "needs_review": int(display == "needs_review"),
        "ineligible": int(status == "ineligible"),
        "deadline_soon": int(soon),
    }


async def test_hiding_takes_a_posting_out_of_its_count_buckets() -> None:
    """공고마다 숨기면 그 공고가 들어 있던 숫자 칸만 1씩 준다. 홈은 같은 규칙으로 숫자를 고친다."""

async def test_paging_with_hidden_postings() -> None:
    """한 쪽에 하나씩 넘겨도 관심 없음 공고는 include_not_interested일 때만 나오고 빠지거나 겹치는 공고가
    없다. 숨기기 전에 받은 커서도 그 뒤부터 이어진다."""
    conn = await connect()
    try:
        world, me, _ = await build(conn)
        repo, now = OpportunityRepository(conn), world.now
        await repo.refresh_judgments(me, now=now)

        async def walk(query: FeedQuery) -> list[str]:
            seen: list[str] = []
            while True:
                page = await repo.feed_page(me, query, now=now)
                seen += titles(page.items, world)
                if page.next_cursor is None:
                    return seen
                query = replace(query, cursor=decode_cursor(page.next_cursor))

        ineligible_only = frozenset({"ineligible"})
        everything = await walk(FeedQuery(limit=1))
        ineligible = await walk(FeedQuery(limit=1, eligibility=ineligible_only))
        assert "장학 B" in everything and "장학 B" in ineligible

        query = FeedQuery(limit=1)  # 장학 B가 마지막인 쪽까지 받은 커서
        while True:
            page = await repo.feed_page(me, query, now=now)
            assert page.next_cursor is not None
            query = replace(query, cursor=decode_cursor(page.next_cursor))
            if titles(page.items, world) == ["장학 B"]:
                break
        await repo.set_mark(me, world.ids["장학 B"], "not_interested", now=now)
        assert await walk(query) == everything[everything.index("장학 B") + 1 :]

        assert await walk(FeedQuery(limit=1)) == [t for t in everything if t != "장학 B"]
        assert await walk(FeedQuery(limit=1, include_not_interested=True)) == everything
        assert await walk(FeedQuery(limit=1, eligibility=ineligible_only)) == [
            t for t in ineligible if t != "장학 B"
        ]
        both = FeedQuery(limit=1, eligibility=ineligible_only, include_not_interested=True)
        assert await walk(both) == ineligible
    finally:
        await conn.rollback()
        await conn.close()

import type { FeedCounts, OpportunityItem, OpportunityMark } from "@/types/api";

// 홈 요약 카드 숫자 규칙(API 명세 5장 counts). 숨긴 공고를 빼거나 다시 넣을 때 화면에서 숫자를 고치고,
// 목 모드는 이 규칙으로 센다. 마감 임박은 지원 어려움을 빼고 D-3~D-day다. 규칙을 바꾸면
// api/tests/test_marks_db.py의 removed_from_counts도 같이 고친다(서버 SQL과 맞는지 그 테스트가 본다)
export const NO_COUNTS: FeedCounts = {
  eligible: 0, new_eligible: 0, undetermined: 0, missing_info: 0, needs_review: 0, ineligible: 0, deadline_soon: 0,
};

export function countDelta(counts: FeedCounts, item: OpportunityItem, sign: 1 | -1): FeedCounts {
  const { status, display_status: display } = item.eligibility;
  const soon = status !== "ineligible" && item.d_day !== null && item.d_day >= 0 && item.d_day <= 3;
  const add = (yes: boolean) => (yes ? sign : 0);
  return {
    eligible: counts.eligible + add(status === "eligible"),
    new_eligible: counts.new_eligible + add(status === "eligible" && item.is_new),
    undetermined: counts.undetermined + add(status === "undetermined"),
    missing_info: counts.missing_info + add(display === "missing_info"),
    needs_review: counts.needs_review + add(display === "needs_review"),
    ineligible: counts.ineligible + add(status === "ineligible"),
    deadline_soon: counts.deadline_soon + add(soon),
  };
}

export function countItems(items: OpportunityItem[]): FeedCounts {
  return items.reduce((counts, item) => countDelta(counts, item, 1), NO_COUNTS);
}

// 화면에서 바꾼 표시(marks)만큼 서버 숫자를 고친다. 서버가 준 표시(item.my_mark)와 숨김 여부가 다른 공고만
// 센다. 목록을 다시 받아 서버가 이미 반영했으면 고칠 것이 없다
export function adjustCounts(
  counts: FeedCounts,
  items: OpportunityItem[],
  marks: Readonly<Record<string, OpportunityMark | null>>,
): FeedCounts {
  return items.reduce((total, item) => {
    if (!(item.id in marks)) return total;
    const hidden = marks[item.id] === "not_interested";
    return hidden === (item.my_mark === "not_interested") ? total : countDelta(total, item, hidden ? -1 : 1);
  }, counts);
}

import { useCallback, useEffect, useRef, useState } from "react";

// 화면 아래 안내(components/Toast)의 글과 번호. 같은 글이 이어 떠도 번호가 바뀌어 화면 읽기 프로그램이 다시 읽는다
export interface ToastState {
  text: string;
  id: number;
}

// 안내를 잠깐 띄운다. 안내가 이어 뜨면 앞 안내의 타이머를 지워 새 안내가 일찍 사라지지 않게 한다
export default function useToast(duration = 2200): [ToastState, (text: string) => void] {
  const [toast, setToast] = useState<ToastState>({ text: "", id: 0 });
  const timer = useRef<ReturnType<typeof setTimeout>>(undefined);
  useEffect(() => () => clearTimeout(timer.current), []);
  const show = useCallback(
    (text: string) => {
      clearTimeout(timer.current);
      setToast((current) => ({ text, id: current.id + 1 }));
      timer.current = setTimeout(() => setToast((current) => ({ ...current, text: "" })), duration);
    },
    [duration],
  );
  return [toast, show];
}

export function markToast(before: OpportunityMark | null, next: OpportunityMark | null): string {
  if (next === "interested") {
    return before === "not_interested" ? "숨김을 풀고 관심 공고에 담았어요" : "관심 공고에 담았어요";
  }
  if (next === "not_interested") {
    const done = before === "interested" ? "관심 공고에서 빼고 숨겼어요." : "숨겼어요.";
    return `${done} 홈의 숨김 탭에서 다시 볼 수 있어요`;
  }
  return before === "not_interested" ? "숨김을 풀었어요" : "관심 공고에서 뺐어요";
}

// 표시를 바꾸지 못했을 때. 그새 목록에서 내린 공고(404)는 새로 고치라고 알린다
export function markError(error: unknown): string {

    const feedItem = opportunities.find((item) => item.id === id);
    if (feedItem) feedItem.prepared = true;
  }

  const tasks = tasksForOpportunity(id);
  detail.prep = {
    prepared: true,
    prep_plan_id: prepPlanId,
    tasks_total: tasks.length,
    tasks_done: tasks.filter((task) => task.is_done).length,
    calendar_events:
      includeCalendar && detail.deadline_at
        ? [{ id: `gcal-${id}`, provider: "google" }]
        : [],
  };
  detail.process.prepare_run_id = `run-prepare-${id}`;

  return {
    kind: "prepare",
    prep_plan_id: prepPlanId,
    documents: detail.documents,
    tasks: tasks.map((task) => ({
      id: task.id,
      title: task.title,
      due_date: task.due_date,
      document_id:
        detail.documents.find((document) => document.task_id === task.id)?.id ?? null,
    })),
    calendar_event:
      includeCalendar && detail.deadline_at
        ? {
            id: `gcal-${id}`,
            provider: "google",
            starts_at: detail.deadline_at,
          }
        : null,
  };
}

export function setStoredDocumentDone(
  opportunityId: string,
  documentId: string,
  isDone: boolean,
): OpportunityDetail {
  const detail = detailsState[opportunityId];
  if (!detail) throw new Error("공고를 찾을 수 없어요.");
  const document = detail.documents.find((item) => item.id === documentId);
  if (!document?.task_id) throw new Error("준비 일정을 먼저 만들어 주세요.");

  document.is_done = isDone;

  const tasks = tasksForOpportunity(opportunityId);
  detail.prep.tasks_done = tasks.filter((item) => item.is_done).length;
  detail.prep.tasks_total = tasks.length;
  return detail;
}

      // 실제 모드는 포스터 등록(W6) 전이라 다시 불러오기를 안내한다
      return POSTER_READY
        ? { title: "포스터를 올리면 공고로 등록하고 자격을 판정해요", action: "포스터 등록", onAction: () => navigate({ name: "upload" }) }
        : { title: "아직 볼 수 있는 공고가 없어요. 새 공고가 올라오면 여기에 보여요", action: "다시 불러오기", onAction: () => setReload((value) => value + 1) };
    }
    if (tabItems.length === 0 && tab === "recommended" && tabCounts.not_interested > 0) {
      const title = all ? "공고를 모두 숨겼어요" : "이 카테고리의 공고를 모두 숨겼어요";
      return { title, action: "숨김 탭 보기", onAction: () => selectTab("not_interested") };
    }
    if (tabItems.length === 0 && tab !== "recommended") {
      const title =
        tab === "interested"
          ? all ? "관심 공고가 없어요. 카드의 ☆ 관심을 누르면 여기에 모여요" : "이 카테고리에는 관심 공고가 없어요"
          : all ? "숨긴 공고가 없어요" : "이 카테고리에는 숨긴 공고가 없어요";
      return all
        ? { title, action: "추천 공고 보기", onAction: () => selectTab("recommended") }
        : { title, action: "전체 카테고리 보기", onAction: () => setCategory("all") };
    }
    if (visibleItems.length + ineligibleItems.length === 0) {
      return { title: "조건에 맞는 공고가 없어요", action: "필터 초기화", onAction: resetFilters };
    }
    return null;
  };
  const empty = emptyState();

  const changeMark = async (item: OpportunityItem, next: OpportunityMark | null) => {
    // 바뀐 뒤 이 탭에서 빠지는 카드면 그 자리로 초점을 옮긴다(화면의 카드 순서와 같다)
    const leaves = tab === "recommended" ? next === "not_interested" : next !== tab;
    const shown = [...visibleItems, ...(showIneligible ? ineligibleItems : [])];
    const index = shown.findIndex((entry) => entry.id === item.id);
    const before = request.data;
    setPending((current) => new Set(current).add(item.id));
    try {
      await setOpportunityMark(item.id, next);
      if (leaves) focusAt.current = index;
      setMarks((current) => ({ ...current, [item.id]: next }));
      showToast(markToast(item.my_mark, next));
      // 저장하는 사이 목록을 다시 받기 시작했으면 저장 전 값을 읽었을 수 있다. 숫자가 어긋나지 않게 한 번 더 받는다
      if (latestData.current !== before) setReload((value) => value + 1);
    } catch (error) {
      showToast(markError(error));
    } finally {
      setPending((current) => {
        const rest = new Set(current);
        rest.delete(item.id);
        return rest;
      });
    }
  };

  const card = (item: OpportunityItem) => (
    <OpportunityCard key={item.id} item={item} pending={pending.has(item.id)} navigate={navigate} onMark={changeMark} />
  );

  return (
    <>
      <Header title={`안녕하세요, ${me.display_name}님`} subtitle="나에게 맞는 기회와 이번 주 할 일을 한눈에 확인하세요." />
      <FeedSummary counts={shownCounts} selected={summaryFilter} onToggle={toggleSummary} />
      <section ref={listRef}>
        <div className="flex items-center justify-between gap-3">
          <FeedTabs tab={tab} counts={tabCounts} onSelect={selectTab} />
          <select
            value={sort}
            onChange={(event) => setSort(event.target.value as NonNullable<FeedParams["sort"]>)}
            className="bg-transparent text-[13px] font-medium text-[#667085] outline-none"
          >
            <option value="deadline">마감 임박순</option>
            <option value="recent">최신순</option>
          </select>
        </div>
        <div className="mt-5 flex flex-wrap gap-2">
          {categoryFilters.map((filter) => (
            <button
              key={filter.value}
              type="button"
              onClick={() => setCategory(filter.value)}
              className={`filter-chip rounded-full transition-all duration-300 ${
                category === filter.value
                  ? "-translate-y-0.5 scale-105 shadow-[0_6px_16px_rgba(79,110,247,0.18)]"
                  : "opacity-55 hover:-translate-y-0.5 hover:scale-105 hover:opacity-100"
              }`}
              aria-pressed={category === filter.value}
            >
              <Badge>{filter.label}</Badge>
            </button>
          ))}
        </div>
        {empty ? (
          <EmptyBox {...empty} />
        ) : (
          <>
            <div key={`${category}-${summaryFilter}-${sort}-${tab}`} className="opportunity-list mt-7 flex flex-col gap-7">
              {visibleItems.map(card)}
            </div>
            {ineligibleItems.length > 0 && (
              <div className="mt-7">
                <button
                  type="button"
                  onClick={() => setShowIneligible((value) => !value)}
                  className="flex w-full items-center justify-between rounded-[14px] border border-[#e5e7eb] bg-white p-4 text-[14px] font-semibold"
                >
                  지원 어려움 {ineligibleItems.length}개
                  <span className="text-[#667085]">{showIneligible ? "⌃" : "⌄"}</span>
                </button>
                {showIneligible && <div className="mt-3 flex flex-col gap-3">{ineligibleItems.map(card)}</div>}
              </div>
            )}
          </>
        )}
      </section>
      <Toast toast={toast} />
    </>
  );
}

export default function OpportunityDetail({
  id,
  focus,
  calendarConnected,
  navigate,

    () =>
      getOpportunity(id).catch((error: unknown) => {

  const [markChange, setMarkChange] = useState<{ id: string; mark: OpportunityMark | null } | null>(null);
