# 테스트 시나리오 자동 실행 — 성공률·응답시간·비용을 재고 실행 기록에 남긴다

> 📝 기준: PRD v0.9 8장(성공 지표와 테스트 시나리오) · API 명세 v0.4 12장 · ERD v0.9 로깅 도메인 · 2026-10-15
>
> 함께 보는 파일: `포스터등록_구현.md`(먼저 합쳤다, main e4e2c57)

AOP 과제의 필수 산출물이 "테스트 시나리오 측정(성공률·응답시간·비용)"이다. 지금까지 만든 기능은 단위·통합 테스트로는 덮여 있지만, **PRD 8장 표의 시나리오가 끝까지 도달하는지**를 재는 것이 없었다. 그래서 시나리오를 돌리는 러너와 시나리오 열한 개를 만든다.

이번 PR은 **러너 틀 + 시나리오**다. 명세 12장의 `GET /internal/metrics`(기간별 집계와 혼동행렬)는 다음 PR이다 — 이 PR이 그 집계가 읽을 기록을 남기는 쪽이다.

**규모와 확인:**
- api만 바뀐다. 새 파일 9개(`app/eval/` 7개, 테스트 2개), 바꾸는 파일 1개(`app/background.py`에 한 줄짜리 속성 추가).
- **DB 변경이 없다.** `agent_runs.scenario_code` 컬럼과 `trigger_type = 'eval'`이 이미 있다(ERD v0.9, `20261006000000_erd_v07.sql`·`20261006000200_erd_v09.sql`). db push가 필요 없다.
- 엔드포인트를 더하지 않는다. 지금은 사람이 `python -m app.eval.cli`로 돌린다(온통청년 수집과 같은 모양).
- api `699 passed, 131 skipped`(DB 없이), DB를 붙이면 `830 passed`. 전에는 `674 passed, 121 skipped` / `795 passed`였다.
- 시나리오 열한 개가 모두 통과한다(아래 "베이스라인").
- 새 동작을 하나씩 되돌려 테스트가 잡는지 봤다. 러너·시나리오 쪽 22가지, 그리고 **시나리오가 지키려는 제품 코드 7가지**를 망가뜨려 봤고 모두 잡혔다(아래 "확인한 것").
- 따로 띄운 검토 에이전트 둘이 봤다(하나는 버그·누수·순서 의존, 하나는 레포 규칙 대조). 지적 20건을 모두 고쳤고, 되돌림 시험에서 더 찾은 2건도 고쳤다. 그대로 둔 것 4가지와 다음으로 미룬 것은 아래에 적었다.

## 합친 뒤 확인

시나리오를 돌리려면 **시험용 DB**가 필요하다. 실제 Supabase 주소면 러너가 시작하지 않는다(사용자·공고를 만들고 지운다).

1. **시나리오 목록:** `api`에서

   ```powershell
   uv run python -m app.eval.cli --list
   ```

   S01–S08·S11–S13 열한 줄이 나온다. DB에 닿지 않는다.
2. **시험용 DB 준비:** 로컬 Postgres에 CI와 같은 순서로 빈 DB를 만들고(`supabase/ci/auth_stub.sql` → `supabase/migrations/*.sql` 이름 순 → `supabase/ci/schema_checks.sql`), 그 주소를 `DATABASE_URL`로 준다. `api/.env`의 Supabase 주소를 그대로 쓰면 안 된다.
3. **돌리기:**

   ```powershell
   $env:DATABASE_URL = "postgresql://postgres:postgres@localhost:5432/unipivot_eval"
   uv run python -m app.eval.cli --out eval_baseline.json
   ```

   표가 나오고 마지막 줄이 `통과 11/11(100.0%)`이면 된다. `eval_baseline.json`이 W6 베이스라인이다(레포에 넣지 않는다 — 아래 "남은 것").
4. **기록 보기:** 같은 DB에서

   ```sql
   select scenario_code, status, latency_ms from agent_runs
   where trigger_type = 'eval' order by started_at;
   select c.tool_name, c.input->>'what', c.output->>'ok'
   from tool_calls c join agent_runs r on r.id = c.run_id
   where r.scenario_code = 'S03' and r.trigger_type = 'eval' order by c.seq;
   ```

   첫 조회에 열한 줄, 둘째 조회에 S03이 확인한 여섯 줄이 나온다. 사용자·공고는 지워졌고 기록은 남아 있다.
5. **시계 바꿔 보기:** `uv run python -m app.eval.cli --now 2027-03-05T09:00:00+09:00`도 `11/11`이다. 날짜를 모두 주입 시계에서 세기 때문이다.
6. **안전장치:** `$env:DATABASE_URL`에 Supabase 주소를 넣고 돌리면 "시험용 DB에서만 돌려요"가 뜨고 아무것도 하지 않는다. 확인한 뒤 시험용 DB 주소로 되돌린다.

```python
"""시나리오 실행 결과 모양. CLI 출력과 베이스라인 JSON이 이 값을 쓴다(PRD 8장)."""

from __future__ import annotations

import math
from collections.abc import Sequence
from dataclasses import dataclass, field
from datetime import date, datetime
from decimal import Decimal
from typing import Any

from pydantic import BaseModel


@dataclass(frozen=True)
class Check:
    """시나리오가 확인한 것 하나. agent_runs 아래 tool_calls(check) 한 줄로도 남는다."""

    what: str
    expected: Any
    actual: Any

    @property
    def ok(self) -> bool:
        return self.actual == self.expected

    def json(self) -> dict[str, Any]:
        return {"what": self.what, "expected": self.expected, "actual": self.actual, "ok": self.ok}


class CheckFailed(AssertionError):
    """기대한 결과에 닿지 못했다. 시나리오는 여기서 멈추고 실패로 남는다."""

    def __init__(self, check: Check) -> None:
        super().__init__(f"{check.what}: 기대 {check.expected!r} · 실제 {check.actual!r}")
        self.check = check


@dataclass
class ScenarioResult:
    code: str
    title: str
    ok: bool
    latency_ms: int  # 시나리오가 끝까지 가는 데 걸린 시간(세계를 만드는 시간도 들어 있다)
    api_ms: float = 0.0  # 그중 엔드포인트가 쓴 시간 합(응답시간 지표)
    run_id: str | None = None  # 시나리오 실행(agent_runs, trigger eval)
    # 이 시나리오에 딸린 다른 실행(공고에 붙인 수집, 준비하기, 포스터 추출). 같은 번호가 붙어 있다
    child_run_ids: list[str] = field(default_factory=list)
    cost_usd: Decimal = Decimal(0)
    llm_calls: int = 0
    checks: list[Check] = field(default_factory=list)
    error: str | None = None  # 실패 이유 한 줄(기대와 다른 결과이거나 터진 예외)

    def json(self) -> dict[str, Any]:
        return {
            "code": self.code,
            "title": self.title,
            "ok": self.ok,
            "latency_ms": self.latency_ms,
            "api_ms": self.api_ms,
            "run_id": self.run_id,
            "child_run_ids": self.child_run_ids,
            "cost_usd": float(self.cost_usd),
            "llm_calls": self.llm_calls,
            "checks": [check.json() for check in self.checks],
            "error": self.error,
        }


@dataclass
class Report:
    """한 번 돌린 결과 전체. W6 베이스라인으로 이 JSON을 고정 저장한다(PRD 8장)."""

    now: datetime  # 주입한 시계
    # 단가를 고른 날(app/pricing.py). 단가가 바뀌면 같은 now로 돌려도 비용이 달라진다
    priced_on: date | None = None  # noqa
    results: list[ScenarioResult] = field(default_factory=list)

    @property
    def total(self) -> int:
        return len(self.results)

    @property
    def passed(self) -> int:
        return sum(1 for result in self.results if result.ok)

    @property
    def success_rate(self) -> float:
        """E2E 성공률. 0건이면 0.0이다."""
        return round(self.passed / self.total, 4) if self.total else 0.0

    @property
    def latencies(self) -> list[int]:
        return [result.latency_ms for result in self.results]

    @property
    def p50(self) -> int:
        return percentile(self.latencies, 50)

    @property
    def p95(self) -> int:
        return percentile(self.latencies, 95)

    @property
    def api_ms(self) -> float:
        return round(sum(result.api_ms for result in self.results), 1)

    @property
    def cost_usd(self) -> Decimal:
        return sum((result.cost_usd for result in self.results), Decimal(0))

    @property
    def llm_calls(self) -> int:
        return sum(result.llm_calls for result in self.results)

    def json(self) -> dict[str, Any]:
        return {
            "now": self.now.isoformat(),
            "priced_on": self.priced_on.isoformat() if self.priced_on else None,
            "scenarios": self.total,
            "passed": self.passed,
            "success_rate": self.success_rate,
            "latency_ms": {"p50": self.p50, "p95": self.p95},
            "api_ms": self.api_ms,
            "cost_usd": float(self.cost_usd),
            "llm_calls": self.llm_calls,
            "results": [result.json() for result in self.results],
        }


def percentile(values: Sequence[int], pct: float) -> int:
    """가장 가까운 순위(nearest-rank) 백분위수. 시나리오가 몇 개뿐이라 값을 섞지 않고 그중 하나를 고른다."""
    if not values:
        return 0
    ordered = sorted(values)
    rank = max(math.ceil(pct / 100 * len(ordered)), 1)
    return ordered[rank - 1]


def plain(value: Any) -> Any:
    """JSON으로 남길 수 있는 값으로 바꾼다(tool_calls.output·베이스라인 JSON에 넣는다)."""
    if isinstance(value, BaseModel):
        return plain(value.model_dump(mode="json"))
    if isinstance(value, dict):
        return {str(key): plain(item) for key, item in value.items()}
    if isinstance(value, (set, frozenset)):
        return sorted(plain(item) for item in value)
    if isinstance(value, (list, tuple)):
        return [plain(item) for item in value]
    if isinstance(value, (datetime, date)):
        return value.isoformat()
    if isinstance(value, Decimal):
        return float(value)
    return value
```

```python
"""녹화한 응답(명세 12장 `fixtures: "recorded"`). 모델·파일 저장소·Google 캘린더를 대신한다.

실제 호출로 바꿔 재는 것은 다음 일이다. 그때는 녹화 대신 진짜 클라이언트를 넣는다(fixtures 값을 늘린다).

from dataclasses import dataclass
from datetime import date, datetime, time, timedelta, timezone
from typing import Any

def tool_reply(name: str, **args: Any) -> ModelTurn:
    """도구 하나를 부르는 모델 답."""
    return ModelTurn(text=None, tool_calls=(ToolCall(name, args, id=f"{RECORDED}-{name}"),))


@dataclass
class Ask:
    """모델에 간 요청 하나. 시나리오가 무엇을 물었는지 확인할 때 쓴다."""

    model: str
    system: str | None
    turns: list[Turn]
    tools: list[str]
    force_tool: str | None

    @property
    def blobs(self) -> list[Any]:
        return [blob for turn in self.turns if isinstance(turn, UserTurn) for blob in turn.blobs]


Reply = ModelTurn | str | Callable[[Ask], ModelTurn | str]


class RecordedLlm:
    """녹화한 답을 차례로 돌려주는 모델. 답이 모자라면 시나리오가 실패한다."""

    provider = "google"

    def __init__(self, *replies: Reply, usage: Usage = RECORDED_USAGE) -> None:
        self.replies = list(replies)
        self.usage = usage
        self.asks: list[Ask] = []

    async def generate(
        self,
        *,
        model: str,
        system: str | None,
        turns: Sequence[Turn],
        tools: Sequence[ToolSpec] = (),
        thinking: str | None = None,
        max_output_tokens: int | None = None,
        force_tool: str | None = None,
    ) -> LlmReply:
        ask = Ask(model, system, list(turns), [tool.name for tool in tools], force_tool)
        self.asks.append(ask)
        if not self.replies:
            raise AssertionError(f"녹화한 답보다 모델을 더 많이 불렀어요(모델 {model})")
        reply = self.replies.pop(0)
        if callable(reply):
            reply = reply(ask)
        turn = ModelTurn(text=reply) if isinstance(reply, str) else reply
        return LlmReply(
            turn=turn, usage=self.usage, latency_ms=RECORDED_LATENCY_MS, finish_reason="STOP"
        )


class RecordedStorage(SupabaseStorage):
    """메모리에 담는 파일 저장소. 올린 파일을 그대로 내려준다."""

    def __init__(self) -> None:
        super().__init__(base_url=f"{RECORDED}://storage", bucket="uploads", service_key=RECORDED)
        self.files: dict[str, bytes] = {}
        self.removed: list[str] = []

    async def upload(self, path: str, data: bytes, content_type: str) -> None:
        self.files[path] = data

    async def download(self, path: str) -> bytes:
        if path not in self.files:
            raise StorageError("파일 저장소에 그 파일이 없어요.")
        return self.files[path]

    async def remove(self, path: str) -> None:
        self.files.pop(path, None)
        self.removed.append(path)


class RecordedCalendar(GoogleCalendarClient):

    """

    def __init__(self) -> None:
        super().__init__(
            api_base=f"{RECORDED}://google",
            token_url=f"{RECORDED}://google/token",
            client_id=RECORDED,
            client_secret=RECORDED,
        )
        self.events: dict[str, GoogleEvent] = {}
        self.titles: dict[str, str] = {}
        self.inserts = 0
        self.deletes: list[str] = []

        return f"{RECORDED}-access-token", 3600

        self.deletes.append(event_id)
```

```python
        """온통청년 정책 하나를 실제 변환 코드로 공고로 만든다(F-11, LLM 없음).

        숨기는 일(retire)까지 하므로, 시나리오가 만들지 않은 공고까지 건드린다. 요건은 같은 코드로

        source_id = await ensure_source(self.conn)
        record = convert(policy, self.today, region_table())

            raise AssertionError(f"녹화한 정책이 걸러졌어요: {record.reason}")
        assert isinstance(record, PolicyRecord)
        found = await self.conn.execute(
            "select id from opportunities where source_id = %s and external_id = %s",
            (source_id, record.external_id),
        )
        if await found.fetchone() is not None:
            raise AssertionError(
                f"이미 수집해 둔 정책({record.external_id})이에요. 시나리오 전용 번호를 쓰세요"
            )
        await save_policy(self.conn, source_id, record, await self.extraction_run())
        row = await (
            await self.conn.execute(
                "select id::text as id from opportunities where source_id = %s and external_id = %s",
                (source_id, record.external_id),
            )
        ).fetchone()
        assert row is not None
        self.opportunities.append(row["id"])
        return str(row["id"])

    async def rows(self, query: str, *params: Any) -> list[dict[str, Any]]:
        """확인용 조회. 시나리오가 화면으로 볼 수 없는 것(캘린더 행 수 등)을 셀 때만 쓴다."""
        return await (await self.conn.execute(query, params)).fetchall()

    async def close(self) -> None:
        """클라이언트를 닫는다. 하나가 실패해도 나머지를 닫는다."""
        for http in self._clients:
            try:
                await http.aclose()
            except Exception:
                logger.exception("클라이언트를 닫지 못했어요")
        self._clients.clear()

    async def cleanup(self) -> None:
        """사용자와 공고를 지운다. 실행 기록은 지표의 원천이라 남긴다(모듈 머리말).

        한 줄이 실패해도 나머지를 지우고, 오류를 올리지 않는다. 치우다 터지면 시나리오가 왜 실패했는지
        (CheckFailed)가 그 오류에 덮인다.
        """
        await self.close()
        statements: list[tuple[str, Sequence[Any]]] = []
        if self.opportunities:
            statements.append(
                ("delete from opportunities where id = any(%s::uuid[])", (self.opportunities,))
            )
        if self.users:
            # 시나리오가 API로 만든 포스터 공고. 번호를 모르니 올린 사람으로 찾는다
            statements.append(
                ("delete from opportunities where uploaded_by = any(%s::uuid[])", (self.users,))
            )
            statements.append(("delete from auth.users where id = any(%s::uuid[])", (self.users,)))
        if self._departments:
            statements.append(
                ("delete from departments where name = any(%s)", (self._departments,))
            )
        for query, params in statements:
            try:
                await self.conn.execute(query, params)
            except Exception:
                logger.exception("치우지 못한 것이 있어요: %s", query[:60])
```

```python
"""시나리오를 차례로 돌리고 성공률·응답시간·비용을 모은다(PRD 8장 지표).

시나리오 하나 = `agent_runs` 한 줄(trigger `eval`, scenario_code `S01`). 그 아래 `tool_calls`에
확인한 것을 `check` 한 줄씩 남긴다 — 다음 PR의 판정 혼동행렬이 이 줄을 읽는다.

시나리오가 뒤에서 만든 실행(준비하기·포스터 추출)은 끝난 뒤 같은 scenario_code를 붙인다. 비용과 LLM
호출 수는 **그 실행들의 `llm_calls`를 더해서** 센다. 시나리오 실행 행 자신의 cost_usd는 0으로 둔다
(제 손으로 모델을 부르지 않는다). 집계하는 쪽은 `agent_runs.cost_usd`를 다시 더하지 말고
scenario_code로 묶은 `llm_calls`를 본다 — 그러지 않으면 같은 비용을 두 번 센다.

시나리오는 한 번에 하나만 돈다. 사용자·공고를 만들고 지우는 동안 다른 시나리오가 끼어들면 피드에
남의 공고가 섞인다.
"""

from __future__ import annotations

import logging
import time
from collections.abc import Sequence
from datetime import datetime
from decimal import Decimal

import psycopg

from app.agent_log import agent_run, using
from app.config import Settings
from app.eligibility import KST
from app.eval.fakes import RecordedCalendar, RecordedLlm, RecordedStorage
from app.eval.models import CheckFailed, Report, ScenarioResult
from app.eval.world import (
    DEFAULT_NOW,
    EvalWorld,
    Scenario,
    connect,
    eval_settings,
    managed_database,
    open_app,
)

logger = logging.getLogger(__name__)
TRIGGER = "eval"
DRAIN_SECONDS = 60.0  # 뒤에서 도는 일을 기다리는 상한(app/main.py의 종료와 같은 뜻)


async def run_scenarios(
    database_url: str,
    scenarios: Sequence[Scenario],
    *,
    now: datetime = DEFAULT_NOW,
) -> Report:
    """시나리오를 차례로 돌린다. 하나가 실패해도 나머지를 돈다(성공률을 재는 것이 목적이다)."""
    if problem := managed_database(database_url):
        raise RuntimeError(problem)
    settings = eval_settings(database_url)
    setup = await connect(database_url)
    log_conn = await connect(database_url)
    # 단가는 돌린 날로 고른다(app/agent_log.py의 record_llm). 베이스라인을 비교할 때 이 날짜를 본다
    report = Report(now=now, priced_on=datetime.now(KST).date())
    try:
        for scenario in scenarios:
            result = await _one(scenario, settings=settings, setup=setup, log=log_conn, now=now)
            report.results.append(result)
    finally:
        for conn in (setup, log_conn):
            try:
                await conn.close()
            except Exception:
                logger.exception("연결을 닫지 못했어요")
    return report


async def _one(
    scenario: Scenario,
    *,
    settings: Settings,
    setup: psycopg.AsyncConnection,
    log: psycopg.AsyncConnection,
    now: datetime,
) -> ScenarioResult:
    llm, storage, calendar = RecordedLlm(), RecordedStorage(), RecordedCalendar()
    world: EvalWorld | None = None
    run_id: str | None = None
    children: list[str] = []
    elapsed_ms = 0
    ok, error = True, None
    try:
        app, pool, log_pool = await open_app(
            settings, now=now, llm=llm, storage=storage, calendar=calendar
        )
        try:
            async with agent_run(using(log), trigger=TRIGGER, scenario_code=scenario.code) as run:
                run_id = run.id
                world = EvalWorld(
                    conn=setup,
                    app=app,
                    settings=settings,
                    now=now,
                    run=run,
                    scenario_code=scenario.code,
                    llm=llm,
                    storage=storage,
                    calendar=calendar,
                )
                started = time.perf_counter()
                try:
                    await scenario.run(world)
                    await _finished(world)
                finally:
                    elapsed_ms = int((time.perf_counter() - started) * 1000)
                    # 뒤에서 도는 일(준비하기·포스터 추출)을 먼저 끝낸다. 확인이 틀려 중간에 멈췄으면
                    # 아직 도는 일이 있고, 그 일이 쥔 연결을 두고 풀을 닫으면 안 된다
                    await app.state.runner.drain(timeout=DRAIN_SECONDS)
                    children = world.extra_runs + await _tag_children(
                        setup, scenario.code, run.id, world.users
                    )
                    await world.cleanup()
                    _check_drained(app.state.runner.running, scenario.code)
        finally:
            await pool.close()
            await log_pool.close()
    except CheckFailed as exc:
        ok, error = False, str(exc)
    except Exception as exc:  # 시나리오가 터져도 나머지 시나리오를 돈다
        logger.exception("시나리오 %s가 터졌어요", scenario.code)
        ok, error = False, f"{type(exc).__name__}: {exc}"
    cost, calls = await _usage(setup, [run_id, *children] if run_id else children)
    return ScenarioResult(
        code=scenario.code,
        title=scenario.title,
        ok=ok,
        latency_ms=elapsed_ms,
        api_ms=round(world.api_ms, 1) if world else 0.0,
        run_id=run_id,
        child_run_ids=children,
        cost_usd=cost,
        llm_calls=calls,
        checks=list(world.checks) if world else [],
        error=error,
    )


async def _finished(world: EvalWorld) -> None:
    """시나리오가 끝났을 때 맞아야 하는 것. 조용히 통과하는 시나리오를 막는다."""
    if not world.checks:
        raise AssertionError("확인(check)이 하나도 없는 시나리오예요")
    if world.llm.replies:
        # 서류 사전이 늘어 모델을 안 부르게 되면 비용이 0이 되는데, 확인은 다 통과한다
        raise AssertionError(f"쓰지 않은 녹화 답이 {len(world.llm.replies)}개 남았어요")


def _check_drained(running: int, code: str) -> None:
    """뒤에서 도는 일을 못 끝냈으면 그 시나리오는 실패다. 비용이 빠지고 기록도 반쪽이 된다."""
    if running:
        raise TimeoutError(
            f"{code}: 뒤에서 도는 일 {running}개가 {DRAIN_SECONDS}초 안에 안 끝났어요"
        )


async def _tag_children(
    conn: psycopg.AsyncConnection, code: str, run_id: str, users: Sequence[str]
) -> list[str]:
    """시나리오가 돌면서 생긴 실행에 시나리오 번호를 붙인다. 붙인 실행 번호를 돌려준다.

    치우기 전에 불러야 한다. 사용자를 지우면 agent_runs.user_id가 null이 되어 더는 찾을 수 없다.
    실패해도 올리지 않는다(치우기를 막지 않게). 그 실행의 비용은 0으로 보인다.
    """
    if not users:
        return []
    try:
        rows = await (
            await conn.execute(
                # 시나리오 실행 자신은 user_id가 없어 걸리지 않지만 분명히 해 둔다
                "update agent_runs set scenario_code = %s where id <> %s and scenario_code is null"
                " and user_id = any(%s::uuid[]) returning id::text as id",
                (code, run_id, list(users)),
            )
        ).fetchall()
    except Exception:
        logger.exception("자식 실행에 시나리오 번호를 붙이지 못했어요: %s", code)
        return []
    return [row["id"] for row in rows]


async def _usage(conn: psycopg.AsyncConnection, run_ids: Sequence[str]) -> tuple[Decimal, int]:
    """시나리오 1회의 LLM 비용과 호출 수(실행 로그의 토큰 × 단가로 이미 계산된 값)."""
    if not run_ids:
        return Decimal(0), 0
    row = await (
        await conn.execute(
            "select coalesce(sum(cost_usd), 0) as cost, count(*) as calls from llm_calls"
            " where run_id = any(%s::uuid[])",
            (list(run_ids),),
        )
    ).fetchone()
    assert row is not None
    return Decimal(str(row["cost"])), int(row["calls"])
```

```python
async def s07(world: EvalWorld) -> None:
    """온통청년 정책, 판정 기준일에 만 34세 마지막 날 → 기준일 기준으로 정확히 판정.

    날짜는 모두 주입한 시계에서 센다 — --now를 바꿔도 같은 경계를 본다.

    나이는 프로필 값이라 tool_calls에 남기지 않는다(world.check 설명). 그래서 몇 살인지 대신
    "조건이 맞는가"로 확인한다.
    """
    basis = world.today
    birthday = _born_on_last_day(basis, YOUTH_MAX_AGE)
    last_day = await world.user(birth_date=birthday.isoformat())
    one_day_earlier = await world.user(birth_date=(birthday - timedelta(days=1)).isoformat())
    opportunity = await world.youth(
        youth_policy(
            plcyNo="eval-S07",
            plcyNm="청년 희망적금 매칭 지원",
            aplyPrdSeCd="0057001",  # 특정 기간
            aplyYmd=f"{basis - timedelta(days=41):%Y%m%d} ~ {basis:%Y%m%d}",
            sprtTrgtMinAge="19",
            sprtTrgtMaxAge=str(YOUTH_MAX_AGE),
        )
    )

    view = await _detail(world, world.client(last_day), opportunity)
    await world.check(
        "판정 기준일", expected=basis.isoformat(), actual=view["eligibility"]["basis_date"]
    )
    condition = view["eligibility"]["conditions"][0]
    await world.check("나이 조건", expected="age", actual=condition["field"])
    await world.check("나이 조건 충족", expected="pass", actual=condition["outcome"])
    # 보이는 나이도 맞아야 한다. 나이 자체는 남기지 않으므로 "맞는가"만 적는다
    await world.check(
        "보이는 나이",
        expected=True,
        actual=condition["user_value_text"] == f"만 {YOUTH_MAX_AGE}세",
    )
    await world.check(
        "만 34세 마지막 날", expected="eligible", actual=view["eligibility"]["status"]
    )

    older = await _detail(world, world.client(one_day_earlier), opportunity)
    await world.check(
        "하루 먼저 태어난 학생", expected="ineligible", actual=older["eligibility"]["status"]
    )
    await world.check(
        "하루 먼저 태어난 학생의 나이 조건",

        actual=older["eligibility"]["conditions"][0]["outcome"],
    )

        "하루 먼저 태어난 학생의 보이는 나이",

        actual=older["eligibility"]["conditions"][0]["user_value_text"]

    )

# ── 공통 ───────────────────────────────────────────────────────────────────


async def _detail(world: EvalWorld, client: httpx.AsyncClient, opportunity: str) -> dict:

def _born_on_last_day(on: date, age: int) -> date:
    """on 날짜에 만 age세인 마지막 날이 되도록 하는 생일(다음 날 age+1세가 된다)."""
    turns = on + timedelta(days=1)
    try:
        return turns.replace(year=turns.year - age - 1)

        return turns.replace(year=turns.year - age - 1, day=28)
```

```python
"""시나리오를 돌려 성공률·응답시간·비용을 찍는다(PRD 8장). api 폴더에서 실행한다.

async def main(argv: Sequence[str]) -> int:

def _print(report: Report) -> None:
    print()
    print(_row("번호", "결과", "확인", "응답시간", "비용(USD)", "시나리오"))
    for result in report.results:
        print(
            _row(
                result.code,
                RESULT[result.ok],
                str(len(result.checks)),
                f"{result.latency_ms}ms",
                f"{float(result.cost_usd):.6f}",
                result.title,
            )
        )
        if result.error:
            print(f"      └ {result.error}")
    rate = f"{report.success_rate * 100:.1f}%"
    print()
    print(
        f"통과 {report.passed}/{report.total}({rate}) ·"
        f" 응답시간 p50 {report.p50}ms · p95 {report.p95}ms ·"
        f" 그중 엔드포인트가 쓴 시간 합 {report.api_ms:.0f}ms ·"
        f" 비용 {float(report.cost_usd):.6f} USD({report.priced_on} 단가) ·"
        f" LLM 호출 {report.llm_calls}회"
    )
    print("실행 기록: agent_runs의 trigger_type = 'eval', scenario_code로 남았어요")


def _row(code: str, result: str, checks: str, latency: str, cost: str, title: str) -> str:
    """표 한 줄. 한글은 두 칸을 차지하므로 글자 수가 아니라 보이는 너비로 맞춘다."""
    return "  ".join(
        (
            _cell(code, 4),
            _cell(result, 4),
            _cell(checks, 4, right=True),
            _cell(latency, 8, right=True),
            _cell(cost, 9, right=True),
            title,
        )
    )


def _cell(text: str, width: int, *, right: bool = False) -> str:
    gap = " " * max(width - _width(text), 0)
    return gap + text if right else text + gap


def _width(text: str) -> int:
    return sum(2 if unicodedata.east_asian_width(char) in "WF" else 1 for char in text)


def _codes(raw: str | None) -> list[str] | None:
    """--scenarios. 주지 않으면 None(전부), 쉼표만 적었으면 빈 목록이라 pick이 거절한다."""
    if raw is None:
        return None
    return [part.strip().upper() for part in raw.split(",") if part.strip()]


def _moment(raw: str | None) -> datetime:
    """--now. 시간대를 적지 않으면 KST로 본다."""
    if not raw:
        return DEFAULT_NOW
    try:
        moment = datetime.fromisoformat(raw)
    except ValueError as exc:
        raise ValueError(f"--now를 읽지 못했어요: {raw} (예: 2026-10-12T09:00:00+09:00)") from exc
    return moment if moment.tzinfo else moment.replace(tzinfo=KST)


if __name__ == "__main__":
    utf8_output()  # 출력을 파이프로 보낼 때 cp949에 없는 글자에서 멈추지 않게(Windows)
    sys.exit(asyncio.run(main(sys.argv[1:]), loop_factory=event_loop_factory()))
```

```python
"""요청이 끝난 뒤 이어서 할 일(준비하기 실행). API 명세 2장의 202 + run_id 작업이 쓴다.

FastAPI BackgroundTasks는 요청의 의존성(DB 연결·트랜잭션)이 그 일을 마칠 때까지 닫히지 않아 프로필 잠금을
붙잡는다. 그래서 요청과 따로 asyncio 작업으로 돌리고, 일은 자기 연결을 따로 연다.
테스트는 InlineRunner로 바꿔 응답 전에 끝까지 돌린다.
"""

import asyncio
import logging
from collections.abc import Coroutine
from typing import Annotated, Any

from fastapi import Depends, Request

logger = logging.getLogger(__name__)


class TaskRunner:
    def __init__(self) -> None:
        self._tasks: set[asyncio.Task[None]] = set()

    async def start(self, job: Coroutine[Any, Any, None]) -> None:
        """일을 띄우고 바로 돌아온다. 일 안의 예외는 일이 스스로 기록한다(여기서는 로그만)."""
        task = asyncio.create_task(job)
        self._tasks.add(task)
        task.add_done_callback(self._finished)

    def _finished(self, task: asyncio.Task[None]) -> None:
        self._tasks.discard(task)
        if not task.cancelled() and (error := task.exception()) is not None:
            logger.error("뒤에서 돌던 일이 실패했어요: %r", error)

    @property
    def running(self) -> int:
        """아직 돌고 있는 일의 수. drain이 끝나도 0이 아니면 못 끝낸 일이 있다."""
        return len(self._tasks)

    async def drain(self, timeout: float) -> None:
        """서버를 끌 때 돌던 일을 timeout초까지 기다린다. 못 끝낸 일은 다음 요청이 멈춘 실행으로 본다."""
        if self._tasks:
            await asyncio.wait(set(self._tasks), timeout=timeout)


class InlineRunner(TaskRunner):
    """테스트용: 일을 그 자리에서 끝까지 돌린다."""

    async def start(self, job: Coroutine[Any, Any, None]) -> None:
        await job


def get_runner(request: Request) -> TaskRunner:
    return request.app.state.runner


RunnerDep = Annotated[TaskRunner, Depends(get_runner)]
```
