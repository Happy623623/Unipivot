# 플래너 — 할 일 조회·추가·수정·삭제와 서류 체크 (F-43)

> 📝 기준: PRD v0.9 F-43 · API 명세 v0.4 7장 · ERD v0.9 · 2026-10-15
>
> 기준 커밋: main `3086058`(#29 실행 로그 연결). 준비하기(#27)가 만든 할 일이 드디어 플래너에 보인다

준비하기가 만든 할 일이 DB에는 쌓이는데 화면에서는 목데이터만 보였다. 이번에 `GET/POST/PATCH/DELETE /planner/tasks`를 만들고, 플래너 화면과 공고 상세의 "서류 체크"를 실제 API에 연결했다. 이것으로 **공고를 보고 → 준비 일정을 만들고 → 서류를 하나씩 체크하는 흐름이 끝까지 돈다.**

**규모와 확인:**
- api 새 파일 5개(스키마·저장소·라우터·테스트 2개), 바꾸는 파일 3개. web 바꾸는 파일 6개. 새 web 파일은 없다.
- **DB 변경이 없다.** `planner_tasks`는 이미 있고 준비하기가 쓰고 있다. 합친 뒤 db push가 필요 없다.
- 새 에러 코드가 없다. `FIELD_READ_ONLY`·`TASK_NOT_DELETABLE`·`VALIDATION_FAILED`·`NOT_FOUND` 모두 명세 13장 표에 있다.
- api `ruff` 통과, `567 passed, 83 skipped`(DB 없이) · `650 passed`(새 DB). **`TZ=UTC`로 돌려도 `650 passed`다**(CI가 UTC라 일부러 봤다). web `typecheck`·`build` 통과(라우트 11개).
- 실제 모드 E2E 6단계, 목 모드 3가지를 돌렸다. 되돌림 시험(변이) api 8가지·web 1가지가 모두 잡혔다.
- 따로 띄운 검토 에이전트가 한 번 봤다. 막아야 할 문제 2건과 고치면 좋은 것 7건을 고쳤고, 남은 4건은 "남은 것"에 적었다.

## 정한 것

| 항목 | 정한 것 | 이유 |
| --- | --- | --- |
| 고칠 수 있는 범위 | 출처마다 다르다. **직접 추가(manual)**: 제목·날짜·완료 + 삭제. **준비·강의계획서**: 날짜·완료만(제목 고정, 삭제 불가). **LMS**: 완료만 | 10/15 선택. 명세 7장은 준비 할 일의 제목까지 열려 있고 PRD F-43은 "직접 추가한 항목만 수정"이라 서로 달랐다. 서류 발급이 밀리면 날짜는 옮겨야 하고, 제목은 공고의 서류 이름이라 바꾸면 무엇을 준비하는지 흐려진다. **두 문서를 이 문구로 맞춘다** |
| 막힌 항목이 섞이면 | 하나라도 막혀 있으면 `400 FIELD_READ_ONLY`로 **아무것도 바꾸지 않는다**. `details.fields`에 막힌 항목 이름을 담는다 | 절반만 저장되면 화면과 서버가 어긋난다 |
| 모르는 항목 | `422`다(`extra="forbid"`). `{"titel": …}` 같은 오타를 조용히 넘기지 않고, `source`·`is_done`을 직접 정해 만들 수도 없다 | 레포의 다른 PATCH 본문과 같다 |
| 빈 본문 | `422`다(바꿀 것이 없다) | 아무것도 안 하는 요청을 200으로 돌려주면 화면이 저장됐다고 믿는다 |
| 기간 | `from`·`to`는 KST 날짜다. 끝이 시작보다 앞서면 422, 한 번에 **400일**까지다 | 달력은 한 달이지만 앞뒤 칸까지 받는다. 상한은 실수로 몇 년을 받지 않게 둔다 |
| 완료한 할 일 | 기본으로 함께 준다(`include_done` 기본 true) | 체크한 할 일이 화면에서 사라지면 안 된다 |
| 마커 | 체크할 수 없는 표시 항목이고, **준비를 마친 공고의 마감일**이다. 공고 상세의 `prepared`와 같은 기준(`PREP_DONE`)을 쓴다 | 실행 중이거나 멈춘 계획까지 넣으면, 상세는 "준비 안 함"인데 플래너에는 마감이 떠 두 화면이 어긋난다(검토 지적) |
| 마커 날짜 | `deadline_at`(UTC)을 **KST 날짜**로 바꿔 넣는다 | 23:00 KST 마감이 UTC로는 전날이다. 테스트도 KST로 센다 |
| 서류 체크 | 그 서류에 걸린 할 일을 완료로 바꾸고(`PATCH /planner/tasks/{task_id}`) 공고 상세를 다시 받아 진행률을 맞춘다. 준비 전에는 할 일이 없어 체크할 수 없다 | 서류 체크와 플래너 체크가 같은 행이다(ERD). 한쪽에서 체크하면 다른 쪽에도 보인다 |
| 할 일이 없는 서류 | 체크를 막고 "공고에 나중에 추가된 서류예요. 준비 일정에 없어서 체크할 수 없어요"라고 알린다 | 준비한 뒤 공고를 다시 수집해 서류가 붙으면(#28) 그 서류에는 할 일이 없다. 지금은 다시 준비하는 길이 없어 "다시 만들면 된다"고 하면 거짓말이다(검토 지적). 고치는 방법은 "남은 것"에 적었다 |
| 남의 할 일 | 읽기·수정·삭제 모두 `user_id` 조건을 건다. 남의 할 일과 없는 할 일은 똑같이 404다 | 서버가 서비스 권한으로 붙어 RLS가 막아주지 않는다(api/CLAUDE.md). 있는지조차 알려주지 않는다 |
| 저장 실패 | 화면은 그대로 두고 안내를 띄운다. 일정 추가·수정 창은 **닫지 않는다** | 창이 닫히면 저장된 것처럼 보이는데 목록은 그대로다(검토 지적) |
| 목 모드 | 실제 API와 같은 규칙을 지킨다(LMS 할 일은 옮기지 못한다) | 목에서 되던 것이 실제에서 막히면 화면을 두 번 고치게 된다 |

## 합친 뒤 확인

1. **API 다시 띄우기:** `http://localhost:8000/docs`에 `GET/POST /api/v1/planner/tasks`와 `PATCH/DELETE /api/v1/planner/tasks/{task_id}`가 보여야 한다.
2. **준비 → 플래너:** 공고를 준비하고 "플래너에서 보기"를 누른다. 캘린더의 그 날 칸에 카테고리 칩이 뜨고, 그 날을 누르면 "○○ 준비"와 "신청 제출"이 보인다. 마감일 칸에는 테두리만 있는 "○○ 마감" 칩이 있다.
3. **서류 체크:** 공고 상세에서 서류를 체크하면 "서류 n/N 완료"가 오르고, 플래너의 그 할 일도 체크돼 있다. 반대로 플래너에서 체크해도 상세에 보인다.
4. **준비 할 일:** ⋯ 메뉴에 "날짜 옮기기"만 있고 삭제가 없다. 눌러 보면 제목은 바꿀 수 없다고 알린다.
5. **직접 추가:** "+ 일정 추가"로 만들고, ⋯ 메뉴에서 수정·삭제가 모두 된다.
6. **달 넘기기:** 이전·다음 달로 넘겨도 그 달 할 일이 보이고, 달력 첫 줄·마지막 줄의 앞뒤 달 날짜에도 칩이 보인다.

### 검토에서 고친 것

| 지적 | 고친 것 |
| --- | --- |
| **(막아야 함)** 준비한 뒤 공고에 새로 생긴 서류에 "준비 일정을 다시 만들면 체크할 수 있어요"라고 하는데, 이미 준비한 공고는 다시 누르면 200과 기존 실행만 돌아와 할 일이 끝까지 안 생긴다. 할 수 없는 행동을 시킨다 | 문구를 사실대로 바꿨다("공고에 나중에 추가된 서류예요. 준비 일정에 없어서 체크할 수 없어요"). 제대로 채우는 방법은 "남은 것"에 적었다 |
| **(막아야 함)** DB 테스트가 `.astimezone()`(머신 시간대)으로 날짜를 세서, CI가 UTC면 하루의 37%(15:00~24:00 UTC)에 깨진다. 그래서 마커의 KST 변환이 사실상 테스트되지 않는다 | `world.now.astimezone(KST).date()`로 바꾸고, UTC로는 전날인 마감(2026-10-24 15:30 UTC = 10-25 00:30 KST)이 KST 날짜에 찍히는지 보는 테스트를 더했다. `TZ=UTC`로 전체를 돌려 확인했다 |
| 마커가 "준비를 마친 계획" 기준을 안 써서, 상세는 "준비 안 함"인데 플래너에만 마감이 뜬다 | 상세와 같은 `PREP_DONE`을 쓴다. 실행 중인 계획은 마커가 없고, 성공하면 생기는 테스트를 더했다 |
| 수정 SQL이 컬럼 이름을 f-string으로 끼운다(레포 규칙은 `sql.Identifier`) | `sql.Identifier` + `sql.Placeholder`로 바꿨다(지금도 주입은 불가능했지만 안전이 호출자에만 달려 있었다) |
| 요청 본문이 모르는 항목을 조용히 무시한다(`{"titel": "오타"}` → 200) | `extra="forbid"`를 달았다. `source`·`is_done`을 직접 정해 만들 수도 없다 |
| 플래너의 저장 실패가 안내만 남기고 **창을 닫는다.** 안내도 650px 패널 아래라 화면 밖이다 | 토스트로 바꾸고(공고 상세와 같다), 실패하면 창을 닫지 않는다 |
| 저장 전에 선택 날짜를 먼저 옮겨서, 실패해도 보던 날이 바뀐다 | 저장이 끝난 뒤에 옮긴다 |
| 달력은 앞뒤 달 날짜까지 그리는데 받는 기간은 그 달뿐이라, 그 칸의 할 일·마감이 안 보인다 | 앞뒤 7일을 더 받는다 |
| 체크박스를 연타하면 응답 순서가 엇갈린다 | 저장하는 동안 그 체크박스를 잠근다 |
| 목 모드의 `moveStoredTask`가 출처를 안 봐서 LMS 할 일도 옮긴다 | 실제 API처럼 막는다 |
| 저장소의 `update`가 `assert`라 단독으로 부르면 500이 난다 | 404 `NOT_FOUND`로 바꿨다 |
| 할 일 조회의 `left join prep_plans`에 `user_id` 조건이 없다(새는 길은 없지만 앱 코드만 믿는다) | 조인에도 `p.user_id = t.user_id`를 걸었다 |

## 남은 것

- **준비한 뒤 생긴 서류는 체크할 수 없다.** 공고를 다시 수집해 서류가 붙으면(#28) 그 서류에는 할 일이 없다. 고치려면 준비하기가 "계획에 없는 서류"를 찾아 할 일을 채우게 하거나, 상세에 "준비 일정 새로 고치기"를 둬야 한다. 준비하기 쪽을 건드리는 일이라 따로 한다.
- **상시 공고는 마커가 없다.** 마커를 `opportunities.deadline_at`에서 읽는데 상시 공고는 그 값이 없고, 학생이 고른 목표일을 담을 자리가 `prep_plans`에 없다(ERD 변경이 필요하다). 할 일은 그대로 보인다.
- **`POST /planner/tasks`의 날짜 상한이 없다.** `9999-12-31`도 받는다. 달력은 그 달만 받아서 화면에서는 안 보인다.
- **목 모드로는 에러 분기를 못 본다.** `FIELD_READ_ONLY`·`TASK_NOT_DELETABLE`·404는 실제 모드에서만 밟힌다. web에 테스트 러너가 없어(`npm test`가 `exit 1`) 화면 규칙은 E2E로만 확인한다.
- **서류 체크마다 공고 상세를 다시 받는다.** 그 호출은 지금 프로필로 다시 판정하고 "최근 본 시각"도 갱신한다(명세 5장). 진행률만 필요한데 가장 무거운 호출이라, 진행률만 주는 응답을 둘지는 측정하고 정한다(W9–10).
- **캘린더(F-32)는 다음 PR이다.** 플래너 아래 "Google Calendar 연결 안 됨" 칸은 설정으로 보내기만 한다.

```python
"""플래너 할 일 SQL (F-43, API 명세 7장).

할 일은 사용자 것만 읽고 쓴다(서버가 서비스 권한으로 붙어 RLS가 막아주지 않는다). 공고에서 온 할 일은
공고 제목·카테고리를 같이 읽어 화면의 칩에 쓴다. 마커는 준비를 마친 공고의 마감일이다(공고 상세의 prepared와 같은 기준:
실행이 성공했거나 실행 기록이 없는 계획). 실행 중이거나 멈춘 계획은 상세가 준비하지 않은 것으로 보여서,
플래너에만 마감이 뜨면 두 화면이 어긋난다. 강의계획서·LMS 할 일은 그 기능(F-14·F-51)이 생기면 같은 표에 쌓인다.
"""

from dataclasses import dataclass
from datetime import date
from typing import Annotated, Any

from fastapi import Depends
from psycopg import AsyncConnection, sql

from app.db import get_conn
from app.errors import ApiError
from app.repositories.opportunities import PREP_DONE
from app.schemas.planner import PlannerLink, PlannerMarker, PlannerResponse, PlannerTask

# 공고에서 온 할 일은 계획 → 공고로 이어 제목·카테고리를 읽는다. 나머지 출처는 아직 연결 대상이 없다
_TASK = (
    "select t.id::text as id, t.title, t.due_date, coalesce(t.is_done, false) as is_done,"
    " t.source::text as source, o.id::text as opportunity_id, o.title as opportunity_title,"
    " o.category::text as category"
    " from planner_tasks t"
    " left join prep_plans p on p.id = t.prep_plan_id and p.user_id = t.user_id"
    " left join opportunities o on o.id = p.opportunity_id"
)


def _task(row: dict[str, Any]) -> PlannerTask:
    link = PlannerLink(
        type="opportunity" if row["opportunity_id"] else None,
        id=row["opportunity_id"],
        title=row["opportunity_title"],
        category=row["category"],
    )
    return PlannerTask(
        id=row["id"],
        title=row["title"],
        due_date=row["due_date"],
        is_done=row["is_done"],
        source=row["source"],
        link=link,
    )


@dataclass(frozen=True)
class TaskRow:
    id: str
    source: str
    is_done: bool


class PlannerRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def tasks(
        self, user_id: str, *, start: date, end: date, include_done: bool
    ) -> PlannerResponse:
        """기간 안의 할 일과 마커. 날짜 → 만든 순으로 준다(화면이 날짜별로 묶는다)."""
        where = " where t.user_id = %(user)s and t.due_date between %(start)s and %(end)s"
        if not include_done:
            where += " and coalesce(t.is_done, false) = false"
        params = {"user": user_id, "start": start, "end": end}
        rows = await (
            await self.conn.execute(
                _TASK + where + " order by t.due_date, t.sort_order, t.created_at, t.id", params
            )
        ).fetchall()
        markers = await (
            await self.conn.execute(
                "select distinct o.id::text as opportunity_id, o.title,"
                " (o.deadline_at at time zone 'Asia/Seoul')::date as date,"
                " o.category::text as category"
                " from prep_plans p join opportunities o on o.id = p.opportunity_id"
                " where p.user_id = %(user)s and " + PREP_DONE + " and o.deadline_at is not null"
                " and (o.deadline_at at time zone 'Asia/Seoul')::date"
                " between %(start)s and %(end)s"
                " order by date, title",
                params,
            )
        ).fetchall()
        return PlannerResponse(
            items=[_task(row) for row in rows],
            markers=[
                PlannerMarker(
                    date=row["date"],
                    title=f"{row['title']} 마감",
                    opportunity_id=row["opportunity_id"],
                    category=row["category"],
                )
                for row in markers
            ],
        )

    async def task(self, user_id: str, task_id: str) -> TaskRow | None:
        """고치기·지우기 전에 보는 행. 남의 할 일은 None이다(없는 것과 같이 다룬다)."""
        row = await (
            await self.conn.execute(
                "select id::text as id, source::text as source,"
                " coalesce(is_done, false) as is_done"
                " from planner_tasks where id = %s and user_id = %s for update",
                (task_id, user_id),
            )
        ).fetchone()
        return None if row is None else TaskRow(row["id"], row["source"], row["is_done"])

    async def add(self, user_id: str, title: str, due_date: date) -> PlannerTask:
        row = await (
            await self.conn.execute(
                "insert into planner_tasks (user_id, source, title, due_date)"
                " values (%s, 'manual', %s, %s) returning id",
                (user_id, title, due_date),
            )
        ).fetchone()
        assert row is not None  # insert ... returning은 늘 한 행이다
        found = await self.one(user_id, str(row["id"]))
        assert found is not None
        return found

    async def update(self, user_id: str, task_id: str, changes: dict[str, Any]) -> PlannerTask:
        """보낸 필드만 바꾼다. 완료로 바뀌면 done_at을 찍고, 풀면 지운다."""
        sets = [
            sql.SQL("{} = {}").format(sql.Identifier(name), sql.Placeholder(name))
            for name in changes
        ]
        if "is_done" in changes:
            sets.append(
                sql.SQL("done_at = case when {} then now() else null end").format(
                    sql.Placeholder("is_done")
                )
            )
        await self.conn.execute(
            sql.SQL(
                "update planner_tasks set {sets} where id = %(id)s and user_id = %(user)s"
            ).format(sets=sql.SQL(", ").join(sets)),
            {**changes, "id": task_id, "user": user_id},
        )
        found = await self.one(user_id, task_id)
        if found is None:  # 그새 지워졌다(계획이 cascade로 지워지는 등)
            raise ApiError(404, "NOT_FOUND", "할 일을 찾을 수 없어요.")
        return found

    async def remove(self, user_id: str, task_id: str) -> None:
        await self.conn.execute(
            "delete from planner_tasks where id = %s and user_id = %s", (task_id, user_id)
        )

    async def one(self, user_id: str, task_id: str) -> PlannerTask | None:
        row = await (
            await self.conn.execute(
                _TASK + " where t.id = %(id)s and t.user_id = %(user)s",
                {"id": task_id, "user": user_id},
            )
        ).fetchone()
        return None if row is None else _task(row)


def get_planner_repo(conn: Annotated[AsyncConnection, Depends(get_conn)]) -> PlannerRepository:
    return PlannerRepository(conn)


PlannerRepoDep = Annotated[PlannerRepository, Depends(get_planner_repo)]
```

```python
# 출처별로 고칠 수 있는 항목(API 명세 7장). 빈 집합이면 아무것도 못 고친다
EDITABLE: dict[str, set[str]] = {
    "manual": {"title", "due_date", "is_done"},
    # 준비 할 일은 날짜만 옮긴다. 제목은 공고의 서류 이름이라 고정이고, 지우려면 준비를 다시 한다
    "prep_plan": {"due_date", "is_done"},
    "syllabus": {"due_date", "is_done"},
    # LMS 과제·공지는 LMS가 기준이라 완료만 바꾼다(F-51)
    "lms_assignment": {"is_done"},
    "lms_announcement": {"is_done"},
}


@router.get("/tasks", response_model=PlannerResponse)
async def read_tasks(
    user: CurrentUserDep,
    repo: PlannerRepoDep,
    from_: str = Query(alias="from", description="YYYY-MM-DD"),
    to: str = Query(description="YYYY-MM-DD"),
    include_done: bool = True,
) -> PlannerResponse:
    """기간 안의 할 일과 마커(준비 중인 공고의 마감일). 날짜는 KST다."""
    start, end = _day(from_, "from"), _day(to, "to")
    if end < start:
        raise _invalid({"to": "끝 날짜는 시작 날짜보다 뒤여야 해요."})
    if (end - start).days + 1 > MAX_DAYS:
        raise _invalid({"to": f"한 번에 {MAX_DAYS}일까지 받을 수 있어요."})
    return await repo.tasks(user.id, start=start, end=end, include_done=include_done)


@router.post("/tasks", status_code=201, response_model=PlannerTask)
async def add_task(
    body: PlannerTaskCreate, user: CurrentUserDep, repo: PlannerRepoDep
) -> PlannerTask:
    """직접 추가(source = manual)."""
    return await repo.add(user.id, body.title, body.due_date)


@router.patch("/tasks/{task_id}", response_model=PlannerTask)
async def change_task(
    task_id: UUID, body: PlannerTaskPatch, user: CurrentUserDep, repo: PlannerRepoDep
) -> PlannerTask:
    """보낸 필드만 바꾼다. 출처가 허락하지 않는 항목이면 400 FIELD_READ_ONLY다."""
    asked = body.fields()
    if not asked:
        raise _invalid({"body": "바꿀 내용을 적어 주세요."})
    task = await repo.task(user.id, str(task_id))
    if task is None:
        raise ApiError(404, "NOT_FOUND", NOT_FOUND)
    locked = sorted(asked - EDITABLE.get(task.source, set()))
    if locked:
        raise ApiError(
            400,
            "FIELD_READ_ONLY",
            _read_only_message(task.source),
            {"fields": locked},
        )
    return await repo.update(user.id, task.id, {name: getattr(body, name) for name in asked})


@router.delete("/tasks/{task_id}", status_code=204, response_class=Response)
async def remove_task(task_id: UUID, user: CurrentUserDep, repo: PlannerRepoDep) -> Response:
    """직접 추가한 할 일만 지운다. 나머지는 400 TASK_NOT_DELETABLE이다."""
    task = await repo.task(user.id, str(task_id))
    if task is None:
        raise ApiError(404, "NOT_FOUND", NOT_FOUND)
    if task.source != "manual":
        raise ApiError(400, "TASK_NOT_DELETABLE", _not_deletable_message(task.source))
    await repo.remove(user.id, task.id)
    return Response(status_code=204)


def _day(value: str, field: str) -> date:
    try:
        return date.fromisoformat(value)
    except ValueError:
        raise _invalid({field: "날짜를 YYYY-MM-DD로 적어 주세요."}) from None


def _invalid(fields: dict[str, str]) -> ApiError:
    return ApiError(422, "VALIDATION_FAILED", "입력값을 확인해 주세요.", {"fields": fields})


def _read_only_message(source: str) -> str:
    if source == "prep_plan":
        return "준비 일정으로 만든 할 일은 날짜만 옮길 수 있어요."
    if source == "syllabus":
        return "강의계획서에서 온 할 일은 날짜만 옮길 수 있어요."
    return "LMS에서 가져온 할 일은 완료만 바꿀 수 있어요."


def _not_deletable_message(source: str) -> str:
    if source == "prep_plan":
        return "준비 일정으로 만든 할 일은 지울 수 없어요. 공고 상세에서 확인해 주세요."
    return "직접 추가한 할 일만 지울 수 있어요."
```

```python
        " o.apply_start_at, o.source_type::text as source_type,"
        " e.user_id is not null as had_result, e.status::text as old_status,"
        " e.missing_fields as old_missing, " + _REQUIREMENTS_JSON + " as requirements"
        " from opportunities o"
        + _COURSE_JOIN
        + _RESULT_JOIN
        + " where"
        + scope
        + " and"
        + _VISIBLE
        + " and o.extraction_run_id is not null"
        " and (%(force)s or e.user_id is null or e.evaluated_at is null"
        " or e.requirements_version <> o.requirements_version"
        " or e.engine_version <> %(engine)s"
        # 날이 바뀌면 다시: 기준일이 "오늘"인 공고(청년정책 포함), 엔진 오류로 판정하지 못한 공고(오류를
        # 고쳤을 수 있다)
        " or (((o.eligibility_basis_date is null and (o.deadline_at is null"
        " or (o.source_type = 'youth_policy' and o.deadline_at >= %(now)s)))"
        " or e.reason_text = %(engine_error)s)"
        " and (e.evaluated_at at time zone 'Asia/Seoul')::date < %(today)s))"
    )

@dataclass(frozen=True)
class Cursor:
    scope: str  # 목록 조건(정렬·필터)의 지문. 조건이 다른 목록에는 쓸 수 없다
    # 마지막 행의 정렬 값(deadline: 마감 시각, recent: 등록 시각). 없을 수 있다
    value: datetime | None
    id: str


@dataclass(frozen=True)
class FeedQuery:
    eligibility: frozenset[str] | None = None  # None이면 전체
    categories: tuple[str, ...] | None = None
    source_types: tuple[str, ...] | None = None
    sort: Sort = "deadline"
    include_expired: bool = False
    include_not_interested: bool = False  # 관심 없음 공고도 준다(F-45)
    limit: int = 20
    cursor: Cursor | None = None

    def scope(self) -> str:
        """cursor를 묶는 목록 조건의 지문. 정렬이나 필터를 바꾸면 목록을 처음부터 다시 부른다.

        같은 목록이면 지문도 같다: 값의 순서는 보지 않고, 모든 값을 고른 필터는 필터 없음과 같다.
        """
        parts = (
            self.sort,
            _filter_key(self.eligibility, ELIGIBILITY_STATUSES),
            _filter_key(self.categories, CATEGORIES),
            _filter_key(self.source_types, SOURCE_TYPES),
            str(self.include_expired),
            str(self.include_not_interested),
        )
        return hashlib.sha256("|".join(parts).encode()).hexdigest()[:16]


def _filter_key(values: Collection[str] | None, everything: Collection[str]) -> str:
    chosen = set(values or ())
    return "" if chosen >= set(everything) else ",".join(sorted(chosen))


@dataclass(frozen=True)
class FeedPage:
    items: list[OpportunityItem]
    next_cursor: str | None


@dataclass(frozen=True)
class Refresh:
    judged: int  # 다시 계산한 공고 수
    changed: int  # 라벨이 바뀐 공고 수(전에 판정이 있던 공고만 센다)


def display_status(status: str, missing_fields: Sequence[str]) -> str:
    """화면 라벨 4종. 판정 불가는 입력하면 바뀔 수 있으면 정보 필요, 아니면 원문 확인 필요다."""
    if status == "undetermined":
        return "missing_info" if missing_fields else "needs_review"
    return status


def encode_cursor(cursor: Cursor) -> str:
    data = {
        "q": cursor.scope,
        "v": cursor.value.isoformat() if cursor.value else None,
        "id": cursor.id,
    }
    raw = json.dumps(data, separators=(",", ":")).encode()
    return base64.urlsafe_b64encode(raw).decode().rstrip("=")


def decode_cursor(text: str) -> Cursor:
    """next_cursor로 준 값을 되돌린다. 모양이 틀리면 ValueError."""
    try:
        data = json.loads(base64.urlsafe_b64decode(text + "=" * (-len(text) % 4)))
        scope, value, ident = data["q"], data["v"], data["id"]
        if not isinstance(scope, str) or not isinstance(ident, str):
            raise ValueError(scope)
        moment = None if value is None else datetime.fromisoformat(value)
        if moment is not None and moment.tzinfo is None:
            raise ValueError(value)
        return Cursor(scope=scope, value=moment, id=str(uuid.UUID(ident)))
    except (binascii.Error, ValueError, KeyError, TypeError, UnicodeDecodeError) as exc:
        raise ValueError("잘못된 cursor") from exc


class OpportunityRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def refresh_judgments(
        self,
        user_id: str,
        *,
        now: datetime,
        force: bool = False,
        include_expired: bool = False,
        display_name: str | None = None,
    ) -> Refresh:
        """피드에 나올 공고(include_expired면 지난 공고까지)의 낡은 판정을 다시 계산해 저장한다.

        force면 그 공고를 모두 다시 판정하고 나머지 공고의 판정은 지운다.
        프로필 행이 없으면(첫 요청이 피드) display_name과 함께 만든다.
        """
        profile = Profile.from_row(await self._lock_profile(user_id, display_name))
        today = now.astimezone(KST).date()
        stale = await (
            await self.conn.execute(
                _stale_sql(_WITH_EXPIRED if include_expired else _ACTIVE),
                {
                    "uid": user_id,
                    "now": now,
                    "force": force,
                    "engine": ENGINE_VERSION,
                    "engine_error": ENGINE_ERROR_SUMMARY,
                    "today": today,
                },
            )
        ).fetchall()
        payload: list[dict[str, Any]] = []
        changed = 0
        if stale:
            departments = await self._departments()
            for item in stale:
                judged = _judge(item, profile, departments, today)
                payload.append(_payload(item, judged.stored))
                old = display_status(item["old_status"] or "", item["old_missing"] or ())
                if item["had_result"] and old != judged.label:
                    changed += 1
        await self._upsert(user_id, payload, now)
        if force:  # 다시 판정하지 않은 공고(마감·숨김·안 보임)의 판정은 지운다
            await self.conn.execute(
                "delete from eligibility_results"
                " where user_id = %s and opportunity_id <> all(%s::uuid[])",
                (user_id, [item["opportunity_id"] for item in payload]),
            )
        else:  # 요건 추출에 실패한 공고의 옛 판정은 지운다(판정하지 않는다)
            await self.conn.execute(
                "delete from eligibility_results e using opportunities o"
                " where e.user_id = %s and e.opportunity_id = o.id and o.extraction_run_id is null",
                (user_id,),
            )
        return Refresh(judged=len(payload), changed=changed)

    async def detail(
        self,
        user_id: str,
        opportunity_id: str,
        *,
        now: datetime,
        display_name: str | None = None,
    ) -> OpportunityDetail | None:
        """공고 상세(S1-6). 이 사용자에게 보이지 않는 공고면 None이다.

        피드와 같은 잠금 아래에서 그 공고를 다시 판정해 저장하고, 조회 기록을 남긴다(is_new가 꺼진다).
        """
        profile_row = await self._lock_profile(user_id, display_name)
        row = await (
            await self.conn.execute(_DETAIL, {"uid": user_id, "oid": opportunity_id})
        ).fetchone()
        if row is None:
            return None
        if row["extraction_run_id"] is None:  # 요건 추출에 실패한 공고는 판정하지 않는다
            await self.conn.execute(
                "delete from eligibility_results where user_id = %s and opportunity_id = %s",
                (user_id, opportunity_id),
            )
            eligibility = DetailEligibility(
                status="undetermined",
                display_status="needs_review",
                reason_text=UNJUDGED_SUMMARY,
                basis_date=None,
                requirements_version=row["requirements_version"],
                missing_fields=[],
                clauses=[],
                conditions=[],
                evaluated_at=None,
            )
        else:
            profile = Profile.from_row(profile_row)
            departments = await self._departments()
            judged = _judge(row, profile, departments, now.astimezone(KST).date())
            await self._upsert(user_id, [_payload(row, judged.stored)], now)
            eligibility = _detail_eligibility(
                judged, profile, departments, row["requirements_version"], now
            )
        await self.conn.execute(_VIEW, (user_id, opportunity_id, now, now))
        names = {item["seq"]: item["file_name"] for item in row["attachments"]}
        apply_start: datetime | None = row["apply_start_at"]
        deadline: datetime | None = row["deadline_at"]
        confidence = row["extraction_confidence"]
        return OpportunityDetail(
            id=str(row["id"]),
            title=row["title"],
            organizer=row["organizer"],
            category=row["category"],
            source_type=row["source_type"],
            status=row["status"],
            original_url=row["original_url"],
            poster_url=None,  # TODO(W6): 포스터 업로드에서 Storage 서명 URL(5분)을 붙인다
            easy_summary=row["easy_summary"],
            apply_start_at=apply_start.astimezone(KST) if apply_start else None,
            deadline_at=deadline.astimezone(KST) if deadline else None,
            needs_review=bool(row["needs_review"]),
            review_reasons=_lines(row["review_reasons"]),
            extraction_confidence=float(confidence) if confidence is not None else None,
            uploaded_by_me=row["uploaded_by_me"],
            course_name=row["course_name"],
            attachments=[_attachment(item) for item in row["attachments"] if item["source_url"]],
            eligibility=eligibility,
            documents=[DocumentItem(**document) for document in row["documents"]],
            prep=Prep(
                prepared=row["prep_done"],
                prep_plan_id=_text(row["prep_plan_id"]) if row["prep_done"] else None,
                tasks_total=row["tasks_total"],
                tasks_done=row["tasks_done"],
                calendar_events=[CalendarEventRef(**event) for event in row["calendar_events"]],
            ),
            process=Process(
                extraction=[_step(step, names) for step in row["steps"]],
                evaluated_at=eligibility.evaluated_at,
                prepare_run_id=_text(row["prepare_run_id"]),
            ),
            reported_by_me=row["reported_by_me"],
            my_mark=row["my_mark"],
        )

    async def set_mark(
        self,
        user_id: str,
        opportunity_id: str,
        mark: str,
        *,
        now: datetime,
        display_name: str | None = None,
    ) -> datetime | None:
        """관심·관심 없음 표시(F-45). 상세를 열 수 있는 공고에만 붙인다. 아니면 None.

        공고마다 표시는 하나다. 다른 표시를 보내면 바꾼다. 프로필 행이 없으면(첫 요청) 만든다.
        피드처럼 프로필 행을 잠근다: 피드 응답 하나의 목록(my_mark)과 숫자(counts)가 어긋나지 않는다.
        """

    async def feed_page(self, user_id: str, query: FeedQuery, *, now: datetime) -> FeedPage:

            "limit": query.limit + 1,
        }

        if not query.include_not_interested:
            where.append(_NOT_DISMISSED)
        if query.categories:
            where.append(" o.category::text = any(%(categories)s)")
            params["categories"] = list(query.categories)
        if query.source_types:
            where.append(" o.source_type::text = any(%(source_types)s)")
            params["source_types"] = list(query.source_types)
        outer = []
        if query.eligibility:
            outer.append("eff_status = any(%(eligibility)s)")
            params["eligibility"] = sorted(query.eligibility)
        if query.cursor:
            outer.append(_after(query.sort, query.cursor))
            params["cursor_value"], params["cursor_id"] = query.cursor.value, query.cursor.id
        sql = _feed_sql(
            " and".join(where),
            " where " + " and ".join(outer) if outer else "",
            _ORDER[query.sort],
        )
        rows = await (await self.conn.execute(sql, params)).fetchall()
        today = now.astimezone(KST).date()
        page = rows[: query.limit]
        next_cursor = None
        if len(rows) > query.limit:
            last = page[-1]
            value = last["deadline_at"] if query.sort == "deadline" else last["created_at"]
            cursor = Cursor(scope=query.scope(), value=value, id=str(last["id"]))
            next_cursor = encode_cursor(cursor)
        return FeedPage(items=[_item(row, today) for row in page], next_cursor=next_cursor)

def _after(sort: Sort, cursor: Cursor) -> str:
    """정렬 순서(_ORDER)에서 cursor 다음에 오는 행. 값이 없는 행은 맨 뒤에 id 순으로 온다."""
    column, beyond = ("deadline_at", ">") if sort == "deadline" else ("created_at", "<")
    if cursor.value is None:
        return f"({column} is null and id {beyond} %(cursor_id)s)"
    return (
        f"({column} {beyond} %(cursor_value)s"
        f" or ({column} = %(cursor_value)s and id {beyond} %(cursor_id)s) or {column} is null)"
    )

def _judge(
    item: dict[str, Any], profile: Profile, departments: list[Department], today: date
) -> _Judged:
    """공고 행 하나(requirements·eligibility_basis_date·deadline_at)를 판정한다.

    엔진 오류면 "판정하지 못함" 행을 돌려준다: 그 공고만 원문 확인 필요로 보인다.
    """
    basis: date | None = None
    try:
        requirements = tuple(Requirement.from_row(r) for r in item["requirements"])
        days = _basis_dates(item, today)
        basis = days[0]
        # 기준일이 둘이면(청년정책) 더 나은 쪽을 쓴다. 같으면 앞 날짜다(max는 처음 나온 것을 고른다)
        judgment = max(
            (
                check_eligibility(
                    list(requirements), profile, basis_date=day, departments=departments
                )
                for day in days
            ),
            key=lambda found: _RANK[found.status],
        )
        return _Judged(
            judgment.storage_row(),
            judgment.display_status,
            judgment,
            requirements,
            judgment.basis_date,
        )
    except Exception:
        logger.exception("판정하지 못한 공고: %s", item["id"])
        return _Judged(_engine_error_row(), "needs_review", None, (), basis)


_RANK = {"ineligible": 0, "undetermined": 1, "eligible": 2}


def _basis_dates(item: dict[str, Any], today: date) -> tuple[date, ...]:
    """판정 기준일(판정엔진_규칙.md 8장). 보통 하나다(공고 기준일 → 마감일 → 오늘).

    청년정책(온통청년)은 신청일 기준이 대부분이고 신청 기간이 몇 년인 정책도 있다. 그래서 신청할 수 있는 첫날
    (오늘, 신청 기간 전이면 시작일)과 마감일을 둘 다 보고 더 나은 결과를 쓴다. 나이 상한은 첫날에, 하한은
    마감일에 맞으면 그 사이 어느 날엔 신청할 수 있다. 신청 기간이 끝났으면 마감일 하나다."""
    if item["source_type"] != "youth_policy" or item["eligibility_basis_date"] is not None:
        return (resolve_basis_date(item["eligibility_basis_date"], item["deadline_at"], today),)
    start = item["apply_start_at"]
    first = max(today, to_kst_date(start)) if start is not None else today
    if item["deadline_at"] is None:
        return (first,)
    deadline = to_kst_date(item["deadline_at"])
    return (deadline,) if deadline <= first else (first, deadline)

def _step(step: dict[str, Any], names: dict[int, str]) -> ProcessStep:
    """처리 과정 한 줄(_DETAIL의 steps 행 하나). 첨부를 읽은 단계는 첨부 이름을 넣어 보인다.

    도구가 오류를 돌려준 호출(없는 첨부 번호 등)과 거절된 제출은 실행 로그에 succeeded로 남는다
    (에이전트는 오류를 모델에 돌려주고 계속 간다). 화면에는 실패로 보인다. 첨부 번호·위치는
    에이전트와 같은 규칙(whole)으로 읽는다. 읽기·토큰 상한에 닿아 코드가 시킨 제출(forced)은
    모델이 고른 단계가 아니라서 pipeline으로 보인다.
    """
    tool: str = step["tool"]
    again = "이어 " if _continued(step) else ""
    if tool in (READ_TEXT, READ_IMAGE):
        number = whole(step.get("attachment_no"))
        name = names.get(number) if number is not None else None
        target = f"첨부 '{name}'" if name else f"첨부 {number}번" if number else "첨부"
        how = "이미지로 " if tool == READ_IMAGE else ""
        label = f"{target} {how}{again}읽기"
    elif tool == FETCH_ORIGINAL:
        label = f"공고 원문 페이지 {again}읽기"
    elif tool == FETCH_YOUTH:
        label = "온통청년에서 정책 정보 받기"
    elif tool == BUILD_YOUTH:
        label = "온통청년 항목으로 지원 자격 정리"
    else:
        label = "지원 자격 정리" if tool == SUBMIT else tool
    failed = step.get("error") is True or (tool == SUBMIT and step.get("accepted") is False)
    chosen = tool in _AGENT_TOOLS and step.get("forced") is not True
    return ProcessStep(
        seq=step["seq"],
        tool=tool,
        label=label,
        status="failed" if failed else step["status"],
        latency_ms=step["latency_ms"],
        chosen_by="agent" if chosen else "pipeline",
        note=_line(step.get("reason")),
    )


def _continued(step: dict[str, Any]) -> bool:
    """앞에서 읽은 곳의 뒷부분을 읽은 호출. 도구가 실제로 읽은 위치를 보고, 오류면 요청한 위치를 본다.

    글자 읽기·원문 읽기는 시작 위치(offset)가 0보다 크면, Vision은 PDF를 2쪽부터 읽었으면 이어 읽기다.
    이미지는 한 장이라 이어 읽기가 없다.
    """
    if step["tool"] != READ_IMAGE:
        offset = whole(step.get("offset"))
        return offset is not None and offset > 0
    pages = step.get("pages")  # 읽은 PDF 쪽 "4–6/8". 이미지는 없다
    if isinstance(pages, str) and (first := _PAGES.match(pages)):
        return int(first.group(1)) > 1
    if step.get("error") is not True:
        return False  # 이미지를 읽었다
    start_page = whole(step.get("start_page"))
    return start_page is not None and start_page > 1


def _line(text: Any) -> str | None:
    """모델이 쓴 글(고른 이유, 원문 확인 필요 이유)을 화면용 한 줄로: 보이지 않는 문자(폭 없는 문자,
    글자 방향 제어)와 주소를 지우고 공백·줄바꿈을 한 칸으로 줄여 LINE_MAX_CHARS자까지. 남는 글이
    없으면 None이다.

    공고 글을 읽은 모델이 쓴 글이라, 공고 속 지시문이 링크를 끼워 넣지 못하게 쉬운 설명과 같은 규칙으로
    정리한다(app/extraction/validate.py). 저장된 값을 읽을 때 정리해서 예전 행에도 같이 적용된다.
    화면은 이 글을 일반 텍스트로 보여 준다(자동 링크·마크다운 없이).
    """
    if not isinstance(text, str):
        return None
    line = " ".join(_LINK.sub("", _INVISIBLE.sub("", text)).split())
    if len(line) > LINE_MAX_CHARS:
        line = line[: LINE_MAX_CHARS - 1].rstrip() + "…"
    return line or None


def _lines(texts: Sequence[Any] | None) -> list[str]:
    """여러 줄을 _line으로 정리한다. 빈 줄과 같은 줄은 빼고, REASONS_MAX줄이 넘으면 "외 N건"으로 줄인다."""
    lines = list(dict.fromkeys(line for text in texts or () if (line := _line(text))))
    if len(lines) > REASONS_MAX:
        return [*lines[:REASONS_MAX], f"외 {len(lines) - REASONS_MAX}건"]
    return lines


def _attachment(item: dict[str, Any]) -> AttachmentItem:

        source_url=item["source_url"],

    )
```

```python
        return str(row["id"]) if row else None

    async def lock_plan(self, plan_id: str) -> bool:
        """계획 행이 아직 있나(잠근다). 멈춘 실행으로 보고 지운 뒤면 False다."""
        row = await (
            await self.conn.execute(
                "select id from prep_plans where id = %s for update", (plan_id,)
            )
        ).fetchone()
        return row is not None

    async def drop_plan(self, plan_id: str) -> None:
        """계획과 그 할 일(on delete cascade)을 지운다."""
        await self.conn.execute("delete from prep_plans where id = %s", (plan_id,))

    async def opportunity(self, opportunity_id: str) -> OpportunityText | None:
        """공고 글. 잠그지 않는다(모델에 묻기 전에 읽는 쪽)."""
        return await self._opportunity(opportunity_id, lock=False)

    async def lock_opportunity(self, opportunity_id: str) -> OpportunityText | None:
        """공고 행을 잠근다. 같은 공고를 여럿이 함께 준비해도 서류는 한 번만 넣는다.

        모델 호출은 이 잠금 밖에서 한다(app/prepare/service.py). 잠근 뒤에는 서류를 다시 읽어
        그새 다른 학생이 넣거나 채운 값을 그대로 쓴다.
        """
        return await self._opportunity(opportunity_id, lock=True)

    async def _opportunity(self, opportunity_id: str, *, lock: bool) -> OpportunityText | None:
        row = await (
            await self.conn.execute(
                "select title, organizer, source_type::text as source_type, raw_text"
                " from opportunities where id = %s" + (" for no key update" if lock else ""),
                (opportunity_id,),
            )
        ).fetchone()
        if row is None:
            return None
        return OpportunityText(row["title"], row["organizer"], row["source_type"], row["raw_text"])

    async def documents(self, opportunity_id: str) -> list[DocumentRow]:
        """공고 서류. 상세와 같은 순서(필수 먼저, 이름 순)다."""
        rows = await (
            await self.conn.execute(
                "select id, name, issuer, lead_days from opportunity_documents"
                " where opportunity_id = %s"
                " order by coalesce(is_required, true) desc, name, id",
                (opportunity_id,),
            )
        ).fetchall()
        return [
            DocumentRow(str(row["id"]), row["name"], row["issuer"], row["lead_days"])
            for row in rows
        ]

    async def add_documents(self, opportunity_id: str, drafts: Sequence[GuideDraft]) -> None:
        """청년정책의 제출 서류 글에서 만든 서류(안내 포함)."""
        for draft in drafts:
            await self.conn.execute(
                "insert into opportunity_documents (opportunity_id, name, issuer, how_to, lead_days,"
                " effort_minutes, is_required) values (%s, %s, %s, %s, %s, %s, %s)",
                (
                    opportunity_id,
                    draft.name,
                    draft.issuer,
                    draft.how_to,
                    draft.lead_days,
                    draft.effort_minutes,
                    draft.is_required,
                ),
            )

    async def save_guides(self, guides: Sequence[tuple[str, Guide]]) -> None:
        """서류 안내의 빈 칸만 채운다. 공고 서류라 다른 학생도 같은 안내를 본다(다시 묻지 않는다).

        모델 호출이 잠금 밖이라, 묻는 동안 다른 학생이 먼저 채웠을 수 있다. 그 값을 덮지 않는다.
        """
        for document_id, guide in guides:
            await self.conn.execute(
                "update opportunity_documents set issuer = coalesce(issuer, %s),"
                " how_to = coalesce(how_to, %s), lead_days = coalesce(lead_days, %s),"
                " effort_minutes = coalesce(effort_minutes, %s) where id = %s",
                (guide.issuer, guide.how_to, guide.lead_days, guide.effort_minutes, document_id),
            )

    async def add_tasks(self, user_id: str, plan_id: str, tasks: Sequence[TaskDraft]) -> None:
        for task in tasks:
            await self.conn.execute(
                "insert into planner_tasks (user_id, source, prep_plan_id, document_id, title,"
                " due_date, sort_order) values (%s, 'prep_plan', %s, %s, %s, %s, %s)",
                (user_id, plan_id, task.document_id, task.title, task.due_date, task.sort_order),
            )
```

```typescript
        // 마감 2일 전까지 서류를 갖추도록 발급 소요일만큼 앞당긴다(모르면 하루, API와 같다)
        due_date: clampToToday(subtractDays(deadline, 2 + (document.lead_days ?? 1))),
        is_done: false,
        source: "prep_plan",
        link: {
          type: "opportunity",
          id,
          title: detail.title,
          category: detail.category,
        },
      };
    });
    const submitTask: PlannerTask = {
      id: `task-${id}-submit`,
      title: "신청 제출",
      due_date: clampToToday(subtractDays(deadline, 1)), // 신청은 마감 하루 전에 낸다
      is_done: false,
      source: "prep_plan",
      link: {
        type: "opportunity",
        id,
        title: detail.title,
        category: detail.category,
      },
    };
    plannerState.items.push(...documentTasks, submitTask);
    if (detail.deadline_at && !plannerState.markers.some((marker) => marker.opportunity_id === id)) {
      plannerState.markers.push({
        kind: "deadline",
        date: deadline,
        title: `${detail.title} 마감`,
        opportunity_id: id,
        category: detail.category,
      });
    }
    const feedItem = opportunities.find((item) => item.id === id);
    if (feedItem) feedItem.prepared = true;
  }

  const tasks = tasksForOpportunity(id);
  detail.prep = {
    prepared: true,
    prep_plan_id: prepPlanId,
    tasks_total: tasks.length,
    tasks_done: tasks.filter((task) => task.is_done).length,
    calendar_events:
      includeCalendar && detail.deadline_at
        ? [{ id: `gcal-${id}`, provider: "google" }]
        : [],
  };
  detail.process.prepare_run_id = `run-prepare-${id}`;

  return {
    kind: "prepare",
    prep_plan_id: prepPlanId,
    documents: detail.documents,
    tasks: tasks.map((task) => ({
      id: task.id,
      title: task.title,
      due_date: task.due_date,
      document_id:
        detail.documents.find((document) => document.task_id === task.id)?.id ?? null,
    })),
    calendar_event:
      includeCalendar && detail.deadline_at
        ? {
            id: `gcal-${id}`,
            provider: "google",
            starts_at: detail.deadline_at,
          }
        : null,
    calendar_error: null,
  };
}

// 준비·강의계획서 할 일 옮기기(날짜만). 직접 추가한 할 일은 updateStoredManualTask가 제목까지 고친다.
// LMS 할 일은 완료만 바꿀 수 있어 실제 API처럼 막는다(API 명세 7장)
export function moveStoredTask(id: string, dueDate: string): PlannerTask {
  const task = plannerState.items.find((item) => item.id === id);
  if (!task) throw new Error("할 일을 찾을 수 없어요.");
  if (task.source === "lms_assignment" || task.source === "lms_announcement") {
    throw new Error("LMS에서 가져온 할 일은 완료만 바꿀 수 있어요.");
  }
  task.due_date = dueDate;
  return task;
}

export function setStoredDocumentDone(
  opportunityId: string,
  taskId: string,
  isDone: boolean,
): OpportunityDetail {
  const detail = detailsState[opportunityId];
  if (!detail) throw new Error("공고를 찾을 수 없어요.");
  const document = detail.documents.find((item) => item.task_id === taskId);
  if (!document) throw new Error("준비 일정을 먼저 만들어 주세요.");

  document.is_done = isDone;
  const task = plannerState.items.find((item) => item.id === taskId);
  if (task) task.is_done = isDone;
  const tasks = tasksForOpportunity(opportunityId);
  detail.prep.tasks_done = tasks.filter((item) => item.is_done).length;
  detail.prep.tasks_total = tasks.length;
  return detail;
}

// 관심·숨김 표시(F-45). 피드 항목과 상세에 같이 적어, 상세를 다시 받아도(서류 체크·다시 판정) 표시가 남는다.
// 없는 공고면 false. 메모리에만 있어 새로고침하면 표시가 없는 목데이터로 돌아간다
export function setStoredMark(id: string, mark: OpportunityMark | null): boolean {
  const item = opportunities.find((entry) => entry.id === id);
  const detail = detailsState[id];
  if (item) item.my_mark = mark;
  if (detail) detail.my_mark = mark;
  return Boolean(item ?? detail);
}

// 포스터 등록(posterStore.ts)이 만든 공고를 피드 맨 앞과 상세에 넣는다
export function addStoredOpportunity(item: OpportunityItem, detail: OpportunityDetail): void {
  opportunities.unshift(item);
  detailsState[detail.id] = detail;
}

export function setStoredPlannerTaskDone(
  taskId: string,
  isDone: boolean,
): PlannerTask {
  const task = plannerState.items.find((item) => item.id === taskId);
  if (!task) throw new Error("할 일을 찾을 수 없어요.");
  task.is_done = isDone;

  if (task.link.type === "opportunity" && task.link.id) {
    const detail = detailsState[task.link.id];
    const document = detail?.documents.find((item) => item.task_id === taskId);
    if (document) document.is_done = isDone;
    if (detail) {
      const tasks = tasksForOpportunity(detail.id);
      detail.prep.tasks_done = tasks.filter((item) => item.is_done).length;
    }
  }
  return task;
}

export function addStoredManualTask(
  title: string,
  dueDate: string,
): PlannerTask {
  const task: PlannerTask = {
    id: `manual-${Date.now()}`,
    title,
    due_date: dueDate,
    is_done: false,
    source: "manual",
    link: { type: null, id: null, title: null, category: null },
  };
  plannerState.items.push(task);
  return task;
}

export function updateStoredManualTask(
  id: string,
  title: string,
  dueDate: string,
): PlannerTask {
  const task = plannerState.items.find((item) => item.id === id);
  if (!task || task.source !== "manual") {
    throw new Error("직접 추가한 일정만 수정할 수 있어요.");
  }
  task.title = title;
  task.due_date = dueDate;
  return task;
}

export function deleteStoredManualTask(id: string): void {
  const index = plannerState.items.findIndex(
    (item) => item.id === id && item.source === "manual",
  );
  if (index < 0) throw new Error("직접 추가한 일정을 찾을 수 없어요.");
  plannerState.items.splice(index, 1);
}
```

```tsx
const GRID_PAD_DAYS = 7;

function monthRange(year: number, month: number) {
  const first = new Date(Date.UTC(year, month - 1, 1));
  const last = new Date(Date.UTC(year, month, 0));
  const shift = (base: Date, days: number) =>
    new Date(base.getTime() + days * 86_400_000).toISOString().slice(0, 10);
  return { from: shift(first, -GRID_PAD_DAYS), to: shift(last, GRID_PAD_DAYS) };
}
```
