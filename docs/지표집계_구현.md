# 지표 집계 — 성공률·응답시간·비용과 판정 혼동행렬, 제품 지표 5개를 한 번에 본다

> 📝 기준: PRD v0.9 8장(성공 지표) · API 명세 v0.4 12장·13장 · ERD v0.9 로깅 도메인 · 2026-10-15
>
> 함께 보는 파일: `시나리오실행_구현.md`(먼저 합쳤다, main 89ddb0e)

앞 PR이 시나리오를 돌려 기록을 남겼다. 이 PR은 그 기록을 읽는 쪽이다. 명세 12장의 마지막 두 줄을 채운다.

- `GET /internal/metrics` — 기간별 성공률·응답시간(p50·p95)·호출비용 + **판정 3×3 혼동행렬** + **제품 지표 5개**
- `POST /internal/eval/run` — 시나리오를 돌린다(CLI와 같은 함수를 부르는 얇은 겉)

이걸로 AOP 필수 산출물의 "테스트 시나리오 측정" 쪽이 끝난다.

**규모와 확인:**
- api만 바뀐다. 새 파일 5개, 바꾸는 파일 10개.
- **DB 변경이 없다.** 집계는 이미 있는 표(`agent_runs`·`tool_calls`·`llm_calls`·`eligibility_results`·`usage_events`·`opportunity_views`·`prep_plans`·`profiles`)만 읽는다. db push가 필요 없다.
- **`.env`에 값을 하나 넣어야 한다**: `INTERNAL_API_KEY`. 비우면 `/internal/*`이 모두 403이다(아래 "합친 뒤 확인" 1번).
- 명세에 없던 것을 더한다: `GET /internal/metrics` 응답 필드, 에러 코드 `EVAL_NOT_ALLOWED`(409). 같은 PR에서 명세를 고친다(CLAUDE.md 규칙).
- api `715 passed, 140 skipped`(DB 없이), DB를 붙이면 `855 passed`. 전에는 `699 passed, 131 skipped` / `830 passed`였다.
- 되돌림 시험 17가지(집계·라우터)와 11가지(앞 PR 러너, 바뀐 코드가 있어 다시 돌림)를 모두 잡았다.

## 정한 것

| 항목 | 정한 것 | 이유 |
| --- | --- | --- |
| 혼동행렬 자료 | 판정 확인 줄에 종류를 적는다. `world.judged(what, expected=, actual=)`가 `tool_calls.input`에 `kind: "eligibility"`를 남기고, 집계는 그 줄만 읽는다 | 10/15 선택. 확인 이름("판정")에 의존하면 이름을 바꾸는 순간 행렬이 비어도 아무도 모른다 |
| 판정 상태만 받기 | `judged`는 기대값이 판정 상태 3가지(eligible·undetermined·ineligible)가 아니면 그 자리에서 실패한다 | 화면 라벨(4가지, `missing_info`·`needs_review` 포함)을 넣으면 3×3에 담기지 않는다 |
| 어느 실행을 행렬에 넣나 | **시나리오 번호마다 가장 최근 실행** 하나씩 | 한 번 돌린 묶음을 가리키는 번호가 실행 행에 없다. 같은 시나리오를 여러 번 돌려도 마지막 결과만 센다 |
| 비용 셈 | `scenario_code`로 묶은 `llm_calls`의 합. `agent_runs.cost_usd`는 더하지 않는다 | 시나리오 실행 행의 cost_usd는 0이고(제 손으로 모델을 안 부른다) 자식 실행에 비용이 있다. 둘 다 더하면 두 번 센다 |
| 응답시간 | `agent_runs.latency_ms`의 `percentile_disc`(실제로 잰 값 중 하나) | 러너가 찍는 p50·p95와 같은 방법이어야 한다. DB 테스트가 두 값이 같은지 본다 |
| 실행 기록의 응답시간 | 시나리오 실행 행의 `latency_ms`를 **시나리오가 일한 시간**으로 바꿨다(`AgentRun.latency_ms`에 직접 잰 값을 넣으면 그 값을 쓴다) | 전에는 치우기·풀 닫기까지 들어가서, CLI가 찍는 수와 DB에 남는 수가 달랐다 |
| 판정 불가 비율 | 기간이 아니라 **지금 저장된 판정** 기준(활성 공고 × 사용자) | 판정은 프로필이 바뀔 때마다 덮어써서 지난 기간의 값이 남지 않는다(사용자×공고마다 한 줄) |
| 주간 재방문율 | 가입 다음 **7일** 안에 앱을 한 번이라도 열었나. 아직 7일이 지나지 않은 사용자는 분모에서 뺀다 | "가입 다음 주"를 7일로 정했다. 열 기회가 없었던 사람을 분모에 넣으면 비율이 내려간다 |
| 준비하기 전환율 | 기간 안에 처음 본 **적격** 공고 중 준비하기까지 간 비율 | PRD 8장이 "적격 공고 상세 조회 → 준비하기"다 |
| 비율이 0인 것과 없는 것 | 분모가 0이면 `rate`는 `null`, 분모가 있고 분자가 0이면 `0.0` | "아무도 안 했다"와 "할 기회가 없었다"는 다르다. 화면이 "—"와 "0%"를 구분해 보여 줄 수 있다 |
| 서비스 키 | `X-Internal-Key`를 `secrets.compare_digest`로 본다. 키가 틀렸을 때와 **서버에 키가 없을 때 모두 403**이고 응답은 같다 | 부른 쪽에 서버 설정 상태를 알려 주지 않는다. 설정을 빼먹은 것은 서버 로그로 알린다 |
| 시나리오 실행 엔드포인트 | DB 연결(저장소 의존)을 받지 않는다. 안에서 `app.eval`을 늦게 가져온다 | 시나리오는 자기 연결·풀을 따로 연다. 요청이 연결을 쥐고 있으면 안 되고, `app.eval`은 앱을 만들어 쓰므로(app.main) 맨 위에서 가져오면 순환 import다 |
| 실제 DB 거절 | Supabase 주소면 409 `EVAL_NOT_ALLOWED`. 명세 13장에 코드를 더한다 | 시나리오는 사용자·공고를 만들고 **지운다**. 기존 코드 중 뜻이 맞는 것이 없었다 |
| user_id 조건 | 집계 조회에는 user_id 조건이 **없다**. 저장소 머리말에 왜 그런지 적었다 | 운영자가 전체를 보는 집계라 좁힐 사용자가 없다(명세 12장: 서비스 키로만 부른다). 돌려주는 값은 센 수와 비율뿐이다 |
| 기간 기본값 | 주지 않으면 오늘까지 30일(KST, 양 끝 포함). 한쪽만 줘도 된다 | 운영자가 그냥 불러도 쓸 수 있어야 한다 |

## 합친 뒤 확인

1. **서비스 키 넣기:** `api/.env`에 한 줄 더한다. 값은 아무 긴 임의 문자열이면 된다.

   ```powershell
   uv run python -c "import secrets; print(secrets.token_urlsafe(32))"
   ```

   나온 값을 `api/.env`의 `INTERNAL_API_KEY=`에 붙이고 API를 다시 띄운다. **이 값은 채팅에 붙이지 않는다.** 비워 두면 `/internal/*`이 모두 403이고, 서버 로그에 "내부 API 키가 비어 있어요"가 뜬다.
2. **키 검증:** 키 없이 부르면 403이어야 한다.

   ```powershell
   curl.exe -i http://localhost:8000/api/v1/internal/metrics
   ```

   `403`과 `FORBIDDEN`이 보인다. 그다음 헤더를 붙여 부른다(`$env:KEY`에 넣고 쓰면 명령 기록에 값이 남지 않는다).

   ```powershell
   $env:KEY = Read-Host "INTERNAL_API_KEY"
   curl.exe -s -H "X-Internal-Key: $env:KEY" http://localhost:8000/api/v1/internal/metrics
   ```
3. **지표 보기:** 위 응답에 `from`·`to`·`scenarios`·`eligibility`·`product`가 있다. 아직 시나리오를 돌리지 않았으면 `scenarios.runs`는 0이고 `product`의 비율은 대부분 `null`이다(자료가 없다는 뜻).
4. **시나리오를 엔드포인트로 돌리기:** **시험용 DB**에서만 한다. `api/.env`의 `DATABASE_URL`이 Supabase 주소면 409 `EVAL_NOT_ALLOWED`가 나오고 아무것도 하지 않는다(맞는 동작이다). 시험용 DB 주소로 띄운 API에서:

   ```powershell
   curl.exe -s -X POST -H "X-Internal-Key: $env:KEY" -H "Content-Type: application/json" `
     -d '{\"scenario_codes\":[\"S02\",\"S05\"],\"fixtures\":\"recorded\"}' `
     http://localhost:8000/api/v1/internal/eval/run
   ```

   `passed`가 2고 `results`에 S02·S05가 있다. 그 뒤 3번을 다시 부르면 `scenarios.runs`가 2로 늘고 `eligibility.checks`가 3이다(S02 1건 + S05 2건).
5. **혼동행렬:** 시험용 DB에서 `python -m app.eval.cli`로 전부 돌린 뒤 3번을 부르면 `eligibility`가 `checks 13 · correct 13 · accuracy 1.0`이고 `eligible_to_ineligible`이 0이다.
6. **기간:** `?from=2020-01-01&to=2020-01-02`로 부르면 모든 수가 0이고 비율이 `null`이다. `?from=2026-12-31&to=2026-01-01`은 422에 `to` 사유가 붙는다.

## 확인한 것

| 확인 | 결과 |
| --- | --- |
| 집계가 실행과 맞나 | 시나리오 11개를 돌린 뒤 집계: `runs 11 · passed 11 · success_rate 1.0 · cost_usd 0.00456 · llm_calls 3`. 러너가 돌려준 값과 모두 같다. 시나리오별 비용·호출 수·응답시간도 하나씩 맞춰 봤다 |
| 응답시간 방법이 같나 | 집계의 p50·p95가 `app/eval/models.percentile`과 같은 값이다(DB 테스트). 같은 번호를 두 번 돌려 평균이 아닌 **잰 값 중 하나**를 고르는지도 봤다 |
| 혼동행렬 | 판정 확인 13건(적격 7·판정 불가 2·부적격 4) 모두 대각선. `accuracy 1.0`, `eligible_to_ineligible 0`, `ineligible_to_eligible 0`. 시각은 KST(+09:00)로 내려간다 |
| 번호별 최신 실행 | 일부러 틀린 판정(적격→부적격)을 낸 S01을 돌리면 행렬에 `eligible_to_ineligible 1`이 뜨고, 같은 번호를 제대로 다시 돌리면 0으로 돌아간다 |
| 기간 자르기 | 옛 날짜 기간으로 부르면 모든 수가 0이고 `by_scenario`가 비고 `run_started_at`이 null이다. 같은 번호를 기간 안·밖에서 돌리면 **기간 안의 비용만** 센다 |
| 제품 지표 5개 | 사용자 3명 + 공고 2개(활성·마감)를 넣어 셈: 즉석 입력 2/3(0.6667), 주간 재방문 2/3(오늘 가입한 사람은 분모에서 뺀다), LMS 연결 1/1, 준비하기 전환 1/2(적격만), 판정 불가 분모 +3(마감 공고의 판정 3건은 빼고), 원인 항목 상위에 `gpa_last_semester`·`age`가 있고 마감 공고의 `region`은 없다 |
| 자료 없음 | 아무 자료도 없는 기간은 네 비율 모두 `rate: null`이다. `rate(0, 5)`는 0.0이고 `rate(0, 0)`은 null이다 |

### 지금 수치 (시험용 DB, 시나리오 11개를 한 번 돌린 뒤)

```text
eligibility  checks 13 · correct 13 · accuracy 1.0 · eligible→ineligible 0 · ineligible→eligible 0

```

제품 지표는 **실제 사용자가 쓰기 시작해야** 숫자가 생긴다. 시나리오는 끝나면 사용자를 지우기 때문이다. 그래서 DB 테스트에서 자료를 넣어 다섯 비율이 맞게 세어지는지만 확인했다.

### 되돌림 시험에서 고친 것

| 가려진 것 | 고친 것 |

| 판정 확인의 기대값 검사를 지워도 통과했다 | 화면 라벨(`missing_info`)을 넣은 시나리오가 실패하는지 본다 |

## 남은 것

- **운영자 화면**: 지금은 `curl`로 JSON을 본다. 발표·멘토링에 쓸 표가 필요하면 CLI에 `--metrics`를 붙이거나 작은 내부 화면을 만든다. 둘 다 이 엔드포인트만 부르면 된다.
- **제품 지표 자료 쌓기**: 비율은 실제 사용에서만 생긴다. 웹이 `POST /events`로 `app_open`·`profile_prompt_shown`·`profile_prompt_submitted`를 보내는지, 상세를 열 때 `opportunity_views`가 남는지는 이미 붙어 있다. `lms_guide_opened`·`lms_connected`는 LMS 기능(F-50)과 함께다.
- **정답셋 20건**: PRD 8장의 정답셋(학교 10·청년 5·포스터 5 × 가상 프로필 5종)은 아직 없다. 지금 혼동행렬은 시나리오가 만든 13건이다. 정답셋을 만들면 요건 추출 정확도·마감일 정확도도 같은 자리에서 잴 수 있다.
- **요건 추출·마감일 정확도**: PRD 8장 지표 표의 앞 두 줄은 정답셋이 있어야 한다. 위 항목 다음이다.
- **스케줄러 작업 5개**: 명세 12장의 `/internal/jobs/*`는 아직 사람이 CLI로 돌린다. 배포할 때 이 라우터에 같은 모양으로 더한다(서비스 키 검증은 이미 있다).
- **기간 기준 섞임**: `scenarios`·`product` 네 개는 기간을 자르고 `undetermined`는 지금 상태다. 한 응답에 기준이 둘이라 화면이 그 차이를 적어 줘야 한다.

## 코드

경로는 레포 루트 기준이다. 새 파일 5개와 바뀐 파일 10개의 전체 내용을 싣는다.

### api (새 파일)

#### `api/app/schemas/metrics.py`

```python
"""내부 지표 집계 (API 명세 v0.4 12장 `GET /internal/metrics`, PRD 8장 성공 지표).

세 묶음을 돌려준다.
- scenarios: 기간 안의 시나리오 실행(agent_runs.trigger_type = 'eval') 성공률·응답시간·호출비용
- eligibility: 가장 최근 시나리오 실행 묶음의 판정 3×3 혼동행렬
- product: 제품 지표 5개

비용은 scenario_code로 묶은 `llm_calls`를 더한다. 시나리오 실행 행의 cost_usd는 0이다(제 손으로
모델을 부르지 않는다). agent_runs.cost_usd를 또 더하면 같은 비용을 두 번 센다.
"""

from datetime import date, datetime
from typing import Literal

from pydantic import BaseModel, ConfigDict, Field

from app.schemas.opportunities import ELIGIBILITY_STATUSES, EligibilityStatus

# 시나리오 실행이 남기는 확인 줄(app/eval/world.py의 check). 혼동행렬은 kind가 아래 값인 줄만 읽는다
CHECK_TOOL = "check"
ELIGIBILITY_CHECK = "eligibility"
STATUSES: tuple[str, ...] = ELIGIBILITY_STATUSES


class Latency(BaseModel):
    p50_ms: int
    p95_ms: int


class ScenarioMetric(BaseModel):
    """시나리오 번호별 집계. 같은 번호를 여러 번 돌렸으면 다 더한다."""

    code: str
    runs: int
    passed: int
    success_rate: float
    latency: Latency
    cost_usd: float
    llm_calls: int


class ScenarioMetrics(BaseModel):
    runs: int
    passed: int
    success_rate: float  # E2E 성공률(PRD 8장)
    latency: Latency
    cost_usd: float
    llm_calls: int
    by_scenario: list[ScenarioMetric]


class MatrixRow(BaseModel):
    """정답 상태 한 줄. counts의 키는 엔진이 낸 상태다."""

    expected: EligibilityStatus
    counts: dict[str, int]
    total: int


class EligibilityMatrix(BaseModel):
    """판정 정확도 3×3(PRD 8장). 가장 최근 시나리오 실행 묶음 기준이다."""

    run_started_at: datetime | None  # 그 묶음의 첫 실행 시각. 확인 줄이 없으면 null
    checks: int
    correct: int
    accuracy: float
    rows: list[MatrixRow]
    eligible_to_ineligible: int  # 핵심 목표: 0건
    ineligible_to_eligible: int  # 따로 추적한다


class Ratio(BaseModel):
    """나눈 값 하나. 분모가 0이면 rate는 null이다(0.0과 구분한다)."""

    numerator: int
    denominator: int
    rate: float | None


class MissingField(BaseModel):
    field: str
    count: int


class UndeterminedRate(Ratio):
    """판정 불가 비율. 지금 저장된 (사용자 × 활성 공고) 판정 기준이다(기간이 아니라 현재 상태)."""

    top_missing_fields: list[MissingField]  # 원인 항목 상위 3개


class ProductMetrics(BaseModel):
    """제품 지표 5개(PRD 8장). 목표치는 W6 베이스라인을 잰 뒤 정한다."""

    undetermined: UndeterminedRate
    profile_prompt: Ratio  # 즉석 입력 응답률: 입력창 노출 → 입력 완료
    prepare_conversion: Ratio  # 준비하기 전환율: 상세 조회 → 준비하기
    lms_connect: Ratio  # LMS 연결 완료율: 토큰 가이드 진입 → 검증 성공
    weekly_return: Ratio  # 주간 재방문율: 가입 다음 주에 1회 이상 접속


class Metrics(BaseModel):
    """응답 키는 from·to다(파이선에서 from은 예약어라 필드 이름만 다르다)."""

    model_config = ConfigDict(populate_by_name=True)

    from_date: date = Field(alias="from")  # 집계 기간(KST 날짜, 양 끝 포함)
    to_date: date = Field(alias="to")
    scenarios: ScenarioMetrics
    eligibility: EligibilityMatrix
    product: ProductMetrics


# POST /internal/eval/run


class EvalRunRequest(BaseModel):
    scenario_codes: list[str] | None = None  # 없으면 전부
    now: datetime | None = None  # 시계 고정. 없으면 기본값
    fixtures: Literal["recorded"] = "recorded"  # 지금은 녹화한 응답만


class EvalCheck(BaseModel):
    what: str
    expected: object
    actual: object
    ok: bool
    kind: str | None = None


class EvalScenarioResult(BaseModel):
    code: str
    title: str
    ok: bool
    latency_ms: int
    api_ms: float
    run_id: str | None
    cost_usd: float
    llm_calls: int
    checks: list[EvalCheck]
    error: str | None


class EvalRunResult(BaseModel):
    now: datetime
    priced_on: date | None  # 단가를 고른 날. 이 날짜가 다르면 비용끼리 비교하지 않는다
    scenarios: int
    passed: int
    success_rate: float
    latency: Latency
    cost_usd: float
    llm_calls: int
    results: list[EvalScenarioResult]
```

```python
"""내부 지표 집계 SQL (API 명세 12장 `GET /internal/metrics`, PRD 8장).

**이 파일의 조회에는 user_id 조건이 없다.** 다른 저장소와 다른 점이고, 일부러 그렇다 — 운영자가
전체를 보는 집계라서 좁힐 사용자가 없다(명세 12장: 사용자 토큰이 아니라 서비스 키로만 부른다).
돌려주는 값은 모두 센 수와 비율이고, 사용자 한 명을 가리키는 값(이름·프로필)은 담지 않는다.

기간은 KST 날짜 양 끝을 포함한다. `agent_runs.started_at`·`usage_events.occurred_on`처럼 기준이 되는
시각을 KST 날짜로 바꿔 비교한다.

응답시간 백분위수는 `percentile_disc`(실제로 잰 값 중 하나를 고른다)다. 시나리오 러너의
`app/eval/models.percentile`과 같은 방법이어야 한다 — DB 테스트가 두 값이 같은지 본다.
"""

from collections.abc import Sequence
from datetime import date
from typing import Annotated, Any

from fastapi import Depends
from psycopg import AsyncConnection

from app.db import get_conn
from app.eligibility import KST
from app.schemas.metrics import (
    CHECK_TOOL,
    ELIGIBILITY_CHECK,
    STATUSES,
    EligibilityMatrix,
    Latency,
    MatrixRow,
    Metrics,
    MissingField,
    ProductMetrics,
    Ratio,
    ScenarioMetric,
    ScenarioMetrics,
    UndeterminedRate,
)

TOP_MISSING = 3  # 판정 불가 원인 항목 상위 몇 개를 보여 줄지(PRD 8장)
RETURN_DAYS = 7  # 주간 재방문: 가입 다음 7일 안에 앱을 한 번이라도 열었나
_EVAL = "eval"
# KST 날짜로 바꿔 기간과 비교한다. 기간은 양 끝을 포함한다
_IN_PERIOD = "(%s at time zone 'Asia/Seoul')::date between %%(from)s and %%(to)s"
_RUN_PERIOD = _IN_PERIOD % "r.started_at"


def rate(numerator: int, denominator: int) -> Ratio:
    """분모가 0이면 rate는 null이다(0.0과 구분한다 — 아직 아무도 안 했다는 뜻)."""
    found = round(numerator / denominator, 4) if denominator else None
    return Ratio(numerator=numerator, denominator=denominator, rate=found)


def _latency(row: dict[str, Any] | None) -> Latency:
    if row is None:
        return Latency(p50_ms=0, p95_ms=0)
    return Latency(p50_ms=int(row["p50"] or 0), p95_ms=int(row["p95"] or 0))


class MetricsRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def metrics(self, period: tuple[date, date]) -> Metrics:
        start, end = period
        window = {"from": start, "to": end}
        return Metrics(
            from_date=start,
            to_date=end,
            scenarios=await self.scenarios(window),
            eligibility=await self.eligibility(window),
            product=await self.product(window),
        )

    # ── 시나리오 실행: 성공률·응답시간·호출비용 ──────────────────────────────

    async def scenarios(self, window: dict[str, date]) -> ScenarioMetrics:
        """기간 안의 시나리오 실행. 비용은 같은 scenario_code가 붙은 실행의 llm_calls 합이다."""
        rows = await self._rows(
            "select r.scenario_code as code, count(*) as runs,"
            " count(*) filter (where r.status = 'succeeded') as passed,"
            " percentile_disc(0.5) within group (order by coalesce(r.latency_ms, 0)) as p50,"
            " percentile_disc(0.95) within group (order by coalesce(r.latency_ms, 0)) as p95"
            f" from agent_runs r where r.trigger_type = '{_EVAL}' and r.scenario_code is not null"
            f" and {_RUN_PERIOD} group by 1 order by 1",
            window,
        )
        spend = {
            row["code"]: row
            for row in await self._rows(
                "select r.scenario_code as code, coalesce(sum(l.cost_usd), 0) as cost,"
                " count(l.id) as calls from agent_runs r"
                " left join llm_calls l on l.run_id = r.id"
                f" where r.scenario_code is not null and {_RUN_PERIOD} group by 1",
                window,
            )
        }
        overall = await self._row(
            "select count(*) as runs, count(*) filter (where r.status = 'succeeded') as passed,"
            " percentile_disc(0.5) within group (order by coalesce(r.latency_ms, 0)) as p50,"
            " percentile_disc(0.95) within group (order by coalesce(r.latency_ms, 0)) as p95"
            f" from agent_runs r where r.trigger_type = '{_EVAL}' and r.scenario_code is not null"
            f" and {_RUN_PERIOD}",
            window,
        )
        by_scenario = [
            ScenarioMetric(
                code=row["code"],
                runs=row["runs"],
                passed=row["passed"],
                success_rate=rate(row["passed"], row["runs"]).rate or 0.0,
                latency=_latency(row),
                cost_usd=float(spend.get(row["code"], {}).get("cost", 0)),
                llm_calls=int(spend.get(row["code"], {}).get("calls", 0)),
            )
            for row in rows
        ]
        runs = int(overall["runs"]) if overall else 0
        passed = int(overall["passed"]) if overall else 0
        return ScenarioMetrics(
            runs=runs,
            passed=passed,
            success_rate=rate(passed, runs).rate or 0.0,
            latency=_latency(overall),
            cost_usd=round(sum(item.cost_usd for item in by_scenario), 6),
            llm_calls=sum(item.llm_calls for item in by_scenario),
            by_scenario=by_scenario,
        )

    # ── 판정 혼동행렬 ───────────────────────────────────────────────────────

    async def eligibility(self, window: dict[str, date]) -> EligibilityMatrix:
        """판정 정확도 3×3. **시나리오 번호마다 가장 최근 실행** 하나씩만 센다.

        한 번 돌린 묶음을 가리키는 번호가 없어서(실행 행에 묶음 id가 없다) 번호별 최신 실행으로 정했다.
        같은 시나리오를 여러 번 돌려도 마지막 결과만 행렬에 들어간다.
        """
        latest = (
            "select distinct on (r.scenario_code) r.id, r.started_at from agent_runs r"
            f" where r.trigger_type = '{_EVAL}' and r.scenario_code is not null and {_RUN_PERIOD}"
            " order by r.scenario_code, r.started_at desc"
        )
        rows = await self._rows(
            f"with latest as ({latest})"
            " select c.input->>'expected' as expected, c.output->>'actual' as actual,"
            " count(*) as count from latest join tool_calls c on c.run_id = latest.id"
            " where c.tool_name = %(tool)s and c.input->>'kind' = %(kind)s group by 1, 2",
            {**window, "tool": CHECK_TOOL, "kind": ELIGIBILITY_CHECK},
        )
        started = await self._row(f"select min(started_at) as first from ({latest}) latest", window)
        counts: dict[str, dict[str, int]] = {status: {} for status in STATUSES}
        for row in rows:
            if row["expected"] in counts:  # judged가 세 상태만 받지만 옛 기록이 섞일 수 있다
                counts[row["expected"]][row["actual"]] = int(row["count"])
        matrix = [
            MatrixRow(expected=status, counts=found, total=sum(found.values()))
            for status, found in counts.items()
        ]
        checks = sum(row.total for row in matrix)
        correct = sum(row.counts.get(row.expected, 0) for row in matrix)
        first = started["first"] if started else None
        return EligibilityMatrix(
            run_started_at=first.astimezone(KST) if first and checks else None,
            checks=checks,
            correct=correct,
            accuracy=rate(correct, checks).rate or 0.0,
            rows=matrix,
            eligible_to_ineligible=counts["eligible"].get("ineligible", 0),
            ineligible_to_eligible=counts["ineligible"].get("eligible", 0),
        )

    # ── 제품 지표 5개 ───────────────────────────────────────────────────────

    async def product(self, window: dict[str, date]) -> ProductMetrics:
        return ProductMetrics(
            undetermined=await self.undetermined(),
            profile_prompt=await self._events(
                window, "profile_prompt_shown", "profile_prompt_submitted"
            ),
            prepare_conversion=await self.prepare_conversion(window),
            lms_connect=await self._events(window, "lms_guide_opened", "lms_connected"),
            weekly_return=await self.weekly_return(window),
        )

    async def undetermined(self) -> UndeterminedRate:
        """판정 불가 비율과 원인 항목 상위 3개. 기간이 아니라 **지금 저장된 판정** 기준이다.

        판정은 프로필이 바뀔 때마다 덮어써서 지난 기간의 값이 남지 않는다(eligibility_results는 사용자
        ×공고마다 한 줄이다). 그래서 기간으로 자르지 않고 활성 공고의 지금 판정을 센다.
        """
        row = await self._row(
            "select count(*) as pairs,"
            " count(*) filter (where e.status = 'undetermined') as undetermined"
            " from eligibility_results e join opportunities o on o.id = e.opportunity_id"
            " where o.status = 'active'",
            {},
        )
        causes = await self._rows(
            "select field, count(*) as count from eligibility_results e"
            " join opportunities o on o.id = e.opportunity_id"
            " cross join unnest(e.missing_fields) as field"
            " where o.status = 'active' and e.status = 'undetermined'"
            " group by 1 order by count(*) desc, field limit %(limit)s",
            {"limit": TOP_MISSING},
        )
        pairs = int(row["pairs"]) if row else 0
        found = int(row["undetermined"]) if row else 0
        return UndeterminedRate(
            **rate(found, pairs).model_dump(),
            top_missing_fields=[
                MissingField(field=cause["field"], count=int(cause["count"])) for cause in causes
            ],
        )

    async def prepare_conversion(self, window: dict[str, date]) -> Ratio:
        """준비하기 전환율: 기간 안에 처음 본 **적격** 공고 중 준비하기까지 간 비율(PRD 8장)."""
        row = await self._row(
            "select count(*) as viewed, count(p.user_id) as prepared from opportunity_views v"
            " join eligibility_results e"
            " on e.user_id = v.user_id and e.opportunity_id = v.opportunity_id"
            " left join prep_plans p"
            " on p.user_id = v.user_id and p.opportunity_id = v.opportunity_id"
            f" where e.status = 'eligible' and {_IN_PERIOD % 'v.first_viewed_at'}",
            window,
        )
        return rate(int(row["prepared"]) if row else 0, int(row["viewed"]) if row else 0)

    async def weekly_return(self, window: dict[str, date]) -> Ratio:
        """주간 재방문율: 기간 안에 가입한 사용자 중 가입 다음 7일에 앱을 한 번이라도 연 비율.

        아직 7일이 지나지 않은 사용자는 분모에서 뺀다(열 기회가 없었다).
        """
        row = await self._row(
            "select count(*) as signed_up, count(*) filter (where exists ("
            "   select 1 from usage_events u where u.user_id = p.id and u.event = 'app_open'"
            "   and u.occurred_on between joined.day + 1 and joined.day + %(days)s"
            " )) as returned from profiles p"
            " cross join lateral (select (p.created_at at time zone 'Asia/Seoul')::date as day)"
            " as joined"
            " where joined.day between %(from)s and %(to)s"
            " and joined.day + %(days)s <= (now() at time zone 'Asia/Seoul')::date",
            {**window, "days": RETURN_DAYS},
        )
        return rate(int(row["returned"]) if row else 0, int(row["signed_up"]) if row else 0)

    async def _events(self, window: dict[str, date], shown: str, done: str) -> Ratio:
        """사용 이벤트 두 개의 비율(노출 → 완료). 기간은 occurred_on(KST 날짜)으로 자른다."""
        row = await self._row(
            "select count(*) filter (where event = %(shown)s) as shown,"
            " count(*) filter (where event = %(done)s) as done from usage_events"
            " where occurred_on between %(from)s and %(to)s",
            {**window, "shown": shown, "done": done},
        )
        return rate(int(row["done"]) if row else 0, int(row["shown"]) if row else 0)

    # ── 조회 ────────────────────────────────────────────────────────────────

    async def _rows(self, query: str, params: dict[str, Any]) -> Sequence[dict[str, Any]]:
        return await (await self.conn.execute(query, params)).fetchall()

    async def _row(self, query: str, params: dict[str, Any]) -> dict[str, Any] | None:
        return await (await self.conn.execute(query, params)).fetchone()


def get_metrics_repo(conn: Annotated[AsyncConnection, Depends(get_conn)]) -> MetricsRepository:
    return MetricsRepository(conn)


MetricsRepoDep = Annotated[MetricsRepository, Depends(get_metrics_repo)]
```

```python
"""내부·운영 API (API 명세 12장). 사용자 토큰이 아니라 서비스 키(`X-Internal-Key`)로만 부른다.

- `POST /internal/eval/run` 테스트 시나리오를 돌린다(CLI `python -m app.eval.cli`와 같은 함수)

키가 틀렸을 때와 서버에 키가 없을 때 모두 403이다. 부른 쪽에 서버 설정 상태를 알려 주지 않는다.

import logging
import secrets
from datetime import date, timedelta
from typing import Annotated

from fastapi import APIRouter, Depends, Header, Query

from app.clock import NowDep

logger = logging.getLogger(__name__)
router = APIRouter(prefix="/internal", tags=["내부"])

FORBIDDEN = "이 API는 서비스 키로만 부를 수 있어요."


def internal_key(
    settings: Annotated[Settings, Depends(get_settings)],
    x_internal_key: Annotated[str | None, Header()] = None,
) -> None:
    """서비스 키 검증. 같은 길이의 틀린 키로 시간을 재지 못하게 compare_digest로 본다."""
    expected = settings.internal_api_key
    if not expected:
        # 서버에 키가 없으면 아무도 부를 수 없다. 부른 쪽에는 그 사실을 알려 주지 않는다
        logger.warning("내부 API 키가 비어 있어요(INTERNAL_API_KEY). /internal/*는 모두 403이에요")
        raise ApiError(403, "FORBIDDEN", FORBIDDEN)
    if not x_internal_key or not secrets.compare_digest(x_internal_key, expected):
        raise ApiError(403, "FORBIDDEN", FORBIDDEN)


InternalKeyDep = Annotated[None, Depends(internal_key)]


@router.get("/metrics", response_model=Metrics)
async def read_metrics(
    repo: MetricsRepoDep,
    now: NowDep,
    _: InternalKeyDep,
    from_: Annotated[str | None, Query(alias="from", description="YYYY-MM-DD(KST)")] = None,
    to: Annotated[str | None, Query(description="YYYY-MM-DD(KST)")] = None,
) -> Metrics:
    """기간 지표. 기간을 주지 않으면 오늘까지 30일이다(KST 날짜, 양 끝 포함).

    판정 불가 비율만 기간이 아니라 지금 저장된 판정 기준이다(저장소 머리말).
    """
    today = now.astimezone(KST).date()
    end = _day(to, "to") if to else today
    start = _day(from_, "from") if from_ else end - timedelta(days=DEFAULT_DAYS - 1)
    if end < start:
        raise _invalid({"to": "끝 날짜는 시작 날짜보다 뒤여야 해요."})
    return await repo.metrics((start, end))


@router.post("/eval/run", response_model=EvalRunResult)
async def run_eval(
    body: EvalRunRequest,
    settings: Annotated[Settings, Depends(get_settings)],
    _: InternalKeyDep,
) -> EvalRunResult:
    """테스트 시나리오를 돌린다(PRD 8장). 돌린 기록은 `agent_runs`에 남고 지표 집계가 읽는다.

    DB 연결을 쥐지 않는다(저장소 의존이 없다). 시나리오는 자기 연결·풀을 따로 열고, 끝나면 만든
    사용자·공고를 지운다. 그래서 **시험용 DB**에서만 돌 수 있다.
    """
    # app.eval은 앱을 만들어 쓰므로(app.main) 모듈 맨 위에서 가져오면 순환 import가 된다
    from app.eval import pick, run_scenarios
    from app.eval.world import DEFAULT_NOW

    try:
        scenarios = pick(body.scenario_codes)
    except KeyError as exc:
        raise _invalid({"scenario_codes": str(exc).strip("'")}) from exc
    if not settings.database_url:
        raise ApiError(503, "DB_UNAVAILABLE", "데이터베이스에 연결할 수 없어요.")
    try:
        report = await run_scenarios(settings.database_url, scenarios, now=body.now or DEFAULT_NOW)
    except RuntimeError as exc:  # 실제 Supabase DB면 돌리지 않는다(app/eval/world.py)
        logger.warning("시나리오를 돌리지 않았어요: %s", exc)
        raise ApiError(
            409, "EVAL_NOT_ALLOWED", "시나리오는 시험용 DB에서만 돌릴 수 있어요."
        ) from exc
    return EvalRunResult(
        now=report.now,
        priced_on=report.priced_on,
        scenarios=report.total,
        passed=report.passed,
        success_rate=report.success_rate,
        latency=Latency(p50_ms=report.p50, p95_ms=report.p95),
        cost_usd=float(report.cost_usd),

        results=[
            EvalScenarioResult(
                code=result.code,
                title=result.title,
                ok=result.ok,
                latency_ms=result.latency_ms,
                api_ms=result.api_ms,
                run_id=result.run_id,
                cost_usd=float(result.cost_usd),
                llm_calls=result.llm_calls,
                checks=[
                    EvalCheck(
                        what=check.what,
                        expected=check.expected,
                        actual=check.actual,
                        ok=check.ok,
                        kind=check.kind,
                    )
                    for check in result.checks
                ],
                error=result.error,
            )
            for result in report.results
        ],
    )


def _day(value: str, field: str) -> date:
    try:

    except ValueError:

def _invalid(fields: dict[str, str]) -> ApiError:
    return ApiError(422, "VALIDATION_FAILED", "입력값을 확인해 주세요.", {"fields": fields})
```

```python
async with agent_run(connect, trigger="poster_upload", user_id=user.id) as run:

        result = await llm.extract(...)

cost_usd를 빼면 단가표(app/pricing.py)로 비용을 계산한다.

202와 run_id를 먼저 돌려주는 작업(준비하기)은 start_run으로 실행 행만 만들고, 뒤에서
agent_run(run_id=...)으로 이어서 기록한다. 실패 이유가 ApiError면 "코드: 문구"로 남겨
GET /runs/{id}가 학생에게 그대로 보여 준다. 그 밖의 예외는 내부 기록이라 보여 주지 않는다.
"""

import time
from collections.abc import AsyncIterator, Callable
from contextlib import AbstractAsyncContextManager, asynccontextmanager
from dataclasses import dataclass
from datetime import date, datetime, timedelta, timezone
from decimal import Decimal
from typing import Any

from psycopg import AsyncConnection
from psycopg.types.json import Jsonb

from app.errors import ApiError
from app.pricing import cost_usd as priced_cost
from app.schemas.me import PROFILE_FIELDS

# autocommit 연결을 주는 공급자. 풀이면 pool.connection, 풀이 없으면 using(conn)이다
LogConnect = Callable[[], AbstractAsyncContextManager[AsyncConnection]]

SECRET_HINTS = ("token", "secret", "password", "authorization", "api_key")
# 프로필 값은 LLM에도 로그에도 넣지 않는다(PRD 6장). 실수로 들어와도 여기서 지운다
PROFILE_KEYS = frozenset(PROFILE_FIELDS)
_KST = timezone(timedelta(hours=9))


def _hidden(key: str) -> bool:
    lowered = key.lower()
    return lowered in PROFILE_KEYS or any(hint in lowered for hint in SECRET_HINTS)


def scrub(value: Any) -> Any:
    """비밀값이나 프로필 항목 이름의 키는 값을 지운다. tool_calls에 남지 않게 하는 마지막 안전장치."""
    if isinstance(value, dict):
        return {
            key: "[REDACTED]" if _hidden(str(key)) else scrub(item) for key, item in value.items()
        }
    if isinstance(value, list):
        return [scrub(item) for item in value]
    return value


def _elapsed_ms(started: float) -> int:
    return int((time.perf_counter() - started) * 1000)


@dataclass
class ToolCall:
    id: str
    output: Any = None


def using(conn: AsyncConnection) -> LogConnect:
    """이미 연 autocommit 연결 하나를 그대로 쓰는 공급자. 풀이 없는 곳(CLI·테스트)에서 쓴다."""
    _require_autocommit(conn)

    @asynccontextmanager
    async def connect() -> AsyncIterator[AsyncConnection]:
        yield conn

    return connect


@dataclass
class AgentRun:
    connect: LogConnect
    id: str
    input_tokens: int = 0
    output_tokens: int = 0
    cost_usd: Decimal = Decimal(0)
    # 직접 잰 시간(ms). 넣으면 이 값을 agent_runs.latency_ms에 쓴다. 비우면 agent_run 블록 전체를 잰다.
    # 블록 끝에 치우는 일이 붙는 실행(시나리오 실행)이 일한 시간만 남기려고 쓴다
    latency_ms: int | None = None
    _seq: int = 0

    @asynccontextmanager
    async def tool(self, name: str, input: dict[str, Any] | None = None) -> AsyncIterator[ToolCall]:
        self._seq += 1
        started = time.perf_counter()
        async with self.connect() as conn:
            cursor = await conn.execute(
                "insert into tool_calls (run_id, seq, tool_name, input, status)"
                " values (%s, %s, %s, %s, 'running') returning id",
                (self.id, self._seq, name, Jsonb(scrub(input or {}))),
            )
            call = ToolCall(id=str((await cursor.fetchone())["id"]))
        status = "failed"
        try:
            yield call
            status = "succeeded"
        finally:
            output = Jsonb(scrub(call.output)) if call.output is not None else None
            async with self.connect() as conn:
                await conn.execute(
                    "update tool_calls set output = %s, status = %s, latency_ms = %s where id = %s",
                    (output, status, _elapsed_ms(started), call.id),
                )

    async def record_llm(
        self,
        *,
        provider: str,
        model: str,
        input_tokens: int,
        output_tokens: int,
        latency_ms: int,
        cost_usd: Decimal | float | None = None,
        tool_call: ToolCall | None = None,
        priced_on: date | None = None,
    ) -> None:
        """LLM 호출 1건. cost_usd를 빼면 priced_on(기본: 오늘 KST)의 단가로 계산한다."""
        if cost_usd is None:
            on = priced_on or datetime.now(_KST).date()
            cost = priced_cost(provider, model, input_tokens, output_tokens, on)
        else:
            cost = Decimal(str(cost_usd))
        async with self.connect() as conn:
            await conn.execute(
                "insert into llm_calls (run_id, tool_call_id, provider, model, input_tokens,"
                " output_tokens, cost_usd, latency_ms) values (%s, %s, %s, %s, %s, %s, %s, %s)",
                (
                    self.id,
                    tool_call.id if tool_call else None,
                    provider,
                    model,
                    input_tokens,
                    output_tokens,
                    cost,
                    latency_ms,
                ),
            )
        self.input_tokens += input_tokens
        self.output_tokens += output_tokens
        self.cost_usd += cost


async def start_run(
    connect: LogConnect,
    *,
    trigger: str,
    user_id: str | None = None,
    scenario_code: str | None = None,
) -> str:
    """실행 행만 만든다(status running). 이어서 agent_run(run_id=...)으로 기록하거나 abandon_run으로 닫는다."""
    async with connect() as conn:
        _require_autocommit(conn)
        cursor = await conn.execute(
            "insert into agent_runs (user_id, trigger_type, scenario_code) values (%s, %s, %s)"
            " returning id",
            (user_id, trigger, scenario_code),
        )
        return str((await cursor.fetchone())["id"])


async def abandon_run(connect: LogConnect, run_id: str, error: ApiError) -> None:
    """시작하지 않을 실행을 실패로 닫는다(같은 공고를 그새 다른 요청이 준비하기 시작했을 때 등)."""
    async with connect() as conn:
        await conn.execute(
            "update agent_runs set status = 'failed', finished_at = now(), latency_ms = 0,"
            " error_message = %s where id = %s and status = 'running'",
            (error_text(error), run_id),
        )


@asynccontextmanager
async def agent_run(
    connect: LogConnect,
    *,
    trigger: str,
    user_id: str | None = None,
    scenario_code: str | None = None,
    run_id: str | None = None,
) -> AsyncIterator[AgentRun]:
    """실행 하나를 기록한다. connect는 autocommit 연결 공급자다(db.get_log_connect, 또는 using(conn)).

    한 줄 쓸 때마다 빌렸다 돌려주므로, 모델을 기다리는 동안 로그 연결을 쥐지 않는다.
    autocommit이어야 실패한 실행도 남는다. run_id를 주면 start_run으로 만든 행을 이어서 쓴다
    (latency_ms는 여기부터 잰다).
    """
    started = time.perf_counter()
    if run_id is None:
        run_id = await start_run(
            connect, trigger=trigger, user_id=user_id, scenario_code=scenario_code
        )
    else:
        async with connect() as conn:
            _require_autocommit(conn)
    run = AgentRun(connect=connect, id=run_id)
    try:
        yield run
    except Exception as exc:
        await _finish(run, started, "failed", error_text(exc))
        raise
    await _finish(run, started, "succeeded", None)


def error_text(exc: BaseException) -> str:
    """agent_runs.error_message. ApiError는 "코드: 문구", 그 밖은 내부 기록(repr)이다."""
    if isinstance(exc, ApiError):
        return f"{exc.code}: {exc.message}"[:500]
    return repr(exc)[:500]


def _require_autocommit(conn: AsyncConnection) -> None:
    if not conn.autocommit:
        raise RuntimeError("agent_run에는 autocommit 연결 공급자(get_log_connect)를 넘겨야 해요.")


async def _finish(run: AgentRun, started: float, status: str, error: str | None) -> None:
    latency = run.latency_ms if run.latency_ms is not None else _elapsed_ms(started)
    async with run.connect() as conn:
        await conn.execute(
            "update agent_runs set status = %s, finished_at = now(), latency_ms = %s,"
            " input_tokens = %s, output_tokens = %s, cost_usd = %s, error_message = %s"
            " where id = %s",
            (
                status,
                latency,
                run.input_tokens,
                run.output_tokens,
                run.cost_usd,
                error,
                run.id,
            ),
        )
```

```python
    def json(self) -> dict[str, Any]:

        return {**found, "kind": self.kind} if self.kind else found


class CheckFailed(AssertionError):
    """기대한 결과에 닿지 못했다. 시나리오는 여기서 멈추고 실패로 남는다."""

    def __init__(self, check: Check) -> None:
        super().__init__(f"{check.what}: 기대 {check.expected!r} · 실제 {check.actual!r}")
        self.check = check


@dataclass
class ScenarioResult:
    code: str
    title: str
    ok: bool
    latency_ms: int  # 시나리오가 끝까지 가는 데 걸린 시간(세계를 만드는 시간도 들어 있다)
    api_ms: float = 0.0  # 그중 엔드포인트가 쓴 시간 합(응답시간 지표)
    run_id: str | None = None  # 시나리오 실행(agent_runs, trigger eval)
    # 이 시나리오에 딸린 다른 실행(공고에 붙인 수집, 준비하기, 포스터 추출). 같은 번호가 붙어 있다
    child_run_ids: list[str] = field(default_factory=list)
    cost_usd: Decimal = Decimal(0)
    llm_calls: int = 0
    checks: list[Check] = field(default_factory=list)
    error: str | None = None  # 실패 이유 한 줄(기대와 다른 결과이거나 터진 예외)

    def json(self) -> dict[str, Any]:
        return {
            "code": self.code,
            "title": self.title,
            "ok": self.ok,
            "latency_ms": self.latency_ms,
            "api_ms": self.api_ms,
            "run_id": self.run_id,
            "child_run_ids": self.child_run_ids,
            "cost_usd": float(self.cost_usd),
            "llm_calls": self.llm_calls,
            "checks": [check.json() for check in self.checks],
            "error": self.error,
        }


@dataclass
class Report:
    """한 번 돌린 결과 전체. W6 베이스라인으로 이 JSON을 고정 저장한다(PRD 8장)."""

    now: datetime  # 주입한 시계
    # 단가를 고른 날(app/pricing.py). 단가가 바뀌면 같은 now로 돌려도 비용이 달라진다
    priced_on: date | None = None  # noqa
    results: list[ScenarioResult] = field(default_factory=list)

    @property
    def total(self) -> int:
        return len(self.results)

    @property
    def passed(self) -> int:
        return sum(1 for result in self.results if result.ok)

    @property
    def success_rate(self) -> float:
        """E2E 성공률. 0건이면 0.0이다."""
        return round(self.passed / self.total, 4) if self.total else 0.0

    @property
    def latencies(self) -> list[int]:
        return [result.latency_ms for result in self.results]

    @property
    def p50(self) -> int:
        return percentile(self.latencies, 50)

    @property
    def p95(self) -> int:
        return percentile(self.latencies, 95)

    @property
    def api_ms(self) -> float:
        return round(sum(result.api_ms for result in self.results), 1)

    @property
    def cost_usd(self) -> Decimal:
        return sum((result.cost_usd for result in self.results), Decimal(0))

    @property
    def llm_calls(self) -> int:
        return sum(result.llm_calls for result in self.results)

    def json(self) -> dict[str, Any]:
        return {
            "now": self.now.isoformat(),
            "priced_on": self.priced_on.isoformat() if self.priced_on else None,
            "scenarios": self.total,
            "passed": self.passed,
            "success_rate": self.success_rate,
            "latency_ms": {"p50": self.p50, "p95": self.p95},
            "api_ms": self.api_ms,
            "cost_usd": float(self.cost_usd),
            "llm_calls": self.llm_calls,
            "results": [result.json() for result in self.results],
        }


def percentile(values: Sequence[int], pct: float) -> int:
    """가장 가까운 순위(nearest-rank) 백분위수. 시나리오가 몇 개뿐이라 값을 섞지 않고 그중 하나를 고른다."""
    if not values:
        return 0
    ordered = sorted(values)
    rank = max(math.ceil(pct / 100 * len(ordered)), 1)
    return ordered[rank - 1]


def plain(value: Any) -> Any:
    """JSON으로 남길 수 있는 값으로 바꾼다(tool_calls.output·베이스라인 JSON에 넣는다)."""
    if isinstance(value, BaseModel):
        return plain(value.model_dump(mode="json"))
    if isinstance(value, dict):
        return {str(key): plain(item) for key, item in value.items()}
    if isinstance(value, (set, frozenset)):
        return sorted(plain(item) for item in value)
    if isinstance(value, (list, tuple)):
        return [plain(item) for item in value]
    if isinstance(value, (datetime, date)):
        return value.isoformat()
    if isinstance(value, Decimal):
        return float(value)
    return value
```

```python
"""시나리오를 차례로 돌리고 성공률·응답시간·비용을 모은다(PRD 8장 지표).

시나리오 하나 = `agent_runs` 한 줄(trigger `eval`, scenario_code `S01`). 그 아래 `tool_calls`에
확인한 것을 `check` 한 줄씩 남긴다 — 다음 PR의 판정 혼동행렬이 이 줄을 읽는다.

시나리오가 뒤에서 만든 실행(준비하기·포스터 추출)은 끝난 뒤 같은 scenario_code를 붙인다. 비용과 LLM
호출 수는 **그 실행들의 `llm_calls`를 더해서** 센다. 시나리오 실행 행 자신의 cost_usd는 0으로 둔다
(제 손으로 모델을 부르지 않는다). 집계하는 쪽은 `agent_runs.cost_usd`를 다시 더하지 말고
scenario_code로 묶은 `llm_calls`를 본다 — 그러지 않으면 같은 비용을 두 번 센다.

시나리오는 한 번에 하나만 돈다. 사용자·공고를 만들고 지우는 동안 다른 시나리오가 끼어들면 피드에
남의 공고가 섞인다.
"""

from __future__ import annotations

import logging
import time
from collections.abc import Sequence
from datetime import datetime
from decimal import Decimal

import psycopg

from app.agent_log import agent_run, using
from app.config import Settings
from app.eligibility import KST
from app.eval.fakes import RecordedCalendar, RecordedLlm, RecordedStorage
from app.eval.models import CheckFailed, Report, ScenarioResult
from app.eval.world import (
    DEFAULT_NOW,
    EvalWorld,
    Scenario,
    connect,
    eval_settings,
    managed_database,
    open_app,
)

logger = logging.getLogger(__name__)
TRIGGER = "eval"
DRAIN_SECONDS = 60.0  # 뒤에서 도는 일을 기다리는 상한(app/main.py의 종료와 같은 뜻)


async def run_scenarios(
    database_url: str,
    scenarios: Sequence[Scenario],
    *,
    now: datetime = DEFAULT_NOW,
) -> Report:
    """시나리오를 차례로 돌린다. 하나가 실패해도 나머지를 돈다(성공률을 재는 것이 목적이다)."""
    if problem := managed_database(database_url):
        raise RuntimeError(problem)
    settings = eval_settings(database_url)
    setup = await connect(database_url)
    log_conn = await connect(database_url)
    # 단가는 돌린 날로 고른다(app/agent_log.py의 record_llm). 베이스라인을 비교할 때 이 날짜를 본다
    report = Report(now=now, priced_on=datetime.now(KST).date())
    try:
        for scenario in scenarios:
            result = await _one(scenario, settings=settings, setup=setup, log=log_conn, now=now)
            report.results.append(result)
    finally:
        for conn in (setup, log_conn):
            try:
                await conn.close()
            except Exception:
                logger.exception("연결을 닫지 못했어요")
    return report


async def _one(
    scenario: Scenario,
    *,
    settings: Settings,
    setup: psycopg.AsyncConnection,
    log: psycopg.AsyncConnection,
    now: datetime,
) -> ScenarioResult:
    llm, storage, calendar = RecordedLlm(), RecordedStorage(), RecordedCalendar()
    world: EvalWorld | None = None
    run_id: str | None = None
    children: list[str] = []
    elapsed_ms = 0
    ok, error = True, None
    try:
        app, pool, log_pool = await open_app(
            settings, now=now, llm=llm, storage=storage, calendar=calendar
        )
        try:
            async with agent_run(using(log), trigger=TRIGGER, scenario_code=scenario.code) as run:
                run_id = run.id
                world = EvalWorld(
                    conn=setup,
                    app=app,
                    settings=settings,
                    now=now,
                    run=run,
                    scenario_code=scenario.code,
                    llm=llm,
                    storage=storage,
                    calendar=calendar,
                )
                started = time.perf_counter()
                try:
                    await scenario.run(world)
                    await _finished(world)
                finally:
                    elapsed_ms = int((time.perf_counter() - started) * 1000)
                    # 실행 기록에도 같은 값을 남긴다. 아래 치우는 시간은 응답시간이 아니다
                    run.latency_ms = elapsed_ms
                    # 뒤에서 도는 일(준비하기·포스터 추출)을 먼저 끝낸다. 확인이 틀려 중간에 멈췄으면
                    # 아직 도는 일이 있고, 그 일이 쥔 연결을 두고 풀을 닫으면 안 된다
                    await app.state.runner.drain(timeout=DRAIN_SECONDS)
                    children = world.extra_runs + await _tag_children(
                        setup, scenario.code, run.id, world.users
                    )
                    await world.cleanup()
                    _check_drained(app.state.runner.running, scenario.code)
        finally:
            await pool.close()
            await log_pool.close()
    except CheckFailed as exc:
        ok, error = False, str(exc)
    except Exception as exc:  # 시나리오가 터져도 나머지 시나리오를 돈다
        logger.exception("시나리오 %s가 터졌어요", scenario.code)
        ok, error = False, f"{type(exc).__name__}: {exc}"
    cost, calls = await _usage(setup, [run_id, *children] if run_id else children)
    return ScenarioResult(
        code=scenario.code,
        title=scenario.title,
        ok=ok,
        latency_ms=elapsed_ms,
        api_ms=round(world.api_ms, 1) if world else 0.0,
        run_id=run_id,
        child_run_ids=children,
        cost_usd=cost,
        llm_calls=calls,
        checks=list(world.checks) if world else [],
        error=error,
    )


async def _finished(world: EvalWorld) -> None:
    """시나리오가 끝났을 때 맞아야 하는 것. 조용히 통과하는 시나리오를 막는다."""
    if not world.checks:
        raise AssertionError("확인(check)이 하나도 없는 시나리오예요")
    if world.llm.replies:
        # 서류 사전이 늘어 모델을 안 부르게 되면 비용이 0이 되는데, 확인은 다 통과한다
        raise AssertionError(f"쓰지 않은 녹화 답이 {len(world.llm.replies)}개 남았어요")


def _check_drained(running: int, code: str) -> None:
    """뒤에서 도는 일을 못 끝냈으면 그 시나리오는 실패다. 비용이 빠지고 기록도 반쪽이 된다."""
    if running:
        raise TimeoutError(
            f"{code}: 뒤에서 도는 일 {running}개가 {DRAIN_SECONDS}초 안에 안 끝났어요"
        )


async def _tag_children(
    conn: psycopg.AsyncConnection, code: str, run_id: str, users: Sequence[str]
) -> list[str]:
    """시나리오가 돌면서 생긴 실행에 시나리오 번호를 붙인다. 붙인 실행 번호를 돌려준다.

    치우기 전에 불러야 한다. 사용자를 지우면 agent_runs.user_id가 null이 되어 더는 찾을 수 없다.
    실패해도 올리지 않는다(치우기를 막지 않게). 그 실행의 비용은 0으로 보인다.
    """
    if not users:
        return []
    try:
        rows = await (
            await conn.execute(
                # 시나리오 실행 자신은 user_id가 없어 걸리지 않지만 분명히 해 둔다
                "update agent_runs set scenario_code = %s where id <> %s and scenario_code is null"
                " and user_id = any(%s::uuid[]) returning id::text as id",
                (code, run_id, list(users)),
            )
        ).fetchall()
    except Exception:
        logger.exception("자식 실행에 시나리오 번호를 붙이지 못했어요: %s", code)
        return []
    return [row["id"] for row in rows]


async def _usage(conn: psycopg.AsyncConnection, run_ids: Sequence[str]) -> tuple[Decimal, int]:
    """시나리오 1회의 LLM 비용과 호출 수(실행 로그의 토큰 × 단가로 이미 계산된 값)."""
    if not run_ids:
        return Decimal(0), 0
    row = await (
        await conn.execute(
            "select coalesce(sum(cost_usd), 0) as cost, count(*) as calls from llm_calls"
            " where run_id = any(%s::uuid[])",
            (list(run_ids),),
        )
    ).fetchone()
    assert row is not None
    return Decimal(str(row["cost"])), int(row["calls"])
```

```python
async def s07(world: EvalWorld) -> None:

async def _detail(world: EvalWorld, client: httpx.AsyncClient, opportunity: str) -> dict:
    response = await client.get(world.path(f"/opportunities/{opportunity}"))
    response.raise_for_status()
    body: dict = response.json()
    return body


def _born_on_last_day(on: date, age: int) -> date:
    """on 날짜에 만 age세인 마지막 날이 되도록 하는 생일(다음 날 age+1세가 된다)."""
    turns = on + timedelta(days=1)
    try:
        return turns.replace(year=turns.year - age - 1)
    except ValueError:  # 2월 29일생: 그 해가 윤년이 아니면 민법상 3월 1일에 나이가 오른다
        return turns.replace(year=turns.year - age - 1, day=28)


def _day(moment: str | None) -> str | None:
    """KST 오프셋이 붙은 시각의 날짜(YYYY-MM-DD)."""
    return datetime.fromisoformat(moment).date().isoformat() if moment else None

        raise KeyError("고를 시나리오 번호를 적어 주세요 (예: S01,S13)")
    if unknown := [code for code in codes if code not in BY_CODE]:
        raise KeyError(f"모르는 시나리오: {', '.join(unknown)}")
    return [BY_CODE[code] for code in codes]
```

```python
    def _token(self, user_id: str) -> str:
        """로그인 토큰. 유효 기간은 **이 컴퓨터의 지금**으로 잰다 — 주입한 시계는 업무 규칙에만 쓴다.

            "sub": user_id,
            "aud": "authenticated",
            "role": "authenticated",
            "exp": issued + 3600,
            "iat": issued - 60,
            "email": f"{user_id[:8]}@eval.invalid",
            "user_metadata": {"full_name": "시나리오 학생"},

        return jwt.encode(claims, self.settings.supabase_jwt_secret, algorithm="HS256")

        self, client: httpx.AsyncClient, run_id: str, *, timeout: float = RUN_TIMEOUT_SECONDS

    async def check(
        self, what: str, *, expected: Any, actual: Any, kind: str | None = None
    ) -> None:
        """기대와 실제를 맞춰 보고 실행 기록에 한 줄 남긴다. 다르면 시나리오를 여기서 멈춘다.

        남는 곳이 tool_calls.input·output이므로 **프로필 값과 토큰은 넘기지 않는다**(ERD의 컬럼 설명,
        api/CLAUDE.md). `scrub`은 키 이름으로만 지우니 값은 걸러 주지 못한다. 나이·평점처럼 프로필에서
        온 값은 그대로 쓰지 말고 맞는지(bool)나 항목 이름으로 바꿔서 확인한다.

        kind는 집계가 골라 읽을 종류다. 판정 확인은 check를 바로 부르지 말고 judged를 쓴다.
        """
        found = Check(what, plain(expected), plain(actual), kind)
        self.checks.append(found)
        recorded = {"what": found.what, "expected": found.expected}
        async with self.run.tool(CHECK_TOOL, recorded | ({"kind": kind} if kind else {})) as call:
            call.output = {"actual": found.actual, "ok": found.ok}
            if not found.ok:
                raise CheckFailed(found)

    async def judged(self, what: str, *, expected: str, actual: Any) -> None:
        """판정 확인. 판정 혼동행렬(PRD 8장)이 이 줄만 읽는다.

                f"판정 확인의 기대값은 {ELIGIBILITY_STATUSES} 중 하나다: {expected!r}"

    async def add(
        self,
        title: str,
        *,
        days: float | None,
        requirements: Sequence[Rule] = (),
        documents: Sequence[str] = (),
        **columns: Any,
    ) -> str:
        """공고 하나. days는 고정 시각(now)에서 센 마감일이고, None이면 상시다."""
        values: dict[str, Any] = {
            "source_type": "school_notice",
            "category": "scholarship",
            "title": title,
            "organizer": "학생지원팀",
            "easy_summary": f"{title} 쉬운 설명",
            "deadline_at": None if days is None else self.now + timedelta(days=days),
            "extraction_run_id": await self.extraction_run(),
            **columns,
        }
        insert = sql.SQL(
            "insert into opportunities ({names}) values ({marks}) returning id"
        ).format(
            names=sql.SQL(", ").join(sql.Identifier(name) for name in values),
            marks=sql.SQL(", ").join(sql.Placeholder() * len(values)),
        )
        row = await (await self.conn.execute(insert, tuple(values.values()))).fetchone()
        assert row is not None
        opportunity_id = str(row["id"])
        self.opportunities.append(opportunity_id)
        for index, rule in enumerate(requirements):
            await self.conn.execute(
                # 추출 저장(save_extraction)처럼 넣은 순서를 created_at에 남긴다
                "insert into requirements (opportunity_id, clause_no, field, operator, value,"
                " basis, is_ambiguous, evidence_text, created_at)"
                " values (%s, %s, %s, %s, %s, %s, %s, %s, now() + %s * interval '1 microsecond')",
                (
                    opportunity_id,
                    rule.clause_no,
                    rule.field,
                    rule.operator,
                    Jsonb(rule.value),
                    rule.basis,
                    rule.is_ambiguous,
                    f"{title} 근거",
                    index,
                ),
            )
        for name in documents:
            await self.conn.execute(
                "insert into opportunity_documents (opportunity_id, name) values (%s, %s)",
                (opportunity_id, name),
            )
        return opportunity_id

    async def youth(self, policy: Mapping[str, Any]) -> str:
        """온통청년 정책 하나를 실제 변환 코드로 공고로 만든다(F-11, LLM 없음).

        importer.collect가 아니라 convert + save_policy를 부른다. collect는 목록에서 사라진 정책을
        숨기는 일(retire)까지 하므로, 시나리오가 만들지 않은 공고까지 건드린다. 요건은 같은 코드로
        만들어진다.

        save_policy는 (source_id, external_id)로 덮어쓰기(upsert)다. 그래서 **같은 번호의 공고가
        이미 있으면 손대지 않고 멈춘다** — 실제로 수집해 둔 정책을 고치고 치울 때 지우면 안 된다.
        """
        source_id = await ensure_source(self.conn)
        record = convert(policy, self.today, region_table())
        if isinstance(record, Skip):
            raise AssertionError(f"녹화한 정책이 걸러졌어요: {record.reason}")
        assert isinstance(record, PolicyRecord)
        found = await self.conn.execute(
            "select id from opportunities where source_id = %s and external_id = %s",
            (source_id, record.external_id),
        )
        if await found.fetchone() is not None:
            raise AssertionError(
                f"이미 수집해 둔 정책({record.external_id})이에요. 시나리오 전용 번호를 쓰세요"
            )
        await save_policy(self.conn, source_id, record, await self.extraction_run())
        row = await (
            await self.conn.execute(
                "select id::text as id from opportunities where source_id = %s and external_id = %s",
                (source_id, record.external_id),
            )
        ).fetchone()
        assert row is not None
        self.opportunities.append(row["id"])
        return str(row["id"])

    async def rows(self, query: str, *params: Any) -> list[dict[str, Any]]:
        """확인용 조회. 시나리오가 화면으로 볼 수 없는 것(캘린더 행 수 등)을 셀 때만 쓴다."""
        return await (await self.conn.execute(query, params)).fetchall()

    async def close(self) -> None:
        """클라이언트를 닫는다. 하나가 실패해도 나머지를 닫는다."""

            try:
                await http.aclose()
            except Exception:
                logger.exception("클라이언트를 닫지 못했어요")
        self._clients.clear()

    async def cleanup(self) -> None:

            statements.append(
                ("delete from opportunities where id = any(%s::uuid[])", (self.opportunities,))
            )
        if self.users:
            # 시나리오가 API로 만든 포스터 공고. 번호를 모르니 올린 사람으로 찾는다
            statements.append(
                ("delete from opportunities where uploaded_by = any(%s::uuid[])", (self.users,))
            )
            statements.append(("delete from auth.users where id = any(%s::uuid[])", (self.users,)))
        if self._departments:
            statements.append(
                ("delete from departments where name = any(%s)", (self._departments,))
            )
        for query, params in statements:
            try:
                await self.conn.execute(query, params)
            except Exception:
                logger.exception("치우지 못한 것이 있어요: %s", query[:60])

async def open_app(
    settings: Settings,
    *,
    now: datetime,
    llm: RecordedLlm,
    storage: RecordedStorage,
    calendar: RecordedCalendar,
) -> tuple[FastAPI, AsyncConnectionPool, AsyncConnectionPool]:
    """실제 풀을 달고 시계·모델·파일 저장소·Google 캘린더만 녹화한 것으로 바꾼 앱.

    lifespan은 돌지 않는다(ASGITransport는 부르지 않는다). 그래서 풀을 여기서 열고 부른 쪽이 닫는다.
    여는 중에 터지면 먼저 연 풀을 닫고 올린다.
    """
    app = create_app(settings)
    pool, log_pool = create_pools(settings.database_url)
    try:
        await pool.open()
        await log_pool.open()
    except Exception:
        await pool.close()
        await log_pool.close()
        raise
    app.state.pool, app.state.log_pool = pool, log_pool

    async def recorded_calendar(
        conn: Annotated[psycopg.AsyncConnection, Depends(get_conn)],
    ) -> CalendarService:
        """토큰 저장소는 실제 DB를 쓰고 Google만 녹화한 것으로 바꾼다."""
        return CalendarService(CalendarRepository(conn), calendar, settings.token_encryption_key)

    app.dependency_overrides.update(
        {
            get_settings: lambda: settings,
            current_time: lambda: now,  # 주입 시계(PRD 8장)
            get_llm: lambda: llm,
            get_storage: lambda: storage,
            get_calendar_service: recorded_calendar,
        }
    )
    return app, pool, log_pool
```
