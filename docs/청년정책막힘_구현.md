# 청년정책 수집 막힘 안내 — 403을 키 탓으로만 말하지 않고, 받는 도중 멈추면 받은 정책까지 넣는다

> 📝 기준: PRD v0.9 F-11 · `청년정책수집_구현.md` · 2026-10-13
>
> 함께 보는 파일: `청년정책수집_구현.md`. 레포에 들어가 있어야 한다

10/13에 미리 보기(`fetch --dry-run`)가 끝나자마자 넣기(`fetch`)를 돌렸더니 온통청년이 HTTP 403과 `{"errorCode":"e001","errorMsg":"invalid api key."}`를 돌려줬다. 키는 맞았다. 같은 키로 미리 보기가 방금 끝났고, 4분 뒤 다시 돌리니 411건이 들어갔다. 그런데 명령은 "온통청년 API 키가 맞지 않아요"라고만 해서 맞는 키를 의심하게 만들었다. 이 PR은 두 가지를 고친다.
- **안내 문구:** 401·403·e001이면 서버가 준 코드와 문구를 붙이고, 키가 틀렸거나 잠깐 막혔을 수 있다고 알린다. 할 일은 "몇 분 뒤 다시 돌리고, 그래도 같으면 키 확인" 순서다.
- **받는 도중 멈춤:** 한 번이라도 받은 뒤에 막히거나 다른 오류(응답 모양 등)가 나면 오류로 끝내지 않고 거기까지 받은 정책을 넣는다. 빠짐없이 받은 것이 아니라 목록에서 사라진 정책은 숨기지 않고, 끝 코드는 1이다. 다시 돌리면 넣은 정책은 그대로 두고 나머지를 넣는다.

**규모와 확인:**
- 바꾸는 파일 4개(api 2개, 테스트 2개). DB 스키마·웹·기준 문서(PRD·ERD·API 명세·판정엔진 규칙)는 바뀌지 않는다.
- api 테스트 12개를 더했다. Linux `482 passed, 43 skipped`, DB를 붙이면 `525 passed`다. 새 동작을 하나씩 되돌리는 시험 20가지가 모두 테스트에 걸렸고, 앞 PR의 받기·명령 시험 28가지도 그대로 걸린다.
- 10/13에 받은 정책 3,234건을 그대로 돌려주는 가짜 온통청년으로 처음부터 막힘, 5쪽부터 막힘, 막힘이 풀린 뒤 다시 넣기, 미리 보기를 돌렸다.

### api (바뀌는 파일)

#### `api/app/youth/client.py`

```python
"""온통청년 청년정책 API(getPlcy) 클라이언트 (PRD F-11, 도구 fetch_youth_policies).

- 요청: GET https://www.youthcenter.go.kr/go/ythip/getPlcy?apiKeyNm=…&rtnType=json&pageNum=…&pageSize=…
- 응답: result.youthPolicyList(정책), result.pagging.totCount(전체 건수). 등록일 최신순이다(10/13 확인).
- 키(YOUTH_API_KEY)는 요청 주소에만 넣는다. 오류 문구·실행 로그·tool_calls에는 넣지 않는다.
- 쪽(100건)이 5xx·연결 오류·JSON 아닌 응답이면 잠시 뒤 한 번 더 받는다(10/13 1차에서 16쪽이 500이었고
  2차에서는 됐다). 그래도 실패하면 10건씩, 그래도 실패한 묶음은 1건씩 나눠 받아 읽지 못한 정책만 건너뛴다.
  첫 쪽도 같다(전체 건수는 처음 받은 묶음에서 안다). 10건 묶음이 앞의 둘 다 실패하면 그 쪽은 통째로
  실패한 것으로 보고, 첫 쪽이 그러면 멈춘다.
- 두 쪽 연속으로 통째로 실패하거나, 받기가 연속 OUTAGE_FAILURES번 실패하면(온통청년이 멈춤) 멈춘다. 호출은
  max_calls번까지다.
- 401·403·e001("invalid api key.")은 키가 틀렸을 때도, 맞는 키로 잠깐 막혔을 때도 온다(10/13: 미리 보기 바로
  뒤 넣기에서 403 e001, 4분 뒤 다시 돌리니 됐다). 다시 받지 않고 서버가 준 코드·문구와 함께 둘 다일 수 있다고 알린다.
- 한 번이라도 받은 뒤에 멈추면(막힘, 응답 모양 오류 등) 오류로 끝내지 않고 거기까지 받은 정책을 돌려준다(stopped).
- 전체 건수가 0이거나 받는 동안 바뀌면 빠짐없이 받은 것으로 보지 않는다(목록에서 사라진 정책을 숨기지 않는다).
"""

import asyncio
import time
from dataclasses import dataclass
from typing import Any

import httpx

from app.logging_redact import redact

BASE_URL = "https://www.youthcenter.go.kr"
POLICY_PATH = "/go/ythip/getPlcy"
PAGE_SIZE = 100
SMALL_PAGE = 10
USER_AGENT = "UNIPIVOT-bot/0.3 (student capstone project)"
SHAPE_ERROR = "온통청년 응답 모양이 달라요(result.youthPolicyList·result.pagging.totCount)"
FIRST_PAGE_ERROR = "온통청년에서 정책 목록을 받지 못했어요(첫 쪽이 두 번 실패)"
BLOCKED_ERROR = (
    "온통청년이 요청을 막았어요({detail}). 키가 틀렸거나, 방금 여러 번 불러 잠깐 막혔을 수 있어요."
    " 몇 분 뒤 다시 돌려 보고, 그래도 같으면 api/.env의 YOUTH_API_KEY를 확인하세요"
)
OUTAGE_FAILURES = 12  # 받기가 연속으로 이만큼 실패하면 멈춘다(응답 없음 30초씩이면 6분)


class YouthApiError(Exception):
    """온통청년 API를 쓸 수 없음. 메시지는 키 없이 사람에게 보여도 되는 한 줄이다. midway는 받는 도중에 났을 때
    FetchResult.stopped에 남기는 짧은 이유다(없으면 메시지)."""

    def __init__(self, message: str, *, midway: str | None = None) -> None:
        super().__init__(message)
        self.midway = midway or message


class _Retry(Exception):
    """잠깐 실패(5xx, 연결 오류, JSON 아닌 응답). 다시 받으면 될 수 있다."""


class _CallLimit(Exception):
    """호출 한도(max_calls)에 닿음."""


class _Outage(Exception):
    """받기가 연속 OUTAGE_FAILURES번 실패함."""


@dataclass(frozen=True)
class FetchResult:
    policies: tuple[dict[str, Any], ...]
    total: int  # 처음 받은 묶음의 totCount
    calls: int
    skipped: tuple[int, ...]  # 읽지 못하고 건너뛴 순번(0부터)
    stopped: str | None  # 끝까지 받지 못한 이유
    total_changed: bool  # 받는 동안 전체 건수가 바뀜(쪽이 밀려 빠진 정책이 있을 수 있다)
    seconds: float

    @property
    def complete(self) -> bool:
        """목록을 빠짐없이 받았다. 이때만 목록에서 사라진 정책을 숨긴다. 0건이면 아니다."""
        return (
            self.total > 0
            and self.stopped is None
            and not self.skipped
            and not self.total_changed
            and len(self.policies) >= self.total
        )

    def summary(self) -> dict[str, Any]:
        """실행 로그(tool_calls.output)에 남기는 값."""
        return {
            "total": self.total,
            "fetched": len(self.policies),
            "calls": self.calls,
            "skipped": list(self.skipped[:50]),
            "stopped": self.stopped,
            "total_changed": self.total_changed,
            "complete": self.complete,
            "seconds": round(self.seconds, 1),
        }


class YouthPolicyClient:
    def __init__(
        self,
        api_key: str,
        *,
        http: httpx.AsyncClient | None = None,
        base_url: str = BASE_URL,
        retry_delay: float = 2.0,
        page_delay: float = 0.2,
        max_calls: int = 600,
    ) -> None:
        if not api_key.strip():
            raise YouthApiError("YOUTH_API_KEY가 비어 있어요(api/.env)")
        self._key = api_key.strip()
        self._http = http or httpx.AsyncClient(timeout=30)
        self._url = base_url.rstrip("/") + POLICY_PATH
        self._retry_delay = retry_delay
        self._page_delay = page_delay
        self._max_calls = max_calls
        self.calls = 0
        self._totals: set[int] = set()  # 응답마다 받은 totCount
        self._first_total: int | None = None  # 처음 받은 응답의 totCount. None이면 아직 받지 못했다
        self._failures = 0  # 연속으로 실패한 받기

    async def aclose(self) -> None:
        await self._http.aclose()

    async def fetch_all(self) -> FetchResult:
        started = time.monotonic()
        self._totals = set()
        self._first_total = None
        self._failures = 0
        found: dict[str, dict[str, Any]] = {}
        skipped: list[int] = []
        stopped: str | None = None
        total: int | None = None
        whole_failures = 0
        num = 1
        try:
            while total is None or (num - 1) * PAGE_SIZE < total:
                page = await self._page(num, PAGE_SIZE)
                if page is not None:
                    _add(found, page[0])
                    total = page[1] if total is None else total
                    whole_failures = 0
                    num += 1
                    continue
                total, failed, whole = await self._split(num, total, found)
                if total is None:
                    raise YouthApiError(FIRST_PAGE_ERROR)
                if whole:  # 받은 묶음이 하나도 없음
                    whole_failures += 1
                    if whole_failures >= 2:
                        stopped = f"{num - 1}~{num}쪽을 받지 못함"
                        break
                    skipped.extend(range((num - 1) * PAGE_SIZE, min(num * PAGE_SIZE, total)))
                    num += 1
                    continue
                whole_failures = 0
                for small in failed:
                    for offset in range((small - 1) * SMALL_PAGE, min(small * SMALL_PAGE, total)):
                        single = await self._page(offset + 1, 1)
                        if single is None:
                            skipped.append(offset)
                        else:
                            _add(found, single[0])
                num += 1
        except _CallLimit:
            stopped = f"호출 {self._max_calls}회 한도에 닿음({num}쪽)"
        except _Outage:
            stopped = f"온통청년이 응답하지 않음(연속 {OUTAGE_FAILURES}번 실패, {num}쪽)"
        except YouthApiError as exc:
            if self._first_total is None:  # 아직 한 번도 받지 못했다
                raise
            stopped = f"{num}쪽에서 {exc.midway}"
        return FetchResult(
            policies=tuple(found.values()),
            total=self._first_total or 0,  # 첫 쪽을 나눠 받다 멈춰도 전체 건수를 남긴다
            calls=self.calls,
            skipped=tuple(skipped),
            stopped=stopped,
            total_changed=len(self._totals) > 1,
            seconds=time.monotonic() - started,
        )

    async def _split(
        self, num: int, total: int | None, found: dict[str, dict[str, Any]]
    ) -> tuple[int | None, list[int], bool]:
        """실패한 100건 쪽을 10건씩 받는다. (전체 건수, 실패한 10건 쪽 번호, 통째로 실패).

        전체 건수를 모르면(첫 쪽) 처음 받은 묶음에서 안다. 앞의 두 묶음이 다 실패하면 그 쪽은 통째로 실패한
        것으로 보고 나머지 묶음은 받지 않는다(온통청년이 멈춘 경우 오래 걸리지 않게)."""
        failed: list[int] = []
        got = False
        first = (num - 1) * (PAGE_SIZE // SMALL_PAGE) + 1
        for small in range(first, first + PAGE_SIZE // SMALL_PAGE):
            if total is not None and (small - 1) * SMALL_PAGE >= total:
                break
            if not got and len(failed) >= 2:
                break
            page = await self._page(small, SMALL_PAGE)
            if page is None:
                failed.append(small)
            else:
                got = True
                _add(found, page[0])
                total = page[1] if total is None else total
        return total, failed, not got

    async def _page(self, num: int, size: int) -> tuple[list[dict[str, Any]], int] | None:
        """(정책, totCount). 잠깐 실패면 한 번 더 받고, 그래도 실패하면 None이다."""
        for attempt in range(2):
            if attempt:
                await asyncio.sleep(self._retry_delay)
            try:
                page = await self._get(num, size)
            except _Retry:
                self._failures += 1
                continue
            self._failures = 0
            return page
        return None

    async def _get(self, num: int, size: int) -> tuple[list[dict[str, Any]], int]:
        if self.calls >= self._max_calls:
            raise _CallLimit
        if self._failures >= OUTAGE_FAILURES:
            raise _Outage
        if self.calls:
            await asyncio.sleep(self._page_delay)
        self.calls += 1
        params = {"apiKeyNm": self._key, "rtnType": "json", "pageNum": num, "pageSize": size}
        try:
            response = await self._http.get(
                self._url, params=params, headers={"User-Agent": USER_AGENT}
            )
        except httpx.HTTPError:
            raise _Retry from None  # 오류 문구에 요청 주소(키)가 들어갈 수 있어 이어 붙이지 않는다
        try:
            data = response.json()
        except ValueError:
            data = None
        blocked = isinstance(data, dict) and data.get("errorCode") == "e001"
        if blocked or response.status_code in (401, 403):
            detail = self._detail(response.status_code, data)
            raise YouthApiError(
                BLOCKED_ERROR.format(detail=detail), midway=f"온통청년이 요청을 막음({detail})"
            )
        if response.status_code >= 500:
            raise _Retry
        if response.status_code != 200:
            detail = self._detail(response.status_code, data)
            raise YouthApiError(f"온통청년이 요청을 받지 않았어요({detail})")
        if data is None:
            raise _Retry  # 200인데 JSON이 아님(점검 화면 등)
        if not isinstance(data, dict):
            raise YouthApiError(SHAPE_ERROR)
        if str(data.get("resultCode")) != "200":
            code = data.get("resultCode", data.get("errorCode"))
            message = data.get("resultMessage", data.get("errorMsg"))
            reason = f"{self._clean(code)} {self._clean(message)}".strip() or "모르는 응답"
            raise YouthApiError(f"온통청년 응답 오류: {reason}")
        result = data.get("result")
        items = result.get("youthPolicyList") if isinstance(result, dict) else None
        paging = result.get("pagging") if isinstance(result, dict) else None
        total = paging.get("totCount") if isinstance(paging, dict) else None
        if not isinstance(items, list) or not isinstance(total, int):
            raise YouthApiError(SHAPE_ERROR)
        self._totals.add(total)
        if self._first_total is None:
            self._first_total = total
        return [item for item in items if isinstance(item, dict) and item.get("plcyNo")], total

    def _detail(self, status: int, data: Any) -> str:
        """HTTP 상태와 서버가 준 오류 코드·문구. 예: HTTP 403·e001 invalid api key."""
        text = f"HTTP {status}"
        if isinstance(data, dict):
            code, message = self._clean(data.get("errorCode")), self._clean(data.get("errorMsg"))
            text += (f"·{code}" if code else "") + (f" {message}" if message else "")
        return text

    def _clean(self, value: Any) -> str:
        """서버가 준 글. 요청 값을 되돌려 줄 수도 있어 키를 지우고 100자로 자른다."""
        text = " ".join(("" if value is None else str(value)).split())
        return redact(text.replace(self._key, "[REDACTED]"))[:100].strip()


def _add(found: dict[str, dict[str, Any]], items: list[dict[str, Any]]) -> None:
    """정책 번호로 모은다. 같은 번호는 나중에 받은 값으로 바꾼다(쪽이 밀려 두 번 받은 경우)."""
    for item in items:
        found[str(item["plcyNo"])] = item
```

```python
"""온통청년 청년정책을 받아 공고로 넣는다(PRD F-11). api 폴더에서 실행한다.

    uv run python -m app.youth.cli fetch --dry-run   # DB 없이: 받아서 몇 건이 들어갈지, 요건이 어떻게 되는지 본다
    uv run python -m app.youth.cli fetch             # DB에 넣는다. 새 정책·바뀐 정책만 요건을 다시 만든다

YOUTH_API_KEY가 필요하고, --dry-run이 아니면 DATABASE_URL도 필요하다(api/.env). LLM은 쓰지 않는다.
"""

import argparse
import asyncio
import sys
from collections import Counter
from collections.abc import Callable, Sequence
from datetime import date, datetime

import psycopg

from app.config import Settings
from app.crawl.cli import _connect

ClientFactory = Callable[[str], YouthPolicyClient]
_SAVED = {"new": "새 공고", "updated": "바뀐 공고", "unchanged": "그대로"}
EXAMPLES = 3


def parse_args(argv: Sequence[str]) -> argparse.Namespace:
    parser = argparse.ArgumentParser(

async def main(argv: Sequence[str], *, make_client: ClientFactory = YouthPolicyClient) -> int:
    args = parse_args(argv)
    settings = Settings()
    if not settings.youth_api_key.strip():
        print("YOUTH_API_KEY가 없어요. api/.env에 온통청년 OPEN API 인증키를 넣어 주세요")
        return 1

        return 1

        conn, log_conn = (
            await _connect(settings.database_url),
            await _connect(settings.database_url),
        )

        return 1

    print("온통청년에서 정책을 받아 공고로 넣는 중이에요. 처음 넣을 때는 1~3분 걸려요", flush=True)

            conn,
            log_conn,
            client,
            today=today,

            " 있어요. 온통청년에서 정말 내려간 정책이면 --hide-gone을 붙여 다시 돌려 주세요"
        )
    print(f"실행 기록: agent_runs {result.run_id}")
    return 1 if result.fetch.stopped else 0


async def dry_run(client: YouthPolicyClient, today: date) -> int:
    try:
        fetched = await client.fetch_all()
    except YouthApiError as exc:
        print(str(exc))
        return 1
    finally:
        await client.aclose()
    _print_fetch(fetched, saving=False)
    table = region_table()
    records: list[PolicyRecord] = []
    skips: Counter[str] = Counter()
    for policy in fetched.policies:
        converted = convert(policy, today, table)
        if isinstance(converted, Skip):
            skips[converted.reason] += 1
        else:
            records.append(converted)
    print(f"가져올 정책 {len(records)}건 · 가져오지 않음 {_reasons(skips)}")
    fields = Counter(
        label(_requirement(draft)) for record in records for draft in record.requirements
    )
    empty = sum(1 for record in records if not record.requirements)
    review = sum(1 for r in records if any(d.field == "other" for d in r.requirements))
    print(
        f"조건 없는 정책 {empty}건 · 기타 조건(원문 확인)이 있는 정책 {review}건 · 항목별 조건 수 "
        + " · ".join(f"{name} {count}" for name, count in fields.most_common())
    )
    print("DB에는 넣지 않았어요(--dry-run). 예시:")
    examples = [record for record in records if record.requirements][:EXAMPLES]
    for record in examples or records[:EXAMPLES]:
        deadline = record.deadline_at.strftime("%Y-%m-%d") if record.deadline_at else "없음"
        print(f"  {record.title} · {record.organizer or '-'} · 마감 {deadline}")
        for draft in record.requirements:
            requirement = _requirement(draft)
            text = condition_text(requirement)
            print(f"    {draft.clause_no}. {label(requirement)} {text[:120]}")
        if record.review_reasons:
            print(f"    원문 확인 필요: {', '.join(record.review_reasons)}")
    return 1 if fetched.stopped else 0


def _requirement(draft: RequirementDraft) -> Requirement:
    return Requirement(
        id="-",
        clause_no=draft.clause_no,
        field=draft.field,
        operator=draft.operator,
        value=draft.value,
        basis=draft.basis,
        is_ambiguous=draft.is_ambiguous,
        evidence_text=draft.evidence_text,
    )


def _print_fetch(fetched: FetchResult, *, saving: bool) -> None:
    print(
        f"온통청년 정책 {len(fetched.policies)}건 받음"
        f"(전체 {fetched.total}건, 호출 {fetched.calls}회, {round(fetched.seconds)}초)"
    )
    if fetched.skipped:
        print(f"읽지 못해 건너뛴 정책 {len(fetched.skipped)}건(순번 {list(fetched.skipped[:10])})")
    if fetched.stopped:
        then = (
            "받은 정책은 넣었어요. 몇 분 뒤 다시 돌리면 나머지를 넣어요"
            if saving
            else "몇 분 뒤 다시 돌려 주세요"
        )
        print(f"끝까지 받지 못했어요: {fetched.stopped}. {then}")
    if saving and not fetched.complete:
        print("목록을 빠짐없이 받지 못해 목록에서 사라진 정책은 숨기지 않았어요")


def _reasons(skips: Counter[str]) -> str:
    return " · ".join(f"{reason} {count}" for reason, count in skips.most_common()) or "없음"


if __name__ == "__main__":
    utf8_output()  # 출력을 파이프로 보낼 때 cp949에 없는 글자에서 멈추지 않게(Windows)
    sys.exit(asyncio.run(main(sys.argv[1:]), loop_factory=event_loop_factory()))
```

```python
def server(
    items: list[dict[str, str]],
    *,
    broken: Callable[[int, int], bool] = lambda start, size: False,
    total: Callable[[int, int], int] | None = None,
) -> Callable[[httpx.Request], httpx.Response]:
```

```python
    listed = [policy(plcyNo=f"{PREFIX}{n:03d}", plcyNm=f"정책 {n}") for n in range(150)]
    blocked = httpx.Response(403, json={"errorCode": "e001", "errorMsg": "invalid api key."})

    def make(api_key: str) -> YouthPolicyClient:

        def handle(request: httpx.Request) -> httpx.Response:
            num, size = int(request.url.params["pageNum"]), int(request.url.params["pageSize"])
            if num >= block_from:
                return blocked
            page = {"totCount": len(listed), "pageNum": num, "pageSize": size}
            found = listed[(num - 1) * size : num * size]
            body = {"resultCode": 200, "result": {"pagging": page, "youthPolicyList": found}}
            return httpx.Response(200, json=body)

        return handle

    with respx.mock() as router:

        " 확인하세요"

async def _cleanup(scenario: str) -> None:
    """이 테스트가 만든 행만 지운다. CLI는 autocommit이라 되돌릴 수 없다."""
    async with await psycopg.AsyncConnection.connect(DATABASE_URL, autocommit=True) as conn:
        await conn.execute(
            "delete from opportunities o using sources s where s.id = o.source_id"
            " and s.base_url = %s and o.external_id like %s",
            (BASE_URL, PREFIX + "%"),
        )
        await conn.execute(
            "delete from sources s where s.base_url = %s"
            " and not exists (select 1 from opportunities o where o.source_id = s.id)",
            (BASE_URL,),
        )
        await conn.execute("delete from agent_runs where scenario_code = %s", (scenario,))


async def _statuses(scenario: str) -> tuple[list[str], dict[str, str]]:
    async with await psycopg.AsyncConnection.connect(DATABASE_URL, autocommit=True) as conn:
        runs = await (
            await conn.execute(
                "select status::text from agent_runs where scenario_code = %s order by started_at",
                (scenario,),
            )
        ).fetchall()
        found = await (
            await conn.execute(
                "select external_id, status::text from opportunities where external_id like %s",
                (PREFIX + "%",),
            )
        ).fetchall()
    return [row[0] for row in runs], {row[0].removeprefix(PREFIX): row[1] for row in found}
```
