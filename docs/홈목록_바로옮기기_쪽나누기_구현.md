# 홈 목록 — 관심·숨기기를 누르면 바로 옮겨 보여 주고, 5개씩 쪽으로 나눈다

> 📝 기준: PRD v0.9 F-40·F-45 · API 명세 v0.4 5장 · 2026-10-14
>
> 함께 보는 파일: `관심공고_구현.md`(먼저 합쳤다, main 79803f4)

관심 공고(F-45)를 합친 뒤 홈에서 눌러 보니 두 가지가 걸렸다(10/13).
- **옮겨지는 것이 보이지 않는다:** 관심·숨기기를 눌러도 공고가 그 탭으로 가지 않고 "지금은 목록에서 내린 공고예요. 화면을 새로 고쳐 주세요."가 떴다. 새로 고쳐도 그대로였다.
  - 원인은 8000 포트에 남아 있던 이전 API로 보인다. 관심 공고 PR 전 코드라 새 경로(`PUT /opportunities/{id}/mark`)가 없어 404가 났고, 화면은 404를 "목록에서 내린 공고"로 안내한다. 아래 "합친 뒤 확인" 1번에서 남은 서버를 끄고 다시 띄운다.
  - 서버가 맞아도 화면은 저장 응답을 받은 뒤에야 바뀌었다. 그래서 누른 공고가 어디로 갔는지 눈으로 따라가기 어려웠다.
- **목록이 너무 길다:** 청년정책 410건이 한 목록에 다 나온다.

그래서 두 가지를 정했다(10/13 요청).
- **바로 옮기기:** 누르면 그 자리에서 공고가 탭으로 옮겨지는 것이 보이게 한다.
- **쪽 나누기:** 한 쪽에 5개씩 보인다. 쪽 줄은 번호 + 이전·다음이고, 지원 어려움 묶음은 쪽마다 목록 아래에 두며 펼치면 그 안도 5개씩이다(10/13 선택).

**규모와 확인:**
- web만 바뀐다. 새 파일 7개, 바꾸는 파일 8개다.
  - 새 파일: 쪽 줄·목록·카테고리 칩·홈 상태(불러오는 중·빈 목록) 컴포넌트 4개, 쪽 계산·목록 나누기·카드 초점 3개
  - 바꾸는 파일: 홈·상세 화면, 탭·카드·안내·관심 버튼 컴포넌트, 안내 훅, 전역 CSS
- DB·API 변경이 없다. db push가 필요 없다.
- web `typecheck`·`build`가 통과한다. api는 바뀌지 않아 Windows `497 passed, 52 skipped`, CI `549 passed` 그대로다.
- 실제 모드(웹·API·청년정책 410건)로 120단계, 목 모드로 19단계를 확인했다.
- 새 동작을 하나씩 되돌려 E2E가 잡는지 봤다. web 50가지를 바꿀 때마다 실제 모드로 다시 빌드해 돌렸고 모두 잡혔다(아래 "확인한 것").
- 따로 띄운 검토 에이전트가 두 번 봤다. 두 번 모두 막을 문제는 없었고, 첫 검토 지적 8건과 고친 뒤 다시 본 검토의 지적 5건을 고쳤다(아래 "검토에서 고친 것").

## 합친 뒤 확인

1. **API 다시 띄우기:** 8000 포트에 이전 API가 남아 있으면 관심·숨기기에서 "지금은 목록에서 내린 공고예요" 안내가 뜬다. PowerShell에서 남은 uvicorn을 모두 끄고, 8000 포트가 비었는지 본다.

   ```powershell
   Get-CimInstance Win32_Process -Filter "Name='python.exe'" | Where-Object { $_.CommandLine -match 'uvicorn|spawn_main' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
   Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue
   ```

   두 번째 명령이 아무것도 보이지 않으면 `api`에서 `uv run uvicorn app.main:app --reload`, `web`에서 `npm run dev`로 띄운다(터미널 따로). `http://localhost:8000/docs`에 `PUT /api/v1/opportunities/{opportunity_id}/mark`가 있어야 한다. `--reload`로 띄운 uvicorn은 Windows에서 일하는 프로세스(`spawn_main`)가 따로 있어서, 터미널 창만 닫으면 이전 코드로 계속 떠 있을 수 있다.
2. **바로 옮기기(홈):**
   - 카드의 "☆ 관심"을 누르면 바로 ★로 바뀌고 "관심" 탭 이름이 잠깐 파랗게 커진다. 아래에 "관심 공고에 담았어요 관심 탭 보기"가 뜬다.
   - 카드의 "숨기기"를 누르면 카드가 바로 빠지고, "숨김" 탭 이름이 잠깐 파랗게 커지며 숫자가 는다. 아래에 "숨겼어요 숨김 탭 보기"가 뜬다.
   - "숨김 탭 보기"를 누르면 숨김 탭에서 그 카드가 파란 테두리로 잠깐 감싸인다.
   - 그 카드의 "숨김 풀기"를 누르면 "숨김을 풀었어요 추천 공고 보기"가 뜬다. "추천 공고 보기"를 누르면 추천 공고에서 그 공고가 있는 쪽이 열린다.
3. **쪽 나누기(홈):** 한 쪽에 공고 5개와 그 아래 "‹ 1 2 3 4 5 … 끝 쪽 ›"가 있다. 다음 쪽을 누르면 목록 머리로 올라간다. 탭을 바꿨다 돌아오면 1쪽이다. "지원 어려움 N개"를 펼치면 그 안도 5개씩이다.
4. **상세:** "숨기기"를 누르면 바로 "숨김 풀기"로 바뀌고 안내가 뜬다.

## 남은 것

- **상세에서 돌아오면 1쪽:** 쪽·탭은 화면 상태라 상세에 갔다 돌아오면 추천 공고 1쪽부터 본다. 주소(`?page=`)에 남기면 돌아와도 그 쪽이다. 홈 Route 모양이 바뀌어 따로 한다.
- **서버에서 쪽 받기:** 홈은 지금도 피드를 50개씩 최대 1,000개 받아 화면에서 5개씩 나눈다. 공고가 1,000개를 넘으면 서버 cursor로 쪽을 받게 바꾼다. 그때는 지원 어려움 묶음 개수와 탭 숫자를 서버가 따로 줘야 한다(응답 필드부터 명세에 더한다).
- **로컬 API:** 404 안내의 원인이 이전 API였는지 "합친 뒤 확인" 1번으로 확인한다. 다시 띄운 뒤에도 같은 안내가 뜨면 그 공고 id와 API 로그를 본다.

```typescript
// 홈 공고 목록 쪽 나누기(F-40). 한 쪽에 5개씩이다
export const PAGE_SIZE = 5;

// 고른 쪽. key는 목록이 무엇인지(탭·카테고리·정렬·요약 카드 거르기)이고, 목록이 바뀌면 1쪽으로 돌아간다
export interface PageAt {
  key: string;
  page: number;
}

export interface Paged<T> {
  page: number;
  pageCount: number;
  items: T[];
}

// 공고가 빠져 쪽 수가 줄면 마지막 쪽에 머문다
export function paginate<T>(items: T[], at: PageAt, key: string): Paged<T> {
  const pageCount = Math.max(1, Math.ceil(items.length / PAGE_SIZE));
  const page = Math.min(at.key === key ? at.page : 1, pageCount);
  return { page, pageCount, items: items.slice((page - 1) * PAGE_SIZE, page * PAGE_SIZE) };
}

// 목록에서 index번째(0부터) 공고가 있는 쪽
export function pageOf(index: number): number {
  return Math.floor(index / PAGE_SIZE) + 1;
}

// 쪽 번호 줄. 7쪽까지는 다 보인다. 넘으면 처음·끝·지금 쪽과 그 앞뒤를 보이고 사이는 "gap"(…)으로 줄이되,
// 처음·끝 가까이에서는 번호를 더 보여 늘 일곱 칸이다. 그래서 쪽을 넘겨도 이전·다음 버튼이 제자리에 있다
export function pageNumbers(page: number, pageCount: number): (number | "gap")[] {
  const run = (from: number, to: number) => Array.from({ length: to - from + 1 }, (_, index) => from + index);
  if (pageCount <= 7) return run(1, pageCount);
  if (page <= 4) return [...run(1, 5), "gap", pageCount];
  if (page >= pageCount - 3) return [1, "gap", ...run(pageCount - 4, pageCount)];
  return [1, "gap", page - 1, page, page + 1, "gap", pageCount];
}
```

```typescript
import { useEffect, useRef, type RefObject } from "react";

// 다음 그리기 뒤에 초점을 둘 홈 카드(카드의 data-card 버튼). index는 화면에 보이는 카드 순서다(목록 뒤에 펼친 묶음).
// leave: 표시를 바꿔 카드가 빠진 자리. 같은 순서의 카드, 맨 끝이면 앞 카드, 카드가 없으면 지금 탭 버튼
// back: 저장하지 못해 돌아온 카드. leave·back은 빠진 카드와 함께 초점을 잃었을 때만 옮긴다(그새 다른 곳을 눌렀으면 그대로 둔다)
// page: 쪽을 넘긴 목록의 첫 카드(화면은 목록 머리로 이미 올렸다). reveal: 안내의 "…보기"로 찾아간 카드(화면 가운데로)
// 목록을 다시 받는 중이라 목록이 없으면 요청을 들고 있다가 목록이 나타난 뒤 옮긴다
export type CardFocus = { kind: "leave" | "page"; index: number } | { kind: "back" | "reveal"; id: string };

export default function useCardFocus(listRef: RefObject<HTMLElement | null>) {
  const want = useRef<CardFocus | null>(null);
  useEffect(() => {
    const request = want.current;
    const list = listRef.current;
    if (!request || !list) return;
    want.current = null;
    const active = list.ownerDocument.activeElement;
    const lost = !active || active === list.ownerDocument.body;
    if ((request.kind === "leave" || request.kind === "back") && !lost) return;
    const cards = [...list.querySelectorAll<HTMLElement>("[data-card]")];
    const card =
      "id" in request ? cards.find((entry) => entry.dataset.card === request.id) : cards[Math.min(request.index, cards.length - 1)];
    if (request.kind === "reveal") card?.scrollIntoView({ block: "center" });
    const scrolled = request.kind === "page" || (request.kind === "reveal" && card !== undefined);
    (card ?? list.querySelector<HTMLElement>('[role="group"] [aria-pressed="true"]'))?.focus({ preventScroll: scrolled });
  });
  return want;
}
```

#### `web/src/lib/useToast.ts`

```typescript
import { useCallback, useEffect, useRef, useState } from "react";

// 안내의 버튼 하나(예: 홈의 "관심 탭 보기")
export interface ToastAction {
  label: string;
  onAction: () => void;
}

// 화면 아래 안내(components/Toast)의 글·번호·버튼. 같은 글이 이어 떠도 번호가 바뀌어 화면 읽기 프로그램이 다시 읽는다
export interface ToastState {
  text: string;
  id: number;
  action?: ToastAction;
}

// 안내를 붙잡아 두는 까닭. 안내 위에 마우스가 있거나(hover) 안내 안에 초점이 있으면(focus) 닫지 않는다
export type ToastHold = (reason: "hover" | "focus", on: boolean) => void;

// 안내를 잠깐 띄운다. 안내가 이어 뜨면 앞 안내의 타이머를 지워 새 안내가 일찍 사라지지 않게 한다.
// 버튼이 있으면 누를 시간을 두 배로 준다. 세 번째 값은 안내를 바로 닫고, 네 번째 값(Toast의 onHold)은
// 붙잡는 동안 타이머를 멈췄다가 놓으면 기본 시간 뒤에 닫는다. 새 안내를 띄우거나 닫으면 붙잡은 것도 푼다
export default function useToast(duration = 2200): [ToastState, (text: string, action?: ToastAction) => void, () => void, ToastHold] {
  const [toast, setToast] = useState<ToastState>({ text: "", id: 0 });
  const timer = useRef<ReturnType<typeof setTimeout>>(undefined);
  const holding = useRef({ hover: false, focus: false });
  useEffect(() => () => clearTimeout(timer.current), []);
  const close = useCallback(() => setToast((current) => (current.text ? { id: current.id, text: "" } : current)), []);
  const hide = useCallback(() => {
    clearTimeout(timer.current);
    holding.current = { hover: false, focus: false };
    close();
  }, [close]);
  const show = useCallback(
    (text: string, action?: ToastAction) => {
      clearTimeout(timer.current);
      holding.current = { hover: false, focus: false };
      setToast((current) => ({ text, id: current.id + 1, action }));
      timer.current = setTimeout(close, action ? duration * 2 : duration);
    },
    [close, duration],
  );
  const hold = useCallback<ToastHold>(
    (reason, on) => {
      holding.current[reason] = on;
      clearTimeout(timer.current);
      if (!holding.current.hover && !holding.current.focus) timer.current = setTimeout(close, duration);
    },
    [close, duration],
  );
  return [toast, show, hide, hold];
}
```

```tsx
    setFind(id);
    const n = (foundCount.current += 1);
    setFound({ id, n });
    setTimeout(() => setFound((current) => (current?.n === n ? null : current)), 1600);
    cardFocus.current = { kind: "reveal", id };
    hideToast();
  };

  // 요약 카드 숫자는 추천 공고 기준이라 추천 공고 탭에서 거른다
  const toggleSummary = (filter: SummaryFilter) => {
    setTab("recommended");
    setSummaryFilter((current) => (current === filter ? null : filter));
    setShowIneligible(false);
  };

  const resetFilters = () => {
    setCategory("all");
    selectTab("recommended");
    setSort("deadline");
  };

  // 빈 목록이면 다음 행동 하나를 버튼과 함께 안내한다. 관심·숨김은 지금 고른 카테고리 안에서 본다
  const emptyState = (): EmptyState | null => {
    const all = category === "all";
    if (isEmptyFeed) {
      // 실제 모드는 포스터 등록(W6) 전이라 다시 불러오기를 안내한다
      return POSTER_READY
        ? { title: "포스터를 올리면 공고로 등록하고 자격을 판정해요", action: "포스터 등록", onAction: () => navigate({ name: "upload" }) }
        : { title: "아직 볼 수 있는 공고가 없어요. 새 공고가 올라오면 여기에 보여요", action: "다시 불러오기", onAction: () => setReload((value) => value + 1) };
    }
    if (tabItems.length === 0 && tab === "recommended" && tabCounts.not_interested > 0) {
      const title = all ? "공고를 모두 숨겼어요" : "이 카테고리의 공고를 모두 숨겼어요";
      return { title, action: "숨김 탭 보기", onAction: () => selectTab("not_interested") };
    }
    if (tabItems.length === 0 && tab !== "recommended") {
      const title =
        tab === "interested"
          ? all ? "관심 공고가 없어요. 카드의 ☆ 관심을 누르면 여기에 모여요" : "이 카테고리에는 관심 공고가 없어요"
          : all ? "숨긴 공고가 없어요" : "이 카테고리에는 숨긴 공고가 없어요";
      return all
        ? { title, action: "추천 공고 보기", onAction: () => selectTab("recommended") }
        : { title, action: "전체 카테고리 보기", onAction: () => setCategory("all") };
    }
    if (visibleItems.length + ineligibleItems.length === 0) {
      return { title: "조건에 맞는 공고가 없어요", action: "필터 초기화", onAction: resetFilters };
    }
    return null;
  };
  const empty = emptyState();

  // 서버 답을 기다리지 않고 바로 옮긴다. 들어간 탭을 강조하고 안내에 그 탭 보기 버튼을 단다. 저장하지 못하면 되돌린다
  const changeMark = async (item: OpportunityItem, next: OpportunityMark | null) => {
    const before = item.my_mark;
    const changed = item.id in marks; // 이 화면에서 바꾼 적이 있는 공고(되돌릴 때 그 값으로 돌린다)
    const kept = marks[item.id];
    // 바뀐 뒤 이 탭에서 빠지는 카드면 그 자리로 초점을 옮긴다(보이는 카드 순서는 지금 쪽 목록 뒤에 펼친 묶음).
    // 쪽에 혼자 있던 카드면 앞 쪽으로 넘어가니 앞 쪽의 마지막 카드다
    const leaves = tab === "recommended" ? next === "not_interested" : next !== tab;
    const inGroup = !main.items.some((entry) => entry.id === item.id);
    const own = inGroup ? group : main;
    const index = (inGroup ? main.items.length : 0) + own.items.findIndex((entry) => entry.id === item.id);
    const alone = own.items.length === 1 && own.page > 1;
    const arrival = arrivalTab(before, next);
    const dataAtClick = request.data;
    if (leaves) cardFocus.current = { kind: "leave", index: alone ? index + PAGE_SIZE - 1 : index };
    setMarks((current) => ({ ...current, [item.id]: next }));
    if (arrival) setArrived((current) => ({ tab: arrival, id: (current?.id ?? 0) + 1 }));
    const goTo = arrival && arrival !== tab ? arrival : null;
    showToast(markToast(before, next, "home"), goTo ? { label: showTabLabel(goTo), onAction: () => openTab(goTo, item.id) } : undefined);
    setPending((current) => new Set(current).add(item.id));
    try {
      await setOpportunityMark(item.id, next);
      // 저장하는 사이 목록을 다시 받기 시작했으면 저장 전 값을 읽었을 수 있다. 숫자가 어긋나지 않게 한 번 더 받는다
      if (latestData.current !== dataAtClick) setReload((value) => value + 1);
    } catch (error) {
      // 되돌린다. 이 화면에서 바꾼 적이 없던 공고면 서버 값을 다시 따른다. 초점을 잃었으면(카드가 빠졌거나 안내 버튼이
      // 바뀌었다) 돌아온 카드에, 그 카드가 이 탭에 없으면 지금 탭 버튼에 둔다
      setMarks((current) => {
        const rest = { ...current };
        if (changed) rest[item.id] = kept;
        else delete rest[item.id];
        return rest;
      });
      cardFocus.current = { kind: "back", id: item.id };
      showToast(markError(error));
    } finally {
      setPending((current) => {
        const rest = new Set(current);
        rest.delete(item.id);
        return rest;
      });
    }
  };

  const card = (item: OpportunityItem) => (
    <OpportunityCard
      key={item.id}
      item={item}
      pending={pending.has(item.id)}
      found={found?.id === item.id}
      navigate={navigate}
      onMark={changeMark}
    />
  );

  return withToast(
    <>
      <Header title={`안녕하세요, ${me.display_name}님`} subtitle="나에게 맞는 기회와 이번 주 할 일을 한눈에 확인하세요." />
      <FeedSummary counts={shownCounts} selected={summaryFilter} onToggle={toggleSummary} />
      <section ref={listRef}>
        <div className="flex items-center justify-between gap-3">
          <FeedTabs
            tab={tab}
            counts={tabCounts}
            arrived={arrived}
            onArrivedEnd={(done) => setArrived((current) => (current?.id === done.id ? null : current))}
            onSelect={selectTab}
          />
          <select
            value={sort}
            onChange={(event) => setSort(event.target.value as NonNullable<FeedParams["sort"]>)}
            className="bg-transparent text-[13px] font-medium text-[#667085] outline-none"
          >
            <option value="deadline">마감 임박순</option>
            <option value="recent">최신순</option>
          </select>
        </div>
        <CategoryChips value={category} onChange={setCategory} />
        {empty ? (
          <EmptyBox {...empty} />
        ) : (
          // 쪽을 넘기면 그 목록의 첫 카드에 초점을 둔다(묶음 카드는 목록 카드 뒤에 있다)
          <FeedList
            listKey={listKey}
            main={main}
            group={group}
            groupTotal={ineligibleItems.length}
            showGroup={showIneligible}
            onToggleGroup={() => setShowIneligible((value) => !value)}
            onPage={(page) => {
              setPageAt({ key: listKey, page });
              cardFocus.current = { kind: "page", index: 0 };
            }}
            onGroupPage={(page) => {
              setGroupPageAt({ key: listKey, page });
              cardFocus.current = { kind: "page", index: main.items.length };
            }}
            card={card}
          />
        )}
      </section>
    </>,
  );
}
```
