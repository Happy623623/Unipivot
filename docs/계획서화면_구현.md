# 계획서 화면 (F-14 3부) — 과목 상세의 "계획서" 탭을 실제 API에 연결

> 📝 기준: API 명세 v0.4 6장 `POST /files` · 8장 `POST /syllabi/extract`·`POST /syllabi/{id}/confirm` · 7장 `POST /calendar/events` · 9장 `GET /lms/courses/{id}` · PRD v0.9 F-14 · `docs/Nextjs_이식_가이드.md` W4 · 2026-10-17
>
> 먼저 합칠 것: `계획서추출_구현.md`(PR #48) → `계획서확정_구현.md` → **이 문서**

API는 끝났고 화면만 목이었다. 이 PR이 그 탭을 실제 API에 연결한다. **F-14가 화면으로 끝까지 돈다.**

```text
과목 상세 → "계획서" 탭
  계획서 없음 → [포털에서 강의계획서 열기] [PDF 올리기]
    → POST /files(kind=syllabus) → POST /syllabi/extract → GET /runs/{id}(단계 표시)
    → 확인 표: 제목·날짜·시각 고치고 넣을 것만 체크 · "구글 캘린더에도 넣기"
    → POST /syllabi/{id}/confirm → "할 일 2건을 플래너에 넣었어요 · 캘린더 2건"
  계획서 있음 → 확정한 일정 목록 · 안 넣은 일정은 [캘린더에 넣기] · 확인 안 한 일정은 [N건 확인하기]
```

DB 변경 없음. API는 과목 상세에 **`course.syllabus_id` 한 칸**이 늘었다(아래 "정한 것" 3번).

## 정한 것

1. **확인 화면에서 제목·날짜·시각을 모두 고친다.** 모델이 주차에서 센 날짜는 하루 이틀 어긋날 수 있다. 고른 일정에 날짜나 시각이 비어 있으면 그 줄에 바로 알려 주고 넣지 않는다. 시각을 서버로 보낼 때는 **오프셋(`+09:00`)을 붙인다**.
2. **캘린더 체크는 연결한 학생에게만 보여 주고, 기본은 켬이다.** 연결하지 않은 학생에게는 체크 대신 "구글 캘린더 연결하기"를 둔다 — 연결 없이 체크하면 확정이 통째로 409로 막히기 때문이다. 확정한 뒤에도 일정마다 "캘린더에 넣기"로 넣을 수 있다(`POST /calendar/events`의 `syllabus_item_id`).
3. **확인하지 않은 일정은 다시 올리지 않고 이어서 확인한다.** 추출만 하고 탭을 떠나면 일정은 서버에 `is_confirmed` false로 남는데, 화면이 계획서 번호를 모르면 **다시 올리는 길밖에** 없었다(그러면 앞서 확정한 일정과 할 일·캘린더가 지워진다). 그래서 과목 상세에 `course.syllabus_id`를 더했다. 이제 "확인하지 않은 일정이 N건 있어요 → N건 확인하기"로 바로 연다.
4. **그만두기를 둔다.** 일정을 하나도 못 찾은 계획서에서도 빠져나갈 수 있어야 한다. 그만두면 과목 상세를 다시 받아 "확인하지 않은 일정 N건"으로 이어 준다.
5. **파일 고르기는 버튼이다.** 숨긴 `<input>`을 `<label>`로 감싸면 키보드로 닿지 않는다(탭 순서에서 빠진다). 포스터 화면과 같이 버튼이 숨은 입력을 누르게 하고, 고른 뒤에는 값을 비워 **같은 파일을 다시 고를 수 있게** 한다.
6. **60초를 넘겨도 실패가 아니다.** 실행은 계속 돈다. "계획서를 아직 읽고 있어요. 조금 뒤에 계획서 탭을 다시 열어 주세요"로 알린다(계획서에는 알림이 없어서 "알림으로 알려드릴게요"라고 하면 안 된다).
7. **권한이 끊기면 다시 연결로 보낸다.** 확정 도중이든 캘린더에 넣는 중이든 `409 CALENDAR_NOT_CONNECTED`를 받으면 연결 버튼을 보여 준다. Google에서 취소하고 돌아오면(`?calendar=error`) 그 까닭도 알려 준다.
8. **확정 결과는 "새로 만든" 수로 말한다.** 두 번 눌러도 할 일은 하나라서, `confirmed`가 아니라 `planner_tasks_created`를 센다. 캘린더를 부탁했는데 새로 들어간 것이 없으면 그것도 말한다.
9. **목 모드도 같은 길을 돈다.** 올리기 → 추출(단계 표시) → 확인 → 확정 → **플래너에 할 일이 생기는 것**까지. 이미 계획서가 있는 과목은 `409 SYLLABUS_EXISTS`를 흉내 내고, 상태 미리보기에 "계획서 읽기 실패"를 더했다. 목데이터의 "데이터베이스" 과목만 계획서가 없는 상태다(일정도 없게 고쳤다 — 서버는 계획서 행이 있을 때만 일정을 준다).
10. **깨진 PDF 안내는 종류에 맞춘다**(API). 계획서에 "사진으로 찍어서 올려 주세요"라고 하면 막힌 길을 알려 주는 셈이다 — 계획서는 사진을 받지 않는다.

### 검토에서 고친 것

검토를 한 번 돌렸고 26가지가 나왔다. 그중 **화면이 멈추거나 거짓을 말하는 것**을 고쳤다.

| 지적 | 고친 것 |
| --- | --- |
| **일정을 하나도 못 찾으면 확인 화면에 갇힌다.** 빈 표와 꺼진 버튼뿐이고 나가는 길이 없었다 | "그만두기"를 뒀다. 나가면 과목 상세를 다시 받아 "확인하지 않은 일정 N건"으로 이어 준다 |
| **탭을 옮기면 확인 표가 사라지고, 되살리는 길이 파괴적이었다.** 다시 올리기밖에 없는데 그러면 앞서 확정한 일정·할 일·캘린더가 지워진다 | 과목 상세에 `course.syllabus_id`를 더해 **다시 올리지 않고** 확인 화면을 연다(명세 9장에 적었다) |
| **같은 파일을 다시 고르면 아무 일도 안 일어난다.** 올리다 실패한 뒤 가장 흔한 되돌리기인데 입력값이 그대로라 `change`가 안 뜬다 | 고른 뒤 입력값을 비운다(포스터 화면과 같은 방식) |
| **60초 넘기면 "알림으로 알려드릴게요"**라고 했다. 계획서에는 알림이 없다 | "조금 뒤에 계획서 탭을 다시 열어 주세요"로 바꿨다 |
| **권한이 끊겨도 200 "캘린더 0건"으로 끝났다**(확정 중 409를 일정별 실패로 삼켰다) | 409는 화면까지 올라오고, 그 자리에 연결 버튼을 보여 준다. 목록의 "캘린더에 넣기"도 같다 |
| **"캘린더 연결하고 넣기"는 넣지 않았다.** 연결하고 돌아오면 아무 일도 없었다 | 버튼을 "캘린더 연결하기"로 바꿨다(하는 일만 적는다). 돌아오면 "캘린더에 넣기"가 된다 |
| Google에서 취소하고 돌아온 `?calendar=error`를 **지우기만** 했다 | 까닭을 알려 준다 |
| **422의 `details.fields`를 버렸다** → 빈 제목이면 "입력값을 확인해 주세요."만 떴다 | 서버가 준 항목 오류를 **그 줄 아래**에 보여 준다. 시각이 빈 것도 날짜처럼 막는다 |
| **확정하는 동안 "계획서를 읽고 있어요"**가 떴다. 올리는 중과 읽는 중도 같은 문구였다 | 올리는 중 → 읽는 중 → 넣는 중을 나눴다. 넣는 동안 표는 잠긴다 |
| **성공 안내를 못 보는 일이 많았다.** 확정하면 과목을 다시 받느라 화면이 뼈대로 바뀌며 안내가 사라졌다 | 다시 받는 동안에는 뼈대로 갈아 치우지 않는다 |
| **"일정 N건을 플래너에 넣었어요"가 거짓일 수 있었다.** 두 번 누르면 새로 만든 할 일이 없는데도 같은 말을 했다 | 새로 만든 수를 센다. 캘린더를 부탁했는데 새로 들어간 것이 없으면 그것도 말한다 |
| **시각 칸을 비우면 말없이 09:00**으로 갔다 | 고른 일정은 날짜와 시각이 모두 있어야 넣는다 |
| **"PDF 올리기"가 키보드로 닿지 않았다**(숨긴 입력을 label로 감쌌다) — 첫 걸음부터 막힌다 | 버튼으로 바꿨다. 브라우저로 초점이 가는지 확인했다 |
| 오류 문구가 보조기기에 알려지지 않고, 표의 칸 이름이 줄마다 같았다 | 오류는 `role="status"`, 칸 이름에 일정 제목을 넣고 잘못된 칸에 `aria-invalid`를 붙였다 |
| **깨진 PDF에 "사진으로 찍어서 올려 주세요"**(포스터 문구)가 나갔다 | 종류에 맞춰 "포털 계획서를 브라우저에서 PDF로 저장해 올려 주세요"로 바꿨다(API) |
| **목 모드가 어려운 길을 다 숨겼다.** 올리기 오류·단계 표시·플래너 할 일·확정 422·캘린더 미연결이 모두 도달 불가였다 | 하루 한도 429, 단계 흉내, **플래너 할 일 만들기**, 날짜 없음·중복 id·빈 제목 422, "캘린더 만료"로 409까지 목에서도 돈다 |
| 목데이터의 "데이터베이스" 과목은 `has_syllabus: false`인데 **확정된 일정이 있었다**(서버에는 있을 수 없는 상태) | 계획서가 없는 과목은 일정도 없게 고쳤다 |

## 남은 것

- **자리만 잡힌 캘린더 일정을 줍는 길이 없다**(확정 PR에서 적은 것 그대로다). 확정 중 Google이 502였거나 권한이 끊기면 `external_event_id`가 빈 행이 남는다. 지금은 목록에서 "캘린더에 넣기"를 다시 누르면 그 자리로 들어간다.
- **과목 상세는 일정이 캘린더에 들어갔는지 알려 주지 않는다.** 그래서 "캘린더에 넣기"는 누른 뒤에만 "넣었어요"로 바뀌고, 탭을 다시 열면 또 보인다(두 번 눌러도 일정은 하나다). 칸을 더하려면 명세 9장을 고쳐야 해서 그대로 뒀다.
- **날짜 칸을 비워도 저장해 둔 날짜가 남는다**(명세 8장: `starts_at`을 비워 보내면 그대로 둔다). 고른 일정은 화면에서 막으니 문제가 되지 않지만, "날짜를 지운다"는 길은 없다.
- **목 모드는 캘린더 "고친 일정 수"를 세지 않는다**(늘 0). 실제 모드에서는 시각을 고쳐 다시 확정하면 `calendar_events_moved`가 올라간다.
- **강의자료 요약(`GET /materials/{file_id}`, P1)은 그대로 준비 중 안내다.** 계획서 탭과 같은 과목 화면 안에 있지만 이 PR과 무관하다.
- 실제 포털 계획서 PDF로는 아직 못 돌려 봤다(샌드박스에 그 파일이 없다). **합친 뒤 네 계획서 한 장으로 한 번 돌려 보고**, 날짜가 이상하면 그 PDF의 글자 모양을 알려 줘.

import type { Category, SourceType } from "@/types/api";

const KST_TIME_ZONE = "Asia/Seoul";

function parseDate(value: string | Date): Date {
  if (value instanceof Date) return value;
  return /^\d{4}-\d{2}-\d{2}$/.test(value) ? new Date(`${value}T00:00:00+09:00`) : new Date(value);
}

// KST 날짜 "YYYY-MM-DD"
export function getKstDateKey(value: string | Date): string {
  const parts = new Intl.DateTimeFormat("en-CA", {
    timeZone: KST_TIME_ZONE,
    year: "numeric",
    month: "2-digit",
    day: "2-digit",
  }).formatToParts(parseDate(value));
  const part = (type: Intl.DateTimeFormatPartTypes) => parts.find((item) => item.type === type)?.value ?? "";
  return `${part("year")}-${part("month")}-${part("day")}`;
}

// KST 시각 "HH:MM"(날짜 입력 칸과 짝). 시각을 비워 보낸 일정은 서버가 09:00으로 두었다
export function getKstTimeKey(value: string | Date): string {
  const parts = new Intl.DateTimeFormat("en-GB", {
    timeZone: KST_TIME_ZONE,
    hour: "2-digit",
    minute: "2-digit",
    hour12: false,
  }).formatToParts(parseDate(value));
  const part = (type: Intl.DateTimeFormatPartTypes) => parts.find((item) => item.type === type)?.value ?? "";
  return `${part("hour")}:${part("minute")}`;
}

// 날짜·시각 입력값을 서버에 보낼 시각으로. **오프셋을 함께 보낸다** —
// 안 붙이면 서버가 KST로 읽어 주지만(명세 8장), 보내는 쪽이 분명히 하는 게 맞다
export function toKstIso(date: string, time: string): string {
  return `${date}T${(time || "09:00").slice(0, 5)}:00+09:00`;
}

export function formatKstLongDate(value: string | Date): string {
  return new Intl.DateTimeFormat("ko-KR", {
    timeZone: KST_TIME_ZONE,
    month: "long",
    day: "numeric",
    weekday: "long",
  }).format(parseDate(value));
}

  return new Intl.DateTimeFormat("en-US", {
    timeZone: KST_TIME_ZONE,
    month: "numeric",
    day: "numeric",
  }).format(parseDate(value));
}

export function formatKstDate(value: string | Date): string {

}

export function getDdayValue(
  deadlineAt: string | null,
  now: string | Date = new Date(),
): number | null {
  if (!deadlineAt) return null;
  const deadline = new Date(`${getKstDateKey(deadlineAt)}T00:00:00Z`);
  const today = new Date(`${getKstDateKey(now)}T00:00:00Z`);
  return Math.round((deadline.getTime() - today.getTime()) / 86_400_000);
}

export function formatDday(deadlineAt: string | null, now: string | Date = new Date()): string {
  return formatDdayValue(getDdayValue(deadlineAt, now));
}

// 서버가 계산한 d_day(마감일 - 오늘, KST)를 그대로 표시한다. null은 마감일 없음
export function formatDdayValue(days: number | null): string {
  if (days === null) return "상시";
  if (days === 0) return "D-day";
  return days > 0 ? `D-${days}` : `D+${Math.abs(days)}`;
}

export function isDeadlineSoon(deadlineAt: string | null, now: string | Date = new Date()): boolean {
  const days = getDdayValue(deadlineAt, now);
  return days !== null && days >= 0 && days <= 3;
}

export function formatRelativeTime(
  value: string | Date,
  now: string | Date = new Date(),
): string {
  const elapsed = Math.max(
    0,
    parseDate(now).getTime() - parseDate(value).getTime(),
  );
  const minutes = Math.floor(elapsed / 60_000);
  if (minutes < 1) return "방금 전";
  if (minutes < 60) return `${minutes}분 전`;
  const hours = Math.floor(minutes / 60);
  if (hours < 24) return `${hours}시간 전`;
  return `${Math.floor(hours / 24)}일 전`;

export function confirmStoredSyllabus(
  syllabusId: string,
  asked: SyllabusConfirmItem[],
  registerCalendar: boolean,
): SyllabusConfirmResult | ApiError {
  // 상태 미리보기의 "캘린더 만료"를 고르면 getMe가 연결 안 됨으로 오고(mockClient), 화면은 체크를
  // 숨긴다. 그래도 확정 도중에 권한이 풀리는 길을 보려면 여기서도 같은 기준을 본다
  const calendarConnected =
    getStoredMe().calendar_connected && getDevScenario() !== "calendar_expired";
  const syllabus = stored.get(syllabusId);
  if (!syllabus) {
    return new ApiError("NOT_FOUND", "계획서를 찾을 수 없어요.", 404);
  }
  const sent = new Map(asked.map((item) => [item.id, item]));
  // 검사 순서도 서버와 같게 둔다 — 일정을 먼저 보고, 그다음 캘린더 연결을 본다
  if (asked.some((item) => !syllabus.items.some((row) => row.id === item.id))) {
    return new ApiError(
      "VALIDATION_FAILED",
      "그 계획서에 없는 일정이에요. 화면을 새로 고치고 다시 해 주세요.",
      422,
    );
  }

    return new ApiError(
      "VALIDATION_FAILED",
      "같은 일정이 두 번 들어 있어요. 화면을 새로 고치고 다시 해 주세요.",
      422,
    );
  }
  const undated = asked.filter(
    (item) =>
      item.selected &&
      !(item.starts_at ?? syllabus.items.find((row) => row.id === item.id)?.starts_at),
  );
  if (undated.length > 0) {
    return new ApiError(
      "VALIDATION_FAILED",
      "날짜가 없는 일정은 고를 수 없어요. 날짜를 적거나 선택을 풀어 주세요.",
      422,
    );
  }
  if (asked.some((item) => !item.title.trim())) {
    return new ApiError("VALIDATION_FAILED", "입력값을 확인해 주세요.", 422, {
      fields: { "items.0.title": "일정 이름을 적어 주세요." },
    });
  }
  if (registerCalendar && !calendarConnected) {
    return new ApiError("CALENDAR_NOT_CONNECTED", "Google 캘린더를 연결해 주세요.", 409, {
      reason: "not_connected",
    });
  }
  let confirmed = 0;
  let tasks = 0;
  let events = 0;
  syllabus.items = syllabus.items.map((row) => {
    const fixed = sent.get(row.id);
    if (!fixed) return row;
    const starts_at = fixed.starts_at ?? row.starts_at;
    const course = courseDetails[syllabus.courseId]?.course.short_name ?? null;
    // 플래너에도 넣는다(실제 서버가 하는 일). 날짜는 KST 날짜다

      row.id,
      fixed.title,
      (starts_at ?? "").slice(0, 10),
      course,
      fixed.selected,
    );

      confirmed += 1;
      if (made) tasks += 1;
      if (registerCalendar && starts_at && !syllabus.calendar.has(row.id)) {
        syllabus.calendar.add(row.id);
        events += 1;
      }
    }
    return { ...row, title: fixed.title, starts_at, is_confirmed: fixed.selected };
  });
  return {
    confirmed,
    planner_tasks_created: tasks,
    calendar_events_created: events,
    calendar_events_moved: 0,
  };
}

  calendarConnected,
  calendarResult,
  onRefresh,
  onConnectCalendar,
  onToast,
}: CourseSyllabusProps) {
  const fileRef = useRef<HTMLInputElement>(null);
  const alive = useRef(true);
  const [phase, setPhase] = useState<Phase>("idle");
  const [steps, setSteps] = useState<string[]>(SYLLABUS_STEPS);
  const [rows, setRows] = useState<ReviewRow[]>([]);
  const [syllabusId, setSyllabusId] = useState("");
  const [connected, setConnected] = useState(calendarConnected);
  const [withCalendar, setWithCalendar] = useState(calendarConnected);
  const [problem, setProblem] = useState("");
  const [problems, setProblems] = useState<Record<string, string>>({}); // 422 항목 오류
  const [pending, setPending] = useState<File | null>(null); // "바꾸기"를 기다리는 파일
  const [added, setAdded] = useState<string[]>([]);
  const [busyItem, setBusyItem] = useState<string | null>(null);
  // 끝난 요청이 사라진 화면에 값을 쓰지 않게 하는 표시. **다시 붙을 때 되살려야** 한다 —
  // React StrictMode는 효과를 붙였다 떼었다 다시 붙이므로, 되살리지 않으면 첫 화면이 영영 멈춘다
  useEffect(() => {
    alive.current = true;
    return () => {
      alive.current = false;
    };
  }, []);
  useEffect(() => {
    setConnected(calendarConnected);
    setWithCalendar(calendarConnected);
  }, [calendarConnected]);
  useEffect(() => {
    if (calendarResult === "error") setProblem("Google 캘린더를 연결하지 못했어요. 다시 눌러 주세요.");
  }, [calendarResult]);

  const confirmedItems = course.syllabus_items.filter((item) => item.is_confirmed);
  const waiting = course.syllabus_items.length - confirmedItems.length;

  const connect = async () => {
    setProblem("");
    try {
      await onConnectCalendar(); // 실제 모드는 여기서 페이지를 떠난다
      if (!alive.current) return;
      setConnected(true);
      setWithCalendar(true);
    } catch (error) {
      setProblem(errorMessage(error, "Google 캘린더 연결을 시작하지 못했어요."));
    }
  };

  const read = async (file: File, replace: boolean) => {
    setProblem("");
    setProblems({});
    setPhase("uploading");
    setSteps(SYLLABUS_STEPS);
    try {
      const uploaded = await uploadSyllabusFile(file);
      if (!alive.current) return;
      setPhase("reading");
      const extraction = await extractSyllabus(uploaded.file_id, course.course.id, {
        replace,
        onSteps: (value: ProcessStep[]) => alive.current && setSteps(value.map((one) => one.label)),
      });
      if (!alive.current) return;
      setSyllabusId(extraction.result.syllabus_id);
      setRows(toReviewRows(extraction.result.items));
      setPhase("review");
      if (extraction.result.items.length === 0) {
        setProblem("계획서에서 시험·발표 일정을 찾지 못했어요. 플래너에 직접 적어 주세요.");
      }
    } catch (error) {
      if (!alive.current) return;
      if (error instanceof ApiError && error.code === "SYLLABUS_EXISTS") {
        setPending(file); // 갈아 끼울지 물어본다
        setPhase("exists");
        return;
      }
      // 60초를 넘겨도 실행은 돌고 있다. 올리기와 읽기는 고칠 방법이 달라 문구도 다르다
      const unfinished = error instanceof ApiError && error.code === "RUN_TIMEOUT";
      const failed = error instanceof ApiError && error.status === 422;
      setProblem(
        unfinished ? STILL_READING : errorMessage(error, failed ? READ_FAILED : UPLOAD_FAILED),
      );
      setPhase("idle");
    }
  };

  const pick = (file?: File) => {
    if (!file) return;
    if (file.size > MAX_BYTES) {
      setProblem("파일이 20MB를 넘어요. 더 작은 파일로 올려 주세요.");
      return;
    }
    void read(file, phase === "exists");
  };

  // 다시 올리지 않고 확인 화면을 연다(뽑아 두고 확인하지 않은 일정, 명세 9장의 syllabus_id)
  const review = () => {
    if (!course.course.syllabus_id) return;
    setProblem("");
    setProblems({});
    setSyllabusId(course.course.syllabus_id);
    setRows(toReviewRows(course.syllabus_items));
    setPhase("review");
  };

  // 확인 화면에서 나간다. 뽑은 일정은 서버에 남아 있어서, 상세를 다시 받으면
  // "확인하지 않은 일정 N건"으로 보이고 다시 올리지 않고 이어서 확인할 수 있다
  const cancel = () => {
    setPhase("idle");
    onRefresh();
  };

  const save = async () => {
    const chosen = rows.filter((row) => row.selected);
    if (chosen.some((row) => !row.date || !row.time)) {
      setProblem(NO_DATE);
      return;
    }
    setProblem("");
    setProblems({});
    setPhase("saving");
    try {
      const result = await confirmSyllabus(
        syllabusId,
        rows.map((row) => ({
          id: row.id,
          title: row.title.trim(),
          starts_at: row.date ? toKstIso(row.date, row.time) : null,
          selected: row.selected,
        })),
        withCalendar,
      );
      if (!alive.current) return;
      onToast(summary(result.planner_tasks_created, result.calendar_events_created, withCalendar));
      setPhase("idle");
      onRefresh();
    } catch (error) {
      if (!alive.current) return;
      if (error instanceof ApiError && error.code === "CALENDAR_NOT_CONNECTED") {
        setProblem("Google 캘린더 연결이 풀렸어요. 아래에서 다시 연결한 뒤 눌러 주세요.");
        setConnected(false);
        setWithCalendar(false);
        setPhase("review");
        return;
      }
      setProblems(fieldErrors(error));
      setProblem(errorMessage(error, CONFIRM_FAILED));
      setPhase("review");
    }
  };

  const addToCalendar = async (item: SyllabusItemView) => {
    setProblem("");
    setBusyItem(item.id);
    try {
      await registerSyllabusCalendarEvent(item.id);
      if (!alive.current) return;
      setAdded((current) => (current.includes(item.id) ? current : [...current, item.id]));
      onToast("캘린더에 넣었어요");
    } catch (error) {
      if (!alive.current) return;
      if (error instanceof ApiError && error.code === "CALENDAR_NOT_CONNECTED") {
        setConnected(false); // 권한이 풀렸다. 다시 연결하는 버튼으로 바뀐다
        setProblem("Google 캘린더 연결이 풀렸어요. 다시 연결해 주세요.");
        return;
      }
      setProblem(errorMessage(error, CALENDAR_FAILED));
    } finally {
      if (alive.current) setBusyItem(null);
    }
  };

  const notice = (
    <p
      role="status"
      className={
        problem
          ? "mb-4 rounded-[10px] bg-[#fef2f2] px-4 py-3 text-[13px] text-[#c53030]"
          : "sr-only"
      }
    >
      {problem}
    </p>
  );
  const input = <SyllabusFileInput inputRef={fileRef} onPick={pick} />;
  const choose = () => fileRef.current?.click();

  if (phase === "review" || phase === "saving") {
    return (
      <>
        {input}
        {notice}
        <SyllabusReviewPanel
          rows={rows}
          problems={problems}
          saving={phase === "saving"}
          connected={connected}
          withCalendar={withCalendar}
          onRows={setRows}
          onWithCalendar={setWithCalendar}
          onConnect={() => void connect()}
          onCancel={cancel}
          onSave={() => void save()}
        />
      </>
    );
  }

  if (phase === "idle" && course.course.has_syllabus) {
    return (
      <>
        {input}
        {notice}
        <SyllabusConfirmedList
          items={confirmedItems}
          waiting={waiting}
          canReview={course.course.syllabus_id !== null}
          calendarConnected={connected}
          added={added}
          busyItem={busyItem}
          onAddToCalendar={(item) => void addToCalendar(item)}
          onConnectCalendar={() => void connect()}
          onReview={review}
          onUpload={choose}
        />
      </>
    );
  }

  return (
    <>
      {input}
      {notice}
      <SyllabusUploadPanel
        phase={phase}
        steps={steps}
        portalUrl={course.course.portal_syllabus_url}
        onChoose={choose}
        onReplace={() => pending && void read(pending, true)}
        onCancel={() => {
          setPending(null);
          cancel();
        }}
      />
    </>
  );
}

// 확정 결과 안내. **새로 만든** 할 일 수를 센다(이미 있던 할 일은 날짜만 맞춘다, 명세 8장)
function summary(tasks: number, events: number, withCalendar: boolean): string {
  const planner = tasks > 0 ? `할 일 ${tasks}건을 플래너에 넣었어요` : "플래너는 그대로예요";
  if (!withCalendar) return planner;
  return events > 0
    ? `${planner} · 캘린더 ${events}건`
    : `${planner} · 캘린더에 새로 넣을 일정은 없었어요`;
}

import { getKstDateKey, getKstTimeKey } from "@/lib/format";
import type { SyllabusItemType, SyllabusItemView } from "@/types/api";

// 계획서 확인 화면의 표 (F-14). 뽑은 일정을 고치고 플래너·캘린더에 넣을 것만 고른다.

export const ITEM_LABELS: Record<SyllabusItemType, string> = {
  midterm: "중간",
  final: "기말",
  presentation: "발표",
  assignment: "과제",

// 화면이 들고 있는 한 줄. 날짜·시각은 입력 칸 값이라 글자로 둔다
export interface ReviewRow {
  id: string;
  item_type: SyllabusItemType;
  title: string;
  date: string; // YYYY-MM-DD (비어 있으면 날짜 미정)

// 뽑은 일정을 표의 줄로. 날짜가 없는 일정은 빈 칸으로 두고 고르지 않은 상태로 시작한다
export function toReviewRows(items: SyllabusItemView[]): ReviewRow[] {
  return items.map((item) => ({
    id: item.id,
    item_type: item.item_type,
    title: item.title,
    date: item.starts_at ? getKstDateKey(item.starts_at) : "",
    time: item.starts_at ? getKstTimeKey(item.starts_at) : "09:00",
    selected: item.starts_at !== null,
  }));
}

interface SyllabusReviewTableProps {
  rows: ReviewRow[];
  disabled: boolean;
  problems: Record<string, string>; // 서버가 준 항목 오류(`items.0.title` 꼴)
  onChange: (rows: ReviewRow[]) => void;
}

export default function SyllabusReviewTable({
  rows,
  disabled,
  problems,
  onChange,
}: SyllabusReviewTableProps) {
  const update = (id: string, patch: Partial<ReviewRow>) =>
    onChange(rows.map((row) => (row.id === id ? { ...row, ...patch } : row)));

  // 서버는 보낸 순서로 `items.2.title`처럼 알려 준다. 그 줄 아래에 보여 준다
  const problemOf = (index: number) =>
    Object.entries(problems).find(([key]) => key.startsWith(`items.${index}.`))?.[1];

  return (
    <ul className="flex flex-col gap-3">
      {rows.map((row, index) => (
        <li
          key={row.id}
          className={`rounded-[12px] border p-4 ${
            row.selected ? "border-[#cfd7ff] bg-[#f7f8fa]" : "border-[#e5e7eb] bg-white"
          }`}
        >
          <div className="flex flex-wrap items-center gap-3">
            <label className="flex items-center gap-2 text-[13px] font-semibold">
              <input
                type="checkbox"
                checked={row.selected}
                disabled={disabled}
                onChange={(event) => update(row.id, { selected: event.target.checked })}
                className="h-4 w-4 accent-[#4f6ef7]"
                aria-label={`${row.title} 플래너에 넣기`}
              />
              <span className="rounded-full bg-[#eef2ff] px-2 py-[2px] text-[12px] text-[#4f6ef7]">
                {ITEM_LABELS[row.item_type]}
              </span>
            </label>
            <input
              type="text"
              value={row.title}
              disabled={disabled}
              onChange={(event) => update(row.id, { title: event.target.value })}
              aria-label={`일정 ${index + 1} 이름`}
              aria-invalid={problemOf(index) !== undefined}
              className="min-w-[160px] flex-1 rounded-[8px] border border-[#e5e7eb] px-3 py-2 text-[14px] font-semibold"
            />
            <input
              type="date"
              value={row.date}
              disabled={disabled}
              onChange={(event) => update(row.id, { date: event.target.value })}
              aria-label={`${row.title} 날짜`}
              aria-invalid={row.selected && !row.date}
              aria-describedby={row.selected && !row.date ? `syllabus-${row.id}-problem` : undefined}
              className="rounded-[8px] border border-[#e5e7eb] px-2 py-2 text-[13px]"
            />
            <input
              type="time"
              value={row.time}
              disabled={disabled}
              onChange={(event) => update(row.id, { time: event.target.value })}
              aria-label={`${row.title} 시각`}
              aria-invalid={row.selected && !row.time}
              className="rounded-[8px] border border-[#e5e7eb] px-2 py-2 text-[13px]"
            />
          </div>
          {row.selected && (!row.date || !row.time) && (
            <p id={`syllabus-${row.id}-problem`} className="mt-2 text-[12px] text-[#c53030]">
              {row.date
                ? "시각을 적어 주세요. 비워 두면 넣을 수 없어요."
                : "날짜를 적어 주세요. 날짜가 없는 일정은 넣을 수 없어요."}
            </p>
          )}
          {problemOf(index) && (
            <p className="mt-2 text-[12px] text-[#c53030]">{problemOf(index)}</p>
          )}
        </li>
      ))}
    </ul>
  );
}

# 새 주차 항목과 과제를 한 피드로(명세 9장 `GET /lms/updates`). 둘을 같은 모양으로 맞춰 union한다.
# 주차 항목은 과목 공통 표라 과목 번호로 내 수강 과목에 잇는다(그래서 남의 과목 항목은 안 나온다)
_UPDATES = (
    "select * from ("
    "  select 'module_item' as kind, i.id, i.first_seen_at as at, c.id as course_id,"
    "    c.name as course_name, i.module_name, i.title, i.item_type, i.html_url,"
    "    null::timestamptz as due_at, null as submission_state,"
    "    (select f.id from files f where f.lms_module_item_id = i.id and f.user_id = c.user_id"
    "      order by f.created_at, f.id limit 1) as uploaded_file_id"
    "  from lms_module_items i"
    "  join lms_courses c on c.canvas_course_id = i.canvas_course_id and c.user_id = %(uid)s"
    "    and coalesce(c.is_active, true)"
    "  where i.first_seen_at >= %(since)s"
    "  union all"
    "  select 'assignment', a.id, a.first_seen_at, c.id, c.name, null, a.title, null, a.html_url,"
    "    a.due_at, a.submission_state::text, null"
    "  from lms_assignments a"
    "  join lms_courses c on c.id = a.lms_course_id and c.user_id = a.user_id"
    "  where a.user_id = %(uid)s and a.removed_at is null and coalesce(c.is_active, true)"
    # 새 과제이거나, 마감이 가까운 미제출 과제다(명세 9장)
    "    and (a.first_seen_at >= %(since)s or (a.submission_state = 'unsubmitted'"
    "      and a.due_at >= %(now)s and a.due_at < %(soon)s))"
    ") as feed where kind = any(%(kinds)s::text[])"
)

_UPSERT_ASSIGNMENT = (
    "insert into lms_assignments (user_id, lms_course_id, canvas_assignment_id, title, due_at,"
    " html_url, submission_state, submitted_at, first_seen_at, removed_at)"
    " values (%(uid)s, %(course)s, %(canvas)s, %(title)s, %(due)s, %(url)s, %(state)s,"
    " %(submitted)s, %(now)s, null)"
    " on conflict (user_id, canvas_assignment_id) do update set"
    " lms_course_id = excluded.lms_course_id, title = excluded.title, due_at = excluded.due_at,"
    " html_url = excluded.html_url, submission_state = excluded.submission_state,"
    " submitted_at = excluded.submitted_at, removed_at = null"
    " returning id"
)

_COURSES = (
    "select c.id, c.canvas_course_id, c.name, c.last_viewed_at,"
    " exists (select 1 from syllabi s where s.lms_course_id = c.id and s.user_id = c.user_id)"
    "   as has_syllabus,"
    " (select count(*) from lms_assignments a where a.user_id = c.user_id"
    "   and a.lms_course_id = c.id and a.submission_state = 'unsubmitted'"
    "   and a.removed_at is null) as open_assignments,"
    # 주차 항목은 과목 공통 표라 과목 번호로 잇는다. 마지막으로 과목을 본 뒤 생긴 것만 센다
    # (연결 전부터 있던 항목은 첫 수집 때 last_viewed_at을 올려서 빼고 센다, save_module_items)
    " (select count(*) from lms_module_items i where i.canvas_course_id = c.canvas_course_id"
    "   and i.first_seen_at > coalesce(c.last_viewed_at, to_timestamp(0))) as new_materials,"
    # 가장 가까운 것 하나: 미제출 과제와 확정된 계획서 일정 중에서(명세 9장)
    " (select json_build_object('kind', due.kind, 'title', due.title, 'due_at', due.at) from ("
    "    select 'assignment' as kind, a.title, a.due_at as at from lms_assignments a"
    "      where a.user_id = c.user_id and a.lms_course_id = c.id"
    "      and a.submission_state = 'unsubmitted' and a.removed_at is null and a.due_at >= %(now)s"
    "    union all"
    "    select 'syllabus_item', i.title, i.starts_at from syllabus_items i"
    "      join syllabi s on s.id = i.syllabus_id"
    "      where s.lms_course_id = c.id and s.user_id = c.user_id and i.is_confirmed"
    "      and i.starts_at >= %(now)s"
    "  ) as due order by due.at limit 1) as next_due"
    " from lms_courses c where c.user_id = %(uid)s and coalesce(c.is_active, true)"
    # 정렬은 ordered()가 한다. DB의 정렬 규칙(collation)은 환경마다 달라서 순서를 맡기지 않는다
)

_UPSERT_ITEM = (
    "insert into lms_module_items (canvas_course_id, canvas_item_id, module_name, title,"
    " item_type, html_url, first_seen_at)"
    " values (%(canvas)s, %(item)s, %(module)s, %(title)s, %(kind)s, %(url)s, %(now)s)"
    # 처음 본 때(`first_seen_at`)는 그대로 둔다. 새 자료 수(`GET /lms/courses`)가 그 시각을 본다
    # 과목이 바뀐 항목(과목 복제 등)은 새 과목으로 다시 붙인다. 안 그러면 동기화마다 새 항목이 된다
    " on conflict (canvas_item_id) do update set canvas_course_id = excluded.canvas_course_id,"
    " module_name = excluded.module_name, title = excluded.title,"
    " item_type = excluded.item_type, html_url = excluded.html_url"
    " returning id"
)

# 연결할 때 `last_synced_at`을 비워 둔다. 연결은 **과목 목록까지**만 받으므로(명세 8장) 과제·주차
# 자료는 아직 하나도 없다. 여기에 지금 시각을 찍으면 바로 뒤에 부르는 `POST /lms/sync`가 "5분 안에
# 받았다"며 건너뛰고, 학생은 연결 직후 5분 동안 과제가 비어 있는 화면을 본다. 토큰을 갈아 끼울
# 때도 비운다 — 방금 고친 토큰으로 곧바로 다시 받아야 한다
_SAVE = (
    "insert into lms_connections (user_id, access_token, token_last4, canvas_user_id, status,"
    " last_synced_at, last_error) values (%(uid)s, %(token)s, %(last4)s, %(canvas)s, 'active',"
    " null, null)"
    " on conflict (user_id) do update set access_token = excluded.access_token,"
    " token_last4 = excluded.token_last4, canvas_user_id = excluded.canvas_user_id,"
    " status = 'active', last_synced_at = null, last_error = null"
)

_UPSERT_COURSE = (
    "insert into lms_courses (user_id, canvas_course_id, name, term, portal_year, portal_term,"
    " portal_course_no, is_active, synced_at)"
    " values (%(uid)s, %(canvas)s, %(name)s, %(term)s, %(year)s, %(pterm)s, %(no)s, true, %(now)s)"
    " on conflict (user_id, canvas_course_id) do update set name = excluded.name,"
    " term = excluded.term, portal_year = excluded.portal_year,"
    " portal_term = excluded.portal_term, portal_course_no = excluded.portal_course_no,"
    " is_active = true, synced_at = excluded.synced_at"
)


class LmsRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def connection(self, user_id: str) -> Connection | None:
        row = await self._row(
            "select status, token_last4, access_token, canvas_user_id, last_synced_at, last_error"
            " from lms_connections where user_id = %s",
            (user_id,),
        )
        return Connection(**row) if row else None

    async def save_connection(
        self, user_id: str, *, token: str, last4: str, canvas_user_id: int | None
    ) -> None:
        """연결을 만들거나 토큰을 갈아 끼운다(명세 8장: 이미 연결돼 있으면 교체).

        `last_synced_at`은 찍지 않는다(비운다) — 연결은 과목 목록까지만 받는다. 이유는 `_SAVE` 머리말.
        """
        await self.conn.execute(
            _SAVE,
            {"uid": user_id, "token": token, "last4": last4, "canvas": canvas_user_id},
        )

    async def mark_error(self, user_id: str, message: str) -> None:
        """다음 동기화에서 토큰이 막혔을 때. 화면은 이 문구로 다시 연결을 안내한다."""
        await self.conn.execute(
            "update lms_connections set status = 'error', last_error = %s where user_id = %s",
            (message, user_id),
        )

    async def delete_connection(self, user_id: str) -> bool:
        """토큰을 즉시 지운다. 과목·과제 기록은 남기고 동기화만 멈춘다(명세 9장)."""
        cursor = await self.conn.execute(
            "delete from lms_connections where user_id = %s", (user_id,)
        )
        return cursor.rowcount > 0

    async def save_courses(
        self, user_id: str, courses: list[dict[str, Any]], *, now: datetime
    ) -> int:
        """수강 과목을 저장하고, 이번에 없던 과목은 목록에서 뺀다. 저장한 과목 수를 돌려준다."""
        ids: list[int] = []
        for course in courses:
            canvas_id = course.get("id")
            name = (course.get("name") or "").strip()
            if not is_canvas_id(canvas_id) or not name:
                continue
            parsed = course_name(name)
            term = (
                (course.get("term") or {}).get("name")
                if isinstance(course.get("term"), dict)
                else None
            )
            await self.conn.execute(
                _UPSERT_COURSE,
                {
                    "uid": user_id,
                    "canvas": canvas_id,
                    "name": name,
                    "term": parsed.term(term),
                    "year": parsed.portal_year,
                    "pterm": parsed.portal_term,
                    "no": parsed.portal_course_no,
                    "now": now,
                },
            )
            ids.append(canvas_id)
        # 빈 목록으로는 내리지 않는다. 학기 사이·필터·끊긴 목록 때문에 비어 올 수 있고,
        # 그때 전부 내리면 사용자가 토큰을 다시 붙여넣기 전까지 과목이 하나도 안 보인다
        if ids:
            await self.conn.execute(
                "update lms_courses set is_active = false"
                " where user_id = %s and not (canvas_course_id = any(%s::bigint[]))",
                (user_id, ids),
            )
        return len(ids)

    async def active_courses(self, user_id: str) -> list[CourseRow]:
        """동기화할 과목. 수강을 뺀 과목(`is_active` false)은 더 받지 않는다."""
        rows = await self._rows(
            "select id, canvas_course_id, name from lms_courses"
            " where user_id = %s and coalesce(is_active, true)",
            (user_id,),
        )
        courses = [
            CourseRow(
                id=str(row["id"]),
                canvas_course_id=row["canvas_course_id"],
                short_name=course_name(row["name"]).short_name,
            )
            for row in rows
        ]
        return sorted(courses, key=lambda one: (one.short_name, one.canvas_course_id))

    async def save_assignments(
        self, user_id: str, course_id: str, items: list[CanvasAssignment], *, now: datetime
    ) -> AssignmentChanges:
        """한 과목의 과제를 저장하고 바뀐 것을 돌려준다.

        먼저 저장된 것을 한 번에 읽어 두고 비교한다. 새 과제·마감 변경·이번에 제출을 가려내려면
        예전 값이 필요한데, upsert의 `returning`은 바뀐 뒤 값만 준다.
        """
        before = {
            row["canvas_assignment_id"]: row
            for row in await self._rows(
                "select canvas_assignment_id, due_at, submission_state::text as submission_state,"
                " removed_at from lms_assignments where user_id = %s and lms_course_id = %s",
                (user_id, course_id),
            )
        }
        changes = AssignmentChanges()
        for item in items:
            row = await self._row(
                _UPSERT_ASSIGNMENT,
                {
                    "uid": user_id,
                    "course": course_id,
                    "canvas": item.canvas_assignment_id,
                    "title": item.title,
                    "due": item.due_at,
                    "url": item.html_url,
                    "state": item.submission_state,
                    "submitted": item.submitted_at,
                    "now": now,
                },
            )
            assert row is not None  # insert ... returning은 늘 한 행이다
            saved = SavedAssignment(
                id=str(row["id"]),
                title=item.title,
                due_at=item.due_at,
                submitted=item.submitted,
            )
            old = before.get(item.canvas_assignment_id)
            # 사라졌다 다시 나타난 과제도 "새 과제"다. 그 사이 할 일·알림이 없었다
            if old is None or old["removed_at"] is not None:
                changes.created.append(saved)
                continue
            if old["due_at"] != item.due_at:
                changes.due_changed.append(saved)
                if old["due_at"] is None:  # 마감이 없다가 생겼다 → 할 일이 있을 수 없다
                    changes.new_deadline.append(saved)
            if item.submitted and old["submission_state"] not in SUBMITTED:
                changes.submitted.append(saved.id)
        # 이번 목록에 없던 과제는 지운 것으로 본다(목록이 비어 와도 찍는다, 머리말)
        fetched = [item.canvas_assignment_id for item in items]
        cursor = await self.conn.execute(
            "update lms_assignments set removed_at = %(now)s"
            " where user_id = %(uid)s and lms_course_id = %(course)s and removed_at is null"
            " and not (canvas_assignment_id = any(%(ids)s::bigint[]))",
            {"uid": user_id, "course": course_id, "ids": fetched, "now": now},
        )
        return changes + AssignmentChanges(removed=max(cursor.rowcount, 0))

    async def sync_planner(self, user_id: str, changes: AssignmentChanges, *, now: datetime) -> int:
        """과제 할 일을 맞춘다(F-51·F-43). 만든 할 일 수를 돌려준다.

        - **이미 낸 과제는 할 일을 만들지 않는다**(SQL에서도 한 번 더 막는다). 연결하고 처음 받을 때
          지난 과제가 한꺼번에 들어온다
        - 새 과제와 **마감이 없다가 생긴 과제**는 할 일을 만든다(마감이 없으면 못 만든다 — `due_date`가
          not null). 마감이 값에서 값으로 바뀐 과제는 만들지 않는다 — PRD F-51은 "마감 변경 시 기존
          일정 수정"이고, 학생이 지운 할 일을 마감이 바뀔 때마다 되살리면 지울 수가 없다
        - 마감이 바뀌면 아직 끝내지 않은 할 일의 날짜만 고친다. 끝낸 할 일은 그대로 둔다
        - 제출한 과제의 할 일은 자동 완료다(PRD F-51)
        """
        # 거를 조건(마감 있음·아직 안 냄·사라지지 않음)은 아래 SQL 한 곳에만 둔다. 파이썬에서 한 번
        # 더 거르면 둘 중 하나가 틀려도 테스트가 알아채지 못한다
        fresh = [one.id for one in changes.created + changes.new_deadline]
        created = 0
        if fresh:
            cursor = await self.conn.execute(
                "insert into planner_tasks (user_id, source, lms_assignment_id, title, due_date)"
                " select a.user_id, 'lms_assignment', a.id, a.title,"
                " (a.due_at at time zone 'Asia/Seoul')::date from lms_assignments a"
                " where a.user_id = %(uid)s and a.id = any(%(ids)s::uuid[]) and a.due_at is not null"
                " and a.submission_state = 'unsubmitted' and a.removed_at is null"
                " and not exists (select 1 from planner_tasks t"
                "   where t.lms_assignment_id = a.id and t.user_id = a.user_id)",
                {"uid": user_id, "ids": fresh},
            )
            created = max(cursor.rowcount, 0)
        moved = [one.id for one in changes.due_changed if one.due_at is not None]
        if moved:
            await self.conn.execute(
                "update planner_tasks t set due_date = (a.due_at at time zone 'Asia/Seoul')::date,"
                " title = a.title from lms_assignments a"
                " where a.id = t.lms_assignment_id and a.user_id = t.user_id"
                " and t.user_id = %(uid)s"
                " and t.lms_assignment_id = any(%(ids)s::uuid[])"
                " and coalesce(t.is_done, false) = false and a.due_at is not null",
                {"uid": user_id, "ids": moved},
            )
        if changes.submitted:
            await self.conn.execute(
                "update planner_tasks set is_done = true, done_at = %(now)s"
                " where user_id = %(uid)s and lms_assignment_id = any(%(ids)s::uuid[])"
                " and coalesce(is_done, false) = false",
                {"uid": user_id, "ids": changes.submitted, "now": now},
            )
        return created

    async def updates(
        self,
        user_id: str,
        *,
        since: datetime,
        now: datetime,
        kinds: list[str],
        course_id: str | None = None,
        cursor: Cursor | None = None,
        limit: int = UPDATE_LIMIT,
    ) -> tuple[list[Any], Cursor | None]:
        """새 주차 항목·과제 피드(F-52·F-51). 처음 본 순(최신 먼저)이고 한 쪽은 `limit`개다.

        `cursor`는 같은 조건(지문)에서만 쓸 수 있다. 마지막 행의 (처음 본 시각, id) 뒤를 이어 읽는다.
        """
        query = _UPDATES
        params: dict[str, Any] = {
            "uid": user_id,
            "since": since,
            "now": now,
            "soon": now + DEADLINE_SOON,
            "kinds": kinds,
        }
        if course_id is not None:
            query += " and course_id = %(course)s"
            params["course"] = course_id
        if cursor is not None:
            query += " and (at, id) < (%(at)s, %(last)s)"
            params["at"], params["last"] = cursor.value, cursor.id
        query += " order by at desc, id desc limit %(limit)s"
        params["limit"] = limit + 1  # 한 개 더 받아 다음 쪽이 있는지 본다
        rows = await self._rows(query, params)
        more = len(rows) > limit
        rows = rows[:limit]
        items = [_update(row) for row in rows]
        if not more or not rows:
            return items, None
        last = rows[-1]
        return items, Cursor(
            scope=update_scope(kinds, course_id, since), value=last["at"], id=str(last["id"])
        )

    async def course_detail(
        self, user_id: str, course_id: str, *, now: datetime, lms_base: str
    ) -> CourseDetail | None:
        """과목 하나의 모든 탭(명세 9장). 내 과목이 아니거나 수강을 뺐으면 None이다.

        **읽고 나서 `last_viewed_at`을 지금으로 올린다.** `is_new`는 올리기 전 값으로 계산한다
        (명세 9장) — 그래서 과목을 연 다음 과목 목록의 "새 자료" 수가 0이 된다.
        """
        head = await self._row(
            # 계획서 번호를 함께 준다. 확인 전 일정이 남은 과목에서 **다시 올리지 않고** 확인 화면을
            # 열 수 있어야 한다(명세 9장). 과목당 계획서는 하나다
            "select c.id, c.canvas_course_id, c.name, c.last_viewed_at,"
            " (select s.id::text from syllabi s where s.lms_course_id = c.id"
            "   and s.user_id = c.user_id) as syllabus_id"
            " from lms_courses c"
            " where c.id = %(course)s and c.user_id = %(uid)s and coalesce(c.is_active, true)",
            {"course": course_id, "uid": user_id},
        )
        if head is None:
            return None
        seen = head["last_viewed_at"]
        parsed = course_name(head["name"])
        detail = CourseDetail(
            course=CourseHeader(
                id=str(head["id"]),
                short_name=parsed.short_name,
                has_syllabus=head["syllabus_id"] is not None,
                syllabus_id=head["syllabus_id"],
                portal_syllabus_url=parsed.syllabus_url,
                html_url=f"{lms_base.rstrip('/')}/courses/{head['canvas_course_id']}",
            ),
            assignments=await self._course_assignments(user_id, course_id),
            module_items=await self._course_items(user_id, head["canvas_course_id"], seen=seen),
            announcements=await self._course_announcements(head["canvas_course_id"]),
            syllabus_items=await self._course_syllabus(user_id, course_id),
            materials=await self._course_materials(user_id, course_id),
        )
        # 본 시각은 읽기가 끝난 뒤에 올린다(위의 is_new가 올리기 전 값을 쓰게).
        # 뒤로 돌리지 않는다 — 그새 첫 수집이 밀어 둔 값을 지우면 지난 자료가 다시 "새 자료"가 된다
        await self.conn.execute(
            "update lms_courses"
            " set last_viewed_at = greatest(coalesce(last_viewed_at, %(now)s), %(now)s)"
            " where id = %(course)s and user_id = %(uid)s",
            {"now": now, "course": course_id, "uid": user_id},
        )
        return detail

    async def _course_assignments(self, user_id: str, course_id: str) -> list[CourseAssignment]:

            " a.html_url from lms_assignments a"
            " where a.user_id = %(uid)s and a.lms_course_id = %(course)s and a.removed_at is null",

    async def _course_items(
        self, user_id: str, canvas_course_id: int, *, seen: datetime | None
    ) -> list[CourseModuleItem]:
        """주차 항목. 과목 공통 표라 과목 번호로 읽고, 올린 파일은 내 것만 잇는다."""
        rows = await self._rows(
            "select i.id, i.module_name, i.title, i.item_type, i.html_url, i.first_seen_at,"
            " (select f.id from files f where f.lms_module_item_id = i.id and f.user_id = %(uid)s"
            "   order by f.created_at, f.id limit 1) as uploaded_file_id"
            " from lms_module_items i where i.canvas_course_id = %(canvas)s",
            {"uid": user_id, "canvas": canvas_course_id},
        )
        items = [
            CourseModuleItem(
                id=str(row["id"]),
                module_name=row["module_name"],
                title=row["title"],
                item_type=row["item_type"],
                html_url=row["html_url"],
                # 과목 목록의 새 자료 수와 같은 기준이다(본 적 없으면 다 새 것, `_COURSES`)
                is_new=row["first_seen_at"] > (seen or _EPOCH),
                uploaded_file_id=str(row["uploaded_file_id"]) if row["uploaded_file_id"] else None,
            )
            for row in rows
        ]
        # 새로 들어온 것이 위로. 같은 때 들어왔으면 주차·제목 순이다
        # 제목이 같은 항목이 한 모듈에 둘씩 있어서(녹화 15쌍) id까지 봐야 순서가 고정된다
        return sorted(
            items,
            key=lambda one: (not one.is_new, one.module_name or "", one.title, one.id),

    async def save_module_items(
        self, user_id: str, canvas_course_id: int, items: list[CanvasModuleItem], *, now: datetime
    ) -> ModuleChanges:
        """주차 항목을 저장하고 처음 본 것을 돌려준다.

        `lms_module_items`는 **과목 공통 표**라 `user_id`가 없다(ERD 3-2: 주차 항목은 수강생 모두에게
        같다). 그래서 다른 수강생이 먼저 동기화했으면 나에게는 "처음 본 항목"이 아니다 — 알림은
        그때 그 과목 수강생 모두에게 한 번 만든다(`add_material_notices`).

        **첫 수집인지는 내 과목 행의 `modules_synced_at`으로 가린다.** 표에 행이 있는지로 가리면
        안 된다 — 항목이 0건인 과목이 흔해서(녹화 6과목 중 2과목) 그 과목에 나중에 올라온 첫 자료가
        영원히 "첫 수집"으로 묶인다. 첫 수집에는 `last_viewed_at`도 지금으로 올려서, 연결 전부터
        있던 항목이 "새 자료" 수에 들어가지 않게 한다(ERD 알림함·조회 기록).

        사라진 항목은 지우지 않는다(표에 `removed_at`이 없다). 교수가 항목을 지워도 기록은 남는다.
        """
        row = await self._row(
            "select modules_synced_at from lms_courses"
            " where user_id = %s and canvas_course_id = %s",
            (user_id, canvas_course_id),
        )
        first_load = row is None or row["modules_synced_at"] is None
        before = {
            row["canvas_item_id"]
            for row in await self._rows(
                "select canvas_item_id from lms_module_items where canvas_course_id = %s",
                (canvas_course_id,),
            )
        }
        created: list[SavedItem] = []
        for one in items:
            row = await self._row(
                _UPSERT_ITEM,
                {
                    "canvas": canvas_course_id,
                    "item": one.canvas_item_id,
                    "module": one.module_name,
                    "title": one.title,
                    "kind": one.item_type,
                    "url": one.html_url,
                    "now": now,
                },
            )
            assert row is not None  # insert ... returning은 늘 한 행이다
            if one.canvas_item_id not in before:
                created.append(
                    SavedItem(
                        id=str(row["id"]),
                        module_name=one.module_name,
                        title=one.title,
                    )
                )
        # 첫 수집 표시와 "여기까지 봤다"를 함께 올린다(둘 다 그 사용자 과목 행이다)
        await self.conn.execute(
            "update lms_courses set modules_synced_at = %(now)s,"
            " last_viewed_at = greatest(coalesce(last_viewed_at, %(now)s), %(now)s)"
            " where user_id = %(uid)s and canvas_course_id = %(canvas)s"
            " and modules_synced_at is null",
            {"uid": user_id, "canvas": canvas_course_id, "now": now},
        )
        return ModuleChanges(created=created, first_load=first_load)

    async def assignment_titles(self, user_id: str, ids: list[str]) -> dict[str, str]:

    async def claim_sync(self, user_id: str, *, now: datetime, before: datetime) -> bool:
        """동기화를 시작한다고 한 문장으로 못 박는다. 이미 누가 가져갔으면 False다.

        `last_synced_at`을 **시작할 때** 찍는다. 두 가지를 한꺼번에 막는다 —
        대시보드를 두 탭에서 열어 같은 사용자를 동시에 동기화하는 것(둘째는 False를 받는다),
        그리고 늘 실패하는 사용자가 배치 앞자리를 영구히 차지하는 것(실패해도 시각이 밀린다).
        성공·실패는 `status`·`last_error`로 본다(명세 9장).
        """
        cursor = await self.conn.execute(
            "update lms_connections set last_synced_at = %(now)s"
            " where user_id = %(uid)s and status <> 'disconnected'"
            " and (last_synced_at is null or last_synced_at <= %(before)s)",
            {"uid": user_id, "now": now, "before": before},
        )
        return cursor.rowcount > 0

    async def touch_synced(self, user_id: str, *, now: datetime) -> None:
        """잘 받았다고 적는다. 오류 표시를 지운다.

        시각을 **뒤로 돌리지 않는다** — 느린 동기화가 뒤에 시작한 동기화의 자리(`claim_sync`)를
        지워 버리면 같은 사용자를 또 동기화하게 되고, 그 사이 찍힌 오류 표시도 사라진다.
        해제한 연결은 건드리지 않는다.
        """
        await self.conn.execute(
            "update lms_connections set last_synced_at = %(now)s, status = 'active',"
            " last_error = null"
            " where user_id = %(uid)s and status <> 'disconnected'"
            " and (last_synced_at is null or last_synced_at <= %(now)s)",
            {"uid": user_id, "now": now},
        )

    async def connected_users(self, *, before: datetime, limit: int) -> list[str]:
        """동기화할 사용자(30분 배치). 오래 안 한 사람부터 본다.

        `before` 뒤에 이미 동기화한(또는 동기화를 시작한) 사람은 건너뛴다. 오류 상태도 넣는다 —
        토큰이 되살아나면 거기서 풀린다. 해제한 사람은 토큰이 없어 빠진다. 실패해도 `claim_sync`가
        시각을 밀어 두므로 한 사람이 앞자리를 계속 차지하지 않는다.
        """
        rows = await self._rows(
            "select user_id from lms_connections"
            " where status <> 'disconnected'"
            " and (last_synced_at is null or last_synced_at <= %(before)s)"
            " order by coalesce(last_synced_at, to_timestamp(0)), user_id limit %(limit)s",
            {"before": before, "limit": limit},
        )
        return [str(row["user_id"]) for row in rows]

    async def assignments(

    ) -> list[AssignmentItem]:

def update_scope(kinds: list[str], course_id: str | None, since: datetime) -> str:
    """피드 조건의 지문. 조건이 다른 목록에는 그 커서를 쓸 수 없다(명세 9장).

    `since`는 UTC로 적는다 — 같은 시각을 다른 오프셋으로 보내도 같은 목록이다. 조건 부분과 `since`를
    `|`로 나눠 두므로, 다음 쪽을 부를 때 커서에서 `since`를 되읽을 수 있다(기본값이 매 요청 달라지는
    문제를 막는다).
    """
    return f"{update_filter(kinds, course_id)}|{since.astimezone(UTC).isoformat()}"


def update_filter(kinds: list[str], course_id: str | None) -> str:
    """지문에서 `since`를 뺀 부분(종류·과목)."""
    return f"{','.join(sorted(kinds))}|{course_id or ''}"


def update_since(scope: str) -> datetime | None:
    """커서 지문에 적힌 `since`. 모양이 틀리면 None이다."""
    try:
        return datetime.fromisoformat(scope.rsplit("|", 1)[1])
    except (IndexError, ValueError):
        return None


def _update(row: dict[str, Any]) -> ModuleItemUpdate | AssignmentUpdate:
    course = AssignmentCourse(
        id=str(row["course_id"]), short_name=course_name(row["course_name"]).short_name
    )
    if row["kind"] == "module_item":
        return ModuleItemUpdate(
            id=str(row["id"]),
            course=course,
            module_name=row["module_name"],
            title=row["title"],
            item_type=row["item_type"],
            html_url=row["html_url"],
            first_seen_at=row["at"].astimezone(KST),
            uploaded_file_id=str(row["uploaded_file_id"]) if row["uploaded_file_id"] else None,
        )
    return AssignmentUpdate(
        id=str(row["id"]),
        course=course,
        title=row["title"],
        due_at=row["due_at"].astimezone(KST) if row["due_at"] else None,
        submission_state=row["submission_state"],
        html_url=row["html_url"],
        first_seen_at=row["at"].astimezone(KST),
    )


def ordered(items: list[CourseItem]) -> list[CourseItem]:
    """화면 이름 순. 같은 이름이면 과목명으로 가른다.

    DB에 `order by`를 맡기지 않는다 — 정렬 규칙(collation)이 환경마다 달라서 한글과 숫자의 앞뒤가
    바뀐다(2026-10-16 CI에서 걸렸다). 파이썬 글자 코드 순으로 정하면 어디서나 같다.
    """
    return sorted(items, key=lambda one: (one.short_name, one.name))


def by_due(items: list[AssignmentItem]) -> list[AssignmentItem]:
    """마감이 가까운 순. 마감이 없는 과제는 뒤로 보낸다.

    `ordered()`와 같은 이유로 DB에 맡기지 않는다(정렬 규칙이 환경마다 다르다).
    """
    return sorted(
        items, key=lambda one: (one.due_at is None, one.due_at or _FAR, one.title, one.id)
    )


def _assignment(row: dict[str, Any]) -> AssignmentItem:

"""LearningX 연결·과목·과제 (F-50·F-51·F-14, API 명세 8장).

토큰은 요청으로만 받고 응답에는 끝 4자리만 넣는다(`token_last4`). 과목 이름은 LearningX가 준
`202620HY23525_데이터베이스`를 그대로 두고, 화면에 쓸 짧은 이름(`short_name`)과 포털 계획서 링크를
함께 내려준다. 계획서 링크는 사용자 브라우저에서만 연다(서버는 포털에 요청하지 않는다).

과제는 마감(`due_at`)이 없을 수 있다(녹화 17건 중 5건은 `due_at`이 null이고 `lock_at`만 있어서 그걸 쓴다).
`submission_state`는 LearningX가 준 값 그대로다(`unsubmitted`·`submitted`·`graded`·`pending_review`).
"""

from datetime import datetime
from typing import Annotated, Literal

from pydantic import BaseModel, ConfigDict, Field

# DB enum(lms_connection_status)·GET /me의 lms.status·web 타입과 같은 세 가지
ConnectionStatus = Literal["active", "error", "disconnected"]

SubmissionState = Literal["unsubmitted", "submitted", "graded", "pending_review"]
# `GET /lms/assignments?state=`. 주지 않으면 open이다(화면이 "할 일"로 먼저 보여 준다)

# 동기화 결과를 남기는 도구 이름. app/lms/sync.py가 쓰고 GET /runs/{id}가 읽는다

"""업로드 파일 검사 (F-13, API 명세 6장).

파일 이름과 브라우저가 보낸 Content-Type은 믿지 않고 앞부분 바이트로 형식을 가린다. 확장자만 .jpg로
바꾼 실행 파일이 저장소에 들어가지 않게 하려는 것이다.

포스터는 JPG·PNG·WEBP 사진과 2쪽 이하 PDF를 받는다. HEIC(아이폰 기본 사진 형식)는 아직 못 읽는다.
아이폰에서 고른 사진은 그대로 HEIC로 올라오기 쉬워서, "형식이 아니에요" 대신 무엇을 하면 되는지
알려 준다.

20MB까지만 메모리로 올린다. FastAPI는 핸들러가 돌기 전에 몸통을 모두 받아 임시 파일에 쓰므로
(1MB가 넘으면 디스크), 여기서 끊는 것은 큰 파일을 통째로 메모리에 올리지 않기 위한 것이다. 아주 큰
몸통 자체를 거절하는 것은 앞단(프록시·ASGI)의 몫이다.

import hashlib
import io
from dataclasses import dataclass
from datetime import datetime, timedelta
from typing import Protocol

from pypdf import PdfReader

from app.eligibility.dates import KST

MAX_BYTES = 20 * 1024 * 1024
MAX_MB = MAX_BYTES // (1024 * 1024)
POSTER_MAX_PAGES = 2
SYLLABUS_MAX_PAGES = 10  # 강의계획서는 보통 2~6쪽이다(녹화한 포털 계획서 기준)
PDF_TEXT_MAX_CHARS = 60_000  # 뽑은 글자 상한. 계획서 10쪽이면 2만 자 안쪽이다
DAILY_UPLOAD_LIMIT = 20  # 사용자당 KST 하루 (API 명세 14장, 10/15 확정)
_CHUNK_BYTES = 1024 * 1024
_NAME_MAX = 200


@dataclass(frozen=True)
class FileType:
    mime: str
    extension: str


JPEG = FileType("image/jpeg", "jpg")
PNG = FileType("image/png", "png")
WEBP = FileType("image/webp", "webp")
PDF = FileType("application/pdf", "pdf")
HEIC = FileType("image/heic", "heic")

# ISO 기반 미디어 파일(ftyp 박스)의 HEIF 계열 브랜드. 아이폰 사진은 heic·heix·mif1로 온다
_HEIF_BRANDS = frozenset({b"heic", b"heix", b"heim", b"heis", b"hevc", b"hevx", b"mif1", b"msf1"})


def sniff(data: bytes) -> FileType | None:
    """앞부분 바이트로 가린 형식. 아는 형식이 아니면 None이다."""
    if data.startswith(b"\xff\xd8\xff"):
        return JPEG
    if data.startswith(b"\x89PNG\r\n\x1a\n"):
        return PNG
    if data[:4] == b"RIFF" and data[8:12] == b"WEBP":
        return WEBP
    if data.startswith(b"%PDF-"):
        return PDF
    if data[4:8] == b"ftyp" and data[8:12] in _HEIF_BRANDS:
        return HEIC
    return None


class Chunked(Protocol):
    """UploadFile처럼 조금씩 읽을 수 있는 것."""

    async def read(self, size: int = -1, /) -> bytes: ...


async def read_upload(source: Chunked) -> bytes:
    """20MB까지만 모은다. 넘으면 나머지를 읽지 않고 413이다."""
    chunks: list[bytes] = []
    total = 0
    while chunk := await source.read(_CHUNK_BYTES):
        total += len(chunk)
        if total > MAX_BYTES:
            raise ApiError(
                413,
                "FILE_TOO_LARGE",
                f"파일이 {MAX_MB}MB를 넘어요. 더 작은 파일을 올려 주세요.",
            )
        chunks.append(chunk)
    return b"".join(chunks)


@dataclass(frozen=True)

    type: FileType
    page_count: int | None  # PDF만 센다
    sha256: str


def inspect_poster(data: bytes) -> Inspected:

    found = sniff(data)

            400,
            "UNSUPPORTED_FILE_TYPE",
            "아이폰 사진 형식(HEIC)은 아직 올릴 수 없어요. 사진을 JPG로 바꿔서 올려 주세요.",
        )
    if found is None:
        raise ApiError(
            400,
            "UNSUPPORTED_FILE_TYPE",
            "JPG·PNG·WEBP 사진이나 2쪽 이하 PDF만 올릴 수 있어요.",

def inspect_syllabus(data: bytes) -> Inspected:

    포털 계획서를 브라우저에서 "PDF로 저장"해 올리는 길이라 스캔본은 거의 없다. 그래도 사진을
    PDF로 감싼 파일이 올 수 있어서, 글자를 못 뽑으면 여기서 막는다 — 모델에 보내도 읽을 것이 없다.

    found = sniff(data)
    if found is not PDF:
        raise ApiError(

    return Inspected(found, pages, hashlib.sha256(data).hexdigest())


def pdf_text(data: bytes, *, max_chars: int = PDF_TEXT_MAX_CHARS) -> str:
    """PDF에서 뽑은 글자(쪽마다 줄바꿈으로 잇는다). 읽지 못하면 빈 글자다.

    상한을 두는 것은 모델 입력을 재는 쪽이 아니라, 깨진 PDF가 메모리를 다 먹지 않게 하려는 것이다.
    """
    try:
        reader = PdfReader(io.BytesIO(data))
    except (PdfReadError, ValueError, OSError):
        return ""
    found: list[str] = []
    total = 0
    for page in reader.pages:
        try:
            text = page.extract_text() or ""
        except Exception:  # pypdf가 쪽 하나에서 터져도 나머지는 읽는다
            continue
        found.append(text)
        total += len(text)
        if total >= max_chars:
            break
    return "\n".join(found)[:max_chars]


def _pdf_pages(data: bytes, *, advice: str = "사진으로 찍어서 올려 주세요.") -> int:
    try:

    except (PdfReadError, ValueError, OSError) as exc:

        # 무엇을 하면 되는지는 종류마다 다르다 — 계획서는 사진을 받지 않는다
        raise ApiError(400, "UNSUPPORTED_FILE_TYPE", f"PDF를 읽지 못했어요. {advice}") from exc

        return None

def _strip_comments(body: str) -> str:

def _segments(body: str) -> list[str]:
    """`;`(묶음 바깥)로 끊어 "이름: 값" 토막들로 만든다."""
    found, buffer, depth = [], "", 0
    for char in body:
        if char in "{[":
            depth += 1
        elif char in "}]":
            depth -= 1
        if char == ";" and depth == 0:
            found.append(buffer)
            buffer = ""
            continue
        buffer += char
    return found + [buffer]

            )
            continue
        named = re.match(r"\s*([A-Z]\w*)(\[\])?\s*$", value.strip().rstrip(";"))
        if named is None:
            continue
        inner = _ts_interface(source, named.group(1), required=False)
        if inner is not None:
            found |= _ts_paths(inner, f"{prefix}{name}{'[]' if named.group(2) else ''}.", source)
    return found


def _braced(value: str) -> tuple[str, str]:
    """`{ ... }` 안쪽과 그 뒤에 남은 것(배열인지 보려고)."""
    start, depth = value.index("{"), 0
    for index in range(start, len(value)):
        depth += (value[index] == "{") - (value[index] == "}")
        if depth == 0:
            return value[start + 1 : index], value[index + 1 :]
    raise AssertionError("묶음이 닫히지 않았어요")


def _ts_interface(text: str, name: str, *, required: bool = True) -> Any:
    """그 이름의 interface 안쪽. 없으면 None이다(타입 별칭·열거형은 들어갈 것이 없다)."""
    body = re.search(rf"export interface {name} \{{(.*?)\n\}}", text, re.S)
    if body is None:
        assert not required, f"web 타입 {name}을 찾지 못했어요"
        return None
    return body.group(1)


def _ts_union(text: str, kind: str) -> str:
    body = re.search(r"export type LmsUpdate =(.*?)export interface LmsUpdateList", text, re.S)
    assert body is not None
    return next(one for one in body.group(1).split("| {") if f'type: "{kind}"' in one)


def _api_paths(schemas: dict[str, Any], schema: dict[str, Any], prefix: str = "") -> set[str]:
    """OpenAPI 스키마를 같은 꼴의 길로 펴낸다($ref를 따라 내려간다)."""
    found: set[str] = set()
    for name, raw in schema.get("properties", {}).items():
        found.add(prefix + name)
        inner, array = _unwrap(schemas, raw)
        if inner is not None:
            found |= _api_paths(schemas, inner, f"{prefix}{name}{'[]' if array else ''}.")
    return found


def _unwrap(schemas: dict[str, Any], raw: dict[str, Any]) -> tuple[dict[str, Any] | None, bool]:
    """그 칸이 묶음(또는 묶음 배열)이면 그 스키마와 배열인지를 돌려준다."""
    for branch in raw.get("anyOf", [raw]):  # null 가능 칸은 anyOf로 온다
        if "$ref" in branch:
            found = schemas[branch["$ref"].rsplit("/", 1)[1]]
            return (found, False) if found.get("properties") else (None, False)
        if branch.get("type") == "array":
            inner, _ = _unwrap(schemas, branch.get("items", {}))
            if inner is not None:
                return inner, True
        if branch.get("properties"):
            return branch, False
    return None, False
