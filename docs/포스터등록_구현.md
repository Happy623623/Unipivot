확인 화면에서 **확인한 내용으로 실제 공고를 만든다**(`POST /posters/confirm`). 지난 PR에서 포스터를 읽어 초안을 채우는 데까지 됐고, 등록 버튼 자리에는 "준비 중"만 있었다. 이제 공고·요건·서류가 만들어지고 **등록 즉시 내 판정이 계산돼** 바로 준비하기로 넘어갈 수 있다. 포스터 흐름(올리기 → 읽기 → 등록)이 여기서 끝난다.

**규모와 확인:**

1. **API 다시 띄우기:** `http://localhost:8000/docs`에 `POST /api/v1/posters/confirm`이 보여야 한다.
2. **등록:** 사이드바 "포스터 등록" → 실제 포스터를 올리고, 확인 화면에서 "공고 등록하고 자격 확인"을 누른다. 공고 상세로 넘어가고 **판정 라벨**이 보여야 한다.
3. **고치고 등록:** "정보 수정"으로 제목·마감일을 고치고 조건 한 줄을 지운 뒤 등록한다. 상세에 고친 제목과 남은 조건만 보인다.

7. **나만 보임:** 등록한 포스터 공고는 홈 목록에 "내가 올린 포스터"로 보이고, 다른 계정으로는 보이지 않는다.
8. **준비하기:** 등록한 공고에서 "준비 일정 만들기"가 되는지 본다(서류 안내가 사전·모델로 채워진다).

## 확인한 것

- **단위·DB 테스트 32개 추가**(등록 로직 16 · API 6 · DB 10). 기본 칸 받기·공백 정리·길이 제한, 빈 제목·지난 마감·시작>마감, 신뢰도는 모델 값, 비교 기준은 초안 값, 요건 지우기·고쳐 보내기·끼워 넣기·같은 줄 두 개, 초안 순서와 묶음 번호 유지, 서류 이름 짝, 마감일 비우기, 중복이면 안 만들기, 두 번 눌러도 하나, 남의 실행·실패한 실행은 404, 모르는 종류는 계약에서 막힘, 공고·요건·서류·판정이 다 생기는지, 학과 기준이 요건 행까지 가는지, 상세 처리 과정 이름, 남에게 안 보이는지, 모호 조건·낮은 신뢰도 배지.
- **실제 모드 E2E(추출·등록) 6단계**: 확인 화면 값 채우기 → 제목을 고쳐 등록(보낸 몸통에 `run_id`와 고친 제목, 묶음 번호가 들어 있는지) → 서버가 막으면 마감일 칸 아래에 사유 → 요건 묶음 강조 → 중복 안내 → 읽기 실패. 업로드 E2E 6단계와 목 모드 흐름(분석 → 확인 → 등록)도 그대로 돈다.
- **되돌림 시험 24가지**가 모두 잡혔다. 비교 기준 버리기(초안·등록 두 곳)·지난 마감 검사·신뢰도 바꿔치기·요건/서류를 보낸 대로 쓰기·짝을 묶음 번호만으로 맞추기·같은 줄 개수 안 세기·글자 정리 빼기·모호/낮은 신뢰도 배지·포스터 원본 안 붙이기·원문·원문 해시·실행 번호 안 붙이기·초안 읽기의 주인·작업 조건·없는 초안 검사·중복 검사·중복도 201·판정 안 하기·학생이 고친 값 무시·중복을 초안 값으로 찾기·상세에 도구 이름 보이기.
- **테스트 정리**: 아무도 읽지 않던 `dropped_requirements`·`dropped_documents`를 없앴고, 가짜 저장소가 인자를 삼켜 라우터가 무엇을 넘기는지 고정하지 못했던 것을 고쳤다("나만 볼 수 있다" 테스트도 다른 계정으로 실제로 열어 본다).

| 마감이 오늘 안에서 이미 지난 시각이면 "등록 즉시 판정"이 생기지 않는다 | 날짜가 아니라 **지금**과 견줘 지난 마감은 422로 막는다. 날짜만 고쳤을 때 붙는 시각도 마감 23:59·시작 00:00으로 바꿨다 |
| '원문 확인 필요' 기준이 공지와 다르다(신뢰도를 안 본다) | 신뢰도 0.6 미만도 배지를 붙인다 |
| 아무도 읽지 않는 `dropped_requirements`·`dropped_documents` | 없앴다 |
| 가짜 저장소가 인자를 삼켜 라우터가 넘기는 값을 고정하지 못한다 | 고친 제목·마감일·지금 시각을 넘기는지 보고, 토스트도 shared `useToast`로 바꿨다 |
| 명세·`web/CLAUDE.md`에 "포스터 등록은 아직"이 남았다 | 지웠다 |

## 남은 것

- **같은 `run_id`로 공고를 여러 개 만들 수 있다.** 중복 막기가 제목+마감일 조회 하나뿐이고 DB 제약이 없다. 동시에 두 요청이 오거나 제목을 바꿔 다시 보내면 두 행이 생긴다(둘 다 내게만 보인다). 등록 버튼이 누르는 동안 비활성이라 실제로 겹치기는 어렵다.
- **등록한 포스터 공고를 지우는 기능이 없다**(10/15 선택: 나중에). 잘못 등록하면 다시 올려 덮지 못하고 공고가 둘이 된다.
- **초안의 발급처·소요 일수·작성 시간은 등록 때 버린다.** 서류 행에는 이름만 들어가고, 준비하기가 사전·모델로 다시 채운다. 확인 화면에서 본 발급처가 상세에서 바로 보이지는 않는다.
- **요건 짝 맞추기가 값의 JSON 글자 비교다.** 화면이 받은 값을 그대로 돌려보내므로 지금은 문제가 없지만, `3`과 `3.0`처럼 숫자 모양이 달라지면 그 줄이 말없이 빠진다.
- **공유(P1)는 아직이다.** 포스터 공고는 올린 본인만 본다. 공유를 켤 때 다른 사용자 판정과 신고·숨김을 함께 본다.
- `opportunities.dedupe_key`(정규화한 제목+주최+마감일)는 아직 아무도 쓰지 않는다. 출처가 다른 공고를 묶을 때 쓸 칸이라 이번에는 채우지 않았다.

#### `api/app/posters/confirm.py`

```python
"""확인 화면에서 고친 값 받기 (F-16, API 명세 6장 POST /posters/confirm).

학생이 고칠 수 있는 것은 **기본 칸**이다: 제목·주최·종류·신청 기간·쉬운 설명. 요건과 서류는
**지운 것만** 반영한다(10/15 선택). 서버가 추출 초안을 기준으로 삼고, 학생이 보낸 목록에 남아
있는 줄만 남긴다.

요건의 항목(field)·연산자·값을 학생이 보낸 대로 저장하면, 화면에서 값을 지어내 판정 규칙을 넣을 수
있다. 지금은 포스터 공고가 올린 본인에게만 보이지만, 공유(P1)를 켜면 남의 판정까지 흔든다.
짝은 (묶음 번호, 항목, 연산자, 값)으로 맞춘다. 고쳐 보낸 줄은 짝이 없으니 지운 것으로 본다.
"""

import json
from collections.abc import Callable, Sequence
from dataclasses import dataclass
from datetime import datetime
from decimal import Decimal
from typing import Any

from app.errors import ApiError
from app.extraction.models import DocumentDraft, RequirementDraft
from app.schemas.posters import PosterDraft

MAX_TITLE = 200
MAX_ORGANIZER = 100
MAX_SUMMARY = 400


@dataclass(frozen=True)
class Confirmed:
    """저장할 값. 요건·서류는 초안에서 살아남은 줄이다."""

    title: str
    organizer: str | None
    category: str
    apply_start_at: datetime | None
    deadline_at: datetime | None
    easy_summary: str | None
    confidence: Decimal
    requirements: tuple[RequirementDraft, ...]
    documents: tuple[DocumentDraft, ...]


def confirm_draft(stored: PosterDraft, edited: PosterDraft, *, now: datetime) -> Confirmed:
    """추출 초안(stored)에 학생이 고친 기본 칸을 얹는다. 잘못된 입력은 422다.

    마감이 이미 지난 공고는 받지 않는다. 등록해도 판정이 생기지 않고(판정은 열린 공고만 한다)
    준비할 것도 없다.
    """
    # 종류(category)는 PosterDraft가 명세의 여덟 값만 받는다. 여기서 또 보지 않는다
    title = _one_line(edited.title, MAX_TITLE)
    if title is None:
        raise _invalid("title", "공고 이름을 적어 주세요.")
    deadline = edited.deadline_at
    if deadline is not None and deadline <= now:
        raise _invalid("deadline_at", "마감이 이미 지났어요. 날짜를 확인해 주세요.")
    apply_start = edited.apply_start_at
    if apply_start is not None and deadline is not None and apply_start > deadline:
        raise _invalid("apply_start_at", "신청 시작일이 마감일보다 늦어요.")
    kept_requirements = _kept(stored.requirements, edited.requirements, _requirement_key)
    kept_documents = _kept(stored.documents, edited.documents, _document_key)
    return Confirmed(
        title=title,
        organizer=_one_line(edited.organizer, MAX_ORGANIZER),
        category=edited.category,
        apply_start_at=apply_start,
        deadline_at=deadline,
        easy_summary=_one_line(edited.easy_summary, MAX_SUMMARY),
        # 신뢰도는 모델이 낸 값이다. 학생이 고칠 수 있는 칸이 아니다
        confidence=Decimal(str(stored.extraction_confidence)),
        requirements=tuple(
            RequirementDraft(
                clause_no=item.clause_no,
                field=item.field,
                operator=item.operator,
                value=item.value,
                basis=item.basis,  # 초안이 남긴 기준. 없으면 학과·지역 판정이 달라진다
                evidence_text=item.evidence_text,
                is_ambiguous=item.is_ambiguous,
            )
            for item in kept_requirements
        ),
        documents=tuple(
            DocumentDraft(name=item.name, is_required=True, form_url=item.form_url)
            for item in kept_documents
        ),
    )


def _kept[Item](
    stored: Sequence[Item], edited: Sequence[Item], key: Callable[[Item], str]
) -> list[Item]:
    """초안 순서를 지키면서, 학생이 보낸 목록에 남아 있는 줄만 남긴다.

    같은 줄이 여러 번 있을 수 있어 개수로 센다. 학생이 값을 고쳐 보낸 줄은 짝이 없어 빠진다.
    """
    wanted: dict[str, int] = {}
    for item in edited:
        wanted[key(item)] = wanted.get(key(item), 0) + 1
    kept: list[Item] = []
    for item in stored:
        found = key(item)
        if wanted.get(found, 0) > 0:
            wanted[found] -= 1
            kept.append(item)
    return kept


def _requirement_key(item: Any) -> str:
    return json.dumps(
        [item.clause_no, item.field, item.operator, item.value], sort_keys=True, ensure_ascii=False
    )


def _document_key(item: Any) -> str:
    return item.name.strip()


def _one_line(value: str | None, limit: int) -> str | None:
    if not value:
        return None
    cleaned = " ".join(value.split())
    return cleaned[:limit] or None


def _invalid(field: str, reason: str) -> ApiError:
    return ApiError(
        422, "VALIDATION_FAILED", "입력값을 확인해 주세요.", {"fields": {field: reason}}
    )
```

```python
"""포스터 한 장 → 공고 초안 (F-16).

Vision 모델을 **한 번만** 부른다. 포스터는 사진 한 장이라 더 읽을 첨부가 없어서, 글자를 옮기는 일과
요건을 뽑는 일을 한 호출에서 함께 받는다(submit_poster의 poster_text + 나머지 항목).

검증은 공지 추출과 같은 코드(app/extraction/validate.check_submission)를 쓴다. 근거 문장은 모델이
옮겨 적은 poster_text에 있는지 본다 — 포스터에는 대조할 다른 원문이 없다.

한 번만 부르므로 final=True로 검증한다. 문제가 있으면 모델에 다시 묻지 않고 코드가 고쳐서 받고,
고친 항목은 확인 화면에서 강조할 low_confidence_fields에 넣는다.
"""

import asyncio
import logging
from collections.abc import Sequence
from dataclasses import dataclass
from datetime import date

from app.eligibility import Department, Requirement, condition_text
from app.extraction.models import DocumentDraft, RequirementDraft
from app.extraction.validate import Context, Evidence, Submission, check_submission
from app.llm import Blob, LlmClient, LlmReply, UserTurn
from app.posters.prompt import (
    CATEGORIES,
    NO_TEXT,
    SUBMIT,
    SUBMIT_POSTER,
    first_message,
    system_prompt,
)
from app.prepare.documents import lookup
from app.schemas.posters import (

    PosterDocumentDraft,
    PosterDraft,
    PosterRequirementDraft,

logger = logging.getLogger(__name__)
TIMEOUT_SECONDS = 50.0  # 웹이 실행을 확인하는 60초 안에 실패를 알려 준다
MAX_OUTPUT_TOKENS = 16_000  # 옮긴 글자 + 요건. 넘치면 제출이 잘려 읽지 못한 것으로 본다
LOW_CONFIDENCE = 0.6  # 이보다 낮으면 제목·마감일을 확인하게 한다
_DEFAULT_CATEGORY = "etc"


class PosterError(Exception):
    """포스터에서 공고를 읽지 못했다. 학생에게 그대로 보여 줄 문구다."""


@dataclass(frozen=True)
class Extracted:
    draft: PosterDraft
    poster_text: str  # 등록(F-16 2차)에서 공고 원문으로 쓴다
    reply: LlmReply


async def extract(
    llm: LlmClient,
    *,
    model: str,
    blob: Blob,
    departments: Sequence[Department],
    today: date,
) -> Extracted:
    """Vision 한 번 호출. 읽지 못하면 PosterError다."""
    try:
        async with asyncio.timeout(TIMEOUT_SECONDS):
            reply = await llm.generate(
                model=model,
                system=system_prompt(departments),
                turns=[UserTurn(text=first_message(today), blobs=(blob,))],
                tools=(SUBMIT_POSTER,),
                force_tool=SUBMIT,
                max_output_tokens=MAX_OUTPUT_TOKENS,
            )
    except TimeoutError as exc:
        raise TimeoutError("포스터를 읽는 데 너무 오래 걸렸어요.") from exc
    call = next((c for c in reply.turn.tool_calls if c.name == SUBMIT), None)
    if call is None:
        raise PosterError(f"포스터에서 글자를 읽지 못했어요({reply.finish_reason or '이유 없음'}).")
    args = call.args
    poster_text = args.get("poster_text")
    if (
        not isinstance(poster_text, str)
        or not poster_text.strip()
        or poster_text.strip() == NO_TEXT
    ):
        raise PosterError("포스터에서 글자를 읽지 못했어요.")

    evidence = Evidence()
    evidence.add(poster_text)
    # 포스터에는 게시일이 없다. 연도 없는 날짜("10. 24.까지")는 사진을 올린 날 뒤로 읽는다
    context = Context(evidence, {}, departments, today)
    submission, problems = check_submission(args, context, final=True)
    if submission is None:
        logger.info("포스터 제출을 받지 못했어요: %s", "; ".join(problems[:3]))
        raise PosterError("포스터에서 지원 조건을 정리하지 못했어요.")

    title = _text(args.get("title"))
    if title is None:
        raise PosterError("포스터에서 공고 이름을 찾지 못했어요.")
    draft = PosterDraft(
        title=title[:200],
        organizer=_cut(_text(args.get("organizer")), 100),
        category=_category(args.get("category")),
        apply_start_at=submission.apply_start_at,
        deadline_at=submission.deadline_at,
        easy_summary=submission.easy_summary,
        requirements=[_requirement(req) for req in submission.requirements],
        documents=[_document(doc) for doc in submission.documents],
        extraction_confidence=float(submission.confidence),
        low_confidence_fields=_low_confidence(
            args.get("low_confidence_fields"), submission, title, _text(args.get("category"))
        ),
    )
    return Extracted(draft, poster_text, reply)


def _requirement(req: RequirementDraft) -> PosterRequirementDraft:
    """조건 문장은 공고 상세와 같은 방법으로 만든다(app/eligibility/describe)."""
    shown = Requirement(
        id="",
        clause_no=req.clause_no,
        field=req.field,
        operator=req.operator,
        value=req.value,
        basis=req.basis,
        is_ambiguous=req.is_ambiguous,
        evidence_text=req.evidence_text,
    )
    return PosterRequirementDraft(
        clause_no=req.clause_no,
        field=req.field,
        operator=req.operator,
        value=req.value,
        basis=req.basis,
        condition_text=condition_text(shown),
        evidence_text=req.evidence_text,
        is_ambiguous=req.is_ambiguous,
    )


def _document(doc: DocumentDraft) -> PosterDocumentDraft:
    """발급처·소요 일수·작성 시간은 서류 사전에서 채운다(준비하기와 같은 사전)."""
    guide = lookup(doc.name)
    return PosterDocumentDraft(
        name=doc.name,
        issuer=guide.issuer if guide else None,
        lead_days=guide.lead_days if guide else None,
        effort_minutes=guide.effort_minutes if guide else None,
        form_url=doc.form_url,
    )


def _low_confidence(
    raw: object, submission: Submission, title: str, category: str | None
) -> list[str]:
    """모델이 고른 항목 + 코드가 보기에 확인이 필요한 항목. 확인 화면에서 강조한다."""
    # 모델이 아무 값이나 줄 수 있다(글이 아닌 것도). 아는 항목만 남기는 것은 마지막 한 줄에서 한다
    found = {name for name in raw if isinstance(name, str)} if isinstance(raw, list) else set()
    if submission.deadline_at is None:
        found.add("deadline_at")  # 마감일을 못 읽으면 학생이 넣어야 한다
    if submission.confidence < LOW_CONFIDENCE:
        found.update(("title", "deadline_at"))
    if any(req.is_ambiguous for req in submission.requirements):
        found.add("requirements")
    if submission.fixes:  # 코드가 고쳐서 받은 것이 있다(날짜 뒤바뀜, 근거 없는 조건 등)
        found.add("requirements")
    if len(title) < 4:  # "장학금"처럼 너무 짧은 제목은 큰 글씨만 읽은 것일 수 있다
        found.add("title")
    if category not in CATEGORIES:  # 모르는 종류는 '그 밖'으로 두므로 학생이 골라야 한다
        found.add("category")
    return [name for name in LOW_CONFIDENCE_FIELDS if name in found]


def _category(raw: object) -> str:
    return raw if isinstance(raw, str) and raw in CATEGORIES else _DEFAULT_CATEGORY


def _text(value: object) -> str | None:
    if not isinstance(value, str):
        return None
    cleaned = " ".join(value.split())
    return cleaned or None


def _cut(value: str | None, limit: int) -> str | None:
    return value[:limit] if value else None
```

```python
def _stale_sql(scope: str) -> str:
    """다시 판정할 공고와 그 요건."""
    return (
        "select o.id, o.requirements_version, o.eligibility_basis_date, o.deadline_at,"
        " o.apply_start_at, o.source_type::text as source_type,"
        " e.user_id is not null as had_result, e.status::text as old_status,"
        " e.missing_fields as old_missing, " + _REQUIREMENTS_JSON + " as requirements"
        " from opportunities o"
        + COURSE_JOIN
        + _RESULT_JOIN
        + " where"
        + scope
        + " and"
        + VISIBLE
        + " and o.extraction_run_id is not null"
        " and (%(force)s or e.user_id is null or e.evaluated_at is null"
        " or e.requirements_version <> o.requirements_version"
        " or e.engine_version <> %(engine)s"
        # 날이 바뀌면 다시: 기준일이 "오늘"인 공고(청년정책 포함), 엔진 오류로 판정하지 못한 공고(오류를
        # 고쳤을 수 있다)
        " or (((o.eligibility_basis_date is null and (o.deadline_at is null"
        " or (o.source_type = 'youth_policy' and o.deadline_at >= %(now)s)))"
        " or e.reason_text = %(engine_error)s)"
        " and (e.evaluated_at at time zone 'Asia/Seoul')::date < %(today)s))"
    )

@dataclass(frozen=True)
class Cursor:
    scope: str  # 목록 조건(정렬·필터)의 지문. 조건이 다른 목록에는 쓸 수 없다
    # 마지막 행의 정렬 값(deadline: 마감 시각, recent: 등록 시각). 없을 수 있다
    value: datetime | None
    id: str


@dataclass(frozen=True)
class FeedQuery:
    eligibility: frozenset[str] | None = None  # None이면 전체
    categories: tuple[str, ...] | None = None
    source_types: tuple[str, ...] | None = None
    sort: Sort = "deadline"
    include_expired: bool = False
    include_not_interested: bool = False  # 관심 없음 공고도 준다(F-45)
    limit: int = 20
    cursor: Cursor | None = None

    def scope(self) -> str:
        """cursor를 묶는 목록 조건의 지문. 정렬이나 필터를 바꾸면 목록을 처음부터 다시 부른다.

        같은 목록이면 지문도 같다: 값의 순서는 보지 않고, 모든 값을 고른 필터는 필터 없음과 같다.
        """
        parts = (
            self.sort,
            _filter_key(self.eligibility, ELIGIBILITY_STATUSES),
            _filter_key(self.categories, CATEGORIES),
            _filter_key(self.source_types, SOURCE_TYPES),
            str(self.include_expired),
            str(self.include_not_interested),
        )
        return hashlib.sha256("|".join(parts).encode()).hexdigest()[:16]


def _filter_key(values: Collection[str] | None, everything: Collection[str]) -> str:
    chosen = set(values or ())
    return "" if chosen >= set(everything) else ",".join(sorted(chosen))


@dataclass(frozen=True)
class FeedPage:
    items: list[OpportunityItem]
    next_cursor: str | None


@dataclass(frozen=True)
class Refresh:
    judged: int  # 다시 계산한 공고 수
    changed: int  # 라벨이 바뀐 공고 수(전에 판정이 있던 공고만 센다)


def display_status(status: str, missing_fields: Sequence[str]) -> str:
    """화면 라벨 4종. 판정 불가는 입력하면 바뀔 수 있으면 정보 필요, 아니면 원문 확인 필요다."""
    if status == "undetermined":
        return "missing_info" if missing_fields else "needs_review"
    return status


def encode_cursor(cursor: Cursor) -> str:
    data = {
        "q": cursor.scope,
        "v": cursor.value.isoformat() if cursor.value else None,
        "id": cursor.id,
    }
    raw = json.dumps(data, separators=(",", ":")).encode()
    return base64.urlsafe_b64encode(raw).decode().rstrip("=")


def decode_cursor(text: str) -> Cursor:
    """next_cursor로 준 값을 되돌린다. 모양이 틀리면 ValueError."""
    try:
        data = json.loads(base64.urlsafe_b64decode(text + "=" * (-len(text) % 4)))
        scope, value, ident = data["q"], data["v"], data["id"]
        if not isinstance(scope, str) or not isinstance(ident, str):
            raise ValueError(scope)
        moment = None if value is None else datetime.fromisoformat(value)
        if moment is not None and moment.tzinfo is None:
            raise ValueError(value)
        return Cursor(scope=scope, value=moment, id=str(uuid.UUID(ident)))
    except (binascii.Error, ValueError, KeyError, TypeError, UnicodeDecodeError) as exc:
        raise ValueError("잘못된 cursor") from exc


class OpportunityRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def refresh_judgments(
        self,
        user_id: str,
        *,
        now: datetime,
        force: bool = False,
        include_expired: bool = False,
        display_name: str | None = None,
    ) -> Refresh:
        """피드에 나올 공고(include_expired면 지난 공고까지)의 낡은 판정을 다시 계산해 저장한다.

        force면 그 공고를 모두 다시 판정하고 나머지 공고의 판정은 지운다.
        프로필 행이 없으면(첫 요청이 피드) display_name과 함께 만든다.
        """
        profile = Profile.from_row(await self._lock_profile(user_id, display_name))
        today = now.astimezone(KST).date()
        stale = await (
            await self.conn.execute(
                _stale_sql(_WITH_EXPIRED if include_expired else _ACTIVE),
                {
                    "uid": user_id,
                    "now": now,
                    "force": force,
                    "engine": ENGINE_VERSION,
                    "engine_error": ENGINE_ERROR_SUMMARY,
                    "today": today,
                },
            )
        ).fetchall()
        payload: list[dict[str, Any]] = []
        changed = 0
        if stale:
            departments = await self._departments()
            for item in stale:
                judged = _judge(item, profile, departments, today)
                payload.append(_payload(item, judged.stored))
                old = display_status(item["old_status"] or "", item["old_missing"] or ())
                if item["had_result"] and old != judged.label:
                    changed += 1
        await self._upsert(user_id, payload, now)
        if force:  # 다시 판정하지 않은 공고(마감·숨김·안 보임)의 판정은 지운다
            await self.conn.execute(
                "delete from eligibility_results"
                " where user_id = %s and opportunity_id <> all(%s::uuid[])",
                (user_id, [item["opportunity_id"] for item in payload]),
            )
        else:  # 요건 추출에 실패한 공고의 옛 판정은 지운다(판정하지 않는다)
            await self.conn.execute(
                "delete from eligibility_results e using opportunities o"
                " where e.user_id = %s and e.opportunity_id = o.id and o.extraction_run_id is null",
                (user_id,),
            )
        return Refresh(judged=len(payload), changed=changed)

    async def detail(
        self,
        user_id: str,
        opportunity_id: str,
        *,
        now: datetime,
        display_name: str | None = None,
    ) -> OpportunityDetail | None:
        """공고 상세(S1-6). 이 사용자에게 보이지 않는 공고면 None이다.

        피드와 같은 잠금 아래에서 그 공고를 다시 판정해 저장하고, 조회 기록을 남긴다(is_new가 꺼진다).
        """
        profile_row = await self._lock_profile(user_id, display_name)
        row = await (
            await self.conn.execute(_DETAIL, {"uid": user_id, "oid": opportunity_id})
        ).fetchone()
        if row is None:
            return None
        if row["extraction_run_id"] is None:  # 요건 추출에 실패한 공고는 판정하지 않는다
            await self.conn.execute(
                "delete from eligibility_results where user_id = %s and opportunity_id = %s",
                (user_id, opportunity_id),
            )
            eligibility = DetailEligibility(
                status="undetermined",
                display_status="needs_review",
                reason_text=UNJUDGED_SUMMARY,
                basis_date=None,
                requirements_version=row["requirements_version"],
                missing_fields=[],
                clauses=[],
                conditions=[],
                evaluated_at=None,
            )
        else:
            profile = Profile.from_row(profile_row)
            departments = await self._departments()
            judged = _judge(row, profile, departments, now.astimezone(KST).date())
            await self._upsert(user_id, [_payload(row, judged.stored)], now)
            eligibility = _detail_eligibility(
                judged, profile, departments, row["requirements_version"], now
            )
        await self.conn.execute(_VIEW, (user_id, opportunity_id, now, now))
        names = {item["seq"]: item["file_name"] for item in row["attachments"]}
        apply_start: datetime | None = row["apply_start_at"]
        deadline: datetime | None = row["deadline_at"]
        confidence = row["extraction_confidence"]
        return OpportunityDetail(
            id=str(row["id"]),
            title=row["title"],
            organizer=row["organizer"],
            category=row["category"],
            source_type=row["source_type"],
            status=row["status"],
            original_url=row["original_url"],
            poster_url=None,  # TODO(W6): 포스터 업로드에서 Storage 서명 URL(5분)을 붙인다
            easy_summary=row["easy_summary"],
            apply_start_at=apply_start.astimezone(KST) if apply_start else None,
            deadline_at=deadline.astimezone(KST) if deadline else None,
            needs_review=bool(row["needs_review"]),
            review_reasons=_lines(row["review_reasons"]),
            extraction_confidence=float(confidence) if confidence is not None else None,
            uploaded_by_me=row["uploaded_by_me"],
            course_name=row["course_name"],
            attachments=[_attachment(item) for item in row["attachments"] if item["source_url"]],
            eligibility=eligibility,
            documents=[DocumentItem(**document) for document in row["documents"]],
            prep=Prep(
                prepared=row["prep_done"],
                prep_plan_id=_text(row["prep_plan_id"]) if row["prep_done"] else None,
                tasks_total=row["tasks_total"],
                tasks_done=row["tasks_done"],
                calendar_events=[CalendarEventRef(**event) for event in row["calendar_events"]],

    async def feed_page(self, user_id: str, query: FeedQuery, *, now: datetime) -> FeedPage:

def _after(sort: Sort, cursor: Cursor) -> str:
    """정렬 순서(_ORDER)에서 cursor 다음에 오는 행. 값이 없는 행은 맨 뒤에 id 순으로 온다."""
    column, beyond = ("deadline_at", ">") if sort == "deadline" else ("created_at", "<")
    if cursor.value is None:
        return f"({column} is null and id {beyond} %(cursor_id)s)"
    return (
        f"({column} {beyond} %(cursor_value)s"
        f" or ({column} = %(cursor_value)s and id {beyond} %(cursor_id)s) or {column} is null)"
    )

def _judge(
    item: dict[str, Any], profile: Profile, departments: list[Department], today: date
) -> _Judged:
    """공고 행 하나(requirements·eligibility_basis_date·deadline_at)를 판정한다.

    엔진 오류면 "판정하지 못함" 행을 돌려준다: 그 공고만 원문 확인 필요로 보인다.
    """
    basis: date | None = None
    try:
        requirements = tuple(Requirement.from_row(r) for r in item["requirements"])
        days = _basis_dates(item, today)
        basis = days[0]
        # 기준일이 둘이면(청년정책) 더 나은 쪽을 쓴다. 같으면 앞 날짜다(max는 처음 나온 것을 고른다)
        judgment = max(
            (
                check_eligibility(
                    list(requirements), profile, basis_date=day, departments=departments
                )
                for day in days
            ),
            key=lambda found: _RANK[found.status],
        )
        return _Judged(
            judgment.storage_row(),
            judgment.display_status,
            judgment,
            requirements,
            judgment.basis_date,
        )
    except Exception:
        logger.exception("판정하지 못한 공고: %s", item["id"])
        return _Judged(_engine_error_row(), "needs_review", None, (), basis)


_RANK = {"ineligible": 0, "undetermined": 1, "eligible": 2}


def _basis_dates(item: dict[str, Any], today: date) -> tuple[date, ...]:
    """판정 기준일(판정엔진_규칙.md 8장). 보통 하나다(공고 기준일 → 마감일 → 오늘).

    청년정책(온통청년)은 신청일 기준이 대부분이고 신청 기간이 몇 년인 정책도 있다. 그래서 신청할 수 있는 첫날
    (오늘, 신청 기간 전이면 시작일)과 마감일을 둘 다 보고 더 나은 결과를 쓴다. 나이 상한은 첫날에, 하한은
    마감일에 맞으면 그 사이 어느 날엔 신청할 수 있다. 신청 기간이 끝났으면 마감일 하나다."""
    if item["source_type"] != "youth_policy" or item["eligibility_basis_date"] is not None:
        return (resolve_basis_date(item["eligibility_basis_date"], item["deadline_at"], today),)
    start = item["apply_start_at"]
    first = max(today, to_kst_date(start)) if start is not None else today
    if item["deadline_at"] is None:
        return (first,)
    deadline = to_kst_date(item["deadline_at"])
    return (deadline,) if deadline <= first else (first, deadline)

def _step(step: dict[str, Any], names: dict[int, str]) -> ProcessStep:
    """처리 과정 한 줄(_DETAIL의 steps 행 하나). 첨부를 읽은 단계는 첨부 이름을 넣어 보인다.

    도구가 오류를 돌려준 호출(없는 첨부 번호 등)과 거절된 제출은 실행 로그에 succeeded로 남는다
    (에이전트는 오류를 모델에 돌려주고 계속 간다). 화면에는 실패로 보인다. 첨부 번호·위치는
    에이전트와 같은 규칙(whole)으로 읽는다. 읽기·토큰 상한에 닿아 코드가 시킨 제출(forced)은
    모델이 고른 단계가 아니라서 pipeline으로 보인다.
    """
    tool: str = step["tool"]
    again = "이어 " if _continued(step) else ""
    if tool in (READ_TEXT, READ_IMAGE):
        number = whole(step.get("attachment_no"))
        name = names.get(number) if number is not None else None
        target = f"첨부 '{name}'" if name else f"첨부 {number}번" if number else "첨부"
        how = "이미지로 " if tool == READ_IMAGE else ""
        label = f"{target} {how}{again}읽기"
    elif tool == FETCH_ORIGINAL:
        label = f"공고 원문 페이지 {again}읽기"
    elif tool == FETCH_YOUTH:
        label = "온통청년에서 정책 정보 받기"
    elif tool == BUILD_YOUTH:
        label = "온통청년 항목으로 지원 자격 정리"
    elif tool == POSTER_TOOL:  # 포스터 추출은 Vision 한 번이라 단계 이름이 다르다
        label = EXTRACT_LABEL
    else:
        label = "지원 자격 정리" if tool == SUBMIT else tool
    failed = step.get("error") is True or (tool == SUBMIT and step.get("accepted") is False)
    chosen = tool in _AGENT_TOOLS and step.get("forced") is not True
    return ProcessStep(
        seq=step["seq"],
        tool=tool,
        label=label,
        status="failed" if failed else step["status"],
        latency_ms=step["latency_ms"],
        chosen_by="agent" if chosen else "pipeline",
        note=_line(step.get("reason")),
    )


def _continued(step: dict[str, Any]) -> bool:
    """앞에서 읽은 곳의 뒷부분을 읽은 호출. 도구가 실제로 읽은 위치를 보고, 오류면 요청한 위치를 본다.

    글자 읽기·원문 읽기는 시작 위치(offset)가 0보다 크면, Vision은 PDF를 2쪽부터 읽었으면 이어 읽기다.
    이미지는 한 장이라 이어 읽기가 없다.
    """
    if step["tool"] != READ_IMAGE:
        offset = whole(step.get("offset"))
        return offset is not None and offset > 0
    pages = step.get("pages")  # 읽은 PDF 쪽 "4–6/8". 이미지는 없다
    if isinstance(pages, str) and (first := _PAGES.match(pages)):
        return int(first.group(1)) > 1
    if step.get("error") is not True:
        return False  # 이미지를 읽었다
    start_page = whole(step.get("start_page"))
    return start_page is not None and start_page > 1


def _line(text: Any) -> str | None:
    """모델이 쓴 글(고른 이유, 원문 확인 필요 이유)을 화면용 한 줄로: 보이지 않는 문자(폭 없는 문자,
    글자 방향 제어)와 주소를 지우고 공백·줄바꿈을 한 칸으로 줄여 LINE_MAX_CHARS자까지. 남는 글이
    없으면 None이다.

    공고 글을 읽은 모델이 쓴 글이라, 공고 속 지시문이 링크를 끼워 넣지 못하게 쉬운 설명과 같은 규칙으로
    정리한다(app/extraction/validate.py). 저장된 값을 읽을 때 정리해서 예전 행에도 같이 적용된다.
    화면은 이 글을 일반 텍스트로 보여 준다(자동 링크·마크다운 없이).
    """
    if not isinstance(text, str):
        return None
    line = " ".join(_LINK.sub("", _INVISIBLE.sub("", text)).split())
    if len(line) > LINE_MAX_CHARS:
        line = line[: LINE_MAX_CHARS - 1].rstrip() + "…"
    return line or None


def _lines(texts: Sequence[Any] | None) -> list[str]:
    """여러 줄을 _line으로 정리한다. 빈 줄과 같은 줄은 빼고, REASONS_MAX줄이 넘으면 "외 N건"으로 줄인다."""
    lines = list(dict.fromkeys(line for text in texts or () if (line := _line(text))))
    if len(lines) > REASONS_MAX:
        return [*lines[:REASONS_MAX], f"외 {len(lines) - REASONS_MAX}건"]
    return lines
```

```python
        """내가 올린 포스터 파일. 남의 파일·다른 종류·LMS 첨부는 None이다."""
        row = await (
            await self.conn.execute(
                "select id::text as id, storage_path, mime_type from files"
                " where id = %s and user_id = %s and origin = 'upload' and kind::text = 'poster'",
                (file_id, user_id),
            )
        ).fetchone()
        return None if row is None else PosterFile(row["id"], row["storage_path"], row["mime_type"])

    async def duplicate(
        self, user_id: str, *, title: str, deadline_at: datetime | None, now: datetime
    ) -> DuplicateCandidate | None:
        """같은 공고가 이미 있으면 그 공고. 제목이 같고 마감일이 같은 날이어야 한다.

        마감일을 읽지 못한 포스터는 아직 마감하지 않은 공고 중에서 제목이 같은 것을 본다. 제목만으로는
        "2026 1학기 교내장학"처럼 해마다 같은 이름인 공고를 엉뚱하게 묶을 수 있어서, 마감일이 있으면
        반드시 같은 KST 날짜여야 한다.
        """
        clean = _normalize(title)
        if not clean:
            return None
        params = {"uid": user_id, "title": clean, "deadline": deadline_at, "now": now}
        when = (
            " and (o.deadline_at at time zone 'Asia/Seoul')::date"
            " = (%(deadline)s::timestamptz at time zone 'Asia/Seoul')::date"
            if deadline_at is not None
            else " and (o.deadline_at is null or o.deadline_at >= %(now)s)"
        )
        row = await (
            await self.conn.execute(
                "select o.id::text as id, o.title from opportunities o"
                + COURSE_JOIN
                + " where o.status in ('active', 'expired') and "
                + VISIBLE
                + f" and {_TITLE} = %(title)s"
                + when
                + " order by o.deadline_at nulls last, o.id limit 1",
                params,
            )
        ).fetchone()
        return (
            None
            if row is None
            else DuplicateCandidate(opportunity_id=row["id"], title=row["title"])
        )

    async def stored(self, user_id: str, run_id: str) -> StoredPoster | None:
        """그 추출 실행이 남긴 초안·옮겨 적은 글·파일. 내 실행만이다.

        실행 상태는 보지 않는다. 초안은 도구가 끝날 때 한 번에 남으므로, 아직 돌고 있거나 실패한
        실행에는 초안이 없어 아래 검사에서 None이 된다.
        """
        row = await (
            await self.conn.execute(
                "select t.input, t.output from tool_calls t join agent_runs r on r.id = t.run_id"
                " where t.run_id = %s and r.user_id = %s and r.trigger_type = 'poster_upload'"
                " and t.tool_name = %s"
                " order by t.seq desc, t.id desc limit 1",
                (run_id, user_id, EXTRACT_TOOL),
            )
        ).fetchone()
        output = row["output"] if row else None
        if not isinstance(output, dict) or "draft" not in output:
            return None
        try:
            draft = PosterDraft.model_validate(output["draft"])
        except ValidationError:
            logger.warning("포스터 초안 모양이 달라 읽지 못했어요: run %s", run_id)
            return None
        source = row["input"] if isinstance(row["input"], dict) else {}
        file_id = source.get("file_id")
        return StoredPoster(
            file_id=str(file_id) if file_id else None,
            draft=draft,
            poster_text=str(output.get("poster_text") or ""),
        )

    async def create(
        self, user_id: str, *, run_id: str, stored: StoredPoster, confirmed: Confirmed
    ) -> str:
        """포스터 공고 행과 요건·서류를 만든다. 올린 본인에게만 보인다(공개 범위 규칙).

        요건·서류 저장은 공지 요건 추출과 같은 코드(extraction/store.save_extraction)를 쓴다.
        extraction_run_id가 붙어야 상세·피드가 판정을 쓴다.
        """
        reasons = []
        if any(item.is_ambiguous for item in confirmed.requirements):
            reasons.append(AMBIGUOUS_REASON)
        if confirmed.confidence < LOW_CONFIDENCE:
            reasons.append(LOW_CONFIDENCE_REASON)
        row = await (
            await self.conn.execute(
                "insert into opportunities (source_type, category, title, organizer, raw_text,"
                " uploaded_by, poster_file_id) values ('poster', %s::opportunity_category, %s, %s,"
                " %s, %s, %s) returning id::text as id",
                (
                    confirmed.category,
                    confirmed.title,
                    confirmed.organizer,
                    stored.poster_text or None,
                    user_id,
                    stored.file_id,
                ),
            )
        ).fetchone()
        assert row is not None
        opportunity_id = row["id"]
        await save_extraction(
            self.conn,
            opportunity_id,
            ExtractionResult(
                succeeded=True,
                requirements=confirmed.requirements,
                documents=confirmed.documents,
                apply_start_at=confirmed.apply_start_at,
                deadline_at=confirmed.deadline_at,
                easy_summary=confirmed.easy_summary,
                confidence=confirmed.confidence,
                needs_review=bool(reasons),
                review_reasons=tuple(reasons),
            ),
            run_id=run_id,
            content_hash=content_hash(stored.poster_text, ()),
        )
        return opportunity_id


def _normalize(title: str) -> str:
    """SQL의 _TITLE과 같은 규칙. 아스키 소문자·숫자와 한글만 남긴다.

    전각 숫자("２")나 한자는 SQL 쪽 [^0-9a-z가-힣]도 지우므로 여기서도 지운다. 두 규칙이 어긋나면
    코드가 찾은 제목과 DB가 비교하는 제목이 달라져 중복을 놓친다.
    """
    return "".join(ch for ch in title.lower() if _kept(ch))


def _kept(ch: str) -> bool:
    return "0" <= ch <= "9" or "a" <= ch <= "z" or "가" <= ch <= "힣"
```

```python
    response: Response,

        raise ApiError(404, "NOT_FOUND", "읽어 온 포스터를 찾을 수 없어요. 다시 올려 주세요.")

    duplicate = await repo.duplicate(
        user.id, title=confirmed.title, deadline_at=confirmed.deadline_at, now=now
    )

    )
    await opportunities.refresh_judgments(user.id, now=now, display_name=user.name)
    return PosterConfirmResult(opportunity_id=opportunity_id, merged=False)
```

```python
    await add_file("계획서", user, kind="syllabus")
```

```ts
// 포스터 등록 화면이 쓰는 데이터 함수 (client.ts가 다시 내보낸다).

export type PosterPreviewState =

  | { status: "failure"; result: null }
  | { status: "duplicate"; result: PosterExtractResult };

export const SHOW_MOCK_STEPS = USE_MOCKS;

// 포스터 파일 올리기 (POST /files). 목 모드는 올린 척하고 file_id를 지어낸다
export function uploadPosterFile(file: File): Promise<PosterUploadResult> {
  if (USE_MOCKS) {

      reused: false,
    });
  }

export function getPosterPreviewState(): Promise<PosterPreviewState> {
  const scenario = getDevScenario();
  if (scenario === "poster_failure") return respond({ status: "failure", result: null });
  if (scenario === "poster_duplicate") {
    return respond({ status: "duplicate", result: duplicatePosterExtractResult });
  }
  return respond({ status: "idle", result: null });
}

// 올린 포스터에서 공고 초안 뽑기 (POST /posters/extract → GET /runs/{id}).
// onSteps로 처리 과정을 그때그때 알려 준다(화면의 단계 목록).
export async function extractPoster(
  fileId: string,
  onSteps?: (steps: ProcessStep[]) => void,
): Promise<PosterExtraction> {
  if (USE_MOCKS) return mockExtract();
  const started = await apiFetch<{ run_id: string }>("/posters/extract", {
    method: "POST",
    body: JSON.stringify({ file_id: fileId }),
  });
  const run = await waitForRun<PosterExtractResult>(started.run_id, (value) =>
    onSteps?.(value.steps),
  );
  if (run.status === "failed" || run.result === null) {
    const error = run.error;
    // 실행 실패 이유는 서버가 학생에게 보여 줄 문구로 남긴 것이다(명세 11장). errorMessage가 그 문구를
    // 그대로 쓰도록 4xx로 만든다(5xx면 화면 문구로 바뀐다)
    throw new ApiError(
      error?.code ?? "POSTER_READ_FAILED",
      error?.message ?? "포스터에서 글자를 읽지 못했어요. 다시 찍어서 올려 주세요.",
      422,
    );
  }
  return { run_id: started.run_id, result: run.result };
}

async function mockExtract(): Promise<PosterExtraction> {
  const scenario = getDevScenario();
  if (scenario === "poster_failure") {
    return rejectAfter(
      new ApiError(
        "POSTER_READ_FAILED",
        "포스터에서 글자를 읽지 못했어요. 포스터 전체가 보이게 밝은 곳에서 다시 찍어 주세요.",
        422,
      ),
    );
  }
  const result = await respond(
    scenario === "poster_duplicate" ? duplicatePosterExtractResult : posterExtractResult,
  );
  return { run_id: "mock-run", result };
}

// 확인한 내용으로 공고 등록 (POST /posters/confirm). 같은 공고가 이미 있으면 merged가 true다.
// 요건·서류는 서버가 run_id로 추출 초안을 다시 읽어 기준으로 삼고, 지운 줄만 뺀다
export async function registerPosterOpportunity(
  runId: string,
  draft: PosterExtractResult["draft"],
): Promise<PosterConfirmResult> {
  if (USE_MOCKS) {
    const detail = await respond(registerStoredPoster(draft));
    return { opportunity_id: detail.id, merged: false };
  }
  return apiFetch<PosterConfirmResult>("/posters/confirm", {
    method: "POST",
    body: JSON.stringify({ run_id: runId, draft }),
  });
}
```

```tsx
      key={item.id}

              cardFocus.current = { kind: "page", index: main.items.length };
            }}
            card={card}
          />

      </section>
    </>,
  );
}
```

```tsx
  const cameraInputRef = useRef<HTMLInputElement>(null);
  const objectUrlRef = useRef<string | null>(null);
  const scenario = useAsyncData(getPosterPreviewState, []);
  const [status, setStatus] = useState<UploadStatus>("idle");
  const [steps, setSteps] = useState<AnalyzeStep[]>([]);
  const [result, setResult] = useState<PosterExtractResult | null>(null);
  const [runId, setRunId] = useState("");
  const [draft, setDraft] = useState<PosterExtractResult["draft"] | null>(null);
  const [previewUrl, setPreviewUrl] = useState("");
  const [fileName, setFileName] = useState("");
  const [isPdf, setIsPdf] = useState(false);
  const [registering, setRegistering] = useState(false);
  const [problems, setProblems] = useState<Record<string, string>>({});
  const [toast, showToast, , holdToast] = useToast();
  const [failureMessage, setFailureMessage] = useState(READ_FAILED);
  const [failureBadge, setFailureBadge] = useState("분석 실패");

  const fail = (message: string, badge: string) => {
    setFailureMessage(message);
    setFailureBadge(badge);
    setStatus("failure");
  };

  useEffect(() => {
    if (!scenario.data) return;
    if (scenario.data.status === "duplicate") {
      setStatus("duplicate");
      setResult(scenario.data.result);
      setDraft(scenario.data.result.draft);
      setPreviewUrl("/assets/mock-opportunity-poster.svg");
    } else {
      setStatus(scenario.data.status);
    }
  }, [scenario.data]);

  useEffect(
    () => () => {
      if (objectUrlRef.current) URL.revokeObjectURL(objectUrlRef.current);
    },
    [],
  );

  const reset = () => {
    if (objectUrlRef.current) URL.revokeObjectURL(objectUrlRef.current);
    objectUrlRef.current = null;
    setStatus("idle");
    setSteps([]);
    setResult(null);
    setRunId("");
    setProblems({});
    setDraft(null);
    setPreviewUrl("");
    setFileName("");
    setIsPdf(false);
    setFailureMessage(READ_FAILED);
    setFailureBadge("분석 실패");
  };

  // 목 모드는 실행이 없어 단계를 흉내 낸다. 실제 모드는 실행의 처리 과정을 그대로 받는다
  const runMockSteps = async () => {
    for (let index = 0; index < EXTRACT_STEPS.length; index += 1) {
      setSteps(
        EXTRACT_STEPS.map((label, at) => ({
          label,
          status: at < index ? "succeeded" : at === index ? "running" : "pending",
        })),
      );
      await wait(600);
    }
    setSteps(EXTRACT_STEPS.map((label) => ({ label, status: "succeeded" })));
  };

  const analyze = async (file?: File) => {
    if (!file) return;
    const validationError = await validatePosterFile(file);
    if (validationError) {
      fail(validationError, "올릴 수 없는 파일");
      return;
    }

    const pdf = file.type === "application/pdf" || /\.pdf$/i.test(file.name);
    setIsPdf(pdf);
    setFileName(file.name);
    if (!pdf) {
      if (objectUrlRef.current) URL.revokeObjectURL(objectUrlRef.current);
      objectUrlRef.current = URL.createObjectURL(file);
      setPreviewUrl(objectUrlRef.current);
    }

    setStatus("uploading");
    let fileId: string;
    try {
      fileId = (await uploadPosterFile(file)).file_id;
    } catch (error) {
      if (error instanceof ApiError && error.code === "DAILY_UPLOAD_LIMIT") {
        setStatus("limit");
        return;
      }
      fail(errorMessage(error, UPLOAD_FAILED), "올리지 못했어요");
      return;
    }
    setStatus("analyzing");
    setSteps([{ label: EXTRACT_STEPS[0], status: "running" }]);
    const extraction = extractPoster(fileId, (progress) => {
      // 실행을 막 시작했을 때는 단계 행이 아직 없다. 빈 목록으로 덮지 않는다
      if (progress.length > 0) {
        setSteps(progress.map((step) => ({ label: step.label, status: step.status })));
      }
    })
      .then((value) => ({ value, error: null }))
      .catch((error: unknown) => ({ value: null, error }));
    if (SHOW_MOCK_STEPS) await runMockSteps();

    const extracted = await extraction;
    if (extracted.error) {
      // 기다리다 끊긴 것은 실패가 아니다. 실행은 계속 돈다
      if (extracted.error instanceof ApiError && extracted.error.code === "RUN_TIMEOUT") {
        setStatus("slow");
        return;
      }
      fail(errorMessage(extracted.error, READ_FAILED), "분석 실패");
      return;
    }
    if (!extracted.value) {
      fail(READ_FAILED, "분석 실패");
      return;
    }
    const { run_id, result: read } = extracted.value;
    setRunId(run_id);
    setResult(read);
    setDraft(read.draft);
    setStatus(read.duplicate_candidate ? "duplicate" : "complete");
  };

  const register = async () => {
    if (!draft) return;
    setRegistering(true);
    setProblems({});
    try {
      const made = await registerPosterOpportunity(runId, draft);
      showToast(made.merged ? "이미 등록된 공고예요. 그 공고로 갈게요" : "공고를 등록했어요");
      setTimeout(() => navigate({ name: "opportunity", id: made.opportunity_id }), 700);
    } catch (error) {
      setRegistering(false);
      // 422는 어느 칸이 문제인지 서버가 알려 준다. 그 칸 아래에 보여 주고 안내도 띄운다
      const fields = fieldErrors(error);
      setProblems(fields);
      showToast(Object.values(fields)[0] ?? errorMessage(error, REGISTER_FAILED));
    }
  };

  const pickAgain = () => {
    reset();
    setTimeout(() => fileInputRef.current?.click());
  };

  if (scenario.loading) {
    return (
      <>
        <Skeleton className="h-[70px] w-[430px]" />
        <Skeleton className="h-[310px] w-full rounded-[18px]" />
      </>
    );
  }

  const preview = (
    <PosterSourcePreview previewUrl={previewUrl} fileName={fileName} isPdf={isPdf} />
  );

  return (
    <>
      <Header title="포스터로 공고 등록" subtitle={SUBTITLE} />
      <PosterFileInputs fileRef={fileInputRef} cameraRef={cameraInputRef} onPick={analyze} />
      {status === "idle" && (
        <PosterDropzone
          onDropFile={analyze}
          onChooseFile={() => fileInputRef.current?.click()}
          onUseCamera={() => cameraInputRef.current?.click()}
        />
      )}
      {status === "uploading" && <PosterUploading fileName={fileName} />}
      {status === "analyzing" && (
        <div className="grid grid-cols-[1fr_1fr] gap-5 max-[900px]:grid-cols-1">
          {preview}
          <PosterAnalyzing steps={steps} />
        </div>
      )}
      {status === "slow" && (
        <PosterNotice
          tone="yellow"
          badge="시간이 걸려요"
          title={STILL_READING}
          action="다시 올리기"
          onAction={pickAgain}
        />
      )}
      {status === "complete" && result && draft && (
        <div className="grid grid-cols-[0.85fr_1.15fr] gap-5 max-[900px]:grid-cols-1">
          {preview}
          <PosterExtractForm
            result={result}
            draft={draft}
            registering={registering}
            problems={problems}
            onDraftChange={setDraft}
            onRegister={register}
          />
        </div>
      )}
      {status === "duplicate" && result?.duplicate_candidate && (
        <div className="grid grid-cols-[1fr_1fr] gap-5 max-[900px]:grid-cols-1">
          {preview}
          <PosterDuplicate
            title={result.duplicate_candidate.title}
            onOpen={() =>
              navigate({ name: "opportunity", id: result.duplicate_candidate!.opportunity_id })
            }
            onPickAgain={pickAgain}
          />
        </div>
      )}
      {status === "limit" && (
        <PosterNotice
          tone="red"
          badge="업로드 한도 초과"
          title="오늘은 더 올릴 수 없어요. 내일 0시부터 다시 올릴 수 있어요"
          action="홈으로"
          onAction={() => navigate({ name: "home" })}
        />
      )}
      {status === "failure" && (
        <PosterNotice
          tone="red"
          badge={failureBadge}
          title={failureMessage}
          action="다시 올리기"
          onAction={pickAgain}
        />
      )}
      <Toast toast={toast} onHold={holdToast} />
    </>
  );
}
```
