# 알림 — 마감 임박·새 공고·정보 필요를 예약해 두고 알림함에 쌓는다

> 📝 기준: PRD v0.9 F-33·F-35 · API 명세 v0.4 10장·12장 · ERD v0.9 알림 중복 방지 표 · 2026-10-15
>
> 함께 보는 파일: `지표집계_구현.md`(먼저 합쳤다, main 36f2339)

남은 P0 여섯 개 중 알림(F-33·F-35)을 먼저 한다. LMS 넷(F-50·51·52·14)을 뒤로 둔 이유는 PRD 8장이 LMS 테스트를 "실제 Canvas 응답을 녹화"로 못 박아 둬서, 그 녹화 자료 없이 시작하면 응답 모양을 지어내게 되기 때문이다. 알림은 표 네 개(`notifications`·`push_subscriptions`·`user_settings`·`opportunity_marks`)가 이미 있고 명세 10장에 응답 모양이, ERD에 중복 방지 키까지 적혀 있다.

이 PR로 **S14**가 풀려 시나리오가 11개 → 12개가 된다.

**규모와 확인:**
- api만 바뀐다. 새 파일 5개, 바꾸는 파일 6개.
- **DB 변경이 없다.** `notifications.dedupe_key`·`read_at`, `user_settings`, `push_subscriptions`가 모두 있다. db push가 필요 없다.
- 명세에 없는 엔드포인트 하나를 더한다: `POST /internal/jobs/schedule-notifications`. 12장 작업 목록에 "알림 발송"만 있고 "알림 예약"이 없었다. 같은 PR에서 명세를 고친다(CLAUDE.md 규칙).
- api `727 passed, 156 skipped`(DB 없이), DB를 붙이면 `883 passed`. 전에는 `715 passed, 140 skipped` / `855 passed`였다.
- 시나리오 **12개 모두 통과**(S14 추가).
- 되돌림 시험 21가지를 모두 잡았다. 그중 셋은 처음에 가려져서 테스트를 고쳤다.

| --- | --- | --- |

| 보낼 이유가 없어지면 | 예약 배치가 아직 안 보낸 행을 지운다: 마감 지남·숨김·공개 범위 밖·준비 취소·판정 바뀜·새 공고를 이미 열어 봄 | 명세 10장("준비를 취소하면 pending 알림을 지운다"). "지원할 수 있는 공고가 있어요"가 부적격이 된 공고를 가리키면 안 된다 |

| 정보 필요 하루 1건 | 발송 배치가 사용자당 KST 하루 1건까지만 보낸다. 넘는 것은 보내지 않고 **둔다**(다음 날 보낸다) | ERD: "하루 1건 제한은 발송 배치가 건다" |
| 숨김 재확인 | 발송 직전에 다시 보고, 숨겼으면 보내지 않고 둔다 | 명세 10장. 예약과 발송 사이에 숨길 수 있다 |
| 푸시 발송 | 이번 PR에는 **없다**. 발송 배치는 "푸시를 보낼 수 있었던 알림 수"(`pushable`)만 센다 | 실제 발송은 VAPID 키와 서비스 워커가 필요하다(F-33). 구독이 하나도 없는 지금도 배치는 제대로 돈다 |
| 조사 붙이기 | 문구의 항목 이름에 목적격 조사를 Python에서 붙여 SQL에 jsonb로 넘긴다 | "거주지역**을** 입력하면"과 "나이**를** 입력하면"이 둘 다 맞아야 한다. 받침을 SQL에서 보는 것보다 한 함수가 낫다 |
| 알림함 cursor | 피드와 같은 cursor를 쓴다(`scheduled_at`·`id`). `unread_only`가 바뀌면 cursor를 거절한다 | 조건이 다른 목록의 cursor로 넘기면 알림이 빠지거나 겹친다 |
| 시나리오 시계 | 세계의 시계를 옮길 수 있게 했다(`world.travel(days=2)`) | S14는 "예약한 뒤 그날이 되면 보낸다"라서 한 시나리오에 시각이 두 번 필요하다. 옮겨도 주입 시계라서 며칠 뒤에 다시 돌려도 같은 결과다 |
| 시나리오의 내부 호출 | 세계가 서비스 키를 붙인 클라이언트를 준다(`world.internal()`) | 예약·발송은 스케줄러가 부르는 작업이다. 시나리오도 같은 길로 부른다 |

### 저장소 조회에 user_id 조건이 없는 곳

예약·발송 배치는 사용자 × 공고를 모두 보는 일이라 좁힐 사용자가 없다(서비스 키로만 부르는 작업이다). 알림함 조회·읽음은 **모두 `user_id` 조건을 건다** — 되돌림 시험에서 그 조건을 지워 남의 알림이 읽음 처리되는지도 확인했다.

## 합친 뒤 확인

`INTERNAL_API_KEY`가 `api/.env`에 있어야 한다(앞 PR에서 넣었다). `$env:KEY`에 담아 쓴다.

1. **알림함(비어 있음):** 로그인한 뒤 브라우저 콘솔이나 `curl`로 `GET /api/v1/notifications`를 부르면 `{"items": [], "unread_count": 0, "next_cursor": null}`이다.
2. **예약:**

   ```powershell
   $env:KEY = Read-Host "INTERNAL_API_KEY"
   curl.exe -s -X POST -H "X-Internal-Key: $env:KEY" http://localhost:8000/api/v1/internal/jobs/schedule-notifications
   ```

   `created`가 0보다 크고 `by_type`에 세 종류가 보인다. 청년정책 410건이 들어 있으면 `deadline_soon`이 꽤 많이 나온다 — 마감일이 있는 적격 공고마다 2건이다.
3. **다시 예약:** 같은 명령을 한 번 더 부르면 `created: 0`이다. 같은 알림을 두 번 만들지 않는다.
4. **발송:** `POST /api/v1/internal/jobs/send-notifications`. `due`는 **09:00이 지난 알림**만 센다. 방금 예약했으면 0일 수 있다(내일 아침에 보낸다). `pushable`은 0이다(구독이 없다 — 실제 푸시는 F-33).
5. **알림함(쌓인 뒤):** 1번을 다시 부르면 보낸 알림이 최신순으로 보이고 `unread_count`가 그 수다. 정보 필요 알림의 `link.focus`가 `profile_input`이다.
6. **읽음:** `POST /api/v1/notifications/read`에 `{"all": true}`를 보내면 `{"unread_count": 0}`이다. 헤더 배지(`GET /me`의 `unread_notifications`)도 0이 된다.
7. **숨기면 빠지는지:** 공고 하나를 홈에서 "숨기기"한 뒤 2번을 다시 부르면 `removed`가 그만큼 늘고, 그 공고의 아직 안 보낸 알림이 사라진다.
8. **시나리오:** 시험용 DB에서 `uv run python -m app.eval.cli --scenarios S14`가 `통과 1/1`이다.

## 확인한 것

| 확인 | 결과 |
| --- | --- |
| 시나리오 12개 | `12/12`. S14는 확인 17개다(예약 → 다시 예약 → D-3 전 → D-3 발송 → D-1 발송 → 더 보낼 것 없음 → 알림함 → 읽음) |
| 예약: 누구에게 | 적격·"그래도 준비한" 공고에만 마감 알림이 간다(부적격·판정 불가 공고에는 안 간다). 숨긴 공고와 끈 종류는 **행을 만들지 않는다**(만들었다 지우는 것과 다른지 `removed == 0`으로 확인). 남의 포스터 공고에는 안 간다 |
| 예약: 언제 | 모두 KST 09:00. 마감 10일 뒤 공고면 새 공고 오늘 09:00 · D-3 10-22 09:00 · D-1 10-24 09:00. 마감이 1.5일 뒤인 공고는 **D-1만** 만든다. 09시가 지난 뒤에 예약하면 새 공고 알림은 내일 09:00이다 |
| 예약: 다시 돌릴 때 | 두 번 돌려도 `created 0 · rescheduled 0 · removed 0`이고 행이 그대로다. 마감을 5일 미루면 아직 안 보낸 D-1만 옮기고(`rescheduled 1`) 이미 보낸 D-3은 그대로다 |
| 예약: 지우기 | 판정이 부적격으로 바뀐 공고, 숨긴 공고, 상세를 열어 본 공고의 새 공고 알림 — 세 가지로 pending 7건이 지워지고 남아야 할 2건만 남는다 |
| 발송 | 구독이 없어도 행을 닫는다(알림함에 남는다). 구독이 있는 사용자만 `pushable`에 센다. 예약 뒤 숨긴 공고는 `sent 0 · skipped 1`로 **두고** 보내지 않는다 |
| 정보 필요 하루 1건 | 3건이 밀려 있어도 `sent 1 · skipped 2`. 같은 날 다시 불러도 0건, 다음 날 1건. 문구가 "거주지역을 입력하면 판정할 수 있어요"다 |
| 두 번 닫지 않기 | 이미 보낸 알림에 `mark_sent`를 다시 불러도 0건이고 `sent_at`이 처음 보낸 날 그대로다(두 배치가 겹쳐 돌 때) |

### 되돌림 시험에서 고친 것

## 남은 것

- **실제 웹 푸시 발송 (F-33)**: VAPID 키 한 쌍, `POST /push/subscriptions`·`DELETE`, 서비스 워커, 푸시 페이로드(명세 10장에 모양이 있다). 발송 배치는 이미 "푸시를 보낼 수 있는 알림"을 세고 있어서 그 자리에 실제 발송만 넣으면 된다. **키는 네가 만들어 `.env`에 넣어야 한다**(채팅에 붙이지 않는다).
- **알림함 화면 (F-35 web)**: 헤더 배지는 이미 `GET /me`의 `unread_notifications`를 본다. 패널·전체 목록 화면과 "누르면 그 화면으로 이동하며 읽음 처리"가 남았다.
- **`GET`·`PATCH /me/settings` (F-06, P1)**: 지금은 `user_settings` 행을 만들 길이 없어서 모두 기본값(푸시 켬, 끈 종류 없음)으로 돈다. 배치는 행이 없는 사용자를 기본값으로 보게 해 뒀다.
- **`task_due`(준비 일정 당일)**: ERD 중복 방지 표에 키가 없다. 키를 정하면 같은 배치에 한 문장 더하는 일이다.
- **LMS 알림 넷**(`new_assignment`·`new_material`·`schedule_change`, LMS 과제의 `deadline_soon`): LMS(F-50대)와 함께. 알림함의 `link`와 `course_id`는 그 세 종류까지 이미 만들어 둬서, 행만 생기면 보인다.
- **헤더 배지의 시계**: `GET /me`의 안 읽은 수는 DB `now()`를 쓰고 알림함은 주입 시계를 쓴다. 지금은 차이가 없지만(배포 전) 한쪽으로 모으는 것이 낫다.
- **큰 사용자 수에서의 예약 비용**: 지금은 사용자 × 공고를 매번 다 본다. `on conflict do nothing`이라 결과는 맞지만, 사용자가 늘면 "지난번 예약 이후 바뀐 것만" 보도록 좁혀야 한다.
- **S09·S10·S15–S18**: S09·S10은 실제 HWP·PDF와 저장한 공지 폴더가, S15–S18은 LMS 기능이 먼저다.

from typing import Literal
from uuid import UUID

NotificationType = Literal[
    "new_eligible",

    "new_material",

    "deadline_soon",

]

OPPORTUNITY_TYPES: tuple[str, ...] = ("new_eligible", "deadline_soon", "profile_needed")


class NotificationLink(BaseModel):
    """누르면 갈 곳. focus가 profile_input이면 상세에서 정보 입력창을 바로 연다."""

    type: LinkType

    def one_of(self) -> "ReadRequest":

# 설정 행이 없는 사용자는 기본값(끈 종류 없음)이다
_NOT_MUTED = " not (%(type)s = any(coalesce(s.muted_notification_types, '{}')))"
_NOT_DISMISSED = " (m.mark is null or m.mark <> 'not_interested')"
_ACTIVE = " o.status = 'active'"
_UNEXPIRED = " (o.deadline_at is null or o.deadline_at >= %(now)s)"
# KST 날짜에 알림 시각을 붙여 timestamptz로 만든다
_AT_HOUR = f"((%s)::date + time '{NOTIFY_HOUR:02d}:00') at time zone 'Asia/Seoul'"
_DEADLINE_DAY = "(o.deadline_at at time zone 'Asia/Seoul')::date - d.days"
_NEXT_DAY = "%(next_day)s"


def needed_phrases() -> dict[str, str]:
    """물어볼 항목 이름 + 목적격 조사. SQL에서 문구를 만들 수 있게 미리 붙여 둔다."""
    return {field: f"{label}{_particle(label)}" for field, label in INPUT_LABELS.items()}


def _particle(word: str) -> str:
    """목적격 조사: 받침이 있으면 "을", 없으면 "를"."""
    last = word[-1]
    if "가" <= last <= "힣":
        return "을" if (ord(last) - 0xAC00) % 28 else "를"
    return "을"


@dataclass(frozen=True)
class Due:
    """보낼 알림 하나. dismissed는 그새 숨긴 공고다(보내지 않고 둔다)."""

    id: str
    user_id: str
    type: str
    dismissed: bool


class NotificationRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    # ── 예약 ────────────────────────────────────────────────────────────────

    async def schedule(self, *, now: datetime) -> ScheduleResult:
        """공고 알림 세 종류를 예약하고, 조건에서 빠진 pending 행을 지운다."""
        today = now.astimezone(KST).date()
        next_day = today if now.astimezone(KST).hour < NOTIFY_HOUR else today + timedelta(days=1)
        common = {"now": now, "next_day": next_day}
        result = ScheduleResult(created=0, rescheduled=0, removed=0, by_type={})
        for kind, query, params in (
            ("new_eligible", _NEW_ELIGIBLE, {}),
            ("deadline_soon", _DEADLINE_SOON, {"days": list(DEADLINE_DAYS)}),
            ("profile_needed", _PROFILE_NEEDED, {"needed": Jsonb(needed_phrases())}),
        ):
            rows = await self._rows(query, {**common, **params, "type": kind})
            created = sum(1 for row in rows if row["inserted"])
            result.created += created
            result.rescheduled += len(rows) - created
            result.by_type[kind] = len(rows)
        result.removed = await self._removed(now)
        return result

    async def _removed(self, now: datetime) -> int:
        """보낼 이유가 없어진 pending 행을 지운다. 보낸 행은 알림함에 남으므로 건드리지 않는다."""
        cursor = await self.conn.execute(_STALE, {"now": now, "types": list(_KINDS)})
        return cursor.rowcount

    # ── 발송 ────────────────────────────────────────────────────────────────

    async def due(self, *, now: datetime, limit: int = SEND_LIMIT) -> list[Due]:
        """보낼 때가 된 pending 알림. 오래된 것부터다."""
        rows = await self._rows(_DUE, {"now": now, "limit": limit})
        return [
            Due(
                id=str(row["id"]),
                user_id=str(row["user_id"]),
                type=row["type"],
                dismissed=row["dismissed"],
            )
            for row in rows
        ]

    async def sent_today(self, *, now: datetime, kind: str) -> dict[str, int]:
        """오늘(KST) 사용자별로 이미 보낸 그 종류의 알림 수. 하루 한도를 보는 데 쓴다."""
        rows = await self._rows(
            "select user_id::text as user_id, count(*) as count from notifications"
            " where type = %(type)s and sent_at is not null"
            " and (sent_at at time zone 'Asia/Seoul')::date = %(today)s group by 1",
            {"type": kind, "today": now.astimezone(KST).date()},
        )
        return {row["user_id"]: int(row["count"]) for row in rows}

    async def pushable(self, ids: Sequence[str]) -> int:
        """그중 푸시를 보낼 수 있는 알림 수(구독이 있고 푸시를 끄지 않았다). 실제 발송은 F-33."""
        if not ids:
            return 0
        row = await self._row(
            "select count(*) as count from notifications n"
            " left join user_settings s on s.user_id = n.user_id"
            " where n.id = any(%(ids)s::uuid[]) and coalesce(s.push_enabled, true)"
            " and exists (select 1 from push_subscriptions q where q.user_id = n.user_id)",
            {"ids": list(ids)},
        )
        return int(row["count"]) if row else 0

    async def mark_sent(self, ids: Sequence[str], *, now: datetime) -> int:
        """보낸 알림을 닫는다. 푸시를 못 보내도 알림함에는 남아야 하므로 succeeded다(ERD)."""
        if not ids:
            return 0
        cursor = await self.conn.execute(
            "update notifications set status = 'succeeded', sent_at = %(now)s"
            " where id = any(%(ids)s::uuid[]) and status = 'pending'",
            {"ids": list(ids), "now": now},
        )
        return cursor.rowcount

    async def send(self, *, now: datetime, limit: int = SEND_LIMIT) -> SendResult:
        """보낼 때가 된 알림을 닫는다. 숨긴 공고와 하루 한도를 넘는 알림은 보내지 않고 둔다."""
        due = await self.due(now=now, limit=limit)
        already = await self.sent_today(now=now, kind="profile_needed")
        sending: list[str] = []
        for item in due:
            if item.dismissed:
                continue
            if item.type == "profile_needed":
                if already.get(item.user_id, 0) >= PROFILE_DAILY:
                    continue
                already[item.user_id] = already.get(item.user_id, 0) + 1
            sending.append(item.id)
        count = await self.pushable(sending)
        return SendResult(
            due=len(due),
            sent=await self.mark_sent(sending, now=now),
            pushable=count,
            skipped=len(due) - len(sending),
        )

    # ── 알림함 ──────────────────────────────────────────────────────────────

    async def unread(self, user_id: str, *, now: datetime) -> int:
        row = await self._row(
            "select count(*) as count from notifications where user_id = %(uid)s"
            " and read_at is null and scheduled_at <= %(now)s",
            {"uid": user_id, "now": now},
        )
        return int(row["count"]) if row else 0

    async def listing(
        self,
        user_id: str,
        *,
        now: datetime,
        unread_only: bool = False,
        limit: int = 20,
        cursor: str | None = None,
    ) -> NotificationList:
        """지난 알림을 최신순으로. 안 읽은 수는 필터와 상관없이 전체 기준이다."""
        scope = f"unread={unread_only}"
        after = ""
        params: dict[str, Any] = {"uid": user_id, "now": now, "limit": limit + 1}
        if cursor:
            found = decode_cursor(cursor)
            if found.scope != scope or found.value is None:
                raise ValueError("조건이 다른 목록의 cursor")
            after = " and (n.scheduled_at, n.id) < (%(at)s, %(id)s::uuid)"
            params |= {"at": found.value, "id": found.id}
        rows = await self._rows(
            _LIST.format(unread=" and n.read_at is null" if unread_only else "", after=after),
            params,
        )
        items = [_item(row) for row in rows[:limit]]
        last = rows[limit - 1] if len(rows) > limit else None
        return NotificationList(
            items=items,
            unread_count=await self.unread(user_id, now=now),
            next_cursor=encode_cursor(
                Cursor(scope=scope, value=last["scheduled_at"], id=str(last["id"]))
            )
            if last
            else None,
        )

    async def read(self, user_id: str, *, now: datetime, ids: Sequence[UUID] | None = None) -> int:
        """읽음 처리. ids가 없으면 전체다. 아직 보낼 때가 안 된 알림은 건드리지 않는다."""
        where = "" if ids is None else " and id = any(%(ids)s::uuid[])"
        await self.conn.execute(
            "update notifications set read_at = %(now)s where user_id = %(uid)s"
            " and read_at is null and scheduled_at <= %(now)s" + where,
            {"uid": user_id, "now": now, "ids": [str(item) for item in ids or ()]},
        )
        return await self.unread(user_id, now=now)

    # ── 조회 ────────────────────────────────────────────────────────────────

    async def _rows(self, query: str, params: dict[str, Any]) -> list[dict[str, Any]]:
        return await (await self.conn.execute(query, params)).fetchall()

    async def _row(self, query: str, params: dict[str, Any]) -> dict[str, Any] | None:
        return await (await self.conn.execute(query, params)).fetchone()


def _item(row: dict[str, Any]) -> NotificationItem:
    return NotificationItem(
        id=str(row["id"]),
        type=row["type"],
        title=row["title"],
        body=row["body"],
        scheduled_at=row["scheduled_at"].astimezone(KST),
        read_at=row["read_at"].astimezone(KST) if row["read_at"] else None,
        link=_link(row),
    )


def _link(row: dict[str, Any]) -> NotificationLink | None:
    """누르면 갈 곳. 대상 id가 하나도 없으면 링크가 없다(명세 10장)."""
    for kind, column in _LINKS:
        if row[column] is not None:
            return NotificationLink(
                type=kind,
                id=str(row[column]),
                course_id=str(row["course_id"]) if row["course_id"] else None,
                focus="profile_input" if row["type"] == "profile_needed" else None,
            )
    return None

    async def user(self, **settings: Any) -> str:
        user_id = str(uuid.uuid4())
        self.users.append(user_id)
        await self.conn.execute("insert into auth.users (id) values (%s)", (user_id,))
        await self.conn.execute(
            "insert into profiles (id, display_name) values (%s, '알림 학생')", (user_id,)
        )

            )

            "source_type": "school_notice",
            "category": "scholarship",
            "title": title,
            "deadline_at": None if days is None else NOW + timedelta(days=days),
            "extraction_run_id": self.run,
            **columns,
        }
        names = ", ".join(values)
        marks = ", ".join(["%s"] * len(values))
        row = await (
            await self.conn.execute(
                f"insert into opportunities ({names}) values ({marks}) returning id::text as id",
                tuple(values.values()),
            )
        ).fetchone()

        self.ids[title] = row["id"]
        return str(row["id"])

            " on conflict (user_id, opportunity_id) do update set status = excluded.status,"
            " missing_fields = excluded.missing_fields",
            (user_id, opportunity_id, status, list(missing)),
        )

            (user_id, opportunity_id, mark),
        )

            )
        ).fetchall()

    def _token(self, user_id: str) -> str:
        """로그인 토큰. 유효 기간은 **이 컴퓨터의 지금**으로 잰다 — 주입한 시계는 업무 규칙에만 쓴다.
        고정 시각으로 만들면 과거 날짜를 넣었을 때 토큰이 만료로 거절된다."""
        issued = int(time.time())
        claims = {
            "sub": user_id,
            "aud": "authenticated",
            "role": "authenticated",
            "exp": issued + 3600,
            "iat": issued - 60,
            "email": f"{user_id[:8]}@eval.invalid",
            "user_metadata": {"full_name": "시나리오 학생"},
        }
        return jwt.encode(claims, self.settings.supabase_jwt_secret, algorithm="HS256")

        self, client: httpx.AsyncClient, run_id: str, *, timeout: float = RUN_TIMEOUT_SECONDS
    ) -> dict[str, Any]:
        """202로 시작한 실행이 끝날 때까지 `GET /runs/{id}`를 다시 묻는다(화면이 하는 그대로)."""
        deadline = asyncio.get_running_loop().time() + timeout

            response.raise_for_status()
            body: dict[str, Any] = response.json()

            if asyncio.get_running_loop().time() > deadline:
                raise TimeoutError(f"실행이 {timeout}초 안에 끝나지 않았어요: run {run_id}")
            await asyncio.sleep(RUN_POLL_SECONDS)

        self, client: httpx.AsyncClient, opportunity_id: str, **params: Any
    ) -> dict[str, Any] | None:
        """피드에서 그 공고 카드를 찾는다. 없으면 None.

        쪽을 끝까지 넘긴다. 한 쪽은 최대 50건이라(명세 5장) DB에 다른 공고가 많으면 1쪽에 없을 수 있고,
        그때 "피드에 없다"고 보면 멀쩡한 코드가 실패로 보인다.
        """
        cursor: str | None = None
        for _ in range(FEED_PAGES):
            query = {**params, "limit": FEED_PAGE, **({"cursor": cursor} if cursor else {})}
            response = await client.get(self.path("/opportunities"), params=query)
            response.raise_for_status()
            page = response.json()
            for item in page["items"]:
                if item["id"] == opportunity_id:
                    return dict(item)
            cursor = page["next_cursor"]
            if not cursor:
                return None
        raise AssertionError(f"피드가 {FEED_PAGES}쪽을 넘어요. 공고가 너무 많은 DB예요")

    # ── 확인 ────────────────────────────────────────────────────────────────

    async def check(
        self, what: str, *, expected: Any, actual: Any, kind: str | None = None
    ) -> None:
        """기대와 실제를 맞춰 보고 실행 기록에 한 줄 남긴다. 다르면 시나리오를 여기서 멈춘다.

        남는 곳이 tool_calls.input·output이므로 **프로필 값과 토큰은 넘기지 않는다**(ERD의 컬럼 설명,
        api/CLAUDE.md). `scrub`은 키 이름으로만 지우니 값은 걸러 주지 못한다. 나이·평점처럼 프로필에서
        온 값은 그대로 쓰지 말고 맞는지(bool)나 항목 이름으로 바꿔서 확인한다.

        kind는 집계가 골라 읽을 종류다. 판정 확인은 check를 바로 부르지 말고 judged를 쓴다.
        """
        found = Check(what, plain(expected), plain(actual), kind)
        self.checks.append(found)
        recorded = {"what": found.what, "expected": found.expected}
        async with self.run.tool(CHECK_TOOL, recorded | ({"kind": kind} if kind else {})) as call:
            call.output = {"actual": found.actual, "ok": found.ok}
            if not found.ok:
                raise CheckFailed(found)

    async def judged(self, what: str, *, expected: str, actual: Any) -> None:
        """판정 확인. 판정 혼동행렬(PRD 8장)이 이 줄만 읽는다.

        expected는 정답 상태, actual은 엔진이 낸 상태다. 둘 다 판정 상태 3가지여야 한다 — 화면 라벨
        (display_status, 4가지)을 넣으면 3×3 행렬에 담기지 않는다.
        """
        if expected not in ELIGIBILITY_STATUSES:
            raise AssertionError(
                f"판정 확인의 기대값은 {ELIGIBILITY_STATUSES} 중 하나다: {expected!r}"
            )
        await self.check(what, expected=expected, actual=actual, kind=ELIGIBILITY_CHECK)

    # ── 세계 만들기 ──────────────────────────────────────────────────────────

    async def extraction_run(self) -> str:
        """공고에 붙일 추출 실행. 요건 추출을 한 척하는 수집 실행 한 줄이다.

        시나리오 실행(trigger eval)을 그대로 쓰면 공고 상세의 처리 과정(F-42)에 확인(check) 줄이
        단계로 보인다. 그래서 따로 만든다. 도구 기록이 없으니 처리 과정은 비어 있다.
        """
        if self._extraction_run is None:
            row = await (
                await self.conn.execute(
                    "insert into agent_runs (trigger_type, status, scenario_code, finished_at,"
                    " latency_ms) values ('batch_crawl', 'succeeded', %s, now(), 0)"
                    " returning id::text as id",
                    (self.scenario_code,),
                )
            ).fetchone()
            assert row is not None
            self._extraction_run = row["id"]
            self.extra_runs.append(row["id"])
        return self._extraction_run

    async def add(

        *,

    async def youth(self, policy: Mapping[str, Any]) -> str:
        """온통청년 정책 하나를 실제 변환 코드로 공고로 만든다(F-11, LLM 없음).

        importer.collect가 아니라 convert + save_policy를 부른다. collect는 목록에서 사라진 정책을
        숨기는 일(retire)까지 하므로, 시나리오가 만들지 않은 공고까지 건드린다. 요건은 같은 코드로
        만들어진다.

        save_policy는 (source_id, external_id)로 덮어쓰기(upsert)다. 그래서 **같은 번호의 공고가
        이미 있으면 손대지 않고 멈춘다** — 실제로 수집해 둔 정책을 고치고 치울 때 지우면 안 된다.
        """
        source_id = await ensure_source(self.conn)
        record = convert(policy, self.today, region_table())
        if isinstance(record, Skip):
            raise AssertionError(f"녹화한 정책이 걸러졌어요: {record.reason}")
        assert isinstance(record, PolicyRecord)
        found = await self.conn.execute(
            "select id from opportunities where source_id = %s and external_id = %s",
            (source_id, record.external_id),
        )
        if await found.fetchone() is not None:
            raise AssertionError(
                f"이미 수집해 둔 정책({record.external_id})이에요. 시나리오 전용 번호를 쓰세요"
            )
        await save_policy(self.conn, source_id, record, await self.extraction_run())
        row = await (
            await self.conn.execute(
                "select id::text as id from opportunities where source_id = %s and external_id = %s",
                (source_id, record.external_id),
            )
        ).fetchone()
        assert row is not None
        self.opportunities.append(row["id"])
        return str(row["id"])

    async def rows(self, query: str, *params: Any) -> list[dict[str, Any]]:
        """확인용 조회. 시나리오가 화면으로 볼 수 없는 것(캘린더 행 수 등)을 셀 때만 쓴다."""
        return await (await self.conn.execute(query, params)).fetchall()

    async def close(self) -> None:
        """클라이언트를 닫는다. 하나가 실패해도 나머지를 닫는다."""
        for http in self._clients:
            try:
                await http.aclose()
            except Exception:
                logger.exception("클라이언트를 닫지 못했어요")
        self._clients.clear()

    async def cleanup(self) -> None:
        """사용자와 공고를 지운다. 실행 기록은 지표의 원천이라 남긴다(모듈 머리말).

        한 줄이 실패해도 나머지를 지우고, 오류를 올리지 않는다. 치우다 터지면 시나리오가 왜 실패했는지
        (CheckFailed)가 그 오류에 덮인다.
        """
        await self.close()
        statements: list[tuple[str, Sequence[Any]]] = []
        if self.opportunities:
            statements.append(
                ("delete from opportunities where id = any(%s::uuid[])", (self.opportunities,))
            )
        if self.users:
            # 시나리오가 API로 만든 포스터 공고. 번호를 모르니 올린 사람으로 찾는다
            statements.append(
                ("delete from opportunities where uploaded_by = any(%s::uuid[])", (self.users,))
            )
            statements.append(("delete from auth.users where id = any(%s::uuid[])", (self.users,)))
        if self._departments:
            statements.append(
                ("delete from departments where name = any(%s)", (self._departments,))
            )
        for query, params in statements:
            try:
                await self.conn.execute(query, params)
            except Exception:
                logger.exception("치우지 못한 것이 있어요: %s", query[:60])

```python
"""시나리오를 차례로 돌리고 성공률·응답시간·비용을 모은다(PRD 8장 지표).

시나리오 하나 = `agent_runs` 한 줄(trigger `eval`, scenario_code `S01`). 그 아래 `tool_calls`에
확인한 것을 `check` 한 줄씩 남긴다 — 다음 PR의 판정 혼동행렬이 이 줄을 읽는다.

시나리오가 뒤에서 만든 실행(준비하기·포스터 추출)은 끝난 뒤 같은 scenario_code를 붙인다. 비용과 LLM
호출 수는 **그 실행들의 `llm_calls`를 더해서** 센다. 시나리오 실행 행 자신의 cost_usd는 0으로 둔다
(제 손으로 모델을 부르지 않는다). 집계하는 쪽은 `agent_runs.cost_usd`를 다시 더하지 말고
scenario_code로 묶은 `llm_calls`를 본다 — 그러지 않으면 같은 비용을 두 번 센다.

시나리오는 한 번에 하나만 돈다. 사용자·공고를 만들고 지우는 동안 다른 시나리오가 끼어들면 피드에
남의 공고가 섞인다.
"""

from collections.abc import Sequence

from decimal import Decimal

from app.config import Settings

from app.eval.models import CheckFailed, Report, ScenarioResult
from app.eval.world import (
    DEFAULT_NOW,
    Clock,
    EvalWorld,
    Scenario,
    connect,
    eval_settings,
    managed_database,
    open_app,
)

logger = logging.getLogger(__name__)
TRIGGER = "eval"
DRAIN_SECONDS = 60.0  # 뒤에서 도는 일을 기다리는 상한(app/main.py의 종료와 같은 뜻)


async def run_scenarios(
    database_url: str,
    scenarios: Sequence[Scenario],
    *,
    now: datetime = DEFAULT_NOW,
) -> Report:
    """시나리오를 차례로 돌린다. 하나가 실패해도 나머지를 돈다(성공률을 재는 것이 목적이다)."""
    if problem := managed_database(database_url):
        raise RuntimeError(problem)
    settings = eval_settings(database_url)
    setup = await connect(database_url)
    log_conn = await connect(database_url)
    # 단가는 돌린 날로 고른다(app/agent_log.py의 record_llm). 베이스라인을 비교할 때 이 날짜를 본다
    report = Report(now=now, priced_on=datetime.now(KST).date())
    try:
        for scenario in scenarios:
            result = await _one(scenario, settings=settings, setup=setup, log=log_conn, now=now)
            report.results.append(result)
    finally:
        for conn in (setup, log_conn):
            try:
                await conn.close()
            except Exception:
                logger.exception("연결을 닫지 못했어요")
    return report


async def _one(
    scenario: Scenario,
    *,
    settings: Settings,
    setup: psycopg.AsyncConnection,
    log: psycopg.AsyncConnection,
    now: datetime,
) -> ScenarioResult:
    llm, storage, calendar = RecordedLlm(), RecordedStorage(), RecordedCalendar()
    clock = Clock(now)  # 시나리오가 옮길 수 있다(world.travel)
    world: EvalWorld | None = None
    run_id: str | None = None
    children: list[str] = []
    elapsed_ms = 0
    ok, error = True, None
    try:
        app, pool, log_pool = await open_app(
            settings, clock=clock, llm=llm, storage=storage, calendar=calendar
        )
        try:
            async with agent_run(using(log), trigger=TRIGGER, scenario_code=scenario.code) as run:
                run_id = run.id
                world = EvalWorld(
                    conn=setup,
                    app=app,
                    settings=settings,
                    clock=clock,
                    run=run,
                    scenario_code=scenario.code,
                    llm=llm,
                    storage=storage,
                    calendar=calendar,
                )
                started = time.perf_counter()
                try:
                    await scenario.run(world)
                    await _finished(world)
                finally:
                    elapsed_ms = int((time.perf_counter() - started) * 1000)
                    # 실행 기록에도 같은 값을 남긴다. 아래 치우는 시간은 응답시간이 아니다
                    run.latency_ms = elapsed_ms
                    # 뒤에서 도는 일(준비하기·포스터 추출)을 먼저 끝낸다. 확인이 틀려 중간에 멈췄으면
                    # 아직 도는 일이 있고, 그 일이 쥔 연결을 두고 풀을 닫으면 안 된다
                    await app.state.runner.drain(timeout=DRAIN_SECONDS)
                    children = world.extra_runs + await _tag_children(
                        setup, scenario.code, run.id, world.users
                    )
                    await world.cleanup()
                    _check_drained(app.state.runner.running, scenario.code)
        finally:
            await pool.close()
            await log_pool.close()
    except CheckFailed as exc:
        ok, error = False, str(exc)
    except Exception as exc:  # 시나리오가 터져도 나머지 시나리오를 돈다
        logger.exception("시나리오 %s가 터졌어요", scenario.code)
        ok, error = False, f"{type(exc).__name__}: {exc}"
    cost, calls = await _usage(setup, [run_id, *children] if run_id else children)
    return ScenarioResult(
        code=scenario.code,
        title=scenario.title,
        ok=ok,
        latency_ms=elapsed_ms,
        api_ms=round(world.api_ms, 1) if world else 0.0,
        run_id=run_id,
        child_run_ids=children,
        cost_usd=cost,
        llm_calls=calls,
        checks=list(world.checks) if world else [],
        error=error,
    )


async def _finished(world: EvalWorld) -> None:
    """시나리오가 끝났을 때 맞아야 하는 것. 조용히 통과하는 시나리오를 막는다."""
    if not world.checks:
        raise AssertionError("확인(check)이 하나도 없는 시나리오예요")
    if world.llm.replies:
        # 서류 사전이 늘어 모델을 안 부르게 되면 비용이 0이 되는데, 확인은 다 통과한다
        raise AssertionError(f"쓰지 않은 녹화 답이 {len(world.llm.replies)}개 남았어요")


def _check_drained(running: int, code: str) -> None:
    """뒤에서 도는 일을 못 끝냈으면 그 시나리오는 실패다. 비용이 빠지고 기록도 반쪽이 된다."""
    if running:
        raise TimeoutError(
            f"{code}: 뒤에서 도는 일 {running}개가 {DRAIN_SECONDS}초 안에 안 끝났어요"
        )


async def _tag_children(
    conn: psycopg.AsyncConnection, code: str, run_id: str, users: Sequence[str]
) -> list[str]:
    """시나리오가 돌면서 생긴 실행에 시나리오 번호를 붙인다. 붙인 실행 번호를 돌려준다.

    치우기 전에 불러야 한다. 사용자를 지우면 agent_runs.user_id가 null이 되어 더는 찾을 수 없다.
    실패해도 올리지 않는다(치우기를 막지 않게). 그 실행의 비용은 0으로 보인다.
    """
    if not users:
        return []
    try:
        rows = await (
            await conn.execute(
                # 시나리오 실행 자신은 user_id가 없어 걸리지 않지만 분명히 해 둔다
                "update agent_runs set scenario_code = %s where id <> %s and scenario_code is null"
                " and user_id = any(%s::uuid[]) returning id::text as id",
                (code, run_id, list(users)),
            )
        ).fetchall()
    except Exception:
        logger.exception("자식 실행에 시나리오 번호를 붙이지 못했어요: %s", code)
        return []
    return [row["id"] for row in rows]


async def _usage(conn: psycopg.AsyncConnection, run_ids: Sequence[str]) -> tuple[Decimal, int]:
    """시나리오 1회의 LLM 비용과 호출 수(실행 로그의 토큰 × 단가로 이미 계산된 값)."""
    if not run_ids:
        return Decimal(0), 0
    row = await (
        await conn.execute(
            "select coalesce(sum(cost_usd), 0) as cost, count(*) as calls from llm_calls"
            " where run_id = any(%s::uuid[])",
            (list(run_ids),),
        )
    ).fetchone()
    assert row is not None
    return Decimal(str(row["cost"])), int(row["calls"])
```

async def _deadlines(world: EvalWorld, client: httpx.AsyncClient) -> list[str]:
    """알림함에 보이는 마감 임박 알림의 D-day."""

        item["body"].rsplit("· ", 1)[-1] for item in box["items"] if item["type"] == "deadline_soon"
    ]

async def _detail(world: EvalWorld, client: httpx.AsyncClient, opportunity: str) -> dict:
    response = await client.get(world.path(f"/opportunities/{opportunity}"))

def _born_on_last_day(on: date, age: int) -> date:
    """on 날짜에 만 age세인 마지막 날이 되도록 하는 생일(다음 날 age+1세가 된다)."""
    turns = on + timedelta(days=1)
    try:
        return turns.replace(year=turns.year - age - 1)
    except ValueError:  # 2월 29일생: 그 해가 윤년이 아니면 민법상 3월 1일에 나이가 오른다
        return turns.replace(year=turns.year - age - 1, day=28)


def _day(moment: str | None) -> str | None:
    """KST 오프셋이 붙은 시각의 날짜(YYYY-MM-DD)."""
    return datetime.fromisoformat(moment).date().isoformat() if moment else None

def test_values_are_turned_into_json_before_they_are_stored() -> None:
    assert plain({"when": datetime(2026, 10, 12, 9, tzinfo=KST)}) == {
        "when": "2026-10-12T09:00:00+09:00"
    }
    # 집합은 순서를 정해 준다. 정수는 해시가 고정이라 {8, 1}은 그대로 쓰면 [8, 1] 순서로 나온다
    assert plain({8, 1}) == [1, 8]
    assert plain({"fields", "clauses"}) == ["clauses", "fields"]
    assert plain([Decimal("0.5"), (1, date(2026, 1, 2))]) == [0.5, [1, "2026-01-02"]]

async def test_the_recorded_calendar_keeps_one_event_per_number() -> None:
    calendar = RecordedCalendar()
    ends_at = datetime(2026, 11, 20, 18, tzinfo=KST)
    first = await calendar.insert("token", event_id="abc", title="[마감] 공고", ends_at=ends_at)
    again = await calendar.insert("token", event_id="abc", title="[마감] 공고", ends_at=ends_at)
    assert isinstance(first, GoogleEvent) and first == again
    assert (calendar.inserts, len(calendar.events)) == (2, 1)  # 두 번 불러도 일정은 하나
    assert calendar.titles == {"abc": "[마감] 공고"}
    # 실제 클라이언트처럼 이번에 보낸 시각으로 돌려준다(마감일이 바뀐 재등록을 가리지 않게)
    moved = await calendar.insert(
        "token", event_id="abc", title="[마감] 공고", ends_at=ends_at + timedelta(days=1)
    )
    assert moved.ends_at == ends_at + timedelta(days=1)
    assert await calendar.refresh("refresh-token") == ("recorded-access-token", 3600)
    await calendar.delete("token", "abc")
    assert calendar.events == {} and calendar.titles == {} and calendar.deletes == ["abc"]
