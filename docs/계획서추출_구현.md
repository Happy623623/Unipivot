# 강의계획서 일정 추출 (F-14 1부) — `POST /files`(계획서) · `POST /syllabi/extract`

> 📝 기준: API 명세 v0.4 6장 `POST /files` · 8장 `POST /syllabi/extract` · 11장 실행 조회 · PRD v0.9 F-14(시나리오 S15) · ERD v0.9 `syllabi`·`syllabus_items` · 2026-10-17
>
> 먼저 합칠 것: `과목상세_구현.md`(#43) → `설정API_구현.md` → `과제캘린더등록_구현.md` → `web학업화면_구현.md` → `시나리오S16S18_구현.md` → **이 문서**

과목 상세의 **"계획서" 탭이 비어 있던 이유**가 이것이다. 학생이 포털 계획서를 PDF로 저장해 올리면, 글자를 뽑아 **중간·기말·발표·과제** 일정만 골라 저장한다. 그 탭이 이제 채워진다.

```text
학생: 과목 상세에서 "계획서 가져오기" → 포털 계획서가 브라우저에 열림 → 인쇄 → PDF로 저장
   → POST /files (kind=syllabus)  → file_id
   → POST /syllabi/extract        → 202 run_id
   → GET /runs/{run_id}           → 중간고사 10/20 10:30, 팀 프로젝트 발표 12/08 …
```

**확정은 다음 PR이다.** 뽑은 일정은 `is_confirmed` false로 저장되고, 플래너·캘린더로 보내는 `POST /syllabi/{id}/confirm`과 화면은 2부에서 한다. 그때 S15도 닫힌다.

DB 변경 없음(`syllabi`·`syllabus_items`는 ERD v0.7부터 있었다).

## 정한 것

1. **글자가 있는 PDF만 받는다**(10쪽까지). 포털 계획서를 "PDF로 저장"하면 글자가 그대로 들어온다. 사진을 PDF로 감싼 파일은 모델에 보낼 것이 없어서 업로드에서 막고, 무엇을 하면 되는지 알려 준다.
2. **모델은 한 번만 부른다.** 계획서는 글자가 다 있어서 더 읽을 첨부가 없다. 요건 추출과 같은 모델(`extraction_model`)을 쓴다.
3. **모델이 낸 일정은 코드가 검사한다.** 종류는 ERD enum 안의 것만, 날짜는 **학기 범위 안**의 날만, 근거 줄이 **모델이 본 글자에 실제로 있는 것만**, 그리고 그 **근거 줄에 날짜나 주차가 보이는 것만** 저장한다. 지어낸 시험 날짜가 플래너·캘린더에 들어가면 학생이 엉뚱한 날에 시험을 준비한다.
4. **일정을 하나도 못 찾으면 먼저 올린 계획서를 그대로 둔다.** `replace`로 올렸더라도다 — 확인해 둔 일정으로 만든 할 일·캘린더 기록까지 함께 사라지기 때문이다. 처음 올리는 계획서는 0개여도 저장한다(시험 일정이 안 적힌 계획서도 있다).
5. **연도 없는 날짜는 그 과목의 학기로 읽는다.** 계획서에는 "8주차 10/20"처럼 연도가 없다. 과목명(`202620HY23525_…`)에서 2026-2를 읽어 **9월 1일 시작**으로 센다. 과목을 붙이지 않았으면 올린 날이 든 학기로 본다(한국 대학은 3월·9월에 시작한다).
6. **시각이 없으면 그날 09:00(KST)**. 계획서 상당수가 날짜만 적는다. 확인 화면에서 학생이 고친다.
7. **일반 강의 주차는 뽑지 않는다.** 시험·발표·과제 제출만이다 — 플래너가 수업 일정으로 가득 차면 쓸모가 없다.
8. **LMS를 연결하지 않아도 올릴 수 있다.** 과목 없이 저장한다(과목당 하나 제한도 걸리지 않는다). 연결한 학생은 과목에 붙고, 이미 계획서가 있으면 `409 SYLLABUS_EXISTS`에 `{"replace": true}`로 갈아 끼운다.
9. **계획서 본문은 기록에 남기지 않는다.** 실행 기록(`tool_calls.output`)에는 글자 수만 적는다. 남의 수업 자료를 우리 DB에 통째로 쌓아 둘 이유가 없다.
10. **뽑은 일정은 모두 확정 전이다.** 확인 화면에서 고른 것만 플래너·캘린더로 간다(2부).

## 합친 뒤 확인

```bash
# 1) 계획서 PDF 올리기(포털 계획서를 브라우저에서 PDF로 저장한 파일)
curl -X POST localhost:8000/api/v1/files -H "Authorization: Bearer $TOKEN" \
  -F "kind=syllabus" -F "file=@계획서.pdf"
# → 201 {"file_id":"...","kind":"syllabus","page_count":3}

# 2) 일정 뽑기(과목을 붙이면 그 학기로 날짜를 읽는다)
curl -X POST localhost:8000/api/v1/syllabi/extract -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' -d '{"file_id":"<uuid>","lms_course_id":"<uuid>"}'
# → 202 {"run_id":"...","status":"running"}

# 3) 결과 보기
curl localhost:8000/api/v1/runs/<run_id> -H "Authorization: Bearer $TOKEN"
# → steps: 계획서 글자 읽기 → 시험·발표 일정 저장
# → result.kind = syllabus_extract, items[].is_confirmed = false

# 4) 같은 과목에 또 올리면 409, replace로 갈아 끼운다
curl -i -X POST localhost:8000/api/v1/syllabi/extract -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' -d '{"file_id":"<uuid>","lms_course_id":"<uuid>"}'

# 5) 과목 상세의 "계획서" 탭에 그 일정이 보인다(확정 전 표시)
curl localhost:8000/api/v1/lms/courses/<course_uuid> -H "Authorization: Bearer $TOKEN"
```

### 검토에서 고친 것

검토를 한 번 돌렸다. "지어낸 일정을 막는다"는 약속이 생각보다 느슨했던 것이 가장 컸다.

| 지적 | 고친 것 |
| --- | --- |
| **근거 검사가 날짜를 묶지 않았다.** 근거 줄이 본문에 있기만 하면 통과였다 — 모델이 `evidence_text: "중간고사"`(본문에 있는 토막)만 주고 날짜를 **학기 안 아무 날**로 적으면 그대로 저장됐다 | 근거 줄에 **날짜나 주차가 보여야** 받는다(`10/20`·`10.20`·`10월 20일`·`2026-10-20`·`8주차`·`Week 8`). 프롬프트에도 같은 규칙을 적었다 |
| **일정 0개여도 기존 계획서를 지웠다.** `replace`는 먼저 지우고 넣는다. 모델이 아무것도 못 찾으면 **확인해 둔 시험 할 일·캘린더 기록까지** 함께 사라졌다(cascade) | 일정을 하나도 못 찾았고 그 과목에 이미 일정이 있으면 **덮어쓰지 않고** 실패한다("먼저 올린 계획서를 그대로 두었다"). 처음 올리는 계획서는 0개여도 저장한다 |
| **실패 문구가 준비하기 것으로 나갔다.** 코드를 남기지 못한 실패(저장 중 DB 오류 등)는 작업별 문구 표를 보는데 거기에 계획서가 없었다 → "준비 일정을 만들지 못했어요" | 계획서·포스터 문구를 표에 더했다(포스터도 같은 구멍이었다). 테스트로 못 박았다 |
| 모델에는 **40,000자까지** 보내는데 근거 대조는 뽑은 글자 **전체**로 했다 → 모델이 못 본 뒤쪽 글자가 근거로 통과할 수 있었다 | 대조도 모델이 본 글자로 한다 |
| 버린 일정을 로그에 남길 때 **계획서 본문 토막**이 함께 들어갔다(실행 기록에는 안 남기기로 한 것과 어긋난다) | 이유와 종류만 남긴다 |
| 학기 끝을 `2월 28일`로 고정해 **윤년 2월 29일** 일정이 버려졌다 | 2월 마지막 날로 센다 |
| 타임아웃·모델 오류·도구 안 부름·깨진 PDF 경로에 테스트가 없었다 | 다섯 가지를 더했다(각각 `LLM_TIMEOUT`·`LLM_ERROR`·`SYLLABUS_READ_FAILED`) |


## 남은 것

- **확정(`POST /syllabi/{id}/confirm`)과 화면이 2부다.** 고른 일정을 플래너 할 일·캘린더 일정으로 만들고(`syllabus_item_id`는 캘린더에서 아직 422다), 과목 상세의 "계획서 가져오기" 버튼과 확인 화면을 붙인다. **그때 S15가 닫힌다.**
- **주차에서 센 일정과 날짜가 적힌 일정을 구분하지 않는다.** 확인 화면(2부)에서 "날짜를 확인해 주세요" 같은 표시를 주고 싶으면 그 칸을 더해야 한다(명세·ERD 변경).
- **같은 버튼을 연타하면 실행과 모델 호출이 그만큼 생긴다.** 과목 계획서는 마지막 것이 이긴다. 명세가 `RATE_LIMITED`를 요구하지 않아 그대로 뒀다.
- **PDF 글자 뽑기는 같은 스레드에서 돈다**(기존 업로드·추출과 같은 방식). 20MB·10쪽 최악에서는 그동안 다른 요청이 기다린다. 쓰레드로 빼는 것은 포스터·첨부와 함께 한 번에 정리하는 게 맞다.
- **주차만 적힌 일정("8주차 중간고사")은 모델이 센다.** 프롬프트에 학기 시작일과 계산 방법을 주지만, 개강일이 해마다 며칠 다르고 휴일이 끼면 하루 이틀 어긋날 수 있다. 확인 화면에서 고치는 것을 전제로 둔다.
- **계획서가 한 과목에 하나라는 것은 과목을 붙였을 때만이다.** 과목 없이 올린 계획서는 여러 개 쌓일 수 있다(지우는 길은 아직 없다).
- `POST /materials`(강의자료 요약, P1)는 그대로다. 업로드의 `lecture_material` 종류도 그때 연다.
- 실제 포털 계획서 PDF로는 아직 못 돌려 봤다(샌드박스에 그 파일이 없다). **합친 뒤 네 계획서 한 장으로 한 번 돌려 보고**, 날짜가 이상하면 그 PDF의 글자 모양을 알려 줘 — 프롬프트를 거기 맞춘다.

#### `api/app/uploads/__init__.py`

```python
"""업로드 파일 검사 (F-13, API 명세 6장).

파일 이름과 브라우저가 보낸 Content-Type은 믿지 않고 앞부분 바이트로 형식을 가린다. 확장자만 .jpg로
바꾼 실행 파일이 저장소에 들어가지 않게 하려는 것이다.

포스터는 JPG·PNG·WEBP 사진과 2쪽 이하 PDF를 받는다. HEIC(아이폰 기본 사진 형식)는 아직 못 읽는다.
아이폰에서 고른 사진은 그대로 HEIC로 올라오기 쉬워서, "형식이 아니에요" 대신 무엇을 하면 되는지
알려 준다.

20MB까지만 메모리로 올린다. FastAPI는 핸들러가 돌기 전에 몸통을 모두 받아 임시 파일에 쓰므로
(1MB가 넘으면 디스크), 여기서 끊는 것은 큰 파일을 통째로 메모리에 올리지 않기 위한 것이다. 아주 큰
몸통 자체를 거절하는 것은 앞단(프록시·ASGI)의 몫이다.
"""

import hashlib
import io
from dataclasses import dataclass
from datetime import datetime, timedelta
from typing import Protocol

from pypdf import PdfReader
from pypdf.errors import PdfReadError

from app.eligibility.dates import KST
from app.errors import ApiError

MAX_BYTES = 20 * 1024 * 1024
MAX_MB = MAX_BYTES // (1024 * 1024)
POSTER_MAX_PAGES = 2
SYLLABUS_MAX_PAGES = 10  # 강의계획서는 보통 2~6쪽이다(녹화한 포털 계획서 기준)
PDF_TEXT_MAX_CHARS = 60_000  # 뽑은 글자 상한. 계획서 10쪽이면 2만 자 안쪽이다
DAILY_UPLOAD_LIMIT = 20  # 사용자당 KST 하루 (API 명세 14장, 10/15 확정)
_CHUNK_BYTES = 1024 * 1024
_NAME_MAX = 200


@dataclass(frozen=True)
class FileType:
    mime: str
    extension: str


JPEG = FileType("image/jpeg", "jpg")
PNG = FileType("image/png", "png")
WEBP = FileType("image/webp", "webp")
PDF = FileType("application/pdf", "pdf")
HEIC = FileType("image/heic", "heic")

# ISO 기반 미디어 파일(ftyp 박스)의 HEIF 계열 브랜드. 아이폰 사진은 heic·heix·mif1로 온다
_HEIF_BRANDS = frozenset({b"heic", b"heix", b"heim", b"heis", b"hevc", b"hevx", b"mif1", b"msf1"})


def sniff(data: bytes) -> FileType | None:
    """앞부분 바이트로 가린 형식. 아는 형식이 아니면 None이다."""
    if data.startswith(b"\xff\xd8\xff"):
        return JPEG
    if data.startswith(b"\x89PNG\r\n\x1a\n"):
        return PNG
    if data[:4] == b"RIFF" and data[8:12] == b"WEBP":
        return WEBP
    if data.startswith(b"%PDF-"):
        return PDF
    if data[4:8] == b"ftyp" and data[8:12] in _HEIF_BRANDS:
        return HEIC
    return None


class Chunked(Protocol):
    """UploadFile처럼 조금씩 읽을 수 있는 것."""

    async def read(self, size: int = -1, /) -> bytes: ...


async def read_upload(source: Chunked) -> bytes:
    """20MB까지만 모은다. 넘으면 나머지를 읽지 않고 413이다."""
    chunks: list[bytes] = []
    total = 0
    while chunk := await source.read(_CHUNK_BYTES):
        total += len(chunk)
        if total > MAX_BYTES:
            raise ApiError(
                413,
                "FILE_TOO_LARGE",
                f"파일이 {MAX_MB}MB를 넘어요. 더 작은 파일을 올려 주세요.",
            )
        chunks.append(chunk)
    return b"".join(chunks)


@dataclass(frozen=True)
class Inspected:
    type: FileType
    page_count: int | None  # PDF만 센다
    sha256: str


def inspect_poster(data: bytes) -> Inspected:
    """포스터로 받을 수 있는 파일인지 보고 형식·쪽수·해시를 돌려준다."""
    found = sniff(data)
    if found is HEIC:
        raise ApiError(
            400,
            "UNSUPPORTED_FILE_TYPE",
            "아이폰 사진 형식(HEIC)은 아직 올릴 수 없어요. 사진을 JPG로 바꿔서 올려 주세요.",
        )
    if found is None:
        raise ApiError(
            400,
            "UNSUPPORTED_FILE_TYPE",
            "JPG·PNG·WEBP 사진이나 2쪽 이하 PDF만 올릴 수 있어요.",
        )
    pages = _pdf_pages(data) if found is PDF else None
    if pages is not None and pages > POSTER_MAX_PAGES:
        raise ApiError(
            413,
            "PAGE_LIMIT_EXCEEDED",
            f"PDF는 {POSTER_MAX_PAGES}쪽까지만 올릴 수 있어요. 포스터가 있는 쪽만 남겨서 올려 주세요.",
        )
    return Inspected(found, pages, hashlib.sha256(data).hexdigest())


def inspect_syllabus(data: bytes) -> Inspected:
    """강의계획서로 받을 수 있는 파일인지 본다. **텍스트가 있는 PDF만** 받는다(명세 6장).

    포털 계획서를 브라우저에서 "PDF로 저장"해 올리는 길이라 스캔본은 거의 없다. 그래도 사진을
    PDF로 감싼 파일이 올 수 있어서, 글자를 못 뽑으면 여기서 막는다 — 모델에 보내도 읽을 것이 없다.
    """
    found = sniff(data)
    if found is not PDF:
        raise ApiError(
            400,
            "UNSUPPORTED_FILE_TYPE",
            "강의계획서는 PDF만 올릴 수 있어요. 포털 계획서를 "
            f"PDF로 저장해서 올려 주세요({SYLLABUS_MAX_PAGES}쪽까지).",
        )
    pages = _pdf_pages(data)
    if pages > SYLLABUS_MAX_PAGES:
        raise ApiError(
            413,
            "PAGE_LIMIT_EXCEEDED",
            f"PDF는 {SYLLABUS_MAX_PAGES}쪽까지만 올릴 수 있어요. 계획서 쪽만 남겨서 올려 주세요.",
        )
    if not pdf_text(data).strip():
        raise ApiError(
            400,
            "UNSUPPORTED_FILE_TYPE",
            "PDF에서 글자를 찾지 못했어요. 사진을 PDF로 만든 파일은 읽을 수 없어요."
            " 포털 계획서를 브라우저에서 PDF로 저장해 올려 주세요.",
        )
    return Inspected(found, pages, hashlib.sha256(data).hexdigest())


def pdf_text(data: bytes, *, max_chars: int = PDF_TEXT_MAX_CHARS) -> str:
    """PDF에서 뽑은 글자(쪽마다 줄바꿈으로 잇는다). 읽지 못하면 빈 글자다.

    상한을 두는 것은 모델 입력을 재는 쪽이 아니라, 깨진 PDF가 메모리를 다 먹지 않게 하려는 것이다.
    """
    try:
        reader = PdfReader(io.BytesIO(data))
    except (PdfReadError, ValueError, OSError):
        return ""
    found: list[str] = []
    total = 0
    for page in reader.pages:
        try:
            text = page.extract_text() or ""
        except Exception:  # pypdf가 쪽 하나에서 터져도 나머지는 읽는다
            continue
        found.append(text)
        total += len(text)
        if total >= max_chars:
            break
    return "\n".join(found)[:max_chars]


def _pdf_pages(data: bytes) -> int:
    try:
        return len(PdfReader(io.BytesIO(data)).pages)
    except (PdfReadError, ValueError, OSError) as exc:
        # 앞 5바이트는 %PDF-인데 안이 깨졌다. 쪽수를 모르면 2쪽 제한을 지킬 수 없어 받지 않는다
        raise ApiError(
            400,
            "UNSUPPORTED_FILE_TYPE",
            "PDF를 읽지 못했어요. 사진으로 찍어서 올려 주세요.",
        ) from exc


def clean_name(name: str | None) -> str | None:
    """올린 파일 이름. 경로와 줄바꿈을 떼고 길이를 줄인다(그대로 쓰면 저장소 경로가 흔들린다)."""
    if not name:
        return None
    base = name.replace("\\", "/").rsplit("/", 1)[-1]
    base = "".join(ch for ch in base if ch.isprintable()).strip()
    return base[:_NAME_MAX] or None


def storage_path(user_id: str, kind: str, file_id: str, extension: str) -> str:
    """버킷 안 경로. ERD 8장대로 사용자 폴더(`<user_id>/…`)로 시작한다."""
    return f"{user_id}/{kind}/{file_id}.{extension}"


def day_start(now: datetime) -> datetime:
    """KST 오늘 0시. 하루 한도를 세는 기준이다."""
    return now.astimezone(KST).replace(hour=0, minute=0, second=0, microsecond=0)


def day_reset(now: datetime) -> datetime:
    """한도가 풀리는 시각(KST 내일 0시). 429의 details.reset_at으로 준다."""
    return day_start(now) + timedelta(days=1)
```

```python
"""파일 업로드 (F-13, API 명세 6장).

포스터(F-16)와 강의계획서(F-14)를 받는다. 강의자료(F-15)는 그 기능과 함께 연다.
받는 것은 종류마다 다르다 — 포스터는 사진과 2쪽 이하 PDF, 계획서는 **글자가 있는 PDF**다.

차례: 20MB까지 읽기 → 바이트로 형식·쪽수 보기 → 같은 파일인지 보기 → 하루 한도 보기 →
저장소에 올리기 → 기록 남기기.

올리기를 기록보다 먼저 한다. 거꾸로 하면 기록을 남긴 뒤 올리다 끊겼을 때, 다음에 같은 파일을 올려도
"이미 있어요"라며 저장소에 없는 파일을 가리킨다. 먼저 올리면 끊겨도 쓰이지 않는 파일만 남는다
(비공개 버킷이라 아무도 보지 못하고, 다시 올리면 제대로 기록된다).

DB 연결은 읽을 때와 쓸 때만 빌린다. 저장소에 올리는 동안 쥐고 있으면 저장소가 느릴 때 요청 풀이
묶여 다른 화면까지 멈춘다. 두 번으로 나눠도 중복은 부분 유니크가 막는다.
"""

import logging
from typing import Annotated
from uuid import uuid4

from fastapi import APIRouter, File, Form, Response, UploadFile

from app.auth import CurrentUserDep
from app.clock import NowDep
from app.errors import ApiError
from app.repositories.files import FileReposDep, StoredFile
from app.schemas.files import FileUploadResult
from app.uploads import (
    DAILY_UPLOAD_LIMIT,
    clean_name,
    day_reset,
    day_start,
    inspect_poster,
    inspect_syllabus,
    read_upload,
    storage_path,
)
from app.uploads.storage import StorageDep, StorageError, SupabaseStorage

logger = logging.getLogger(__name__)
router = APIRouter(prefix="/files", tags=["업로드"])

POSTER = "poster"
SYLLABUS = "syllabus"
# 종류마다 받는 파일이 다르다. 여기 없는 종류(lecture_material)는 그 기능과 함께 연다
INSPECT = {POSTER: inspect_poster, SYLLABUS: inspect_syllabus}


@router.post(
    "",
    status_code=201,
    response_model=FileUploadResult,
    responses={200: {"model": FileUploadResult, "description": "이미 올린 파일(reused)"}},
)
async def upload_file(
    user: CurrentUserDep,
    repos: FileReposDep,
    storage: StorageDep,
    now: NowDep,
    response: Response,
    file: Annotated[UploadFile, File()],
    kind: Annotated[str, Form()],
) -> FileUploadResult:
    """파일을 저장소에 올리고 `file_id`를 준다. 같은 파일을 다시 올리면 200과 기존 id다."""
    inspect = INSPECT.get(kind)
    if inspect is None:
        raise ApiError(
            422,
            "VALIDATION_FAILED",
            "입력값을 확인해 주세요.",
            {"fields": {"kind": "지금은 포스터와 강의계획서만 올릴 수 있어요."}},
        )
    data = await read_upload(file)
    found = inspect(data)

    async with repos() as repo:
        existing = await repo.existing(user.id, kind=kind, sha256=found.sha256)
        # 이미 올린 파일은 새로 저장하지 않으므로 하루 한도를 보지 않는다
        used = None if existing else await repo.uploads_since(user.id, day_start(now))
    if existing is not None:
        return _reused(existing, response)
    if used is not None and used >= DAILY_UPLOAD_LIMIT:
        raise ApiError(
            429,
            "DAILY_UPLOAD_LIMIT",
            f"오늘 올릴 수 있는 {DAILY_UPLOAD_LIMIT}개를 다 썼어요. 내일 다시 올려 주세요.",
            {"reset_at": day_reset(now).isoformat()},
        )

    file_id = str(uuid4())
    path = storage_path(user.id, kind, file_id, found.type.extension)
    try:
        await storage.upload(path, data, found.type.mime)
    except StorageError as exc:
        logger.warning("파일 저장소 업로드 실패: %s", exc)
        raise ApiError(
            502, "STORAGE_API_ERROR", "파일을 저장하지 못했어요. 잠시 후 다시 시도해 주세요."
        ) from exc

    async with repos() as repo:
        saved = await repo.add(
            user.id,
            file_id=file_id,
            kind=kind,
            path=path,
            mime_type=found.type.mime,
            size_bytes=len(data),
            page_count=found.page_count,
            sha256=found.sha256,
            original_name=clean_name(file.filename),
        )
        if saved is None:  # 올리는 사이에 같은 파일이 들어왔다. 방금 올린 것은 지운다
            winner = await repo.existing(user.id, kind=kind, sha256=found.sha256)
            assert winner is not None  # 충돌이 났다는 것은 그 행이 있다는 뜻이다
    if saved is None:
        await _discard(storage, path)
        return _reused(winner, response)
    return FileUploadResult(file_id=file_id, kind=kind, page_count=found.page_count)


def _reused(found: StoredFile, response: Response) -> FileUploadResult:
    response.status_code = 200
    return FileUploadResult(
        file_id=found.id,
        kind=found.kind,
        page_count=found.page_count,
        duplicate_of=found.id,
        reused=True,
    )


async def _discard(storage: SupabaseStorage, path: str) -> None:
    """되돌리기용 삭제. 여기서 실패해도 요청은 성공이라 기록만 남긴다."""
    try:
        await storage.remove(path)
    except StorageError as exc:
        logger.warning("쓰이지 않는 업로드 파일을 지우지 못했어요: %s", exc)
```

```python
"""과목명 파싱과 포털 계획서 링크 (F-14·F-50).

LearningX 과목명은 `202620HY23525_데이터베이스` 꼴이다(2026-10-16 녹화, 8과목 모두 같았다).
앞에서 연도(2026)·학기 코드(20)·과목번호(23525)를 떼어 포털 계획서 링크를 만들고, `_` 뒤를 화면 이름으로 쓴다.
꼴이 다르면 이름 전체를 화면 이름으로 쓰고 링크를 만들지 않는다 — 없는 번호로 포털을 열면 빈 창이 뜬다.

포털에는 서버가 요청하지 않는다(robots.txt). 링크는 사용자 브라우저에서만 연다(API 명세 8장).
"""

import re
from dataclasses import dataclass
from datetime import date
from typing import Any

BIGINT_MAX = 2**63 - 1  # Canvas 번호는 bigint 칸에 들어가야 한다


def is_canvas_id(value: Any) -> bool:
    """Canvas 번호로 쓸 수 있는 값인지. bool과 bigint를 넘는 수는 거른다(그대로 넣으면 DB가 터진다)."""
    return isinstance(value, int) and not isinstance(value, bool) and 0 < value <= BIGINT_MAX


# 명세 8장의 링크 그대로. 사용자 브라우저에서 열면 그 과목 계획서 팝업이 뜬다
PORTAL_SYLLABUS_URL = (
    "https://portal.hanyang.ac.kr/openPop.do?header=hidden"
    "&url=/haksa/SughAct/findSuupPlanDocHyIn.do&flag=BB"
    "&year={year}&term={term}&suup={course_no}&language=ko"
)
# 학기 코드 → 표시. 1·2학기만 녹화로 확인했고 계절학기는 한양대 코드 규칙을 따랐다
TERM_NAMES: dict[int, str] = {10: "1", 11: "여름", 20: "2", 21: "겨울"}
# 학기 코드 → 시작 (월, 일). 계획서의 "8주차"·"10/20"을 읽는 기준이다(F-14).
# 개강일은 해마다 며칠 다르지만, 주차·연도를 가리는 데는 이 정도로 충분하다
TERM_START: dict[int, tuple[int, int]] = {10: (3, 1), 11: (6, 20), 20: (9, 1), 21: (12, 20)}
_COURSE_NAME = re.compile(r"^(?P<year>\d{4})(?P<term>\d{2})HY(?P<no>\d{3,6})_(?P<short>.+)$")


@dataclass(frozen=True)
class CourseName:
    """과목명에서 뽑은 값. 꼴이 다르면 short_name만 있고 나머지는 None이다."""

    short_name: str
    portal_year: int | None = None
    portal_term: int | None = None
    portal_course_no: str | None = None

    @property
    def syllabus_url(self) -> str | None:
        """포털 계획서 링크. 번호를 못 뽑았으면 없다."""
        if self.portal_year is None or self.portal_term is None or not self.portal_course_no:
            return None
        return PORTAL_SYLLABUS_URL.format(
            year=self.portal_year, term=self.portal_term, course_no=self.portal_course_no
        )

    @property
    def semester_start(self) -> date | None:
        """그 학기가 시작하는 날. 과목명에서 연도·학기를 못 뽑았으면 없다(F-14)."""
        if self.portal_year is None or self.portal_term not in TERM_START:
            return None
        month, day = TERM_START[self.portal_term]
        return date(self.portal_year, month, day)

    def term(self, fallback: str | None = None) -> str | None:
        """학기 표시(`2026-2`). 꼴이 다르면 LearningX가 준 학기 이름을 쓴다."""
        if self.portal_year is None or self.portal_term is None:
            return fallback
        name = TERM_NAMES.get(self.portal_term)
        return f"{self.portal_year}-{name}" if name else fallback


def course_name(name: str) -> CourseName:
    found = _COURSE_NAME.match(name.strip())
    if not found:
        return CourseName(short_name=name.strip())
    return CourseName(
        short_name=found["short"].strip(),
        portal_year=int(found["year"]),
        portal_term=int(found["term"]),
        portal_course_no=found["no"],
    )
```

#### `api/app/syllabi/extract.py`

```python
"""계획서 글자 → 일정 목록 (F-14).

모델을 **한 번만** 부른다. 계획서는 글자가 다 있어서 더 읽을 첨부가 없다.

받은 값은 믿지 않고 코드가 검사한다 — 종류는 ERD enum 안의 것만, 날짜는 학기 범위 안의 날만,
근거 줄은 계획서 글자에 실제로 있는 것만 받는다. 모델이 지어낸 일정이 플래너·캘린더에 들어가면
학생이 엉뚱한 날에 시험을 준비한다.
"""

import asyncio
import logging
import re
from dataclasses import dataclass
from datetime import date, datetime, time, timedelta
from typing import Any

from app.eligibility import KST
from app.llm import LlmClient, LlmReply, ToolCall, UserTurn
from app.schemas.syllabi import EXTRACT_TOOL, SyllabusItemType
from app.syllabi.prompt import EXTRACT_SPEC, MAX_ITEMS, TYPE_LABELS, first_message, system_prompt

logger = logging.getLogger(__name__)
TIMEOUT_SECONDS = 50.0  # 웹이 실행을 확인하는 60초 안에 실패를 알려 준다
MAX_OUTPUT_TOKENS = 8_000
MAX_INPUT_CHARS = 40_000  # 계획서 10쪽이면 2만 자 안쪽이다. 넘치면 앞에서 자른다
DEFAULT_TIME = time(9, 0)  # 시각이 적혀 있지 않은 일정은 그날 아침 9시로 둔다
_TITLE_MAX = 200


class SyllabusError(Exception):
    """계획서에서 일정을 읽지 못했다. 학생에게 그대로 보여 줄 문구다."""


@dataclass(frozen=True)
class DraftItem:
    item_type: SyllabusItemType
    title: str
    starts_at: datetime


@dataclass(frozen=True)
class Extracted:
    course_name: str | None
    semester: str | None
    items: list[DraftItem]
    reply: LlmReply
    call: ToolCall


async def extract(
    llm: LlmClient,
    *,
    model: str,
    text: str,
    semester_start: date,
    semester_end: date,
    uploaded_on: date,
) -> Extracted:
    """모델 한 번 호출. 읽지 못하면 SyllabusError다."""
    try:
        async with asyncio.timeout(TIMEOUT_SECONDS):
            reply = await llm.generate(
                model=model,
                system=system_prompt(),
                turns=[
                    UserTurn(
                        text=first_message(
                            text[:MAX_INPUT_CHARS],
                            semester_start=semester_start,
                            semester_end=semester_end,
                            uploaded_on=uploaded_on,
                        )
                    )
                ],
                tools=(EXTRACT_SPEC,),
                force_tool=EXTRACT_TOOL,
                max_output_tokens=MAX_OUTPUT_TOKENS,
            )
    except TimeoutError as exc:
        raise TimeoutError("계획서를 읽는 데 너무 오래 걸렸어요.") from exc
    call = next((one for one in reply.turn.tool_calls if one.name == EXTRACT_TOOL), None)
    if call is None:
        raise SyllabusError(
            f"계획서에서 일정을 읽지 못했어요({reply.finish_reason or '이유 없음'})."
        )
    items = extracted_items(
        call.args,
        # 대조는 **모델이 본 글자**로 한다. 뒤를 잘라 보냈으면 그 뒤 글자는 근거가 될 수 없다
        text=text[:MAX_INPUT_CHARS],
        semester_start=semester_start,
        semester_end=semester_end,
    )
    return Extracted(
        course_name=_text(call.args.get("course_name"), 100),
        semester=_text(call.args.get("semester"), 20),
        items=items,
        reply=reply,
        call=call,
    )


def extracted_items(
    args: dict[str, Any], *, text: str, semester_start: date, semester_end: date
) -> list[DraftItem]:
    """모델이 낸 일정 중 **쓸 수 있는 것만** 고른다. 버린 것은 로그에만 남긴다."""
    raw = args.get("items")
    if not isinstance(raw, list):
        return []
    found: list[DraftItem] = []
    seen: set[tuple[str, datetime]] = set()
    for one in raw[: MAX_ITEMS * 2]:  # 넘치게 온 것도 걸러 보고 상한에서 자른다
        item = _item(one, text=text, semester_start=semester_start, semester_end=semester_end)
        if item is None:
            continue
        key = (item.title, item.starts_at)
        if key in seen:  # 같은 일정을 두 번 적었다
            continue
        seen.add(key)
        found.append(item)
        if len(found) >= MAX_ITEMS:
            break
    return found


def _item(raw: Any, *, text: str, semester_start: date, semester_end: date) -> DraftItem | None:
    if not isinstance(raw, dict):
        return None
    kind = raw.get("item_type")
    title = _text(raw.get("title"), _TITLE_MAX)
    if kind not in TYPE_LABELS or title is None:
        return _skip("종류나 이름이 없어요", raw)
    evidence = _text(raw.get("evidence_text"), 500)
    if evidence is None or not _in_text(evidence, text):
        # 계획서에 없는 줄을 근거로 댔다 = 지어낸 일정이다
        return _skip("근거 줄이 계획서에 없어요", raw)
    day = _date(raw.get("date"))
    if day is None or not semester_start <= day <= semester_end:
        return _skip("날짜가 학기 범위 밖이에요", raw)
    if not _dated(evidence, day):
        # 이름만 옮겨 적고 날짜는 아무 날로 적는 것을 막는다. 근거 줄에 날짜나 주차가 보여야 한다
        return _skip("근거 줄에 날짜도 주차도 없어요", raw)
    at = _time(raw.get("time")) or DEFAULT_TIME
    return DraftItem(kind, title, datetime.combine(day, at, tzinfo=KST))


def _skip(why: str, raw: Any) -> None:
    """버린 이유만 남긴다. 계획서 본문은 로그에도 남기지 않는다(실행 기록과 같은 기준)."""
    kind = raw.get("item_type") if isinstance(raw, dict) else None
    logger.info("계획서 일정 하나를 버렸어요: %s (종류 %s)", why, kind)
    return None


_WEEK = re.compile(r"(\d{1,2})\s*(?:주\s*차|주차|週|weeks?|wk)", re.IGNORECASE)


def _dated(evidence: str, day: date) -> bool:
    """근거 줄이 그 날짜를 뒷받침하는지.

    계획서는 "8주차 10/20 중간고사"처럼 날짜나 주차로 날을 가리킨다. 둘 다 없는 줄(예: "중간고사"만)
    은 날짜의 근거가 되지 못한다 — 모델이 이름만 옮기고 날짜를 아무 날로 적을 수 있다.
    """
    squeezed = _squeeze(evidence)
    month, date_no = day.month, day.day
    shapes = (
        f"{month}/{date_no}",
        f"{month:02d}/{date_no:02d}",
        f"{month}/{date_no:02d}",
        f"{month:02d}/{date_no}",
        f"{month}.{date_no}",
        f"{month:02d}.{date_no:02d}",
        f"{month}-{date_no}",
        f"{month:02d}-{date_no:02d}",
        f"{month}월{date_no}일",
        f"{day.isoformat()}",
    )
    if any(shape in squeezed for shape in shapes):
        return True
    return bool(_WEEK.search(evidence))  # 주차만 적힌 줄은 모델이 학기 시작일로 센다


def _in_text(evidence: str, text: str) -> bool:
    """근거 줄이 계획서 글자에 있는지. 공백 차이는 무시한다(PDF는 줄바꿈이 제각각이다)."""
    return _squeeze(evidence) in _squeeze(text)


def _squeeze(value: str) -> str:
    return "".join(value.split())


def _text(value: Any, limit: int) -> str | None:
    if not isinstance(value, str) or not value.strip():
        return None
    return value.strip()[:limit]


def _date(value: Any) -> date | None:
    if not isinstance(value, str):
        return None
    try:
        return date.fromisoformat(value.strip()[:10])
    except ValueError:
        return None


def _time(value: Any) -> time | None:
    if not isinstance(value, str) or not value.strip():
        return None
    try:
        return time.fromisoformat(value.strip()[:5])
    except ValueError:
        return None


def semester_range(semester_start: date | None, uploaded_on: date) -> tuple[date, date]:
    """연도 없는 날짜를 읽을 기준 범위.

    LMS 과목이 있으면 그 과목의 학기 시작일을 쓴다. 없으면 올린 날이 든 학기를 쓴다 —
    한국 대학은 3월·9월에 시작하므로 그 전후로 끊는다.
    """
    if semester_start is not None:
        return semester_start, semester_start + timedelta(days=150)
    year = uploaded_on.year
    if uploaded_on.month <= 2:  # 1~2월은 지난 2학기의 끝자락이다
        return date(year - 1, 9, 1), _last_of_february(year)
    if uploaded_on.month <= 8:
        return date(year, 3, 1), date(year, 8, 31)
    return date(year, 9, 1), _last_of_february(year + 1)


def _last_of_february(year: int) -> date:
    """2월 마지막 날. 윤년이면 29일이다(그날 일정을 버리지 않게)."""
    return date(year, 3, 1) - timedelta(days=1)
```

#### `api/app/syllabi/service.py`

```python
"""계획서 추출 실행 (F-14, API 명세 8장 `POST /syllabi/extract`).

202와 run_id를 먼저 주고 뒤에서 돈다(포스터 추출과 같은 방식). 일은 요청과 따로 돌며 자기 연결을 연다.

차례: 저장소에서 PDF 받기 → 글자 뽑기 → 모델 한 번 → 받은 일정 검사 → 계획서·일정 저장.
모델을 기다리는 동안 DB 연결(요청 풀)을 쥐지 않는다.

실패 이유는 ApiError로 남겨 학생에게 그대로 보인다. 글자를 못 읽은 것(SYLLABUS_READ_FAILED)은
다른 PDF로 다시 올리면 되는 일이고, LLM_TIMEOUT·STORAGE_API_ERROR는 잠시 뒤 다시 누르면 되는 일이다.
"""

import logging
from collections.abc import Callable
from contextlib import AbstractAsyncContextManager
from dataclasses import dataclass
from datetime import date, datetime
from typing import Annotated

from fastapi import Depends, Request
from psycopg import AsyncConnection

from app.agent_log import AgentRun, ToolCall, abandon_run, agent_run, start_run
from app.background import RunnerDep, TaskRunner
from app.config import Settings, get_settings
from app.errors import ApiError
from app.llm import LlmClient
from app.llm.deps import LlmDep
from app.repositories.syllabi import SavedSyllabus, SyllabusFile, SyllabusRepository
from app.schemas.syllabi import READ_TOOL, SAVE_TOOL
from app.syllabi.extract import Extracted, SyllabusError, extract, semester_range
from app.uploads import pdf_text
from app.uploads.storage import StorageDep, StorageError, SupabaseStorage

logger = logging.getLogger(__name__)
Connect = Callable[[], AbstractAsyncContextManager[AsyncConnection]]
TRIGGER = "syllabus_upload"
RETRY_HINT = "포털 계획서를 브라우저에서 PDF로 저장해 올려 주세요."
NO_TEXT = "계획서에서 글자를 찾지 못했어요."
SLOW = "계획서를 읽는 데 너무 오래 걸렸어요. 잠시 후 다시 눌러 주세요."
STORAGE_FAILED = "올린 계획서를 불러오지 못했어요. 잠시 후 다시 눌러 주세요."
MODEL_FAILED = "계획서를 읽지 못했어요. 잠시 후 다시 눌러 주세요."
STOPPED = "계획서를 읽다 멈췄어요. 다시 눌러 주세요."
KEPT_OLD = (
    "이 PDF에서는 일정을 찾지 못했어요. 먼저 올린 계획서를 그대로 두었으니, 다른 PDF로 올려 주세요."
)


@dataclass(frozen=True)
class SyllabusJob:
    run_id: str
    user_id: str
    file: SyllabusFile
    course_id: str | None
    course_short_name: str | None  # 과목을 붙였으면 그 이름(모델이 못 읽었을 때 쓴다)
    semester_start: date | None  # 과목명에서 센 학기 시작일(연도 없는 날짜의 기준)
    today: date  # KST
    now: datetime


class SyllabusService:
    def __init__(
        self,
        *,
        transaction: Connect,
        log_connection: Connect,
        storage: SupabaseStorage,
        llm: LlmClient | None,
        model: str,
        runner: TaskRunner,
    ) -> None:
        self.transaction = transaction
        self.log_connection = log_connection
        self.storage = storage
        self.llm = llm
        self.model = model
        self.runner = runner

    def repo(self, conn: AsyncConnection) -> SyllabusRepository:
        return SyllabusRepository(conn)

    async def begin(self, job_without_run: "SyllabusJob") -> str:
        """실행 행을 만들고 일을 띄운다. run_id를 준다."""
        run_id = await start_run(
            self.log_connection, trigger=TRIGGER, user_id=job_without_run.user_id
        )
        job = SyllabusJob(**{**job_without_run.__dict__, "run_id": run_id})
        work = self.execute(job)
        try:
            await self.runner.start(work)
        except Exception:
            work.close()
            await self._close(run_id)
            raise
        return run_id

    async def execute(self, job: SyllabusJob) -> None:
        try:
            async with agent_run(
                self.log_connection, trigger=TRIGGER, user_id=job.user_id, run_id=job.run_id
            ) as run:
                text = await self._text(run, job)
                async with run.tool(SAVE_TOOL, {"file_id": job.file.id}) as call:
                    extracted = await self._read(run, call, job, text)
                    saved = await self._save(job, extracted)
                    # `GET /runs/{id}`가 이 출력으로 결과를 만든다(repositories/runs.py)
                    call.output = {
                        "syllabus_id": saved.id,
                        "course_name": saved.course_name,
                        "items": [one.model_dump(mode="json") for one in saved.items],
                    }
        except Exception:
            logger.exception("계획서 추출 실행 실패: run %s", job.run_id)
            await self._close(job.run_id)

    async def _text(self, run: AgentRun, job: SyllabusJob) -> str:
        """저장소에서 PDF를 받아 글자를 뽑는다(모델에 넘길 것)."""
        async with run.tool(READ_TOOL, {"file_id": job.file.id}) as call:
            try:
                data = await self.storage.download(job.file.storage_path)
            except StorageError as exc:
                logger.warning("계획서를 저장소에서 받지 못했어요: %s", exc)
                raise ApiError(502, "STORAGE_API_ERROR", STORAGE_FAILED) from exc
            text = pdf_text(data)
            if not text.strip():
                raise ApiError(422, "SYLLABUS_READ_FAILED", f"{NO_TEXT} {RETRY_HINT}")
            call.output = {"chars": len(text)}  # 글자는 남기지 않는다(계획서 본문이다)
            return text

    async def _read(self, run: AgentRun, call: ToolCall, job: SyllabusJob, text: str) -> Extracted:
        """모델에 한 번 넘긴다. 기다리는 동안 DB 연결을 쥐지 않는다."""
        if self.llm is None:
            raise ApiError(502, "LLM_ERROR", MODEL_FAILED)
        start, end = semester_range(job.semester_start, job.today)
        try:
            extracted = await extract(
                self.llm,
                model=self.model,
                text=text,
                semester_start=start,
                semester_end=end,
                uploaded_on=job.today,
            )
        except SyllabusError as exc:
            raise ApiError(422, "SYLLABUS_READ_FAILED", f"{exc} {RETRY_HINT}") from exc
        except TimeoutError as exc:
            raise ApiError(502, "LLM_TIMEOUT", SLOW) from exc
        except Exception as exc:
            logger.warning("계획서 모델 호출 실패: %r", exc)
            raise ApiError(502, "LLM_ERROR", MODEL_FAILED) from exc
        await run.record_llm(
            provider=self.llm.provider,
            model=self.model,
            input_tokens=extracted.reply.usage.input_tokens,
            output_tokens=extracted.reply.usage.output_tokens,
            latency_ms=extracted.reply.latency_ms,
            tool_call=call,
        )
        return extracted

    async def _save(self, job: SyllabusJob, extracted: Extracted) -> SavedSyllabus:
        async with self.transaction() as conn:
            repo = self.repo(conn)
            if not extracted.items and job.course_id is not None:
                # 일정을 하나도 못 찾았다. 이미 확인해 둔 일정이 있으면 **덮어쓰지 않는다** —
                # 그 일정으로 만든 할 일·캘린더 기록까지 함께 지워진다(cascade)
                if await repo.existing_items(job.user_id, job.course_id) > 0:
                    raise ApiError(422, "SYLLABUS_READ_FAILED", KEPT_OLD)
            return await repo.save(
                job.user_id,
                file_id=job.file.id,
                course_id=job.course_id,
                # 모델이 교과목명을 못 읽으면 LMS 과목 이름을 쓴다(둘 다 없으면 비운다)
                course_name=extracted.course_name or job.course_short_name,
                semester=extracted.semester,
                items=extracted.items,
                now=job.now,
            )

    async def _close(self, run_id: str, message: str = STOPPED) -> None:
        """아직 running인 실행을 실패로 닫는다(이미 닫혔으면 그대로 둔다)."""
        try:
            await abandon_run(self.log_connection, run_id, ApiError(500, "INTERNAL_ERROR", message))
        except Exception:
            logger.exception("계획서 실행을 닫지 못했어요: run %s", run_id)


def get_syllabus_service(
    request: Request,
    llm: LlmDep,
    runner: RunnerDep,
    storage: StorageDep,
    settings: Annotated[Settings, Depends(get_settings)],
) -> SyllabusService:
    state = request.app.state
    pool, log_pool = getattr(state, "pool", None), getattr(state, "log_pool", None)
    if pool is None or log_pool is None:
        raise ApiError(503, "DB_UNAVAILABLE", "데이터베이스에 연결할 수 없어요.")
    return SyllabusService(
        transaction=pool.connection,
        log_connection=log_pool.connection,
        storage=storage,
        llm=llm,
        # 계획서는 글자만 읽는다. 공지 요건 추출과 같은 모델을 쓴다(단가표 키도 같다)
        model=settings.extraction_model,
        runner=runner,
    )


SyllabusServiceDep = Annotated[SyllabusService, Depends(get_syllabus_service)]
```

#### `api/app/repositories/syllabi.py`

```python
"""강의계획서 SQL (F-14, ERD `syllabi`·`syllabus_items`).

내 것만 읽고 쓴다. 과목당 계획서는 하나다(`syllabi (lms_course_id)` 부분 유니크) — 다시 올리면
`replace`로 갈아 끼운다(옛 일정과 그것으로 만든 할 일·캘린더 기록은 함께 지워진다, cascade).

과목을 붙이지 않은 계획서(LMS 미연결)는 여러 개 있을 수 있다. 그때는 과목 연결 없이 저장한다.
"""

import logging
from collections.abc import Sequence
from dataclasses import dataclass
from datetime import date, datetime
from typing import Annotated

from fastapi import Depends
from psycopg import AsyncConnection

from app.db import get_conn
from app.lms.parse import course_name as parse_course_name
from app.schemas.syllabi import SyllabusItemView
from app.syllabi.extract import DraftItem

logger = logging.getLogger(__name__)


@dataclass(frozen=True)
class SyllabusFile:
    id: str
    storage_path: str


@dataclass(frozen=True)
class SyllabusCourse:
    """계획서를 붙일 LMS 과목. 학기 시작일로 연도 없는 날짜를 읽는다."""

    id: str
    name: str
    short_name: str
    semester_start: date | None


@dataclass(frozen=True)
class SavedSyllabus:
    id: str
    course_name: str | None
    items: list[SyllabusItemView]


class SyllabusRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def syllabus_file(self, user_id: str, file_id: str) -> SyllabusFile | None:
        """내가 올린 계획서 PDF. 남의 파일·다른 종류는 None이다."""
        row = await (
            await self.conn.execute(
                "select id::text as id, storage_path from files"
                " where id = %s and user_id = %s and origin = 'upload'"
                "   and kind::text = 'syllabus'",
                (file_id, user_id),
            )
        ).fetchone()
        return None if row is None else SyllabusFile(row["id"], row["storage_path"])

    async def course(self, user_id: str, course_id: str) -> SyllabusCourse | None:
        """내 수강 과목. 수강을 뺀 과목과 남의 과목은 None이다."""
        row = await (
            await self.conn.execute(
                "select id::text as id, name from lms_courses"
                " where id = %s and user_id = %s and coalesce(is_active, true)",
                (course_id, user_id),
            )
        ).fetchone()
        if row is None:
            return None
        # 학기 시작일은 과목명에서 센다(`202620HY23525_…` → 2026-2 → 9/1). 개강일 칸은 없다
        parsed = parse_course_name(row["name"])
        return SyllabusCourse(
            id=row["id"],
            name=row["name"],
            short_name=parsed.short_name,
            semester_start=parsed.semester_start,
        )

    async def existing(self, user_id: str, course_id: str) -> str | None:
        """그 과목에 이미 붙은 계획서 id(없으면 None). 덮어쓸지 묻는 데 쓴다."""
        row = await (
            await self.conn.execute(
                "select id::text as id from syllabi where user_id = %s and lms_course_id = %s",
                (user_id, course_id),
            )
        ).fetchone()
        return None if row is None else row["id"]

    async def existing_items(self, user_id: str, course_id: str) -> int:
        """그 과목 계획서에 이미 들어 있는 일정 수. 빈 결과로 덮어쓰지 않으려고 센다."""
        row = await (
            await self.conn.execute(
                "select count(i.id) as count from syllabi s"
                " left join syllabus_items i on i.syllabus_id = s.id"
                " where s.user_id = %s and s.lms_course_id = %s",
                (user_id, course_id),
            )
        ).fetchone()
        return int(row["count"]) if row else 0

    async def save(
        self,
        user_id: str,
        *,
        file_id: str,
        course_id: str | None,
        course_name: str | None,
        semester: str | None,
        items: Sequence[DraftItem],
        now: datetime,
    ) -> SavedSyllabus:
        """계획서와 일정을 저장한다. 같은 과목에 있던 계획서는 지우고 새로 넣는다.

        일정은 **확정 전**(`is_confirmed` false)이다. 확인 화면에서 고른 것만 플래너·캘린더로 간다.
        """
        if course_id is not None:
            # 과목당 하나다. 옛 일정과 그것으로 만든 할 일·일정 기록도 cascade로 함께 지워진다
            await self.conn.execute(
                "delete from syllabi where user_id = %s and lms_course_id = %s",
                (user_id, course_id),
            )
        row = await (
            await self.conn.execute(
                "insert into syllabi (user_id, lms_course_id, file_id, course_name, semester,"
                " created_at) values (%(uid)s, %(course)s, %(file)s, %(name)s, %(semester)s,"
                " %(now)s) returning id::text as id",
                {
                    "uid": user_id,
                    "course": course_id,
                    "file": file_id,
                    "name": course_name,
                    "semester": semester,
                    "now": now,
                },
            )
        ).fetchone()
        assert row is not None
        syllabus_id = row["id"]
        saved: list[SyllabusItemView] = []
        for item in items:
            made = await (
                await self.conn.execute(
                    "insert into syllabus_items (syllabus_id, item_type, title, starts_at,"
                    " is_confirmed) values (%s, %s, %s, %s, false) returning id::text as id",
                    (syllabus_id, item.item_type, item.title, item.starts_at),
                )
            ).fetchone()
            assert made is not None
            saved.append(
                SyllabusItemView(
                    id=made["id"],
                    item_type=item.item_type,
                    title=item.title,
                    starts_at=item.starts_at,
                    is_confirmed=False,
                )
            )
        return SavedSyllabus(syllabus_id, course_name, saved)
```

```python
@dataclass(frozen=True)
class RunRow:
    id: str
    user_id: str | None
    trigger_type: str
    status: str
    started_at: datetime | None
    finished_at: datetime | None
    latency_ms: int | None

        if self.error_message and (match := _CODED.match(self.error_message)):

def _label(tool_name: str) -> str:
    """화면에 보이는 단계 이름. 작업마다 표가 다르고, 표에 없으면 도구 이름 그대로다."""
    return (
        PREPARE_LABELS.get(tool_name)
        or POSTER_LABELS.get(tool_name)
        or LMS_LABELS.get(tool_name)
        or SYLLABUS_LABELS.get(tool_name)
        or tool_name
    )


class RunRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def run(self, run_id: str) -> RunRow | None:
        row = await (
            await self.conn.execute(
                "select id, user_id, trigger_type, status::text as status, started_at, finished_at,"
                " latency_ms, error_message from agent_runs where id = %s",
                (run_id,),
            )
        ).fetchone()
        if row is None:
            return None
        return RunRow(
            id=str(row["id"]),
            user_id=str(row["user_id"]) if row["user_id"] else None,
            trigger_type=row["trigger_type"],
            status=row["status"],
            started_at=_kst(row["started_at"]),
            finished_at=_kst(row["finished_at"]),
            latency_ms=row["latency_ms"],
            error_message=row["error_message"],
        )

    async def steps(self, run_id: str) -> list[ProcessStep]:
        rows = await (
            await self.conn.execute(
                "select seq, tool_name, status::text as status, latency_ms from tool_calls"
                " where run_id = %s order by seq, id",
                (run_id,),
            )
        ).fetchall()
        return [
            ProcessStep(
                seq=row["seq"],
                tool=row["tool_name"],
                label=_label(row["tool_name"]),
                status=row["status"],
                latency_ms=row["latency_ms"],
                chosen_by="pipeline",
                note=None,
            )
            for row in rows
        ]

    async def prepare_result(self, user_id: str, run_id: str) -> PrepareResult | None:
        """그 실행이 만든 내 계획. 없으면(지워짐) None."""
        plan = await (
            await self.conn.execute(
                "select id, opportunity_id from prep_plans where agent_run_id = %s and user_id = %s",
                (run_id, user_id),
            )
        ).fetchone()
        if plan is None:
            return None
        params: dict[str, Any] = {"plan": plan["id"], "oid": plan["opportunity_id"]}
        documents = await (
            await self.conn.execute(
                "select d.id::text as id, d.name, d.issuer, d.how_to, d.lead_days, d.effort_minutes,"
                " d.form_url, coalesce(d.is_required, true) as is_required,"
                " t.id::text as task_id, t.is_done"
                " from opportunity_documents d left join planner_tasks t"
                " on t.prep_plan_id = %(plan)s and t.document_id = d.id"
                " where d.opportunity_id = %(oid)s"
                " order by coalesce(d.is_required, true) desc, d.name, d.id",
                params,
            )
        ).fetchall()
        tasks = await (
            await self.conn.execute(
                "select id::text as id, title, due_date, document_id::text as document_id"
                " from planner_tasks where prep_plan_id = %(plan)s order by sort_order, due_date, id",
                params,
            )
        ).fetchall()

            prep_plan_id=str(plan["id"]),
            documents=[DocumentItem(**row) for row in documents],
            tasks=[PrepTask(**row) for row in tasks],

            calendar_event=None,

            return None

    async def syllabus_result(self, user_id: str, run_id: str) -> SyllabusExtractResult | None:
        """그 실행이 뽑은 계획서 일정(명세 8장). 저장 단계가 없으면 None이다."""
        output = await self._tool_output(user_id, run_id, SYLLABUS_TOOL)
        if not isinstance(output, dict):
            return None
        try:
            return SyllabusExtractResult(
                syllabus_id=str(output["syllabus_id"]),
                course_name=output.get("course_name"),
                items=[SyllabusItemView.model_validate(one) for one in output.get("items", [])],
            )
        except (KeyError, TypeError, ValueError, ValidationError):
            logger.warning("계획서 결과 모양이 달라 읽지 못했어요: run %s", run_id)
            return None

    async def poster_result(self, user_id: str, run_id: str) -> PosterExtractResult | None:
        """그 실행이 만든 초안. 기록이 지워졌거나 모양이 달라졌으면 None이다."""
        output = await self._tool_output(user_id, run_id, POSTER_TOOL)
        if not isinstance(output, dict) or "draft" not in output:
            return None
        try:
            draft = PosterDraft.model_validate(output["draft"])
        except ValidationError:
            logger.warning("포스터 초안 모양이 달라 읽지 못했어요: run %s", run_id)
            return None
        candidate = output.get("duplicate_candidate")
        duplicate = None
        if isinstance(candidate, dict):
            try:
                duplicate = DuplicateCandidate.model_validate(candidate)
            except ValidationError:
                duplicate = None
        return PosterExtractResult(draft=draft, duplicate_candidate=duplicate)
```

```python
from fastapi import APIRouter

from app.auth import CurrentUserDep

router = APIRouter(prefix="/runs", tags=["실행"])


@router.get("/{run_id}", response_model=RunView)
async def read_run(run_id: UUID, user: CurrentUserDep, repo: RunRepoDep) -> RunView:
    """실행 진행·결과(API 명세 11장). 본인 실행만 본다. 배치 실행은 403, 남의 실행·없는 실행은 404다.

    steps는 처리 과정(F-42)이고, 끝나면 result나 error(코드·문구)가 붙는다. result는 kind로 가린다:
    준비하기는 계획·서류·할 일(prepare), 포스터 추출은 공고 초안과 중복 후보(poster_extract),
    LMS 동기화는 과목·과제 수(lms_sync), 계획서 추출은 뽑은 일정(syllabus_extract)이다.
    """
    run = await repo.run(str(run_id))
    if run is not None and run.user_id is None:
        raise ApiError(403, "FORBIDDEN", "이 실행은 볼 수 없어요.")
    if run is None or run.user_id != user.id:
        raise ApiError(404, "NOT_FOUND", "실행을 찾을 수 없어요.")
    result: RunResult | None = None
    if run.status == "succeeded" and run.trigger_type == "prepare":
        result = await repo.prepare_result(user.id, run.id)
    elif run.status == "succeeded" and run.trigger_type == "poster_upload":
        result = await repo.poster_result(user.id, run.id)
    elif run.status == "succeeded" and run.trigger_type == "lms_sync":
        result = await repo.lms_sync_result(user.id, run.id)
    elif run.status == "succeeded" and run.trigger_type == "syllabus_upload":
        result = await repo.syllabus_result(user.id, run.id)
    return RunView(
        id=run.id,
        trigger_type=run.trigger_type,
        status=run.status,
        started_at=run.started_at,
        finished_at=run.finished_at,
        latency_ms=run.latency_ms,
        steps=await repo.steps(run.id),
        result=result,
        error=run.error(),
```

```python
class FakeStorage:
    def __init__(self) -> None:
        self.objects: dict[str, bytes] = {}
        self.asked: list[str] = []
        self.broken = False

    async def download(self, path: str) -> bytes:
        self.asked.append(path)
        if self.broken:
            raise StorageError("저장소가 거절했어요")
        if path not in self.objects:
            raise StorageError("그 파일이 없어요")
        return self.objects[path]

    async def upload(self, path: str, data: bytes, content_type: str) -> None:
        self.objects[path] = data

    async def remove(self, path: str) -> None:
        self.objects.pop(path, None)

@asynccontextmanager
async def committed() -> AsyncIterator[Fixture]:
    """사용자 둘, 과목 둘, 계획서 파일 둘을 커밋한다. 끝나면 지운다."""

        row = await (
            await setup.execute(
                "insert into lms_courses (user_id, canvas_course_id, name, is_active)"
                " values (%s, %s, %s, %s) returning id::text as id",
                (owner, canvas, name, active),
            )
        ).fetchone()
        assert row is not None
        world.courses[name] = row["id"]
        return row["id"]

    async def add_file(name: str, owner: str, *, kind: str = "syllabus") -> str:
        file_id = str(uuid4())
        path = f"{owner}/{kind}/{file_id}.pdf"
        await setup.execute(
            "insert into files (id, user_id, kind, origin, storage_path, mime_type, sha256)"
            " values (%s, %s, %s, 'upload', %s, 'application/pdf', %s)",
            (file_id, owner, kind, path, f"{abs(hash(name)):064d}"[:64]),
        )
        world.files[name] = file_id
        world.paths[file_id] = path
        return file_id

    await add_course("202620HY23525_데이터베이스", user, 9_900_101)
    await add_course("202620HY23534_기계학습", user, 9_900_102, active=False)

    await add_file("남의 계획서", other)

    await setup.commit()  # 뒤에서 도는 일은 자기 연결로 본다. 커밋해야 보인다
    try:
        yield world
    finally:
        await setup.execute("delete from auth.users where id = any(%s::uuid[])", ([user, other],))
        await setup.commit()
        await setup.close()


@asynccontextmanager
async def api(
    settings: Settings, llm: Any, storage: FakeStorage
) -> AsyncIterator[Callable[[str], httpx.AsyncClient]]:
    app = create_app(settings)
    pool, log_pool = create_pools(DATABASE_URL)
    await pool.open()
    await log_pool.open()
    app.state.pool, app.state.log_pool, app.state.runner = pool, log_pool, InlineRunner()
    app.dependency_overrides[get_settings] = lambda: settings
    app.dependency_overrides[get_llm] = lambda: llm
    app.dependency_overrides[get_storage] = lambda: storage
    clients: list[httpx.AsyncClient] = []

    def client(user_id: str) -> httpx.AsyncClient:
        http = httpx.AsyncClient(
            transport=httpx.ASGITransport(app=app),
            base_url="http://test",
            headers={"Authorization": f"Bearer {make_token(user_id)}"},
        )
        clients.append(http)
        return http

    try:
        yield client
    finally:
        for http in clients:
            await http.aclose()
        await pool.close()
        await log_pool.close()


async def extract(
    world: Fixture,
    settings: Settings,
    llm: Any,
    *,
    body: dict[str, Any] | None = None,
    storage: FakeStorage | None = None,
    name: str = "내 계획서",
    user: str | None = None,
) -> dict[str, Any]:
    """`POST /syllabi/extract` → `GET /runs/{id}`. InlineRunner라 응답 전에 실행이 끝나 있다."""
    store = storage or FakeStorage()
    file_id = world.files[name]
    store.objects.setdefault(world.paths[file_id], PDF)
    async with api(settings, llm, store) as client:
        http = client(user or world.user)
        started = await http.post(
            "/api/v1/syllabi/extract", json={"file_id": file_id, **(body or {})}
        )
        assert started.status_code == 202, started.text
        run_id = started.json()["run_id"]
        return (await http.get(f"/api/v1/runs/{run_id}")).json()
```
