# 포스터에서 공고 읽기 (F-16 2차)

> 📝 기준: PRD v0.9 F-16 · API 명세 v0.4 6·11·13장 · ERD v0.9 5장 · 2026-10-15
>
> 기준 커밋: main `a48282e`(#32 포스터 업로드)

올린 포스터 사진에서 **제목·주최·종류·신청 기간·지원 자격·제출 서류를 읽어 확인 화면에 채운다**(`POST /posters/extract`). 지난 PR에서 파일은 저장소에 올라가게 됐지만, 올린 뒤에는 "자동 정리는 준비 중"이라고만 알렸다. 이제 Vision 모델이 포스터를 읽고 학생은 그 결과를 확인할 수 있다. **확인한 내용으로 공고를 만드는 `POST /posters/confirm`은 다음 PR(3차)**이다.

**규모와 확인:**
- api 새 파일 10개(포스터 프롬프트·추출·실행, 저장소·라우터·스키마와 테스트 3개), 바꾸는 파일 8개. web 새 파일 3개, 바꾸는 파일 8개, 지우는 파일 1개.
- **DB 변경이 없다.** 초안은 테이블이 아니라 그 실행의 `tool_calls.output`에 둔다. 합친 뒤 db push가 필요 없다.
- **새 의존성이 없다.** 이미 쓰는 Gemini 클라이언트(`app/llm`)를 그대로 쓴다.
- **새 에러 코드 1개: `POSTER_READ_FAILED`(422).** 같은 PR에서 명세 13장 표에 넣는다.
- **모델을 부르니 `.env`의 `GOOGLE_CLOUD_PROJECT`가 있어야 돌아간다**(준비하기·요건 추출과 같은 설정). 없으면 실행이 `LLM_ERROR`로 실패한다. 모델은 `VISION_MODEL`이다.
- api `ruff` 통과, `651 passed, 112 skipped`(DB 없이) · `763 passed`(새 DB). web `typecheck`·`build` 통과.
- 가짜 Storage로 실제 모드 E2E 2벌(업로드 6단계, 추출 5단계)과 목 모드 흐름을 돌렸다. 되돌림 시험(변이) 32가지가 모두 잡혔다.
- 따로 띄운 검토 에이전트 둘이 api와 web·문서를 나눠 봤다. **모델에 기준 날짜를 안 줘서 연도를 지어낼 수 있던 것**, **도구에 없는 항목을 시키던 프롬프트**, **강조 목록에 이상한 값이 오면 읽은 내용을 통째로 버리던 것**, **기다리다 끊긴 것을 "분석 실패"로 보여 주던 것**을 포함해 14건을 고쳤다.

## 확인한 것

- **단위·DB 테스트 40개**(추출 18 · API 7 · DB 15). 한 번만 묻는지, 도구를 강제하는지, 오늘 날짜를 주는지, 옮겨 적은 글로 근거를 대조하는지, 글자 없음·제출 없음·제목 없음, 모르는 종류, 짧은 제목, 강조 목록에 이상한 값, 마감일이 오늘보다 앞섬·너무 뒤임, 서류 사전, 조건 문장, 남의 파일·계획서, 모델 없음·느림·오류, 저장소 오류, 중복 네 갈래(같은 날·다른 날·남의 포스터·마감일 없음), 초안 다시 읽기와 모양이 깨졌을 때, 비용 기록.
- **공지 요건 추출 프롬프트가 글자 그대로인지** 쪼개기 전후로 뽑아 대조했다(차이 없음). 공지 쪽 테스트 89개도 그대로 통과한다.

- **목 모드**는 분석 → 확인 → 등록까지 그대로 돈다.

## 남은 것

- **등록(`POST /posters/confirm`)이 다음이다.** 확인 화면에서 고친 값으로 공고를 만들고, 업로더 본인 판정을 계산하고, 중복이면 기존 공고에 합친다(`merged: true`). `poster_text`가 그때 공고 원문이 된다.
- **고친 값이 아직 아무 데도 안 쓰인다.** 실제 모드에서는 "정보 수정"을 감췄다. 등록이 붙을 때 다시 연다.
- **취소된 실행은 `running`으로 남는다.** 서버를 끄면 `TaskRunner.drain`을 넘긴 포스터 실행이 그대로 남는다(준비하기처럼 "5분 넘으면 멈춘 것으로 본다"는 회수 규칙이 없다). 학생은 60초 뒤 "아직 읽고 있어요"를 보고 다시 올리면 된다.
- **서류 양식 링크(`form_url`)는 확인 화면에 안 보인다.** 등록하면 상세의 "양식 내려받기"가 되므로, 등록 PR에서 보여 줄지 정한다.
- **중복 찾기가 공고 전체를 훑는다.** 제목 정규화에 인덱스가 없다. 지금 규모(수백 건)에서는 문제가 없고, 늘면 표현식 인덱스를 둔다.
- **HEIC**와 `kind = syllabus`·`lecture_material`은 그대로 다음이다(F-14·F-15).

```python
2. 그 글에서 제목·주최·종류·신청 기간·자격 요건·제출 서류를 뽑는다. evidence_text는 poster_text에 적은 글에서 그대로 복사한다.
3. 포스터에 없는 것은 넣지 않는다. 지어내지 않는다.
4. QR 코드, 링크, "자세한 내용은 홈페이지 참조"처럼 포스터 밖에 있는 내용은 읽을 수 없다. 그런 안내가 있으면 그 항목을 low_confidence_fields에 넣는다.
5. 사진이 흐리거나 잘려 글자를 제대로 읽지 못하면 보이는 것만 적고 confidence를 낮게 둔다.

## 제목·주최·종류
- title: 포스터에 가장 크게 적힌 공고 이름 그대로. "지금 신청하세요!" 같은 홍보 문구는 넣지 않는다.
- organizer: 주최·주관 기관. 적혀 있지 않으면 넣지 않는다.
- category: {categories}
- low_confidence_fields: 확신하지 못하는 항목 이름. {", ".join(LOW_CONFIDENCE_FIELDS)} 중에서 고른다. 학생이 확인 화면에서 그 칸을 눈여겨본다.

{requirement_rules(departments, attachments=False, date_basis=DATE_BASIS)}"""


def _documents_schema() -> dict:
    schema = deepcopy(_SHARED["documents"])
    schema["items"]["properties"].pop("form_attachment_no", None)  # 포스터에는 첨부가 없다
    return schema


SUBMIT_POSTER = ToolSpec(
    name=SUBMIT,
    description="포스터에서 읽은 글자와 뽑은 공고 내용을 제출한다. 코드가 검증한다.",
    parameters={

                "type": "string",
                "description": f"포스터에 보이는 글자를 그대로 옮긴 글. 글자가 없으면 {NO_TEXT}",
            },
            "title": {"type": "string", "description": "공고 이름"},
            "organizer": {"type": "string", "description": "주최·주관 기관. 없으면 넣지 않는다"},
            "category": {"type": "string", "enum": list(CATEGORIES)},
            "requirements": _SHARED["requirements"],
            "documents": _documents_schema(),
            "apply_start": _SHARED["apply_start"],
            "deadline": _SHARED["deadline"],
            "easy_summary": _SHARED["easy_summary"],
            "confidence": _SHARED["confidence"],
            "low_confidence_fields": {
                "type": "array",
                "items": {"type": "string", "enum": list(LOW_CONFIDENCE_FIELDS)},
                "description": "확신하지 못하는 항목. 없으면 빈 목록",
            },
        },
```

```python
"""포스터 한 장 → 공고 초안 (F-16).

Vision 모델을 **한 번만** 부른다. 포스터는 사진 한 장이라 더 읽을 첨부가 없어서, 글자를 옮기는 일과
요건을 뽑는 일을 한 호출에서 함께 받는다(submit_poster의 poster_text + 나머지 항목).

검증은 공지 추출과 같은 코드(app/extraction/validate.check_submission)를 쓴다. 근거 문장은 모델이
옮겨 적은 poster_text에 있는지 본다 — 포스터에는 대조할 다른 원문이 없다.

한 번만 부르므로 final=True로 검증한다. 문제가 있으면 모델에 다시 묻지 않고 코드가 고쳐서 받고,
고친 항목은 확인 화면에서 강조할 low_confidence_fields에 넣는다.
"""

import asyncio
import logging
from collections.abc import Sequence
from dataclasses import dataclass
from datetime import date

from app.eligibility import Department, Requirement, condition_text
from app.extraction.models import DocumentDraft, RequirementDraft
from app.extraction.validate import Context, Evidence, Submission, check_submission
from app.llm import Blob, LlmClient, LlmReply, UserTurn
from app.posters.prompt import (
    CATEGORIES,
    NO_TEXT,
    SUBMIT,
    SUBMIT_POSTER,
    first_message,
    system_prompt,
)
from app.prepare.documents import lookup
from app.schemas.posters import (
    LOW_CONFIDENCE_FIELDS,
    PosterDocumentDraft,
    PosterDraft,
    PosterRequirementDraft,
)

logger = logging.getLogger(__name__)
TIMEOUT_SECONDS = 50.0  # 웹이 실행을 확인하는 60초 안에 실패를 알려 준다
MAX_OUTPUT_TOKENS = 16_000  # 옮긴 글자 + 요건. 넘치면 제출이 잘려 읽지 못한 것으로 본다
LOW_CONFIDENCE = 0.6  # 이보다 낮으면 제목·마감일을 확인하게 한다
_DEFAULT_CATEGORY = "etc"


class PosterError(Exception):
    """포스터에서 공고를 읽지 못했다. 학생에게 그대로 보여 줄 문구다."""


@dataclass(frozen=True)
class Extracted:
    draft: PosterDraft
    poster_text: str  # 등록(F-16 2차)에서 공고 원문으로 쓴다
    reply: LlmReply


async def extract(
    llm: LlmClient,
    *,
    model: str,
    blob: Blob,
    departments: Sequence[Department],
    today: date,
) -> Extracted:
    """Vision 한 번 호출. 읽지 못하면 PosterError다."""
    try:
        async with asyncio.timeout(TIMEOUT_SECONDS):
            reply = await llm.generate(
                model=model,
                system=system_prompt(departments),
                turns=[UserTurn(text=first_message(today), blobs=(blob,))],
                tools=(SUBMIT_POSTER,),
                force_tool=SUBMIT,
                max_output_tokens=MAX_OUTPUT_TOKENS,
            )
    except TimeoutError as exc:
        raise TimeoutError("포스터를 읽는 데 너무 오래 걸렸어요.") from exc
    call = next((c for c in reply.turn.tool_calls if c.name == SUBMIT), None)
    if call is None:
        raise PosterError(f"포스터에서 글자를 읽지 못했어요({reply.finish_reason or '이유 없음'}).")
    args = call.args
    poster_text = args.get("poster_text")
    if (
        not isinstance(poster_text, str)
        or not poster_text.strip()
        or poster_text.strip() == NO_TEXT
    ):
        raise PosterError("포스터에서 글자를 읽지 못했어요.")

    evidence = Evidence()
    evidence.add(poster_text)
    # 포스터에는 게시일이 없다. 연도 없는 날짜("10. 24.까지")는 사진을 올린 날 뒤로 읽는다
    context = Context(evidence, {}, departments, today)
    submission, problems = check_submission(args, context, final=True)
    if submission is None:
        logger.info("포스터 제출을 받지 못했어요: %s", "; ".join(problems[:3]))
        raise PosterError("포스터에서 지원 조건을 정리하지 못했어요.")

    title = _text(args.get("title"))
    if title is None:
        raise PosterError("포스터에서 공고 이름을 찾지 못했어요.")
    draft = PosterDraft(
        title=title[:200],
        organizer=_cut(_text(args.get("organizer")), 100),
        category=_category(args.get("category")),
        apply_start_at=submission.apply_start_at,
        deadline_at=submission.deadline_at,
        easy_summary=submission.easy_summary,
        requirements=[_requirement(req) for req in submission.requirements],
        documents=[_document(doc) for doc in submission.documents],
        extraction_confidence=float(submission.confidence),
        low_confidence_fields=_low_confidence(
            args.get("low_confidence_fields"), submission, title, _text(args.get("category"))
        ),
    )
    return Extracted(draft, poster_text, reply)


def _requirement(req: RequirementDraft) -> PosterRequirementDraft:
    """조건 문장은 공고 상세와 같은 방법으로 만든다(app/eligibility/describe)."""
    shown = Requirement(
        id="",
        clause_no=req.clause_no,
        field=req.field,
        operator=req.operator,
        value=req.value,
        basis=req.basis,
        is_ambiguous=req.is_ambiguous,
        evidence_text=req.evidence_text,
    )
    return PosterRequirementDraft(
        clause_no=req.clause_no,
        field=req.field,
        operator=req.operator,
        value=req.value,
        condition_text=condition_text(shown),
        evidence_text=req.evidence_text,
        is_ambiguous=req.is_ambiguous,
    )


def _document(doc: DocumentDraft) -> PosterDocumentDraft:
    """발급처·소요 일수·작성 시간은 서류 사전에서 채운다(준비하기와 같은 사전)."""
    guide = lookup(doc.name)
    return PosterDocumentDraft(
        name=doc.name,
        issuer=guide.issuer if guide else None,
        lead_days=guide.lead_days if guide else None,
        effort_minutes=guide.effort_minutes if guide else None,
        form_url=doc.form_url,
    )


def _low_confidence(
    raw: object, submission: Submission, title: str, category: str | None
) -> list[str]:
    """모델이 고른 항목 + 코드가 보기에 확인이 필요한 항목. 확인 화면에서 강조한다."""
    # 모델이 아무 값이나 줄 수 있다(글이 아닌 것도). 아는 항목만 남기는 것은 마지막 한 줄에서 한다
    found = {name for name in raw if isinstance(name, str)} if isinstance(raw, list) else set()
    if submission.deadline_at is None:
        found.add("deadline_at")  # 마감일을 못 읽으면 학생이 넣어야 한다
    if submission.confidence < LOW_CONFIDENCE:
        found.update(("title", "deadline_at"))
    if any(req.is_ambiguous for req in submission.requirements):
        found.add("requirements")
    if submission.fixes:  # 코드가 고쳐서 받은 것이 있다(날짜 뒤바뀜, 근거 없는 조건 등)
        found.add("requirements")
    if len(title) < 4:  # "장학금"처럼 너무 짧은 제목은 큰 글씨만 읽은 것일 수 있다
        found.add("title")
    if category not in CATEGORIES:  # 모르는 종류는 '그 밖'으로 두므로 학생이 골라야 한다
        found.add("category")
    return [name for name in LOW_CONFIDENCE_FIELDS if name in found]


def _category(raw: object) -> str:
    return raw if isinstance(raw, str) and raw in CATEGORIES else _DEFAULT_CATEGORY


def _text(value: object) -> str | None:
    if not isinstance(value, str):
        return None
    cleaned = " ".join(value.split())
    return cleaned or None


def _cut(value: str | None, limit: int) -> str | None:
    return value[:limit] if value else None
```

```python
"""포스터 추출 실행 (F-16, API 명세 6장 POST /posters/extract).

202와 run_id를 먼저 주고 뒤에서 돈다(준비하기와 같은 방식). 일은 요청과 따로 돌며 자기 연결을 연다.

차례: 저장소에서 포스터 받기 → 학과 목록 읽기 → Vision 한 번 → 중복 공고 찾기 → 실행 기록에 초안 남기기.
초안은 따로 저장하지 않고 tool_calls.output에 둔다. GET /runs/{id}가 그것을 다시 읽어 준다.
모델을 기다리는 동안 DB 연결(요청 풀)을 쥐지 않는다. 로그 연결도 한 줄 쓸 때마다 빌렸다 돌려준다.

실패 이유는 ApiError로 남겨 학생에게 그대로 보인다. 글자를 못 읽은 것(POSTER_READ_FAILED)은 다시
찍어 올리면 되는 일이고, LLM_TIMEOUT·STORAGE_API_ERROR는 잠시 뒤 다시 누르면 되는 일이다.
"""

import logging
from collections.abc import Callable
from contextlib import AbstractAsyncContextManager
from dataclasses import dataclass
from datetime import date, datetime
from typing import Annotated

from fastapi import Depends, Request
from psycopg import AsyncConnection

from app.agent_log import AgentRun, ToolCall, abandon_run, agent_run, start_run
from app.background import RunnerDep, TaskRunner
from app.config import Settings, get_settings
from app.errors import ApiError
from app.extraction.store import load_departments
from app.llm import Blob, LlmClient
from app.llm.deps import LlmDep
from app.posters.extract import Extracted, PosterError, extract
from app.posters.prompt import SUBMIT
from app.repositories.posters import PosterFile, PosterRepository
from app.schemas.posters import DuplicateCandidate
from app.uploads.storage import StorageDep, StorageError, SupabaseStorage

logger = logging.getLogger(__name__)
Connect = Callable[[], AbstractAsyncContextManager[AsyncConnection]]
TRIGGER = "poster_upload"
RETRY_HINT = "포스터 전체가 보이게 밝은 곳에서 다시 찍어 주세요."
SLOW = "포스터를 읽는 데 너무 오래 걸렸어요. 잠시 후 다시 눌러 주세요."
STORAGE_FAILED = "올린 포스터를 불러오지 못했어요. 잠시 후 다시 눌러 주세요."
MODEL_FAILED = "포스터를 읽지 못했어요. 잠시 후 다시 눌러 주세요."
STOPPED = "포스터를 읽다 멈췄어요. 다시 눌러 주세요."


@dataclass(frozen=True)
class PosterJob:
    run_id: str
    user_id: str
    file: PosterFile
    today: date  # KST. 연도 없는 날짜를 읽는 기준이다
    now: datetime


class PosterService:
    def __init__(
        self,
        *,
        transaction: Connect,
        log_connection: Connect,
        storage: SupabaseStorage,
        llm: LlmClient | None,
        model: str,
        runner: TaskRunner,
    ) -> None:
        self.transaction = transaction
        self.log_connection = log_connection
        self.storage = storage
        self.llm = llm
        self.model = model
        self.runner = runner

    async def file(self, user_id: str, file_id: str) -> PosterFile | None:
        async with self.transaction() as conn:
            return await PosterRepository(conn).poster_file(user_id, file_id)

    async def begin(self, user_id: str, file: PosterFile, *, now: datetime, today: date) -> str:
        """실행 행을 만들고 일을 띄운다. run_id를 준다."""
        run_id = await start_run(self.log_connection, trigger=TRIGGER, user_id=user_id)
        job = PosterJob(run_id, user_id, file, today, now)
        work = self.execute(job)
        try:
            await self.runner.start(work)
        except Exception:
            work.close()
            await self._close(run_id)
            raise
        return run_id

    async def execute(self, job: PosterJob) -> None:
        try:
            async with agent_run(
                self.log_connection, trigger=TRIGGER, user_id=job.user_id, run_id=job.run_id
            ) as run:
                async with run.tool(SUBMIT, {"file_id": job.file.id}) as call:
                    extracted = await self._read(run, call, job)
                    duplicate = await self._duplicate(job, extracted)
                    call.output = {
                        "draft": extracted.draft.model_dump(mode="json"),
                        "duplicate_candidate": duplicate.model_dump() if duplicate else None,
                        # 등록(F-16 2차)에서 공고 원문으로 쓴다
                        "poster_text": extracted.poster_text,
                    }
        except Exception:
            logger.exception("포스터 추출 실행 실패: run %s", job.run_id)
            await self._close(job.run_id)

    async def _read(self, run: AgentRun, call: ToolCall, job: PosterJob) -> Extracted:
        """저장소에서 받아 모델에 한 번 넘긴다. 모델을 기다리는 동안 DB 연결을 쥐지 않는다."""
        if self.llm is None:
            raise ApiError(502, "LLM_ERROR", MODEL_FAILED)
        try:
            data = await self.storage.download(job.file.storage_path)
        except StorageError as exc:
            logger.warning("포스터를 저장소에서 받지 못했어요: %s", exc)
            raise ApiError(502, "STORAGE_API_ERROR", STORAGE_FAILED) from exc
        async with self.transaction() as conn:
            departments = await load_departments(conn)
        blob = Blob(data, job.file.mime_type or "image/jpeg")
        try:
            extracted = await extract(
                self.llm, model=self.model, blob=blob, departments=departments, today=job.today
            )
        except PosterError as exc:
            raise ApiError(422, "POSTER_READ_FAILED", f"{exc} {RETRY_HINT}") from exc
        except TimeoutError as exc:
            raise ApiError(502, "LLM_TIMEOUT", SLOW) from exc
        except Exception as exc:
            logger.warning("포스터 모델 호출 실패: %r", exc)
            raise ApiError(502, "LLM_ERROR", MODEL_FAILED) from exc
        await run.record_llm(
            provider=self.llm.provider,
            model=self.model,
            input_tokens=extracted.reply.usage.input_tokens,
            output_tokens=extracted.reply.usage.output_tokens,
            latency_ms=extracted.reply.latency_ms,
            tool_call=call,
        )
        return extracted

    async def _duplicate(self, job: PosterJob, extracted: Extracted) -> DuplicateCandidate | None:
        async with self.transaction() as conn:
            return await PosterRepository(conn).duplicate(
                job.user_id,
                title=extracted.draft.title,
                deadline_at=extracted.draft.deadline_at,
                now=job.now,
            )

    async def _close(self, run_id: str, message: str = STOPPED) -> None:
        """아직 running인 실행을 실패로 닫는다(이미 닫혔으면 그대로 둔다)."""
        try:
            await abandon_run(self.log_connection, run_id, ApiError(500, "INTERNAL_ERROR", message))
        except Exception:
            logger.exception("포스터 실행을 닫지 못했어요: run %s", run_id)


def get_poster_service(
    request: Request,
    llm: LlmDep,
    runner: RunnerDep,
    storage: StorageDep,
    settings: Annotated[Settings, Depends(get_settings)],
) -> PosterService:
    state = request.app.state
    pool, log_pool = getattr(state, "pool", None), getattr(state, "log_pool", None)
    if pool is None or log_pool is None:
        raise ApiError(503, "DB_UNAVAILABLE", "데이터베이스에 연결할 수 없어요.")
    return PosterService(
        transaction=pool.connection,
        log_connection=log_pool.connection,
        storage=storage,
        llm=llm,
        model=settings.vision_model,
        runner=runner,
    )


PosterServiceDep = Annotated[PosterService, Depends(get_poster_service)]
```

```python
"""포스터 추출 SQL (F-16).

- 올린 포스터 파일 찾기: 내 파일(origin = 'upload', kind = 'poster')만
- 중복 공고 찾기: 제목을 정규화해 같고 마감일이 같은 KST 날짜인 공고. 내가 볼 수 있는 공고만 본다
  (공개 범위는 공고 목록·상세와 같은 조건을 쓴다)

초안은 따로 저장하지 않고 그 실행이 남긴 tool_calls.output에 둔다. 다시 읽는 SQL은 실행 조회와 함께
repositories/runs.py에 있다(준비하기가 계획 행에서 결과를 다시 읽는 것과 같은 방식이다).
"""

from dataclasses import dataclass
from datetime import datetime

from psycopg import AsyncConnection

from app.repositories.opportunities import COURSE_JOIN, VISIBLE
from app.schemas.posters import DuplicateCandidate

# 제목 비교용 정규화: 영문 소문자·숫자·한글만 남긴다("2026 교내 장학" → "2026교내장학")
_NORMALIZED = "regexp_replace(lower({}), '[^0-9a-z가-힣]', '', 'g')"
_TITLE = _NORMALIZED.format("o.title")


@dataclass(frozen=True)
class PosterFile:
    id: str
    storage_path: str
    mime_type: str | None


class PosterRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def poster_file(self, user_id: str, file_id: str) -> PosterFile | None:
        """내가 올린 포스터 파일. 남의 파일·다른 종류·LMS 첨부는 None이다."""
        row = await (
            await self.conn.execute(
                "select id::text as id, storage_path, mime_type from files"
                " where id = %s and user_id = %s and origin = 'upload' and kind::text = 'poster'",
                (file_id, user_id),
            )
        ).fetchone()
        return None if row is None else PosterFile(row["id"], row["storage_path"], row["mime_type"])

    async def duplicate(
        self, user_id: str, *, title: str, deadline_at: datetime | None, now: datetime
    ) -> DuplicateCandidate | None:
        """같은 공고가 이미 있으면 그 공고. 제목이 같고 마감일이 같은 날이어야 한다.

        마감일을 읽지 못한 포스터는 아직 마감하지 않은 공고 중에서 제목이 같은 것을 본다. 제목만으로는
        "2026 1학기 교내장학"처럼 해마다 같은 이름인 공고를 엉뚱하게 묶을 수 있어서, 마감일이 있으면
        반드시 같은 KST 날짜여야 한다.
        """
        clean = _normalize(title)
        if not clean:
            return None
        params = {"uid": user_id, "title": clean, "deadline": deadline_at, "now": now}
        when = (
            " and (o.deadline_at at time zone 'Asia/Seoul')::date"
            " = (%(deadline)s::timestamptz at time zone 'Asia/Seoul')::date"
            if deadline_at is not None
            else " and (o.deadline_at is null or o.deadline_at >= %(now)s)"
        )
        row = await (
            await self.conn.execute(
                "select o.id::text as id, o.title from opportunities o"
                + COURSE_JOIN
                + " where o.status in ('active', 'expired') and "
                + VISIBLE
                + f" and {_TITLE} = %(title)s"
                + when
                + " order by o.deadline_at nulls last, o.id limit 1",
                params,
            )
        ).fetchone()
        return (
            None
            if row is None
            else DuplicateCandidate(opportunity_id=row["id"], title=row["title"])
        )


def _normalize(title: str) -> str:
    """SQL의 _TITLE과 같은 규칙. 아스키 소문자·숫자와 한글만 남긴다.

    전각 숫자("２")나 한자는 SQL 쪽 [^0-9a-z가-힣]도 지우므로 여기서도 지운다. 두 규칙이 어긋나면
    코드가 찾은 제목과 DB가 비교하는 제목이 달라져 중복을 놓친다.
    """
    return "".join(ch for ch in title.lower() if _kept(ch))


def _kept(ch: str) -> bool:
    return "0" <= ch <= "9" or "a" <= ch <= "z" or "가" <= ch <= "힣"
```

```python
def requirement_rules(
    departments: Sequence[Department],
    *,
    attachments: bool,
    date_basis: str = NOTICE_DATE_BASIS,

    """요건·서류·날짜 규칙. 공지 추출(prompt.system_prompt)과 포스터 추출이 함께 쓴다.

    원문 확인 사유(review_note)도 묻지 않는다(포스터는 low_confidence_fields로 받는다).

    date_basis는 연도 없는 날짜를 어느 날 기준으로 읽을지 적은 문장이다. 공지는 게시일,
    포스터는 사진을 올린 날이다. 부르는 쪽이 그 날짜를 메시지에 꼭 함께 넣어야 한다(기준을 모르면
    모델이 연도를 지어낸다).
    """
    fields = "\n".join(
        f"- {name}({label}) · {_operators(name)} · 예: {_VALUE_EXAMPLES[name]}"
        for name, label in FIELD_LABELS.items()
    )
    form = (
        " 양식 파일이 첨부에 있으면 form_attachment_no에 첨부 번호를 넣는다." if attachments else ""

        if attachments
        else ""
    )  # 포스터는 원문 확인 사유 대신 low_confidence_fields를 쓴다
    return f"""## 요건 규칙

- 나이는 만 나이다. 병역 기간만큼 상한을 늘린다는 문구가 있으면 between 값에 "military_extension": true를 넣고, 늘리는 최대 개월이 있으면 {{"max_months": 36}}처럼 쓴다.
- 이수 학기는 마친 학기 수다. "8학기 이내 재학"은 semesters_completed lte 7, "N학기 이상 이수"는 gte N이다. 현재 학기를 세는지 애매하면 is_ambiguous를 true로 둔다.
- 학적: "재학생"은 enrollment_status eq "enrolled", "휴학생 포함"은 in ["enrolled", "on_leave"], "졸업유예자 제외"는 not_in ["deferred_graduation"]이다. graduated는 이미 졸업한 사람이다. 졸업예정자·수료생만 되거나 이들을 빼는 조건은 학적 값에 없으니 other로 둔다. "졸업예정자 포함"·"수료생 포함"처럼 대상을 넓히기만 하는 말은 조건으로 만들지 않는다.

- 학위과정 조건을 만들지 않는 말: "대학(원)생"·"학부생 및 대학원생"처럼 모든 과정을 받는 말, 과정을 적지 않은 "재학생"·"대학생", 학과 이름 속 "학부"(예: 컴퓨터학부). 지원·진학하려는 과정(대학원 신입생 모집의 석사과정, 대학원 진학 예정자)과 받았거나 받을 학위("학사 학위 소지자", "학부 졸업(예정)자")를 보는 조건은 other로 둔다.
- 소득: 학자금 지원구간은 income_bracket(0–10), 기준 중위소득 %는 median_income_pct, 기초생활수급·차상위는 welfare_status다. 서로 바꿔 계산하지 않는다. 여러 소득 기준이 "또는"이면 같은 묶음에 넣는다.

{fields}

- degree_program 값: bachelor 학부, master 석사, doctoral 박사, integrated 석박사통합
- welfare_status 값: none 해당 없음, near_poverty 차상위, basic_livelihood 기초생활수급

- 다른 항목에는 basis를 넣지 않는다.

## 학과 목록
{_department_block(departments)}

## 서류·날짜·요약

- easy_summary: 학생에게 보여줄 쉬운 설명 2–3문장(누가, 무엇을, 언제까지). 링크는 넣지 않는다.{review}
- confidence: 요건을 빠짐없이 정확히 뽑았다고 보는 정도(0–1)."""


def _operators(field: str) -> str:
    return ", ".join(op for op in _OPERATOR_ORDER if op in ALLOWED_OPERATORS[field])


def _department_block(departments: Sequence[Department]) -> str:
    if not departments:
        return "아직 없다. 학과 조건은 원문 그대로 쓰고 is_ambiguous를 true로 둔다."
    names = ", ".join(department.name for department in departments)
    colleges = ", ".join(dict.fromkeys(department.college for department in departments))
    groups = ", ".join(dict.fromkeys(department.field_group for department in departments))
    return f"- 학과: {names}\n- 단과대학: {colleges}\n- 계열: {groups}"


def notice_message(
    notice: NoticeInput, body: str, truncated: bool, attachment_lines: Sequence[str]
) -> str:
    """첫 메시지. body는 상한까지 자른 본문이다(Library.body)."""
    posted = notice.posted_on.isoformat() if notice.posted_on else "모름"
    lines = ["[공고]", f"제목: {notice.title}", f"게시일: {posted}"]
    if notice.organizer:
        lines.append(f"게시처: {notice.organizer}")
    if notice.original_url:
        lines.append(f"원문 링크: 있음({FETCH_ORIGINAL}로 다시 읽을 수 있다)")
    note = f"\n(본문이 길어 앞 {len(body):,}자만 넣었다)" if truncated else ""
    lines += ["", "[본문]", (body or "(본문 없음)") + note, "", "[첨부]"]
    lines += list(attachment_lines) or ["없음"]
    return "\n".join(lines)
```

```python
# 러너·테스트)이 지난 시각으로 열어도 기록이 거꾸로 가지 않는다
_VIEW = (
    "insert into opportunity_views (user_id, opportunity_id, first_viewed_at, last_viewed_at)"
    " values (%s, %s, %s, %s) on conflict (user_id, opportunity_id) do update set"
    " last_viewed_at = greatest(opportunity_views.last_viewed_at, excluded.last_viewed_at)"
)


def _stale_sql(scope: str) -> str:
    """다시 판정할 공고와 그 요건."""
    return (
        "select o.id, o.requirements_version, o.eligibility_basis_date, o.deadline_at,"
        " o.apply_start_at, o.source_type::text as source_type,"
        " e.user_id is not null as had_result, e.status::text as old_status,"
        " e.missing_fields as old_missing, " + _REQUIREMENTS_JSON + " as requirements"
        " from opportunities o"
        + COURSE_JOIN
        + _RESULT_JOIN
        + " where"
        + scope
        + " and"
        + VISIBLE
        + " and o.extraction_run_id is not null"
        " and (%(force)s or e.user_id is null or e.evaluated_at is null"
        " or e.requirements_version <> o.requirements_version"
        " or e.engine_version <> %(engine)s"
        # 날이 바뀌면 다시: 기준일이 "오늘"인 공고(청년정책 포함), 엔진 오류로 판정하지 못한 공고(오류를
        # 고쳤을 수 있다)
        " or (((o.eligibility_basis_date is null and (o.deadline_at is null"
        " or (o.source_type = 'youth_policy' and o.deadline_at >= %(now)s)))"
        " or e.reason_text = %(engine_error)s)"
        " and (e.evaluated_at at time zone 'Asia/Seoul')::date < %(today)s))"
    )


def _feed_sql(where: str, outer: str, order: str) -> str:
    return (
        "with feed as (select o.id, o.title, o.organizer, o.category::text as category,"
        " o.source_type::text as source_type, o.deadline_at, o.created_at, o.easy_summary,"
        " o.needs_review, coalesce(o.uploaded_by = %(uid)s, false) as uploaded_by_me,"
        " c.name as course_name,"
        " exists(select 1 from prep_plans p where p.user_id = %(uid)s and p.opportunity_id = o.id"
        " and " + PREP_DONE + ") as prepared,"
        " coalesce(o.created_at >= %(new_since)s, false) and not exists(select 1"
        " from opportunity_views v where v.user_id = %(uid)s and v.opportunity_id = o.id) as is_new,"
        " " + _JUDGED + " as judged,"
        " case when " + _JUDGED + " then e.status::text else 'undetermined' end as eff_status,"
        " case when " + _JUDGED + " then coalesce(e.missing_fields, '{}') else '{}' end"
        " as eff_missing,"
        " e.reason_text, m.mark as my_mark"
        " from opportunities o" + COURSE_JOIN + _RESULT_JOIN + _MARK_JOIN + " where" + where + ")"
        " select * from feed" + outer + " order by " + order + " limit %(limit)s"
    )


@dataclass(frozen=True)
class Cursor:
    scope: str  # 목록 조건(정렬·필터)의 지문. 조건이 다른 목록에는 쓸 수 없다
    # 마지막 행의 정렬 값(deadline: 마감 시각, recent: 등록 시각). 없을 수 있다
    value: datetime | None
    id: str


@dataclass(frozen=True)
class FeedQuery:
    eligibility: frozenset[str] | None = None  # None이면 전체
    categories: tuple[str, ...] | None = None
    source_types: tuple[str, ...] | None = None
    sort: Sort = "deadline"
    include_expired: bool = False
    include_not_interested: bool = False  # 관심 없음 공고도 준다(F-45)
    limit: int = 20
    cursor: Cursor | None = None

    def scope(self) -> str:
        """cursor를 묶는 목록 조건의 지문. 정렬이나 필터를 바꾸면 목록을 처음부터 다시 부른다.

        같은 목록이면 지문도 같다: 값의 순서는 보지 않고, 모든 값을 고른 필터는 필터 없음과 같다.
        """
        parts = (
            self.sort,
            _filter_key(self.eligibility, ELIGIBILITY_STATUSES),
            _filter_key(self.categories, CATEGORIES),
            _filter_key(self.source_types, SOURCE_TYPES),
            str(self.include_expired),
            str(self.include_not_interested),
        )
        return hashlib.sha256("|".join(parts).encode()).hexdigest()[:16]


def _filter_key(values: Collection[str] | None, everything: Collection[str]) -> str:
    chosen = set(values or ())
    return "" if chosen >= set(everything) else ",".join(sorted(chosen))


@dataclass(frozen=True)
class FeedPage:
    items: list[OpportunityItem]
    next_cursor: str | None


@dataclass(frozen=True)
class Refresh:
    judged: int  # 다시 계산한 공고 수
    changed: int  # 라벨이 바뀐 공고 수(전에 판정이 있던 공고만 센다)


def display_status(status: str, missing_fields: Sequence[str]) -> str:
    """화면 라벨 4종. 판정 불가는 입력하면 바뀔 수 있으면 정보 필요, 아니면 원문 확인 필요다."""
    if status == "undetermined":
        return "missing_info" if missing_fields else "needs_review"
    return status


def encode_cursor(cursor: Cursor) -> str:
    data = {
        "q": cursor.scope,
        "v": cursor.value.isoformat() if cursor.value else None,
        "id": cursor.id,
    }
    raw = json.dumps(data, separators=(",", ":")).encode()
    return base64.urlsafe_b64encode(raw).decode().rstrip("=")


def decode_cursor(text: str) -> Cursor:
    """next_cursor로 준 값을 되돌린다. 모양이 틀리면 ValueError."""
    try:
        data = json.loads(base64.urlsafe_b64decode(text + "=" * (-len(text) % 4)))
        scope, value, ident = data["q"], data["v"], data["id"]
        if not isinstance(scope, str) or not isinstance(ident, str):
            raise ValueError(scope)
        moment = None if value is None else datetime.fromisoformat(value)
        if moment is not None and moment.tzinfo is None:
            raise ValueError(value)
        return Cursor(scope=scope, value=moment, id=str(uuid.UUID(ident)))
    except (binascii.Error, ValueError, KeyError, TypeError, UnicodeDecodeError) as exc:
        raise ValueError("잘못된 cursor") from exc

    async def refresh_judgments(
        self,
        user_id: str,
        *,
        now: datetime,
        force: bool = False,
        include_expired: bool = False,
        display_name: str | None = None,
    ) -> Refresh:
        """피드에 나올 공고(include_expired면 지난 공고까지)의 낡은 판정을 다시 계산해 저장한다.

        force면 그 공고를 모두 다시 판정하고 나머지 공고의 판정은 지운다.
        프로필 행이 없으면(첫 요청이 피드) display_name과 함께 만든다.
        """
        profile = Profile.from_row(await self._lock_profile(user_id, display_name))
        today = now.astimezone(KST).date()
        stale = await (
            await self.conn.execute(
                _stale_sql(_WITH_EXPIRED if include_expired else _ACTIVE),
                {
                    "uid": user_id,
                    "now": now,
                    "force": force,
                    "engine": ENGINE_VERSION,
                    "engine_error": ENGINE_ERROR_SUMMARY,
                    "today": today,
                },
            )
        ).fetchall()
        payload: list[dict[str, Any]] = []
        changed = 0
        if stale:
            departments = await self._departments()
            for item in stale:
                judged = _judge(item, profile, departments, today)
                payload.append(_payload(item, judged.stored))
                old = display_status(item["old_status"] or "", item["old_missing"] or ())
                if item["had_result"] and old != judged.label:
                    changed += 1
        await self._upsert(user_id, payload, now)
        if force:  # 다시 판정하지 않은 공고(마감·숨김·안 보임)의 판정은 지운다
            await self.conn.execute(
                "delete from eligibility_results"
                " where user_id = %s and opportunity_id <> all(%s::uuid[])",
                (user_id, [item["opportunity_id"] for item in payload]),
            )
        else:  # 요건 추출에 실패한 공고의 옛 판정은 지운다(판정하지 않는다)
            await self.conn.execute(
                "delete from eligibility_results e using opportunities o"
                " where e.user_id = %s and e.opportunity_id = o.id and o.extraction_run_id is null",
                (user_id,),
            )
        return Refresh(judged=len(payload), changed=changed)

        self,

        *,

        display_name: str | None = None,

            eligibility = DetailEligibility(
                status="undetermined",

        await self.conn.execute(_VIEW, (user_id, opportunity_id, now, now))
        names = {item["seq"]: item["file_name"] for item in row["attachments"]}

            uploaded_by_me=row["uploaded_by_me"],

    async def set_mark(
        self,
        user_id: str,
        opportunity_id: str,
        mark: str,
        *,
        now: datetime,
        display_name: str | None = None,
    ) -> datetime | None:
        """관심·관심 없음 표시(F-45). 상세를 열 수 있는 공고에만 붙인다. 아니면 None.

        공고마다 표시는 하나다. 다른 표시를 보내면 바꾼다. 프로필 행이 없으면(첫 요청) 만든다.
        피드처럼 프로필 행을 잠근다: 피드 응답 하나의 목록(my_mark)과 숫자(counts)가 어긋나지 않는다.
        """
        await self._lock_profile(user_id, display_name)
        params = {"uid": user_id, "oid": opportunity_id, "mark": mark, "now": now}
        if await (await self.conn.execute(_MARK_OPENABLE, params)).fetchone() is None:
            return None
        row = await (await self.conn.execute(_MARK_UPSERT, params)).fetchone()
        assert row is not None
        return row["marked_at"]

    async def clear_mark(self, user_id: str, opportunity_id: str) -> None:

        set_mark처럼 프로필 행을 잠근다. 프로필 행이 없으면 만들지 않는다(지울 표시도 없다).
        """
        await self.conn.execute(
            "select 1 from profiles where id = %s for no key update", (user_id,)
        )
        await self.conn.execute(
            "delete from opportunity_marks where user_id = %s and opportunity_id = %s",
            (user_id, opportunity_id),
        )

    async def feed_page(self, user_id: str, query: FeedQuery, *, now: datetime) -> FeedPage:
        params: dict[str, Any] = {
            "uid": user_id,
            "now": now,
            "new_since": now - timedelta(days=NEW_DAYS),
            "limit": query.limit + 1,
        }
        where = [_WITH_EXPIRED if query.include_expired else _ACTIVE, VISIBLE, _SHOWN]
        if not query.include_not_interested:
            where.append(_NOT_DISMISSED)
        if query.categories:
            where.append(" o.category::text = any(%(categories)s)")
            params["categories"] = list(query.categories)
        if query.source_types:
            where.append(" o.source_type::text = any(%(source_types)s)")
            params["source_types"] = list(query.source_types)
        outer = []
        if query.eligibility:
            outer.append("eff_status = any(%(eligibility)s)")
            params["eligibility"] = sorted(query.eligibility)
        if query.cursor:
            outer.append(_after(query.sort, query.cursor))
            params["cursor_value"], params["cursor_id"] = query.cursor.value, query.cursor.id
        sql = _feed_sql(
            " and".join(where),
            " where " + " and ".join(outer) if outer else "",
            _ORDER[query.sort],
        )
        rows = await (await self.conn.execute(sql, params)).fetchall()
        today = now.astimezone(KST).date()
        page = rows[: query.limit]
        next_cursor = None
        if len(rows) > query.limit:
            last = page[-1]
            value = last["deadline_at"] if query.sort == "deadline" else last["created_at"]
            cursor = Cursor(scope=query.scope(), value=value, id=str(last["id"]))
            next_cursor = encode_cursor(cursor)
        return FeedPage(items=[_item(row, today) for row in page], next_cursor=next_cursor)

    async def feed_counts(self, user_id: str, *, now: datetime) -> FeedCounts:
        """홈 요약 카드: 필터와 상관없이 지금 보이는 활성 공고 전체 기준."""
        row = await (
            await self.conn.execute(
                _COUNTS,
                {
                    "uid": user_id,
                    "now": now,
                    "new_since": now - timedelta(days=NEW_DAYS),
                    "today": now.astimezone(KST).date(),
                    "soon": SOON_DAYS,
                },
            )
        ).fetchone()
        assert row is not None
        return FeedCounts.model_validate(row)

    async def _lock_profile(self, user_id: str, display_name: str | None) -> dict[str, Any]:
        """프로필 행을 (없으면 만들고) 잠근 뒤 읽는다.

        같은 사용자의 판정은 한 번에 하나씩: 프로필 저장과 피드 읽기가 겹쳐도 옛 프로필로 덮어쓰지 않는다.
        no key update라서 이 사용자의 다른 행(이벤트·알림 등)이 profiles를 참조하며 넣는 것은 막지 않는다.
        """
        await self.conn.execute(
            "insert into profiles (id, display_name) values (%s, %s) on conflict do nothing",
            (user_id, display_name),
        )
        row = await (
            await self.conn.execute(
                "select * from profiles where id = %s for no key update", (user_id,)
            )
        ).fetchone()
        assert row is not None
        return row

    async def _upsert(self, user_id: str, payload: list[dict[str, Any]], now: datetime) -> None:
        """판정 여러 개를 한 문장으로 저장한다(_payload 모양)."""
        if payload:
            await self.conn.execute(
                _UPSERT,
                {"uid": user_id, "engine": ENGINE_VERSION, "now": now, "rows": Jsonb(payload)},
            )

    async def _departments(self) -> list[Department]:
        """판정에 쓰는 학과 목록. 목록에서 빠진(폐지·통합) 학과도 단과대학·계열을 알아야 해서 모두 읽는다."""
        rows = await (
            await self.conn.execute("select name, college, field_group from departments")
        ).fetchall()
        return [Department.from_row(row) for row in rows]


def _after(sort: Sort, cursor: Cursor) -> str:
    """정렬 순서(_ORDER)에서 cursor 다음에 오는 행. 값이 없는 행은 맨 뒤에 id 순으로 온다."""
    column, beyond = ("deadline_at", ">") if sort == "deadline" else ("created_at", "<")
    if cursor.value is None:
        return f"({column} is null and id {beyond} %(cursor_id)s)"
    return (
        f"({column} {beyond} %(cursor_value)s"
        f" or ({column} = %(cursor_value)s and id {beyond} %(cursor_id)s) or {column} is null)"
    )


def _item(row: dict[str, Any], today: date) -> OpportunityItem:
    deadline: datetime | None = row["deadline_at"]
    status: str = row["eff_status"]
    missing = list(row["eff_missing"] or [])
    return OpportunityItem(
        id=str(row["id"]),
        title=row["title"],
        organizer=row["organizer"],
        category=row["category"],
        source_type=row["source_type"],
        deadline_at=deadline.astimezone(KST) if deadline else None,
        d_day=(to_kst_date(deadline) - today).days if deadline else None,
        easy_summary=row["easy_summary"],
        eligibility=FeedEligibility(
            status=status,
            display_status=display_status(status, missing),
            summary=(row["reason_text"] or "") if row["judged"] else UNJUDGED_SUMMARY,
            missing_fields=missing,
        ),
        needs_review=bool(row["needs_review"]),
        uploaded_by_me=row["uploaded_by_me"],
        course_name=row["course_name"],
        prepared=row["prepared"],
        is_new=row["is_new"],
        my_mark=row["my_mark"],
    )


@dataclass(frozen=True)
class _Judged:
    stored: dict[str, Any]  # eligibility_results에 넣을 값(Judgment.storage_row 모양)
    label: str  # display_status
    judgment: Judgment | None  # 엔진이 오류를 냈으면 None
    requirements: tuple[Requirement, ...]
    basis_date: date | None


def _judge(
    item: dict[str, Any], profile: Profile, departments: list[Department], today: date
) -> _Judged:
    """공고 행 하나(requirements·eligibility_basis_date·deadline_at)를 판정한다.

    엔진 오류면 "판정하지 못함" 행을 돌려준다: 그 공고만 원문 확인 필요로 보인다.
    """
    basis: date | None = None
    try:
        requirements = tuple(Requirement.from_row(r) for r in item["requirements"])
        days = _basis_dates(item, today)
        basis = days[0]
        # 기준일이 둘이면(청년정책) 더 나은 쪽을 쓴다. 같으면 앞 날짜다(max는 처음 나온 것을 고른다)
        judgment = max(
            (
                check_eligibility(
                    list(requirements), profile, basis_date=day, departments=departments
                )
                for day in days
            ),
            key=lambda found: _RANK[found.status],
        )
        return _Judged(
            judgment.storage_row(),
            judgment.display_status,
            judgment,
            requirements,
            judgment.basis_date,
        )
    except Exception:
        logger.exception("판정하지 못한 공고: %s", item["id"])
        return _Judged(_engine_error_row(), "needs_review", None, (), basis)


_RANK = {"ineligible": 0, "undetermined": 1, "eligible": 2}


def _basis_dates(item: dict[str, Any], today: date) -> tuple[date, ...]:
    """판정 기준일(판정엔진_규칙.md 8장). 보통 하나다(공고 기준일 → 마감일 → 오늘).

    청년정책(온통청년)은 신청일 기준이 대부분이고 신청 기간이 몇 년인 정책도 있다. 그래서 신청할 수 있는 첫날
    (오늘, 신청 기간 전이면 시작일)과 마감일을 둘 다 보고 더 나은 결과를 쓴다. 나이 상한은 첫날에, 하한은
    마감일에 맞으면 그 사이 어느 날엔 신청할 수 있다. 신청 기간이 끝났으면 마감일 하나다."""
    if item["source_type"] != "youth_policy" or item["eligibility_basis_date"] is not None:
        return (resolve_basis_date(item["eligibility_basis_date"], item["deadline_at"], today),)
    start = item["apply_start_at"]
    first = max(today, to_kst_date(start)) if start is not None else today
    if item["deadline_at"] is None:
        return (first,)
    deadline = to_kst_date(item["deadline_at"])
    return (deadline,) if deadline <= first else (first, deadline)

def _detail_eligibility(
    judged: _Judged,
    profile: Profile,
    departments: list[Department],
    requirements_version: int,
    now: datetime,
) -> DetailEligibility:
    """상세의 판정표. 조건 문구는 엔진(describe)이 만들고, 내 값은 저장한 값과 같은 모양이다."""
    judgment = judged.judgment
    if judgment is None:  # 엔진 오류: 판정표 없이 원문 확인 필요
        return DetailEligibility(
            status="undetermined",
            display_status="needs_review",
            reason_text=ENGINE_ERROR_SUMMARY,
            basis_date=judged.basis_date,
            requirements_version=requirements_version,
            missing_fields=[],
            clauses=[],
            conditions=[],
            evaluated_at=now.astimezone(KST),
        )
    by_id = {requirement.id: requirement for requirement in judged.requirements}
    user_values = {
        result["requirement_id"]: result["user_value"]
        for result in judged.stored["condition_results"]
    }
    conditions = [
        Condition(
            **row,
            operator=by_id[row["requirement_id"]].operator,
            value=by_id[row["requirement_id"]].value,
            user_value=user_values[row["requirement_id"]],
        )

    ]
    return DetailEligibility(
        status=judgment.status,
        display_status=judgment.display_status,
        reason_text=judgment.reason_text,
        basis_date=judgment.basis_date,
        requirements_version=requirements_version,
        missing_fields=list(judgment.missing_fields),
        clauses=[Clause(**clause) for clause in clause_rows(judgment)],
        conditions=conditions,
        evaluated_at=now.astimezone(KST),
    )


def _step(step: dict[str, Any], names: dict[int, str]) -> ProcessStep:
    """처리 과정 한 줄(_DETAIL의 steps 행 하나). 첨부를 읽은 단계는 첨부 이름을 넣어 보인다.

    도구가 오류를 돌려준 호출(없는 첨부 번호 등)과 거절된 제출은 실행 로그에 succeeded로 남는다
    (에이전트는 오류를 모델에 돌려주고 계속 간다). 화면에는 실패로 보인다. 첨부 번호·위치는
    에이전트와 같은 규칙(whole)으로 읽는다. 읽기·토큰 상한에 닿아 코드가 시킨 제출(forced)은
    모델이 고른 단계가 아니라서 pipeline으로 보인다.
    """
    tool: str = step["tool"]
    again = "이어 " if _continued(step) else ""
    if tool in (READ_TEXT, READ_IMAGE):
        number = whole(step.get("attachment_no"))
        name = names.get(number) if number is not None else None
        target = f"첨부 '{name}'" if name else f"첨부 {number}번" if number else "첨부"
        how = "이미지로 " if tool == READ_IMAGE else ""
        label = f"{target} {how}{again}읽기"
    elif tool == FETCH_ORIGINAL:
        label = f"공고 원문 페이지 {again}읽기"
    elif tool == FETCH_YOUTH:
        label = "온통청년에서 정책 정보 받기"
    elif tool == BUILD_YOUTH:
        label = "온통청년 항목으로 지원 자격 정리"
    else:
        label = "지원 자격 정리" if tool == SUBMIT else tool
    failed = step.get("error") is True or (tool == SUBMIT and step.get("accepted") is False)
    chosen = tool in _AGENT_TOOLS and step.get("forced") is not True
    return ProcessStep(
        seq=step["seq"],
        tool=tool,
        label=label,
        status="failed" if failed else step["status"],
        latency_ms=step["latency_ms"],
        chosen_by="agent" if chosen else "pipeline",
        note=_line(step.get("reason")),
    )


def _continued(step: dict[str, Any]) -> bool:
    """앞에서 읽은 곳의 뒷부분을 읽은 호출. 도구가 실제로 읽은 위치를 보고, 오류면 요청한 위치를 본다.

    글자 읽기·원문 읽기는 시작 위치(offset)가 0보다 크면, Vision은 PDF를 2쪽부터 읽었으면 이어 읽기다.
    이미지는 한 장이라 이어 읽기가 없다.
    """
    if step["tool"] != READ_IMAGE:
        offset = whole(step.get("offset"))
        return offset is not None and offset > 0
    pages = step.get("pages")  # 읽은 PDF 쪽 "4–6/8". 이미지는 없다
    if isinstance(pages, str) and (first := _PAGES.match(pages)):
        return int(first.group(1)) > 1
    if step.get("error") is not True:
        return False  # 이미지를 읽었다
    start_page = whole(step.get("start_page"))
    return start_page is not None and start_page > 1


def _line(text: Any) -> str | None:
    """모델이 쓴 글(고른 이유, 원문 확인 필요 이유)을 화면용 한 줄로: 보이지 않는 문자(폭 없는 문자,
    글자 방향 제어)와 주소를 지우고 공백·줄바꿈을 한 칸으로 줄여 LINE_MAX_CHARS자까지. 남는 글이
    없으면 None이다.

    공고 글을 읽은 모델이 쓴 글이라, 공고 속 지시문이 링크를 끼워 넣지 못하게 쉬운 설명과 같은 규칙으로
    정리한다(app/extraction/validate.py). 저장된 값을 읽을 때 정리해서 예전 행에도 같이 적용된다.
    화면은 이 글을 일반 텍스트로 보여 준다(자동 링크·마크다운 없이).
    """
    if not isinstance(text, str):
        return None
    line = " ".join(_LINK.sub("", _INVISIBLE.sub("", text)).split())
    if len(line) > LINE_MAX_CHARS:
        line = line[: LINE_MAX_CHARS - 1].rstrip() + "…"
    return line or None


def _lines(texts: Sequence[Any] | None) -> list[str]:
    """여러 줄을 _line으로 정리한다. 빈 줄과 같은 줄은 빼고, REASONS_MAX줄이 넘으면 "외 N건"으로 줄인다."""
    lines = list(dict.fromkeys(line for text in texts or () if (line := _line(text))))
    if len(lines) > REASONS_MAX:
        return [*lines[:REASONS_MAX], f"외 {len(lines) - REASONS_MAX}건"]
    return lines


def _attachment(item: dict[str, Any]) -> AttachmentItem:
    if item["error"]:
        status = "failed"
    elif item["method"]:
        status = "succeeded"
    else:
        status = "skipped"  # 에이전트가 읽지 않은 첨부
    return AttachmentItem(
        id=str(item["id"]),
        file_name=item["file_name"],
        source_url=item["source_url"],
        extract_status=status,
    )


def _text(value: Any) -> str | None:
    return str(value) if value is not None else None
```

```python
결과는 따로 저장하지 않고 실행이 만든 행에서 다시 읽는다. 준비하기는 그 실행의 계획(prep_plans)·서류·할 일이다.

# 준비하기 단계 이름(화면의 처리 과정). 정해진 순서로 도는 단계라 chosen_by는 pipeline이다.
# 마감일 캘린더 등록은 준비하기 단계가 아니라 따로 부르는 API다(POST /calendar/events, F-32)
PREPARE_LABELS = {
    "get_document_guide": "필요 서류 확인",
    "build_prep_plan": "마감일에서 거꾸로 일정 짜기",
}
# 포스터 추출 단계 이름. Vision 한 번이라 단계도 하나다(app/posters/service.py)
POSTER_LABELS = {POSTER_TOOL: "포스터에서 글자·날짜 읽기"}

_CODED = re.compile(r"^([A-Z][A-Z_]+): (.+)$", re.S)  # agent_log.error_text의 "코드: 문구"
logger = logging.getLogger(__name__)


@dataclass(frozen=True)
class RunRow:
    id: str
    user_id: str | None
    trigger_type: str
    status: str
    started_at: datetime | None
    finished_at: datetime | None
    latency_ms: int | None
    error_message: str | None

    def error(self) -> RunError | None:

        if self.status != "failed":

def _label(tool_name: str) -> str:

    return PREPARE_LABELS.get(tool_name) or POSTER_LABELS.get(tool_name) or tool_name


class RunRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def run(self, run_id: str) -> RunRow | None:
        row = await (
            await self.conn.execute(
                "select id, user_id, trigger_type, status::text as status, started_at, finished_at,"
                " latency_ms, error_message from agent_runs where id = %s",
                (run_id,),
            )
        ).fetchone()
        if row is None:
            return None
        return RunRow(
            id=str(row["id"]),
            user_id=str(row["user_id"]) if row["user_id"] else None,
            trigger_type=row["trigger_type"],
            status=row["status"],
            started_at=_kst(row["started_at"]),
            finished_at=_kst(row["finished_at"]),
            latency_ms=row["latency_ms"],
            error_message=row["error_message"],
        )

    async def steps(self, run_id: str) -> list[ProcessStep]:
        rows = await (
            await self.conn.execute(
                "select seq, tool_name, status::text as status, latency_ms from tool_calls"
                " where run_id = %s order by seq, id",
                (run_id,),
            )
        ).fetchall()
        return [
            ProcessStep(
                seq=row["seq"],
                tool=row["tool_name"],
                label=_label(row["tool_name"]),
                status=row["status"],
                latency_ms=row["latency_ms"],
                chosen_by="pipeline",
                note=None,
            )
            for row in rows
        ]

    async def prepare_result(self, user_id: str, run_id: str) -> PrepareResult | None:
        """그 실행이 만든 내 계획. 없으면(지워짐) None."""
        plan = await (
            await self.conn.execute(
                "select id, opportunity_id from prep_plans where agent_run_id = %s and user_id = %s",
                (run_id, user_id),
            )
        ).fetchone()
        if plan is None:
            return None
        params: dict[str, Any] = {"plan": plan["id"], "oid": plan["opportunity_id"]}
        documents = await (
            await self.conn.execute(
                "select d.id::text as id, d.name, d.issuer, d.how_to, d.lead_days, d.effort_minutes,"
                " d.form_url, coalesce(d.is_required, true) as is_required,"
                " t.id::text as task_id, t.is_done"
                " from opportunity_documents d left join planner_tasks t"
                " on t.prep_plan_id = %(plan)s and t.document_id = d.id"
                " where d.opportunity_id = %(oid)s"
                " order by coalesce(d.is_required, true) desc, d.name, d.id",
                params,
            )
        ).fetchall()
        tasks = await (
            await self.conn.execute(
                "select id::text as id, title, due_date, document_id::text as document_id"
                " from planner_tasks where prep_plan_id = %(plan)s order by sort_order, due_date, id",
                params,
            )
        ).fetchall()
        return PrepareResult(
            prep_plan_id=str(plan["id"]),
            documents=[DocumentItem(**row) for row in documents],
            tasks=[PrepTask(**row) for row in tasks],
            # 마감일 캘린더는 따로 등록한다(POST /calendar/events). 준비하기 결과에는 담지 않는다
            calendar_event=None,
            calendar_error=None,
        )

    async def poster_result(self, user_id: str, run_id: str) -> PosterExtractResult | None:
        """그 실행이 만든 초안. 기록이 지워졌거나 모양이 달라졌으면 None이다."""
        row = await (
            await self.conn.execute(
                "select t.output from tool_calls t join agent_runs r on r.id = t.run_id"
                " where t.run_id = %s and r.user_id = %s and t.tool_name = %s"
                " order by t.seq desc, t.id desc limit 1",
                (run_id, user_id, POSTER_TOOL),
            )
        ).fetchone()
        output = row["output"] if row else None
        if not isinstance(output, dict) or "draft" not in output:
            return None
        try:
            draft = PosterDraft.model_validate(output["draft"])
        except ValidationError:
            logger.warning("포스터 초안 모양이 달라 읽지 못했어요: run %s", run_id)
            return None
        candidate = output.get("duplicate_candidate")
        duplicate = None
        if isinstance(candidate, dict):
            try:
                duplicate = DuplicateCandidate.model_validate(candidate)
            except ValidationError:
                duplicate = None
        return PosterExtractResult(draft=draft, duplicate_candidate=duplicate)
```

```python
from fastapi import APIRouter

from app.auth import CurrentUserDep

router = APIRouter(prefix="/runs", tags=["실행"])


@router.get("/{run_id}", response_model=RunView)
async def read_run(run_id: UUID, user: CurrentUserDep, repo: RunRepoDep) -> RunView:
    """실행 진행·결과(API 명세 11장). 본인 실행만 본다. 배치 실행은 403, 남의 실행·없는 실행은 404다.

    steps는 처리 과정(F-42)이고, 끝나면 result나 error(코드·문구)가 붙는다. result는 kind로 가린다:
    준비하기는 계획·서류·할 일(prepare), 포스터 추출은 공고 초안과 중복 후보(poster_extract)다.
    """
    run = await repo.run(str(run_id))
    if run is not None and run.user_id is None:
        raise ApiError(403, "FORBIDDEN", "이 실행은 볼 수 없어요.")
    if run is None or run.user_id != user.id:
        raise ApiError(404, "NOT_FOUND", "실행을 찾을 수 없어요.")
    result: RunResult | None = None
    if run.status == "succeeded" and run.trigger_type == "prepare":
        result = await repo.prepare_result(user.id, run.id)
    elif run.status == "succeeded" and run.trigger_type == "poster_upload":
        result = await repo.poster_result(user.id, run.id)
    return RunView(
        id=run.id,
        trigger_type=run.trigger_type,
        status=run.status,
        started_at=run.started_at,
        finished_at=run.finished_at,
        latency_ms=run.latency_ms,
        steps=await repo.steps(run.id),
        result=result,
        error=run.error(),
    )
```

```python
"""Supabase Storage 업로드 (F-13).

버킷은 비공개다(ERD 8장). 클라이언트는 버킷에 직접 닿지 못하고, 서버가 서비스 역할 키로만 올린다.
경로는 `<user_id>/<kind>/<file_id>.<확장자>`다.

- 올리기: POST {base}/object/{bucket}/{path} (본문은 파일 바이트 그대로)
- 받기: GET {base}/object/{bucket}/{path} (서버가 포스터를 모델에 넘길 때 쓴다)
- 지우기: DELETE {base}/object/{bucket}/{path}

서비스 역할 키는 DB 전체를 읽고 쓸 수 있는 값이라 응답·로그·오류 문구에 넣지 않는다. 내려받기는
나중에 API가 만드는 5분짜리 서명 URL로만 한다(포스터 추출에서 쓴다).
"""

from typing import Annotated
from urllib.parse import quote

import httpx
from fastapi import Depends

from app.config import Settings, get_settings

TIMEOUT_SECONDS = 60.0  # 20MB까지 올라온다


class StorageError(Exception):
    """저장소에 올리지 못했다. 설정이 비었을 때도 이 오류다(키·주소는 담지 않는다)."""


class SupabaseStorage:
    def __init__(self, *, base_url: str, bucket: str, service_key: str) -> None:
        self.base_url = base_url.rstrip("/")
        self.bucket = bucket
        self.service_key = service_key

    @property
    def ready(self) -> bool:
        """주소·버킷·키가 모두 있어야 올릴 수 있다."""
        return bool(self.base_url and self.bucket and self.service_key)

    def _url(self, path: str) -> str:
        quoted = quote(path, safe="/")
        return f"{self.base_url}/object/{quote(self.bucket, safe='')}/{quoted}"

    async def upload(self, path: str, data: bytes, content_type: str) -> None:
        await self._send("POST", path, content=data, content_type=content_type)

    async def download(self, path: str) -> bytes:
        """올려 둔 파일을 다시 받는다(포스터를 모델에 넘길 때). 없으면 StorageError다."""
        body = await self._send("GET", path)
        if not body:
            raise StorageError("파일 저장소에 그 파일이 없어요.")
        return body

    async def remove(self, path: str) -> None:
        """올려 둔 파일을 지운다(기록을 남기지 못했을 때 되돌리기용). 없으면 그냥 지나간다."""
        await self._send("DELETE", path, gone_is_ok=True)

    async def _send(
        self,
        method: str,
        path: str,
        *,
        content: bytes | None = None,
        content_type: str | None = None,
        gone_is_ok: bool = False,
    ) -> bytes:
        if not self.ready:
            raise StorageError("파일 저장소 설정이 비었어요(SUPABASE_SERVICE_ROLE_KEY).")
        headers = {"Authorization": f"Bearer {self.service_key}"}
        if content_type:
            headers["Content-Type"] = content_type
        try:
            async with httpx.AsyncClient(timeout=TIMEOUT_SECONDS) as client:
                response = await client.request(
                    method, self._url(path), content=content, headers=headers
                )
        except httpx.HTTPError as exc:
            raise StorageError(f"파일 저장소에 닿지 못했어요: {type(exc).__name__}") from exc
        if gone_is_ok and response.status_code in (404, 410):
            return b""
        if response.status_code >= 400:
            raise StorageError(f"파일 저장소가 요청을 거절했어요({response.status_code}).")
        return response.content


def get_storage(settings: Annotated[Settings, Depends(get_settings)]) -> SupabaseStorage:
    return SupabaseStorage(
        base_url=settings.storage_base_url,
        bucket=settings.supabase_storage_bucket,
        service_key=settings.supabase_service_role_key,
    )


StorageDep = Annotated[SupabaseStorage, Depends(get_storage)]
```

```python
"""준비하기 API 단위 테스트용 가짜 서비스·실행 저장소. 실제 실행·SQL은 test_prepare_db.py가 본다."""

import itertools
from datetime import date, datetime
from typing import Any

from app.prepare.service import Started
from app.repositories.prepare import PlanState
from app.repositories.runs import RunRow
from app.schemas.opportunities import OpportunityDetail, ProcessStep
from app.schemas.posters import PosterExtractResult
from app.schemas.prepare import PrepareResult

_ids = itertools.count(1)


def new_id() -> str:
    return f"00000000-0000-4000-8000-{next(_ids):012d}"


class FakePrepareService:
    def __init__(self) -> None:
        self.details: dict[str, OpportunityDetail] = {}  # 공고 id → 지금 판정한 상세. 없으면 404
        self.plans: dict[tuple[str, str], PlanState] = {}
        self.judge_calls: list[tuple[str, str, str | None]] = []
        self.resets: list[str] = []
        self.begins: list[tuple[str, str, date, date]] = []  # (user, 공고, 마감, 오늘)
        self.conflict: Started | None = None  # begin 사이에 다른 요청이 계획을 만든 경우

    async def judge(
        self, user_id: str, opportunity_id: str, *, now: datetime, display_name: str | None
    ) -> OpportunityDetail | None:
        self.judge_calls.append((user_id, opportunity_id, display_name))
        return self.details.get(opportunity_id)

    async def plan(self, user_id: str, opportunity_id: str) -> PlanState | None:
        return self.plans.get((user_id, opportunity_id))

    async def reset(self, plan: PlanState) -> None:
        self.resets.append(plan.id)
        self.plans = {key: value for key, value in self.plans.items() if value.id != plan.id}

    async def begin(
        self, user_id: str, opportunity_id: str, *, deadline: date, today: date
    ) -> Started:
        self.begins.append((user_id, opportunity_id, deadline, today))
        if self.conflict is not None:
            return self.conflict
        run_id = new_id()
        self.plans[(user_id, opportunity_id)] = PlanState(new_id(), run_id, "running", False)
        return Started(run_id, "running", created=True)


class FakeRunRepository:
    def __init__(self) -> None:
        self.runs: dict[str, RunRow] = {}
        self.steps_by_run: dict[str, list[ProcessStep]] = {}
        self.results: dict[str, PrepareResult] = {}
        self.poster_results: dict[str, PosterExtractResult] = {}
        self.result_calls: list[tuple[str, str]] = []

    async def run(self, run_id: str) -> RunRow | None:
        return self.runs.get(run_id)

    async def steps(self, run_id: str) -> list[ProcessStep]:
        return list(self.steps_by_run.get(run_id, []))

    async def prepare_result(self, user_id: str, run_id: str) -> PrepareResult | None:
        self.result_calls.append((user_id, run_id))
        return self.results.get(run_id)

    async def poster_result(self, user_id: str, run_id: str) -> PosterExtractResult | None:
        self.result_calls.append((user_id, run_id))
        return self.poster_results.get(run_id)


def run_row(**values: Any) -> RunRow:
    base: dict[str, Any] = {
        "id": new_id(),
        "user_id": None,
        "trigger_type": "prepare",
        "status": "running",
        "started_at": None,
        "finished_at": None,
        "latency_ms": None,
        "error_message": None,
    }
    return RunRow(**{**base, **values})
```

```tsx
    const changed = item.id in marks; // 이 화면에서 바꾼 적이 있는 공고(되돌릴 때 그 값으로 돌린다)
    const kept = marks[item.id];
    // 바뀐 뒤 이 탭에서 빠지는 카드면 그 자리로 초점을 옮긴다(보이는 카드 순서는 지금 쪽 목록 뒤에 펼친 묶음).
    // 쪽에 혼자 있던 카드면 앞 쪽으로 넘어가니 앞 쪽의 마지막 카드다
    const leaves = tab === "recommended" ? next === "not_interested" : next !== tab;
    const inGroup = !main.items.some((entry) => entry.id === item.id);
    const own = inGroup ? group : main;
    const index = (inGroup ? main.items.length : 0) + own.items.findIndex((entry) => entry.id === item.id);
    const alone = own.items.length === 1 && own.page > 1;
    const arrival = arrivalTab(before, next);
    const dataAtClick = request.data;
    if (leaves) cardFocus.current = { kind: "leave", index: alone ? index + PAGE_SIZE - 1 : index };
    setMarks((current) => ({ ...current, [item.id]: next }));
    if (arrival) setArrived((current) => ({ tab: arrival, id: (current?.id ?? 0) + 1 }));
    const goTo = arrival && arrival !== tab ? arrival : null;
    showToast(markToast(before, next, "home"), goTo ? { label: showTabLabel(goTo), onAction: () => openTab(goTo, item.id) } : undefined);
    setPending((current) => new Set(current).add(item.id));
    try {
      await setOpportunityMark(item.id, next);
      // 저장하는 사이 목록을 다시 받기 시작했으면 저장 전 값을 읽었을 수 있다. 숫자가 어긋나지 않게 한 번 더 받는다
      if (latestData.current !== dataAtClick) setReload((value) => value + 1);
    } catch (error) {
      // 되돌린다. 이 화면에서 바꾼 적이 없던 공고면 서버 값을 다시 따른다. 초점을 잃었으면(카드가 빠졌거나 안내 버튼이
      // 바뀌었다) 돌아온 카드에, 그 카드가 이 탭에 없으면 지금 탭 버튼에 둔다
      setMarks((current) => {
        const rest = { ...current };
        if (changed) rest[item.id] = kept;
        else delete rest[item.id];
        return rest;
      });
      cardFocus.current = { kind: "back", id: item.id };
      showToast(markError(error));
    } finally {
      setPending((current) => {
        const rest = new Set(current);
        rest.delete(item.id);
        return rest;
      });
    }
  };

  const card = (item: OpportunityItem) => (
    <OpportunityCard
      key={item.id}
      item={item}
      pending={pending.has(item.id)}
      found={found?.id === item.id}
      navigate={navigate}
      onMark={changeMark}
    />
  );

  return withToast(
    <>
      <Header title={`안녕하세요, ${me.display_name}님`} subtitle="나에게 맞는 기회와 이번 주 할 일을 한눈에 확인하세요." />
      <FeedSummary counts={shownCounts} selected={summaryFilter} onToggle={toggleSummary} />
      <section ref={listRef}>
        <div className="flex items-center justify-between gap-3">
          <FeedTabs
            tab={tab}
            counts={tabCounts}
            arrived={arrived}
            onArrivedEnd={(done) => setArrived((current) => (current?.id === done.id ? null : current))}
            onSelect={selectTab}
          />
          <select
            value={sort}
            onChange={(event) => setSort(event.target.value as NonNullable<FeedParams["sort"]>)}
            className="bg-transparent text-[13px] font-medium text-[#667085] outline-none"
          >
            <option value="deadline">마감 임박순</option>
            <option value="recent">최신순</option>
          </select>
        </div>
        <CategoryChips value={category} onChange={setCategory} />
        {empty ? (
          <EmptyBox {...empty} />
        ) : (
          // 쪽을 넘기면 그 목록의 첫 카드에 초점을 둔다(묶음 카드는 목록 카드 뒤에 있다)
          <FeedList
            listKey={listKey}
            main={main}
            group={group}
            groupTotal={ineligibleItems.length}
            showGroup={showIneligible}
            onToggleGroup={() => setShowIneligible((value) => !value)}
            onPage={(page) => {
              setPageAt({ key: listKey, page });
              cardFocus.current = { kind: "page", index: 0 };
            }}
            onGroupPage={(page) => {
              setGroupPageAt({ key: listKey, page });
              cardFocus.current = { kind: "page", index: main.items.length };
            }}
            card={card}
          />
        )}
      </section>
    </>,
  );
}
```
