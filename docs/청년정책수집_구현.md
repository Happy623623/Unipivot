# 청년정책 수집 — 온통청년 정책을 공고로 넣고 칸별 요건을 코드로 만든다

> 📝 기준: PRD v0.9 F-11 · `판정엔진_규칙.md` 8장(기준일)·11장(이 PR에서 더함) · API 명세 v0.4 11·12장 · ERD v0.9 5장 · 2026-10-13
>
> 함께 보는 파일: `학위과정_구현.md`, `로그인진단_구현.md`(둘 다 먼저 합친다), `판정엔진_규칙.md`. 모두 레포에 들어가 있어야 한다

온통청년 OPEN API로 청년정책을 받아 공고(opportunities)로 넣는다. 요건은 정책의 칸(연령·지역·학력·전공·특화·취업·결혼·소득)에서 코드로 만들고 LLM은 쓰지 않는다. 명령은 사람이 돌린다. 웹은 그대로이고, 홈의 "청년정책" 칩·판정표·원문 보기·AI 처리 과정이 그대로 쓰인다.
- **범위(10/13 결정):** 승인된 정책 중 신청 기간이 상시이거나 끝나지 않았고, 사업이 끝나지 않았고, 서울·인천·경기를 한 곳이라도 고른 정책(전국 포함)만 넣는다. 10/13에 받은 3,234건 중 410건이다.
- **서술형 조건(10/13 결정):** 추가 자격·참여 제한 글과 프로필에 없는 조건(취업 상태, 결혼, 연소득 금액, 특화 대상)은 기타 조건(원문 확인)이다. 그런 조건이 있는 정책은 "원문 확인 필요"로 보인다.
- **나이:** 청년정책은 마감일 하나로 나이를 따지지 않는다. 신청할 수 있는 첫날(오늘, 신청 기간 전이면 시작일)과 마감일을 둘 다 보고 맞는 쪽을 쓴다. 믿기 어려운 나이 값(상한 없이 34세 이상, 자녀 나이)은 원문 확인이다.
- **명령:** `uv run python -m app.youth.cli fetch --dry-run`(DB 없이 미리 보기), `uv run python -m app.youth.cli fetch`(넣기). 처음 넣을 때 1~3분, 그다음은 몇 초다. 키는 `api/.env`의 `YOUTH_API_KEY`다.

**규모와 확인:**
- 새 파일 13개(api 7개, 테스트 6개), 바꾸는 파일 6개(api 4개, 테스트 2개). DB 스키마와 웹은 바뀌지 않는다.
- api 테스트 99개를 더했다(DB 테스트 8개 포함). Linux `470 passed, 43 skipped`, DB를 붙이면 `513 passed`다. 새 동작을 하나씩 되돌리는 시험 119가지가 모두 테스트에 걸렸다.
- 10/13에 받은 정책 3,234건으로 미리 보기·넣기·다시 넣기·일주일 뒤를 돌렸고, DB 왕복에 10ms를 넣어 시간을 쟀다. 실제 모드 웹으로 16단계를 확인했다.
- 검토 에이전트 2개가 차례로 봤다. 지원할 수 있는 학생을 "지원 어려움"으로 보던 경우 6가지를 포함해 지적 14가지를 고쳤다.

### 명령 출력 읽는 법

| 출력 | 뜻 | 할 일 |
| --- | --- | --- |
| `YOUTH_API_KEY가 없어요. api/.env에 온통청년 OPEN API 인증키를 넣어 주세요` | 키가 비었다 | 아래 "합친 뒤 처음 넣기"대로 키를 넣는다 |
| `온통청년 API 키가 맞지 않아요(HTTP 403·e001). api/.env의 YOUTH_API_KEY를 확인하세요` | 키가 틀렸다 | 마이페이지의 인증키와 맞춘다(앞뒤 공백·따옴표 없이) |
| `온통청년에서 정책 목록을 받지 못했어요(첫 쪽이 두 번 실패)` | 온통청년에 닿지 못했다 | 인터넷 연결을 보고 잠시 뒤 다시 돌린다 |
| `읽지 못해 건너뛴 정책 N건(순번 […])` | 몇 건을 받지 못했다. 이번에는 목록에서 사라진 정책을 숨기지 않는다 | 다음 실행에 다시 받는다 |
| `끝까지 받지 못했어요: …`(끝 코드 1) | 두 쪽 연속 실패, `온통청년이 응답하지 않음(연속 12번 실패, N쪽)`, 호출 한도. 받은 정책은 넣었다 | 잠시 뒤 다시 돌린다 |
| `목록을 빠짐없이 받지 못해 목록에서 사라진 정책은 숨기지 않았어요` | 위 둘 중 하나가 있었다 | 없음 |
| `목록에서 한 번에 N건이 사라져 숨기지 않았어요. …` | 한 번에 많이 사라졌다 | 온통청년에서 정말 내려갔으면 `fetch --hide-gone`으로 다시 돌린다 |
| `DB에 연결하지 못했어요: …` | DB에 닿지 못했다 | `api/.env`의 `DATABASE_URL`과 네트워크를 본다 |

#### `api/app/youth/client.py`

```python
"""온통청년 청년정책 API(getPlcy) 클라이언트 (PRD F-11, 도구 fetch_youth_policies).

- 요청: GET https://www.youthcenter.go.kr/go/ythip/getPlcy?apiKeyNm=…&rtnType=json&pageNum=…&pageSize=…
- 응답: result.youthPolicyList(정책), result.pagging.totCount(전체 건수). 등록일 최신순이다(10/13 확인).
- 키(YOUTH_API_KEY)는 요청 주소에만 넣는다. 오류 문구·실행 로그·tool_calls에는 넣지 않는다.
- 쪽(100건)이 5xx·연결 오류·JSON 아닌 응답이면 잠시 뒤 한 번 더 받는다(10/13 1차에서 16쪽이 500이었고
  2차에서는 됐다). 그래도 실패하면 10건씩, 그래도 실패한 묶음은 1건씩 나눠 받아 읽지 못한 정책만 건너뛴다.
  첫 쪽도 같다(전체 건수는 처음 받은 묶음에서 안다). 10건 묶음이 앞의 둘 다 실패하면 그 쪽은 통째로
  실패한 것으로 보고, 첫 쪽이 그러면 멈춘다.
- 두 쪽 연속으로 통째로 실패하거나, 받기가 연속 OUTAGE_FAILURES번 실패하면(온통청년이 멈춤) 멈춘다. 키가
  틀리면(403 e001) 바로 멈춘다. 호출은 max_calls번까지다.
- 전체 건수가 0이거나 받는 동안 바뀌면 빠짐없이 받은 것으로 보지 않는다(목록에서 사라진 정책을 숨기지 않는다).
"""

import asyncio
import time
from dataclasses import dataclass
from typing import Any

import httpx

from app.logging_redact import redact

BASE_URL = "https://www.youthcenter.go.kr"
POLICY_PATH = "/go/ythip/getPlcy"
PAGE_SIZE = 100
SMALL_PAGE = 10
USER_AGENT = "UNIPIVOT-bot/0.3 (student capstone project)"
SHAPE_ERROR = "온통청년 응답 모양이 달라요(result.youthPolicyList·result.pagging.totCount)"
FIRST_PAGE_ERROR = "온통청년에서 정책 목록을 받지 못했어요(첫 쪽이 두 번 실패)"
OUTAGE_FAILURES = 12  # 받기가 연속으로 이만큼 실패하면 멈춘다(응답 없음 30초씩이면 6분)


class YouthApiError(Exception):
    """온통청년 API를 쓸 수 없음. 메시지는 키 없이 사람에게 보여도 되는 한 줄이다."""


class _Retry(Exception):
    """잠깐 실패(5xx, 연결 오류, JSON 아닌 응답). 다시 받으면 될 수 있다."""


class _CallLimit(Exception):
    """호출 한도(max_calls)에 닿음."""


class _Outage(Exception):
    """받기가 연속 OUTAGE_FAILURES번 실패함."""


@dataclass(frozen=True)
class FetchResult:
    policies: tuple[dict[str, Any], ...]
    total: int  # 처음 받은 묶음의 totCount
    calls: int
    skipped: tuple[int, ...]  # 읽지 못하고 건너뛴 순번(0부터)
    stopped: str | None  # 끝까지 받지 못한 이유
    total_changed: bool  # 받는 동안 전체 건수가 바뀜(쪽이 밀려 빠진 정책이 있을 수 있다)
    seconds: float

    @property
    def complete(self) -> bool:
        """목록을 빠짐없이 받았다. 이때만 목록에서 사라진 정책을 숨긴다. 0건이면 아니다."""
        return (
            self.total > 0
            and self.stopped is None
            and not self.skipped
            and not self.total_changed
            and len(self.policies) >= self.total
        )

    def summary(self) -> dict[str, Any]:
        """실행 로그(tool_calls.output)에 남기는 값."""
        return {
            "total": self.total,
            "fetched": len(self.policies),
            "calls": self.calls,
            "skipped": list(self.skipped[:50]),
            "stopped": self.stopped,
            "total_changed": self.total_changed,
            "complete": self.complete,
            "seconds": round(self.seconds, 1),
        }


class YouthPolicyClient:
    def __init__(
        self,
        api_key: str,
        *,
        http: httpx.AsyncClient | None = None,
        base_url: str = BASE_URL,
        retry_delay: float = 2.0,
        page_delay: float = 0.2,
        max_calls: int = 600,
    ) -> None:
        if not api_key.strip():
            raise YouthApiError("YOUTH_API_KEY가 비어 있어요(api/.env)")
        self._key = api_key.strip()
        self._http = http or httpx.AsyncClient(timeout=30)
        self._url = base_url.rstrip("/") + POLICY_PATH
        self._retry_delay = retry_delay
        self._page_delay = page_delay
        self._max_calls = max_calls
        self.calls = 0
        self._totals: set[int] = set()  # 응답마다 받은 totCount
        self._failures = 0  # 연속으로 실패한 받기

    async def aclose(self) -> None:
        await self._http.aclose()

    async def fetch_all(self) -> FetchResult:
        started = time.monotonic()
        self._totals = set()
        self._failures = 0
        found: dict[str, dict[str, Any]] = {}
        skipped: list[int] = []
        stopped: str | None = None
        total: int | None = None
        whole_failures = 0
        num = 1
        try:
            while total is None or (num - 1) * PAGE_SIZE < total:
                page = await self._page(num, PAGE_SIZE)
                if page is not None:
                    _add(found, page[0])
                    total = page[1] if total is None else total
                    whole_failures = 0
                    num += 1
                    continue
                total, failed, whole = await self._split(num, total, found)
                if total is None:
                    raise YouthApiError(FIRST_PAGE_ERROR)
                if whole:  # 받은 묶음이 하나도 없음
                    whole_failures += 1
                    if whole_failures >= 2:
                        stopped = f"{num - 1}~{num}쪽을 받지 못함"
                        break
                    skipped.extend(range((num - 1) * PAGE_SIZE, min(num * PAGE_SIZE, total)))
                    num += 1
                    continue
                whole_failures = 0
                for small in failed:
                    for offset in range((small - 1) * SMALL_PAGE, min(small * SMALL_PAGE, total)):
                        single = await self._page(offset + 1, 1)
                        if single is None:
                            skipped.append(offset)
                        else:
                            _add(found, single[0])
                num += 1
        except _CallLimit:
            stopped = f"호출 {self._max_calls}회 한도에 닿음({num}쪽)"
        except _Outage:
            stopped = f"온통청년이 응답하지 않음(연속 {OUTAGE_FAILURES}번 실패, {num}쪽)"
        return FetchResult(
            policies=tuple(found.values()),
            total=total or 0,
            calls=self.calls,
            skipped=tuple(skipped),
            stopped=stopped,
            total_changed=len(self._totals) > 1,
            seconds=time.monotonic() - started,
        )

    async def _split(
        self, num: int, total: int | None, found: dict[str, dict[str, Any]]
    ) -> tuple[int | None, list[int], bool]:
        """실패한 100건 쪽을 10건씩 받는다. (전체 건수, 실패한 10건 쪽 번호, 통째로 실패).

        전체 건수를 모르면(첫 쪽) 처음 받은 묶음에서 안다. 앞의 두 묶음이 다 실패하면 그 쪽은 통째로 실패한
        것으로 보고 나머지 묶음은 받지 않는다(온통청년이 멈춘 경우 오래 걸리지 않게)."""
        failed: list[int] = []
        got = False
        first = (num - 1) * (PAGE_SIZE // SMALL_PAGE) + 1
        for small in range(first, first + PAGE_SIZE // SMALL_PAGE):
            if total is not None and (small - 1) * SMALL_PAGE >= total:
                break
            if not got and len(failed) >= 2:
                break
            page = await self._page(small, SMALL_PAGE)
            if page is None:
                failed.append(small)
            else:
                got = True
                _add(found, page[0])
                total = page[1] if total is None else total
        return total, failed, not got

    async def _page(self, num: int, size: int) -> tuple[list[dict[str, Any]], int] | None:
        """(정책, totCount). 잠깐 실패면 한 번 더 받고, 그래도 실패하면 None이다."""
        for attempt in range(2):
            if attempt:
                await asyncio.sleep(self._retry_delay)
            try:
                page = await self._get(num, size)
            except _Retry:
                self._failures += 1
                continue
            self._failures = 0
            return page
        return None

    async def _get(self, num: int, size: int) -> tuple[list[dict[str, Any]], int]:
        if self.calls >= self._max_calls:
            raise _CallLimit
        if self._failures >= OUTAGE_FAILURES:
            raise _Outage
        if self.calls:
            await asyncio.sleep(self._page_delay)
        self.calls += 1
        params = {"apiKeyNm": self._key, "rtnType": "json", "pageNum": num, "pageSize": size}
        try:
            response = await self._http.get(
                self._url, params=params, headers={"User-Agent": USER_AGENT}
            )
        except httpx.HTTPError:
            raise _Retry from None  # 오류 문구에 요청 주소(키)가 들어갈 수 있어 이어 붙이지 않는다
        try:
            data = response.json()
        except ValueError:
            data = None
        bad_key = isinstance(data, dict) and data.get("errorCode") == "e001"
        if bad_key or response.status_code in (401, 403):
            raise YouthApiError(
                "온통청년 API 키가 맞지 않아요(HTTP 403·e001). api/.env의 YOUTH_API_KEY를 확인하세요"
            )
        if response.status_code >= 500:
            raise _Retry
        if response.status_code != 200:
            raise YouthApiError(f"온통청년이 요청을 받지 않았어요(HTTP {response.status_code})")
        if data is None:
            raise _Retry  # 200인데 JSON이 아님(점검 화면 등)
        if not isinstance(data, dict):
            raise YouthApiError(SHAPE_ERROR)
        if str(data.get("resultCode")) != "200":
            raise YouthApiError(f"온통청년 응답 오류: {data.get('resultCode')} {self._safe(data)}")
        result = data.get("result")
        items = result.get("youthPolicyList") if isinstance(result, dict) else None
        paging = result.get("pagging") if isinstance(result, dict) else None
        total = paging.get("totCount") if isinstance(paging, dict) else None
        if not isinstance(items, list) or not isinstance(total, int):
            raise YouthApiError(SHAPE_ERROR)
        self._totals.add(total)
        return [item for item in items if isinstance(item, dict) and item.get("plcyNo")], total

    def _safe(self, data: dict[str, Any]) -> str:
        """서버가 준 오류 문구. 요청 값을 되돌려 줄 수도 있어 키를 지우고 100자로 자른다."""
        message = " ".join(str(data.get("resultMessage") or "").split())
        return redact(message.replace(self._key, "[REDACTED]"))[:100].strip()
```

```python
def _income(policy: Mapping[str, Any]) -> list[Condition]:
    """소득. 연소득 금액(만 원)은 프로필에 없고, 기타는 글(earnEtcCn)이라 둘 다 원문 확인이다."""
    code = _text(policy.get("earnCndSeCd"))
    if code in (None, INCOME_ANY):
        return []
    note = _meaningful(_INCOME_LABEL.sub("", _text(policy.get("earnEtcCn")) or ""))
    if code == INCOME_YEARLY:
        low, high = _whole(policy.get("earnMinAmt")), _whole(policy.get("earnMaxAmt"))
        parts = [f"{low:,}만 원 이상"] if low > 1 else []
        parts += [f"{high:,}만 원 이하"] if high > 0 else []
        text = "연소득 " + " ".join(parts) if parts else "연소득 조건이 있음"
        text += f" ({note})" if note else ""
    else:
        text = f"소득: {note}" if note else "소득 조건이 있음"
    return [_other(text, f"온통청년 {text}")]

    text = _meaningful(policy.get(key))
    return [_other(f"{name}: {text}", f"온통청년 {name}: {text}")] if text else []


def _other(text: str, evidence: str) -> Condition:
    """기타 조건(원문 확인). 글이 길면 앞부분만 쓰고 전체는 근거에 둔다."""
    if len(text) > TEXT_MAX:
        evidence = f"온통청년 {text}"
    return Condition(
        "other", "eq", {"text": _cut(text, TEXT_MAX)}, None, _cut(evidence, EVIDENCE_MAX)
    )


def _drafts(clauses: Iterable[list[Condition]]) -> list[RequirementDraft]:
    drafts = []
    for clause_no, clause in enumerate(clauses, 1):
        for condition in clause:
            drafts.append(
                RequirementDraft(
                    clause_no=clause_no,
                    field=condition.field,
                    operator=condition.operator,
                    value=condition.value,
                    basis=condition.basis,
                    evidence_text=condition.evidence,
                    is_ambiguous=condition.ambiguous,
                )
            )
    return drafts


def _checked(drafts: list[RequirementDraft]) -> tuple[tuple[RequirementDraft, ...], bool]:
    """판정 엔진이 받을 수 있는 모양인지 본다(요건 추출과 같은 검사). 아니면 그 조건만 모호한 기타 조건으로 바꾼다.
    정책 자료가 틀린 경우다(예: 최소 나이가 최대 나이보다 큼)."""
    checked, broken = [], False
    for draft in drafts:
        requirement = Requirement(
            id="draft",
            clause_no=draft.clause_no,
            field=draft.field,
            operator=draft.operator,
            value=draft.value,
            basis=draft.basis,
        )
        if requirement_problem(requirement) is None:
            checked.append(draft)
            continue
        broken = True
        text = _cut(draft.evidence_text or "원문 확인 필요", TEXT_MAX)
        checked.append(
            replace(
                draft,
                field="other",
                operator="eq",
                value={"text": text},
                basis=None,
                is_ambiguous=True,
            )
        )
    return tuple(checked), broken


def _choices(policy: Mapping[str, Any], key: str) -> list[str]:
    """쉼표로 나눈 코드. 제한없음 코드가 있거나 모든 코드를 골랐으면 조건이 없다."""
    codes = _codes(policy.get(key))
    if not codes or NO_LIMIT[key] in codes or set(_NAMES[key]) <= set(codes):
        return []
    return codes


def _codes(value: Any) -> list[str]:
    return list(dict.fromkeys(code.strip() for code in str(value or "").split(",") if code.strip()))


def _raw_text(policy: Mapping[str, Any]) -> str:
    """공고 원문(opportunities.raw_text). 칸마다 "이름: 내용"이고, 내용의 줄바꿈은 둔다."""
    sections = []
    for key, name in _RAW_SECTIONS:
        if _meaningful(policy.get(key)):
            lines = (" ".join(line.split()) for line in str(policy[key]).splitlines())
            sections.append(f"{name}: " + "\n".join(line for line in lines if line))
    return "\n".join(sections)


def _meaningful(value: Any) -> str | None:
    """빈 값·"-"·"해당없음" 같은 글은 None이다. 공백·줄바꿈은 한 칸으로 줄인다."""
    text = _text(value)
    if text is None or text.lower() in _TRIVIAL or not re.search(r"[0-9A-Za-z가-힣]", text):
        return None
    return text


def _text(value: Any) -> str | None:
    text = " ".join(str(value).split()) if value is not None else ""
    return text or None


def _cut(text: str | None, limit: int) -> str | None:
    if text is None or len(text) <= limit:
        return text
    return text[: limit - 1].rstrip() + "…"


def _whole(value: Any) -> int:
    try:
        return int(str(value).strip())
    except (TypeError, ValueError):
        return 0


def _day(value: Any) -> date | None:
    text = str(value or "").strip()
    if not re.fullmatch(r"\d{8}", text):
        return None
    try:
        return date(int(text[:4]), int(text[4:6]), int(text[6:]))
    except ValueError:
        return None


def _hash(values: Mapping[str, Any]) -> str:
    def plain(item: Any) -> Any:
        if isinstance(item, datetime):
            return item.isoformat()
        if isinstance(item, RequirementDraft):
            return asdict(item)
        if isinstance(item, tuple | list):
            return [plain(part) for part in item]
        return item

    text = json.dumps({key: plain(item) for key, item in values.items()}, ensure_ascii=False)
    return hashlib.sha256(text.encode()).hexdigest()
```

```python
"""온통청년 지역 코드(zipCd) → 판정 엔진의 거주지역 조건 (판정엔진_규칙.md 11장).

zipCd는 법정동 코드 앞 5자리(시군구) 목록이다. 코드표는 region_codes.py다.
- 끝 지역: 지금 있는 시군구 중 아래에 구를 두지 않은 곳(구가 있는 시는 그 구). 시 코드(안산시)는 그 아래 구를
  모두 고른 것으로 본다.
- 끝 지역을 모두 고른 정책은 전국이라 거주지역 조건을 만들지 않는다.
- 시도의 끝 지역을 모두 고르면 시도 이름("경기도"), 일부면 시군구 이름("경기도 안산시 단원구")이다.
  한 시의 구를 모두 고르면 시 이름으로 줄인다("경기도 안산시").
- 판정할 수 없는 곳은 같은 묶음의 기타 조건(원문 확인)으로 둔다. 그곳에 사는 학생은 지원 어려움이 아니라
  원문 확인 필요가 된다.
  - 판정 엔진이 모르는 시도(2026-07 출범한 전남광주통합특별시). 네 곳 이상이면 "전남광주통합특별시(광양시
    빼고)", "전남광주통합특별시 중 12곳"처럼 줄여 쓴다
  - 없어진 코드(2026-07 개편 전 인천 중구·동구·서구 등)와 코드표에 없는 코드
  - 시도의 끝 지역을 5곳 이상 고르고 한두 곳만 빠뜨린 경우의 빠진 곳(정책 등록 때 코드가 덜 옮겨진 경우가 많다)
- 2026-07-01 인천 개편 보정: 7월 전에 등록한 정책 중 옛 중구·서구를 제물포구·검단구로만 옮긴 정책이 많다
  (10/13 받은 3234건 중 527건). 7월 전 정책이 제물포구(검단구)를 고르고 영종구(서해구)를 빠뜨렸으면, 인천의
  나머지를 모두 골랐을 때는 영종구(서해구)도 고른 것으로 보고, 아니면 원문 확인으로 둔다.
"""

from __future__ import annotations

from collections.abc import Iterable
from dataclasses import dataclass
from datetime import date
from functools import cache

from app.eligibility.regions import normalize_sido
from app.youth.region_codes import ROWS

CAPITAL = ("11", "28", "41")  # 서울·인천·경기(코드 앞 2자리)
_SPLIT_DATE = date(2026, 7, 1)
_SPLITS = {"28125": "28155", "28290": "28275"}  # 제물포구 → 영종구, 검단구 → 서해구
_NEAR_MISSING = 2  # 빠진 끝 지역이 이만큼 이하이고
_NEAR_COVERED = 5  # 고른 끝 지역이 이만큼 이상이면 빠진 곳은 원문 확인
_FEW = 3  # 모르는 시도에서 고른 곳(빠진 곳)이 이만큼 이하면 이름을 쓰고, 많으면 줄여 쓴다


@dataclass(frozen=True)
class RegionCondition:
    values: tuple[str, ...]  # 거주지역 in 값(판정할 수 있는 이름)
    uncertain: tuple[str, ...]  # 판정할 수 없는 곳. 기타 조건(원문 확인)이 된다


class RegionTable:
    def __init__(self, rows: Iterable[tuple[str, str, bool]]) -> None:
        self.names: dict[str, str] = {}
        self.current: set[str] = set()
        for code, name, exists in rows:
            self.names[code] = name
            if exists:
                self.current.add(code)
        self.children: dict[str, frozenset[str]] = {}
        for parent in self.current:
            prefix = self.names[parent] + " "
            kids = frozenset(code for code in self.current if self.names[code].startswith(prefix))
            if kids:
                self.children[parent] = kids
        self.leaves = frozenset(code for code in self.current if code not in self.children)
        by_sido: dict[str, set[str]] = {}
        for code in self.leaves:
            by_sido.setdefault(code[:2], set()).add(code)
        self.by_sido = {sido: frozenset(codes) for sido, codes in sorted(by_sido.items())}

    def covers_capital(self, codes: Iterable[str]) -> bool:
        """서울·인천·경기를 한 곳이라도 고른 정책(전국 포함). 없어진 코드도 센다."""
        return any(code.startswith(CAPITAL) for code in codes)

    def condition(
        self, codes: Iterable[str], registered_on: date | None = None
    ) -> RegionCondition | None:
        """거주지역 조건. 전국이거나 코드가 없으면 None이다."""
        given = sorted({code.strip() for code in codes if code and code.strip()})
        if not given:
            return None
        covered: set[str] = set()
        for code in given:
            covered |= self._leaves_under(code)
        maybe: set[str] = set()
        if registered_on is not None and registered_on < _SPLIT_DATE:
            for source, split in _SPLITS.items():
                if source in covered and split not in covered and split in self.leaves:
                    maybe.add(split)
        if self.leaves <= covered | maybe:
            return None
        values: list[str] = []
        uncertain: list[str] = []
        stale = [code for code in given if code in self.names and code not in self.current]
        for leaves in self.by_sido.values():
            hit = covered & leaves
            near = maybe & leaves
            if not hit and not near:
                continue
            sido_name = self.names[min(leaves)].split()[0]
            if not normalize_sido(sido_name):
                uncertain.append(self._unknown_sido(sido_name, hit | near, leaves))
                continue
            if hit | near == leaves:
                values.append(sido_name)
                continue
            values.extend(self._collapsed(hit))
            uncertain.extend(self.names[code] for code in sorted(near))
            missing = leaves - hit - near
            if len(missing) <= _NEAR_MISSING and len(hit) >= _NEAR_COVERED:
                uncertain.extend(self.names[code] for code in sorted(missing))
        uncertain.extend(f"{self.names[code]}(없어진 지역)" for code in stale)
        uncertain.extend(f"지역 코드 {code}" for code in given if code not in self.names)
        return RegionCondition(tuple(dict.fromkeys(values)), tuple(dict.fromkeys(uncertain)))

    def _unknown_sido(self, sido_name: str, chosen: set[str], leaves: frozenset[str]) -> str:
        """판정 엔진이 모르는 시도에서 고른 곳(원문 확인). 여러 곳이면 이름을 다 늘어놓지 않고 줄인다."""
        if chosen == leaves:
            return sido_name
        names = self._collapsed(chosen)
        if len(names) <= _FEW:
            return ", ".join(names)
        missing = sorted(leaves - chosen)
        if len(missing) <= _FEW:
            short = ", ".join(self.names[code].removeprefix(sido_name + " ") for code in missing)
            return f"{sido_name}({short} 빼고)"
        return f"{sido_name} 중 {len(chosen)}곳"

    def _leaves_under(self, code: str) -> set[str]:
        if code in self.leaves:
            return {code}
        return set(self.children.get(code, frozenset()) & self.leaves)

    def _collapsed(self, hit: set[str]) -> list[str]:
        """고른 끝 지역의 이름. 한 시의 구를 모두 골랐으면 시 이름 하나로 줄인다."""
        named: dict[str, str] = {}
        done: set[str] = set()
        for parent, kids in self.children.items():
            leaves = kids & self.leaves
            if leaves and leaves <= hit:
                named[parent] = self.names[parent]
                done |= leaves
        named.update({code: self.names[code] for code in hit - done})
        return [named[code] for code in sorted(named)]


def parse_rows(text: str) -> list[tuple[str, str, bool]]:
    rows = []
    for line in text.splitlines():
        if line.strip():
            code, name, exists = line.split("|")
            rows.append((code, name, exists == "1"))
    return rows


@cache
def region_table() -> RegionTable:
    return RegionTable(parse_rows(ROWS))
```

```python
"""온통청년 정책을 공고로 넣는다 (PRD F-11). 수집 한 번이 실행 하나(agent_runs.trigger_type = batch_crawl)다.

실행의 도구 호출은 둘이다. 넣은 공고의 extraction_run_id가 이 실행이라 공고 상세의 처리 과정에 그대로 보인다.
1. fetch_youth_policies: 온통청년에서 정책 목록을 끝까지 받는다(client.py)
2. build_youth_requirements: 가져올 정책을 고르고 요건을 만들어 저장한다(convert.py)

정책마다 한 트랜잭션이다.
- 새 정책·바뀐 정책(변환 결과의 content_hash가 다름): 공고 행을 넣거나 고치고 요건을 바꾼다(save_extraction).
  요건이 바뀌면 requirements_version이 오르고, 판정은 피드를 읽을 때 다시 계산된다.
- 같은 정책: 고치지 않는다. 조회수처럼 변환에 안 쓰는 칸만 바뀐 정책이다. 넣은 정책의 content_hash·상태를
  먼저 한 번에 읽어, 같고 활성인 정책은 DB에 다시 가지 않는다(원격 DB에서 정책마다 오가면 느리다).
- 가져온 정책이 숨김·만료였으면 활성으로 돌린다(만료는 마감이 지나지 않았을 때만). 상시 정책이 마감 코드로
  바뀌었다가 다시 상시가 되면 변환 결과가 전과 같아서, 같은 정책이어도 돌린다.
- 이미 넣은 정책이 범위를 벗어나면 마감·사업 종료는 만료, 수도권 밖·승인 안 됨은 숨김으로 바꾼다.
- 목록을 빠짐없이 받았을 때만 목록에서 사라진 정책을 숨긴다. 한 번에 활성 공고의 GONE_SHARE(최소 GONE_MIN건)
  넘게 사라졌으면 온통청년 목록이 덜 온 것일 수 있어 숨기지 않고 수만 남긴다(gone_kept). 온통청년에서 정말
  내려간 정책이면 hide_gone(명령의 --hide-gone)으로 숨긴다.
"""

from collections import Counter
from dataclasses import dataclass, field
from datetime import date
from typing import Literal

from psycopg import AsyncConnection

from app.agent_log import agent_run
from app.extraction.models import ExtractionResult
from app.extraction.store import save_extraction
from app.youth import BUILD_TOOL, FETCH_TOOL
from app.youth.client import BASE_URL, FetchResult, YouthPolicyClient
from app.youth.convert import PolicyRecord, Skip, convert
from app.youth.regions import region_table

SOURCE_TYPE = "youth_policy"
SOURCE_NAME = "온통청년"
SCOPE = "마감 전·상시, 전국+수도권"
GONE_MIN = 20
GONE_SHARE = 0.2

Saved = Literal["new", "updated", "unchanged"]


@dataclass
class CollectResult:
    run_id: str
    fetch: FetchResult
    counts: Counter[str] = field(default_factory=Counter)  # new·updated·unchanged·expired·hidden
    skips: Counter[str] = field(default_factory=Counter)  # 가져오지 않은 이유별 정책 수
    gone_kept: int = 0  # 목록에서 너무 많이 사라져 숨기지 않은 정책 수


async def ensure_source(conn: AsyncConnection) -> str:
    """sources의 온통청년 행. 없으면 만든다."""
    row = await (
        await conn.execute(
            "select id from sources where type = %s and base_url = %s order by id limit 1",
            (SOURCE_TYPE, BASE_URL),
        )
    ).fetchone()
    if row is None:
        row = await (
            await conn.execute(
                "insert into sources (type, name, base_url) values (%s, %s, %s) returning id",
                (SOURCE_TYPE, SOURCE_NAME, BASE_URL),
            )
        ).fetchone()
    return str(row["id"])


async def collect(
    conn: AsyncConnection,
    log_conn: AsyncConnection,
    client: YouthPolicyClient,
    *,
    today: date,
    scenario: str | None = None,
    hide_gone: bool = False,
) -> CollectResult:
    """conn은 데이터(autocommit, 정책마다 트랜잭션), log_conn은 실행 로그용이다. today는 KST 날짜다.
    온통청년 오류(YouthApiError)는 실행을 실패로 남기고 그대로 올라간다."""
    source_id = await ensure_source(conn)
    table = region_table()
    async with agent_run(log_conn, trigger="batch_crawl", scenario_code=scenario) as run:
        async with run.tool(FETCH_TOOL, {"page_size": 100, "scope": SCOPE}) as call:
            fetched = await client.fetch_all()
            call.output = fetched.summary()
        result = CollectResult(run_id=run.id, fetch=fetched)
        tool_input = {"policies": len(fetched.policies), "hide_gone": hide_gone}
        async with run.tool(BUILD_TOOL, tool_input) as call:
            known = await _known(conn, source_id)
            skipped: dict[str, Skip] = {}
            for policy in fetched.policies:
                converted = convert(policy, today, table)
                if isinstance(converted, Skip):
                    skipped[str(policy["plcyNo"])] = converted
                    result.skips[converted.reason] += 1
                elif known.get(converted.external_id) == (converted.content_hash, "active"):
                    result.counts["unchanged"] += 1  # 같고 활성인 공고는 DB에 다시 가지 않는다
                else:
                    result.counts[await save_policy(conn, source_id, converted, run.id)] += 1
            expired, hidden, result.gone_kept = await retire(
                conn,
                source_id,
                skipped,
                {str(policy["plcyNo"]) for policy in fetched.policies},
                known,
                complete=fetched.complete,
                hide_gone=hide_gone,
            )
            result.counts["expired"] += expired
            result.counts["hidden"] += hidden
            await conn.execute(
                "update sources set last_collected_at = now() where id = %s", (source_id,)
            )
            call.output = {
                "saved": dict(result.counts),
                "skipped": dict(result.skips),
                "gone_kept": result.gone_kept,
            }
    return result


async def _known(conn: AsyncConnection, source_id: str) -> dict[str, tuple[str | None, str]]:
    """이미 넣은 정책: 번호 → (content_hash, 상태). 정책마다 DB를 오가지 않게 한 번에 읽는다."""
    rows = await (
        await conn.execute(
            "select external_id, content_hash, status::text from opportunities"
            " where source_id = %s",
            (source_id,),
        )
    ).fetchall()
    return {row["external_id"]: (row["content_hash"], row["status"]) for row in rows}


async def save_policy(
    conn: AsyncConnection, source_id: str, record: PolicyRecord, run_id: str
) -> Saved:
    """정책 한 건을 한 트랜잭션으로 넣는다. 제목·기관·주소도 변환 결과(content_hash)에 들어 있다."""
    async with conn.transaction():
        existing = await (
            await conn.execute(
                "select id, content_hash from opportunities"
                " where source_id = %s and external_id = %s for update",
                (source_id, record.external_id),
            )
        ).fetchone()
        saved: Saved = "new" if existing is None else "updated"
        if existing is not None and existing["content_hash"] == record.content_hash:
            opportunity_id, saved = str(existing["id"]), "unchanged"
        else:
            opportunity_id = await _upsert(conn, source_id, record)
            await save_extraction(
                conn,
                opportunity_id,
                _as_extraction(record),
                run_id=run_id,
                content_hash=record.content_hash,
            )
        await conn.execute(_RESTORE, (opportunity_id,))
    return saved


async def _upsert(conn: AsyncConnection, source_id: str, record: PolicyRecord) -> str:
    row = await (
        await conn.execute(
            "insert into opportunities (source_id, source_type, external_id, category, title,"
            " organizer, original_url, raw_text) values (%(source_id)s, 'youth_policy',"
            " %(external_id)s, 'youth_policy', %(title)s, %(organizer)s, %(url)s,"
            " %(raw_text)s) on conflict (source_id, external_id) do update set"
            " title = excluded.title, organizer = excluded.organizer,"
            " original_url = excluded.original_url, raw_text = excluded.raw_text"
            " returning id",
            {
                "source_id": source_id,
                "external_id": record.external_id,
                "title": record.title,
                "organizer": record.organizer,
                "url": record.original_url,
                "raw_text": record.raw_text,
            },
        )
    ).fetchone()
    return str(row["id"])


async def retire(
    conn: AsyncConnection,
    source_id: str,
    skipped: dict[str, Skip],
    fetched: set[str],
    known: dict[str, tuple[str | None, str]],
    *,
    complete: bool,
    hide_gone: bool = False,
) -> tuple[int, int, int]:
    """범위를 벗어난 활성 공고를 만료·숨김으로 바꾼다. (만료 수, 숨김 수, 숨기지 않은 사라진 정책 수).

    known은 이번 수집 전에 읽은 넣은 정책(_known)이다. 목록에서 사라진 정책은 빠짐없이 받았을 때만 숨기고,
    한 번에 너무 많이 사라졌으면 hide_gone일 때만 숨긴다."""
    closed = [number for number, skip in skipped.items() if skip.expired]
    out = [number for number, skip in skipped.items() if not skip.expired]
    expired = (await conn.execute(_EXPIRE, (source_id, closed))).rowcount
    hidden = (await conn.execute(_HIDE, (source_id, out))).rowcount
    if not complete:
        return expired, hidden, 0
    active = {number for number, (_, status) in known.items() if status == "active"}
    gone = sorted(active - fetched)
    if not hide_gone and len(gone) > max(GONE_MIN, len(active) * GONE_SHARE):
        return expired, hidden, len(gone)
    hidden += (await conn.execute(_HIDE, (source_id, gone))).rowcount
    return expired, hidden, 0


_RESTORE = (
    "update opportunities set status = 'active' where id = %s and (status = 'hidden'"
    " or (status = 'expired' and (deadline_at is null or deadline_at > now())))"
)
_ACTIVE_OF_SOURCE = "where source_id = %s and status = 'active'"
_EXPIRE = (
    f"update opportunities set status = 'expired' {_ACTIVE_OF_SOURCE} and external_id = any(%s)"
)
_HIDE = f"update opportunities set status = 'hidden' {_ACTIVE_OF_SOURCE} and external_id = any(%s)"


def _as_extraction(record: PolicyRecord) -> ExtractionResult:
    """요건 저장(save_extraction)이 받는 모양. 코드로 만든 요건이라 신뢰도는 없다."""
    return ExtractionResult(
        succeeded=True,
        requirements=record.requirements,
        apply_start_at=record.apply_start_at,
        deadline_at=record.deadline_at,
        easy_summary=record.easy_summary,
        needs_review=bool(record.review_reasons),
        review_reasons=record.review_reasons,
    )
```

```python
def parse_args(argv: Sequence[str]) -> argparse.Namespace:

        prog="python -m app.youth.cli", description="온통청년 청년정책을 받아 공고로 넣는다"

    )
    return parser.parse_args(argv)


async def main(argv: Sequence[str], *, make_client: ClientFactory = YouthPolicyClient) -> int:
    args = parse_args(argv)
    settings = Settings()
    if not settings.youth_api_key.strip():
        print("YOUTH_API_KEY가 없어요. api/.env에 온통청년 OPEN API 인증키를 넣어 주세요")
        return 1
    today = datetime.now(KST).date()
    if args.dry_run:
        return await dry_run(make_client(settings.youth_api_key), today)
    if not settings.database_url:
        print("DATABASE_URL이 없어요(api/.env)")
        return 1
    try:
        conn, log_conn = (
            await _connect(settings.database_url),
            await _connect(settings.database_url),
        )
    except psycopg.OperationalError as exc:
        print(f"DB에 연결하지 못했어요: {exc}")
        return 1
    client = make_client(settings.youth_api_key)
    print("온통청년에서 정책을 받아 공고로 넣는 중이에요. 처음 넣을 때는 1~3분 걸려요", flush=True)
    try:
        result = await collect(
            conn,
            log_conn,
            client,
            today=today,
            scenario=args.scenario,
            hide_gone=args.hide_gone,
        )
    except YouthApiError as exc:
        print(str(exc))
        return 1
    except psycopg.Error as exc:
        # 정책마다 트랜잭션이라 앞에서 넣은 정책은 남는다. 다시 돌리면 같은 정책은 건너뛰고 이어서 넣는다
        first = (str(exc).splitlines() or [""])[0][:200]
        print(f"DB에 넣다가 멈췄어요({type(exc).__name__}: {first}). 넣은 정책은 남아 있어요")
        return 1
    finally:
        await client.aclose()
        await conn.close()
        await log_conn.close()
    _print_fetch(result.fetch, saving=True)
    saved = sum(result.counts[key] for key in _SAVED)
    print(
        f"가져올 정책 {saved}건: "
        + " · ".join(f"{name} {result.counts[key]}" for key, name in _SAVED.items())
    )
    skipped = sum(result.skips.values())
    print(
        f"가져오지 않은 정책 {skipped}건: {_reasons(result.skips)}"
        f" → 이미 넣은 공고 중 만료 {result.counts['expired']} · 숨김 {result.counts['hidden']}"
    )
    if result.gone_kept:
        print(
            f"목록에서 한 번에 {result.gone_kept}건이 사라져 숨기지 않았어요. 온통청년 목록이 덜 왔을 수"
            " 있어요. 온통청년에서 정말 내려간 정책이면 --hide-gone을 붙여 다시 돌려 주세요"
        )
    print(f"실행 기록: agent_runs {result.run_id}")
    return 1 if result.fetch.stopped else 0


async def dry_run(client: YouthPolicyClient, today: date) -> int:
    try:
        fetched = await client.fetch_all()
    except YouthApiError as exc:
        print(str(exc))
        return 1
    finally:
        await client.aclose()
    _print_fetch(fetched, saving=False)
    table = region_table()
    records: list[PolicyRecord] = []
    skips: Counter[str] = Counter()
    for policy in fetched.policies:
        converted = convert(policy, today, table)
        if isinstance(converted, Skip):
            skips[converted.reason] += 1
        else:
            records.append(converted)
    print(f"가져올 정책 {len(records)}건 · 가져오지 않음 {_reasons(skips)}")
    fields = Counter(
        label(_requirement(draft)) for record in records for draft in record.requirements
    )
    empty = sum(1 for record in records if not record.requirements)
    review = sum(1 for r in records if any(d.field == "other" for d in r.requirements))
    print(
        f"조건 없는 정책 {empty}건 · 기타 조건(원문 확인)이 있는 정책 {review}건 · 항목별 조건 수 "
        + " · ".join(f"{name} {count}" for name, count in fields.most_common())
    )
    print("DB에는 넣지 않았어요(--dry-run). 예시:")
    examples = [record for record in records if record.requirements][:EXAMPLES]
    for record in examples or records[:EXAMPLES]:
        deadline = record.deadline_at.strftime("%Y-%m-%d") if record.deadline_at else "없음"
        print(f"  {record.title} · {record.organizer or '-'} · 마감 {deadline}")
        for draft in record.requirements:
            requirement = _requirement(draft)
            text = condition_text(requirement)
            print(f"    {draft.clause_no}. {label(requirement)} {text[:120]}")
        if record.review_reasons:
            print(f"    원문 확인 필요: {', '.join(record.review_reasons)}")
    return 1 if fetched.stopped else 0


def _requirement(draft: RequirementDraft) -> Requirement:
    return Requirement(
        id="-",
        clause_no=draft.clause_no,
        field=draft.field,
        operator=draft.operator,
        value=draft.value,
        basis=draft.basis,
        is_ambiguous=draft.is_ambiguous,
        evidence_text=draft.evidence_text,
    )


def _print_fetch(fetched: FetchResult, *, saving: bool) -> None:
    print(
        f"온통청년 정책 {len(fetched.policies)}건 받음"
        f"(전체 {fetched.total}건, 호출 {fetched.calls}회, {round(fetched.seconds)}초)"
    )
    if fetched.skipped:
        print(f"읽지 못해 건너뛴 정책 {len(fetched.skipped)}건(순번 {list(fetched.skipped[:10])})")
    if fetched.stopped:
        print(f"끝까지 받지 못했어요: {fetched.stopped}")
    if saving and not fetched.complete:
        print("목록을 빠짐없이 받지 못해 목록에서 사라진 정책은 숨기지 않았어요")


def _reasons(skips: Counter[str]) -> str:
    return " · ".join(f"{reason} {count}" for reason, count in skips.most_common()) or "없음"


if __name__ == "__main__":
    utf8_output()  # 출력을 파이프로 보낼 때 cp949에 없는 글자에서 멈추지 않게(Windows)
    sys.exit(asyncio.run(main(sys.argv[1:]), loop_factory=event_loop_factory()))
```

```python
"""로그에서 토큰을 가린다 (PRD 7장 토큰 보안). 앱을 만들 때 install_log_redaction()을 한 번 부른다.

가리는 것: Authorization 헤더, Bearer 토큰, token=… 값, JWT, Google access·refresh token,
LearningX(Canvas) 개인 액세스 토큰, Fernet 암호문, Anthropic·Google API 키, 주소에 붙은 API 키
(온통청년 apiKeyNm=… 등). 요청 주소처럼 문자열이 아닌 인자도 문자열로 바꿔 보고 가릴 것이 있으면 가린다.
"""

import logging
import re
from collections.abc import Mapping
from typing import Any

_REDACTED = "[REDACTED]"
_PATTERNS: tuple[tuple[re.Pattern[str], str], ...] = (
    (
        re.compile(r"(?i)(authorization['\"]?\s*[:=]\s*['\"]?(?:bearer\s+)?)[^\s'\",}]+"),
        r"\1" + _REDACTED,
    ),
    (re.compile(r"(?i)(bearer\s+)[A-Za-z0-9._~+/=-]+"), r"\1" + _REDACTED),
    (
        re.compile(r"(?i)((?:access_|refresh_|provider_)?token['\"]?\s*[:=]\s*['\"]?)[^\s'\",}&]+"),
        r"\1" + _REDACTED,
    ),
    (re.compile(r"eyJ[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}"), _REDACTED),
    (re.compile(r"ya29\.[A-Za-z0-9._-]+"), _REDACTED),
    (re.compile(r"1//[A-Za-z0-9._-]{10,}"), _REDACTED),
    (re.compile(r"\b\d{2,6}~[A-Za-z0-9]{20,}"), _REDACTED),
    (re.compile(r"gAAAAA[A-Za-z0-9_=-]{20,}"), _REDACTED),
    (re.compile(r"sk-ant-[A-Za-z0-9_-]{20,}"), _REDACTED),
    (re.compile(r"AIza[0-9A-Za-z_-]{35}"), _REDACTED),
    # 주소에 붙은 키: apiKeyNm=…, api_key=…, x_api_key=…, serviceKey=…
    (
        re.compile(r"(?i)(?<![A-Za-z0-9])((?:apiKeyNm|api_?key|service_?key)=)[^&\s'\"]+"),
        r"\1" + _REDACTED,
    ),
)
# 이런 말이 든 서식 문자열이면 인자(문자열)를 통째로 가린다: logger.info("Authorization: %s", value)
_SENSITIVE_FORMAT = re.compile(r"(?i)authorization|bearer|token|secret|password|api[_-]?key")


def redact(text: str) -> str:
    for pattern, replacement in _PATTERNS:
        text = pattern.sub(replacement, text)
    return text


_installed = False


def install_log_redaction() -> None:
    """모든 로그 레코드의 메시지·인자·예외 내용에서 토큰을 가린다. 여러 번 불러도 한 번만 건다.

    인자가 있는 레코드는 서식 문자열을 건드리지 않고 인자만 가린다. 인자 개수와 타입이 그대로라서
    uvicorn 접근 로그처럼 인자를 직접 꺼내 쓰는 포매터도 깨지지 않는다.
    """
    global _installed
    if _installed:
        return
    previous = logging.getLogRecordFactory()
    formatter = logging.Formatter()

    def factory(*args: Any, **kwargs: Any) -> logging.LogRecord:
        record = previous(*args, **kwargs)
        if record.args:
            mask_all = isinstance(record.msg, str) and bool(_SENSITIVE_FORMAT.search(record.msg))

            def clean(item: Any) -> Any:
                if isinstance(item, str):
                    return _REDACTED if mask_all else redact(item)
                if item is None or isinstance(item, int | float):
                    return item
                try:
                    text = str(item)  # httpx 요청 로그의 주소(httpx.URL) 같은 객체
                except Exception:
                    return item  # 문자열로 못 바꾸는 값은 로그 쪽이 알아서 처리한다(부른 곳을 멈추지 않는다)
                cleaned = redact(text)
                return cleaned if cleaned != text else item

            if isinstance(record.args, Mapping):
                record.args = {key: clean(item) for key, item in record.args.items()}
            elif isinstance(record.args, tuple):
                record.args = tuple(clean(item) for item in record.args)
        elif isinstance(record.msg, str):
            record.msg = redact(record.msg)
        if record.exc_info and not record.exc_text:
            record.exc_text = redact(formatter.formatException(record.exc_info))
        return record

    logging.setLogRecordFactory(factory)
    _installed = True
```

```python
def _stale_sql(scope: str) -> str:
    """다시 판정할 공고와 그 요건."""
    return (
        "select o.id, o.requirements_version, o.eligibility_basis_date, o.deadline_at,"
        " o.apply_start_at, o.source_type::text as source_type,"
        " e.user_id is not null as had_result, e.status::text as old_status,"
        " e.missing_fields as old_missing, " + _REQUIREMENTS_JSON + " as requirements"
        " from opportunities o"
        + _COURSE_JOIN
        + _RESULT_JOIN
        + " where"
        + scope
        + " and"
        + _VISIBLE
        + " and o.extraction_run_id is not null"
        " and (%(force)s or e.user_id is null or e.evaluated_at is null"
        " or e.requirements_version <> o.requirements_version"
        " or e.engine_version <> %(engine)s"
        # 날이 바뀌면 다시: 기준일이 "오늘"인 공고(청년정책 포함), 엔진 오류로 판정하지 못한 공고(오류를
        # 고쳤을 수 있다)
        " or (((o.eligibility_basis_date is null and (o.deadline_at is null"
        " or (o.source_type = 'youth_policy' and o.deadline_at >= %(now)s)))"
        " or e.reason_text = %(engine_error)s)"
        " and (e.evaluated_at at time zone 'Asia/Seoul')::date < %(today)s))"
    )


def _feed_sql(where: str, outer: str, order: str) -> str:
    return (
        "with feed as (select o.id, o.title, o.organizer, o.category::text as category,"
        " o.source_type::text as source_type, o.deadline_at, o.created_at, o.easy_summary,"
        " o.needs_review, coalesce(o.uploaded_by = %(uid)s, false) as uploaded_by_me,"
        " c.name as course_name,"
        " exists(select 1 from prep_plans p where p.user_id = %(uid)s and p.opportunity_id = o.id)"
        " as prepared,"
        " coalesce(o.created_at >= %(new_since)s, false) and not exists(select 1"
        " from opportunity_views v where v.user_id = %(uid)s and v.opportunity_id = o.id) as is_new,"
        " " + _JUDGED + " as judged,"
        " case when " + _JUDGED + " then e.status::text else 'undetermined' end as eff_status,"
        " case when " + _JUDGED + " then coalesce(e.missing_fields, '{}') else '{}' end"
        " as eff_missing,"
        " e.reason_text"
        " from opportunities o" + _COURSE_JOIN + _RESULT_JOIN + " where" + where + ")"
        " select * from feed" + outer + " order by " + order + " limit %(limit)s"
    )


@dataclass(frozen=True)
class Cursor:
    scope: str  # 목록 조건(정렬·필터)의 지문. 조건이 다른 목록에는 쓸 수 없다
    # 마지막 행의 정렬 값(deadline: 마감 시각, recent: 등록 시각). 없을 수 있다
    value: datetime | None
    id: str


@dataclass(frozen=True)
class FeedQuery:
    eligibility: frozenset[str] | None = None  # None이면 전체
    categories: tuple[str, ...] | None = None
    source_types: tuple[str, ...] | None = None
    sort: Sort = "deadline"
    include_expired: bool = False
    limit: int = 20
    cursor: Cursor | None = None

    def scope(self) -> str:
        """cursor를 묶는 목록 조건의 지문. 정렬이나 필터를 바꾸면 목록을 처음부터 다시 부른다.

        같은 목록이면 지문도 같다: 값의 순서는 보지 않고, 모든 값을 고른 필터는 필터 없음과 같다.
        """
        parts = (
            self.sort,
            _filter_key(self.eligibility, ELIGIBILITY_STATUSES),
            _filter_key(self.categories, CATEGORIES),
            _filter_key(self.source_types, SOURCE_TYPES),
            str(self.include_expired),
        )
        return hashlib.sha256("|".join(parts).encode()).hexdigest()[:16]


def _filter_key(values: Collection[str] | None, everything: Collection[str]) -> str:
    chosen = set(values or ())
    return "" if chosen >= set(everything) else ",".join(sorted(chosen))

@dataclass(frozen=True)
class Refresh:
    judged: int  # 다시 계산한 공고 수
    changed: int  # 라벨이 바뀐 공고 수(전에 판정이 있던 공고만 센다)


def display_status(status: str, missing_fields: Sequence[str]) -> str:
    """화면 라벨 4종. 판정 불가는 입력하면 바뀔 수 있으면 정보 필요, 아니면 원문 확인 필요다."""
    if status == "undetermined":
        return "missing_info" if missing_fields else "needs_review"
    return status


def encode_cursor(cursor: Cursor) -> str:
    data = {
        "q": cursor.scope,
        "v": cursor.value.isoformat() if cursor.value else None,
        "id": cursor.id,
    }
    raw = json.dumps(data, separators=(",", ":")).encode()
    return base64.urlsafe_b64encode(raw).decode().rstrip("=")


def decode_cursor(text: str) -> Cursor:
    """next_cursor로 준 값을 되돌린다. 모양이 틀리면 ValueError."""
    try:
        data = json.loads(base64.urlsafe_b64decode(text + "=" * (-len(text) % 4)))
        scope, value, ident = data["q"], data["v"], data["id"]
        if not isinstance(scope, str) or not isinstance(ident, str):
            raise ValueError(scope)
        moment = None if value is None else datetime.fromisoformat(value)
        if moment is not None and moment.tzinfo is None:
            raise ValueError(value)
        return Cursor(scope=scope, value=moment, id=str(uuid.UUID(ident)))
    except (binascii.Error, ValueError, KeyError, TypeError, UnicodeDecodeError) as exc:
        raise ValueError("잘못된 cursor") from exc


class OpportunityRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def refresh_judgments(
        self,
        user_id: str,
        *,
        now: datetime,
        force: bool = False,
        include_expired: bool = False,
        display_name: str | None = None,
    ) -> Refresh:
        """피드에 나올 공고(include_expired면 지난 공고까지)의 낡은 판정을 다시 계산해 저장한다.

        force면 그 공고를 모두 다시 판정하고 나머지 공고의 판정은 지운다.
        프로필 행이 없으면(첫 요청이 피드) display_name과 함께 만든다.
        """
        profile = Profile.from_row(await self._lock_profile(user_id, display_name))
        today = now.astimezone(KST).date()
        stale = await (
            await self.conn.execute(
                _stale_sql(_WITH_EXPIRED if include_expired else _ACTIVE),
                {
                    "uid": user_id,
                    "now": now,
                    "force": force,
                    "engine": ENGINE_VERSION,
                    "engine_error": ENGINE_ERROR_SUMMARY,
                    "today": today,
                },
            )
        ).fetchall()
        payload: list[dict[str, Any]] = []
        changed = 0
        if stale:
            departments = await self._departments()
            for item in stale:
                judged = _judge(item, profile, departments, today)
                payload.append(_payload(item, judged.stored))
                old = display_status(item["old_status"] or "", item["old_missing"] or ())
                if item["had_result"] and old != judged.label:
                    changed += 1
        await self._upsert(user_id, payload, now)
        if force:  # 다시 판정하지 않은 공고(마감·숨김·안 보임)의 판정은 지운다
            await self.conn.execute(
                "delete from eligibility_results"
                " where user_id = %s and opportunity_id <> all(%s::uuid[])",
                (user_id, [item["opportunity_id"] for item in payload]),
            )
        else:  # 요건 추출에 실패한 공고의 옛 판정은 지운다(판정하지 않는다)
            await self.conn.execute(
                "delete from eligibility_results e using opportunities o"
                " where e.user_id = %s and e.opportunity_id = o.id and o.extraction_run_id is null",
                (user_id,),
            )
        return Refresh(judged=len(payload), changed=changed)

    async def detail(
        self,
        user_id: str,
        opportunity_id: str,
        *,
        now: datetime,
        display_name: str | None = None,
    ) -> OpportunityDetail | None:
        """공고 상세(S1-6). 이 사용자에게 보이지 않는 공고면 None이다.

        피드와 같은 잠금 아래에서 그 공고를 다시 판정해 저장하고, 조회 기록을 남긴다(is_new가 꺼진다).
        """
        profile_row = await self._lock_profile(user_id, display_name)
        row = await (
            await self.conn.execute(_DETAIL, {"uid": user_id, "oid": opportunity_id})
        ).fetchone()
        if row is None:
            return None
        if row["extraction_run_id"] is None:  # 요건 추출에 실패한 공고는 판정하지 않는다
            await self.conn.execute(
                "delete from eligibility_results where user_id = %s and opportunity_id = %s",
                (user_id, opportunity_id),
            )
            eligibility = DetailEligibility(
                status="undetermined",
                display_status="needs_review",
                reason_text=UNJUDGED_SUMMARY,
                basis_date=None,
                requirements_version=row["requirements_version"],
                missing_fields=[],
                clauses=[],
                conditions=[],
                evaluated_at=None,
            )
        else:
            profile = Profile.from_row(profile_row)
            departments = await self._departments()
            judged = _judge(row, profile, departments, now.astimezone(KST).date())
            await self._upsert(user_id, [_payload(row, judged.stored)], now)
            eligibility = _detail_eligibility(
                judged, profile, departments, row["requirements_version"], now
            )
        await self.conn.execute(_VIEW, (user_id, opportunity_id, now, now))
        names = {item["seq"]: item["file_name"] for item in row["attachments"]}
        apply_start: datetime | None = row["apply_start_at"]
        deadline: datetime | None = row["deadline_at"]
        confidence = row["extraction_confidence"]
        return OpportunityDetail(

    async def feed_page(self, user_id: str, query: FeedQuery, *, now: datetime) -> FeedPage:
        params: dict[str, Any] = {
            "uid": user_id,
            "now": now,
            "new_since": now - timedelta(days=NEW_DAYS),
            "limit": query.limit + 1,
        }
        where = [_WITH_EXPIRED if query.include_expired else _ACTIVE, _VISIBLE, _SHOWN]
        if query.categories:
            where.append(" o.category::text = any(%(categories)s)")
            params["categories"] = list(query.categories)
        if query.source_types:
            where.append(" o.source_type::text = any(%(source_types)s)")
            params["source_types"] = list(query.source_types)
        outer = []
        if query.eligibility:
            outer.append("eff_status = any(%(eligibility)s)")
            params["eligibility"] = sorted(query.eligibility)
        if query.cursor:
            outer.append(_after(query.sort, query.cursor))
            params["cursor_value"], params["cursor_id"] = query.cursor.value, query.cursor.id
        sql = _feed_sql(
            " and".join(where),
            " where " + " and ".join(outer) if outer else "",
            _ORDER[query.sort],
        )
        rows = await (await self.conn.execute(sql, params)).fetchall()
        today = now.astimezone(KST).date()
        page = rows[: query.limit]
        next_cursor = None
        if len(rows) > query.limit:
            last = page[-1]
            value = last["deadline_at"] if query.sort == "deadline" else last["created_at"]
            cursor = Cursor(scope=query.scope(), value=value, id=str(last["id"]))
            next_cursor = encode_cursor(cursor)
        return FeedPage(items=[_item(row, today) for row in page], next_cursor=next_cursor)

    async def _lock_profile(self, user_id: str, display_name: str | None) -> dict[str, Any]:
        """프로필 행을 (없으면 만들고) 잠근 뒤 읽는다.

def _after(sort: Sort, cursor: Cursor) -> str:
    """정렬 순서(_ORDER)에서 cursor 다음에 오는 행. 값이 없는 행은 맨 뒤에 id 순으로 온다."""
    column, beyond = ("deadline_at", ">") if sort == "deadline" else ("created_at", "<")
    if cursor.value is None:
        return f"({column} is null and id {beyond} %(cursor_id)s)"
    return (
        f"({column} {beyond} %(cursor_value)s"
        f" or ({column} = %(cursor_value)s and id {beyond} %(cursor_id)s) or {column} is null)"
    )

@dataclass(frozen=True)
class _Judged:
    stored: dict[str, Any]  # eligibility_results에 넣을 값(Judgment.storage_row 모양)
    label: str  # display_status
    judgment: Judgment | None  # 엔진이 오류를 냈으면 None
    requirements: tuple[Requirement, ...]
    basis_date: date | None


def _judge(
    item: dict[str, Any], profile: Profile, departments: list[Department], today: date
) -> _Judged:
    """공고 행 하나(requirements·eligibility_basis_date·deadline_at)를 판정한다.

    엔진 오류면 "판정하지 못함" 행을 돌려준다: 그 공고만 원문 확인 필요로 보인다.
    """
    basis: date | None = None
    try:
        requirements = tuple(Requirement.from_row(r) for r in item["requirements"])
        days = _basis_dates(item, today)
        basis = days[0]
        # 기준일이 둘이면(청년정책) 더 나은 쪽을 쓴다. 같으면 앞 날짜다(max는 처음 나온 것을 고른다)
        judgment = max(
            (
                check_eligibility(
                    list(requirements), profile, basis_date=day, departments=departments
                )
                for day in days
            ),
            key=lambda found: _RANK[found.status],
        )
        return _Judged(
            judgment.storage_row(),
            judgment.display_status,
            judgment,
            requirements,
            judgment.basis_date,
        )
    except Exception:
        logger.exception("판정하지 못한 공고: %s", item["id"])
        return _Judged(_engine_error_row(), "needs_review", None, (), basis)


_RANK = {"ineligible": 0, "undetermined": 1, "eligible": 2}


def _basis_dates(item: dict[str, Any], today: date) -> tuple[date, ...]:
    """판정 기준일(판정엔진_규칙.md 8장). 보통 하나다(공고 기준일 → 마감일 → 오늘).

    청년정책(온통청년)은 신청일 기준이 대부분이고 신청 기간이 몇 년인 정책도 있다. 그래서 신청할 수 있는 첫날
    (오늘, 신청 기간 전이면 시작일)과 마감일을 둘 다 보고 더 나은 결과를 쓴다. 나이 상한은 첫날에, 하한은
    마감일에 맞으면 그 사이 어느 날엔 신청할 수 있다. 신청 기간이 끝났으면 마감일 하나다."""
    if item["source_type"] != "youth_policy" or item["eligibility_basis_date"] is not None:
        return (resolve_basis_date(item["eligibility_basis_date"], item["deadline_at"], today),)
    start = item["apply_start_at"]
    first = max(today, to_kst_date(start)) if start is not None else today
    if item["deadline_at"] is None:
        return (first,)
    deadline = to_kst_date(item["deadline_at"])
    return (deadline,) if deadline <= first else (first, deadline)

def _step(step: dict[str, Any], names: dict[int, str]) -> ProcessStep:
    """처리 과정 한 줄(_DETAIL의 steps 행 하나). 첨부를 읽은 단계는 첨부 이름을 넣어 보인다.

    도구가 오류를 돌려준 호출(없는 첨부 번호 등)과 거절된 제출은 실행 로그에 succeeded로 남는다
    (에이전트는 오류를 모델에 돌려주고 계속 간다). 화면에는 실패로 보인다. 첨부 번호·위치는
    에이전트와 같은 규칙(whole)으로 읽는다. 읽기·토큰 상한에 닿아 코드가 시킨 제출(forced)은
    모델이 고른 단계가 아니라서 pipeline으로 보인다.
    """
    tool: str = step["tool"]
    again = "이어 " if _continued(step) else ""
    if tool in (READ_TEXT, READ_IMAGE):
        number = whole(step.get("attachment_no"))
        name = names.get(number) if number is not None else None
        target = f"첨부 '{name}'" if name else f"첨부 {number}번" if number else "첨부"
        how = "이미지로 " if tool == READ_IMAGE else ""
        label = f"{target} {how}{again}읽기"
    elif tool == FETCH_ORIGINAL:
        label = f"공고 원문 페이지 {again}읽기"
    elif tool == FETCH_YOUTH:
        label = "온통청년에서 정책 정보 받기"
    elif tool == BUILD_YOUTH:
        label = "온통청년 항목으로 지원 자격 정리"
    else:
        label = "지원 자격 정리" if tool == SUBMIT else tool
    failed = step.get("error") is True or (tool == SUBMIT and step.get("accepted") is False)
    chosen = tool in _AGENT_TOOLS and step.get("forced") is not True
    return ProcessStep(
        seq=step["seq"],
        tool=tool,
        label=label,
        status="failed" if failed else step["status"],
        latency_ms=step["latency_ms"],
        chosen_by="agent" if chosen else "pipeline",
        note=_line(step.get("reason")),
    )


def _continued(step: dict[str, Any]) -> bool:
    """앞에서 읽은 곳의 뒷부분을 읽은 호출. 도구가 실제로 읽은 위치를 보고, 오류면 요청한 위치를 본다.

    글자 읽기·원문 읽기는 시작 위치(offset)가 0보다 크면, Vision은 PDF를 2쪽부터 읽었으면 이어 읽기다.
    이미지는 한 장이라 이어 읽기가 없다.
    """
    if step["tool"] != READ_IMAGE:
        offset = whole(step.get("offset"))
        return offset is not None and offset > 0
    pages = step.get("pages")  # 읽은 PDF 쪽 "4–6/8". 이미지는 없다
    if isinstance(pages, str) and (first := _PAGES.match(pages)):
        return int(first.group(1)) > 1
    if step.get("error") is not True:
        return False  # 이미지를 읽었다
    start_page = whole(step.get("start_page"))
    return start_page is not None and start_page > 1


def _line(text: Any) -> str | None:
    """모델이 쓴 글(고른 이유, 원문 확인 필요 이유)을 화면용 한 줄로: 보이지 않는 문자(폭 없는 문자,
    글자 방향 제어)와 주소를 지우고 공백·줄바꿈을 한 칸으로 줄여 LINE_MAX_CHARS자까지. 남는 글이
    없으면 None이다.

    공고 글을 읽은 모델이 쓴 글이라, 공고 속 지시문이 링크를 끼워 넣지 못하게 쉬운 설명과 같은 규칙으로
    정리한다(app/extraction/validate.py). 저장된 값을 읽을 때 정리해서 예전 행에도 같이 적용된다.
    화면은 이 글을 일반 텍스트로 보여 준다(자동 링크·마크다운 없이).
    """
    if not isinstance(text, str):
        return None
    line = " ".join(_LINK.sub("", _INVISIBLE.sub("", text)).split())
    if len(line) > LINE_MAX_CHARS:
        line = line[: LINE_MAX_CHARS - 1].rstrip() + "…"
    return line or None


def _lines(texts: Sequence[Any] | None) -> list[str]:
    """여러 줄을 _line으로 정리한다. 빈 줄과 같은 줄은 빼고, REASONS_MAX줄이 넘으면 "외 N건"으로 줄인다."""
    lines = list(dict.fromkeys(line for text in texts or () if (line := _line(text))))
    if len(lines) > REASONS_MAX:
        return [*lines[:REASONS_MAX], f"외 {len(lines) - REASONS_MAX}건"]
    return lines


def _attachment(item: dict[str, Any]) -> AttachmentItem:
    if item["error"]:
        status = "failed"
    elif item["method"]:
        status = "succeeded"
    else:
        status = "skipped"  # 에이전트가 읽지 않은 첨부
    return AttachmentItem(
        id=str(item["id"]),
        file_name=item["file_name"],
        source_url=item["source_url"],
        extract_status=status,
    )


def _text(value: Any) -> str | None:
    return str(value) if value is not None else None
```

```python
        skipped: tuple[int, ...] = (),
        stopped: str | None = None,
        error: str | None = None,
    ) -> None:
        self.items = items
        self.skipped = skipped
        self.stopped = stopped
        self.error = error
        self.closed = False

    async def fetch_all(self) -> FetchResult:
        if self.error:
            raise YouthApiError(self.error)
        return FetchResult(
            policies=tuple(self.items),
            total=len(self.items) + len(self.skipped),
            calls=1,
            skipped=self.skipped,
            stopped=self.stopped,
            total_changed=False,
            seconds=0.1,
        )

    async def aclose(self) -> None:
        self.closed = True


async def skip_if_other_youth_policies(conn: Any, prefix: str) -> None:
    """청년정책 공고가 이미 있는 DB면 건너뛴다. 빠짐없이 받은 수집은 목록에 없는 공고를 숨기므로 그 DB의
    공고를 숨기거나(CLI는 autocommit) 숫자가 어긋난다. CI의 빈 DB에서 돈다."""
    cursor = await conn.execute(
        "select count(*) from opportunities where source_type = 'youth_policy'"
        " and external_id not like %s",
        (prefix + "%",),
    )
    row = await cursor.fetchone()
    count = row["count"] if isinstance(row, dict) else row[0]
    if count:
        pytest.skip(f"청년정책 공고가 {count}건 있는 DB라 건너뜀(빈 DB에서 돈다)")
```

```python
def server(
    items: list[dict[str, str]],
    *,
    broken: Callable[[int, int], bool] = lambda start, size: False,
    total: Callable[[int, int], int] | None = None,
) -> Callable[[httpx.Request], httpx.Response]:
    """getPlcy 흉내. broken(시작 순번, 쪽 크기)이 참이면 500이다. total(시작 순번, 쪽 크기)은 totCount다."""

    def handle(request: httpx.Request) -> httpx.Response:
        params = request.url.params
        assert params["apiKeyNm"] == KEY and params["rtnType"] == "json"
        num, size = int(params["pageNum"]), int(params["pageSize"])
        start = (num - 1) * size
        if broken(start, size):
            return httpx.Response(500, json={"status": 500, "error": "Internal Server Error"})
        body = {
            "resultCode": 200,
            "resultMessage": "성공적으로 데이터를 가지고 왔습니다.",
            "result": {
                "pagging": {
                    "totCount": total(start, size) if total else len(items),
                    "pageNum": num,
                    "pageSize": size,
                },
                "youthPolicyList": items[start : start + size],
            },
        }
        return httpx.Response(200, json=body)

    return handle
```
